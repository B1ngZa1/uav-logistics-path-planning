## 2.3.2 多机协同作战环境构建

## 第3章 基于注意力 Seq2Seq 框架的强化多无人机协同侦查任务规划

## 3.1 引言

从自顶向下研究方向下，实现无人机协同任务规划，首先要建立合理的协同侦查任务规划模型，在第二章本文分析协同侦察任务规划问题的关键要素，包括环境的信息，侦察节点的生存概率，无人机的续航里程等，在此基础上，对问题的关键因素和约束条件进行数学化描述，建立了合理的数学模型。其次要针对该模型采用合理的方法进行求解。通过分析，可知该问题本质上是一个组合优化问题，同时也是一个 NP 问题[4]。针对这个优化问题，典型的群体智能算法，往往只能给出静态环境下的特定解，针对环境信息可变模型，当数据变动时，需要重新优化，实时性差。

针对该问题，本文提出了一种基于强化学习与 Seq2Seq 神经网络框架的多无人机任务规划方法，首先，基于 Transformer 注意力神经网络搭建了 Seq2Seq 框架的求解模型，能够针对模型数据，求解出合理的多机协同侦察序列，然后，通过基于模型的强化学习算法，对求解模型不断优化，最终得到近似最优解模型。通过从协同侦察数学模型的数据空间中随机采样问题样本，使得模型对整个问题空间样本均能得出有效解，大大改善了求解模型的动态性，其次，基于 Transformer的求解模型在求解速度上，远远优于传统群体智能算法，解决了经典群体智能算法实时性差的问题。

## 3.2 Seq2Seq 框架与 Transformer 模型

Seq2Seq 框架是一种用于映射可变长度序列到另一可变长度序列的 RNN 架构[30]，2014 年由 Choet al.提出，由 Sukskever 在翻译应用中使用。该技术突破了传统固定大小输入问题框架，开通了将经典深度神经网络运用于翻译与智能问答这一类序列型任务的先河，并被证实在翻译领域以及人机问答、快答应用中具有不俗的表现[31]。

Seq2Seq 框架解决问题的主要思路是通过深度神经网络将一个作为输入的序列映射为一个作为输出的序列，这一过程由编码输入与解码输出两个环节组成。其中负责处理输入序列的神经网络称为编码器(encoder)，负责接收编码器的输入并产生输出序列的神经网络成为解码器(decoder)，编码器将序列数据映射为一个中间向量，解码器负责从中间向量中解码出期望的序列数据。该架构主要创新之处为编码器和解码器的长度可以不同，因此可以处理可变长度序列。Seq2Seq 的整体框架如图 3-1，该模型每一时刻的输入与输出是不一样的，对于序列项依次传入，每个序列项对应不同的输出。如上图所示，现有序列“Howare you EOL”作为输入，那么我们的目的就是将该序列输入网络中之后，将其映射为序列“I amfine EOL”输出。

在编码器中，各类长度不同的输入序列 X，一般将会由循环神经网络(Recurrent neural Network, RNN)构建的编码器编译为中间向量 c，该向量 c 通常为RNN 中最后一个状态 h，或是多个节点的状态 h 加权总和，如公式 3-1。

$$
\begin{array} { r } { \mathbf { h } _ { t } = f ( x _ { t } , \pmb { h } _ { t - 1 } ) } \\ { \mathbf { c } = \emptyset \big ( \{ \pmb { h } _ { 1 } \cdots \pmb { h } _ { T _ { s } } \} \big ) } \end{array}\tag{3-1}
$$

编码完成后，中间向量 c 将会进入解码器进行译码。解码的过程可以被理解

为运用贪心算法来返回对应概率最大的序列，或通过集束搜索在序列输出前检索大量的序列，从而得到最优的选择，如公式 3-2。

$$
\begin{array} { c } { { \pmb { s } _ { t } = f ( y _ { t - 1 } , \pmb { s } _ { t - 1 } , \pmb { c } ) } } \\ { { \pmb { p } ( y _ { t } | y _ { < t } , \pmb { X } ) = g ( y _ { t - 1 } , \pmb { s } _ { t - 1 } , \pmb { c } ) } } \end{array}\tag{3-2}
$$

为了解决 RNN 输出的中间向量 c的维度太小而难以适当地概括一个长序列，Bahdanau, D.在 2015 年在 Seq2Seq 框架引入了注意力机制[32] (attention mechanism)，通过将中间向量 c 的元素和输出序列的元素相关联，使解码过程可以聚焦于输入序列的不同部分来收集产生下一个输出序列所需的编码细节，每个时间步关注输入序列的特定部分，这使得该网络的性能得到了明显改善。

然而基于 RNN 网络的 Seq2Seq 结构存在网络训练时间长，难以较好实现并行计算的问题。谷歌在 2017 年提出了 Transformer 模型，抛弃了传统的时序结构，并且在语序特征的提取效果较传统的 RNN、LSTM 更好[33]，逐渐被应用至各个领域，如 GPT 模型[34]以及谷歌最新提出的 Bert 模型[35]等。

Transformer 模型结构如图 3-2 所示。该模型整体上仍使用了 Seq2Seq 的Encoder-Decoder 框架。其 encoder 组件由 6 个 encoder 共同堆叠而成，每个 encoder又包括 self-attention 和 Feed Forward Neural Network 两层网络组成。Decoder 组件组成也基本如此，但是在 self-attention 和 Feed-Forward 间添加了一层 Encoder-Decoder Attention 用于关注 Encoder 的编码信息。

该结构对于输入序列信息，首先将序列数据编码为向量(Embedding 操作)，然后输入 Self-attention 层。对于每一个输入 Embedding 向量 X，网络定义了三个 64维参数向量矩阵 $W ^ { Q }$ 、 $W ^ { K }$ 、 $W ^ { V }$ ，分别对应输入的三个向量:querys、keys、values，得到输入序列中子序列于其他子序列之间的区分，以确定在某个位置编码特定子序列时，需要聚焦的子序列，其计算公式如公式 3-3。

$$
\begin{array} { c } { { \mathrm {  ~ Q = X W } ^ { Q } } } \\ { { \mathrm {  ~ K = X W } ^ { K } } } \\ { { \mathrm {  ~ V = X W } ^ { V } } } \\ { { \mathrm {  ~ Z = } s o f t m a x \left( \frac { Q K ^ { T } } { \sqrt { d _ { k } } } \right) * \mathrm {  ~ V ~ } } } \end{array}\tag{3-3}
$$

通过矩阵间的运算能得到输入序列潜在的语义信息，最后经过 softmax 操作得到每个子序列被关注程度的分值(权重)，其中 $\sqrt { d _ { k } }$ 可以调节内积的大小，防止内积进入 softmax 溢出区。

## 3.3 Seq2Seq 框架解决协同侦察任务规划关键问题

在多无人机协同侦察任务规划问题中，对多个敌方目标的侦查规划，等同于在当前战场环境条件下给出合理的侦查路径序列，然而，求解多机协同侦察任务规划问题与求解序列问题又有显著区别，主要体现在:

1. 在多无人机协同规划问题中，侦查目标的信息是并非是序列相关的，因此需要对序列模型的编码器进行修改，防止侦查节点目标的顺序对生成的侦查路径造成影响。

2. 在求解序列问题时，输入序列之间的约束是隐形的，如翻译应用中的语言语法约束是不可见的，然而在多无人机协同规划问题中，任务的目标是清晰的，能侦查到的数据以及无人机本身的信息是已知的，因此执行任务时对执行序列的约束是可见的，如何在编码器规划路径的过程中，加入多无人机的侦察侦察约束，是本文的工作之一。

3. 大部分序列模型是监督模型，而多无人机协同侦查问题只有优化目标，因此如何通过优化目标优化序列模型，使规划出的路径相对最优，是本文的工作之。

基于 Seq2Seq 框架的思想，本文提出了基于注意力机制的协同侦察任务规划求解模型，在谷歌 Transformer 序列模型的基础上，对无人机协同任务规划问题的特性进行了定性适配，使其能够对多无人机协同规划多目标组合优化问题进行优化求解。协同侦察序列模型通过训练一个任务分配策略 $p ( \pi | s )$ ，从当前战场的约束 条 件 中 给 出 任 务 规 划 ， 如 公 式 3-5 。 定 义 给 出 的 规 划 序 列 为 $\pi =$ $( \pi _ { 1 } , \cdots , \pi _ { N _ { T } } ) , \ \pi _ { t } \in T$ ，s 为当前规划问题的实例。

$$
p _ { \theta } ( \pi | s ) = \prod _ { t = 1 } ^ { n } \mathfrak { p } _ { \theta } ( \pi _ { t } | s , \pi _ { 1 : t - 1 } )\tag{3-5}
$$

侦察节点的坐标的 embeddings 编码通过协同侦察序列模型的编码器，解码器处理后，利用掩码机制来约束解码过程，给出合理的任务规划序列??。

## 3.4 协同侦察任务规划求解模型的构建

## 3.4.1 编码器

本文协同侦察序列模型的编码器结构基于 Transformer 模型的编码器修改而成，主要解决了侦察节点序列非相关性对编码器的干扰问题。

在多无人机协同侦察问题中，各个侦察节点的相关信息并非是序列相关的，而 Transformer 模型编码器默认会对数据的序列相关性进行学习。因此，本文采用的编码器结构并没有使用 Position Embedding 层[33]。在编码器的设计上，首先将节点的信息映射为 $\mathrm { \Delta } \mathrm { d } _ { h } = 1 2 8$ 维的 Node embeddings，然后进行编码处理。为了区分在侦察模型中的基地节点与侦察节点，在线性映射层中，使用了不同的参数：

$$
\mathsf { h } _ { i } ^ { ( 0 ) } = \left\{ _ { W _ { 0 } ^ { x } ( x _ { i } , y _ { i } ) + b _ { 0 } ^ { x } , i = 1 , \ldots n } ^ { \mathsf { W } ^ { x } ( x _ { i } , y _ { i } ) + b _ { 0 } ^ { x } , i = 0 } \right.\tag{3-6}
$$

其中， $\mathsf { W } ^ { x } , b ^ { x }$ 为的线性映射层的参数。

<!-- image-->  
图 3-4 编码器网络结构  
Fig. 3-4 Structure of encoder layer

经过编码的节点信息通过 N 层注意力层，其中注意力层由 Multi-headattention(MHA)和 node-wise fully connection feed-forward(FF)层两个子层构成，各子层输入与输出使用 sikp-connection 连接，编码器的网络结构如图 3-4 所示，其中 skip-connection 的设计灵感是来自于微软的 ResNet，解决了网络层数加深之后反而学习效果变差的问题，是现代神经网络广泛采用的设计理念之一[36]。

$$
\widehat { h } _ { i } = B N ^ { l } \left( h _ { i } ^ { ( l - 1 ) } + M H A \left( h _ { 1 } ^ { ( l - 1 ) } , \cdots , h _ { n } ^ { ( l - 1 ) } \right) \right)\tag{3-7}
$$

$$
\mathrm { H } _ { i } ^ { ( l ) } = B N ^ { l } \left( \widehat { h } _ { i } + F F ^ { l } ( \widehat { h } _ { i } ) \right)\tag{3-8}
$$

注意力层编码处理的计算公式如(3-7)(3-8)，定义 $\mathsf { h } _ { i } ^ { ( l ) }$ 为第 l 层产生的节点embedding， $l \in \{ 1 , \cdots , N \}$ ，其中带有上标的 BN 和 MHA 代表层之间不共享参数，其中 MHA 层使用 M=8 个 heads，每个的维度为 $\begin{array} { r } { \frac { \mathrm { d } _ { h } } { M } = 1 6 } \end{array}$ 。FF 层使用了一个隐含层，维度为 512，使用 Relu 激活函数。在实际的实验过程中，测试表示使用 batchnormalization(BN)正则化[37]效果好于 Transformer 编码器的正则化层，因此本文采用了 batch normalization(BN)对网络的输出进行正则化。

在解码器最后一层，通过计算网络输出层 embedding 的平均值得到 graphembedding ： $\begin{array} { r } { \bar { \mathsf { h } } ^ { ( N ) } = \frac { 1 } { n } \sum _ { i = 1 } ^ { n } h _ { i } ^ { ( N ) } } \end{array}$ ，然后将输出层 embedding 和 graph embedding 传递解码器。

## 3.4.4 优化目标与强化学习奖励机制

由掩码机制可知，解码器做出的任务规划序列是符合约束条件的，但一开始序列神经网络的参数是随机的，无法保证模型的性能表现，需要随序列神经网络参数进行优化。而多无人机协同规划问题并非是一个监督学习问题，模型无法从标签数据中获得性能提升。为了改善模型的性能表现，本文采用了 REINFORCE强化学习算法[7]来改善模型的参数，通过将协同规划数学模型中的优化目标与强化学习算法的损失函数相结合，使强化学习算法可以为序列模型网络规划出的路径打分，并通过不断地训练，最大化目标分值达到改序列模型性能表现的目的。

REINFORCE 算法是一种策略梯度算法，策略梯度强化学习算法直接使用神经网络来表示策略，此时策略可以表示为参数化的策略函数: $\pi _ { \theta } = \mathrm { P } ( \mathsf { a } | \mathsf { s } , \theta ) \approx$ π(a|s)。

策略函数确定了在给定的状态和一定的参数设置下，采取任何行为的概率，因此事实上它是一个概率密度函数。在实际应用策略产生行为时，是按照这个概率分布进行行为采样的。策略函数的参数决定了概率分布的形态。

通过设计一个优化目标，可以衡量策略的好坏，并尽可能的优化策略，获得更多的奖励。在无人机协同侦查问题模型中，定义优化的目标函数为：

$$
\begin{array} { r l r } {  { \boldsymbol { J } ( \theta ) = \sum _ { s } d _ { \pi _ { \theta } } ( s ) \sum _ { a } \boldsymbol { \pi } _ { \theta } ( s , a ) R _ { s } ^ { a } } } \\ & { = } & { a \times f _ { 1 } + b \times f _ { 2 } + c \times f _ { 3 } } \end{array}\tag{3-15}
$$

其中 $f _ { 1 }$ ， $f _ { 2 }$ ， $f _ { 3 }$ 分别是无人机侦查模型中的三个优化目标函数， $a , b , c$ 分别对应三个目标函数的在损失函数的比例系数。

为了求得最优策略，对目标函数进行求导得到梯度公式：

$$
\nabla _ { \theta } J ( \theta ) = \operatorname { E } _ { \pi \theta } { \big [ } \nabla _ { \theta } \log \pi _ { \theta } ( s , a ) Q _ { \pi } ( s , a ) { \big ] }\tag{3-16}
$$

其中 $\nabla _ { \theta } \log \pi _ { \theta } ( s , a )$ 被称为分值函数（score function）。然后使用梯度上升来更新参数，优化策略，针对不同的优化目标函数，梯度公式中的分值函数不会变化，变化的只是 $Q _ { \pi } ( s , a )$ 。对于公式里的期望，可以通过采用的方式来替代，即使用 t时刻的收获作为当前策略下行为价值。

针对多无人机协同侦查任务，使用 REINFORCE 强化学习损失函数为：

$$
\mathcal { L } ( \theta | s ) = \mathrm { E } _ { p \theta ( \pi | S ) } \big [ \big ( L ( \pi ) - b ( s ) \big ) \nabla \log p _ { \theta } ( \pi | s ) \big ]\tag{3-17}
$$

通过修改强化学习的目标函数，使 $L ( \pi ) = a \times f _ { 1 } + b \times f _ { 2 } + c \times f _ { 3 }$ ，达到优化任务规划的目的， $b ( s )$ 是 REINFORCE 算法中的 baseline，baseline 可以减小模型的方差并提升模型的训练速度。这里采用了滑动平均模型 $\mathsf { M } \gets \mathsf { \beta } \mathsf { M } + ( 1 - \mathsf { \beta } ) L ( \pi )$ 作为 REINFORCE 算法的 baseline。

本章从自顶向下的角度研究了多无人机协同侦查任务规划问题，首先介绍了Seq2Seq 框架的基本概念，以及注意力机制在 Seq2Seq 框架中的应用，然后对多无人机协同侦察任务规划问题与 Seq2Seq 解决的序列问题的异同进行了分析，并针对协同侦察模型创建了基于 Seq2Seq 的序列网络模型，并创新性地采用了序列神经网络和强化学习算法对任务规划问题进行了求解，避免了经典的群体智能启发式算法实时性差，只能应用于静态环境等缺点。训练结果表明，基于 Seq2Seq序列神经网络的求解模型能够有效地对协同侦查任务规划问题进行求解，且能工作于整个问题空间，实时性较传统启发式算法具有显著提升。

## 第4章 基于 EDDRQN 网络的多无人机协同作战规划

## 4.1 引言

不同于自顶向下的研究角度，从自底向上的角度研究多无人机协同任务规划问题，需要将多无人机系统中无人机单元看作具有一定自我调节能力的个体，通过个体对环境的感知和学习做出决策，然后通过与其余个体进行有限的信息交流实现整体的一致性，以达到完成任务到的目的，在问题的求解过程中，自底向上的研究角度强调个体对环境的感知和应对。

然而如果使用传统的控制方法控制多个无人机，系统的设计将异常复杂，难以实现。而强化学习作为一种从环境的反馈中学习的方法，非常适合解决自底向上角度无人机协同问题。因此，本文在仿真环境中建立了多机协同作战环境，并提出了基于增强型深度分布式循环 Q 网络(EDDRQN)的多智能强化学习网络，并应用于多无人机协同作战规划中。通过使用深度神经网络控制无人机单元，使无人机可以根据当前环境信息做出决策，并使用强化学习的方法，使无人机可以在仿真环境中学习如何协同完成作战任务。针对多无人机在同一环境中学习策略互相干扰的问题，引入了 Off-environment 学习策略，减轻了互相干扰问题，提高了无人机学习协同任务的速度。在仿真实验中表明，通过强化学习的多无人机系统能够很好的完成任务。

## 4.2 基于强化学习的多机协同作战关键问题

基于强化学习的多无人机的协同作战过程可以用马尔科夫博弈过程来描述，这里用元组 $( n , S , A _ { 1 } , \cdots , A _ { n } , T , \gamma , R _ { 1 } , \cdots , R _ { n } )$ 来描述。其中 表示无人机的个数， 为系统的状态，这里指多无人机的联合状态， 为状态转移函数，指给定无人机当前状态和联合行为时，下一状态的概率分布，即T: $: S \times A _ { 1 } \times A _ { 2 } \times \dots \times A _ { n } \times S \to$ [0,1]， 为回报函数， $R _ { i } \colon \mathrm { S } \times A _ { 1 } \times A _ { 2 } \times \cdots \times A _ { n } \times S  [ 0 , 1 ]$ ， $R _ { i } ( s , a _ { 1 } , \cdots , a _ { n } , s ^ { \prime } )$ 表示无人机 在状态 时候，采取联合行为 $( a _ { 1 } , \cdots , a _ { n } )$ 之后在状态 $s ^ { \prime }$ 取得的回报 。

在有多个无人机的情况下，状态转移的结果是由多个无人机联合动作所确定的， $\mathbf { a } _ { k } = \left[ a _ { 1 , k } ^ { T } , \cdots , a _ { n , k } ^ { T } \right] , \mathbf { a } _ { k } \in A , a _ { 1 , k } ^ { T } \in A _ { i }$ ，联合策略 也是如此。因为无人机的回报函数 $R _ { i , k + 1 }$ 取决于联合动作，因此也取决于联合策略：

$$
R _ { i } ^ { h } ( x ) = E \left\{ \sum _ { k = 0 } ^ { \infty } \gamma ^ { k } R _ { i , k + 1 } | x _ { 0 } = x , h \right\}\tag{4-1}
$$

因此每个无人机的 函数也取决于联合动作和联合策略：

$$
Q _ { i } ^ { h } \colon S \times A \to \mathbb { R } , Q _ { i } ^ { h } ( x , { \pmb a } ) = E \left\{ \sum _ { k = 0 } ^ { \infty } \gamma ^ { k } R _ { i , k + 1 } | x _ { 0 } = x , { \pmb a } _ { 0 } = { \pmb a } , h \right\}\tag{4-2}
$$

与单无人机强化学习情景相比，多无人机协同强化学习的主要区别在于，多无人机的状态转移和回报都是建立在联合动作的条件下的，如图 所示：

然而随着无人机的数量由单数变为复数，该多无人机强化学习协作系统也出现了相应的挑战，主要体现为：

随着无人机数量的增加，相比于单无人机情景，多无人机的联合状态和联合动作空间呈几何级增长，增加了多无人机系统获取有效策略的难度。

需要构建合适的控制网络，能使多无人机之间，既能有效地沟通，达到共享战场信息的目的，又能使无人机之间互相独立地完成协同任务。

为了使无人机能有效地从探索过的经验中学习，在单无人机环境中，绝大多数强化学习算法都使用了经验回放机制来加速智能体的学习过程。然而复数无人机在强化学习环境中学习有效协同策略时，单个无人机学习到的最优策略随其余无人机策略的改变而改变，造成无人机的经验回放中存在变量，会对无人机的学习过程造成干扰，导致系统不稳定。

随着深度学习技术的发展，第一个问题可以使用神经网络来解决，在谷歌提出的 DQN 算法中就使用了神经网络来替代表示 Q 函数，解决了单智能体强化学习环境中传统表格式存储方法的局限性[11]。在多无人机协同作战任务规划中，本文也通过建立神经网络控制的方式，对多无人机的联合状态和联合动作空间进行表示。
