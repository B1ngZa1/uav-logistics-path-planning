相较于逻辑函数和双曲函数等传统的神经网络激活函数，ReLu 具备以下几方面的优势：1）其具有相应的仿生物学原理，关于大脑方面的相关研究表明生物神经元的信息编码通常是分散及稀疏的[59]。这说明通常情况下在同一时间内，大脑中约有1%到4%的神经元处于活跃状态。而 ReLu 可以对神经网络中神经元的活跃度（即输出为正值）进行调试，使其符合实际生物学对模拟神经网络的要求[60]；2）实现了更高效率的梯度下降及反向传播：有效避免了梯度爆炸和梯度消失问题；3）形式简单，使得神经网络的整体计算成本下降。

## 3、评价网络参数更新方式

基于建立马尔可夫决策过程和评价网络，在与仿真环境的交互过程中，将产生的新的经验数据存储进经验数据库中，并通过优先经验回放的方式提取数据库中的数据，更新评价网络的参数。

## （1）网络参数更新公式

下面介绍网络参数的更新方式。若用评价网络的输出值 $Q \big ( s , a , \pmb { \omega } \big )$ 近似$\boldsymbol { Q } ^ { * } ( s , a )$ ，需满足

$$
\begin{array} { r } { J \left( \omega \right) { = } \Xi \Big [ \left( \boldsymbol { Q } ^ { \ast } \left( s , a \right) { - } \boldsymbol { Q } \left( s , a , \omega \right) \right) ^ { 2 } \Big ] } \end{array}\tag{2-14}
$$

最小。结合贝尔曼最优方程

$$
\mathcal { Q } ^ { \ast } \left( s , a \right) = R _ { s s } ^ { a } \mathrm { , + \gamma \sum _ { { s ^ { \prime } } \in S } } p _ { s s } ^ { a } \mathrm { , \operatorname* { m a x } } \mathcal { Q } ^ { \ast } \left( s ^ { \prime } , a ^ { \ast } \right)\tag{2-15}
$$

可得到评价网络的参数更新公式：

$$
\begin{array} { r l } & { \Delta \omega { = } \alpha \Big ( \boldsymbol { Q } ^ { \flat } \big ( s , a \big ) { - } \boldsymbol { Q } \big ( s , a , \omega \big ) \Big ) \nabla _ { \omega } \boldsymbol { Q } \big ( s , a , \omega \big ) } \\ & { \quad { = } \alpha \Big ( R _ { s s } ^ { a } { , + } \gamma \operatorname* { m a x } _ { a ^ { \flat } } \boldsymbol { Q } \big ( s ^ { \flat } , a ^ { \flat } , \omega \big ) { - } \boldsymbol { Q } \big ( s , a , \omega \big ) \Big ) \nabla _ { \omega } \boldsymbol { Q } \big ( s , a , \omega \big ) } \end{array}\tag{2-16}
$$

其中， $\alpha$ 表示学习率， $R _ { s s ^ { \prime } } ^ { a } + \gamma \operatorname* { m a x } _ { a ^ { \prime } } { \cal Q } ( s ^ { \prime } , a ^ { \prime } , \omega )$ 称为目标Q值， $Q \big ( s , a , \pmb { \omega } \big )$ 称为当前Q 值。

从上述更新公式中可以看出，评价网络需要同时输出目标 Q 值与当前 Q 值，这会导致数据的相关性，影响网络的训练效果。针对这一问题，设计目标网络（target Q network）用以输出目标 Q 值，与评价网络的参数更新方式不同，目标网络的网络参数 $\omega ^ { - }$ 是每经过C步后复制当前的 得到的。另外，为了避免过高估计 Q 值，利用目标网络和评价网络分开的优势，采用文献[61]中 Double Q-Learning 的方法，定义 $\delta = R _ { s s } ^ { a } , + \gamma Q \bigg ( s ^ { \prime } , \arg \operatorname* { m a x } Q \big ( s ^ { \prime } , a , \omega \big ) , \omega ^ { - } \bigg ) - Q \big ( s , a , \omega \big )$ 为时序差分误差，将评价网络的网络参数更新公式变为： ）

$$
\Delta \omega = \left\{ \begin{array} { l l } { \alpha \Big [ R _ { s s } ^ { a } , - Q \big ( s , a , \omega \big ) \Big ] \nabla Q \big ( s , a , \omega \big ) } & { \overset { = } \longrightarrow \mathrm { i } \mathtt { M L P } \mathrm { i } \ddag \mathbb { H } \downarrow \big [ \mathrm { L } \ddag \mathcal { I } \big ] \overline { { \mathrm { H } } } \mathrm { I } \mathrm { L } \mathrm { J } \overline { { \mathrm { M } } } \mathrm { J } \overline { { \mathrm { M } } } \big / \mathrm { L } \overline { { \mathcal { H } } } } \\ { \alpha \partial \nabla Q \big ( s , a , \omega \big ) } & { \mathcal { N } \overline { { \mathrm { H } } } \mathrm { J } \mathrm { L } \mathrm { J } \overline { { \mathrm { M } } } \big / \mathrm { L } \overline { { \mathrm { H } } } \big / \mathrm { H } \overline { { \mathrm { J } } } } \end{array} \right.\tag{2-17}
$$

## （2）经验数据库中的数据提取方式

下面介绍经验数据库D中的数据提取方式，用以更新评价网络的网络参数。在经验总结环节，已经根据初步决策方案获得一些经验数据，如算法 2-1中的第8行所示。根据马尔可夫决策过程对状态 ，动作 ，立即收益值 $R _ { s s " } ^ { a }$ 的定义，经验数据库中的数据可以以 $\left( s , a , R _ { s s ^ { \prime } } ^ { a } , s ^ { \prime } \right)$ 的形式储存进 D 中。在这一环节产生的经验数据也会继续存储进D中，需要注意的是，由于相邻的数据之间具有相关性，因此不能按照存储顺序直接提取数据。通常的做法是从经验数据库 D 中进行随机收取经历数据E进行训练。

需要注意的是，这些储存起来的经历数据的作用并不是等价的。有的经历数据会对网络的收敛提供更大帮助。为了提高数据的利用效率，本节采用文献[62]中提出的优先经验回放方法，即将经历数据 $\left( s , a , R , s ^ { \prime } \right)$ 的重要程度设置优先级，并使得优先级越高的经历数据更有可能被抽取。

## 3.1 引言

上一章针对优先级不同的多个静态任务目标，研究了大规模无人机集中式任务决策问题，首先在理解人脑运行机制的基础上，通过仿照人脑的经验-推理-决策-改进的过程，提出基于经验总结-行为预测-评价改进-在线决策的类脑智能方法，然后采用其中的经验总结-评价改进-在线决策环节进行对基于地面站的无人机集群任务决策进行求解。这一章将介绍基于类脑智能方法的多无人机分布式任务决策问题。本章以多无人机执行围捕任务为背景，需要注意的是，与上一章不同，这里讨论的问题为动态决策问题，即无人机的位置和速度随着对方无人机的行动轨迹不断变化，且随着环境内无人机数量的增多，任务决策问题的难度变得更大。因此，对于多无人机分布式任务决策问题来说，存在如下几个难点：1）考虑到多无人机围捕的任务特点，整个任务环境是动态变化的，这对无人机的单步决策速度提出了更高的要求；2）由于决策主体从地面站变为任务区域内的无人机，因此各无人机在围捕过程中仅能根据自身的观测状态进行决策，这种部分状态可观测性的特点会影响决策结果的有效性和准确性；3）围捕过程中，环境中存在外界干扰等不确定因素的影响，这也大大增加了多无人机的决策难度。考虑上述难点，研究有效的无人机任务决策方法，对于解决多无人机分布式任务决策问题十分必要。

## 3.2 问题描述

假设某任务区域内存在若干架己方无人机和对方无人机，其中对方无人机为待围捕目标。各个无人机均可以在指定任务区域内自由飞行，无人机在实际执行任务的过程中，仅能根据自身传感器获得的信息进行决策。此外区域中存在若干个静态障碍物，若无人机在飞行过程中与障碍物相撞可被认为撞毁，无法继续逃跑或完成围捕任务；若在规定时间内，对方无人机在己方无人机的攻击范围内，那么判定己方无人机的围捕任务成功，否则，对方无人机获胜。综上，本节的任务决策目标可以描述为，考虑己方与我方无人机的飞行速度、任务需求以及避碰条件等因素的影响，仅利用各无人机的自身观测状态，在规定时间内完成己方无人机对对方无人机的围捕任务。

## （1）速度约束

在围捕任务中，通常假设双方无人机均存在最大速度限制， 即

$$
\left\| \nu _ { \overline { { i } } } \right\| \leq \nu _ { \operatorname* { m a x } I } , \left\| \nu _ { \overline { { j } } } \right\| \leq \nu _ { \operatorname* { m a x } J }\tag{3-1}
$$

其 中 $\nu _ { \bar { i } }$ 和 $\nu _ { \overline { { j } } }$ 分别表示己方无人机和对方无人机的速度， $\overline { { i } } \in \left[ 1 , N _ { I } \right]$ ，$\overline { { j } } \in \left[ N _ { I } + 1 , N _ { I } + N _ { J } \right]$ $N _ { I }$ 和 $N _ { J }$ 分别为任务区域内的己方和对方无人机总数。$\nu _ { \operatorname* { m a x } I }$ 和 $\nu _ { \operatorname* { m a x } J }$ 分别表示己方无人机和对方无人机的最大速度。

$$
\nu _ { \operatorname* { m a x } I } < \nu _ { \operatorname* { m a x } J }\tag{3-2}
$$
