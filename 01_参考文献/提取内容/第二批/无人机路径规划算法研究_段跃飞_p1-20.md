## 摘　要

随着无人机生产及应用成本降低，传感器、自动化和人工智能等技术的快速发展，通过搭载摄像机、GPS 定位系统、多种硬件传感器、任务载荷系统等装置，无人机已可应用于覆盖、跟踪、对抗、通信等领域，高效地完成各种人力难以操作的任务。无人机路径规划（UAV Path Planning）问题是无人机完成任务的基础。为了减少路径规划时间、提升路径最优性、降低无人机损毁可能性，路径规划算法的研究已然成为了无人机应用领域的热点问题。目前数据采集是无人机通信领域的主要应用场景之一，本文分别对无人机在空间分布异构无线传感器网络中的数据采集路径规划算法与三维复杂环境中两点间的路径规划算法展开了研究，具体工作如下：

一、为了提高环境信息的完整性及规划路径的准确性，分别针对数据采集路径规划问题与复杂环境两点间路径规划问题创建了三维环境模型。目前数据采集路径规划问题的三维环境模型大部分是通过二维平面坐标与高度坐标的组合进行简化表示，损失了许多环境信息，针对该问题本文构建了空间分布的异构无线传感器网络模型。由于三维复杂环境中可能存在多种威胁源，本文采用威胁度模型针对不同威胁源分别进行了建模，为后续路径规划奠定了基础。

二、为了提高无人机在无线传感器网络数据采集的规划效率，设计了一种基于不返回旅行商问题和三点凸优化问题的两阶段数据采集路径规划算法（two-stagepath planning algorithm based on no-return traveling salesman problem and three-pointconvex optimization, NTSP-TCO）。首先将无人机对空间分布异构无线传感器网络的数据采集路径规划问题近似为特殊的带邻域旅行商（traveling salesman problemwith neighborhood, TSPN）问题，并将其分为两个阶段进行求解。其次，制定并解决了一个不返回的旅行推销员（no-return traveling salesman problem, NTSP) 问题，获取无人机遍历传感器设备的最短路径。最后，迭代解决一系列的三点凸优化(three-point convex optimization, TCO) 问题获取到无人机数据采集的最优路径。仿真结果表明，随传感器设备数增加、采集半径增大，该方法可有效缩短路径采集路径长度，同时减少路径采集点个数。

三、为了提高无人机飞行的路径最优性，设计了一种双向稀疏威胁探测 A∗ 算法（bidirectional sparse threat detection AStar algorithm, BSTDAStar），实现了三维复杂环境的无人机高效路径规划。针对大规模复杂环境中信息量暴增导致传统 A∗ 算法出现路径拐点多、规划时间长、路径安全性降低等问题，本文采用限制搜索方

向、自适应改变搜索步长、引入双向搜索机制、改进启发函数、增加无人机雷达探测功能提前避障等方式对其进行了改进。仿真结果表明，相比传统的 A∗ 算法和改进的RRT∗ 算法，BSTDAStar算法能在更短的时间内，规划出一条安全、平滑的最优路径。

综上，本文从任务角度，针对无人机路径规划的两个场景，分别创建了三维环境模型，设计了 NTSP-TCO、BSTDAStar 算法。NTSP-TCO 算法能够有效缩短规划路径长度、减少采集点个数，提高了数据采集任务的完成效率；BSTDAStar 算法相比传统算法缩短了路径长度，提升了路径平滑性与安全性。本文研究的算法为三维空间无人机的高效路径规划提供了理论基础。

关键词：三维路径规划，无线传感器网络，旅行商问题，凸优化，A∗ 算法

## ABSTRACT

With the reduction of UAV production and application costs, and the rapid development of technologies such as sensor, automation and artificial intelligence, UAV has been applied in the fields of coverage, tracking, countermeasure and communication by carrying cameras, GPS positioning systems, a variety of hardware sensors, mission loading systems and other devices, and then efficiently complete a variety of tasks that are difficult to operate by manpower.The UAV path planning problem is the basis for UAV to complete the task. In order to reduce path planning time, improve the quality of path and decrease the possibility of UAV damage, the research of path planning algorithm has become a hot issue in the field of UAV application. At present, data acquisition is one of the main application scenarios in the field of UAV communication. At present, data acquisition is one of the main application scenarios in the field of UAV communication. In this thesis, the data acquisition path planning algorithm of UAV in spatially distributed heterogeneous wireless sensor network and the path planning algorithm between two points in three-dimensional complex environment are studied respectively. The specific work is as follows:

1. In order to increase the integrity of environmental information and the accuracy of planning path, a three-dimensional environment model is created for the data collection path planning problem and the path planning problem between two points in complex environment respectively. At present, most of the 3D environment models for data acquisition path planning problem are simplified by the combination of 2D plane coordinates and value of height, which loses a lot of environmental information. To solve this problem, a spatially distributed heterogeneous wireless sensor network model is constructed. Because there may be multiple threat sources in the three-dimensional complex environment, the threat degree model is used to model different threat sources separately, laying the foundation for subsequent path planning.

2. For improving the planning efficiency of UAV data acquisition in wireless sensor network, a two-stage path planning algorithm based on no-return traveling salesman problem and three-point convex optimization(NTSP-TCO) is designed. Firstly, the Problem of UAV data acquisition path planning for spatially distributed heterogeneous wireless sensor networks is approximated as a special traveling salesman problem with Neighborhood

(TSPN), and it is solved in two stages. Secondly, a non-returning traveling salesman problem(NTSP) is formulated and solved to obtain the shortest path for the UAV to traverse the sensor nodes. On this basis, a series of three-point convex optimization problems(TCO) are iteratively solved to obtain the optimal path of UAV data acquisition. The simulation results show that with the increase of the number of sensor nodes and the increase of communication radius, the method can effectively shorten the length of path acquisition and reduce the number of path acquisition points at the same time.

3. In order to improve the path quality of UAV flight path, a bidirectional sparse threat detection AStar algorithm (BSTDAStar) is designed, which realizes efficient UAV path planning in 3D complex environment. Aiming at problems such as many path inflection points, long planning time, and reduced path security in the traditional A∗ algorithm caused by the surge of information in large-scale and complex environments, this thesis improves the traditional AStar algorithm through the method of limiting the search direction, adaptively changing the search step size, introducing a two-way search mechanism, improving the heuristic function, and adding the UAV radar detection function to avoid obstacles in advance. The simulation results show that, compared with the traditional AStar algorithm and the improved RRTStar algorithm, BSTDAStar method can plan a safe and smooth optimal path in a shorter time.

In this thesis, 3D environment models are creared respectively for the two scenarios of UAV path planning, and NTSP-TCO and BSTDAStar algorithms are designed to realize the path planning of UAV in 3D space from the perspective of tasks. The NTSP-TCO algorithm can effectively shorten the length of planning path, reduce the number of collection points, and improve the completion efficiency of data acquisition tasks. Compared with the traditional algorithm, the BSTDAStar algorithm shorts the path length, improves the smoothness and security of the path. The algorithm proposed in this thesis provides a theoretical basis for efficient path planning of 3D space UAV.

Keywords: 3D path planning, Wireless sensor network, Traveling salesman problem, Convex optimization, AStar algorithm

## 第一章 绪 论

## 1.1 无人机路径规划的背景与意义

无人驾驶飞机（Unmanned aerial vehicle, UAV），是利用无线电遥控设备和程序控制装置操纵的不载人飞行器。1914 年英国第一次将无线电遥控装置用于无人机，1917 年第一架无人机成功发射 [1]，在全世界引起了极大的轰动。这意味着自人类历史上第一次达成飞行成就之后，航空技术又出现了一个标志性的里程碑。

起初无人机被应用于军事领域，从英国研制出第一架可复用无人驾驶靶机至今，无人机在军事方面的应用已经有 90 年的历史。由于无人机因具备无人员伤亡风险、机动性能好、持续作战能力强、对作战环境要求低、战场生存能力较强等优点，目前军事方面的主要用途包含边界巡逻 [2]、侦察勘测 [3]、电子对抗 [4, 5]、战略攻击 [6] 任务等。随着无人机制造工艺提升、无人机生产及应用成本降低、电子及传感器、机器人、自动化和人工智能等技术的快速发展，各种以无人机为基础的研究呈井喷式增长。近年来，无人机已经开始从军事领域向科研和民用转移，目前小型无人机（通常指重量不超过 25 公斤）已经广泛被公众使用。实际数据表明，无人机已能达到成本低、体积小、机动性能好、操作简便灵活、降低人力成本[7] 等需求，可在节约人力成本的同时能够提高任务执行的效率。

现在无人机可以执行的任务场景更加广泛，通过搭载摄像机、GPS 定位系统、多种硬件传感器、任务载荷系统等装置，能够在低空环境之中与各种民用行业的应用结合，完成一些人力难以操作的任务，进而给整个社会生产带来不一样的解决方案。现有的无人机可以分为旋翼和固定翼无人机，旋翼无人机能够保持空中悬停，并且可以在任何方向上移动，但其机动性和有效载荷有限；固定翼无人机需要持续向前运动来保证飞行，通常具有较高的速度和较高的有效负载，但不适用于空中停留等任务。同时根据搭载的设备不同，无人机可被用于各个行业应用的不同任务，能够解决的关于无人机的问题也层出不穷。如在紧急搜救方面，固定翼无人机可以巡航发现受难者，帮助加快搜索救援行动 [8]；或携带医疗药物飞往各个人类难以抵达的遇难点，降低受灾人员的伤亡率；还可以代替人类应用于森林火灾扑灭 [9]、防疫消杀等危险场景，减少个人伤亡的风险。在无线通信系统方面，旋翼无人机可以作为中继节点 [10] 来扩展通信范围 [11]，最大限度地提高网络数据通信能力；或在远程或恶劣环境中从无线传感器网络收集数据 [12]；也可以帮助移动网络中的节点定位 [13] 等。

无人机执行任务的一般步骤可分为需求分析、模型构建、路径规划三个部分。

作为任务规划的最后环节，路径规划是无人机执行任务的重要组成部分，也是完成任务的重要前提。其目的在特定任务环境下，给定无人机起始位置与目标位置，根据任务目标通过一些路径规划算法在适当的时间内计算出一条满足任务约束的、最优或次最优的飞行路径，使得无人机能够回避禁飞区域、危险区域等威胁源的同时，安全、可行地在规定时间内完成预定的任务。

目前，研究者们已经提出了许多路径规划算法以快速有效地规划无人机飞行路径。常见的无人机路径规划算法根据角度不同可划分为不同类别。由实时性或全局性可分为如下两类，一种是全局经典算法，如 A∗ 算法、随机路图法、人工势场法（artificial potential field, APF）等，另一种是通过实时测量局部环境信息规划路径的智能优化算法，如遗传算法（genetic algorithm, GA）、粒子群优化算法（particle swarm optimization, PSO）、蚁群算法（Ant colony optimization, ACO）等；从环境特征或路径特征可分为如下两类，一种是离散域路径规划算法，路径由离散路径点及相连线段组成，如基于图的路径规划算法、旅行商问题（travelingsalesman problem, TSP）求解算法、物流路径规划算法等，一种是连续域路径规划算法，路径由路径每一点的航向与航速构成，如 A∗ 算法、APF 等；从任务角度亦可分为如下两类，一种是基于实际应用的路径规划算法，如无线网络中的无人机通信中继路径规划算法、物流运输中的路径规划算法等，另一种是基于理论的两点间路径规划算法，如A∗ 算法、APF、ACO等等。不同路径规划算法路径的规划方式与结论各不相同，也各有优劣之处。因此，选择适合的路径规划算法对于无人机路径规划非常重要。通过采用合适的路径规划算法，来发现一条最佳的、无碰撞的路径，同时使路径长度、旅行时间和能源消耗最小化。

但由于飞行任务的复杂化，目前的无人机路径规划算法仍存在许多问题和不确定因素，这对路径规划算法的适应能力、算法效率等提出了更高的要求，主要不足之处如下：

## （1）三维环境模型创建不完备

目前研究者们在二维环境路径规划算法的研究已经很完备，但在三维环境中的路径规划算法研究还存在一些不足之处。许多三维空间路径规划问题将三维环境模型创建为二维平面坐标与高度坐标的组合，通过限制无人机飞行高度对三维环境模型进行简化处理，损失了许多环境信息。下一步研究有必要针对更完备三维环境进行路径规划。

## （2）已有的算法存在局限性

尽管研究者们已经提出了许多路径规划算法，但由于算法本身存在一定局限性。例如 A∗ 算法能够获取最优路径但每次运行只能计算得到一条路径、当环境规

模增大复杂度增加规划时间会急剧增长；智能优化算法虽然能获取多条可行路径，但其规划路径不具备最优性等。研究者们有必要针对不同的应用场景采取不同算法进行路径规划，同时通过细节微调及针对性改进完成任务需求。

## （3）路径规划算法未曾与无人机自身的特点相结合

最初的路径规划算法是研究者们基于机器人或移动机器人提出的，因此普适的的路径规划算法不能够直接应用于无人机路径规划问题。研究者们有必要针对无人机自身性能约束、无人机优势如雷达探测功能、通信功能研究更高效可行的无人机路径规划算法。

## 1.2 无人机路径规划算法的国内外研究

由于机器人、自动化和人工智能等技术的发展，路径规划技术不断在更新迭代。伴随着无人机的问世，早期移动机器人的路径规划技术逐步发展到更具有针对性的无人机路径规划技术。1995 年来自东北大学电气通信研究所的 Y.Kitamura等人 [14] 提出了一种无人机在动态可观察三维环境中的无碰撞路径规划算法，算法统一基于八叉树表示环境对象，采用人工势场法来有效搜索可行路径。2003 年来自陕西西安飞行自动控制研究所的唐强等人 [15] 对国内外在无人机路径规划领域的早期研究成果进行了总结，对路径规划涉及的关键问题进行了描述，并介绍了几种常用的路径规划算法，如A∗ 算法、遗传算法、基于案例的算法等。近年来，国内外在无人机路径规划算法方面也有了许多的研究成果。

现有的无人机路径规划算法从应用角度分为基于应用的路径规划算法，如无线网络中数据采集路径规划算法那 [16]、覆盖路径规划算法 [17]、战场攻击路径规划算法 [18] 等，和基于理论的两点间路径规划算法，如 A∗ 算法 [19]、人工势场法[20]、蚁群算法 [21] 等；也可从环境维度角度分为二维环境方法 [22] 和三维环境方法 [23]；亦可从规划路径角度分为基于路径点的离散路径规划算法 [24] 和基于航向与航速的连续路径规划算法 [25]；还可以针对环境先验信息分为先验信息已知的全局路径规划算法和先验信息不确定的实时路径规划算法 [26] 等。本文从应用角度出发，针对基于应用的路径规划算法与两点间的路径规划算法两个方面，分别对无线传感器网络中的数据采集路径规划算法、复杂环境下的两点间路径规划算法进行了研究。

## 1.2.1 基于应用的无人机路径规划算法研究

针对不同类型的任务，可得到多种不同应用场景的路径规划问题。本小节对基于应用的无人机路径规划算法研究现状进行了介绍，主要从覆盖、跟踪、对抗、

通信等几个角度分别进行阐述。

## 1.2.1.1 无人机覆盖路径规划算法研究

无人机覆盖路径规划是无人机应用路径规划中的一个典型问题，其目标是根据环境的几何信息确定一条无人机的可行路径，使其能够携带相关的传感器沿该路径实现对目标区域的完全访问 [27] 或覆盖 [28]，达到最优的环境覆盖效果。本节对覆盖路径规划的两方面应用，即区域覆盖、目标搜索的研究现状进行阐述。

无人机区域覆盖路径规划的相关应用土地测绘、航拍、农业植保、物流运输等。测绘、航拍等任务通常是基于环境信息未知情况下进行路径规划，进而为无人机避障、土地精准农业、矿山开采等后续工作获取到所需的环境模型。2005 年美国德克萨斯农工大学航空航天工程系的 S. Chakravorty[29] 等人将不确定环境中的单无人机探索路径规划问题视为不确定马尔可夫决策过程的自适应最优控制问题，提出了一种在不确定环境中进行智能路径规划的方法。2007 年美国杨百翰大学电气与计算机工程系的P.B.Sujit[30] 等人考虑无人机存在有限的通信半径、最小转弯半径等约束的情况下，提出了一种探索存在障碍物未知区域的多架无人机的协作路径规划技术，结合无人机性能约束进行了路径规划。2022 年南开大学的张世勇 [31] 等人总结与综述了目前的无人机覆盖及探索路径规划算法，并对异构多无人机协同探索、应用智能学习算法、存在定位不准确性、存在通信约束等几个未来发展方向做了展望。

无人机目标搜索路径规划的相关应用有情报侦察、气象监测、搜索救援、电力设备巡检等。此类型的大部分工作聚焦于环境信息已知的路径规划问题。2008年美国 IAI（Intelligent, Automation, Inc.）公司的陈丹 [32] 等人提出了一种协作执行情报、监视、侦察（ISR）任务的博弈论数据融合辅助路径规划算法，以响应无人机飞行时检测到的弹出障碍物，最大限度降低无人机在执行 ISR 任务期间被威胁、摧毁的风险。但该算法是在已知静态障碍物分布的前提下进行的路径规划。2016 年空军航空大学的范琼建 [26] 等人针对不确定环境下的侦察路径规划进行了研究，基于无人机机载探测设备建立探测模型，设计了无人机侦察不确定环境的仿真实验。针对搜索救援任务，2011 年诺丁汉大学马来西亚校区电气与电子工程系的 HaiderA.F.Almurib[33] 等人针对搜索与救援任务提出了搜索目标和物资运送的两阶段算法，通过最短路算法获取初始静态路径，采用虚拟势函数算法获得可行动态路径，通过视频跟踪目标运送物资。由于大部分情况环境信息不一定完全已知，因此 2022 年东南大学的陈建辉 [34] 等人针对环境先验信息量不同的情况下，提出了离线和在线路径规划策略，在有限飞行时间内检测更多地目标。

## 1.2.1.2 无人机跟踪路径规划算法研究

随着无人机控制与定位技术发展，无人机跟踪路径规划成为了无人机应用路径规划中热点问题之一，主要将其分为两个方向，路径跟随和目标跟踪。无人机跟踪路径规划的目的是在动态环境下沿参考路径飞行或追踪运动目标，飞行过程需达到满足无人机运动学约束、避免与未知障碍物发生碰撞的要求。

现有文献已经提出多种无人机路径跟随方法，在该类型任务场景中，无人机需沿着预先设定的路径进行飞行，通过减小无人机和路径间的距离误差实现任务目标。2012 年美国的 DadkhahN[35] 等人介绍了无人机路径跟随过程中不确定性的主要来源，并对有关研究的算法做了一个综述，并介绍了他们在无人机自主导航中的应用。2014 年印度的 P.B. Sujit[36] 等人对固定翼无人机在给定高度飞行条件下的各种路径跟随算法做了一个综述，作者介绍基于几何学的方法主要包括视线法 [37] 和追踪法等通过在给定路径上指定一个虚拟节点并令无人机跟随该点从而保证无人机飞行在给定路径上，因此无人机与路径间的距离误差取决于无人机在路径的投影点与虚拟节点的距离；基于控制学的方法主要包括滑模方法 [38]、模型预测控制（Model Predictive Control, MPC） [39] 等，通过控制误差变量为 0 来实现路径跟随，可以更方便的考虑稳定性指标，即无人机在不同路径、环境条件下能否准确跟随路径。

无人机目标跟踪路径规划主要分为目标状态估计和跟踪路径规划两个阶段[40]。目标状态估计通过对搭载摄像头的无人机获取的图像序列处理识别得到航拍影像中的目标，获取其运动轨迹信息并估计状态，目前目标状态估计的方法包含基于滤波的方法、基于深度学习的方法等。2019 年福建的志正 [41] 等人通过卡尔曼滤波来预测目标状态，采用贝叶斯方法优化的遗传算法对目标进行跟踪。2020年北京航空航天大学的李伯豪 [42] 等人提出了一种改进的深度确定性策略梯度算法，采用深度强化学习方法在障碍物环境下对无人机进行了地面目标跟踪。由于固定翼无人机巡航速度一般大于地面目标跟踪移动速度，2019年北京的陈建国 [43]针对固定翼无人机对不同运动状态地面目标的近距离目标跟踪问题，基于 Dubins模型设计了一种定向俯仰跟踪的方法。

## 1.2.1.3 无人机对抗路径规划算法研究

无人机对抗路径规划一般应用军用领域，主要将其分为攻击、干扰、拦截等方向。

无人机在敌方防御区域执行攻击或干扰任务的目标是在具有较小的雷达探测发现几率、可接受的航程基础下，规划一条能够抵达目标位置的路径，以掩护己方无人机突防或实时对地攻击。2009 年空军工程大学的吴军 [44] 等人针对机载预警雷达与地面雷达对低空突防无人机的严重威胁，采用无人机作为干扰机来构造电子干扰条件，构造空间威胁模型，基于 A∗ 算法实施了路径规划。该文献中干扰无人机采用定向干扰，只是在固定方位进行掩护。2014 年北京理工大学的段远望[45] 等人引入层次分析法构建雷达威胁模型，考虑动态认知对抗场景即敌方雷达探测概率及威胁实时变化情况下采用蚁群算法分别对具备干扰能力的无人机进行了路径规划。为了摧毁敌方单位，往往需要多架无人机同时攻击目标。2019 年西北工业大学的严飞 [46] 等人针对攻击性多无人机协同攻击作战，提出了一种获得最大系统效能的任务分配算法以及同时攻击目标的航迹规划算法。基于协同粒子群算法和协同函数、协同变量相结合的算法规划的路径满足了无人机无人机的运动学约束及时间协同约束。

无人机在己方区域执行干扰或拦截任务的目标是动态规划路径，有效干扰或阻断敌方无人机、导弹等装备，防止情报泄露或受到袭击。2013 年加查玛达大学的 HHTriharminto [47] 等人研究了存在杂波环境的动态条件下对运动目标的拦截问题，提出了改进的 L+Dumo 算法，可从各个角度拦截运动目标。在运动目标基础上，2015 年西北工业大学的王晓光 [48] 等人针对敌方无人机存在伴飞诱饵情况下我方自杀式无人机的攻击策略问题，提出了一种改进的 Lanchester 方程，计算最优攻击模型。由于博弈方法的发展，2022 年空军装备部的刘莎 [49] 等人针对无人机协同对抗问题进行了研究，基于实时态势分析提出了一种基于动态非零和博弈的无人机集群协同对抗机动决策算法，采用改进的粒子群优化方法实现了集群对抗路径规划问题。

## 1.2.1.4 无人机通信路径规划算法研究

与主要依赖地面设施的传统地面通信相比，具有高移动性、可灵活部署、大概率建立视距链路（Line-of-Sight link, LoS）的无人机辅助通信目前已在无线通信领域得到了广泛应用。无人机辅助通信的最大优势就是可以为缺少通信覆盖的区域（比如该区域的基础通信设备受地震等自然灾害而损坏或者受城市、山区地形严重遮挡）提供临时的通信服务。目前无人机通信路径规划的应用主要分为低空基站、移动中继、数据采集等方面。

无人机搭载基站等通信设备，可在基站损坏时部署为静态基站，可以保证用户正常通信；或在基站过载时部署为移动基站，灵活调整位置保证边缘用户的通信质量。无人机作为静态基站时主要致力于寻找最佳的部署位置。2020 年北京邮电大学的张天魁 [50] 等人研究了无人机辅助蜂窝网络中无人机部署、缓存分配与用户关联的联合优化问题，通过最大化用户体验质量（Quality of Experience, QoE）

来寻找无人机的最佳部署位置。但是静态基站忽视了无人机的高移动性和可灵活控制等特性。2022 年重庆理工大学的周永涛 [51] 等人以最大化任务周期内地面移动用户与无人机基站之间的网络总吞吐量为目标，提出了一种基于深度强化学习的无人机移动基站路径规划算法，采用深度确定性策略梯度算法规划了移动基站的飞行路径。

无人机作为移动中继设备可为相聚较远的地面用户或用户组之间提供通信连接，或在通信基础设施暂时不可用的区域如灾区提供可靠的通信网络，保证信息快速准确的传输。2014 年韩国的 DaeHyungChoi [52] 等人采用圆形轨迹作为无人机在两个固定地面节点的通信中继路径，提出了一种能量效率最大化算法。固定轨迹是可行的，但通常不是最优的。2017 年北京大学的张书航 [53] 等人以最小化无人机中继网络的中断概率为目标优化了无人机路径、发射功率。2019 年哈尔滨工业大学的许江 [54] 等人研究了无人机采用时分中继为多对地面用户传送数据的问题，通过联合优化时隙分配、中继功率分配、无人机路径来最大化各通信对间的最小平均信息速率。为提高能效，2020 年韩国的 TaewoonKim [55] 等人提出了一种节能、协作的多条中继方法，在满足时间约束等情况下最小化无人机功耗。

考虑到无线传感器网络位于无线覆盖范围有限的偏远地区或服务质量较低的密集地区的场景，无人机可作为移动汇聚节点用于采集网络传感器设备的数据。无人机数据采集问题根据任务目的有不同的目标函数。2019 年加拿大的MahdiBenGhorbel[56] 等人以最小化无人机和传感器能耗为目标，通过解决采集点位确定、传感器分配、旅行商问题求解三个子问题规划了无人机路径。2022 年内蒙古的文谢 [57] 等人研究了无线可充电传感器网络中的无人机数据采集问题，通过解决节点聚类、锚节点选择、路径规划、能量补充等子问题规划了无人机路径。2018 年浙江的刘娟 [58] 等人以最小化无人机从每个传感器设备收集的最大、平均信息年龄（Age of Information, AoI）为目标，采用动态规划和遗传算法规划了无人机路径。

本文针对无人机辅助空间分布异构无线传感器网络完成数据采集任务的路径规划算法进行了研究，目前此领域算法研究已经十分丰富，但多聚集在二维场景或固定高度的三维场景，未考虑到空间传感器分布模型，实际三维环境中并非二维平面与固定高度的组合，相较其复杂度增加，对算法的要求也随之提高。此外，由于无线传感器网络传感器设备存在最大通信距离，异构传感器的最大通信距离也各不相同，而异构无线传感器网络的数据采集路径规划算法研究还不充分。因此，有必要设计一种算法解决空间场景下无人机对异构无线传感器网络数据采集中的路径规划问题。

## 1.2.2 基于理论的无人机路径规划算法研究

复杂环境的无人机最优路径规划问题指的是在一个存在障碍物的环境中，无人机以时间最短、路径最短或某效用为目标从起点到终点找到一条安全可行无碰撞路径。近年来，研究者们已经设计了多种算法 [59] 对此进行了研究。目前常见的无人机路径规划算法大致可分为经典算法、智能优化算法及强化学习算法三类，其各自优缺点不同，相应适用范围也不相同。

## 1.2.2.1 无人机路径规划的经典算法

经典的无人机路径规划算法有：基于搜索的算法如 A∗ 算法 [19]、基于采样的算法如 RRT（Rapid-exploration Random Tree）算法 [60]、人工势场法 [20] 等。

A∗ 算法是经典的启发式搜索算法，可高效地求解最短路问题。该算法在Dijkstra 算法基础上，引入了当前点到终点的启发式成本估计函数，减少了扩展节点与计算开销，可快速收敛并保证最优性，权衡了规划效率与路线质量。但传统A∗ 算法在大规模复杂环境中计算量会迅速增加，且其规划路径存在过多转折点，因此在实际应用中并不能取得令人满意的结果。因此许多研究者针对 A∗ 算法搜索方向、冗余节点 [61]、代价函数 [62]、多算法结合 [63] 等方面进行了改进。尽管改进的 A∗ 算法可以在复杂环境下高效探索路径并找到最优解，但基于搜索的路径规划算法无法获取到多条路径，未来的研究方向可能是将 A∗ 算法进一步与无人机特征相结合，进而在大规模复杂环境下实时规划最优路径。

RRT 算法是基于采样的路径规划算法。该算法易于实现，搜索效率高，高维场景的算法复杂程度低。但 RRT 算法存在路径冗余不具有最优性，复杂环境内规划时间长等问题。因此研究者们提出了 RRT∗ [64]、P-RRT∗ [65]、Informed-RRT∗ [66]、Bi-RRT∗ [65] 等算法。RRT∗ 算法通过对新路径点一定范围内路径进行重新连接，获取初始路径后迭代寻优等方式获取路径，因此具备渐近最优性。P-RRT∗ 通过以一定概率向终点扩展的方式加速寻找初始路径，提升规划效率。informed-RRT∗ 算法通过规划路径长度确定采样椭圆区域，增加寻优效率。Bi-RRT∗ 算法通过双树进行搜索，增加规划效率。改进的RRT∗ 算法目前已经可以循环寻求渐进最优解，但其路径存在抖动，路径质量很大程度上仍取决于初始路径，未来可以结合模糊控制和机器学习来提高路径稳定性。

人工势场法是基于虚拟力的路径规划算法。该算法使路径点按照势场下降的方式避开障碍物向目标点移动，具有目的性和方向性，计算复杂度低。但该算法是不完备的，容易陷入局部最小值区域。许多研究者对其进行了改进，如引入角度与速度调节因子 [67]、相对距离 [68]、模糊逻辑 [69] 等。

## 1.2.2.2 无人机路径规划的智能优化算法

智能优化算法引入了启发式思想，能够很好地处理复杂动态的非结构化约束和NP-hard问题，根据实时测量的环境元素信息进行路径规划，省略了构建复杂环境模型的过程。常见的无人机路径规划智能优化算法有：基于群体的算法如蚁群算法 [21] 等，基于进化的算法如遗传算法等。

基于群体的算法通过模拟生物的群体行为来建立最短路径。以蚁群算法为例，该算法模拟了蚁群间协作，是一种正反馈机制算法，该算法旨在通过评估下一个搜索路径点的信息素密度来找到最佳路径。蚁群算法目前已可以在已知的静态大规模环境中找到最优路径 [70]。但该算法容易陷入局部最优解，导致算法收敛速度慢，在实时规划情况下并不实用。常见的改进方式包括改进启发函数 [71]、改进信息素更新机制 [72]、自适应策略 [73] 等。

基于进化的算法通过适者生存原则模拟自然生物进化来建立最优解。以遗传算法为例，该算法将问题所有可能解编码为染色体，组成初始种群，通过交叉、变异和选择获取到最优解。该算法简单、搜索能力强、易于其他算法结合、能更好地利用历史信息。但该算法容易过早收敛，当逼近问题最优解时，算法收敛速度会降低；此外，该算法的运算过程较复杂，计算效率不高，算法的性能依赖于合适的参数。常见的改进方式包括限制生成区域 [74]、自适应策略 [75]、结合其他算法 [76] 等。

智能优化算法的优势在于能够应对静态和动态威胁，能够获取多条路径以备选择。但在复杂环境中，该类型算法需要大量的计算资源来规划路径，规划时间大幅增加，因此尽管该类型算法可以处理动态威胁，大部分研究仍以离线规划方式为主。

## 1.2.2.3 无人机路径规划的强化学习算法

强化学习（Reinforcement Learning, RL）算法无需环境信息，通过智能体与环境进行交互，获取反馈信息来进行优化决策的人工智能算法，因此适用于未知环境的路径规划。近年来常用于无人机路径规划的强化学习算法有：基于值函数的强化学习如 Q（Q-Learning）、DQN（DeepQ-learning）等、基于策略的强化学习如PG（Policy Gradients）、DDPG（Deep Deterministic Policy Gradient）等。

基于值函数的强化学习与环境交互后，输出下一步要进行动作的价值，根据最高价值选择动作，仅能处理离散动作决策，但其数据利用效率较高。2021 年周彬 [77] 等人针对无人机自主导航及快速路径规划问题，提出了一种基于导向强化 Q学习的无人机路径规划算法，在栅格环境中实现了自主导航和快速路径规划，有效加快了算法收敛速度。但传统的 Q 算法存在维度突变、易过拟合、易陷于局部最优的问题，部分研究结合深度学习与 QL 算法，产生了深度强化学习领域的一种经典算法 DQN。2022 年辛伯彦 [78] 等人提出了一种 DQN 算法，该算法改进了奖励机制与经验回访机制解决了无人机自主路径规划问题。

基于策略的强化学习与环境交互后，输出下一步要进行动作的概率，根据概率采取行动，因此每种动作都可能被选中，可以处理连续动作决策。2020 年李一兵[79] 等人提出了基于深度确定性策略梯度 DDPG 的无人机自主路径规划算法，该算法在存在空中障碍物的三维连续环境中规划了无人机路径。2022 年清华大学的陈昱宏 [80] 等人在大规模且连续的搜救场景下，基于分层学习的概念，对传统 DDPG算法进行了改进，提出了一种适用于多目标任务的深度强化学习算法MTDDPG算法，有效提高了完成任务的效率和训练时间。

强化学习能够在复杂环境下自主学习最优策略，自适应地调整路径规划方案，但该算法需要大量的计算，调整许多参数，这些参数可能会对规划路径产生很大的影响。

近年来二维路径规划算法研究非常完备，三维路径规划算法也已经有很多研究，但针对实际复杂场景的威胁源建模、实时动态规划、算法与无人机结合等方面研究仍不充分。因此，实际应用中的三维复杂环境、多种任务实时性要求、路径规划算法与无人机性能的结合对无人机路径规划算法提出了严峻的挑战。

## 1.3 本文的工作及结构安排

本论文首先针对无人机对无线传感器网络进行数据采集问题，设计了一种基于旅行商（Travelling Salesman Problem, TSP）和凸优化（convex optimization）问题的离散域路径规划算法；其次针对三维复杂环境中两点间路径规划问题，设计了一种基于 A∗ 的连续域路径规划算法。

## 1.3.1 工作与创新

一、针对传统数据采集路径规划任务中常将三维环境通过固定高度方式简化为二维环境的问题，对无人机在三维环境下的路径规划问题进行了场景建模。

二、设计了一种基于 NTSP-TCO 问题的两阶段算法，对空间分布异构无线传感器网络的数据采集问题规划无人机的路径。该算法首先引入虚拟点对传统 TSP问题进行了改进，得到了不返回旅行商问题，规划得到无人机由起点遍历传感器设备到终点的单向遍历路径。在此基础上考虑异构传感器设备存在不同的通信半径，设计了一种三点凸优化算法迭代得到无人机采集数据的最优离散点路径。

三、设计了一种 BSTDAStar 算法，对空间复杂环境的无人机进行高效路径规划。首先针对空间复杂环境建立了威胁度模型。考虑到三维环境搜索空间大、威胁源复杂、规划时间长等问题，分别针对 A∗ 算法的搜索方向、搜索步长、搜索机制、启发函数等方向进行了分析并改进。考虑到无人机可搭载雷达等设备完成探测功能，将无人机探测距离引入该算法，将无人机特征与算法结合进行了针对性改进，高效的规划出一条可行、安全、平滑的最优路径。

四、设计了一种综合可行性、路径长度、路径平滑度、威胁度、路径规划时间的路径效用函数对规划的路径进行效用分析。该效用函数通过是否满足无人机航向角约束、路径长度、平均转向角、路径威胁度与规划时间五个方面分别设计了路径的可行性效用、路径长度效用、路径平滑度效用、威胁度效用、路径规划时间效用五个函数，进而得到了总路径效用函数，通过该函数对无人机飞行路径进行了评估。
