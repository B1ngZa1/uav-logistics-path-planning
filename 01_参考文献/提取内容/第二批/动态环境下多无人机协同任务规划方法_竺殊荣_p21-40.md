的最大航程约束， $\mathrm { { M } _ { U _ { i } } }$ 表示无人机可以执行的任务类型约束， $\mathrm { P _ { U _ { i } } }$ 表示无人机 $\mathrm { U } _ { \mathrm { i } }$ 的武器载荷约束。对于无人机的其它的物理限制条件如最小转弯半径、最小航迹段长度、最大俯仰角等，一般在航迹规划阶段进行考虑。可假定在任务分配阶段，无人机去执行集合 T 中的每一个任务时可以忽略这些约束条件的影响。

根据上述的定义，将多无人机协同任务分配问题描述为：在满足战场环境中的约束条件下，将任务集合中的 $\mathrm { N _ { T } }$ 个任务分配给 $\mathrm { N _ { U } }$ 架具有不同作战能力的无人机，并使得无人机机群执行任务的总代价最小。

由上述的描述可知，多无人机协同任务分配问题是多约束条件下的组合优化问题，约束条件多且复杂，下面对各约束条件进行具体的说明。

## 2.1.4 多无人机协同任务分配约束条件

本节对多机任务分配模型涉及到的约束条件进行定义。

## （1） 最大航程约束：

最大航程约束限制了编队中每架无人机的最远航程，是衡量无人机性能和耗油量的主要指标，不能为无人机分配其不可达的目标，引入最大航程约束体现了无人机间执行任务能力的差别和不同性能的无人机协同完成任务的特性。

## （2） 无人机载荷约束：

由于无人机编队中无人机体积和载重量的不同，引入无人机载荷约束规定了每架无人机可携带的武器数量。每架无人机分配到的任务序列所要求的总武器投放量不能超过其武器载荷。

## （3） 任务时序约束：

不同的任务之间存在时序约束，体现了任务间的依赖关系和执行顺序，比如对某一目标点执行的攻击任务需在侦察任务完成后进行。任务之间的时序约束可以用偏序关系表示。如果任务 $\mathrm { T _ { i } }$ 要在 $\mathrm { T _ { j } }$ 之前进行，则任务间的时序关系表示为 $\mathrm { T _ { i } { \preccurlyeq } T _ { j } }$ ，称 $\mathrm { T _ { i } }$ 为 $\mathrm { T _ { j } }$ 的前序任务。无人机在执行某任务时，该任务的所有前序任务必须已经完成。

## （4） 类型约束：

类型约束包括无人机类型约束和任务类型约束。任务类型包括侦察、巡航和打击任务，每个任务只能有一个单一的任务类型。无人机类型约束用集合 $\mathbf { M } _ { \mathrm { U } _ { \mathrm { i } } }$ 表示， $\mathrm { M } _ { \mathrm { U } _ { \mathrm { i } } } { \in } \mathrm { M }$ , 按类型将无人机分为 4 类, $\mathrm { M _ { U _ { i } } = \{ S \} }$ 表示侦察型无人机， $\mathrm { M _ { U _ { i } } } { = } \{ \mathrm { A } \}$ 表示打击型无人机, , $\mathrm { M _ { U _ { i } } = \{ S , A \} }$ 表示察

打一体式无人机, $\mathrm { M _ { U _ { i } } } { = } \{ \mathrm { E } \}$ 表示巡航型无人机。

## （5） 多机协同性约束：

多无人机协同任务分配算法要求在合理时间内将全部作战任务分配给机群内的无人机。在某个任务的所有约束条件被满足的情况下，单架无人机能够独立完成这个任务。比如某侦察任务在无人机机载的传感设备的检测范围内，则规定无人机能够完成此侦察任务。本文定义的协同性约束有一个任务只能由一架无人机执行，一架无人机可以被分配多个任务目标，并按照一定的次序去执行这些任务。

## 2.1.5 多无人机协同任务分配数学建模

多无人机协同任务分配是带约束条件的最优化问题，最优化问题通过约束条件来限制参数的取值，并设置目标函数作为问题的评价指标，问题的求解是在满足一系列约束条件的情况下，使得目标函数达到最小值。

所以，对多机协同任务分配问题进行数学建模需要根据任务分配问题的描述和约束的定义，设置目标函数和约束条件集合。并设置合理的目标函数来评价任务分配方案的优劣，本文设置的多无人机协同任务分配的优化目标为：

（1） 有尽可能多的任务能够得到分配执行；

（2） 执行任务的所有无人机的总航程代价最短。

优化目标（1）体现了无人机机群对整个任务集合中的任务的执行完成度，则优化目标（1）用被分配的任务总数与总的任务数量的比值表示。假定经过任务分配后，每架无人机分配到的任务数量为 $\mathrm { N _ { U _ { i } } }$ ，由于优化目标是期望目标函数最小化，所以计算公式为：

$$
\mathrm { J _ { 1 } } { = } 1 - \mathrm { \frac { \sum _ { i = 1 } ^ { N _ { U } } N _ { U _ { i } } } { N _ { T } } }\tag{2.1}
$$

优化目标（2）要求无人机机群执行分配到的任务目标的总航程代价最短，将总航程指标用 ${ { \ J } _ { 2 } }$ 表示，表示公式为：

$$

$$
\mathrm {  ~ X _ { i j u } = \{ \begin{array} { l l } { 1 , \mathrm { \mathcal { F } \mathcal { M } \mathcal { M } \ l \ u \ j d i f \ i f \cdots  \langle \underline { { F } } \underline { { \mathcal { M } } } \mathrm { \Sigma \backslash \Sigma } \mathrm { i \Sigma } \mathrm { i \Sigma } \mathrm { i \Sigma } \mathrm { i \Sigma } \mathrm { i \Sigma } \mathrm { j \Sigma } \mathrm { j \Sigma } } } \\ { 0 , } & { \ \mathrm { ( u \in U , \ i , \ j \in T ) } } \end{array}  }\tag{2.3}

$\mathrm { d _ { i j u } }$ 表示无人机 u 从任务 i 转移到任务 j 所要飞行的航程代价，即 $\mathrm { d _ { i j u } }$ 为任务 i 与任务 j 之间的距离。

根据以上的描述，多无人机协同任务分配问题的目标函数为任务分配的完成度指标与无人机执行任务的总航程代价指标之和，求解目标是使得目标函数最小化。目标函数 J 表示为：

## 2.2 多无人机协同任务动态重分配

## 2.2.1 动态重分配问题

经过多机协同任务分配后，无人机按照任务分配方案依次去执行任务。而实际的战场环境是一个动态环境，整个战场的信息不是一成不变的，无人机或者任务点的状态随时都会发生改变，无人机任务分配的方案也要随之改变。因此，需要进行动态环境下的无人机任务重分配。

通过任务重分配能让无人机更快的适应动态变化的环境，提升了无人机任务规划系统的稳定性和响应能力。所以任务重分配对实时性要求较高，希望在快速求解的基础上得到一个较优的重分配方案，若继续采用 2.1 节介绍的多机协同任务分配模型和相应算法进行求解，则代价太大，显然是不合适的。所以要根据任务重分配的特点，简化重分配模型，提升算法的执行效率，对无人机机群内的局部无人机进行任务分配方案和任务执行次序的调整。

重分配方法需要考虑的因素主要包括：

1)重分配的触发场景和突发情况的类别；

2)需要进行重分配的任务种类和数量；

3)无人机编队中正在执行任务的无人机种类和数量

4)无人机当前位置和剩余可飞行航程

5)现有无人机编队是否能满足待重分配任务集合的要求。若能满足，则进行任务重分配，否则，可通过请求增派无人机支援等方式进行解决。

## 2.2.2 动态重分配触发场景

任务动态重分配的场景应该进行预先设置，当无人机机群在执行任务的过程中遇到突发情况时，将根据预先设置的场景启动动态重分配响应机制。本文根据多无人机作战的实际情况，将触发动态重分配的场景分为任务取消或增加、任务点位置更新和无人机故障这三种，重分配的触发条件是无人机在任务执行过程中遇到这几种分配场景中的一种或者多种情况。

下面对重分配触发场景作具体介绍：

## 1)任务取消或增加

由于战场中的部分环境信息处于未知状态，从而导致任务空间的变化，比如出现新的重要目标点，无人机机群需要在新目标点上执行任务，则要向任务集合 T 中增加一个或多个任务；又比如遭遇突发的恶劣天气状况，无人机执行任务危险系数过高，则需要取消任务集 T中的某一个任务。

当出现新增任务时，通过重分配算法将其分配给无人机机群内的某架无人机，并对这架无人机执行任务的次序进行调整。根据图2-3所示，假设无人机原先的执行任务顺序是 $\{ \mathrm { T } _ { 1 } \substack {  }$ $\mathrm { T } _ { 3 } \}$ ，在执行任务 $\mathrm { T } _ { 1 }$ 过程中，新增攻击任务 $\mathrm { T } _ { 2 }$ ，则通过重分配得到的新的任务序列为： $\{ \mathrm { T } _ { 1 } \substack {  }$ $\mathrm { T } _ { 2 } \mathrm {  T } _ { 3 } \}$ 。

## 2)任务位置更新

在实际环境中，由于目标点的位置可能发生改变，还有传感器和情报信息的滞后性，任务分配时所依赖的战场环境数据存在一定的误差，所以当更新后的任务点位置与原先的任务点位置有较大差别时，要对该任务进行重分配。

在执行任务的过程中，无人机因自身出现故障而失去执行任务的能力。这个时候出现故障的无人机的任务序列中的所有待执行的任务就需要重新分配。

## 2.2.3 动态重分配问题建模

任务动态重分配导致机群中的多架无人机所要执行的任务集合发生了改变，需要对这些无人机执行任务的次序进行调整，将任务序列的调整问题建模为旅行商问题(TravelingSalesman Problem，TSP)[58-59]。TSP 一般描述为：一位旅行商需要访问 n 个城市并返回出发点，每个城市只能访问一次，目标是求得所有路径中的最小值。

TSP 在图论意义下被称为 Hamilton 圈[60]问题，用图论中的数学语言描述为： $\scriptstyle { \mathrm { G } } = ( { \mathrm { V } } , { \mathrm { E } } )$ 为完全连通的有向图，图中节点的集合为 V，边的的集合为 E，各顶点之间的距离为 ${ \mathrm { d } } _ { \mathrm { i j } }$ ，L 为解序列，决策变量 $\mathbf { X } _ { \mathrm { i j } }$ 表示为：

$$
\mathbf { x _ { i j } } = \left\{ \begin{array} { l l } { 1 , \quad } & { ( \mathrm { i , j ) \in L } } \\ { 0 , } & { \sharp \overset { \cdot } { \right. } } \end{array}\tag{2.12}
$$

TSP 数学模型表示如下：

目标函数：

$$
\mathrm { M I N \ Z = \sum _ { i \ne j } d _ { i j } x _ { i j } }\tag{2.13}
$$

约束条件：

$$
\sum _ { \mathrm { i } \in \mathrm { V } , \mathrm { i } \neq \mathrm { j } } \mathrm { x } _ { \mathrm { i j } } { = } 1\tag{2.14}
$$

$$
\sum _ { \mathrm { j } \in \mathrm { V } , \mathrm { j } \neq \mathrm { i } } \mathrm { x } _ { \mathrm { i j } } { = } 1\tag{2.15}
$$

$$
\sum _ { \mathrm { i , j \in V } } \mathrm { x _ { \mathrm { i j } } = \mathrm { | L | } }\tag{2.16}
$$

其中，|L|为 L 中的元素个数，约束条件(2.14)、(2.15)约束了每个节点只能访问一次，约束条件(2.16)约束了Hamilton 圈中没有任何子回路。

## 2.3 本章小结

本章主要对多无人机协同任务分配与动态重分配问题模型进行了分析研究。首先列出了多无人机协同任务分配的建模流程，将复杂的任务集合分解为适合于单架无人机执行的子任务，然后用无人机集合、任务集合、任务类型、约束条件对任务分配问题进行了描述，并对无人机自身约束条件和任务约束条件进行了定义，最终建立了更贴合实际战场环境的任务分配数学模型。分析了动态重分配问题的特点和求解该问题要考虑的要素，对重分配的触发条件进行了归纳总结，并建立了适用于动态环境的重分配问题模型。

## 第三章 基于 SOM 神经网络的多无人机协同任务分配与重分配方法

建立任务规划模型后，需要采用相应的算法进行问题求解，本章介绍了基于SOM 神经网络的多无人机协同任务分配与动态重分配方法。简单介绍了自组织特征映射神经网络的结构、原理，分析了基于SOM神经网络算法的关键要素。详细阐述了基于 SOM神经网络的多无人机协同任务分配算法步骤，主要对SOM 神经网络的初始化、优胜邻域的计算和权值更新进行了设计。对于多无人机协同任务动态重分配问题采用了分组策略，首先采用基于 SOM神经网络的聚类算法进行聚类分组，对聚类算法的初始类簇中心、优胜邻域内节点的权值更新公式进行了改进设计，然后采用引入精英蚁群的蚁群算法进行无人机任务序列的动态调整。基于分组策略的动态重分配方法具有较快的响应能力，可根据环境的动态变化对无人机任务分配结果进行局部调整。

## 3.1 自组织特征映射神经网络简介

自组织特征映射(Self-organizing Feature Map，SOM)神经网络是一种竞争型神经网络，由赫尔辛基大学 Kohonen.T 教授于 20 世纪 80 年代提出[61][62]。神经元在动物大脑中呈有序排列，由多个神经元组织而成的处理单元对外界特定的输入信息做出响应。在生物神经系统中，当一个神经元兴奋以后，会对周围神经元产生抑制作用，这种现象为侧抑制。这种抑制作用会使神经细胞间出现竞争，其结果是某些神经元被激活，而另一些神经元处于抑制状态。大脑中神经元的这些响应特点不是先天安排好的，而是通过后天的自组织学习形成的，SOM 神经网络就是模拟上述生物神经系统的人工神经网络。

SOM 神经网络是由输入层、竞争层(输出层)构成的两层网络，网络中没有隐含层，两层网络之间的各神经元是双向连接的。输入层模拟感知外界输入信息的器官，通过权值向量将外部输入传输到竞争层各神经元。竞争层模拟大脑皮层做出响应，竞争层神经元有多种排列方式，包括一维线阵，二维平面阵，三维矩阵等。SOM神经网络是一种非监督学习式神经网络，不需要任何先验知识，所以 SOM 神经网络算法不以网络的误差作为算法的准则，而是通过模拟神经元之间的竞争与抑制来指导网络的学习，具有自组织特性，SOM神经网络有两个学习规则：

（1） Winner Take All(WTA)规则:网络的输出层神经元之间相互竞争，每一时刻只有一个神经元处于兴奋状态，而其它神经元处于抑制状态。将这个处于兴奋状态的神经元称为获胜神经元。

（2） Kohonen规则:获胜神经元会影响它周围的神经元的状态，获胜神经元对其邻近神经元的影响随神经元之间距离增加由兴奋变为抑制。

（2） 优胜邻域的设计：SOM 神经网络每次迭代只对获胜节点的优胜邻域内各节点进行权值更新，所以优胜领域的设计至关重要。优胜邻域的设计原则是随着迭代次数的增加，优胜邻域不断减小，保证输出层各节点的权值向量之间既有区别也有相似性，且当获胜节点对某一输入有响应时，其邻域节点也能做出响应。

（3） 学习率的设计：学习率是权值更新中用到的参数，学习率的设计对网络收敛的速度、精度都有影响。在训练开始时，学习率可以选取较大的值，随着迭代次数的增加，学习率也不断下降，最后在较小的值上缓慢降至0 值，从而表征迭代过程的结束。

## 3.3 基于 SOM 神经网络和蚁群算法的任务动态重分配方法

## 3.3.1 任务动态重分配算法流程

使用 3.2 节介绍的基于 SOM 神经网络的任务分配方法可得到一套合理的任务分配方案，但由于战场态势的变化，任务分配方案也要随之改变，这时就需要任务重分配算法进行快速响应。本节利用 SOM 神经网络的自组织、自适应能力结合引入精英蚂蚁策略的蚁群算法提出了任务动态重分配算法，对突发情况进行快速响应，并得出具备较高任务效能的任务重分配方案。

本文提出的基于 SOM 神经网络和蚁群算法的任务动态重分配方法使用了分组策略，分为两个步骤。首先使用基于 SOM 神经网络的聚类算法将需要进行重分配的任务集合和正在执行任务的无人机集合进行聚类分组，然后采用蚁群算法对分组后任务序列发生改变的无人机进行内部任务执行次序的调整，并最终输出经过动态调整的任务重分配方法。任务动态重分配算法的流程图如3.3所示。

## 3.3.2 基于 SOM 神经网络的聚类算法

在2.2.2 节设置的动态重分配触发场景包括任务增加或取消，任务位置更新，无人机故障这三种。当出现这三种突发情况的一种或多种时，将需要进行重分配的任务加入到集合 $\mathrm { T _ { r e } }$ 中，然后采用基于SOM 神经网络的聚类算法对 $\mathrm { T _ { r e } }$ 中的任务和无人机集合进行聚类分组。

基于SOM 神经网络的聚类算法的基本流程如图 3.1所示。本文为了将算法应用于任务动态重分配问题中，对算法进行了如下几点的设计：

## （1） 网络初始化：

网络输入层节点为 $\mathrm { T _ { r e } }$ 中的任务，输入层节点的权值为任务坐标。将竞争层设置为一维线阵，每个竞争层节点代表一个类簇 ${ \bf { C } } _ { 1 } ^ { \prime } ;$ ，竞争层节点的初始权值设置为类簇的初始中心。

## （2） 初始类簇中心：

假定作战空间下参与到重分配的无人机数量为 n，则通过聚类算法聚类得到的类簇数量

为 n。将类簇 ${ \bf { C } } _ { 1 } ^ { \mathrm { { - } } }$ 的初始类簇中心设置为无人机 $\mathrm { U } _ { \mathrm { i } }$ 的当前位置坐标。

## （3） 优胜邻域的设计:

将优胜邻域设计成以优胜节点为中心，半径为 r(t)的圆形区域。r(t)随着算法迭代次数增加将不断减小，r(t)的计算公式为：

$$
\scriptstyle \mathrm { r ( t ) = C _ { 1 } } ( 1 - { \frac { t } { t _ { \operatorname* { m a x } } } } )\tag{3.4}
$$

公式中 $\mathrm { C } _ { 1 }$ 为正常数，t为当前迭代次数， $\mathrm { \Delta t _ { m a x } }$ 为最大迭代次数。

## （4） 网络权值更新规则：

采用Kohonen学习规则对优胜邻域内的所有节点进行权值更新。权值更新的程度随节点离优胜节点的距离增大而不断减小。权值更新公式如下：

$$
\mathrm { w _ { i j } ( t + 1 ) { = } w _ { i j } ( t ) + \eta ( N ) [ X _ { i } { - } w _ { i j } ( t ) ] }\tag{3.5}
$$

$$
\eta ( \mathrm { N } ) { = } \mathrm { C } _ { 2 } \ \mathrm { e } ^ { \mathrm { - N } }\tag{3.6}
$$

其中 $\mathrm { X _ { i } }$ 输入向量，η(N)为优胜邻域内的节点与优胜节点之间的距离 N 的函数。

## 3.3.3 基于蚁群算法的无人机任务序列调整

经过 3.3.2 的聚类分组操作后，无人机集合中的部分无人机所要执行的任务集合发生了变化，需要调整这些无人机执行任务的次序，即选择一条线路使得无人机从当前位置出发执行其分配到的任务集合中所有任务的飞行总航程最短。将这个问题建模为 TSP，假设共有 k 架无人机执行任务的顺序需要调整，则采用引入精英策略的蚁群算法解决这 k 个 TSP。

蚁群算法(ant colony optimization, ACO)是意大利学者 Marco Dorigo[64-65]受到自然界中蚂蚁觅食行为的启发而提出，是一种模拟蚂蚁群体从蚁穴到食物源搜索最短路径行为的仿生优化算法。蚁群最初以随机的方式搜寻食物，在找到食物回城的路径中，蚁群会分泌化学物质信息素。信息素同时也是蚂蚁间通信的物质，蚂蚁能够感知到当前路径上的信息素浓度，并倾向于朝着该物质浓度高的地方前进。在蚂蚁释放信息素总量一定的情况下，蚂蚁所走的路径越短，则该条路径上的信息素浓度越高，通过这种方式引导其它蚂蚁搜索该路径。这样最优路径上的信息量累积越来越多，其它路径上的信息量随着时间而逐渐挥发，这样便形成了一个正反馈机制。精英蚂蚁[66-67]是指在全部蚂蚁都构造完各自路径后，在所有路径中走过最短路径的那些蚂蚁。

蚁群在寻找最优路径过程中，通过信息素的作用发掘路径信息，没有借助于外界信息，表现出高度的自组织特性，这种搜索过程可以从下图看出。

在图3.4中，A点为蚁穴，E点为食物源，FC 为障碍物，则蚂蚁只能经过A-BFD-E或 A-BCD-E 这两条路径，BFD 和 BCD 两条路径的长度分别为 2 个单位和 1 个单位。初始状态下所有路径上都未留有信息素。每个时间单位都有 30只蚂蚁从 B点去往D点和有30 只蚂蚁由D 点去往 B 点，从这两个岔路口出发选择往左还是往右。一开始，所有蚂蚁进行随机选择，如图 3.4(b)所示。经过几个时间单位后，由于 BCD 路径比 BFD 路径短，当蚂蚁在路径上留下的信息素总量一定时，BCD 路径上的信息素浓度较高，所以有更多的蚂蚁选择 BCD 路径，如图 3.4(c)所示。经过更长时间积累后，BCD 上的信息素浓度会越来越高，最后所有的蚂蚁都会选择 BCD 这条较短的路径。

蚁群算法是群智能领域的一种重要算法，该算法具有正反馈、自组织性、较强的鲁棒性、易于其他方法结合等优点，在解决诸如TSP 的优化问题方面展现出了优异的性能，所以本文将无人机任务序列的动态调整问题建模为TSP，并采用该算法解决。

下面对蚁群算法具体步骤中涉及到的参数进行设置。设定蚁群中的蚂蚁数量为 m，待调整序列的节点数量为 n，待调整节点集为 $\mathrm { V = \left\{ \ v _ { 0 } , \ v _ { 1 } , . . . , v _ { n - 1 } \right\} }$ ，其中 $\mathbf { V } _ { 0 }$ 表示无人机的当前位置。$\tau _ { \mathrm { i j } } ( \mathrm { t } )$ 表示 t 时刻边(i,j)上的信息素轨迹强度。 $\boldsymbol { \mathrm { \eta _ { i j } ( t ) } }$ 表示边 $( \mathrm { i } , \mathrm { j } )$ 的能见度，代表了蚂蚁选择节点时由节点 i 移动到节点 j 的期望度，通常可以取 $\begin{array} { r } { \eta _ { \mathrm { i j } } ( \mathrm { t } ) = \frac { 1 } { \mathrm { d } _ { \mathrm { i j } } } . } \end{array}$ 。蚁群算法中设置的蚂蚁能够记忆已经访问过的节点，并且知道所在点距离其它节点的距离，所以为每只蚂蚁建立一个禁忌表 tabuk，tabuk记录了蚂蚁 k 已经经过的节点。在当次迭代周期内，蚂蚁不能经过 tabuk中存在的节点，在下一次迭代开始后，禁忌表将清空，表示新一轮搜索过程的开始。

蚁群算法的关键包括路径选择概率更新规则和信息素浓度更新规则。

1.路径选择概率更新规则：

蚂蚁 k 在 t 时刻处于节点 i 时，转移到节点 j 的转移概率Pijk(t)计算公式为：

$$
\begin{array} { r } { \mathrm { P } _ { \mathrm { i j } } ^ { \mathrm { k } } ( \mathrm { t } ) = \left\{ \begin{array} { l l } { \frac { \tau _ { \mathrm { i j } } ( \mathrm { t } ) ^ { \alpha } \boldsymbol { \eta } _ { \mathrm { i j } } ( \mathrm { t } ) ^ { \beta } } { \sum _ { \mathrm { r } \in \mathrm { a l l o w e d } _ { \mathrm { k } } } \tau _ { \mathrm { i r } } ( \mathrm { t } ) ^ { \alpha } \boldsymbol { \eta } _ { \mathrm { i r } } ( \mathrm { t } ) ^ { \beta } } , \mathrm { j } \in \mathrm { a l l o w e d } _ { \mathrm { k } } } \\ { 0 , \ } & { \mathrm { o t h e r w i s e } } \end{array} \right. } \end{array}\tag{3.7}
$$

其中 allowedk=V-tabuk，表示蚂蚁还未访问的节点。 $\mathfrak { a }$ 和 $\beta$ 为启发因子，表征信息素浓度和能见度在公式中的重要性，实验表明 α 设置为 1，β 取 2-5 较为合适。

## 2.信息素浓度更新规则

1)局部更新规则：每一次迭代过程中，蚂蚁每进行一次节点间的转移，则采用公式（3.8）和（3.9）更新相应路径上的信息素浓度：

$$
\tau _ { \mathrm { i j } } ( \mathrm { t + 1 } ) { = } \rho { \cdot } \tau _ { \mathrm { i j } } ( \mathrm { t } ) { + } \Delta \tau _ { \mathrm { i j } } ( \mathrm { t } , \mathrm { t + 1 } )\tag{3.8}
$$

$$
{ \Delta \tau _ { \mathrm { i j } } ( \mathrm { t , t + 1 } ) } { = } \sum _ { \mathrm { k = 1 } } ^ { \mathrm { m } } \Delta \tau _ { \mathrm { i j } } ^ { \mathrm { k } } ( \mathrm { t , t + 1 } )\tag{3.9}
$$

其中 $\rho$ 表示信息素保留的持久度， $\Delta \mathfrak { {tau } } _ { \mathrm { i j } } ( \mathfrak { t } , \mathfrak { t } { + } 1 )$ 为节点i 到节点j 信息素的增量。

2)精英蚂蚁更新规则：精英蚂蚁是指当所有蚂蚁都走完各自路径后，经过所有路径中最短路径的蚂蚁。在一次迭代结束后，对当次迭代最优路径进行额外的信息素浓度增强，通过引入精英蚂蚁能有效提升蚁群算法的收敛速度。信息素更新公式为：

$$
\Delta \mathfrak {tau } _ { \mathrm { i j } } ( \mathfrak { t } , \mathfrak { t } + \mathfrak { n } ) { = } \lambda \Delta \mathfrak { \tau } _ { \mathrm { i j } } ^ { \mathrm { b e s t } }\tag{3.10}
$$

$$
\Delta \tau _ { \mathrm { i j } } ^ { \mathrm { b e s t } } = \left\{ \begin{array} { l l } { \displaystyle \frac { 1 } { { \mathsf { d } } _ { \mathrm { i j } } } , \Xi \mathcal { \bar { H } } \displaystyle \mathcal { L } \Xi \mathcal { \bar { H } } \displaystyle \tilde { \Xi } \Xi \mp \Psi \displaystyle \Xi \mathrm { , } \ddag \Xi ( \displaystyle \mathrm { i } , \displaystyle \mathrm { j } ) } \\ { 0 , \qquad \mathrm { o t h e r w i s e } } \end{array} \right.\tag{3.11}
$$

本文使用蚁群算法求解无人机任务序列调整问题的具体步骤为：

步骤一：初始化：清空禁忌表， $\tau _ { \mathrm { i j } } ( \mathrm { t } )$ 为一个正常数 C，迭代次数计数器 $\mathrm { N } _ { \mathrm { c } } { = } 0$ 。

步骤二：迭代次数加一： $\mathrm { N _ { c } } { \gets } \mathrm { N _ { c } } { + } 1$

步骤三：将 m 只蚂蚁的出发位置置于无人机当前位置所在的节点上。

步骤四：路径构建：根据路径选择概率公式（3.7）计算蚂蚁从当前节点到其它节点的转移概率，并选择下一个要去的节点。

步骤五：蚂蚁向新的节点转移，将该节点加入蚂蚁的禁忌表中，并根据局部信息素更新公式（3.8）、（3.9）更新该路径的信息素。

步骤六：判断蚂蚁是否遍历了所有节点，若还有节点未访问，则转到第 4 步继续循环。否则，进入第7 步执行。

步骤七：根据精英蚂蚁信息素更新公式（3.10）、（3.11）更新最优路径上的信息素浓度。

步骤八：若 $\mathrm { N _ { c } }$ 超过了预先设置的最大迭代次数，则结束迭代并输出结果。否则跳转到第2步继续执行。

经过蚁群算法调整了组内任务执行次序后，任务重分配过程结束，各架无人机按照调整后的任务序列继续执行任务。

## 3.5 本章小结

本章研究了基于 SOM 神经网络的多无人机协同任务分配与动态重分配算法，并列出了算法具体流程。在任务分配的算法方面对基于 SOM神经网络的算法进行了改进，在网络初始化时充分考虑了任务分配问题的特性，并将 SOM 神经网络的两条学习规则结合用于优胜邻域的选取和网络权值更新步骤中，由于SOM神经网络网络结构简单高效、具有自适应能力且不需要任何先验知识，可以得到分配时间与总分配代价较优的分配方案。在动态重分配算法方面采用聚类分组策略，共分为两步。首先采用基于 SOM神经网络的聚类算法对需要进行重分配的任务集合和无人机集合进行聚类，并对聚类算法的初始类簇中心、优胜邻域的半径和权值更新规则进行了设计。然后通过在蚁群算法中引入精英蚂蚁策略，将局部更新规则与精英蚂蚁信息素更新规则结合，进行无人机执行任务顺序的调整。结合这两个步骤，得到具有动态响应能力的任务重分配方法。
