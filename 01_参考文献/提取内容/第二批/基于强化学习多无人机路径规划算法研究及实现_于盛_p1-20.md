## 摘 要

无人机技术已经成为各国战略目标中的重中之重，由于其小型，便捷，低成本广泛地受到商业推广，在军事领域和民用领域应用及其广泛。无人机技术也正从单无人机向多无人机协同工作方向过渡，因此研究多无人机的协同控制也显得尤为重要。

目前针对于无人机的任务规划研究多集中在传统的 A\*算法，人工势场法，D\*算法以及一些早期开始流行的智能算法，如蚁群算法，粒子群算法，遗传算法等。针对于单无人机问题，这些算法的运行时间可以接受。然而这些在多无人机协同工作的场景下，以上算法的运行时间会指数倍增加，在紧急情况很难满足时间上的要求。而针对这些不足，本文针对于不同的业务场景设计了基于强化学习的多无人机路径规划算法，并进行系统实现。

本文首先介绍了聚类相关基础知识，分析了无人机部署问题上各种方法的优劣，结合 DBSCAN 算法和 k-means 算法基于人口密度提出了一种无人机部署方法。其次阐述了强化学习的一些基本知识，再此基础上设计了单无人机单目标的路径规划算法，并且采用提前初始化 Q 值表和压缩状态空间两种方式对其进行优化使得运行效率显著调高。针对于单无人机执行多目标的情况设计了相关路径规划算法，分析了这种场景的缺点和不足。基于 MADDPG 算法，设计了多无人机多目标的路径规划算法，通过对奖励函数的设计使得无人机可以在不发生碰撞的前提下以最短距离到达目的地。仿真实验结果表明，该算法适合于不同环境下运行，不需要重复进行训练，相对于传统算法在执行效率上具有显著提升。最后在上述算法的基础上，结合 nginx，java，mysql 等技术设计网站，实现聚类算法和多无人机路径规划算法的线上执行。

关键词：强化学习，多无人机，MADDPG，协同路径规划

## Abstract

UAV technology has become the most important strategic goal of all countries. Because of its small size, convenience, low cost, it is widely used in the military and civil fields. UAV technology is also transiting from single UAV to multi UAV cooperative work, so it is very important to study multi UAV cooperative control.

At present, the research of UAV task planning mainly focuses on the traditional a \* algorithm, artificial potential field method, D \* algorithm and some early popular intelligent algorithms, such as ant colony algorithm, particle swarm algorithm, genetic algorithm, etc. For single UAV, the running time of these algorithms is acceptable. However, in the case of multiple UAVs working together, the running time of the above algorithm will exponentially increase, and it is difficult to meet the time requirements in emergency. In view of these shortcomings, this paper designs a multi UAV path planning algorithm based on reinforcement learning for different business scenarios, and implements the system.

Firstly, this paper introduces some basic knowledge of reinforcement learning, and then designs a single UAV single objective path planning algorithm, and optimizes it by initializing Q value table in advance and compressing state space, so that the operation efficiency can be significantly improved. Secondly, according to the situation of single UAV executing multi-objective, we design a path planning algorithm, and analyze the shortcomings and shortcomings of this scenario. Since then, based on maddpg algorithm and neural network, this paper designs a path planning algorithm for multiple UAVs, which makes UAVs use experience playback mechanism to learn neural network, so as to reduce the time to reach the target and avoid the collision between UAVs. The simulation results show that the algorithm is suitable for different environments and does not need repeated training. Compared with the traditional algorithm, the efficiency of the algorithm is significantly improved. Finally, on the basis of the above algorithm, the web site is designed with nginx, Java, MySQL and other technologies to realize the online execution of clustering algorithm and multi UAV path planning algorithm.

Keywords: Reinforcement learning, multiple UAVs, MADDPG, collaborative path planning

## 第1章 绪 论

## 1.1 课题研究的目的和意义

本课题来源于国家自然科学基金《面向地震灾害的多维机动信息采集传输与灾情综合评估》（项目编号：61071104）。无人驾驶飞机也叫“无人机”，英文缩写为“UAV”，是指由无线电遥控设备和独立的程序控制装置，或完全或间歇地由机载计算机操作的无驾驶飞机。无人机由于其智能化，操作灵活等特点以及其丰富的功能，在各个领域都得到了广泛的应用。

按应用领域划分，无人机可分为军用和民用。在军事方面，无人机分为侦察机和目标机。在民用方面无人机技术已经被广泛应用于航空摄影、植保、新闻报道、微自拍、快运、农业、野生动物观察、灾害救援、影视拍摄、传染病监测、救灾、电力巡查、浪漫制造等领域，大大的拓展了无人机本身的用途，各个国家都在积极发展无人机技术，扩展无人机在各行各业的应用。

无人机路径规划的目的是在未知或已知障碍物信息和硬件条件的约束下，规划当前位置和目标地址之间的最优路径。对于单台无人机来说，由于其体积一般小于常规飞机，而且其载油量也受到重量和尺寸的限制，无法实现大规模的连续侦察；由于机身的尺寸，无人机的通信设备和传感器性能无法与一架有人驾驶的飞机相比，所以单架无人机在用来处理覆盖大范围、大任务区的任务的搜索时间相对要更长。此外，当无人机执行高坠毁风险任务时，由于自身的故障或遭受外界的攻击，很可能无法完成搜索任务，这也使得搜索任务系统缺乏容错能力。小型无人机完成任务的成功率也会较低。基于这种情况，为了改善单一无人机执行任务时的局限性，美国空军委员会提出，针对复杂场景，应以无人机群的方式协同工作，取代单一无人机执行任务[1]。在绝大多数相对复杂的应用场景下，无人机群相较单个无人机将体现出明显的多机协同工作的优势，即使用多架相同或不同功能的无人机组成无人机群，进行协同工作，共同执行任务。本文将针对传统无人机群路径规划算法的缺点，在航迹规划时通过改变状态空间和初始化价值函数等方法，降低算法运行的时间。使其能够更迅速的实现无人机群的搜索任务。

近些年来由于机器学习的广泛应，很多学者也针对无人机的智能化提出了可行的方案。强化学习，机器学习的一个分支，在这个领域成绩显著。机器学习主要包括三大类：监督学习，非监督学习和强化学习。监督学习是利用一组已知类别的样本调整分类器的参数，使其达到所要求性能的过程，主要用于分类和回归分析。非监督学习就是不对数据进行标明，让机器自动去判断数据的相似性，归到一类等等。强化学习的核心是智能体通过与环境进行交互获得奖励，根据奖励的大小调整策略。本文将利用非监督学习中的聚类算法根据人口密度对无人机位置进行部署。并利用强化学习方法，针对不同业务类型设计高效的无人机的路径规划算法，使无人机能以最短的消耗完成任务。

## 1.2 国内外研究现状

## 1.2.1路径规划研究现状

1959年，荷兰科学家 Dijkstra提出了一种计算单源最短路径的算法[2]，该算法以贪心算法为思想，以起点为中心，向四周扩展，每一次探索中选择的下一个顶点都是距离起点欧几里得距离最近的点，当搜索的范围内覆盖到目标点则算法结束。这种算法被称作 Dijkstra最短路径搜索算法，因其得到的路径为最短路径，亦叫做贪心算法。在已知全局信息的静态地图中，这种方法能够得到最佳的路径，但执行效率较低。

1968 年，A\*路径规划算法被提出[3]，这种算法在 Dijkstra 算法的基础上，引入了启发式策略的思想。也就是在考虑当前位置到起点的距离的基础上，加入了一个参数用来评估当前位置到目标点之间的度量，以此来确定下一步要扩展的节点位置。与 Dijkstra 算法相比，A\*路径规划算法在扩展节点的选择上更具有目的性。因此，A\*算法在地图上访问的节点的数量相比 Dijkstra 算法要少很多，效率也有很大程度的提升。在具有大规模障碍物的复杂地图上，或者是在多维度的路径规划问题求解上，A\*算法的时间复杂度很高，在环境未知多变的地图中也存在无法求出有效解的可能。因此，国内外学者对于A\*算法做出来大量的改进工作，如 1985 年提出是的 IDA\*算法[4]，2004 年的 LPA\*算法[5]，以及 2008 年提出的BidirectionalA\*算法[6]等，都是 A\*算法的改进算法。

1986 年，美国科学家 OussamaKhatib 提出了人工势场法（PotentialField）[7]，其基本思想源于物理学中“场”的概念。算法将机器人在环境中运动的过程，模拟为在一种抽象的人工的“场”中的运动。目标点对机器人产生“引力”，而障碍物对机器人则会产生“斥力”。通过求解这两种力的合力就可以得出机器人运动的方向。人工势场法的主要难点在于参数的配置以及引力和斥力函数的设计上。应用人工势场法规划的路径一般相对安全且较平滑，实时性好，广泛应用于机器人机械臂等控制对象上。但是该算法也存在不可避免的缺点，在合力为 0 的位置很容易陷入局部最优。且当目标附近有障碍物时，移动机器人由于引力和斥力的抵消将很难甚

至永远也到达不了目标点。

1994 年，StentzA 提出了 D\*算法[8]，也被称为 D-Star 或 DynamicA\*算法，顾名思义，D\*算法是一种动态 A\*算法。这种算法能够解决在动态环境中 A\*算法无法求解的路径规划问题。算法的主要思想是先利用 Dijstra 算法从目标节点向起始节点搜索最短路径，然后按照这个路线进行移动，当移动的下一节点没有改变时，利用上一步 Dijstra 计算出的最短路径从出发点向后追溯即可。当感知出下一节点将发生改变，如障碍物位置发生变化或者路线突然阻塞，则利用启发式思想调整当前位置的权重并更新路径。这种方法主要应用于探路领域，火星探测器就采用了该方法。D\*算法在动态环境下是非常有效的。在移动到目标点的过程中，只需要检查最短路径上邻域节点的变化。但是，如果路径上距离较远的位置环境发生了改变，算法是无法预测的。针对这个问题，后来又涌现出了许多 D\*方法的改进版本，比如 1995 年 StentzA 本人提出的 FocusedD\*方法[9]，2005 年 KoenigS 等提出的 D\*Lite[10]算法，2006 年提出的 FieldD\*方法等，这些改进版本都对于原方法的计算效率进行了改善并扩展了应用范围。

1996年和概率图法（PRM）[11]被提出，紧接着1998年快速探索随机树法（RRT）[12]方法被提出。在这之前的路径规划算法都是以环境模型为基础进行的路径搜索，而这两种算法是以采样方法为基础的。不同于对整个环境空间进行建模，这两种方法在整个空间中随机选取散点，值到散点覆盖到起点和终点，各散点之间最短的连线即为最短的搜索路径。

2007 年，AlexNash 提出了 Theta\*算法[13]，该算法也是 A\*算法的一种改进，主要解决了在传统 A\*算法中，规划出来的路径只能沿着给出的模型（比如网格模型）中的单元顺序行走的问题。Theta\*算法中，会首先计算下一状态和当前状态的父节点之间有无视线，如果两个状态之间有视线（是直线连通的），则下一状态的父节点就被更新为当前状态的父节点，如果状态间没有视线，则同 A\*算法一样。经过这样改进的路径更加优化更加平滑，但是需要多次进行检查，在较为细致的网格中计算开销将十分巨大。

近年以来，人工智能技术的发展也给路径规划问题带来新的思路和方向。较为突出的有机器学习方法，混杂系统方法，以及遗传算法、模糊逻辑算法等。相较于传统算法，以上方法具有较高程度的智能特性，在静态，动态以及未知不确定的环境中都有着不错的表现。而对于人员搜救、战时目标打击、运送物资等多目标路径规划问题，多智能体算法有着更高的性能。多智能体系统是由多个具有一定自主性的智能 Agent 组成的[14]，这些 Agent 能够在共同目标窗口内协作、竞争和通信。相对于单个智能体，多智能体系统往往能够完成更加复杂艰巨的任务，且通常付出更小的代价，却收获更大的整体效益。这是由于单个 Agent 解决问题的能力有限，复杂的任务则需要多个 Agent 之间合作，从而共同实现一个整体或局部目标。但针对于路径规划问题，如果在同一环境中存在多个 Agent 同时移动，对其进行路径规划将会变得尤其困难。目前国内外针对解决多智能体的路径规划的问题也取得了一些进展，冯涛[15]提出了一种免疫协同进化算法，该算法在静态障碍物环境控制多个机器人在躲避障碍物情况下规划出最短路径;2017年李东正提出了一种基于主从结构的机器人并行协同路径规划算法[16]。它的子层结构采用了粒子群并行算法，用于为各个智能体生成目前能计算出的最优路径。与此同时主层结构则应用了微分进化算法，与子层结构几乎同时给出了考虑当前之智能体与智能体、智能体与障碍物之间避免碰撞的情况下，总时间最短的路径组合方案。以上两个算法都是在未知地图的基础上运行的，由于在未知环境下试错的过程较为漫长也导致了算法的复杂度较高，要进行多次尝试才能到达目标。2015 年郑延斌等人[17]首先利用 A\*算法启发式的得到多个智能体到达目标的最短路径，同时计算访问节点的时间，通过动态对时间窗进行计算和加锁来重置路线来避免冲突。该算法针对于临时最短路径的估计采用了欧式距离，算法在迭代过程中没能考虑崎岖路径造成的代价，因此算法的运算时间也较高。刘敬一于2018 年将分层强化学习算法及人工势场法结合起来[18]，实现了多智能体的路径规划算法，算法首先将多智能体的运行环境抽象为一个人工势能场，以物理学上的场定义环境确定每点的势能值，并且根据此计算出最优路径下可获得的最大回报。之后利用分层强化学习方法进行无环境模型学习的策略更新。该算法较好的完成了地图残缺或无环境模型情况下的路径规划问题。

## 1.2.2强化学习研究现状

强化学习是机器学习的一个分支，是一种无需先验知识的机器学习算法。强化学习具有很强的鲁棒性，它的核心是与环境交互进行迭代学习，它的两大基本特征是：与环境不断交互进行试错探索、在与环境交互后得到延迟回报。强化学习的目的是在迭代过程中获取新的知识，以此改进状态-动作函数来适应环境[19]。基于强化学习的路径规划指的是智能体通过各类型传感器感知周围环境状态，根据策略选择相应的动作，智能体执行完动作后会使当前状态发生改变，同时获得一个即时奖赏 [20]，以便于对策略函数进行更新迭代。强化学习的学习速率受到状态空间大小以及环境复杂度的限制。

目前强化学习算法主要可分为 Value-based 算法、Policy-based 算法、和基于Trust Region 的算法。其中 Value-based 强化学习方法的代表是 Q-learning 算法，2015谷歌在《Nature》上提出了结合深度学习的 DQN 强化学习算法，使强化学习再次回到研究的热点，DQN的主要创新之处在于使用了神经网络来替代传统 Q函数，而且DQN是引入了经验回放机制，解决了经验数据的相关性非平稳分布的问题，大大提高了交互数据的利用效率。目前DQN算法已经在游戏领域上取得了非常好的效果，证实了算法的有效性和通用性。随后各国学者对DQN网络进行了优化和改进，Schaul 等提出在DQN网络的基础上，将数据的重要程度应用在经验回放的频率上，大大加快了神经网络的收敛速度[21]。Van提出了Double-DQN算法，由于DQN 算法中期望 Q 值和模型计算出的 Q 值是通过一个神经网络计算的，因此存在估计偏差，而 Double-DQN 则避免了过高估计，使得算法获得了更加高效的学习速率[22]。Wang 等针对 DQN 架构层面进行了改动，提出了 Dueling-DQN，获取了更好的策略评估[23]。2016 年，谷歌在的 AlphaGo[24]就是以 DQN 为基础，结了合蒙特卡洛搜索树获得的。它解决了了围棋领域的大规模空间搜索问题，一举打败世界冠军。然而基于 Value-based 的强化学习算法有一些固有的缺点，使它的应用领域受到了限制。首先 Value-based 强化学习算法难以应用到连续的动作空间以及随机型的策略中。其次值函数的微小变动会引起决策策略的巨大变化，从而使神经网络无法收敛，尤其是引入函数近似后，虽然算法的泛化能力得到了提高，但是也引入了偏差，这使得训练的收敛性更加难以保障。在这一领域 Policy-based 算法有着很好的适应性，Policy-based 的算法的思想是将策略参数化，通过直接学习策略，突破于高维连续动作以及随机型策略的限制。

强化学习中较为经典的基于 Policy-based 的算法有 REINFORCE 算法[25]，目前基于 Policy-based 的深度强化学习算法则都是大多数都是建立在 Actor-Critic 框架下的。David Silver 于2014年提出了用于连续动作空间的确定性策略梯度定理和一种确定性目标策略的 Actor-Critic 算法[26]。Actor-Critic 算法在 Policy-based 思想上结合了 Value-based 方法，综合了两者的优点。而后谷歌的 DeepMind 团队又在DQN 基础上结合 Actor-Critic 的思想提出了 DDPG 算法，解决了 DQN 无法适用于连续动作空间的问题[27]。2016 年 Mnih 也基于 Actor-Critic 提出了 A3C 算法，该算法不仅适用于离散也适用于连续空间的控制问题，通过异步的方式，解决了 Online的强化学习算法在和神经网络结合后，数据相关性非平稳分布问题，大大提升了训练的速度[28]。2017 年 OpenAI 于 NIPS 上提出了 MADDPG 算法[29]，首次将深度强化学习运用于多智能体，解决了传统算法在多智能体中难以运用的困难。2019年何明等人针对于 MADDPG 算法学习训练效率低，收敛速度慢的问题研究了MADDPG算法经验优先抽取机制，提高了 MADDPG算法的训练速度[30]。

基于 Trust Region 的深度强化学习算法，是在优化论中的 Trust Region 的基础上结合强化学习理论获得的。2015年，利用 Schulman 提出的TRPO 算法对策略梯度进行优化，保证了策略的单调性改进。主要解决的问题是在策略更新后目标函数单调且不递减，同时用神经网络表示策略后，减少坏的更新迭代对策略的影响[31]。然而由于 TRPO 算法较为复杂，而且对于深度神经网络中常常使用的 dropout等方法并不兼容，因此应用受限。因此Schulman 对TRPO算法进行了改进，提出了PPO算法，相对于 TRPO算法，PPO算法更容易实现且提高了数据利用效率[32]。

## 2.1.1 k-means

k-means 聚类算法也称 k均值聚类算法，是一种简单且经典的基于距离的聚类算法。它以距离作为相似度的评价指标，即两个对象的距离越近，相似度就越大。这个算法认为类簇是由相互靠近的对象组成的，因此它的最终目标是得到紧凑独立的簇。

k-means 聚类算法是一种通过迭代求解的聚类分析算法。算法首先随机选取k个对象作为初始的聚类中心，然后计算每个对象到各个种子聚类中心之间的距离，将每个对象分配给距离它最近的聚类中心。聚类中心以及分配给它们的对象构成一个临时的簇。每次分配一个样本，各个聚类中心会根据簇中现有的对象进行调整。这个过程将不断重复直到满足终止条件，终止条件通常定义为没有（或最小数目）对象被重新分配给不同的簇中，没有（或最小数目）聚类中心再发生变化，此时误差平方和局部最小。

假设簇划分为 $( C _ { 1 } , C _ { 2 } , \cdots , C _ { k } )$ ，则我们的目标是最小化平方误差E

$$
E = \sum _ { i = 1 } ^ { k } \sum _ { x \in C _ { i } } \Vert x - \mu _ { i } \Vert _ { 2 } ^ { 2 }\tag{2-1}
$$

其中 $\mu _ { i }$ 是 $C _ { i }$ 的均值向量，有时也称为质心，表达式为：

$$
\mu _ { i } = { \frac { 1 } { | C _ { i } | } } \sum _ { x \in C _ { i } } x\tag{2-2}
$$

图2-1展示了通过 k-means 算法进行聚类后的聚类结果，可以明显看出对于数据点质心位置分散的情况，结果簇是密集的，簇与簇之间区别明显，k-means 算法能够得到很好的效果，而且 k-means 算法原理简单，收敛速度也很快，主要参数只有 k 值需要提前设置，因此适用于简单模型。基于 k-means 聚类的算法结果如图2-1所示，可见其对于球形分布的数据聚类效果较好。

(2) 若 则令 $m _ { i } = - 1$ ，暂时将 i号节点标记为噪音点

a) 令 $m _ { i } = k$ ，即将i号节点归属于第 k个聚类

## 2.2 基于聚类的无人机部署算法

城市环境中，无人机被广泛应用在电力巡检，救灾援助，影视拍摄等方面。本文考虑在城市区域设置无人机以满足紧急情况下即时执行响应业务的需求，由于城市环境错综复杂，设置无人机的初始位置显得尤为重要。无人机初始位置的设定不但要考虑距离自己负责街区的距离，还需考虑原本街区位置的实际情况，尽量不要让一架无人机负责区域跨越不同街区，造成管理上的问题。

由于城市环境较为复杂，直接采用 DBSCAN 算法或k-means 算法都会由于算法的局限性带来他们自身的问题。比如城市环境往往会采用环形结构的建筑群风格如图2-4所示。

本文考虑将上述两种聚类算法进行串连，以DBSCAN算法弥补街区跨越的问题，以k-means 算法解决球形区域的约束。算法执行流程如下，首先通过 DBSCAN算法对距离较远的街区进行划分，通过密度可达性算法计算各主街区所在区域的大致面积，进而计算出该街区所配置的无人机的个数 k。对于每个主街区采用k-means 算法进行无人机区域划分，保证无人机到自身所在区域内任意位置的平均距离最小。

整体算法流程如下，首先将人口密度数据经由 DBSCAN算法进行聚类，实现各个密度相连区域的划分，聚类个数为N，聚类结果为 $T _ { i } , i = 1 . . . N$ 。计算出人口密度地图中 X 坐标和 Y 坐标的最大值和最小值分别为 $X _ { \operatorname* { m i n } }$ ， $Y _ { \mathrm { m i n } }$ ， $X _ { \mathrm { m a x } }$ ， $Y _ { \mathrm { m a x } }$ 。在$( X _ { \mathrm { m i n } } , Y _ { \mathrm { m i n } } )$ ， $( X _ { \mathrm { m i n } } , Y _ { \mathrm { m a x } } )$ ， $( X _ { \mathrm { m a x } } , Y _ { \mathrm { m i n } } )$ ， $( X _ { \mathrm { m a x } } , Y _ { \mathrm { m a x } } )$ 围成的四边形区域以 0.01 为间隔均匀选取坐标点组成集合 C。DBSCAN 算法聚类生成的每一个簇都分配一个$m _ { i } , i = 1 , \cdots , N$ 。遍历坐标集合 C 中的每一个坐标，一旦该坐标到任何一个簇 $T _ { i }$ 密度相连， $m _ { i } = m _ { i } + 1$ 。坐标集合遍历后 $m _ { i }$ 可以近似表示每一个聚类区域的大致面积。针对每一区域进行 k-means 算法的 k 值由 $k _ { i } = m _ { i } / s _ { i }$ 计算。 $s _ { i }$ 表示平均每一架无人机管辖区域的面积。再根据 $k _ { i }$ 为每一个区域执行 k-means 算法即可得到最后的聚类结果。算法收敛结果如图 2-7 所示，k-means 算法的聚类中 $\therefore L ^ { \prime }$ 即为无人机部署的位置。
