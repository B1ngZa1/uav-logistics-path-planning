## 第3章 Q-learning 单无人机路径规划算法

本章首先阐述了路径规划环境建模以及传统路径规划方法。针对于单无人机单目标问题以及单无人机多目标问题，在基于 Q-learning 算法的路径规划算法基础上提出了基于初始化价值函数的优化方法，以及基于更改状态动作空间的优化方法。大幅度提升了算法执行速率，使其可以在突发任务情况下迅速找出合理路径完成任务。

## 3.1 路径规划环境建模

在机器人的路径规划问题中，首先需要对机器人的目标环境进行建模。环境建模是解决无人机路径规划的首要问题，也是能够实现无人机自主导航的基础[32]。具体的环境建模过程分为两个部分：首先根据一定的规则划分目标空间，然后对目标环境的地图信息进行处理，提取目标空间的特征信息[33]。之后对目标环境的地图信息进行处理，使之方便计算机的存储和进一步使用。目前经典的环境建模方法主要包括栅格模型法、拓扑模型法以及三维模型法等[34]。

## 3.1.1 栅格模型

栅格模型法是环境建模中最为成熟的，也是目前应用最广泛的方法[35]。栅格模型法的工作原理是以单元的形式划分目标空间，单元之间不重合，相互连接，称为栅格[35]。根据机器人的实际应用，栅格一般分为自由栅格和障碍栅格两类。无人机可以在自由栅格中自由移动，但不能在障碍栅格中移动。

栅格模型需要平衡环境精度、时间和空间代价。环境精度越高就意味着栅格数量越多，这会导致更大的时间、空间和内部需求；相反，为了节省内存、时间、空间，栅格会变得很大，虽然路径规划的速度会更快，但是这也使得路径规划的精度会降低[36]。

## 3.1.2 拓扑模型

拓扑模型通常用 的形式来表达环境信息，建造环境的过程相对简单，占用的内存更少[37]。其中， N 表示节点集，即环境的节点集合； 是边的集合，表示节点与节点间的连接。由于拓扑模型不需要实时获取机器人的

位置信息，因此在有效路径的搜索上具有较高的效率。该拓扑模型适用于目标环境中障碍物密集分布的情况。

## 3.1.3 高维模型

随着无人机行业的高速发展，无人机的应用场景也越来越广泛。为了应对无人机运动空间的高度复杂性，出现了高维模型[38]。其中，三维模型在无人机的环境建模中得到了广泛的应用。高维模型更加直观，包含了更多的环境信息，随之而来的则是存储环境信息的更高的内存需求。同时这也增加了路径规划算法的时间复杂度。

考虑本文采用强化学习为背景，尤其是 Q-learning 算法对于离散状态空间有着迫切的需要，而且栅格法也可以很好的满足障碍物和可通行区域的设定需求，本章考虑采用二维栅格法进行环境建模。

## 3.2 基于机器学习的路径规划算法

随着人工智能的技术的告诉发展，采用机器学习解决路径规划的算法应运而生。目前应用比较广泛的机器学习的路径规划技术有两种：

第一种是监督学习，文献[39]首先利用卷积神经网络分析激光信息，然后利用 算法作为标记信息，利用监督学习的方法对智能体进行运动路径的规划，这种算法在环境变化不大的情况下有着较好的效果；但该算法对于传统的标记算法依赖性较强，而对标记信息进行采集也较为耗时，而且对于环境经常变化的情况算法的实用性较差。

第二种就是强化学习。由于路径规划问题可以映射成一个标准的马尔可夫决策过程(MDP)，因此非常适合采用强化学习进行解决。通常会通过值迭代建立一张累积奖励值表，用于存储当前状态 (如无人机当前的位置)当前动作a下可获得的累积奖励。当整张奖励表确定之后，无人机在任意位置都可以根据当前状态，通过 Q 值表获得不同动作对应的不同奖励值，从而选出奖励值最大的动作，将其定义为下一时刻的运动方向。

## 3.3.1强化学习组成结构

在人工智能领域，用智能体 Agent 来表示一个具有自主行为能力的对象。而强化学习的目的就是使智能体通过不断与环境进行交互学习，从而获得选

择达到其目标的最优动作的能力。

<!-- image-->  
图 3-1 强化学习基本框架

在很多场景中，人们无法了解 Agent 的决策过程，因此无法产生用于监督学习的完整信息。然而，通过设计 Agent 的目标和不同环境下相应的奖励信息，可以使 Agent 通过强化学习获得最优的策略。因此可以说强化学习就是智能体 Agent 与环境通过交互从而获得某种学习能力的过程。强化学习的框架如图 3-1 所示。

在强化学习领域，有三个最为重要的参数，智能体和环境的交互包含了智能体的动作 Action，环境的状态值 State 以及智能体在当前环境执行动作所获得的奖励值 Reward。当智能体 Agent 执行了某一个动作 Action 与环境进行了交互之后，会获得一个即时的奖励，同时环境的状态 State 随之发生改变，而当前动作是否是最优的则可通过奖励 Reward 来衡量。

强化学习的理论是建立在如下两个假设的基础上的[41]：

（1）强化学习建立在经典物理学的范畴上，即时间可以被分割成离散的  
有 时 间 片 ， 在 这 些 时 间 片 上 状 态 ， 动 作 和 获 得 的 奖 励 即 为  
$\{ s _ { 0 } , a _ { 0 } , r _ { 0 } , s _ { 1 } , a _ { 1 } , r _ { 1 } , \cdots s _ { t } , a _ { t } , r _ { t } \}$ 。

（2）一旦输入是确定的，那么输出一定也是确定的。

强化学习由于满足了以上的时间片和确定性假设，可以将一起问题定义成一个马尔科夫决策过程。

马尔科夫决策过程要求：下一个时刻的状态只由当前时刻的状态决定，

而与之前的所有状态无关。假设当前状态 $S _ { t }$ ，则有：

$$
P ( s _ { t + 1 } \mid s _ { t } ) = P ( s _ { t + 1 } \mid s _ { t } , s _ { t - 1 } , . . . s _ { 1 } , s _ { 0 } )\tag{3-1}
$$

在 MDP 中，每个状态对应一个动作，下一个状态也可以由当前动作决定。而每一个状态的好坏都可以用一个确定的数值来判定。当前状态的好坏可以决定对未来回报的期望。我们用 $G _ { \mathrm { t } }$ 来代表当前时刻状态所具有的累积汇报值，它表示未来所有时刻奖励 Reward 的累加。 $G _ { \mathrm { t } }$ 的公式如式(3-2)所示：

$$
G _ { t } = R _ { t + 1 } + \lambda R _ { t + 2 } + \ldots = \sum _ { k = 0 } ^ { \infty } \lambda ^ { k } R _ { t + k + 1 }\tag{3-2}
$$

式(3-2)中， 是时间折扣因子，通常小于 1，它意味着当前时刻获得的奖励是最直接的也是最重要的，而之后时刻带来的奖励的影响会逐级递减。由公式(3-2)可见， $G _ { \mathrm { t } }$ 的计算了从当前时刻开始，所获得的所有奖励 Reward的叠加，这种计算方法在实际应用中效率极低。因此，在强化学习引入的价值函数(Value Function)的概念，用来表示当状态具有的价值。价值函数的定义如式(3-3)所示：

$$
V ^ { \pi } ( s ) = \sum _ { s ^ { \prime } \in s } p ( s ^ { \prime } \mid s , \pi ( s ) ) [ r ( s ^ { \prime } \mid s , \pi ( s ) ) + \lambda V ^ { \pi } ( s ^ { \prime } ) ] = \operatorname { E } [ G _ { t } \mid S _ { t } = s ]\tag{3-3}
$$

我们将公式(3-3)进行展开，得到如下形式：

$$
\begin{array} { r l } & { V ^ { \pi } ( s ) = \mathrm { E } [ G _ { t } \mid S _ { t } = s ] } \\ & { \quad \quad = \mathrm { E } [ R _ { t + 1 } + \lambda R _ { t + 2 } + \lambda ^ { 2 } R _ { t + 3 } + \ldots \mid S _ { t } = s ] } \\ & { \quad \quad = \mathrm { E } [ R _ { t + 1 } + \lambda ( R _ { t + 2 } + \lambda R _ { t + 3 } + \ldots ) \mid S _ { t } = s ] } \\ & { \quad \quad = \mathrm { E } [ R _ { t + 1 } + \lambda G _ { t + 1 } \mid S _ { t } = s ] } \\ & { \quad \quad = \mathrm { E } [ R _ { t + 1 } + \lambda V ^ { \pi } ( S _ { t + 1 } ) \mid S _ { t } = s ] } \end{array}\tag{3-4}
$$

公式(3-4)就是贝尔曼(Bellman)方程的基本形式，可以看出当前的状态价值由当前的奖励与下一时刻的价值决定。贝尔曼方程是通过迭代的方式进行求解的。

价值函数表示了当前状态可能获得的累积奖励，然而我们更希望得到的是当前状态下执行了一个动作所能获得的价值，由此选择价值最大的动作作为最优决策。因此在强化学习中，动作价值函数 $Q ^ { \pi } ( s , a )$ 用来表示在当前状态

下，执行了一个动作所获得的累积奖励，动作价值的计算公式如式(3-5)所示：

$$
\boldsymbol { Q } ^ { \pi } ( s , a ) = \sum _ { s ^ { \prime } \in s } p ( s ^ { \prime } \mid s , a ) [ r ( s ^ { \prime } \mid s , a ) + \lambda V ^ { \pi } ( s ^ { \prime } ) ] = \operatorname { E } [ G _ { t } \mid S _ { t } = s , A _ { t } = a ]\tag{3-5}
$$

动作价值函数的贝尔曼方程如下：

$$
Q ^ { \pi } ( s , a ) = \mathrm { E } [ R _ { t + 1 } + \lambda Q ^ { \pi } ( S _ { t + 1 } , A _ { t + 1 } ) \mid S _ { t } = s , A _ { t } = a ]\tag{3-6}

$$
\begin{array} { c } { { V ^ { \ast } ( s ) = \displaystyle \operatorname* { m a x } _ { \pi } V ^ { \pi } ( s ) } } \\ { { Q ^ { \ast } ( s , a ) = \displaystyle \operatorname* { m a x } _ { \pi } Q ^ { \pi } ( s , a ) } } \end{array}\tag{3-7}
$$

从上式可以看出，最优的动作价值函数就是指所有策略中的动作价值函数的最大值。

其中，价值函数和动作价值函数可以推导出如下的贝尔曼最优方程[42]

## 3.3.2 Q-learning

根据上文所述的动作价值函数的值迭代算法，要想更新整张 Q 值表，就需要对所有状态，所有动作下的 Q 值进行更新，然而在引用场景中，由于序列样本的有限，通过遍历所有状态和动作的方法更新表将很难实现。为了解决这个问题，Q-Learning 算法中采用了一种新的迭代方法[43]：

$$
Q ( S _ { t } , A _ { t } )  Q ( S _ { t } , A _ { t } ) + \alpha ( R _ { t + 1 } + \lambda \operatorname* { m a x } _ { a } Q ( S _ { t + 1 } , a ) - Q ( S _ { t } , A _ { t } ) )\tag{3-11}
$$

Q-learning 算法采用渐进的方法，通过当前的奖励和下一时刻获得的最大 Q 值表示当前时刻的近似真实的 Q 值。 代表每一次靠近的步长，通过这种差分迭代的方法可以使得 Q 值表快速收敛。

选择动作的策略有两种方法：

(1) Exploration：随机地从动作集合 选择一个动作，这增加了对位置环境探索的可能，更 Q 值的迅速更新。

(2) Exploitation：根据 Q 值的大小，选择当前环境下最优的动作，这个策略 称作贪婪策略(greedy policy)，即

$$
\pi ( S _ { t + 1 } ) = \arg \operatorname* { m a x } _ { a } { Q ( S _ { t + 1 } , a ) }\tag{3-12}
$$

而在 Q-learning 算法中，动作的选择采用了两者结合的 策略，其中 是一个较小的值，代表随机选取动作的概率，可以通过更改 的大小来改变动作选择过程中 Exploration 和 Exploitation 的比例，算法最后可以收敛到最优值。Q-learning 的具体算法形式如算法 4 所示：

## 4.2 基于策略的强化学习方法

基于Q学习的强化学习算法，是一种典型的 ValueBased 强化学习方法，它主要是对价值函数进行了近似的表示，基于价值来学习。但是这种学习方法对于连续动作的处理能力不足，Q 学习方法一般只能处理离散的动作，无法处理连续的动作，对于本文无人机的路径规划问题无人机的动作是一个连续的向量，继续用离散的动作来表示过于局限。因此本章我们考虑采用策略学习的方法解决路径规划问题。

## 4.2.1 Actor-Critic 算法

Actor-Critic是一种基于策略的强化深度学习方法，他是 DDPG 算法的基础。算法由两个神经网络组成，演员(Actor)和评价者(Critic)。其中 Actor 网络表示策略函数，网络输入是当前环境，输出为动作，用于与环境进行交互。而 Critic网络表示之前讲到了的价值函数，它的输入是当前状态和执行的动作，输出是 Q 值，负责评估 Actor 的表现[49]。

在Actor-Critic 算法中，我们需要对策略函数和价值函数做近似，策略函数的近似如下：

$$
\pi _ { \theta } ( s , a ) = P ( a \mid s , \theta ) \approx \pi ( a \mid s )\tag{4-11}
$$

对于状态价值和动作价值函数分别为：

$$
\hat { \nu } ( s , w ) \approx \nu _ { \pi } ( s )\tag{4-12}
$$

$$
\hat { q } ( s , a , w ) \approx q _ { \pi } ( s , a )\tag{4-13}
$$

对于 Actor-Critic 评估点有很多种选择，目前较为流行的 Actor-Critic 评估点主要有：

a) 第一种是基于状态价值的，Actor 的策略函数的参数更新公式为：

$$
\theta { = } \theta { + } \alpha \nabla _ { \theta } \log \pi _ { \theta } ( s _ { t } , a _ { t } ) V ( s , w )\tag{4-14}
$$

b) 第二种是基于动作价值的，如 DQN 一样，我们一般习惯采用动作价值函数 Q进行价值评估。此时 Actor 的策略函数参数更新的公式为：

$$
\theta \mathrm { = } \theta + \alpha \nabla _ { \theta } \log \pi _ { \theta } ( s _ { t } , a _ { t } ) Q ( s , a , w )\tag{4-15}
$$

基于动作价值的 Actor-Critic 算法的流程如下，Actor 也使用神经网络作为策略函数输出动作，Critic 使用神经网络来计算动作价值并且更新网络参数。表 4-1所示的 Actor-Critic 算法是一个很好的算法框架，但是由于算法中包含两个神经网络，它们都需要梯度更新，而且互相依赖，因此收敛速度较慢，离实际应用还比较远。

## 4.2.2 DDPG 算法

由于Actor-Critic网络采用两个神经网络，而他们的更新方式又是相互依赖的，会造成不容易收敛的结果。因此可以采用 DDPG 来解决这个问题。DDPG 的思想仿照DDQN，为每一个神经网络添加一个目标网络。算法中包括四个神经网络[50]：

1. Actor当前网络：负责策略网络参数 的迭代更新，负责根据当前状态 选择当前动作 ，用于和环境交互生成 S′, R。

2. Actor目标网络：负责根据经验回放池中采样的下一状态 选择最优下一动作 $A ^ { \prime }$ 。网络参数 $\theta ^ { \prime }$ 定期从 复制。

3. Critic 当前网络：负责价值网络参数 w 的迭代更新，负责计算当前 Q 值Q S A w '( , , ) 。目标 Q 值 $y _ { i } = R + \gamma Q ^ { \prime } ( S ^ { \prime } , A ^ { \prime } , w ^ { \prime } )$

4. Critic目标网络：负责计算目标 Q值中的 $Q ^ { \prime } ( S ^ { \prime } , A ^ { \prime } , w ^ { \prime } )$ 部分。网络参数 w′定期从w 复制。

此外 DDPG 从当前网络到目标网络的复制过程和 DQN 不同，DDQN 中是直接将当前Q网络的参数复制到目标 Q网络，而 DDPG每次参数只更新一部分，即：

$$
w ^ { \prime } = \tau w + ( 1 - \tau ) w ^ { \prime }\tag{4-16}
$$

$$
\theta ^ { \prime } = \tau \theta + ( 1 - \tau ) \theta ^ { \prime }\tag{4-17}
$$

其中 $\tau$ 是更新系数，一般取 0.1 或 0.01
