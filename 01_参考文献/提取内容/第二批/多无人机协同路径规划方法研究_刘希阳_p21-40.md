$$
\begin{array}{c} \begin{array} { r } { \boxed { \nu _ { x g } } } \\ { \nu _ { y g } } \\ { \nu _ { z g } } \end{array} = R \cdot \left[ \begin{array} { l } { \nu _ { x } } \\ { \nu _ { y } } \\ { \nu _ { z } } \end{array} \right]  \end{array}\tag{2-8}
$$

其中， $\nu _ { x g } , \nu _ { y g } , \nu _ { z g }$ 为机体坐标系下飞行器沿着 $O _ { g } X _ { g } , O _ { g } Y _ { g } , O _ { g } Z _ { g }$ 的速度，$\nu _ { x } , \nu _ { y } , \nu _ { z }$ 为飞行器在地面坐标系下沿着OX,OY,OZ轴的速度。

$$
\begin{array} { l } { \alpha \approx 0 , \beta \approx 0 } \\ { \sin \alpha \approx 0 , \cos \alpha \approx 1 } \\ { \sin \beta \approx 0 , \cos \beta \approx 1 } \end{array}\tag{2-9}
$$

旋转矩阵此时可以简化为:

$$
R = \left[ { \begin{array} { c } { \cos \gamma \sin \gamma 0 } \\ { - \sin \gamma \cos \gamma 0 } \\ { 0 \quad 0 \quad 1 } \end{array} } \right]\tag{2-10}
$$

$$
\left\{ \begin{array} { c } { \nu _ { x g } = \cos \gamma \cdot \Delta P _ { X } / \Delta t + \sin \gamma \cdot \Delta P _ { Y } / \Delta t } \\ { \nu _ { y g } = - \sin \gamma \cdot \Delta P _ { X } / \Delta t + \cos \gamma \cdot \Delta P _ { Y } / \Delta t } \\ { \nu _ { z g } = \Delta P _ { Z } / \Delta t } \end{array} \right.\tag{2-11}
$$

## 第3章目标分配方法研究

## 3.1引言

多无人机目标分配问题，在多无人机协作过程是首要解决的基本问题，计算结果将作为接下来的局部路径规划的先验信息，用于指定无人机群中每一架飞行器的目标任务点。本文考虑的N架飞行器在分散有N个目标的环境中，进行一对一对分配的任务场景，分配的指标为最短路径和或者最快到达时间和，从而可以让飞行器群尽快到达目标任务点，对需求位置进行覆盖。更复杂的目标分配问题将考虑飞行器能量消耗约束、飞行器载重约束、目标任务点的需求不一致，飞行器与目标点二者数量不相等，等多种约束条件。作为一类组合优化问题，目标分配难以获得精确的解析解，同时也无法采用凸优化等优化方法，但是一些进化算法对于求解诸如组合优化问题，NP-hard问题等比较有效，不需要求导和函数连续性的限定，同时分配的过程中，由于信息不完全、飞行器数量较多等情况，可能会出现无法同时考虑所有飞行器和目标的信息从而只能匹配出次优解等情况。本章将针对信息完全和不完全两种情况，在已知所有飞行器和目标点的位置时，我们采用集中式结构通过进化算法来进行迭代求解。在无法已知所有飞行器和目标点位置，同时飞行器拥有局部通信和目标点位置感知的情况下，提出一种基于KM最优匹配的混合式结构，来设计相应的目标分配算法，同时给出相应算法的仿真实验结果和性能分析。

本章主要内容安排如下：3.2节针对目标、飞行器信息完全的情况，给出基于进化算法设计的集中式目标分配算法；3.3节针对飞行器通信范围、感知范围有限的情况，给出基于KM算法设计的混合式目标分配算法；3.4进行仿真实验和分析；3.5进行本章的总结。

## 3.2 基于进化算法的集中式目标分配

本小节将采用遗传算法和改进的粒子群算法，在拥有完美信息的情况下，采用集中式架构对目标分配问题进行求解。

## 3.2.1基于遗传算法的目标分配算法设计

遗传算法是模拟达尔文进化论中自然选择过程的一种最优化算法，对种群中的个体不断地进行筛选从而得到最优解。基本思想则是充当上帝模拟整个进化过程，主要包括的步骤有：编码，种群初始化，适应度计算，选择，交叉，变异等。

编码过程相当于是对问题的备选解进行升维的过程，编码完成后的一个个体可以称之为“染色体”，而每一个染色体降维后所代表的问题备选解的指标大小就是该染色体的适应度大小，也是这个染色体的表现型，初始化具有一定大小规模的染色体群，称之为“种群”，利用自然选择原理对种群进行筛选，就能获得平均适应度更好的下一代种群，同时通过交叉、变异的过程来模拟自然界中的基因混合、基因突变等过程，最终经过一定的代数，筛选出最优解。

关于编码的方式有二进制编码法、浮点编码法、符号编码法，不同的编码方式适应不同的问题形式，这里将我们在第二章提到的分配矩阵作为我们的染色体，同时每个染色体应该满足式（3-1）中的约束条件。

$$
T \left( i \right) \in [ 1 , N ] , i \in [ 1 , N ] \wedge T ( i ) ! = T ( j ) , i ! = j\tag{3-1}
$$

一条染色体所代表的分配路径和倒数即为该条染色体的适应度，适应度越大，路径和越小。最优解对应就是我们的最优分配矩阵，即最短路径和的分配方法。种群中的一个个体就是一种分配方法，即对应一种目标分配矩阵，终止条件设定为最大迭代次数，我们算法的伪代码如下。


除算法的基本流程以外，主要包括几个函数算子如下：

1.Fitness(p)一适应度函数,该函数计算种群中每个个体的适应度大小;

2.Randomchoose(P,F)—按照每个个体的适应度大小作为参考概率抽选一个个体；

3.Max(P,F)—选择种群中适应度最大的个体；

4.Cross(p1,p2)—对种群中的两个个体p1,p2进行交叉操作；

5.Mutation(p)—对个体p进行变异操作。

对几个主要算子如下介绍：

(1)适应度函数：在目标分配问题中，我们将问题定义为寻找一个目标分配矩阵，使得所有飞行器和目标点之间的路径和最小，所以在遗传算法进行优化的时候，我们认为种群中路径和越小的适应度越大，所以我们的适应度定义为路径和的倒数。

$$

## 3.3.2网格内匹配

假设在每一个网格内，飞行器的数量为M，目标点的数量为N，在不同的网格内，可能会出现 $M > N$ ，M=N，M<N三种情况，假设为Z二者之中的较小值，即 $Z = \operatorname* { m i n } ( N , M )$ ，为了使网格内的飞行器和目标点可以尽可能多地，同时尽可能地使匹配上的所有目标点与飞行器路径和最短，我们要求网格内匹配时满足如下条件

$$
T = \arg \operatorname* { m i n } _ { T } \sum _ { i = 1 } ^ { Z } \left\| P _ { 0 } ^ { i } - P _ { g } ^ { T ( i ) } \right\|\tag{3-20}
$$

针对这种匹配问题，有一种最优匹配算法叫KM（Kuhn-Munkras）最优匹配，用于求解带权二分图的最佳匹配问题。

二分图是图论中的一种模型，如果用 $G = ( V , E )$ 来表示一个图，那么V是图G中的顶点集合，E是图G中的边集合，如果满足如下两个条件：（1）如果能将V分为两个独立的集合A,B；（2）E中所有边的顶点分别属于A和 $\pmb { B } ;$ 那么则G为一个二分图，如果每一条边带有权重，那么G为带权二分图。将M称为一组匹配，当且仅M当中的所有边没有公共顶点的条件下。而KM算法则是以匈牙利算法为基础，匈牙利算法用来寻找二分图的最大匹配，即寻找一组满足匹配条件的最多的边数。KM算法则是利用贪心算法对匈牙利算法进行扩展，通过引入顶标将最优权值问题转化为最大匹配问题，通过修改顶标不断增加图中的可行边数，直到图中存在仅仅由可行边组成的完全匹配为止。

对于应用贪心思想的算法比较困难的一点是如何找到全局最优解而不是局部最优解，KM算法思想是通过先不添加限制条件从最优解出发，假设每个都顶点可以获得最好的期望，然后通过逐步添加二分图中的关于边的顶点限制从而以最小的代价向目标约束靠近，保证每一步都是最优的，从而最终得到最优解。

对于二分图最大匹配问题来说，实际上是各边权重都为1的二分图带权最优匹配问题的一种特例，此时去求最大权重匹配相当于在求最大匹配边数。为了应用KM最大匹配，我们将飞行器和目标点的集合表示成为带权完全二分图，如图3-7所示，左集合为所有飞行器构成的集合，右集合为所有目标点构成的集合。

$$
\begin{array} { r } { A = \left\{ P _ { 0 } ^ { \mathrm { i } } \right\} , i \in [ 1 , M ] } \\ { B = \left\{ P _ { \mathrm { g } } ^ { \mathrm { i } } \right\} , j \in [ 1 , N ] } \end{array}\tag{3-21}
$$

并且定义左集合A中的顶点和右集合B中的顶点连接权重为：

$$
\boldsymbol { W _ { i } ^ { j } } = \frac { 1 } { \left\| P _ { 0 } ^ { i } - P _ { g } ^ { j } \right\| }\tag{3-22}
$$

表示相距距离越近的目标点-飞行器点对，越应该被匹配得到。
