$$
V ^ { ' } ( s ) = \operatorname* { m a x } _ { a \in A ( s ) } ( \sum _ { s ^ { \prime } } P ( s ; a ; s ^ { \prime } ) ( R ( s ; a ; s ^ { \prime } ) + \gamma V ^ { ' } ( s ^ { \prime } ) ) ) \ \quad \forall s \in S\tag{2-7}
$$

上式为贝尔曼最优方程，它不依赖具体的策略，可以通过迭代的方式求解，得到最优策略 $\pi ^ { * } ( s )$ ：

$$
\pi ^ { * } ( s ) = \arg \operatorname* { m a x } _ { a \in A ( s ) } ( \sum _ { s ^ { \prime } } P ( s ; a ; s ^ { \prime } ) ( R ( s ; a ; s ^ { \prime } ) + \gamma V ^ { * } ( s ^ { \prime } ) ) ) \quad \forall s \in S\tag{2-8}
$$

另外，在强化学习研究中，可以给状态动作对赋值，习惯上称为 Q 值，这些值的集合称为 Q 值函数。对照状态值函数 $\boldsymbol { V } ^ { * } ( s )$ 的定义，也可以定义最优 Q 值函数以及贝尔曼最优方程：

$$
\boldsymbol { Q } ^ { * } ( s , a ) = \operatorname* { m a x } _ { \pi } ( \boldsymbol { Q } ^ { \pi } ( s , A ) ) \quad \ \forall s \in S , a \in A ( s )\tag{2-9}
$$

$$
Q ^ { ' } ( s , a ) = \sum _ { s ^ { \prime } } P ( s ; a ; s ^ { \prime } ) ( R ( s ; a ; s ^ { \prime } ) + \gamma \operatorname* { m a x } _ { a ^ { \prime } \in A ( s ^ { \prime } ) } Q ^ { ' } ( s ^ { \prime } , a ^ { \prime } ) ) \forall s \in S , a \in A ( s )\tag{2-10}
$$

策略的最优解 $\pi ^ { * } ( s )$ 为：

$$
\pi ^ { * } ( s ) = \arg \operatorname* { m a x } _ { \mathbf { a } \in \mathrm { A } ( s ) } \mathcal { Q } ^ { * } ( s , a )\tag{2-11}
$$

事实上，如果已知系统的状态转移函数以及它的奖励函数，该问题就是经典的动态规划问题，但强化学习的前提是不知道这个系统的模型，因而学习的任务就是从任意初始的值函数开始，通过不断的试错学习，更新值函数，经过足够数量的迭代后，求得最优策略 $\pi ^ { * } ( s )$ 0

## 2.1.2 强化学习的基本原理及模型

强化学习的思想源于 Thorndike 响应定律：在某一特定的环境下，动物可能对环境发生多个响应，当某个响应使动物得到满足后，这个响应与环境的联系就会增强，当这种环境再次出现后，动物做出这种响应的概率也会加大。反之，如果某个响应不能得到动物的满意，则这个响应与环境的联系就会减弱，当动物再次遇到这种情况时，仍然发生这个响应的概率也会降低。同 Thorndike响应定律类似，强化学习也是通过系统中的智能体与环境交互，在一次动作选择后，获得一个惩罚或者奖赏值，这个值将影响今后智能体再次碰到这个状态时所采用的动作。

Watkins 给强化学习下了一个这样的定义，当智能体能够感知环境，并且可以为适应环境而主动对环境进行试探，具备以下特征时，则可称为强化学习：

（1）智能体能够主动探索环境，而不是依靠等待其他因素改变智能体的行为；

（2）环境可以对智能体探索动作给予反馈（评价）；

（3）智能体在环境中执行动作并获得奖励（惩罚）的过程中，获得知识，不断调整策略，以达到学习的目的。

从 Watkins 对强化学习的定义可以看出，他把强化学习当作一个不断试错的过程，其基本原理的示意图可用图 2-1 表示。在图 2-1 中所展示的强化学习模型中，智能体先是感知环境，获得智能体所处的状态 s，然后智能体依据策略函数，从动作库中选择动作，最后智能体所处的状态在动作执行后发生改变，与此同时产生一个奖励值 r 传递给智能体，并通过这个奖励值，调整策略。这样，智能体通过与环境持续不断的交互，通过反馈调整下一次的策略选择，最终达到目标。

（2）强化学习系统中，当增加数据时，并不需要调整全部的数据，只需要调整新数据带来的影响，是一种增量学习方法，能够在线使用；

## 2.1.3 强化学习的组成要素

由 2.1.2 节得到的强化学习模型可知，一个完备的强化学习系统，除了智能体和环境之外，还应包括四个组成元素，分别是：策略函数、状态（状态动作对）值函数、报酬（奖励）函数和环境模型（非必须）。环境模型定义了强化学习系统所处的环境，该系统中的智能体通过不停试错的方式来选择策略，在足够数量的探索、试错后，能够得到状态转移概率函数和回报函数，此外，强化学习系统还需要构造一个状态的效用函数也就是值函数，用来策略选择。

## （1）策略决策函数

策略决策函数决定了智能体在给定时刻与环境的交互过程中应该选择或者采取的动作，是一个强化学习系统的关键。这是因为策略函数直接决定了智能体每一步的行为，也决定了强化学习系统的性能，策略函数优劣是一个强化学习系统是否高效的关键。假定 S 为系统的状态空间，A 为可选的动作空间，强化学习的策略表示一种映射关系， 是处于环境中的智能体从它的所有可能的状态空间到它所能采取的动作集合的映射。在这个集合中，获得最大的奖励值，是强化学习的目标，相对应的策略为最优策略 $\pi ^ { * }$ 。强化学习的策略函数来源于心理学中的刺激-反射规则，它反映了动作和环境的一种联系。策略可以是一个简单的函数或者查找表（lookup table）；而另一些情况下，如在搜索过程中，策略具有比较大的随机性，计算量较大。

## （2）回报函数

回报函数是指智能体在与环境的交互过程中，由感知的环境状态（或状态动作对）到强化信号 r 的映射，是对动作执行后的评价，用来指导今后的动作选择。奖励信息一般用一个标量来表示，如果得到正数表示得到环境的正回报，即奖励；得到负数表示得到环境的负回报，即惩罚。在强化学习的整个过程中，得到的正数多表示智能体在该模型中的策略得当，奖励多；反之，负数多表示智能体在该模型中的策略不佳，惩罚多，完成这些动作起到了与目标相悖的效果。由于回报函数一般比较确定、客观，可以作为策略选择的标准。

## （3）值函数

回报函数是对一个状态（也可以是一个状态动作对）的实时表达，表明执行当前动作的“好坏”，是一种“近视”的表达信号；而值函数更多的是考虑动作执行的后续效果。它将每次动作回报的值进行累积，用得到的总回报，作为一系列决策的优劣，目的是寻找全局最优，而不是局部最优，把研究的重心放在了目标的长远性和系统的不确定性上。

强化学习中的智能体在状态 $s _ { t }$ 的值函数 $V ( s _ { t } )$ 是指在该状态下执行动作 $a _ { { _ t } }$ 后，在达到目标状态的过程中，得到累积奖励的期望。按照 2.1.1 节讲述的无限折扣总回报模型，可以将 $V ( s _ { t } )$ 定义如下：

$$
V ( s _ { t } ) = E [ \sum _ { t = 0 } ^ { \infty } \gamma ^ { t } r _ { t + 1 } \mid s _ { 0 } = s ]\tag{2-12}
$$

其中 $\gamma \in [ 0 , 1 ]$ 为折扣因子（衰减系数）， $s _ { t }$ 和 $r _ { t + 1 }$ 分别表示在 t 时刻的状态和由

$s _ { t }$ 转移到 $s _ { t + 1 }$ 后得到的即时回报。

从公式（2-12）可以看出，值函数是对这一次动作执行效果的长远预测，是从这一时刻改变状态起，智能体得到的累积奖赏的总和，而回报函数是对环境状态改变的立即评价。值函数是随后一系列动作选择效果的累积，因此当前动作回报高，并不意味着状态值高，而是需要观察这一动作执行之后的效果。值函数是在强化学习系统的整个周期内通过观察给出的，因而在动作选择时，一般要选择能得到最大值函数的动作，而不是那些能带来当前最大回报的动作。因为很有可能某一状态下执行的动作回报值低，但从长远来看，这次动作的执行，对整个强化学习过程有益。由此可见，确定值函数是大部分强化学习算法的核心，也是强化学习的难点。

## （4）环境模型

环境模型是指强化学习模型能够对外部环境进行模拟，智能体在决策时，考虑将来可能发生的状态，结合今后和现在，做出最终决策。例如智能体执行一个动作后，环境模型可以帮助预测到智能体的下一状态和立即回报。将模型加入到强化学习模型中去，也是强化学习发展的一个新方向。通过环境模型，让智能体在策略选择时，考虑未来状态和回报，形成了一些比较实用的方法。强化学习的四个基本元素的关系可用图 2-4 表示：

针对不同的问题，学者们提出了很多不同类型的强化学习算法，常用的算法有瞬时差分算法、AHC 算法、Q 学习算法、Sarsa 算法等，下面对这些算法做简单的介绍：

## 2.2.1 强化学习算法的目的

通过学习，寻找一个策略 ，能够使每一个状态 s 所对应的状态值函数 $V ^ { \pi } ( \mathrm { s } )$ 或状态动作对所对应的 $Q ^ { \pi } ( s , a )$ 值函数达到最大，是强化学习的目标[31]。即设法求

得一个策略 $\pi { \mathrel { : } } S \to A$ ，能够使每个状态执行后得到的奖励值最大：

$$
V ^ { \pi } ( s ) = E { \left\{ } r _ { 1 } + \gamma r _ { 2 } + \cdots + \gamma ^ { i - 1 } r _ { i } + \cdots { \right\} } s _ { 0 } = s { \Biggr \} }\tag{2-13}
$$

$$
Q ^ { \pi } ( \mathbf { s } , \mathbf { a } ) = E \Big \{ r _ { 1 } + \gamma r _ { 2 } + \cdots + \gamma ^ { i - 1 } r _ { i } + \cdots \big | s _ { 0 } = s , a _ { 0 } = a \Big \}\tag{2-14}
$$

$$
V ^ { \pi } ( s ) = \mathrm { m a x } ( V ^ { \pi } ( s ) )\tag{2-15}
$$

$$
Q ^ { \pi } ( s , a ) = \operatorname* { m a x } ( Q ^ { \pi } ( s , a ) )\tag{2-16}
$$

其中， $r _ { i }$ 表示在智能体执行动作后的即时奖赏， $\gamma ( \gamma \in [ 0 , 1 ] )$ 为衰减系数。

$V ^ { ^ { * } } ( s )$ 和 $\boldsymbol { Q } ^ { * } ( s , a )$ 分别称为状态值函数（V 值函数）和状态动作值函数（Q 值函数），相应的最优策略为：

$$
\pi ^ { * } = \arg \operatorname* { m a x } V ^ { * } ( s )\tag{2-17}
$$

$$
\pi ^ { * } = \arg \operatorname* { m a x } Q ^ { * } ( s , a )\tag{2-18}
$$

在强化学习中，如果通过策略得到了值函数 $V ^ { ' } ( { \mathrm { s } } )$ 或 $\boldsymbol { Q } ^ { * } ( s , a )$ ，通常不直接用最优值选择动作，这样选择的话容易陷入局部最优，导致算法不收敛。贝叶斯估计、间接选择法以及近似效用模型都可以用作值函数的选择。

## 2.2.2 瞬时差分算法

瞬时差分算法，简称 TD 算法，是解决时间信度分配这一类问题的经典方法。1988 年，Sutton[33]在 Samuel、klopf 等人研究的基础上，结合动态规划算法（DP 算法）和蒙特卡洛算法（MC 算法），给出了 TD 算法的步骤。与 MC算法相似，TD 算法不需要外部信息导入，是一种和模型无关的方法。TD 算法的值函数的更新方式是通过相邻状态的误差来估算的，也就是利用连续两次值函数估计值的差值来更新值函数，不需要指导信号，这一点同动态规划的算法思想是一致的，而非不是 MC 算法那样需要在一个学习阶段结束后才更新最终回报。TD 算法能够有效利用知识进行学习，预测未来行为，收敛速度块，且不需要环境模型。TD 算法的步骤一般包括策略评估、策略改良、策略迭代三个部分。

在 TD 算法提出之前，一般用预测的奖励值和实际得到的奖励值之间的误差更新这一状态的策略值，TD 算法则直接采用相邻两个状态的预测值修改这一状态的策略值。根据策略函数更新方式的不同，能够衍生出不同种类的 TD 学习算法，在这其中最简单的，也是最容易计算的形式是 TD(0)算法，其迭代公式为：

$$
V ( s _ { t } ) \gets V ( s _ { t } ) + \alpha [ r _ { t + 1 } + \gamma V ( s _ { t + 1 } ) - V ( s _ { t } ) ]\tag{2-19}
$$

式中，参数 为学习速率， $\gamma$ 为折扣率。

从更新公式（2-19）可知，当前值函数 $V ( s _ { t } )$ 以 $r _ { t + 1 } + \gamma V ( s _ { t + 1 } )$ 为逼近目标，不需要等待一幕结束后才更新值函数，在当前状态的下一时刻，就可以利用下一状态的立即奖励 $r _ { t + 1 }$ 以及后继状态值 $V ( s _ { t + 1 } )$ 之和作为当前值函数 $V ( s _ { t } )$ 的估计。即每一状态的值函数利用相邻状态的值函数进行调整，TD(0)算法回溯图如图 2-6(a)所示。

TD(0)算法仅仅利用下一状态的值函数和奖励值更新当前状态值，即一步更新，也可以将算法扩展到多步，即利用该状态以后 n 步累积折扣与第 n 步的状态值函数之和更新当前状态值，这样算法的奖励值以及状态值函数的更新式为：

$$
R _ { t } ^ { ( n ) } = r _ { t + 1 } + \gamma r _ { t + 2 } + \gamma ^ { 2 } r _ { t + 3 } + \cdots + \gamma ^ { n } V _ { t } ( s _ { t + n } )\tag{2-20}
$$

$$
V ( s _ { t } ) \gets V ( s _ { t } ) + \alpha [ R _ { t } ^ { ( n ) } - V ( s _ { t } ) ]\tag{2-21}
$$

上式中， $R _ { t } ^ { ( n ) }$ 表示在某一时刻 t 上的 n 步奖励值（回报），实际上，当 n 增大至目标状态后，n步 TD算法就是MC 算法。

n步TD算法可以做进一步改进，将不同步上的所有回报值之和作为当前状态估计值的逼近，然后再进行学习，即：

$$
\begin{array} { l } { { R _ { t } ^ { ( \lambda ) } = ( 1 - \lambda ) R _ { t } ^ { ( 1 ) } + ( 1 - \lambda ) \lambda R _ { t } ^ { ( 2 ) } + ( 1 - \lambda ) \lambda ^ { 2 } R _ { t } ^ { ( 3 ) } + \cdots } } \\ { { \displaystyle \ = ( 1 - \lambda ) \sum _ { n = 1 } ^ { n = \infty } \lambda ^ { n - 1 } R _ { t } ^ { ( n ) } } } \end{array}\tag{2-22}
$$

其中权值系数 $( 1 - \lambda ) \sum _ { n = 1 } ^ { n = \infty } \lambda ^ { n - 1 } = 1$ ，如果序列是有限的，当 $n { = } T { - } t$ 时，状态转移至目标状态，此时所有 $n ( n \geq T - t )$ 步回报值均与 $R _ { t }$ 相同，上式变为：

$$
R _ { t } ^ { ( \lambda ) } = ( 1 - \lambda ) \sum _ { n = 1 } ^ { T - t - 1 } \lambda ^ { n - 1 } R _ { t } ^ { ( n ) } + \lambda ^ { T - t - 1 } R _ { t }\tag{2-23}
$$

$$
V ( s _ { t } ) \gets V ( s _ { t } ) + \alpha [ R _ { t } ^ { ( \lambda ) } - V ( s _ { t } ) ]\tag{2-24}
$$

现且不实用，只具有理论上的可能。

## 2.2.3 Q 学习算法

Watkins 在 1992 年提出的 Q 强化学习算法是强化学习中最实用的一种方法，它不需要建立环境模型，有些人把这种算法当作 TD 算法的一种，是一种离线的TD算法。该算法更新 Q值需要假设的一些动作，而不是根据策略的映射关系选择的动作。与TD算法最大的不同是，Q学习算法是对状态动作对的值 $Q ( s , a )$ 进行迭代，TD算法采用的是策略值函数 $V ( s )$ 迭代，两种算法估计的目标函数不同。

在 Q 学习中，当选择动作 $a _ { \mathrm { t } }$ ，则 $Q ( s _ { t } , a _ { t } )$ 的计算公式为：

$$
Q ( s _ { t } , a _ { t } ) = r _ { t } + \gamma \sum _ { s _ { t + 1 } } P _ { s _ { t } s _ { t + 1 } } ^ { a } \operatorname* { m a x } _ { a _ { t } } Q ( s _ { t + 1 } , a _ { t } \mid a _ { t } \in A ]\tag{2-25}
$$

从上式可以看出，它的值函数更新依赖于这以后的值函数的累积值：

$Q ( s _ { t } , a _ { t } )$ 的更新公式为：

$$
Q ( s _ { t } , a _ { t } )  Q ( s _ { t } , a _ { t } ) + \alpha [ r _ { t + 1 } + \gamma \operatorname* { m a x } _ { a \in A ( s ) } Q ( s _ { t + 1 } , a ) - Q ( { s _ { t } , a _ { t } } ) ]\tag{2-26}
$$

上式中， 称为学习率， 为折扣率。 $Q ( \mathrm { s } _ { \mathrm { t } } , a _ { \mathrm { t } } )$ 指的是按一定策略执行动作后的报酬值。每一个状态动作对都可以用一个查询表（Lookup Table）来表示值函数，其大小为状态集合 S 和动作集合A的Cartesian Product（笛卡尔乘积）的个数。

Watkins 证明了 Q 学习的收敛性，当满足下列条件时，值函数 $Q ( s , a )$ 经过迭代会收敛于最优值 $\boldsymbol { Q } ^ { * } ( \mathbf { s } , \boldsymbol { a } )$

（1）强化学习所处的环境需要满足 MDP 过程；

（2）Q值用查找表的方式来存储表示；

（3）选择恰当的学习率 ；

（4）每个状态动作对的值可以重复使用。

## 2.2.4 Sarsa 算法

Sarsa 算法[34]可以看作是 Q 学习算法一种特殊的在线策略形式。Sarsa 算法采用实际的 Q 值迭代，而不是 Q 学习算法中采用假设的值函数迭代，并且 Sarsa 算法的每个学习步长，都按照TD算法的学习形式进行迭代，选择动作和更新值函数是同时进行的，根据执行一个动作获得的奖励值来更新值函数。系统中的智能体都根据当前Q值确定下一状态时的动作，Q值更新方式为：

$$
Q ( s _ { t } , a _ { t } ) \gets Q ( s _ { t } , a _ { t } ) + \alpha [ r _ { t + 1 } + \gamma Q ( s _ { t + 1 } , a _ { t + 1 } ) - Q ( s _ { t } , a _ { t } ) ]\tag{2-27}
$$

Sarsa 学习算法在解决一些控制问题上，相比 Q 学习算法，性能更好。

## 2.2.5 自适应启发评价算法

自适应启发评价算法[35]，简称 AHC 算法，也是一种经典的强化学习算法，它由评价器（Critic）和行动器（Actor）两部分组成，行动器用于策略选择（动作选择），评价器利用环境的反馈信号来对值函数进行估计，即评价行动器选择的动作。AHC 方法中，行动器 Actor 用作指导智能体在某一环境状态 s 下，执行动作 a，并用执行动作后的效果来指导策略函数的迭代；评价器 Critic是行动器中策略函数的评估单元，根据已知的经验样本 $< s , a , r , s ^ { \prime } >$ 生成误差信号，一方面将误差信号反馈给行动器，更新策略函数，另一方面更新评价器对应的 Q 值函数。该系统示意图可用图 2-7 表示。

从AHC 算法框架可以看出，该算法与其他的策略函数迭代方法不同，它的策略评估过程和策略更新过程是同时进行的，评价器中以 Q 值函数的形式存储了先验知识，能够提供误差信号，进行策略迭代，因而学习效率更高。

假设系统的状态集合为 $S = \{ s _ { 1 } , s _ { 2 } , \cdots s _ { n } \}$ ，智能体在每一个状态下可以选择的动作集合为 $A = \{ a _ { 1 } , a _ { 2 } , \cdots a _ { m } \}$ ，行动器策略函数的特征参数向量为 $Y = \{ y _ { 1 } , y _ { 2 } , \cdots y _ { \mathrm { n } } \}$ ，在状态 s 和特征参数 y 时，执行动作 a 的概率为 $\pi ( s , a , y )$ ，评价器中 Q 值函数的特征参数矩阵为 $Q = \left\{ q _ { i j } \right\} _ { n \times m }$ ，状态动作对在特征矩阵Q下的 Q 值估计为 $q ( s , a , Q )$ 评价器根据先验知识得到一个经验样本 $< s _ { i } ^ { t } , a _ { j } ^ { t } , r _ { t + 1 } , s _ { k } ^ { t + 1 } >$ ，其中 i j k , , 表示相应状态集和动作集的索引。评价器可以根据经验样本给出误差信号：

$$
E r r o r = \boldsymbol { r } _ { t + 1 } + \gamma \cdot \operatorname* { m a x } _ { a \in A } q ( s _ { k } ^ { t + 1 } , a , Q ) - q ( s _ { i } ^ { t } , a _ { j } ^ { t } , Q )\tag{2-28}
$$

其中 $\gamma$ 表示强化学习的折扣因子。

求得误差信号以后，行动器可以用公式（2.29）更新策略函数的特征参数：

$$
y _ { i } ( t + 1 ) = y _ { i } ( t ) + \alpha \cdot E r r o r \cdot \frac { \hat { \sigma } \ln ( \pi ( s _ { t } , a _ { t } , Y ) ) } { \hat { \sigma } w _ { i } }\tag{2-29}
$$

上式中， $\alpha$ 是行动器的学习步长。

按照公式（2.30），评价器更新Q值函数的特征参数：

$$
q _ { i j } ( t + 1 ) = q _ { i j } ( t ) + \beta \cdot E r r o r\tag{2-30}
$$

上式中， $\beta$ 是评价器的学习步长。

## 2.2.6 分层强化学习

分层强化学习（HRL）充分吸收了分治的思想，分解强化学习中的任务，因而在子任务中，强化学习所需要考虑的状态空间数大幅减少，从而达到降维的目的，加快收敛速度。同时，分层强化学习通过引入状态抽象，使得每个子任务可以忽略无关的细节，只在和当前任务相关的空间内学习，进一步缩小了状态空间，同样也加快了学习速度。经过多年的研究和发展，学者们提出了Option、HAM、MAXQ、OMQ 等分层强化学习方法[36]，他们均以半马尔科夫决策过程为基础[41]。

## 2.2.6.1 半马尔科夫决策过程

半马尔科夫决策过程，以下简称 SMDP，由一个六元组 $< S , A , R , P , \lambda , T >$ 定义，它假设系统在状态 s 时执行动作 a 的等待时间为 步后，系统在 s点时执行动作 a 转移到s'后的状态转移概率为 $P ( s ^ { \prime } , \tau | s , a )$ ，相对应的奖励函数为$R ( s , a ) = E \{ r _ { t } + \gamma r _ { t + 1 } + \cdots + \gamma ^ { \tau } r _ { t + \tau } \}$

参照MDP 过程，可以给出 SMDP 的值函数贝尔曼最优公式：

$$
V ^ { ' } ( s ) = \operatorname* { m a x } _ { a \in A } [ R ( s , a ) + \sum _ { s ^ { \prime } , \tau } \gamma ^ { \tau } P ( s ^ { \prime } , \tau \mid s , a ) V ^ { ' } ( s ^ { \prime } ) ]\tag{2-31}
$$

状态动作对值函数最优公式为：

$$
\mathcal { Q } ^ { * } ( s , a ) = R ( s , a ) + \sum _ { s ^ { \prime } , \tau } \gamma ^ { \tau } P ( s ^ { \prime } , \tau \mid s , a ) \operatorname* { m a x } _ { a \in A } \mathcal { Q } ^ { * } ( s ^ { \prime } , a ^ { \prime } ) ]\tag{2-32}
$$

Q 学习迭代公式为：

$$
\boldsymbol { Q } _ { k + 1 } ( s , a ) = ( 1 - \alpha ) \boldsymbol { Q } _ { k } ( s , a ) + \alpha [ r _ { t } + \gamma r _ { t + 1 } + \cdots + \gamma ^ { \tau - 1 } r _ { t + \tau - 1 } + \operatorname* { m a x } _ { a ^ { \iota } \in A } \boldsymbol { Q } _ { k } ( s ^ { \prime } , a ^ { \tau } ) ]\tag{2-33}
$$

## 2.2.6.2 分层强化学习主要算法

分层强化学习需要在每层结束后做出决策，并不需要每走一步做出决策，分层强化学习的典型算法有以下几个：

## （1）Option

Option 方法通过动作分层，将强化学习问题分为若干个子问题。该方法可以理解为扩大了强化学习系统的动作空间，它将一个学习过程分成几个 Option，每个 Option 可以当作一种特殊的动作，一个 Option 是动作序列的集合，Option的引入，扩展了强化学习的动作库。Option 作为基本动作的集合，在它的内部也可以使用传统的强化学习算法来更新策略。这样，通过抽象一个 Option，可以提高算法的效率。

## （2）HAM

HAM 方法通过对策略分层，利用先验知识设计一个有限状态机集合，含有4 个内部状态。HAM 的学习过程一方面对各个状态内部进行学习，另一个方面是通过策略实现各个状态之间的转换，通过状态抽象，加快了学习速度。

## （3）MAXQ

MAXQ 通过任务分层，将一个强化学习任务分成一些子任务，这些子任务组成一个任务图，这样就把强化学习整个过程分解为完成这些子任务的学习，减少了状态空间。

## 2.3 强化学习的应用领域

强化学习可以在未知环境中不通过引导信号进行学习，随着研究的进展，在解决实际工程应用问题中也得到了比较充分的应用和实践。近些年来，强化学习在机器人控制、市场决策、工业自动化等领域得到了应用，成为解决序贯决策问题的有效方法。本节我们对强化学习在优化控制、调度管理、求解人工智能复杂问题等领域上的应用做简单介绍。

## 2.3.1 优化控制中应用

在模型未知的非线性系统控制问题中，强化学习与控制理论相结合，充分利用其自适应能力强的特点，结合神经网络，设计非线性系统控制器。Liu D 等人将强化学习与神经网络拟合，设计了自适应学习的汽车发动机燃控比控制，通过测试数据表明，该模型可以提高发动机的性能，减少能耗。Park 等人采用

ADP 的思想设计了同步发电机神经网络控制器，以及基于多机电力系统静态补偿器的神经模糊控制器。Lin 等人基于 ACDS 设计了地铁自动列车的自适应优化控制器，该算法不需要交通模型，可直接从交通数据中进行自学习。Zhao 等人采用 DHP 方法实现了高速公路系统闸道的协调管理。王雪松等人提出的基于协同最小二乘支持向量机学习算法，充分利用了支持向量机的泛化能力，并在小车爬山控制问题上验证了算法的效率。

## 2.3.2 机器人领域的应用

由于机器人需要在未知环境中，对环境变化做出正确的选择，这就要求机器人在复杂环境中需要具有很好的适应性。机器人为增强在不确定环境中适应性，需要具备一定的学习能力，与环境有效交互，以适应环境，做出合理的动作选择。利用强化学习来引导机器人的学习也成为机器人研究的重点之一。很多大学的机器人研究实验室都将强化学习作为机器人学习控制的关键技术。Hara 等人利用 Q 强化学习，研究了机器人在二维平面内的最佳运动方式，通过合理设定机器人与环境的交互方式，实现了机器人在复杂环境中的自主运动。Ueno等人将Actor-Critic强化学习方法应用到机器人在位置环境的行走问题中，并提出了一种自适应学习速率更新的方法，实验表明利用该算法可以使双足机器人在不确定环境中自主行走。Abbeel 等人[37]研究了无人机直升机的飞行控制问题，它首先利用飞行员帮助找到无人机的运动学模型及奖励函数的参数，然后用强化学习模型设计控制器，能够让无人直升机自主飞行。王学宁等人[38]研究了策略梯度方法在强化学习中的应用，克服了强化学习不能保证收敛、难以引入先验知识的缺陷，并在月球车的控制协调问题上得到了应用。

## 2.3.3 调度控制领域的应用

强化学习结合动态规划，通过不断的尝试，把学习效果作为评价函数，应用在组合优化问题的研究上。Crites 等人以电梯群控系统为测试平台，研究了多 Agent 的强化学习，利用广义策略迭代，求得全部 Agent 的奖励信号，并影响单个 Agent 的行为，通过实验表明，该算法性能高，收敛速度快，控制效果好。Zhang 等人研究了航天飞机发射中的 job-shop 问题，采用神经网络和 TD算法相结合解决调度控制，实验效果优于原来的迭代修正算法。李耀宇等人[39]利用强化学习，研究了舰载机在航母甲板上的调度方法，并且通过仿真实验表明，这种方法的结果能够满足调度要求，可以借助计算机实现甲板作业的指挥调度。

夏新海[40]将强化学习用到了交通岗的红黄绿灯的控制问题中，并在状态空间的设计上做了改进，减少了复杂度，且通过实验验证了算法的有效性。刘长春将平均报酬的思想用到了强化学习算法中，并在生产调度系统中得到了运用，优化了调度策略。沈晶利用分层强化学习的 OMQ 方法分析了多智能体出租车问题。Tham 利用分布式强化学习方法用到了无线传感器网络中的多智能体系统中，通过智能体的不断尝试，调整网络节点的合作方式，以达到无线传感器网络的融合。

## 2.3.4 人工智能问题求解中的应用

人工智能研究的一个重要领域是复杂问题求解与建模，早期的问题求解方法如启发式搜索、产生式系统等，都很难在问题空间很大的情况下获取和表示知识，比较典型的如 IBM 公司设计的“深蓝”系统，尽管性能很强，但仍需要手工调整参数和知识数据库，智能化程度仍需提高。而强化学习可以在环境中自主学习，为处理这类问题提供了一种新的方法，在一些问题的解决上取得了不错的效果。如 samuel 开发的一款跳棋游戏，就用到了强化学习。Thrun 将强化学习用到了国际象棋游戏中，Sutton 也将强化学习应用到围棋程序设计中，Tesauro 采用 BP 神经网络逼近，设计了 Back-Gammon 下棋程序。除此之外，强化学习在角色扮演游戏中也有广泛的应用，如俄罗斯方块、超级玛丽、星际争霸等[32]。

## 2.4 本章小结

本章重点介绍了强化学习的相关知识，首先以马尔科夫模型为切入点，介绍了强化学习的基本模型、基本原理和主要组成要素；其次介绍 TD 算法、Q学习算法等经典的强化学习算法，并给出了算法的步骤；最后，对强化学习在优化控制、机器人、调度控制等领域的应用做了简单的介绍。

## 3.1.1 基本思想

在马尔科夫决策过程中，智能体在某一状态的动作选择由策略和值函数决定，标准的强化学习算法，一般对智能体掌握的先验知识使用的较少。但在实际的决策过程中，与人类的决策过程相似，如果智能体具备感知环境的能力，它每执行一个动作，都应该是在一种潜意识的驱动下完成的，而这种潜意识的形成是智能体对环境作出判断，并结合自身的特点后形成的[42]。鉴于此，为了让强化学习更能体现人类或动物更为真实的动作选择过程，本文尝试改变标准强化学习系统的结构，将马尔科夫过程用一个七元组表示，即 $\left. \mathrm { S } ; \mathrm { M } ; \mathrm { A } ; \mathrm { P } ; \mathrm { R } ; \gamma ; \mathrm { V } \right.$ ，相对于 2.1.1 节中所述的马尔科夫模型，增加了一个要素 M，用来表示马尔科夫过程的动机空间。这样，强化学习的映射关系由原来的状态到动作的映射，转变为状态到动机、动机再到动作的两层映射。这样，我们可以通过在动机层引入经验知识或者智能体的意图，用来引导智能体的动作选择。图 3-1(a)展示了标准强化学习系统的结构图，图 3-1(b)展示了动机引导强化学习系统的结构图。

## 3.2 基于模拟退火的动机引导强化学习

## 3.2.1 基本思想.

在强化学习中，智能体需要与环境交互，选择合适的动作，但如果智能体在任务开始阶段就只利用当前值函数的最大值进行迭代，则有可能会在学习过程中陷入局部最优，甚至不可能找到最优解。本节将模拟退火理论和强化学习方法相结合，在动作选择上采用模拟退火策略，以保证算法具备对新环境的进行探索的能力[43]。模拟退火算法（SA）的思想来源于物体的降温过程，设一个物体在状态 $S _ { 0 }$ 时对应的值为 $E _ { s _ { 0 } }$ ，随后随机产生一个状态 $s ^ { \prime }$ 对应 $E _ { s } ,$ ，通过比较 $E _ { s ^ { \prime } }$ 和 $E _ { s _ { 0 } }$ ，如果 $E _ { s ^ { \prime } } < E _ { s _ { 0 } }$ ，则令随机产生的状态 $s ^ { \prime }$ 为当前状态；如果 $E _ { s ^ { \prime } } > E _ { s _ { 0 } }$ ，产生一个随机数 $\delta$ ，通过比较 $\delta$ $E _ { s } ,$ 、 $E _ { s _ { 0 } }$ 的关系，如果 $\delta < \exp [ \frac { E _ { s } , - E _ { s _ { 0 } } } { T } ]$ ，则接受随机状态。

Metropolis 准则是在重要性采样法的基础上发展而来的，本文将模拟退火（SA）中的 Metropolis 准则吸收到强化学习算法中来。即在 Q 学习过程中，设定一个初始温度 T，然后选择一个随机数 $\delta \in [ 0 , 1 ]$ ，首先根据贪心策略选择动作$a _ { 1 }$ ，然后随机产生一个动作 $a _ { 2 }$ ，利用公式（3-4）比较 $Q ( s , a _ { 1 } )$ 1 $Q ( s , a _ { 2 } )$ 和随机数 $\delta$ 的关系，如果

$$
\delta < \exp [ \frac { Q ( s , a _ { 2 } ) - Q ( s , a _ { 1 } ) } { T } ]\tag{3-4}
$$

则选择随机动作 $a _ { 2 }$ ，否则，仍执行根据策略选择的动作 $a _ { 1 }$ 。

强化学习的探索策略采用模拟退火算法后，其在探索过程中，除了选择优化动作外，还能根据退火温度，以一定的概率尝试其他动作。在强化学习的开始阶段，由于智能体不能掌握外部环境，一般设置一个比较高的控制参数，能够接受非最优解，在多次迭代后，逐步减少控制参数的值，即减少随机过程出现的概率，最终达到全局最优。可见，模拟退火算法能够有效防止智能体在试错过程中，一味追求当前的最优值而陷入局部最优。基于模拟退火的强化学习算法中，选择合适的退火策略和初始温度对模拟退火算法的效率有很大影响，常用的退火策略有对数下降法、等比降温法、快速下降法等。

## 3.2.2 算法描述

将 Metropolis 准则引入到 3.1.2 节所用的动机引导强化学习的动机选择中，不单单依据当前状态动机对的值函数选择动机，而是通过设定一定的退火温度，在运行的开始阶段增加对环境探索的机会。在降温策略中，本文采用等比降温方法，其迭代方式为： $t _ { k + 1 } = \lambda \cdot t _ { k } \cdot k ( \lambda \in ( 0 . 5 , 1 ) )$ ，其中 可以调节降温的速度。为描述方便，我们将基于模拟退火的动机引导强化学习算法称为 M-SA-Q 学习算法。
