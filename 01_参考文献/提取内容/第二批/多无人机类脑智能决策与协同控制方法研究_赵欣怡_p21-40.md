迪亚大学的张友民[45]针对存在执行器故障与模型不确定的无人机系统，提出一种分布式容错协同控制律，他们同样将执行器故障作为综合扰动项并采用模糊神经网络方法对其进行估计，补偿进容错控制器中，实现多无人机的姿态同步跟踪控制。2019 年，新加坡国立大学的谢立华[46]进一步针对 GPS 拒止环境下 leader-follower 结构的编队控制问题，提出一种合作式估计-控制方法，仅利用使用测距和里程传感器，同时实现了相对定位及 follower 对leader的跟踪控制。但上述方法并没有考虑机间碰撞对无人机飞行性能的影响。从上面论述可以看出，对于多无人机系统来说，同时考虑模型不确定、外界干扰等综合扰动、机间避碰约束以及执行器故障的影响，实现多无人机系统安全稳定编队控制仍是一个开放性问题。而且，上述研究成果均侧重于满足系统的稳态性能，而对系统的动态性能（包括超调量和收敛时间）则关注较少。

为进一步提高飞行控制品质，改善系统的动态控制性能，预设性能控制以其可以定量刻画被控系统动态与稳态性能的优势吸引了许多研究学者的关注。预设性能控制[47]是希腊 C.P.Bechlioulis 等学者于 2008 年首次提出的一种新的控制方法。所谓预设性能是指在保证跟踪误差收敛到一个预先设定的任意小的区域的同时, 保证收敛速度及超调量满足预先设定的条件。近些年来，预设性能控制器被逐渐应用到多智能体领域，相关研究成果主要集中在希腊国立雅典理工大学的C.P.Bechlioulis 团队，瑞典皇家理工大学的 V.D.Dimos 团队，华南理工大学的戴诗陆团队。2016 年，C.P.Bechlioulis 等人[48]针对 leader-follower 框架下的高阶非线性多智能体系统，考虑模型不确定的影响，设计了一种预设性能同步控制律。该控制律可以使得follower 智能体仅通过与邻居的相对状态信息，就可以按照预先设计的任意收敛速度与收敛精度跟踪上 leader 智能体，而且，多智能体的动态与稳态性能与通信拓扑结构、控制增益选择及模型不确定均无关。然而，该方法没有考虑智能体之间的避碰问题。2017年，V.D.Dimos 等人[49]考虑多无人机之间的避碰与通信连接约束，即无人机之间不能保持过远或者过近的距离，防止其互相碰撞或丢失通信信号，针对双积分系统的状态同步问题，提出一种分布式控制律，其包括与同步误差成比例的比例项以及基于速度测量值的阻尼项，实现了对位置速度组合误差的定量刻画，然而该方法仅能实现智能体状态保持一致。2018年，C.P.Bechlioulis 与 V.D.Dimos 等人[50]合作研究了具有未知非线性动力学模型的车辆纵向控制问题，他们考虑了两种架构，一是前继跟随架构，即后面车辆仅需根据前一辆车辆的行动状态设计控制器，二是双向控制架构，即车辆在设计控制器时不仅需要考虑其前方车辆的行动轨迹，还需要考虑其后方车辆状态。针对这一问题，他们设计了预设性能控制器，使得车辆之间保持预先设定的动态与稳态性能。2018 年，戴诗陆等[51][52]考虑了前继跟随架构下的无人船纵向控制问题，采用神经网络估计方法设计干扰观测器，在此基础上采用预设性能方法与动态面控制技术设计了编队控制器，使多无人船系统在沿着给定轨迹航行的同时，后面的无人船可以与前面无人船保持期望角度。上述两种方法只考虑了简单的单leader 和单 follower 的级联结构。2019 年，V.D.Dimos 等[53]考虑了更为复杂的系统模型，他们针对模型不确定与外界干扰影响下的刚体非线性 SE3模型，提出了一种新的分散式预设性能控制方法，利用与邻居间的相对信息，使其编队位置误差与姿态误差始终保持在预定的区域范围内，然而该方法仅能使得多智能体之间的状态保持一致并停留在原地，并不满足多无人机协同飞行的要求，即无人机需要沿着给定的轨迹进行飞行。

综上所述，多无人机的协同飞行需要满足两点要求：一是考虑外界环境干扰、模型不确定等综合扰动的影响，在编队内一架或多架无人机出现执行器故障的情况下，多无人机系统仍需要按照给定的航线形成编队并稳定飞行；二是在编队生成与保持的过程中，多无人机之间需要避免碰撞。然而，从上述文献中可以看出，大多数控制方法只考虑了其中一种问题，即无人机间的避碰约束或是飞行过程中受到的综合扰动以及执行器故障的影响。此外，针对多无人机协同控制的研究成果大多侧重于满足编队保持过程的稳态性能，而对形成过程的暂态性能关注较少。因此，为了进一步提高控制品质，研究可以同时保证被控系统的动态性能与稳态性能的预设性能控制方法十分必要。然而在现有多智能体预设性能的研究成果中，大多数方法仅能保证多智能体的稳定状态收敛到某一特定值，无法实现多无人机沿着给定轨迹飞行的目的。因此，如何考虑模型不确定、外界干扰等综合扰动的影响，使多无人机系统在编队生成及保持过程中具备良好的暂态与稳态性能，在编队内一架或多架无人机出现执行器故障的情况下，仍能达到避免碰撞及稳定飞行的要求，提高多无人机系统的飞行控制品质，仍是一个挑战性的研究课题。

## 1.3 研究内容与组织结构

## 1.3.1 论文的研究内容

本文充分考虑多无人机的特点，以实现多无人机类脑智能决策与协同控制为目的，重点开展对下述问题的研究：

## （一）考虑任务优先级的大规模无人机集中式类脑智能任务决策

针对大规模无人机集中式任务决策问题，以地面站为决策主体，为优先级不同的各个探测任务指派合适的无人机。综合考虑任务目标属性随机且各不相同的特点、传统任务决策方法计算量大、求解速度慢的难题以及任务环境不确定对无人机性能的影响，首先在理解人脑运行机制的基础上，通过仿照人脑的经验-推理-决策-改进的过程，提出基于经验总结-行为预测-评价改进-在线决策的类脑智能方法。然后针对上述大规模无人机集中式任务决策问题，采用类脑智能方法中的经验总结-评价改进-在线决策环节进行求解，解决实时性差与鲁棒性差的问题，实现环境不确定影响下的快速智能任务决策。

（二）面向围捕任务的多无人机分布式类脑智能任务决策

以若干架己方无人机围捕对方无人机为任务场景，考虑状态部分可观测的特点、任务环境动态性与不确定性因素的影响，采用上述提出的基于经验总结-行为预测-评价改进-在线决策的类脑智能方法，首先通过已有经验总结初步决策方案，在此基础上以成功完成围捕任务为目标，建立奖赏机制，同时建立经验数据库，存储多无人机围捕任务中的经验数据；其次，利用数据库中的经验数据，推测对方无人机的行动策略，预测其下一时刻的行动加速度；再次，基于中心化评价-去中心化决策的方式，建立评价网络与决策网络，通过评价网络的输出指导决策网络的决策结果，改进己方无人机的行动策略；最后利用训练好的网络完成在线决策，并在不满足要求时进行闭环迭代，解决环境动态性、不确定性与状态部分可观测性给无人机任务决策的有效性带来的影响，最终实现多无人机分布式类脑智能决策。

（三）考虑避碰约束的多无人机自适应协同容错控制

在地面站为无人机分配好任务后，执行同一任务的多架无人机需要组成编队，稳定飞行至指定任务地点。综合考虑避碰约束、执行器故障、模型不确定性与外界干扰等综合干扰的影响，采用被动容错方法，将故障作为综合扰动项进行处理，结合滑模方法对干扰具有鲁棒性及不敏感性的特点，以及预设性能方法定量刻画被控系统动态与稳态性能的优势，提出了一种自适应分布式滑模容错控制器，基于预设性能函数设计时变自适应律，解决了传统滑模控制律的不连续性以及对扰动上界的依赖性问题，同时在编队内一架或多架无人机出现故障时，还能使编队位置及速度跟踪误差始终保持在与扰动无关的预设性能区域内，达到避免碰撞的要求，实现多架无人机对预定航线的编队跟踪飞行。

（四）基于竞争机制的多无人机有限时间任务决策与协同控制

上述研究内容都是以个体合作的方式实现多无人机的任务决策与协同控制，需要注意的是，自然界中的复杂协作行为不仅可以通过合作的方式进行，还可以通过竞争的方式产生。以多无人机追踪闯入特定区域的移动目标为任务场景，创新性地采用赢者通吃的竞争机制对多无人机之间的协作关系进行建模，即在整个过程中，距离目标最近的若干无人机赢得竞争执行追踪任务，其余无人机则返回指定地点待命。为提高决策过程的快速性与控制过程的稳定性，考虑对偶神经网

络高平行性以及求解实时性的特点，以及有限时间方法收敛速度快、精确度高以及抗干扰能力强的优势，提出基于自适应对偶神经网络和干扰补偿的有限时间动态任务决策与协同控制方法，使得无人机能够根据任务决策指令快速完成追踪任务决策，并在决策过程尚未收敛时保证自身状态不会发散。

## 第2章 考虑任务优先级的多无人机集中式类脑智能任务决策

## 2.1 引言

多无人机任务决策是指在执行任务过程中，考虑我方无人机自身能力，任务目标情况和任务需求的情况下，为不同的任务决策恰当的无人机，以最小的任务代价实现任务收益最大化。根据协商机制不同，通常将无人机的任务决策分为集中式和分布式两种决策方式。本章重点介绍集中式任务决策，下一章将会给出分布式任务决策方法。需要注意的是，随着无人机数量的增多，任务决策问题将更加困难。因此，对于大规模无人机集中式任务决策问题来说，存在如下几个难点：1）由于不同任务目标的任务属性随机且各不相同，仅通过已有经验进行决策是不可取的，无法涵盖每种任务的分配方案；2）传统的任务决策方法如粒子群算法、蚁群算法、遗传算法等启发式算法往往面临求解困难，计算量大，求解速度慢的问题，无法满足在线任务决策对实时性的要求；3）由于任务环境是复杂多变的，因此环境中会存在很多不确定因素，影响无人机完成任务的效率。而大多数任务决策方法则是基于确定环境的假设进行求解，导致其分配结果可能无法满足实际任务需求，导致鲁棒性较差。因此研究高效的大规模无人机任务决策方法十分必要。

近年来人工智能在各领域的研究成果斐然，如谷歌 Deepmind 和牛津大学“LipNet” 唇语解读系统，谷歌的 AlphaGo 与 AlphaGo Zero 等。然而，尽管人工智能在各领域的应用成果层出不穷, 但仅是从某一特定领域逼近或是超过人类的智能水平[1]。欧盟“人类大脑计划”的建议报告指出[3]：“除人脑以外，没有任何一个自然或人工系统能够具有对新环境与新挑战的自适应能力、新信息与新技能的自动获取能力、在复杂环境下进行有效决策并稳定工作直至几十年的能力。” 由此可见，借鉴大脑是发展人工智能的一条重要路线，各国的研究学者们也在积极开展在类脑智能方向的研发工作[4]-[5]。

因此，为了解决上述问题，本章首先在理解人脑运行机制的基础上，通过仿照人脑的经验-预测-决策-改进的过程，提出基于经验总结-行为预测-评价改进-在线决策的类脑智能方法。然后针对上述大规模无人机集中式任务决策问题，采用类脑智能方法中的经验总结-评价改进-在线决策环节进行求解，解决实时性差与鲁棒性差的问题，实现环境不确定影响下的快速智能任务决策。

本章结构安排如下：第2.2 节介绍提出的基于经验总结-行为预测-评价改进-在线决策的类脑智能方法；第 2.3节首先对需要解决的大规模无人机任务决策问题进行描述，然后采用类脑智能方法中的经验总结-评价改进-在线决策环节进行求解；第 2.4 节在 Linux 操作系统中，采用 Python 语言和谷歌开源程序 Tensorflow工具包仿真验证所提方法的有效性；第2.5节给出本章工作总结。

## 2.2 类脑智能方法

人的大脑是一个通用智能系统, 由千亿个神经元和数百万亿突触连接构成,具有感知、学习、推理和决策等能力，是宇宙间已知的最复杂的对象，拥有已知的最强的智能。因此，为了使无人机在复杂多变的任务环境中具有自适应和自主决策能力，在理解人脑运行机制的基础上，研究新的类脑智能方法十分必要。

从人类进行决策的思维方式出发，美国 OpenAI 的 John Schuman 曾指出强化学习方法具有和人一样通过奖惩机制学习的能力，是用于决策的通用框架。简单来说，强化学习是智能体与环境不断交互，从而不断强化自己的决策能力的过程[54]，如图 2-1 所示，在每个时间步长，智能体根据自身所处的状态选择采取的动作，执行动作后，智能体会根据环境反馈进入下一个状态，同时得到这一次状态转移的收益。强化学习的目标就是从智能体与环境的试错交互过程中获取信息，以最大化累计收益的方式学习最优策略，指导智能体根据状态做出最佳决策。

综上所述，不管从人脑进行决策的思维方式或是人脑不同区域的功能与协作机制来看，强化学习方法都是设计类脑方法必须借鉴与参考的重要方法。

## 1、经验总结

经验总结是指针对任务决策过程中可能面对的各种情况，根据人脑中的已有经验，建立初步决策方案；然后分析可能的任务完成效果，以成功完成任务为最终目标，总结出奖惩机制，即设置决策主体进行单步决策后会收到的立即收益值，需要注意的是，该收益可能为正，也可能为负，根据任务完成效果而定；在此基础上，将过往的任务决策数据，以及获得的立即收益值储存起来，建立经验数据库。这一步是离线学习过程的基础，后续的行为预测与评价改进环节将利用经验数据库中的数据进行学习。

## 2、行为预测

复杂的任务场景往往涉及双方对抗的情况，这会大大增加任务决策的难度。在这种情况下，如果可以预先知道对方可能的行动策略（即对方的行为模式）以及下一时刻采取的行为，会对己方决策效果的提高产生至关重要的作用。因此，行为预测是指根据对方已有的行为特点，利用经验数据库中的数据，采用极大似然法等概率论方法，推测出对方可能的行动策略，并根据该策略，预测对方下一时刻的行为。这一步作为离线学习过程的中间环节，为后续的评价改进环节提供依据。

## 3、评价改进

仿照人脑根据奖惩机制进行学习的方式，决策主体（本章中为地面站中的计算机）自身也需要具备评价决策结果好坏并进行自我改进的能力。因此，采用基于评价函数的强化学习方法，首先根据第一步中设置的立即收益值，建立评价函数，将不同决策结果对应的平均总收益值作为依据，输出评价结果，并根据评价结果进行决策；然后将决策结果和获得的立即收益值作为新的经验数据，补充进经验数据库中；最后抽取经验数据库中的部分数据，对评价结果与决策策略（即自身的行为模式）进行改进与优化。不断重复这一过程，直到获得最优评价函数或最优行动策略。这一步是离线学习过程的重点与关键，对在线决策环节的任务完成效果起决定性作用。

## 4、在线决策

在仿真环境中模拟无人机在执行任务过程中可能面对的各种情况，以及环境中的不确定因素对无人机完成任务效果带来的影响，决策主体采用离线学习过程得到的最优评价函数或最优行动策略在线给出决策结果，进行若干组仿真实验，并根据奖惩机制，判断在线决策结果是否满足合理性要求，当不满足要求时，重新进行行为预测和评价改进环节，实现闭环迭代，直到完成合理性验证，最终实现多无人机在线任务决策。

本节以无人机任务决策为背景，从人脑进行决策的思维方式以及人脑不同区域的功能与协作机制出发，提出基于经验总结-行为预测-评价改进-在线决策的类脑智能方法。下面将针对大规模无人机集中式任务决策问题，以给不同任务区域分配若干架无人机为例，验证所提类脑智能方法的有效性。需要注意的是，由于此任务不涉及双方对抗，因此后续在应用类脑智能方法时省略了行为预测的环节。

根据初步决策方案和奖惩机制，产生经验数据，并将其以统一格式存储进经验数据库中，为后续的评价改进环节做准备。

## 2.4.2 评判改进

根据 2.4.1 节中建立的奖惩机制和经验数据库，地面站中的计算机需要利用经验数据库中的数据，评价决策结果好坏并进行改进。在传统的强化学习方法中，有一大类是基于评价函数的强化学习方法，这类方法通常采用评价函数指导决策结果。以经典的 Q-learning 方法[57]为例，其包括评价表和贪婪策略两部分，评价表用以估计当前状态下不同动作可以获得的平均最大累计收益值，而贪婪策略则选择其中最大值对应的动作作为当前最优动作。在训练过程中，将根据评价表中的数值，指导贪婪策略选择的动作，并根据仿真环境的反馈，获得立即收益与下一状态。然而，随着求解问题规模的扩大，传统强化学习方法会出现维数灾难的问题，不适用于大规模任务决策问题[58]。因此，具有神经网络拟合功能且鲁棒性强的深度强化学习方法引起了研究学者们的广泛关注。其中最具代表性的方法之一是美国谷歌 Deepmind 在 Nature 上提出的深度 Q 网络（Deep Q Network，DQN）[56]。深度 网络方法用深度神经网络代替传统强化学习中的评价表格，形成评价网络。

本节中的评价改进环节即借鉴传统强化学习中评价表格的作用，利用神经网络的拟合功能，建立评价网络，用来输出当前决策结果可能获得的平均最大总收益值；在与仿真环境的交互过程中，将产生的新的经验数据存储进经验数据库中，并通过优先经验回放的方式提取数据库中的数据，逐步改进评价结果的准确度，也是改进决策结果的最优性。

首先，为了利用传统强化学习中评价表格的作用建立评价网络，需要根据上一节建立的奖惩机制，将把式(2-1)-(2-4)中描述的任务决策问题，总结为马尔科夫决策过程（Markov Decision Process，MDP）。

## 1、建立马尔科夫决策过程

这里首先给出 MDP 的典型组成要素，然后将式(2-1)-(2-4)中描述的集中式任务分配问题，总结为 MDP。

## （1）MDP的典型组成要素

MDP是满足马尔科夫特性的随机过程，主要包括如下 5部分：1）状态集 ；2）动作集 （2.2 节论述中的行为，即 MDP 中的动作）；3）立即收益值 $R _ { s s " } ^ { a }$ ，，即在状态 下执行动作 达到下一状态 时，获得的收益值；4）状态转移概率$P _ { s s " } ^ { a }$ ，即在状态 下执行动作a 达到下一状态 的概率；5）折扣因子 $\gamma \in \left[ 0 , 1 \right]$ MDP描述了智能体与环境的交互过程：智能体在状态 下执行动作 ，并根据状态转移概率 $P _ { s s " } ^ { a }$ 达到下一状态 $s ^ { \prime }$ ，获得立即收益 $R _ { s s " } ^ { a }$ ，并继续这一过程。MDP 的目标为找到一个策略可以最大化平均累积收益值，其中策略表示从状态空间到动作空间的映射，可以通过函数 $\pi : S  A$ 或分布 $\pi : S \times A \to \left[ 0 , 1 \right]$ 定义。因此，MDP目标可以写为如下优化问题：

$$
\operatorname* { m a x } _ { \pi \in \Pi } \Xi \biggl [ \sum _ { l = 1 } ^ { L } \gamma ^ { l - 1 } R _ { s _ { l } s _ { l } ^ { \prime } } ^ { a _ { l } } | \pi \biggr ]\tag{2-7}
$$

其中 $\Xi [ \cdot ]$ 表示期望符号，表示策略空间， 表示交互过程的总步长。

## （2）面向任务优先级集中式任务分配的 MDP 建立

根据式(2-1)-(2-4)中描述的任务决策问题，建立 MDP，各符号的含义如下：1）状态集

根据任务的具体情况，将优先级为 的任务需要的总探测能力、总围捕能力、该任务目标的损伤能力及所在的环境中的风速及降雨量作为状态 ，即

$$
s = ( s e a r ( T _ { m } ) , p r e y ( T _ { m } ) , t h r e ( T _ { m } ) , w _ { m } , r _ { m } ) \in S\tag{2-8}
$$

需要注意的是，初始状态会从给定的范围中随机产生。

## 2）动作集

将选择的无人机类型 $U ^ { j }$ 作为动作 ，即

$$
a = U ^ { j } \in A\tag{2-9}
$$

其中，动作空间 定义为无人机类型，即 $\boldsymbol { A } = \left\{ U ^ { 1 } , U ^ { 2 } , . . . , U ^ { N _ { T } } \right\}$

3）立即收益值 $R _ { s s } ^ { a }$

$$
R _ { s s " } ^ { a } { = } R\tag{2-10}
$$

其中， 为式(2-5)中的奖惩机制。

## 4）状态转移概率 $P _ { s s " } ^ { a }$

对于本节研究的任务决策问题，将无人机实际完成任务的效率 $e f i \left( U ^ { j } \left| w _ { m } , r _ { m } \right. \right)$ 作为状态转移概率 $P _ { s s ^ { \prime } } ^ { a }$ ，即

$$
P _ { s s " } ^ { a } \mathrm { = } e \hslash \left( U ^ { j } \left| w _ { m } , r _ { m } \right. \right)\tag{2-11}
$$

由于环境不确定的影响，无人机实际完成任务的效率也是不确定的，本节假设实际效率服从以经验效率为平均值，具备一定方差的正态分布。理论上，式(2-11)中用到的经验效率可以从实际任务中总结得到。

## 5）折扣因子

表示未来收益值相对于当前收益值的重要程度。当 $\gamma { = } 0$ 时，相当于只考虑当前收益不考虑未来收益， $\gamma { = } 1$ 时，将未来收益和当前收益看得同等重要。这里选取折扣因子 $\gamma { = } 0 . 9$ 0

## （1）评价网络含义及输入输出变量介绍

在本节讨论的大规模无人机任务决策问题中，评价值 $\boldsymbol { Q } ^ { * } ( s , a )$ 指代在当前任务及环境状态 下，指派类型为 的无人机执行该任务可能获得的平均最大收益值。由于完成各种探测任务所需能力以及任务目标所在环境是复杂多变的，与深度 Q 网络方法一致，首先引入神经网络近似环节对评价值 $\boldsymbol { Q } ^ { * } ( s , a )$ 进行参数化，即 $Q \big ( s , a , \pmb { \omega } \big )$ ，其中 $\pmb { \omega }$ 是网络参数，解决评价表格规模过大造成计算困难的问题。

因此，设计如图 2-7所示的求解流程，主要包括评价网络和贪婪策略两部分，评价网络的作用在于指导选择执行任务的无人机类型及数量。其输入为执行某一任务需要的总探测能力、总围捕能力、该任务目标的损伤能力及对应的环境中风速及降雨量，即状态s；输出为选择某一类无人机能获得的平均最大总收益$\boldsymbol { Q } ^ { * } ( s , a )$ 的近似值 $Q \big ( s , a , \pmb { \omega } \big )$ 。贪婪策略的作用在于选择 $\boldsymbol { Q } ^ { * } \left( s , a \right)$ 最大的无人机执行任务，即 $a = \arg \operatorname* { m a x } _ { a } \mathcal { Q } \big ( s , a , \omega \big )$

根据评价网络的含义与输入输出变量的定义可知，在训练过程的一个回合（epsiode）中，如图 2-7所示，将环境中风速及降雨量及完成某一任务需要的能力输入到基于评价网络-贪婪策略的评价改进环节中，利用评判网络输出不同类型的无人机能获得的最大总收益值，通过贪婪策略选择最大输出值对应的无人机执行任务，考虑环境不确定对无人机完成任务效率的影响，获得执行该任务仍需的能力，重复该过程直到选择的编队无人机能够完成该任务，输出执行任务的无人机类型及数量。
