理图片等高维度的信息，并且基于深度强化学习技术的无人机避障导航系统不需要专家经验或者标记数据，可以真正的做到从经验中自主学习，能够很好的适用于无人机的各种应用场景。但是目前强化学习算法在无人机自主避障导航系统中的应用仍处于初始阶段，存在着较大的缺陷：

(1) 无人机导航问题是一个多目标强化学习问题，目前大多数基于深度强化学习的无人机自主避障导航算法都没有考虑目标随机的场景，现有强化学习方法的导航目标通常隐式地蕴含在神经网络的参数中，这种方式导致需要为不同的目标训练不同的模型参数，由于强化学习策略的训练需要大量的计算开销而且导航目标不可枚举，导致现有的强化学习方法很难直接应用于无人机自主避障导航系统中。此外，导航问题的不同目标之间共享一些共同的特征（如不同的目标之间可以共享共同的路径或者方向），如果能够利用这些共同特征，可以使智能体学习到导航问题的内在特征，但是现有的多目标强化学习算法并不能利用这些目标的内在特征[44]。

(2) 无人机的避障导航策略是多个策略的结合，无人机需要在尽快的飞向目标点的同时避开障碍物的干扰，但是现有的深度强化学习算法通常只根据智能体所处环境的当前状态进行决策，在 3D 场景下的无人机避障导航问题中，由于环境的部分可测性以及传感器容量的有限性，无人机当前的视觉观测信息并不能完全的表示智能体所处的真实状态以及智能体所经过轨迹的信息，也不能表示智能体所采取的历史决策，会造成无人机在某一段决策序列之间循环的问题。

(3) 奖励函数是智能体与环境交互的反馈信号，是强化学习算法成功应用的核心组件之一。在无人机避障导航问题中，如果无人机成功到达目标则给出正的奖励，不能到达目标或者发生了碰撞则给予负的奖励是比较直接的奖励方式，但是这种稀疏奖励的设置方式导致智能体很难获得有效的反馈，并导致智能体收敛较慢甚至不能学到有效的策略，因此难以设计高效的奖励函数是强化学习算法应用于无人机自主避障导航系统中的重大阻碍。

(4) 探索­利用（Exploration and Exploitation）困境是深度强化学习算法成功应用的一大难题。有效探索的缺乏会导致智能体难以发现环境中存在的关键信息，导致智能体学习不到有效的控制策略。探索过度则会导致对现有样本的利用不足，导致策略收敛过慢，造成计算资源的浪费。优秀的探索方案不仅可以提高智能体的学习与收敛速度，而且可以提升智能体在复杂任务中的性能，因此探索策略的研究是深度强化学习算法在无人机自主避障导航系统中应用的另一关键问题。

## 1.3 研究目标与内容

## 1.3.1 研究目标

传统的基于视觉的无人机避障导航算法通常通过感知避免方案实现，或者通过视觉SLAM算法与路径规划算法结合实现，这些算法要么通过预先设定的策略实现无人机的避障导航，要么需要实时构建环境的地图，不能满足现今无人机应用场景中对于自主性的要求，也难以应用于大型、动态、开放的 3D 环境中。因此，本文主要研究使用深度强化学习技术提高无人机避障导航系统的自主性以及灵活性。通过结合深度学习的表征提取能力和强化学习的最优控制能力，以端到端的方式实现无人机自主避障导航系统，使无人机在避免碰撞的情况下飞到预定的目标点附近，从而填补目前的深度强化学习技术在无人机自主避障导航系统中的不足。

## 1.3.2 研究内容

针对目前的深度强化学习技术在无人机避障导航中的不足与难点，本文的主要研究内容如下：

(1) 目标驱动的无人机自主避障导航模型。本文借鉴了目标驱动的马尔可夫决策过程[45] 的思想，在计算无人机在某一状态下的动作时会同时参考智能体当前的动作以及当前的导航目标，从而解决经典深度强化学习算法需要为不同的目标重新训练新模型的问题。更进一步地，本文提出了动态相对目标的概念，用以代替经典多目标强化学习中的全局绝对目标，达到利用不同目标之间的共同特征的目的。本文通过逐步的动态相对目标代替一次飞行的全局绝对目标，达到利用不同目标之间的共同特征的目的，从而使智能体学到导航问题的内在特征。更进一步地，碰撞等关键信息在无人机避障导航问题中极为稀少，为了使强化学习算法能够高效地利用稀有信息，本文采取了基于TD­误差的优先经验回放技术，增加稀有信息被采样到的概率，提高了智能体的收敛速度。

(2) 应用于无人机自主避障导航系统的奖励函数设计。为了使智能体更加有效地学习，本文设计了一种非稀疏 (non­sparse) 的奖励函数，该奖励函数由状态迁移奖励、碰撞惩罚、目标奖励以及步数惩戒组成，该奖励函数既能够及时地给予无人机正确的反馈，又能防止无人机学到一些取巧的技巧，能够表示避障导航任务的固有特征。

(3) 记忆增强的深度强化学习算法研究。无人机避障导航环境是部分可测环境，为了提高深度强化学习算法在部无人机避障导航问题中的成功率，本文设计了一种记忆结构将无人机的历史观测以及动作考虑到当前的决策过程中，用于增强部分可测环境下对无人机当前状态估计的准确性。该结构使无人机在决策时不仅仅考虑当前的观测信息，而且把历史的观测以及动作纳入考虑范围内，从而赋予无人机跳出局部循环的能力。

(4) 基于高斯分布探索增强方法的强化学习探索机制研究。为了使智能体高效地平衡探索­利用，提高无人机避障导航策略的收敛速度，本文提出了一种基于值分布强化学习的探索方法。本文把强化学习中的值函数建模为高斯分布而不是一个确定的均值，然后根据贝尔曼方程推导出了基于EM距离的优化指标，并进一步将高斯分布的方差应用于智能体的探索中，从而提高无人机避障导航策略的收敛速度。本文提出的基于高斯分布的强化学习探索增强方法不需要任何超参数，而且在极大地提高了无人机避障导航策略收敛速度的同时获得更高的成功率。

第五章：基于值分布的强化学习探索机制研究。本章从深度强化学习算法探索­利用均衡的角度提高深度强化学习避障导航策略的收敛速度，主要研究基于高斯分布方法提高强化学习算法的收敛速度。本章首先介绍了强化学习问题中的探索­利用窘境，其次介绍了值分布强化学习的基本概念，然后提出了基于高斯分布的值迭代方法，并进一步提出了基于高斯分布的强化学习探索增强方法。更进一步地，将高斯分布探索增强方法应用到 DQN 以及 DSAC 算法中，得到了高斯分布探索增强的 GE­DQN 与 GE­DSAC算法，从而以这些算法验证本文提出的高斯分布探索增强方法不同强化学习算法中的有效性。

## 2.1 深度学习基础

人工神经网络是深度学习的基础。人工神经网络 (Artificial Neural Network, ANN) 是依照生物神经网络设计的一类典型的数学模型，简称为神经网络[46]。在机器学习领域，神经网络是指由许多人工神经元通过一定的层次结构连接所构成的一种模型，这些人工神经元之间通过可学习的参数连接在一起，从而模拟生物神经网络中的信息流动过程。

## 2.1.1 神经元

神经元是神经网络中信息处理与流动的基本单元，其主要思想来源于对生物神经元结构与基本功能的克隆。神经元可以接受上游神经元的输入信号，并通过可学习的参数对其进行线性和非线性运算，然后将运算的结果作为输出传递给下游的神经元。

$$

## 2.1.3 常见深度神经网络模型

虽然含有非线性激活函数的人工神经元已经可以提取非线性的特征，但是人工神经元在复杂的数据场景下难以取得较好的效果，因此学者逐渐转向深层网络的研究，本小节主要介绍多层感知机、卷积神经网络等常见的深度神经网络模型。

## 1. 多层感知机

单个神经元组成的神经网络又可以被称为感知机模型。如果将多个互不相连的神经元堆叠在一起，并且每一个神经元都与全部的输入连接，就构成了一层全连接神经网络，将多层这样网络连接在一起，就构成了多层感知机（Multi­Layer Perception, MLP），典型的多层感知机的结构如图2­3所示。

多层感知机模型在单个神经元的输入层与输出层之间加入了一到多层的隐藏层，而且输出层也可以包含多个输出。相对于单个神经元，深度神经网络的特征提取能力有了较大的提高，可以灵活的应用到分类、回归、聚类等问题之中。

在多层感知机中，一个神经元输出的计算方式和单层感知机类似，假设一个多层感知机模型的第l−1层含有m个神经元，则第l 层的第i个神经元的输出 $a _ { i } ^ { l }$ 的计算方式如公式2.2所示。

$$
a _ { l } ^ { i } = \sigma ( \sum _ { j = 1 } ^ { m } w _ { i , j } ^ { l } a _ { j } ^ { l - 1 } + b _ { i } ^ { l } )\tag{2.2}
$$

其中 $w _ { i , j } ^ { l }$ 代表第 l 层的第 i 个神经元与第 l − 1 层的第 j 个神经元连接的权重大小，$a _ { j } ^ { l - 1 }$ 代表第l−1层的第j 个神经元的输出， $b _ { i } ^ { l }$ 代表第l层的第i个神经元对应的偏置。更进一步地，假设其第l−1层含有m个神经元，第l层含有n个神经元，使用 $W \in R ^ { n \times m }$ 代表第 l 层的权重矩阵， $a ^ { l } \in R ^ { m }$ 代表第 l − 1 层的输入向量，bl 代表第 l 层的偏置向量，则第l 层的神经元的输出 $a ^ { l } \in R ^ { n }$ 的计算方式如公式(2.3)所示。

$$
a ^ { l } = \sigma ( W ^ { l } a ^ { l - 1 } + b ^ { l } )\tag{2.3}
$$

## 2. 卷积神经网络

卷积神经网络（Convolutional Neural Network, CNN）是深度学习技术的代表模型之一，卷积神经网络起源于Lecun等人提出的LeNet[49]。卷积神经网络的主要思想是稀疏连接、参数共享、等变表征，从而减少神经网络系统的参数数目，增强深度学习系统的特征提取能力。到目前为止，专家学者对卷积神经网络的研究取得了许多成果，并已经成功应用于图像处理[49,50]、语音识别[51]、自然语言处理[52] 等信息处理系统中。

卷积神经网络主要由卷积层、池化层组成。卷积和池化是卷积神经网络中的核心操作，一般的卷积神经网络通常由多个卷积层和池化层构成，通过对卷积层的步长、卷积核的大小以及层次连接结构进行调节可以得到各种不同结构的卷积神经网络，下面分别对卷积层与池化层进行详细介绍。

卷积层主要由多个堆叠的卷积核组成，每一个卷积核都是一个二维矩阵，该二维矩阵在输入上按照一定的步长进行滑动，并在滑动的过程中执行卷积操作，从而得到卷积层的输出，并将其作为下一层的输入。深度学习系统中的卷积运算实质上是互相关运算，其计算过程如图2­4所示。大多数学者认为，浅层的卷积层可以提取到图像中的边缘信息，而深层的卷积层则可以对这些低级特征进行处理，从而提取到物体及其分布等高层的特征。

池化层（Pooling Layer）又被称为下采样层，池化层中的核心操作是池化操作，池化操作使用某一位置附近的输入的总体特征作为该位置的输出，具有降低输入特征大小、避免过拟合的作用，而且池化层具有使少量的偏移数据保持近似不变的性质，该性质被称为局部平移不变性。在卷积神经网络中，常见的池化操作包含最大池化、平均池化以及随机池化，不同池化操作的示意图如图2­5所示，这些池化操作的区别为：

(1) 最大池化：最大池化是最常用的池化操作，该池化方法通过选取操作窗口区域中的最大值作为该区域池化后的值。

(2) 平均池化：平均池化选择池化窗口中所有元素的平均值作为该区域池化之后的值。

(3) 随机池化：随即池化首先根据窗口元素的值归一化为被选择的概率，然后依据此概率进行采样得到池化的结果，元素越大被选中的概率越高。

## 2.2 强化学习基础

## 2.2.1 马尔可夫决策过程

强化学习是一种研究如何从环境状态映射到智能体动作从而获得最大累计奖励的学习方法。在智能体与环境的交互中，智能体首先对环境进行观测，进一步处理得到环境的状态 $s _ { t }$ ，并根据一定的策略决定当前时刻要采取的动作 $a _ { t }$ ，然后环境对智能体的状态做出反应，智能体得到一定的奖励 $r _ { t }$ 。具体的交互过程如图2­6所示。

马尔可夫决策过程（Markov Decision Process, MDP）通常用于对强化学习问题进行建模,马尔可夫决策过程通常使用一个五元组 $< S , A , P , R , \gamma >$ 来描述[53]，其中：

(1) S 代表所有环境状态的集合，也被称为状态空间。 $s _ { t } \in S$ 表示智能体在t时刻所处的状态。

(2) A 表示智能体可执行动作的集合，或者称为动作空间， $a _ { t } \in A$ 表示智能体在 t 时刻所采取的动作。

<!-- image-->  
图2­6马尔可夫决策过程

(3) P 代表智能体的状态转移矩阵，使用 $P ( s ^ { \prime } | s , a )$ 代表状态 s 下执行动作 a 所转移到的下一个动作为 $s ^ { \prime }$ 的概率，在马尔可夫决策过程中，状态转移矩阵需要满足$P ( s \mid s _ { t - 1 } , s _ { t - 2 } , . . . , s _ { 1 } ) = P ( s | s _ { t - 1 } )$ ，该性质被称为马尔可夫决策过程的无后效性，也就是说环境的下一个状态只和当前环境状态有关，而和其他历史上发生的其他环境状态无关。

(4) R 代表奖励函数。奖励函数是一定状态下动作到奖励分布的映射，在状态 $s _ { t }$ 执行动作 $a _ { t }$ 的奖励使用 $R ( s _ { t } , a _ { t } , s _ { t + 1 } )$ 或者 $r _ { t + 1 }$ 表示，代表着在状态 $s _ { t }$ 执行动作 $a _ { t }$ 时环境反馈的期望。

(5) γ 是折扣因子，用于权衡立即奖励与未来奖励的重要程度，通常介于 0 与 1 之间。

马尔可夫决策过程的目标是寻找一个从状态空间到动作空间的映射，从而获得最大累积奖励。为了对其进行形式化定义，首先我们给出时刻 t 的预期折扣收益 $G _ { t }$ 的定义，预期折扣收益是从当前开始到情节 (episode) 结束智能体所获得的折扣奖励的综合，具体的定义如公式(2.4)所示。

$$
G _ { t } = r _ { t + 1 } + \gamma r _ { t + 2 } + \gamma ^ { 2 } r _ { t + 3 } + . . . = \sum _ { k = 0 } ^ { \infty } \gamma ^ { k } r _ { t + k + 1 }\tag{2.4}
$$

在马尔可夫决策过程中，状态空间到动作分布的映射被称为策略，通常用符号 $\pi$ 表示, 具体定义为状态 s 下选择每个可能动作的概率分布。如果智能体按照策略 $\pi$ 行动则$\pi ( a | s )$ 表示在给定状态s下采取动作a的概率。马尔可夫决策过程的目标是寻找一个最优策略 $\pi ^ { * }$ 使得按照此策略行动能够最大化智能体获得的累计折扣回报的期望，其定义如公式(2.5)所示。

$$
\begin{array} { l } { \displaystyle \mathbb { E } [ G _ { 0 } | s _ { 0 } , \pi ] = \mathbb { E } [ \sum _ { t = 0 } ^ { \infty } \gamma ^ { t } r _ { t } | a _ { t } \sim \pi ( \cdot | s _ { t } ) , s _ { 0 } ] } \\ { \displaystyle = \sum _ { \tau } P _ { \pi } ( \tau ) R ( \tau ) } \end{array}\tag{2.5}
$$

其中 $\begin{array} { r } { R ( \tau ) = \sum _ { t = 0 } \gamma ^ { t } r _ { t } } \end{array}$ 代表轨迹 τ 的累计折扣回报， $P _ { \pi } ( \tau )$ 代表轨迹 τ 在策略 $\pi$ 下出现的概率。

策略π在状态s的状态值函数表示从状态s开始并且之后的动作遵循策略π的预期收益的期望，通常使用 $V ^ { \pi } ( s )$ 表示。对于马尔可夫决策过程， $V ^ { \pi } ( s )$ 的定义如公式(2.6)所示。

$$
V ^ { \pi } ( s ) = \mathbb { E } _ { \pi } [ G _ { t } | s _ { t } = s ] = \mathbb { E } _ { \pi } [ \sum _ { k = 0 } ^ { \infty } \gamma ^ { k } r _ { t + k + 1 } | s _ { t } = s ]\tag{2.6}
$$

根据马尔可夫决策过程无后效性的特征，结合 $G _ { t }$ 的定义，可以得到状态值函数的贝尔曼方程如公式2.7所示。

$$
\begin{array} { r l } & { V ^ { \pi } ( s ) = \mathbb { E } _ { \pi } [ G _ { t } | s _ { t } = s ] } \\ & { \qquad = \mathbb { E } _ { \pi } [ r _ { t + 1 } + \gamma G _ { t + 1 } | s _ { t } = s ] } \\ & { \qquad = \mathbb { E } _ { \pi } [ r _ { t + 1 } + \gamma V ^ { \pi } ( s _ { t + 1 } ) | s _ { t } = s ] } \end{array}\tag{2.7}
$$

策略 π 在动作 a 下的状态­动作值函数定义为在状态 s 下采取动作 a，并且之后的动作遵循策略π 的预期收益，通常使用 $Q ^ { \pi } ( s , a )$ 表示。 $Q ^ { \pi } ( s , a )$ 定义如公式(2.8)所示。

$$
Q ^ { \pi } ( s , a ) = \mathbb { E } [ G _ { t } | s _ { t } = s , a _ { t } = a ] = \mathbb { E } _ { \pi } [ \sum _ { k = 0 } ^ { \infty } \gamma ^ { k } r _ { t + k + 1 } | s _ { t } = s , a _ { t } = a ]\tag{2.8}
$$

类似地，可以得到状态­动作值函数的贝尔曼方程如公式(2.9)所示。

$$
Q ^ { \pi } ( s , a ) = \mathbb { E } _ { \pi } [ r _ { t + 1 } + \gamma Q ^ { \pi } ( s _ { t + 1 } , a _ { t + 1 } ) | s _ { t } = s , a _ { t } = a ]\tag{2.9}
$$

根据状态值函数与状态­动作值函数的定义，可以得到 $V ^ { \pi } ( s )$ 与 $Q ^ { \pi } ( s , a )$ 之间的关系如公式所示。

$$
V ^ { \pi } ( s ) = \sum _ { a \in A } \pi ( a | s ) Q ^ { \pi } ( s , a ) = \mathbb { E } [ Q ^ { \pi } ( s , a ) ]\tag{2.10}
$$

更进一步地，根据公式(2.9)与公式(2.10), 可以的状态值函数与状态­动作值函数之间的贝尔曼方程如公式(2.11)所示。

$$
Q ^ { \pi } ( s , a ) = r _ { t + 1 } + \gamma V ^ { \pi } ( s _ { t + 1 } )\tag{2.11}
$$

## 2.2.2 强化学习策略求解方法

强化学习的目标是设计一个算法，使得智能体可以在与环境交互的过程中通过试错的方式学习到一个最大化累计折扣收益期望的策略。根据环境模型是否已知，强化学习算法可以分为基于模型 (model­base) 与模型无关 (model­free) 两种，基于模型的算法主要是指状态转移矩阵与奖励函数是已知的，从而在学习的过程中可以利用相关的信息，而模型无关算法则不需要任何状态转移矩阵以及奖励函数相关信息。此外，通过在线学习的方式，首先求解状态转移矩阵以及奖励函数，然后进一步根据这些信息对策略进行求解，也被认为是基于模型的方法。

在基于模型的马尔可夫决策过程的求解中，动态规划算法[54] 是一个较为有效的算法，动态规划算法首先对终止状态的值函数 $V ( s _ { T } )$ 进行求解，然后根据上文提到的贝尔曼方程重复求解 $V ( s _ { T - 1 } ) , V ( s _ { T - 2 } ) , \ldots$ ，直到通过递归求出所有的解。但是在模型未知的场景下，动态规划算法不能得到最终状态的相关信息，因此也无法计算其他状态对应的值，此时可以采取蒙特卡洛（Monte­Carlo）或者时序差分 (Temporal­Difference, TD) 方法[55] 首先根据采样的数据代替期望用于对值函数进行估计，然后以值迭代的方式求解最优策略。此外，基于策略的求解方法也是在模型未知场景下常用的求解方式之一，基于策略的方法首先对策略进行参数化，然后按照优化的思想根据智能体探索的信息更新策略的参数，最终收敛到最优策略。

总体上来说，强化学习算法包含两种主流的方法：基于策略的方法以及基于值的方法，基于策略的方法通常更加适合连续的随机环境，并且具有更快的收敛速度，基于值的方法拥有更加高效的采样策略，而且训练过程也更加的稳定。本小节主要针对这些算法进行介绍，并进一步引入一些两种方式结合的算法。

## 1. 基于值的方法

基于值迭代的强化学习算法是较为常用的算法之一。在值迭代算法中，所有状态的值都会被保存下来，并根据智能体与环境交互得到的信息不断对状态的值函数进行更新，直到值函数收敛到最优估计，然后通过最优值函数求出最优策略 $\pi ^ { * }$ 。

Q­学习（Q­Learning）[56] 方法是目前较为流行的基于值的强化学习算法之一。Q­学习是一种基于时序差分方法[55] 对动作值函数进行估计的异策略 (Off­Policy) 强化学习算法，Q­学习算法使用表格保存状态­动作对的 Q 值，然后根据单步状态转换序列中的即时奖励以及下一状态­动作值函数的最大值代替Q值的目标，该估计值被称为 $Q _ { t a r g e t } ,$ 其计算方式如公式(2.12)所示。

$$
Q _ { t a r g e t } = r + \gamma \operatorname* { m a x } _ { a ^ { \prime } \in A } Q ( s ^ { \prime } , a ^ { \prime } )\tag{2.12}
$$

在上式中， $Q ( s ^ { \prime } , a ^ { \prime } )$ 表示下一状态对应的动作值函数的值，在Q学习的过程中，首先通过查表的方式找到所需的Q 值，然后通过公式(2.13)对Q 值进行更新。

$$
Q ( s , a )  ( 1 - \alpha ) Q ( s , a ) + \alpha [ r + \gamma \operatorname* { m a x } _ { a ^ { \prime } \in A } Q ( s ^ { \prime } , a ^ { \prime } ) ]\tag{2.13}
$$

在上式中， $\gamma$ 为上文提到的折扣因子，α 用于控制Q值的更新步长。Q­学习通过贪心的方式选择后记状态的最大 Q 值作为下一节点的状态值，并与当前的立即奖励相加得到TD目标，然后将对应状态和动作的Q值向目标的方向更新。研究表明，在离散并且有限的马尔可夫决策过程中，Q­学习算法可以收敛到最优的动作值函数[57]，Q 学习算法的伪代码如算法2.1所示。

由于 Q­学习需要枚举所有的状态，但是许多现实场景中的实际问题的状态空间都十分巨大，因此基于表格的 Q­学习不能应用于这些场景中。随着深度学习的发展，DeepMind 团队提出了 DQN 算法[17]，DQN 算法使用卷积神经网络近似每一个状态下不同动作的 Q 值。但是神经网络的引入带来了其他的问题，主要就是神经网络的训练样本之间需要满足独立同分布的条件，但是马尔可夫决策过程中产生的样本是高度相关的，因此DQN 中引入了经验回放机制用于解决数据之间的相关问题。

## 2. 基于策略的方法

虽然基于值的强化学习算法能够解决部分强化学习问题，但是由于基于值的强化学习算法需要枚举所有的动作，不能处理连续动作空间的问题，因此有部分学者对基于策略的强化学习算法进行了一定的研究。

与基于值的方法不同，基于策略的方法首先把策略进行参数化，然后直接根据该策略选择动作而不需要考虑相关的价值函数。假设使用θ 表示策略的参数，智能体在时刻t处于状态s，则智能体在时刻t采取动作a的概率为 $\pi ( a \mid s , \theta ) = P r \{ a _ { t } = a | s _ { t } = s , \theta _ { t } =$ $\theta \}$ 。强化学习的目标是学习到一个策略 $\pi _ { \theta }$ 从而最大化累计折扣奖励的期望，对应的目标函数为 $\begin{array} { r } { J ( \theta ) = \sum _ { \tau } P ( \tau | \theta ) R ( \tau ) } \end{array}$ ，对应的梯度为 $\nabla _ { \theta } J ( \theta ) = \mathbb { E } _ { s \sim P , a \sim \pi } [ \nabla _ { \theta } \log \pi _ { \theta } ( s , a ) Q ^ { \pi } ( s , a ) ]$ 0如果以蒙特卡洛的方式对 $Q ^ { \pi } ( s , a )$ 进行采样，则可以使用梯度上升的方式沿着最大化累计折扣奖励的梯度方向更新参数，如公式(2.14)所示。

$$
\theta _ { t + 1 } \gets \theta _ { t } + \alpha \nabla _ { \theta } J ( \theta )\tag{2.14}
$$

相比于基于值的强化学习算法，策略梯度方法的主要不足是具有较高的方差，其中一种降低方差的方法是使用状态值函数 V 作为累计折扣奖励的基线（Baseline），并在计算的过程中减去基线的值，从而在保持无偏估计的同时降低方差。

## 3. 基于演员评论家（Actor­Critic）的算法

基于值的强化学习算法需要针对动作空间进行枚举，因此不能用于处理连续动作空间的问题。基于策略的强化学习算法每次都需要采样数条完整的轨迹并计算这些轨迹的累计折扣奖励，导致较大方差的同时使得采样效率的低下。为了同时利用基于值的强化学习算法以及基于策略的强化学习方法的优势，有学者提出了演员­评论家算法(Actor­Critic, AC)[58,59]，扩展算法到连续动作空间或者大型动作空间的同时根据时序差分算法减少算法的偏差，提高采样效率。AC 算法中包含 Actor 和 Critic 两部分，Actor通过学习最佳策略从而控制智能体的行为，可以将环境状态作为输入并输出对应的最优动作，而 Critic 则通过对最优值函数的估计来评估当前状态的质量，并根据时序差分算法生成值迭代信息，并使用梯度下降算法对参数进行更新，同时能够生成对 Actor 的指导信息，辅助 Actor 进行梯度更新。Actor­Critic 算法的结构如图2­7所示。

<!-- image-->  
图2­7 演员­评论家算法结构图

在AC算法中，Actor使用神经网络近似动作的分布，其主要目的是根据给定的状态生成对应的最优动作。Critic使用另外的神经网络对值函数进行近似。Actor根据环境的状态产生对应的动作分布，而 Critic 根据 Actor 输出的动作分布以及环境状态，计算出对应的状态­动作值函数的期望值。在训练过程中，Actor和Critic分开进行训练，Critic首先根据 TD 目标进行学习，而 Actor 则根据 Critic 计算的状态­动作值根据公式2.15进行更新。

$$
\nabla _ { \theta } J ( \theta ) = \mathbb { E } _ { s \sim P , a \sim \pi } [ \nabla _ { \theta } \log \pi _ { \theta } ( s , a ) Q ^ { \pi } ( s , a ) ]\tag{2.15}
$$

更进一步地，如果使用一个 Critic 同时计算状态值函数 V (s) 以及动作值函数 $Q ( s , a )$ ，则可以结合上文提到的基于基线的策略梯度算法，此时策略梯度的目标函数如公式(2.16)所示。

$$
\nabla _ { \theta } J ( \theta ) = \mathbb { E } _ { s \sim P , a \sim \pi } [ \nabla _ { \theta } \log \pi _ { \theta } ( s , a ) ( Q ^ { \pi } ( s , a ) - V ( s _ { t } ) ) ]\tag{2.16}
$$

其中 $A ( s , a ) = Q ( s , a ) - V ( s )$ 被称为优势函数，该函数可以表示当前动作的相对质量，衡量在特定状态下一个动作的价值相对于其他动作的优势。在实际的实现中，根据状态值函数与状态­动作值函数的关系，Q 值可以根据 V 值结合单步采样的立即奖励加以估计，也就是 $Q ( s _ { t } , a _ { t } ) = r + \gamma V ( s _ { t + 1 } )$ ，因此可以在Critic只计算V值的情况下实现，此时 Actor 的梯度如公式(2.17)所示。

$$
\nabla _ { \theta } J ( \theta ) = \sum \nabla _ { \theta } \log \pi _ { \theta } ( s _ { t } , a _ { t } ) ( r + \gamma V ( s _ { t + 1 } ) - V ( s _ { t } ) )\tag{2.17}
$$

该算法被称为优势演员­评论家算法（Advantage Actor­Critic, A2C），优势函数的引入提高了算法的学习效率，而且可以减小估计的方差，从而使学习更加稳定。

## 2.3 基于强化学习的无人机控制

强化学习控制无人机背后的直觉在于使无人机与环境交互的过程中自动学习最优的飞行方法，如果一个动作使无人机到达了更好的状态，则下次产生该动作的趋势就会加强，在这种直觉下，不需要硬编码任务的控制信号，只需要提供针对无人机动作的反馈，该反馈可以对无人机所处状态的优劣进行评估，从而引导无人机自身选择更好的控制行为。

如果我们想要使无人机精确飞到某个目标，这种情况下，无人机首先观测自身所处的状态，这些状态可能包含其当前位置、速度等信息，然后它可以执行一系列的控制指令、或者执行一个高级的控制动作，如果无人机正确地完成了任务，环境会给予较大的奖励，无人机会认为该动作可以收获到奖励，从而增加该动作被执行的几率。相反地，则会减小相应动作的几率。在这种情况下，我们不需要精确地给出无人机执行的控制指令，只需要给予其正确的反馈，无人机会在强化学习算法的迭代下找到最佳策略。

在基于强化学习的无人机控制方法中，强化学习算法通过与环境的交互间接学习环境的相关信息，不需要已知的环境信息，本文研究基于强化学习的无人机控制方法，从而解决无人机在3D 场景下的自主避障导航问题。

## 第三章 基于目标驱动强化学习的无人机自主避障导航模型

本章对无人机避障导航问题进行了形式化描述，首先把无人机避障导航问题建模为目标驱动的马尔可夫决策过程，然后给出了该模型的状态空间、动作空间，其次提出了利用导航问题内在特征的动态相对目标方法，然后设计了应用于无人机避障导航问题的非稀疏奖励函数，最后给出了结合优先经验采样技术的DQN算法以及DSAC算法的无人机避障导航策略求解方法，从而使用深度强化学习方法解决无人机避障导航问题，并为后续的算法改进奠定了基础。

## 3.1 目标驱动的马尔可夫决策过程

无人机视觉导航问题需要实现原始图片信息和导航目标到运动指令的映射。深度强化学习技术能以端到端的方式直接把无人机的视觉观测信息转化为控制动作，但是标准的强化学习算法的目的在于在找到一个环境状态到动作的映射，其决策时只考虑环境状态而不考虑无人机当前飞行的目标。如果以这种方式训练深度强化学习算法，则无人机飞行的目标隐含地编码在了神经网络的参数中，不能随意更改导航的目标，而且策略的训练过程中不能利用目标之间的相关性，因此不能直接应用于无人机自主避障导航问题中。为了克服经典深度强化学习算法在无人机避障导航问题中的缺陷，我们把无人机自主避障导航问题建模为一个目标驱动的马尔可夫决策过程[45,60]，使强化学习算法在决策时同时考虑当前的观测和规划的目标，并同时作为条件决定下一时刻需要采取的动作，从而使强化学习算法能够不重新训练而应用于不同的导航目标，而且可以利用不同导航目标之间的相关性，减少模型的训练时间。

为了使用深度强化学习算法解决无人机避障导航问题，本小节首先根据马尔可夫决策过程对无人机自主避障导航问题进行建模，然后分别阐述该模型中的状态空间、动作空间、目标集成以及奖励函数的设计等问题。

无人机避障导航问题就是控制无人机在避开障碍物的情况下飞到预定的目标附近的过程，该过程是一个序列决策问题，问题的核心是不断的根据无人机当前的导航目标以及前置视觉传感器的信息决定无人机的飞行速度与方向等控制信息。在无人机避障导航的场景下，无人机通过视觉传感器、GPS等获取的数据是无人机周边环境的体现，该环境状态信息可以结合目标位置共同作为系统状态。无人机的前行、左转、右转、上升、下落等控制指令可以作为决策的动作，而无人机是否发生碰撞、离目标的距离以及与目标的相对角度等信息可以作为环境对于无人机的奖励，因此无人机避障导航问题可以建模为一个马尔可夫决策过程，下文将介绍该模型的具体内容。

## 3.2 状态空间

## 3.2.1 环境状态构成

在无人机避障导航场景中，环境状态是不可知的，因此我们只能使用无人机对环境的观测作为环境状态的代替。无人机可以通过其装载的传感器感知环境的状态，该信息被称为观测 (Observation)。在本文中，无人机的观测有两部分组成，分别为视觉传感器信息和无人机的位置信息。无人机为了躲避环境中的障碍物，需要能够感知障碍物的信息，因此我们使用无人机装载的前置摄像头获取的信息作为观测的一部分。其次，无人机的位置数据对于无人机避障导航问题来说也是必不可少的信息。因此我们使用无人机的位置信息作为观测的另一部分，该信息主要包含无人机飞行方向相对于 XOY 平面的偏转角度 $y a w _ { t }$ 以及无人机当前的位置 $( x _ { t } , y _ { t } )$

除了无人机的观测信息之外，为了让无人机能够飞向随机的目标点，我们把导航的目标与无人机的观测集成到一起作为环境的状态。在导航任务中，无人机的目标由一个坐标点 $( x _ { g } , y _ { g } )$ 确定，因此我们使用该坐标点作为目标的信息。在深度强化学习算法的实现中，无人机所处环境的状态信息以及目标信息在使用中没有差别，因此在本文中使用状态信息代表这些信息的集合。

## 3.2.2 位置目标特征融合

在导航问题中，导航任务的不同目标的轨迹路径可能存在一些共同的特性。如图3­1所示，轨迹 $\tau _ { 0 }$ 和轨迹 $\tau _ { 1 }$ 共享部分相同的路径，而轨迹 $\tau _ { 1 }$ 与轨迹 $\tau _ { 2 }$ 可以共享相同的控制序列，为了利用不同目标之间的共同特征，使智能体学到导航任务的固有内在特征，我们提出了逐步的（step­wise）动态相对目标代替逐情节 (episode­wise) 的全局绝对目标的方法，使用无人机当前位置与导航目标之间的相对值作为每一个决策节点的临时目标，并用该临时目标替换一次导航任务的全局目标与无人机当前的位置信息，达到利用不同目标之间的共同特征的目的。

在具体的实现中，除了临时目标的位置以外，本文还计算了 $y a w _ { t }$ 与该临时目标的偏转角度 $y a w _ { g t }$ 替换无人机的全局朝向 $y a w _ { t }$ 作为辅助的目标特征，从而将 $( x _ { g t } , y _ { g t } , y a w _ { g t } )$ 作为无人机相对于目标的特征，并用这些融合的信息代替无人机的目标信息以及位置信息。

状态空间是环境状态的集合，总的来说，本文所建立的应用于无人机避障导航问题的马尔可夫决策过程的状态由无人机的视觉观测信息 $O _ { t }$ 、无人机的位置信息与目标的位置信息的相对值 $g _ { t } = ( x _ { g t } , y _ { g t } , y a w _ { g t } )$ 组成，这些值共同确定了无人机及其所处环境和执行任务的状态，对于无人机避障导航任务来说至关重要。

## 3.3 动作空间

动作空间是智能体可执行动作的集合。本文主要关注无人机在固定高度避障导航的问题，选择固定高度飞行的原因有两个，首先就是由于是在开放环境下进行导航，在变动高度的情况下，无人机容易学到一些作弊的行为（如首先飞到足够的高度，越过障碍后再进行降落），其次是因为本文只用无人机前置视觉传感器的信息作为避障的主要输入，该信息并不能指示高度方向是否会发生碰撞。为了避免强化学习算法与动力学控制指令耦合，我们首先根据无人机的一些速度控制和方向控制指令实现了一些较为高层的控制指令，主要包含以固定的速度前行特定的时间、左转一定的角度以及右转一定的角度，更进一步地，我们将无人机的控制动作进行离散化，离散化后包含左转、右转、直行三个动作，动作的具体细节为：

(1) 左转：以 30◦/s 的速度左转 1 秒；

(2) 右转：以 30◦/s 的速度右转 0.7 秒；

(3) 直行：向搭载摄像头的方向以2m/s的速度前进1秒。

值得注意的是，左转和右转动作的角度并不相同，这样设计的主要动机是为了创建两个不会互相抵消的动作，防止无人机被困在某些环境中。

## 3.4 奖励函数设计

奖励函数是马尔可夫决策过程的核心组件之一，奖励函数的优劣直接决定了强化学习算法的学习速度以及收敛性。奖励函数是环境提供给智能体的一个反馈信号，该信号反映了智能体选择的动作的价值。在无人机导航中，如果无人机执行了一个动作，该动作使无人机到达了目的地，则奖励函数应该给无人机大于零的奖励，表示无人机执行的动作对于当前的导航目标来说有着积极的影响。

一个合适的奖励函数首先要能够恰当地反应任务的特性，给予智能体适当的反馈信号，在选择正确的动作时给予智能体较大的奖励，否则给予较小的奖励或者负的奖励。其次，合适的奖励函数也应该具有较为平坦的分布，从而加快强化学习算法的收敛速度。

在无人机避障导航问题中，一个较为直接的想法是使用稀疏奖励。如果无人机成功到达目标，则给予+1的奖励，如果发生了碰撞或者在预定的步数限制内没有到达目标，则给予­1的奖励。但是如果在无人机导航的过程中使用稀疏奖励，智能体在训练的初期使用近似随机的策略与环境交互，容易导致智能体很难获得积极的奖励，从而导致强化学习算法难以收敛甚至无法收敛。为了克服这个问题，本文设计了一种应用于无人机避障导航问题的非稀疏奖励函数，该奖励函数主要有四部分构成，分别为转移奖励、碰撞惩戒、目标奖赏以及步数惩罚。

转移奖励用于表示无人机相对于导航目标的距离变化，可以使无人机每一步的移动都能得到相应的反馈信号而不是在情节的结束才能得到有效的奖励，是奖励函数的主要部分之一，对智能体的高效学习有着至关重要的作用。使用 $( x _ { g } , y _ { g } )$ 代表无人机在一个完整情节的导航的目标，转移奖励的定义如公式(3.1)所示。

$$
r _ { t r a n s } = \sqrt { ( x _ { g } - x _ { t } ) ^ { 2 } + ( y _ { g } - y _ { t } ) ^ { 2 } } - \sqrt { ( x _ { g } - x _ { t + 1 } ) ^ { 2 } + ( y _ { g } - y _ { t + 1 } ) ^ { 2 } }\tag{3.1}
$$

碰撞惩戒是无人机安全飞行的重要指示部分，它能够指导无人机避免与障碍物的碰撞。在本文中，碰撞惩戒被定义为 $r _ { c o l l i s i o n } = c _ { t }$ ，其中 $c _ { t }$ 是一个指示变量，指示无人机是否发生碰撞，如果发生了碰撞则 $c _ { t }$ 为1，否则 $c _ { t }$ 为 $0 _ { \circ }$ 。类似地，目标奖赏用于指示无人机是否成功的到达了目标，其被定义为 $r _ { t g t } = d _ { t }$ ， $d _ { t }$ 也是一个指示变量，用于指示无人机是否到达了目标,如果无人机到达了目标，则 $d _ { t } = 1$ ，否则 $d _ { t }$ 为 $0 .$ 。

步数惩罚是奖励函数的最后一部分，主要用于打破无人机的导航目标方向存在障碍情况下的困境。使用步数惩罚的主要原因是如果不存在步数惩罚，而障碍物和导航的目标方向均在无人机的正前方，由于转向动作几乎不产生负的奖励，而向其他方向前进都会导致奖励变少，因此可能导致无人机困在转向的循环中，因此步数惩戒也是必须的一部分。步数惩戒被简单地定义为 $r _ { s t e p } = - 0 . 0 1$ 。

最终的奖励函数根据各部分进行加权得到，最终奖励函数的完整形式如公式(3.2)所示。

$$
R ( s _ { t } , a _ { t } , s _ { t + 1 } ) = 0 . 0 1 * r _ { t r a n s } - 3 * r _ { c o l l i s i o n } + 2 * r _ { t g t } + r _ { s t e p }\tag{3.2}
$$

## 3.5 基于深度强化学习算法的无人机避障导航策略求解

## 3.5.1 基于深度强化学习的无人机避障导航框架

把无人机避障导航问题建模为一个马尔可夫决策过程后，该模型可以使用深度强化学习算法进行求解。如图3­2所示，无人机与环境的交互过程主要包含以下几步：

(1)每个时刻t无人机对环境进行观察，得到对环境的观测 $o _ { t }$ ，并根据全局目标计算对应的局部目标 $g _ { t }$ ，然后利用深度学习的方法对其进行特征提取，得到具体的状态特征表示 $s _ { t }$ ；

(2) 将 $s _ { t }$ 输入到决策网络中，并得到对应的动作 $a _ { t } \colon$ ；

(3) 无人机在执行动作之后系统进入下一个状态 $s _ { t + 1 }$ ，并获得一定的奖励 $r _ { t + 1 }$ 。强化学习算法通过交互获得的 $< s _ { t } , a _ { t } , s _ { t + 1 } , r _ { t } >$ 等信息根据一定的优化算法更新自身参数以最大化累计折扣回报的期望。

(4) 如果 $s _ { t + 1 }$ 是终止状态，则重置环境。在本文中，如果无人机到达了目标、发生了碰撞或者决策次数超过了上限，则无人机进入到终止状态。

(5)重复步骤（1）­（4）的过程，直到策略收敛。
