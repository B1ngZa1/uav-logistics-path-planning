## 2.3.3 复杂机动目标的自主跟踪路径规划模型

2.3.2 节在基于 POMDP 的无人机路径规划问题中，将目标的运动模型设为匀速直线模型，这种模型虽然较为简单，但是不能充分反映目标真实的运动规律，影响目标跟踪精度。IMM 算法能够将多个运动模型整合在一个系统中，提高跟踪算法对复杂机动目标的跟踪效果[23-26]。本节在 2.3.2 节研究的基础上，在POMDP 框架下建立基于 IMM 的无人机对复杂机动目标的自主跟踪路径规划模型。

基于似然函数，更新各个模型的匹配概率

$$
\mu _ { k } ^ { j } = p \big ( m _ { k } ^ { j } \big | z _ { k } \big ) = \frac { 1 } { c } \Lambda _ { k } ^ { j } \overline { { c } } _ { j }\tag{2-60}
$$

其中， $c = \sum _ { i = 1 } ^ { r } \Lambda _ { k } ^ { i } \overline { { c } } _ { i }$ 。

## (4) 估计融合

将各个 UKF 的滤波结果基于各自模型的匹配概率加权融合，得到系统的融合估计值，即

$$
\begin{array} { r l r } { \hat { \zeta } _ { k } = \displaystyle \sum _ { i = 1 } ^ { r } \hat { \zeta } _ { k } ^ { i } \mu _ { k } ^ { i } , } & { } & \\ { { \pmb { P } } _ { k } = \displaystyle \sum _ { i = 1 } ^ { r } \mu _ { k } ^ { i } \left[ { \pmb { P } } _ { k } ^ { i } + \left( \hat { \zeta } _ { k } - \hat { \zeta } _ { k } ^ { i } \right) \bullet \left( \hat { \zeta } _ { k } - \hat { \zeta } _ { k } ^ { i } \right) ^ { T } \right] } & { } & \end{array}\tag{2-61}
$$

根据上述 3 个步骤，路径规划模型的信念状态实现更新，即 $\pmb { \xi } _ { k } = \hat { \pmb { \zeta } } _ { k }$ $b _ { k } ^ { \zeta } \left( \zeta \right) = \mathrm { N } \left( \zeta - \xi _ { k } , P _ { k } \right)$ 。

综上，复杂机动目标的自主跟踪路径规划 POMDP 模型建立完成，为了实现路径规划POMDP 模型的在线求解，本文设计提出了有限行动集算法。

## 2.4 自主跟踪路径规划模型的有限行动集算法

受模型框架的特点限制，POMDP 模型的计算量较大，难以实时精确求解。首先，状态空间的不确定性增加了对状态估计的滤波计算，同时在计算代价值时还要进行基于状态分布的积分运算，如(2-49)式，相对于 MDP，这些过程增大了计算量。其次，与 MDP 一样，POMDP 模型是远视的决策模型，以未来长远的奖励或者代价为决策目标来计算当前的行动，远视的策略在带来较好的决策效果的同时也带来了较大的额外负担。因此，在实时决策的问题模型中，多采用近似算法对远期代价进行估计。

本章根据所建立的 POMDP 模型特点，基于蒙特卡洛法提出了有限行动集的算法来实时求解无人机目标跟踪的行动策略。

## 2.4.1 近似求解的思路

实时求解的核心工作是减小 POMDP 的计算量，有限行动集算法的思路就是从状态估计和远期代价的计算两个方面入手，做必要的近似和简化，减小行动值计算的计算量。

首先，在行动代价的计算方面，设目标不具备在较短时间内大幅度改变运动状态的能力，且所有数据关联正确，目标的代价函数计算可直接转换为对滤波状态协方差矩阵的迹的计算，即

$$
\begin{array} { l } { { C \left( b _ { k } , A _ { k } \right) = \displaystyle { \int \mathbb { E } _ { \eta _ { k + 1 } , w _ { k } } \left[ \left\| \boldsymbol { \zeta } _ { k + 1 } - \boldsymbol { \xi } _ { k + 1 } \right\| ^ { 2 } \big | \boldsymbol { x } _ { k } , \boldsymbol { \zeta } , \boldsymbol { \xi } _ { k } , A _ { k } \right] b _ { k } ^ { \boldsymbol { \zeta } } \left( \boldsymbol { \zeta } \right) d \boldsymbol { \zeta } } } } \\ { { \quad \quad = \boldsymbol { T } r \big ( P _ { k + 1 } \big ) } } \end{array}\tag{2-62}
$$

其次，对于以滤波得出的估计值 $\xi _ { k }$ 来计算远期代价，代替该状态的信念，避免了高维概率密度函数的积分运算，将(2-49)式 $J _ { _ { H } } = \mathbb { E } \left[ \sum _ { k = 0 } ^ { H - 1 } C { \left( b _ { k } , { A } _ { k } \right) } \right]$ 近似为$\boldsymbol { J } _ { H } \approx \sum _ { k = 1 } ^ { H } C \left( \boldsymbol { \hat { b } _ { k } } , \boldsymbol { A _ { k } } \right)$ 。在本章后续文中 $\hat { b } _ { \boldsymbol k }$ 等上标符号表示对基于当前滤波值对后续状态的预测。

## 2.4.2 算法流程

已知决策的行动空间 $A _ { k } = \left( a _ { k } , \varphi _ { k } \right)$ ，设 $a _ { k } \in \left[ a _ { \operatorname* { m i n } } , a _ { \operatorname* { m a x } } \right]$ $\varphi _ { k } \in \left[ - \varphi _ { \operatorname* { m a x } } , \varphi _ { \operatorname* { m a x } } \right]$ 计算最优行动策略即在行动空间中搜索最优的 $a _ { k }$ 和 $\varphi _ { k }$ ，计算公式如式(2-53)所示。为减少计算量，提高解算精度，有限行动集的方法将连续的行动空间转变为一个有限的行动集，即通过选取集合 $\left[ { \big ( } a _ { 1 } , \varphi _ { 1 } { \big ) } , { \big ( } a _ { 1 } , \varphi _ { 2 } { \big ) } , \cdots , { \big ( } a _ { N } , \varphi _ { M } { \big ) } \right]$ 将行动空间离散化，其中， $\left[ a _ { 1 } , a _ { 2 } , \cdots , a _ { N } \right]$ 和 $\left[ { \varphi _ { 1 } , \varphi _ { 2 } , \cdots , \varphi _ { M } } \right]$ 分别表示连续行动空间中 $a _ { k }$ 和 $\varphi _ { k }$ 的典型值。基于有限行动集的最优行动策略选择步骤如下：

步骤 1：选取 时刻的 $x _ { k }$ 和 $\left( \xi _ { \boldsymbol { k } } , \pmb { P } _ { \boldsymbol { k } } \right)$ 作为初始状态 $\hat { \bf x } _ { k } \ : , \ : \ : \ : \ : \hat { \pmb { \xi } } _ { k } \ : , \ : \ : \ : \hat { \pmb { P } } _ { k }$ ，并以概率$\mu _ { k }$ 最大的模型作为预测时限 内的运动模型。

步骤 2：将 $\hat { \pmb { x } } _ { k }$ 和 NM 个行动值分别带入式(2-27)，预测 NM 个行动值时在$k + 1$ 时刻的状态 $\hat { \mathbf { x } } _ { k + 1 } = \left\{ \hat { \mathbf { x } } _ { k + 1 } ^ { 1 } , \hat { \mathbf { x } } _ { k + 1 } ^ { 2 } , \cdots , \hat { \mathbf { x } } _ { k + 1 } ^ { N M } \right\}$ 。并将 $\hat { \pmb { \xi } } _ { k }$ $\hat { P } _ { k }$ 带入式(2-34)至式(2-46)得出协方差和 $\hat { \pmb { P } } _ { k + 1 } = \left\{ \hat { \pmb { P } } _ { k + 1 } ^ { 1 } , \hat { \pmb { P } } _ { k + 1 } ^ { 2 } , \cdots , \hat { \pmb { P } } _ { k + 1 } ^ { N M } \right\}$ 。并计算得到 NM 个行动值在 时刻的代价$\mathrm { c o s t } _ { k } = \left\{ T r \Big ( \hat { P } _ { k + 1 } ^ { 1 } \Big ) , T r \Big ( \hat { P } _ { k + 1 } ^ { 2 } \Big ) , \cdots , T r \Big ( \hat { P } _ { k + 1 } ^ { \ ' N M } \Big ) \right\}$ 。

步骤 3：预测目标状态 $\hat { \pmb { \xi } } _ { k + 1 } = { \cal F } \hat { \pmb { \xi } } _ { k }$ ，同时预测无人机 $k + 2$ 的状态和行动代价，并将累加预测的行动代价。

步骤 4：预测递推值 时刻，将各次预测的行动代价累加，建立如图2-7 所示的行动与代价相对关系树状结构图，至此，无人机状态预测空间和代价累加空间均包含 $N M ^ { H }$ 个元素。

步骤 5：找出预测代价最小的行动方案，沿图 2-7 中虚线所示向前回溯，当前状态下的最优行动值 $\boldsymbol { A } _ { k }$ 即为最优行动策略在 时刻的行动值。

## 2.6 本章小结

本章以实现无人机在被动探测机动目标的任务过程中的自主行动决策为背景，基于 POMDP 建模框架，建立了目标跟踪的路径规划模型。针对单一模型对复杂运动目标的跟踪效果不佳的问题，在 POMDP 模型中引入了 IMM 机制，建立的 IMM-UKF 方法能够有效提升目标跟踪效果和行动决策的质量。最后，为实现模型在线求解，提出有限行动集的方法来求解行动策略，实现了远视策略与在线规划的统一。较之于 NBO 算法，有限行动集的方法能够完成非线性条件下无人机的路径规划。仿真结果验证了本章所建立 POMDP 模型的有效性，无人机能够依靠探测的量测信息在线决策自身航路，保证对复杂机动目标的持续跟踪。

## 3 基于深度强化学习的单无人机智能空战机动决策研究

无人机智能空战研究中，机动决策是无人机实现空战的关键技术。在进行探测跟踪的过程中空战双方距离不断接近，随之进入机动占位阶段，即根据武器发射要求和双方的空间态势不断进行机动，寻求进入有利态势，在攻击对方的同时避免被对方攻击。该阶段最具对抗性，对飞行员决策的反应时间和机动策略的要求最高。传统的自主机动决策方法面临决策实时性和策略鲁棒性不足的问题，本章以强化学习为建模理论框架，系统分析了强化学习方法在无人机智能空战机动决策中的原理应用，建立了基于深度强化学习的无人机智能空战机动决策模型，设计了模型的训练方法，实现了单无人机空战对抗中的机动策略自主学习，为后续多无人机协同空战机动决策的研究提供理论支持。

## 3.1 引言

空战机动决策是飞行员根据对空战态势的理解和判断，操控飞机做出机动动作，从而在空战中占据有利态势，获得满足发射武器的火控条件的动态决策过程。自主机动决策是利用决策模型代替飞行员做出机动决策，是实现无人机智能化空战的关键技术。

如图 3-1 所示，受限于地面遥控操纵方式的实时性和抗干扰性，目前无人机尚无法执行空战任务。因此，将人工智能固化在无人机平台上，将决策中枢从地面移植到空中，让无人机在空战中的机动决策自主化成为无人机实现智能空战的有效途径。

<!-- image-->  
图 3-1 无人机决策模式的智能化

空战机动决策模型涉及对战双方在三维空间内的位置、速度以及武器状态条件，因此模型的状态维度较高，同时由于飞行的速度快，所以模型的动态性强，尤其在近距空战中，双方的态势变化更加剧烈，这些特点要求自主空战机动决策系统能够在庞大的状态空间中快速计算出合理的行动策略，对决策的实时性和策略的鲁棒性提出了较高的要求。在传统的空战机动决策研究中，基于优化方法和对策理论的方法难以对大规模的模型进行实时解算，基于专家系统的方法将人类的经验总结形成决策支持系统用以辅助飞行员决策，但是空战经验纷繁复杂且变换多样，这种方法提供的策略在难以覆盖状态空间的同时还面临着策略固化无法自我更新的问题，因而这些算法产生的机动策略不能适应复杂多变的无人机智能空战对抗过程。

本章提出了基于强化学习建立空战机动决策模型的方法，利用强化学习的自主“探索性”，从空战的对抗过程中针对对手的策略不断探索更新自身策略，实现自主机动占位。在研究过程中主要发现并解决如下几个问题。

首先，建立了空战机动决策的系统模型，给出了基于强化学习的空战机动决策模型框架，深入分析了各个元素的设计及面临的主要问题。基于设计的建模框架，采用模糊 Q 学习（Fuzzy Q Learning, FQL）进行了空战机动决策的实例化建模，在论证了建模方法有效性的同时，发现了传统强化学习方法在处理大规模连续状态问题时，由于状态维度爆炸导致的实时性不足的问题。

其次，针对这一现象，采用深度神经网络进行值函数的近似估计，构建了连续状态空间的空战机动决策强化学习模型，解决了空战机动策略在连续空间上的泛化问题，提高了决策实时性和鲁棒性。同时，针对深度强化学习决策模型训练过程中，由于空战环境状态空间大，奖励稀疏导致训练不收敛的问题，依据空战模型的特点，设计了强化学习训练方法，以提高强化学习的效率。

本章后续内容安排如下，首先介绍了单无人机智能空战机动决策框架，随后介绍了在此框架下分别基于传统强化学习中的 FQL 算法，深度强化学习中的DQN 和深度确定性策略梯度（Deep Deterministic Policy Gradient, DDPG）算法的机动决策建模方法。

## 3.2.1.1 飞机运动模型

飞机的运动模型是空战模型的基础，机动决策主要考虑空战双方在三维空间内的位置关系和速度矢量。因此，本文采用三自由度的质点模型作为飞机的运动模型。论文中对质点模型做如下假设：

(1)假设飞机为一个刚体；

(2)假设地球为惯性坐标系，即将地面坐标系看作惯性坐标，忽略地球自传及公转影响；

(3)忽略地球曲率；忽略攻角和侧滑角，假设速度方向与机体轴重合。

基于上述假设，飞机三自由度质点模型的参数定义如图 3-2 所示。

<!-- image-->  
图 3-2 飞机三自由度质点运动模型

在地面坐标系中，ox 轴取正东方，oy 轴取正北方，oz 轴取铅垂方向，则飞机的运动模型如(3-1)式所示。

$$
\left\{ \begin{array} { c } { \dot { x } = \nu \cos \gamma \sin \psi } \\ { \dot { y } = \nu \cos \gamma \cos \psi } \\ { \dot { z } = \nu \sin \gamma } \end{array} \right.\tag{3-1}
$$

在同一坐标系中，飞机的动力学模型如(3-2)式所示。

$$
\left\{ \begin{array} { c } { \dot { \nu } = g \left( n _ { x } - \sin \gamma \right) } \\ { \dot { \gamma } = \displaystyle \frac { g } { \nu } \big ( n _ { z } \cos \mu - \cos \gamma \big ) } \\ { \dot { \psi } = \displaystyle \frac { g n _ { z } \sin \mu } { \nu \cos \gamma } } \end{array} \right.\tag{3-2}
$$

在(−)式和(−)式中， 和 表示飞机在坐标系中的位置坐标， 表示速度， $\dot { y }$ 和z 表示速度 在三个坐标轴上的投影值。航迹角 表示速度与水平面 o-x-y 之间的夹角。航向角 表示速度向量在 o-x-y 平面上的投影 $\nu ^ { \prime }$ 与 oy轴之间的夹角。g 表示重力加速度。位置向量 $\pmb { p } = \left[ x , y , z \right]$ ，速度向量为$\pmb { \dot { p } } = \left[ \dot { x } , \dot { y } , \dot { z } \right]$ 。

$\left[ n _ { x } , n _ { z } , \mu \right]$ 是控制飞机进行机动的控制变量，则飞机的控制空间$\pmb { \varDelta } = \left[ n _ { \boldsymbol { x } } , n _ { \boldsymbol { z } } , \mu \right]$ $n _ { x }$ 是速度方向的过载，代表飞机的推力与减速作用。 $n _ { z }$ 表示俯仰方向的过载，即法向过载。 $\mu$ 是围绕速度矢量的滚转角。通过 $n _ { x }$ 控制飞机的速度大小，通过 $n _ { z }$ 和 $\mu$ 控制速度矢量的方向，进而控制飞机进行机动动作。
