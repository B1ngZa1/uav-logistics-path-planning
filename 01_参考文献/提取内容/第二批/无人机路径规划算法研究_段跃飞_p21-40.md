## 第二章 无人机路径规划理论

## 2.1 无人机路径规划基础

无人机路径规划是采用路径规划算法在规划区域内为无人机寻找一条从起点到终点的可行无碰撞路径，以实现预定的任务目标，如路径长度最短、任务完成时间最短等。路径规划过程一般遵循环境建模、路径规划两个步骤。

## 2.1.1 三维环境建模

在大部分应用中，无人机执行任务的环境信息是先验已知的。在开始路径规划之前，需要对环境进行建模，一个合适的环境模型可以有效地减少计算量。常见的三维环境建模方法有栅格法 [81]、几何法 [82] 等。

栅格法是最通用的单元分解建模方法之一，旨在将规划空间分割成众多相同单元体，能够较准确地描述三维空间的环境信息，获取障碍物的基本形状和细节。该方法具有实现简单快速、计算处理方便、精度可调节等优点，适用于各种规划空间的建模。但栅格法存在两方面缺点，一方面，规划空间增大、复杂度增加导致路径规划算法需要处理数量庞大的栅格数据，规划效率明显降低；另一方面，栅格地图中节点移动方向与栅格邻接状态相关，常见的三维立方体栅格地图中节点移动方向，如平面八叉树方向与垂直方向的共 10 方向、遍历所有邻近节点的 26 方向等，会导致规划路径常为对角线与直线的组合，并非最短距离，不能保证路径最优，在无障碍物环境中该缺点更加明显。

几何法旨在根据实际空间的尺寸、形状、边界情况及环境中物体特征，用点、线、面、体等几何体对规划空间及障碍物进行建模。几何法能够直观地对环境进行描述，进而获取到详细的环境信息与障碍物的特征，在建模中能达到很高的环境精度，且无人机在无障碍物自由空间的移动方向不受环境建模方法的限制，仅与无人机本身约束相关。该方法的不足之处是过于注重对环境信息的描述，在障碍物密集、布局复杂、障碍物存在不规则几何体难以处理的情况下，几何模型构建难度很大。

## 2.1.2 A\* 算法简介

作为一种典型的启发式路径搜索算法，A∗ 算法 [19] 求解最短路径问题具备高效性，目前该算法已被广泛应用于路径规划领域。A∗ 算法通过计算搜索区域内各节点的代价函数值，取代价最小点作为路径的扩展节点，直至抵达目标点，进而

构造最优路径。 $A ^ { * }$ 算法的核心代价函数公式表示为:

$$
f ( n ) = g ( n ) + h ( n )\tag{2-1}
$$

式中，n 为当前的路径点序号； $f ( n )$ 为当前路径点的总代价； $g ( n )$ 为无人机起点到当前路径点的实际代价， $h ( n )$ 为当前路径点到无人机终点的估计代价。容易看出，当实际代价 $g ( n ) { = } 0$ 时， $A ^ { * }$ 算法就退化成了贪心最佳优先搜索算法 [83]（GreedyBest First Search），能够以最快的规划速度抵达目标点；估计代价 $h ( n )$ 代表了算法的启发性部分，当 $h ( n ) { = } 0$ 时， $A ^ { * }$ 算法就退化成了 Dijkstra [84] 最短路算法，通过扩展大量节点的方式找到最短路径。

## 算法 2-1 传统 A∗ 算法

1 初始化 open list、close list，将起点加入 open list 中，计算代价函数值 f(S);

3 选择 open list 中代价函数值最小的点 n 为当前点;

5 找到目标点，从终点逐步追踪父节点，直至起点S，获取路径 $P ;$

7 else  
8 将点 n 插入 close list，并从 open list 中删除;

A∗ 算法结合了 Dijkstra 算法和贪心最佳优先搜索算法的优点，在获取到最优路径的基础上，采用启发式的思想，加快算法规划速度。 $A ^ { * }$ 算法进行路径规划时，核心是获取 open list 和 close list 两个列表，前者存放下一步搜索区域内的待扩展节点，后者存放已获取的路径点，及当前搜索过程计算 open list 各点代价函数选择出的最小代价点。通过迭代获取搜索区域内的最小代价点直至 close list 中存在无人机终点，即获取到了最优路径，其算法流程如上所示。

传统 A∗ 算法的路径性能指标为路径长度，根据环境建模方法不同，通常采用欧氏距离、曼哈顿距离、对角线距离之一作为度量。本文是在三维空间几何地图上进行路径规划，因此代价函数选择Euclidean距离。

## 2.2 TSP 问题概述

TSP问题 [85]，即旅行商问题是一个典型的组合优化问题。传统的TSP问题是指一个旅行商去 n 个城市旅行，该旅行商人从一个城市出发，经过所有城市且每个城市仅经过一次，最后返回出发的城市，要求总的行程最短。该问题以图论角度看，本质是在一个带权完全无向图上，其中顶点表示城市，边表示道路，权值表示道路长度，找一个总长度最小的 Hamilton 回路的问题。由于该问题可行解是所有顶点的全排列，随顶点数增加，组合爆炸式增长，是一个NP完全问题，可表示为以下的整数规划问题：

$$
\begin{array} { l } { \displaystyle \operatorname* { m i n } _ { i , j } \sum _ { i , j } c _ { i j } x _ { i j } } \\ { \mathrm { s . t . } \sum _ { j = 1 } ^ { n } x _ { i j } = 1 , \quad i = 0 , 1 , \ldots , n - 1 } \\ { \displaystyle \sum _ { i = 1 } ^ { n } x _ { i j } = 1 , \quad j = 0 , 1 , \ldots , n - 1 } \\ { \displaystyle x _ { i j } \in \{ 0 , 1 \} } \end{array}\tag{2-2}
$$

其中， $c _ { i j }$ 为图中一对城市 (i,j) 的道路长度， $x _ { i j }$ 商人从城市 i 离开是否访问城市 j，访问则取值为 1，否则为 0。目标函数表示回路的长度最小，约束 1、2 表示每个城市只能访问一次。

目前 TSP 问题的求解算法主要可以分为确定性算法、启发式算法两类。确定性算法能准确地求出最优解，但在往往仅用于小规模问题求解，面对规模较大的问题时会因计算量巨大而难以求出最优解，常见的确定性算法有穷举法、动态规划算法、分支定界算法等。启发式算法则常被用于解决大规模 TSP 问题，虽然不能求出最优解，但可以计算得接近最优的解，常用的的启发式算法有蚁群算法、遗传算法、k-opt算法、模拟退火算法等。因此目前TSP求解算法大多集中在启发式解法。

TSPN 问题 [86]，即带邻域的旅行商问题是 TSP 问题的一种变体，旅行商需要抵达城市的一定范围内即可认为经过该城市，是 NP-hard 问题。本文数据采集路径规划问题的目标是从异构无线传感器设备收集数据，考虑到异构传感器设备发射功率有限且不同，无人机必须飞得足够近以完成数据采集任务，因此该最优路径规划问题类似于 TSPN 问题。但本文数据采集路径规划问题的起点和终点不同，且均根据任务情况预先指定；由于异构传感器设备各自具有不同的传输功率，导致各节点通信半径不同。因此本文路径规划问题不能采用传统 TSPN 问题求解算法进行直接求解。

## 2.3 凸优化方法基础理论

凸优化 [87] 在各领域都有着广泛的研究与应用，对一系列非常困难的最优化问题，凸优化是一种强大的、计算效率高的求解方法。只要将一个非凸的问题转化为标准的凸优化问题就可以高效的进行求解，本小节将给出凸优化的相关基本概念和凸优化问题判别方式为后面的研究做准备。

## 2.3.1 凸集

对于任意的 $x , y \in C ,$ ，与任意的 $\lambda \in [ 0 , 1 ]$ 有:

$$
\lambda x + ( 1 - \lambda ) y \in C\tag{2-3}
$$

则集合 C 为凸集。简单来说，集合 C 内任意两点间的线段仍属于集合 C，则称集合 C 为凸集。常见的凸集有线段、凸多边形、超平面、圆形、椭圆、凸多面体、球、椭球等。

设 $C _ { 1 } , C _ { 2 } \subset R ^ { n }$ 是凸集， $a \in R$ ，则保证集合凸性的运算有：

（1） $C _ { 1 } \cap C _ { 2 } = \{ x \mid x \in C _ { 1 } , x \in C _ { 2 } \}$ 是凸集；

（2） $C _ { 1 } \pm C _ { 2 } = \{ x \pm y | x \in C _ { 1 } , y \in C _ { 2 } \}$ 是凸集。

设 $f \colon R ^ { n } \to R ^ { m }$ 是仿射函数，即

$$
f ( x ) = A x + b , A \in R ^ { m \times n } , b \in R ^ { m }\tag{2-4}
$$

若C为凸集，则存在：

（1） $f ( C ) = \{ f ( x ) \mid x \in C \}$ 是凸集；

（2） $f ^ { - 1 } ( C ) = \{ f ( x ) \mid x \in C \}$ 是凸集。

## 2.3.2 凸函数

设集合 C 是非空凸集，f 是定义在 C 上的函数，如果对于任意的 $x , y \in C , a \in$ (0, 1) 均有

$$
f ( \alpha x + ( 1 - \alpha ) y ) \leq \alpha f ( x ) + ( 1 - \alpha ) f ( y )\tag{2-5}
$$

则称 f 为 C 上的凸函数。简单来说，凸函数就是函数中任意两点的连线都在函数的上方。常见的凸函数有线性函数、二次函数、最小二乘函数、p 范数等。

由凸函数的性质有如下凸函数判别方式：

（1）一元函数 f(x) 是C上的凸函数的充要条件是：

$$
f ( y ) \geq f ( x ) + \nabla f ( x ) ^ { T } ( y - x ) , \forall x , y \in C\tag{2-6}
$$

（2）设 $C \in R ^ { n }$ 是非空开凸集，多元函数 $f ( x )$ 在 C 上二阶连续可微，则 $f ( x )$ 是C 上的凸函数的充要条件是 $f ( x )$ 的 Hessen 矩阵满足：

$$
\nabla ^ { 2 } f ( x ) \succeq 0 , \forall x \in C\tag{2-7}
$$

几种保证 $\ntrianglerighteq$ 函数的运算有：

（1）透视函数: 若 $f ( x )$ 为凸函数，则如下函数为凸函数，其中 $t > 0$ 。

$$
g ( x , t ) = t f { \binom { x } { t } }\tag{2-8}
$$

（2）凸函数的非负组合: 若 $f _ { 1 } ( x ) , \dots , f _ { m } ( x )$ 为凸函数，则如下函数为凸函数。

$$
g ( x ) = w _ { 1 } f _ { 1 } ( x ) + \ldots + w _ { m } f ( x )\tag{2-9}
$$

（3）凸函数求最大: 若 $f _ { 1 } ( x ) , \dots , f _ { m } ( x )$ 为凸函数，则如下函数为凸函数。

$$
g ( x ) = \operatorname* { m a x } \left\{ f _ { 1 } ( x ) , \ldots , f _ { m } ( x ) \right\}\tag{2-10}
$$

## 2.3.3 凸优化问题模型

一般的最优化问题定义如下：

$$
\begin{array} { l l } { \operatorname* { m i n } } & { f ( x ) } \\ { \mathrm { s . t . } } & { g _ { i } ( x ) \leq 0 , \quad i = 0 , 1 , \ldots , m } \\ & { h _ { i } ( x ) = 0 , \quad i = 0 , 1 , \ldots , l } \end{array}\tag{2-11}
$$

其中，min 是最小化 minimize 的缩写，s.t. 是约束于 subject to 的缩写，x 是未

知变量集合。

标准的凸优化问题要求目标函数 $f ( x )$ ， $g _ { i } ( x ) , i = 0 , 1 , \ldots , m$ 是凸函数， $h _ { i } ( x ) =$ $0 , i = 0 , 1 , \dots , l$ 是线性函数。即目标函数是凸函数，可行集

$$
S = \{ g _ { i } ( x ) \leq 0 , i = 1 , \ldots , m , h _ { i } ( x ) = 0 , i = 1 , \ldots , l \}\tag{2-12}
$$

是 $\ntrianglerighteq$ 集，则上述问题为 $\boxed { \amalg }$ 优化问题。简单来说就是在一组 $\ntrianglerighteq$ 的集合与仿射空间组成的可行域中求解目标函数最小值的问题。

综上所述，球形区域为凸集，求解球形区域距空间中一点距离的函数为凸函数， $\ntrianglerighteq$ 函数的非负组合也是 $\ntrianglerighteq$ 函数，因此本文的三点 $\ntrianglerighteq$ 优化问题是 $\ntrianglerighteq$ 函数。

## 第三章 基于 NTSP-TCO 的数据采集路径规划算法

## 3.1 引言

在无线传感器网络（Wireless Sensor Network，WSN）中，传统的多跳传输方式导致 Sink 节点周围的传感器设备在数据转发上相比其它的设备会花费更多的能量，这种数据采集方式很容易导致能量空洞，进而影响WSN的寿命和性能。随着无人机相关技术的进步，无人机具备了成本低、移动性高、部署灵活便捷、可建立 LoS 通信链路等优点，将其引入 WSN 中进行数据采集任务可有效解决上述的能量空洞问题。目前无人机的数据采集问题多集中于地面分布WSN中，本章聚焦于无人机对空间分布异构 WSN 进行数据采集时的路径规划问题，为使无人机能更快更高效地完成任务，需要对无人机的采集路径做出合理的优化，以最大化数据采集效率，减少能耗。考虑到任务中存在传感器设备通信半径较小，无人机需要悬停进行数据采集的情况，本章基于旋翼无人机进行进一步研究。

对于在WSN中采集数据的无人机，本章的目标是最小化其数据采集路径的长度以减少能耗，从相关无线传感器设备采集数据并保证数据尽快上传。因为传感器设备的发射功率是有限的，为保证能成功从传感器设备采集数据，无人机必须飞得离传感器设备足够近。因此，无人机在此种WSN中采集数据的最优路径规划问题类似于带邻域的旅行商问题，该问题是NP-Hard 的。

为解决上述问题，本节中设计基于 NTSP-TCO 的两阶段数据采集路径规划算法，解决无人机在空间分布的异构无线传感器网络采集数据的最优路径规划问题，算法的流程简图如图3-1所示。该方法设计了基于优化理论求解NTSP问题和TCO 问题的两阶段路径规划算法，以确保找出一条最短的路径来从所有相关的传感器设备中采集数据。首先制定并解决了一个不返回的旅行商问题，来获取无人机遍历所有无线传感器设备的最优路径。基于该遍历路径，迭代解决一系列的三点凸优化问题求取异构传感器设备的最优路径线段。最后用分析结果和仿真结果验证了所提方法的有效性。

## 3.2 系统模型构建

本节考虑采集空间的大小为 $a \times b \times c$ ，其中不含威胁源。设空间中存在单架四旋翼无人机，K 个无线传感器设备 $\mathbf { K } = \{ 1 , 2 , . . . , K \}$ 。设备在空间中随机分布并采集数据等待上传，且部署后其位置固定。给定无人机的起点 $q _ { s t a r t } = ( x _ { s } , y _ { s } , z _ { s } )$ 和目标点 $q _ { t a r g e t } = ( x _ { t } , y _ { t } , z _ { t } )$ 。设 $\left( x _ { k } , y _ { k } , z _ { k } \right)$ 为第k个无线传感器设备的位置坐标， $D _ { k }$ 为该设备的最大通信半径， $\forall k \in \{ 1 , 2 , . . . , K \}$ 0

假设本章的系统模型满足下列条件：

（1）无人机的速度是恒定的。设无人机的速度为 $V _ { \circ }$

（2）无人机在空间中有一个起点、一个终点和一个采集路径。

（3）无人机在发射阶段后飞行高度不固定。

（4）WSN 中的设备是异构的。每个传感器设备的传输功率、通信能力不同，即每个设备的最大通信半径不同。

对于使用无人机进行数据采集的问题，最重要的是高效的采集 WSN 的数据，保证数据的有效性。无人机通过采集路径，从 $\left( x _ { s } , y _ { s } , z _ { s } \right)$ 飞到 $( x _ { t } , y _ { t } , z _ { t } )$ ，并从索引为 $k \in \{ 1 , 2 , . . . , K \}$ 的无线传感器设备采集数据。因此本章的目标是找到一条高效的采集路径，由 $K + 2$ 个路径点组成的有序序列表示， $P = [ p _ { 1 } , p _ { 2 } , . . . , p _ { K + 2 } ]$ ，在保证设备成功上传数据的同时，最大限度地减小从无线传感器设备数据采集路径的路径长度。

考虑到 WSN 多被部署在空旷的区域，且无人机与无线传感器设备之间一般没有大面积遮挡，本章假设无人机与无线传感器设备之间的信道模型为 LoS 链路，其信道增益遵循自由空间传播模型，仅依赖于无人机与无线传感器设备的距离。设无人机与传感器设备 k 之间的距离为 $d _ { k }$ ，载波频率为 $f _ { c }$ ，光速为 c，LoS 链路的平均附加损耗为 $\eta _ { L o S }$ 。根据 LoS 信道模型，从无人机到无线传感器设备 k 的通信链路路径损耗 $L _ { L o S , k }$ 应为：

$$

设第k个无线传感器设备的发射功率为 $P _ { k }$ ， $\forall k \in \{ 1 , 2 , . . . , K \}$ ，单位是 dB。由于本章关注的是异构无线传感器网络，因此 $P _ { k }$ 的值是不同的。设无人机成功解码无线传感器设备 k 处数据的接收信噪比阈值为 $\Gamma _ { k }$ ，单位为 dB。设背景噪声功率为$P _ { n }$ ，单位为dB。为了让无人机能够成功解码来自无线传感器设备k的数据，应有：

## 3.3 无人机数据采集的节点路径规划算法 NTSP-TCO

容易发现，当采集半径 $R _ { k } > 0 , \forall k \in \{ 1 , 2 , . . . , K \}$ 时，上述优化问题类似于TSPN 问题，而当 $R _ { k } = 0 , \forall k$ 时，该问题类似于传统的 TSP 问题。TSP 和 TSPN 都是 NP-Hard 问题，但存在有效地逼近算法和现代的软件工具来对其进行求解。然而相较于一般的 TSPN 问题，本文的优化问题在如下两方面有所不同，即无人机具有不同的起点与终点、异构传感器设备采集半径不同，无法直接进行求解。因此本文设计了基于 NTSP 和TCO 问题的两阶段算法 $\mathrm { N T S P - T C O }$ 。

NTSP-TCO 算法将上述问题分为如下两个阶段进行求解。

## 3.3.1 NTSP 问题

本文首先制定了一个不返回的辅助 TSP 即 NTSP 问题并设计了该问题的求解算法，计算获取无人机对空间中所有无线传感器设备的遍历路径，确保无人机能够对所有设备完成数据采集任务。

已知空间中存在 K 个无线传感器设备 $\mathrm { ~ K ~ } = \{ 1 , 2 , . . . , K \}$ ，考虑到还有起点、终点、以及一个虚拟节点，因此该 NTSP 问题共存在 K + 3 个节点。具体来说，虚拟节点 virtual node 对应虚拟设备，不存在具体坐标，起始节点 S 对应起点$q _ { s t a r t } = ( x _ { s } , y _ { s } , z _ { s } )$ ，目标节点 T 对应终点 $q _ { t a r g e t } = ( x _ { t } , y _ { t } , z _ { t } )$ ，节点 A、B 对应无线传感器设备 $k , \forall k \in \mathrm { K }$ 。

由此可知，在 NTSP 的可行解中，无人机从虚拟节点 virtual node 出发，访问起始节点、目标节点及 K 个无线传感器设备对应节点，然后返回该虚拟节点，期间无人机只遍历每个节点一次。为保证无人机能够从起始节点 S 遍历无线传感器设备相应节点后抵达目标节点 T，起始节点 S 应是虚拟节点 virtual node 之后第二个访问的节点，而目标节点T是无人机倒数第二个访问的节点。于是就得到了NTSP问题的 $( K + 3 ) \times ( K + 3 )$ 维节点转移代价矩阵，见表3-1：
