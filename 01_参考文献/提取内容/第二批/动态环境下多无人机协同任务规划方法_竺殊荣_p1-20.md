## 摘要

在现代战争中，无人机开始以机群方式协同执行任务。通过研究动态环境下的多无人机任务规划方法，可以使机群以较小的代价完成复杂的任务，提升机群执行任务的成功率和效率，增强无人机机群的容错性、鲁棒性。对无人机任务规划方法的研究主要包括任务规划模型的建立和任务规划算法的运用，现有的任务规划模型缺乏对战场约束条件的考量，不适应实际的需求。任务规划算法的计算效率过低，对动态情况响应不足。这些问题的存在降低了无人机机群的安全性和生存能力，并导致机群执行任务的失败。

针对上述问题，本文首先对任务规划中的任务分配与重分配问题进行了描述与建模。分析了多无人机协同任务分配的约束条件，对现有的无人机多任务分配问题模型(CMTAP)进行了扩展，建立符合战场需求的任务分配模型。当无人机在执行任务过程中遇到突发情况需要进行任务重分配时，对无人机机群的任务分配方案进行局部调整，建立了任务动态重分配模型。

在任务分配与重分配模型的基础上，本文接着提出了基于自组织特征映射（SOM）神经网络的任务分配方法，根据战场环境信息进行网络的初始化并结合SOM 神经网络中的 Kohonen 规则和 Winner Take All 规则求解任务分配方案。针对重分配问题提出了基于分组策略的任务动态重分配方法，采用基于 SOM 神经网络的聚类算法对需要进行重分配的任务和无人机进行分组聚类，分组完成后使用引入精英蚁群策略的蚁群算法对执行任务集合更改的无人机进行任务序列的调整，该方法能够快速响应无人机机群执行任务过程中遇到的突发情况。

仿真实验以及与同类算法的比较分析表明：本文提出的多无人机协同任务分配方法能够在较短时间内得出合理有效的任务分配方案；本文提出的无人机路径规划方法提升了无人机在动态环境下的适应能力，为无人机规划出能够避开威胁区域且飞行距离较短的安全飞行路径。

关键词：无人机，任务规划，任务分配，任务重分配，路径规划

## Abstract

Unmanned Aerial Vehicle (UAV) plays a key role in battlefield intelligence gathering, reconnaissance, electronic interference and firepower strike. In modern warfare, UAV often perform tasks in a cooperation way. The tasks planning method of multi-UAV in dynamic environment can increase the efficiency of executing tasks and make the UAV fleet fulfil complex task at a small cost. The research on task planning of multi-UAV mainly includes the establishment of the task planning model and the application of task planning algorithm. The existing task planning models lack the consideration of battlefield constraints and fail to meet the actual requirements. Moreover, the calculation cost of task planning algorithm is too expensive and the response to dynamic situation is not timely.

Aiming at the above problems, we first research the description and modeling of task planning. We analyze the constraints of cooperative task assignment of multi-UAV, expend the existing cooperative multiple task assignment problem (CMTAP) model to meet battlefield requirements. When UAV fleet encounter emergency during task execution, we establish a dynamic task reassignment model and make local adjustment to task assignment scheme.

Based on the model of task assignment and reassignment, we then research the cooperative task assignment and reassignment method of multi-UAV. We propose a task assignment method based on Self-organizing Feature Map (SOM) neural network. This method initializes the SOM neural network based on the battlefield information and combines learning rules of SOM neural network to solve the task assignment problem. We also propose a task reassignment method based on grouping strategy, we use a cluster algorithm based on SOM neural network to cluster the tasks that need to be reassigned and adopt an ant colony algorithm to adjust the task sequence of UAV fleet.

Finally, A UAV path planning method based on Q-learning in dynamic environment is proposed. According to the characteristics of path planning problem, we establish the Markov Decision Process (MDP) model. Based on the MDP model, the combination of Q-learning algorithm and eligibility traces technology is adopted to

plan a flight path for UAV that could avoid threat area.

The result of simulation experiment and the comparison with other algorithms show that the cooperative task assignment and reassignment method of multi-UAV proposed in this paper can obtain a reasonable and effective task assignment scheme, and can respond dynamically to various emergencies encountered by the UAV fleet. The path planning method of UAV proposed in this paper improves the adaptability of UAV to dynamic unknown or partially unknown environment.

Keyword: UAV, task planning, task assignment, task reassignment, path planning

## 第一章 绪论

## 1.1 研究背景与意义

由于无人机(Unmanned Aerial Vehicle, UAV)具有智能化、功能多样、操作灵活等特点，在军事领域得到了大量的应用。在现代战争中，无人机起着情报收集、重要区域控制、监视和打击重点目标等关键作用[1-3]。随着无人机执行任务的环境日益复杂，任务种类的多样性也随之增加，而单架无人机的能力有限，很多国家和机构将研究重心投入到多无人机协同执行任务方面。

多机协同任务是指多架无人机协同执行复杂的任务。在多无人机机群中，每架无人机担负着不同角色，每架无人机可执行一个或多个子任务，通过无人机之间的相互协作和决策，完成单架无人机无法完成的任务，提升无人机作战效能。无人机机群在协同执行任务时具备以下优势：

（1） 系统鲁棒性：无人机机群具有智能自主协同、适应能力强等特性，编队中的个体并不依赖于某个中心节点来运行。在作战过程中，当部分无人机由于突发情况失去作战能力时，整个无人机机群仍具有一定的完整性，可以继续执行作战任务。

（2） 功能分布化：将整个战场环境下所需要完成的各项任务如情报侦察、监视、火力打击与毁伤评估等分发给低成本、功能单一的无人机执行，通过大量的异构无人机协同完成复杂任务，使得无人机机群具有可观的作战能力。

（3） 费效收益比：费效比关注的是投入费用和产出效益的比值，功能单一的无人机制造周期短且造价低。在执行作战任务过程中投入大数量的无人机个体，而敌方采取应对措施时需要消耗数十倍甚至上百倍的成本，这将给我方带来巨大的费效收益优势。

无人机协同作战的概念在军事领域得到大量理论研究和实验验证。2016 年美国空军正式提出《2016—2036 年小型无人机系统飞行规划》，希望构建横跨航空、太空、网空三大作战疆域的小型无人机系统，并在 2036 年实现无人机系统集群作战。基于无人自主技术，美军提出了利用微小型无人机集群作战的模式，以降低作战成本，提升作战行动的灵活性。典型项目如DARPA的“小精灵”无人机，计划研制一种部分可回收的侦察和电子战无人机集群，从敌方防御范围外的大型战斗平台如运输机、轰炸机上投放，利用无线网络实现通信与协同，通过影响导弹防御、通信与内部安全，甚至利用电脑病毒袭击敌方数据网络等方式压制敌方。

此外，美国海军还在“低成本无人机群技术”项目下开展了相关技术研究，利用小型筒式发射无人机组成无人机群压制对手[4-5]。

在民用领域，无人机机群同样具有优势，无人机协同工作技术的应用可以在科研、监测、农业植保、环保、送货等众多领域带来经济效益。目前很多企业采用无人机机群进行快递的配送，特别是在物流发货的高峰期，需要多无人机协同技术的支撑，使得无人机顺利完成配送。在农业领域，无人机机群的应用已经从无人机农药喷洒逐渐扩展到无人机农业信息采集、农业光谱数据分析等领域。农业应用的无人机机群，将帮助农民绘制农田中的杂草地图从而提高作物产量。

我国目前也在大力推行无人机协同技术的发展，在 2017 年 7 月国务院发布的《新一代人工智能发展规划》中指出应借助人工智能重点突破自主无人系统相关共性技术、核心技术，将人工智能与无人机机群紧密融合，支撑无人机集群应用和产业发展。

引导无人机机群协同执行任务的关键技术就是多机协同任务规划，多机协同任务规划在保证无人机机群安全指数最大化的基础上，使得机群以较小的代价完成复杂的任务。高效的协同任务规划方案能够极大提升机群执行任务的成功率和效率，并降低风险和成本[6]。而在实际应用中，环境空间具有动态性、不确定性等特点，任务规划的方案也会随时发生变化，所以研究自组织、自适应能力强的动态环境下的任务规划方法能够提升无人机机群对突发事件的响应能力，提升无人机机群的容错性、鲁棒性。

国内外学者对多无人机机协同任务规划问题进行了大量的研究，并取得了丰硕的理论成果。随着战场规模越来越庞大，无人机执行任务的类型越来越多样化，约束条件越来越多，目前的任务规划技术存在着模型与实际环境不符，算法的执行效率过低，动态环境下算法的响应能力不足等缺点，所以只有对目前的技术不断改进，才能顺应无人机技术发展的潮流。本文采用的具体的任务规划流程如图 1.1 所示。首先收集战场信息，然后进行任务规划问题的分析与建模，采用任务分配算法求解得到无人机执行任务的序列，根据任务序列进行无人机航迹规划。当无人机编队在执行任务的过程中遭遇突发情况时，使用任务重分配方法对局部无人机任务序列进行调整，并对任务序列改变的无人机重新进行路径规划，直到无人机机群任务执行完成，整个规划过程结束。本文依据上述流程，从多机协同任务规划问题的建模、多机协同任务分配、多机协同任务重分配、无人机路径规划这四个层面对动态环境下的多机协同任务规划展开研究，并对当前存在的问题提出解决方案。

## 1.2 国内外研究现状

## 1.2.1 无人机协同任务分配与动态重分配研究现状

多无人机协同任务分配基于战场环境中的各种约束条件，为无人机机群中的无人机分配一个或者多个任务，并确定无人机执行任务的次序，任务分配是多无人机协同任务规划的重要组成部分，也是实现无人机机群协同作战的前提[7]。在分配过程中，要充分考虑到任务的类型、任务间的时序约束，无人机可执行的任务类型、作战能力、有效载荷等因素，以全体任务的完成效率达到最优为目标，将作战任务合理地分配给无人机机群[8]。所以，多无人机协同任务分配问题是多约束条件下的组合优化 NP 问题[9]。该问题求解的关键是任务分配模型的建立和分配算法的使用。

任务分配的具体模型包括多旅行商问题(MTSP, Multiple Traveling Salesman Problem)[10-11]、混合整数线性规划(mixed integer linear programming, MILP)模型[12-13]、车辆路径问题(VRP,Vehicle Routing Problem)[14-15]。ZORLU[16]考虑了无人机载荷约束，将问题建模为有载荷约束的 CVRP 模型。Shima T 等人[17]提出了无人机多任务分配问题模型(cooperative multiple taskassignment problem ,CMTAP)，将任务类型分为识别、攻击和毁伤评估，并在模型中加入了任务间的时序、任务的执行时间、多机协同约束等。苏菲等[18]在 CMTAP 模型的基础上，引入了动态任务时间约束和无人机任务能力的约束，建立了扩展的多机协同任务分配模型。夏令儒等[19]对 MTSP 进行路径和时间的优化，建立了 MTSP 数字规划模型。王正[20]在 MILP 模型的基础上，对多基地异构多无人机多任务分配问题进行了改进 MILP 建模。姚敏等[21]设计了一种适应于多无人机、多任务目标、多任务种类的无人机群协同多任务分配模型。GuerrieroF[22]考虑每个任务的开始时间、结束时间，将问题建模为有软时间窗口约束的 VRP 问题(VRP-STW)。

在任务分配建模完成后，需要设计具体的算法进行求解。解决任务分配问题的算法主要分为最优化方法和启发式方法。匈牙利算法是一种最常用的最优化方法，谷稳[23]提出了基于匈牙利算法的无人机目标分配问题解决方案，柳毅等[24]将匈牙利算法推广至多目标分配中。此外，文献[25][26]采用 MILP 方法进行多无人机目标分配求解，其它最优化方法还包括动态规划、图论等。最优化方法能够求出问题最优解，但其求解的代价随着问题规模的增大而呈几何级增长，导致求出最优解的时间消耗过长。而启发式方法在求解时耗和求解质量之间进行折中，目的是在一定时间范围内得出问题的满意解[27]，是目前国内外学者的研究重点。群算法包括蚁群算法、粒子群算法等是目前应用较多的启发式方法，这些算法模拟的是自然界中鸟类、昆虫、鱼类的集群行为。李炜[28]采用混合整数线性规划方法构造优化函数，并利用粒子群算法求最优解。孙小雷等[29]采用路径航程作为任务分配过程全局目标函数的输入，采用与任务协同相匹配的粒子结构进行改进粒子群优化任务分配迭代寻优。文献[30]使用蚁群算法求解多约束条件下的任务分配问题，文献[31]改进了蚁群算法的信息素更新规则，并解决了多机器人任务分配问题。文献[32][33][34][35]中也都采用了各种群智能算法求解任务分配问题。

多机协同任务动态重分配是在任务分配完成后，无人机机群在执行分配到的任务的过程中，碰到无人机故障、任务取消等突发情况时，需要对任务规划结果进行动态调整，以适应环境的变化，所以动态重分配对算法的实时性要求较高。赵敏[36]采用分布协同拍卖的目标分配算法研究了突发机制下的多类型无人机任务重分配。吴敏尔[37]针对多无人机任务重分配问题提出一种基于监督的顺序拍卖机制。胡雄超[38]结合无人机森林灭火的实例，设计了两种动态任务再分配算法。许书诚[39]提出了改进的 K 均值聚类算法对无人机任务重分配问题进行初步分组，并在此基础上提出了分合粒子群优化算法进行组内任务分配。崔亚妮等[40]在 Leader-Follower编队结构下，充分考虑了无人机编队执行当前任务队后续时敏目标时间窗口的影响，提出了一种多无人机时敏任务动态分配算法。杨尚君等[41]提出一种从任务层次上解决多无人作战飞机的动态任务分配问题的方法，并利用混合细菌觅食算法进行解决。

近年来许多学者将自组织特征映射(Self-organizing Feature Map，SOM)神经网络应用到多智能体任务规划中。Anmin Zhu[42]等人利用基于 SOM神经网络的算法将多机器人系统的任务分配与路径规划结合进行求解，并使机器人能够在目的地确定之前就开始移动，此方法容易导致机器人在多个目标点之间迂回，且未考虑机器人自身约束条件。在文献[43]中，Anmin Zhu在原有算法的基础上进行了改进，在算法中考虑的每个机器人当前的行进方向。Z. HENDZEL等人[44]基于 SOM 神经网络提出了一种机器人路径导航方法，但该方法的研究对象为单个智能体。WM Shen 等人[45]基于 SOM 神经网络提出了一种生物启发控制模型，用于多机器人系统的任务分配和执行，但此方法未考虑多机器人间的协同，且不适用于任务数较多的场景。朱大奇[46][47][48]等人利用 SOM 神经网络针对水下机器人的任务分配与路径规划问题进行了一系列的研究。有关 SOM 神经网络的研究多是针对于多机器人系统的控制，大多数方法仅考虑了智能体与目标之间的距离约束，未考虑智能体自身的约束、任务的约束等，且利用 SOM 神经网络进行多无人机协同任务规划的研究较少。

## 1.2.2 动态环境下的无人机路径规划研究现状

动态环境下的无人机路径规划是在环境信息未知或部分未知的情况下，采用算法为无人机规划出从起飞位置到目标位置的最优路径，并使无人机能规避诸如雷达、极端天气、敌方阵地等威胁区域[49][50]。

基于马尔可夫决策过程的强化学习方法如 Q 学习算法、SARSA 算法等利用奖励函数和状态转移策略逐步进行战场区域的探索和预测，通过自主学习过程提高智能体处理复杂未知环境的能力，因此常被用于求解动态环境下的智能体路径规划问题。文献[51]在 Q 学习算法基础上增加一层学习过程，对环境进行深度学习，并成功应用于多障碍物环境下移动机器人路径规划。文献[52]提出一种基于标称控制的监督式强化学习算法，并将其用于机器人的路径规划当中。文献[53]建立了一种基于 Q 学习的无人驾驶船舶路径规划模型，该方法可在未知环境中规划出较优路径并成功避让多个障碍物。文献[54]利用 Kohonen 网络对连续外部环境进行聚类的内部状态表示，并提出了基于 Kohonen 网络的 Q 学习强化学习算法。文献[55]采用一种自适应随机探索方法结合强化学习完成无人机导航和避障任务。文献[56]在 Q 学习的回报函数中引入回报成型技术，提出一种有效的无人机三维航迹规划算法。文献[57]结合 RBF网络设计了一个状态连续-动作连续的Q学习应用框架，并利用算法进行机器人自主避障。

## 1.3 研究内容及创新点

目前，国内外的学者对多无人机协同任务规划问题的研究十分普遍，在任务规划模型的

建立和任务规划算法的应用方面有很多成果。但是，目前的研究还存在以下问题：

（1） 在建立符合条件的任务分配模型如 MTSP 模型、CVRP 模型时，为满足模型的标准而忽略了实际战场的需求，所建立的模型对任务分配的目标和战场约束条件进行了简约化处理，降低了研究成果在实战中应用中的效果。

（2） 现有的任务分配模型中无人机和任务的类型多是单一的，缺乏对异构无人机属性和多任务类型的考量。现有的无人机编队中的无人机在用途、载荷、作战能力等方面各不相同，在实际作战中，往往需要多种类型的无人机之间进行协同才能完成某一任务，因此基于单一无人机种建立的任务分配模型不支持复杂任务的情况。

（3） 现有的某些任务规划算法计算结果准确但是时间代价过大，在实际战场中的应用价值往往是很低的，所以算法应该在一定时间范围内得出任务规划的结果，并具备对突发情况的响应能力。

（4） 动态环境下的信息是部分未知甚至完全未知的，而现有的算法往往需要获取全局环境信息，随着环境不确定性的增加，算法效率将大大降低。

针对目前研究存在的问题，本文的主要内容有：针对问题(1)和问题(2)，在现有模型的基础上考虑更复杂的战场约束条件，进行多机协同任务分配与动态重分配的问题描述与建模。针对问题(3)，研究自组织、自适应能力强的 SOM 神经网络在多无人机协同任务分配与动态重分配问题求解中的应用。针对问题(4)，研究动态环境下基于Q学习的无人机路径规划算法，为无人机规划一条能够避开威胁区域的较优路径。

本文的创新点如下：

（1） 扩展了多机协同任务分配的模型，并采用基于 SOM 神经网络的方法进行任务分配。

在任务分配建模时对 CMTAP 模型进行扩展，增加了约束条件集合，引入无人机的武器载荷约束并在任务类型中引入巡航任务，由于巡航任务有起点和终点，建立了非对称任务分配模型，使模型更贴合实际环境的要求；采用基于 SOM神经网络的算法进行任务分配方案的求解。并对基于SOM神经网络的算法进行了改进，在网络初始化时充分考虑了任务分配问题的特性，并将 SOM 神经网络的两条学习规则结合用于优胜邻域的选取和网络权值的更新，由于SOM神经网络网络结构简单高效、具有自适应能力且不需要任何先验知识，可以得到分配时间与总分配代价较优的分配方案。

（2） 采用聚类分组策略进行多机协同任务动态重分配，使用基于 SOM 神经网络的聚类算法进行聚类，再使用引入精英蚁群机制的蚁群算法对分组内的任务次序进行调整。

本文提出的动态重分配方案共分为两步。首先采用基于 SOM 神经网络的聚类算法对需要进行重分配的任务集合和无人机集合进行聚类，并对聚类算法的初始类簇中心、优胜邻域的半径和权值更新规则进行了设计。然后通过在蚁群算法中引入精英蚂蚁策略，将局部更新规则与精英蚂蚁信息素更新规则结合，进行无人机执行任务顺序的调整。结合这两个步骤，得到具有动态响应能力的动态重分配方法。

（3） 基于 Q 学习与效用追踪技术进行动态环境下的无人机路径规划。

首先根据无人机自身约束条件和路径规划问题的特性建立了马尔可夫决策过程(MarkovDecision Process，MDP)模型。在MDP 模型的基础上，基于Q学习算法进行无人机路径规划，无人机通过与环境的不断交互，不断改进自身行为，且Q学习对环境信息未知的情况有较强的适应性，能够为无人机规划出一条避开威胁区域的较优飞行路径。在Q学习中引入效用追踪技术，重点关注对最终路径规划结果有较大影响力的航路点和无人机飞行动作，提升了 Q学习算法的收敛速度。将 Boltzmann 策略与轮盘法结合用于无人机飞行动作选择，有效平衡了探索和利用，提高了算法获取最优策略的速度。

## 2.1.1 多无人机协同任务分配建模流程

多无人机协同任务分配建模是任务分配的重要步骤，任务分配算法需要在任务分配模型的基础上进行求解。建模流程如图 2.1 所示，任务规划系统首先接收上级下发的任务集合，然后进行任务分解，将任务集根据任务类型分解为一个个可分配给无人机执行的子任务。同时对战场信息进行收集，包括无人机当前坐标、任务点坐标、威胁区域信息等。在完成任务分解和战场信息收集这两个准备工作后，进行问题的建模，建模包括问题描述、设定约束条件、建立目标函数三个步骤。建模完成后，可以采用合适的分配算法进行求解，并得出任务分配的方案。

本文在 CMTAP 模型的基础上，综合考虑了异构无人机执行包含多种任务类型的任务集合的情况，扩展了约束条件，建立了满足无人机飞行安全和任务需求的多无人机协同任务分配模型，且使得建立的模型更符合战场的需求。

## 2.1.2 多无人机协同任务分配任务集分解

随着各国对无人机研发力度的不断加大，各式的新型无人机层出不穷，单架无人机的性能越来越来强大，能够完成的任务种类也越来越多样。但是在实际战场中，很多复杂任务是单一无人机无法做到的，而异构无人机的协同作战是无人机技术发展的重要趋势，编队中的每架无人机各司其职，达到互补的效果，更能提升编队完成任务的效率，并充分发挥无人机协同工作的效能。为了达到这个效果，在任务分配模型建立前，需要对下发的作战任务集进行分解，将任务集合分解为适合单架无人机完成的子任务。

<!-- image-->  
图 2.2 任务集分解图

任务集分解图如图 2.2 所示，本节根据多无人机协同作战的战场环境特点，进行任务类

型分解，将无人机的作战任务分解为侦察、巡航、打击这 3 类。

侦察任务：无人机在战场上执行侦察任务是其最主要的用途，携带摄像头和传感器的无人机可以对目标区域进行数据采集，通过高精度设备辨别目标并确定目标点位置。实时战术侦察无人机上载有数据传输设备，可以将侦察获得的图像进行信息处理后实时传回地面指挥站，为指挥站决策提供情报。

巡航任务：由于战场环境瞬息万变，通过安排无人机在多个重要目标点之间来回遍历飞行，能够快速感知环境中新的威胁信息并迅速发现战场态势的变化，从而将感知到的信息传回给指挥站，提升了紧急情况下指挥站的应急响应效率。巡航任务有巡航起始点和巡航终止点，若有一个巡航任务i，其它任务j 到该巡航任务的距离用 ${ \mathrm { d } } _ { \mathrm { i j } }$ 表示，那么 $\mathrm { d _ { i j } } \neq \mathrm { d _ { j i } }$ ，所以本文建立的任务分配模型为非对称模型。

打击任务：现代军用无人机具备携带和发射武器的能力，且拥有十分可观的作战能力，可以对目标点实时精确打击。比如美国的 MQ-9 型无人机上装载了空地导弹、小直径炸弹等一系列具有强打击能力的武器。由于无人机的载重量限制，所以在任务分配建模时需考虑到不同型号的无人机的武器载荷量。

## 2.1.3 多无人机协同任务分配问题描述

本文以多无人机联合执行对敌方作战任务为背景，将任务集分解为侦察任务、巡航任务和打击任务，战场中所要执行的任务的数量为 $\mathrm { N _ { T } }$ ，可执行任务的无人机的数量为 $\mathrm { N _ { U } }$ 。多机协同任务分配问题可用四元组{U,T,M,R}表示，其中 U 表示无人机的集合，T 表示任务的集合，M 表示任务类型的集合，R 表示约束条件的集合。

定义战场中可作战的无人机集合 $\mathrm { U = \{ U _ { 1 } , U _ { 2 } , . . . , U _ { N _ { U } } \} }$ ；任务的集合为 $\mathrm { T } { = } \{ \mathrm { T } _ { 1 } , \mathrm { T } _ { 2 } , . . . , \mathrm { T } _ { \mathrm { N } _ { \mathrm { T } } } \}$ ；任务类型用集合 M 表示， $\scriptstyle \mathbf { M } = \left\{ \mathbf { S } , \mathbf { A } , \mathbf { E } \right\}$ ，其中 S 表示侦察任务，E 表示巡航任务，A 表示攻击任务，对每个作战目标需要执行侦察、攻击、巡航中的一个或多个任务。

对于任意的 $\mathrm { T } _ { \mathrm { i } } \in \mathrm { T }$ ，定义 $\mathrm { R _ { T _ { i } } } { = } \{ \mathrm { M _ { T _ { i } } , ~ } \mathrm { Q _ { T _ { i } } } \}$ 表示任务 Ti 的约束条件。其中 $\mathbf { M } _ { \mathrm { T _ { i } } } { \in } \mathbf { M }$ ，表示任务类型约束，规定每种任务只能有一种任务类型。 $\mathrm { Q _ { T _ { i } } }$ 表示任务点需投放的武器数量，当且仅当$\mathrm { M _ { T _ { i } } } \mathrm { = } \{ \mathrm { A } \}$ 时， $\mathrm { Q _ { T _ { i } } }$ 不为 0，而将侦察任务和巡航任务的 $\mathrm { { Q _ { T _ { i } } } }$ 置为 0。

对于任意的 $\mathrm { U } _ { \mathrm { i } } \in \mathrm { U }$ ，定义 $\mathrm { R _ { U _ { i } } = \{ D _ { U _ { i } } , M _ { U _ { i } } , P _ { U _ { i } } \} }$ 表示无人机 $\mathrm { U } _ { \mathrm { i } }$ 的自身约束条件，包括无人机最大航程约束、无人机可执行的任务类型约束和无人机武器载荷约束。其中， $\mathrm { D } _ { \mathrm { U } _ { \mathrm { i } } }$ 表示无人机
