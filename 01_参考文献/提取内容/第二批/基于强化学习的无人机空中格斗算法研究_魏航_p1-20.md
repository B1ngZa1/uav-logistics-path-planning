## 摘 要

随着无人战斗机在军事领域上的应用越来越广泛，世界各国都在下大力气研制无人机，无人战斗机的出现也将改变未来的空战态势，成为决定战场的重要力量。在这其中，无人机的智能化水平将是无人机技术发展的关键，未来的无人战斗机将不仅能够通过传感器感知状态信息，区分敌我目标，还能够根据不同的作战任务，进行空战决策。空战决策理论经过近几十年的发展，逐步形成了以专家系统、微分对策为主的传统方法和以神经网络、遗传算法、蚁群算法为代表的智能方法。本文主要研究了基于强化学习的无人机空中格斗算法，主要做了以下几个方面的工作：

一是对强化学习的基本理论做了详细的介绍，通过强化学习算法的对比分析，指出了当前强化学习研究面临的一些困难和问题，同时对强化学习的应用领域做了介绍。

二是以强化学习的经典算法以及现阶段研究热点为依据，以强化学习系统中涉及的策略、值函数、回报函数等要素为核心，改进了算法性能。首先通过添加一个动机层，通过这一层，将先验知识引入到强化学习中，形成状态映射到动机、再从动机映射到动作的两层映射关系，提高了收敛速度。随后又采用模拟退火算法进一步提高了算法的性能。

三是以空中格斗决策为重点，完成了 RBF 神经网络的动机引导强化学习算法的设计，通过对比不同决策意图下的飞行轨迹，验证了算法的有效性。

关键词：无人战斗机；强化学习；动机引导；空中格斗

## Abstract

With unmanned combat air vehicles in the military field is applied more and more widely, the research is developing in the world. UCAV will completely change the future air combat situation, has become an important force in the battlefield. The intelligent level of UCAV will be the key to the development of UCAV Technology. The UCAV will not only be able to load information through the sensors, but also participate in air combat. The air combat decision-making theory has been developed in recent decades.It has gradually formed two methods, one is expert system, differential game, etc.,and the other is neural network, genetic algorithm and so on, etc.In this paper, we will use reinforcement learning to solve the air combat decision-making,the main work is as follows:

First, this paper introduces the basic principle of reinforcement learning algorithm, studies on the typical reinforcement learning algorithm,introduces the application field of reinforcement learning.

Scend, based on the research hotspot and the classical of reinforcement learning, improve algorithm performance.This chapter introduces the motivation layer, the two layer structure is changed into three layers structure, the prior knowledge introduces to the reinforcement learning algorithm, improved the speed of algorithm. Then, the idea of simulated annealing algorithm is introduced,the performance of the algorithm is proved by experiments.

Third, focus on the air combat decision, on the basis of neural network,the motivation guided reinforcement learning algorithm is designed.The effectiveness of the algorithm is verified by comparing the flight trajectory of different decision intention.

Keywords: Unmanned Combat Air Vehicles, Reinforcement Learning, Motive Guidance, Air Combat

## 第 1 章 绪 论

## 1.1 课题研究背景

无人战斗机，简称 UCAV[1]，英文全称是 Unmanned Combat Air Vehicles，是一种新型的空中武器，它不但能执行空中侦查任务，还能够攻击地面目标，甚至进行空中作战。UCAV 出现以后，世界各国都对 UCAV 在未来战场上的应用抱以很大的期望，也都十分重视 UCAV 的发展。无人机首次出现在人们的视野前还是在 1933 年，当时，无人机是以“空中靶机”的形式出现，第二次世界大战后，特别是越南战争以来，无人机在战场上的作用逐渐显现，以美国为首的西方国家以及中、俄等国都在无人机的研制上投入了大量的人力、物力、财力。

起初，无人机在战场中主要发挥其机动性好、飞行高度高、隐身能力强的特点，以执行战场侦查、监视任务为主，一方面能节省成本，另一方面也能减少伤亡，以最小的代价掌握战场环境、敌方部署等信息。上个世纪 90 年代以来，伴随着控制工程技术的发展，特别是在电子技术和航空技术不断变革的背景下，无人机的续航能力不断提高，功能进一步完善，威力也逐渐增强，在现代战争中的地位也越来越突出。现代无人机也由早期执行战术任务为主，逐步向战略任务渗透，成为空中战场上不可或缺的一支力量。2001 年，捕食者无人机在阿富汗战争中执行了对地攻击和精确打击任务，这也是无人战斗机首次在实战中扮演攻击者的角色，就取得了出乎意料的效果。2003 年，美国再次操控捕食者无人机实施了一次“斩首行动”，击毙了“911”事件头号主犯阿布-阿里。在随后的伊拉克战争中，美国投入了 4 架全球鹰、20 架捕食者以及其他各种尺寸、航程的无人机达 60 架，渗透到了战争进行的全过程，这些无人机一方面能够执行常规的低空拍照侦查任务，另一方面还能在敏感地区执行对地精确打击任务，大显神威。以至于美国的军事专家认为：UCAV 代表了未来军事科技发展的新趋势，美国军队也将享受 UCAV 带来的效益，它已经具备了重塑战争的能力[2]。

随着 UCAV 在实战中的应用，国外军事强国也都看到了 UCAV 的重要性，都十分重视 UCAV 的发展，下大力气研发无人机，对无人机的使用也呈现出多元化的趋势，而美国无论从投入还是产出方面，都遥遥领先于其他国家。2009年，美国空军对外发布了《2009 年至 2047 年无人机发展规划图》，并在此后的每隔两年，都根据技术的进步、任务需求的变化，更新发展规划，及时调整方向。美国根据无人机执行任务的不同，将无人机分为 5 大类（详见表 1-1）。这份报告同时指出，UCAV 的研制将是美国空军未来 40 年的一项核心任务，无人机将在战场上逐步取代有人驾驶飞机，担负起对地打击、空中格斗等任务，将主导未来战场上制空权的争夺，“无人化空战”有望成为将来空中战场的主要模式。

其实早在 1993 年，美军就已经意识到了 UCAV 的重要性，提出了一系列的预研报告，为以后的无人机发展规划奠定了坚实的基础[3]。1997 年，美国国防部高级研究计划局（DARPA，也称先进研究计划局）首次在报告中使用了“无人战斗机（UCAV）”一词，并且认为未来的无人机应具备空中压制和攻击能力。同年，美国空军启动了 UCAV 的研制，并成立了相关实验室，以波音公司的 X-46A 为研究对象，验证了 UCAV 执行空中打击任务的可行性。2000 年，美国的海军同样也开始了无人战斗机的研究，目的是让其能够配合航母作战，并且使用格鲁曼公司研制的 X-47A 做了技术可行性验证。2005 年，美国陆军开始实施“灰鹰”项目，目的是为每个陆军作战师装备一个长航时察打一体无人机系统连。

近年来，美国将无人机高效用于战场的愿景正逐渐成为现实，美国陆军充分认识到了无人机的重要性，在 2012 年 ，成立了“灰鹰”（图 1-1）无人机系统满编连，也叫 F/227 连，编制 128 人，装备有 12 架 MQ-1C 灰鹰（Gray Eagle）无人机和相关地面站。美国陆军无人机项目负责人蒂莫西·巴克斯特上校认为：

从试飞的情况看，“灰鹰”无人机具备了足以改变战场规则的能力。“灰鹰”的续航能力、有效载荷都较前辈 “捕食者”（Predator）无人机有了较大的提升，作战半径 400km，最大载荷 360kg，可以携带 4 枚“地狱火”导弹，作战能力、生存能力大幅提升。

从无人机的发展可见，UCAV 的出现将彻底改变未来的空战态势，未来的空中作战将有可能以无人机为主，随着 UCAV 性能的提升，其在战场上发挥的作用也将不单单是战场侦查与监视，更多的应该是执行对地攻击、防空火力压制甚至是空中格斗等任务，逐步完成从常规的侦查平台到作战平台的转换。也就是说，具备自主空战能力的无人机将是未来军用无人机研究的重点，这也就要求无人机能够具备评估战场态势的能力，并生成相应的机动命令，自主执行作战任务。

UCAV 的智能化水平，是未来军用无人机能否控制战场的关键。首先，UCAV 应当具备分析空中、地面战场，正确识别敌我目标，并完成攻击任务；其次，UCAV 要装备强有力的信息系统，及时和友方作战单元进行交互，主动解决在空中飞行时遇到的问题，逐步减少对地面系统的依赖；第三，UCAV 将演变为一个平台，控制器、无线电、传感器、武器等都可以像电脑配件一样，根据任务功能的不同，即插即用。

在战场上，制空权的争夺是一次战斗的核心，而空中格斗是能否取得制空权的关键，也是现今世界各国军事训练的重点。在未来的空中战场上，将会出现无人机格斗，那时，UCAV 的智能化水平也将直接影响其在战场上效能的发挥。与有人作战飞机一样，无人战斗机空中格斗也需要尽快找到优势区域，以完成火力摧毁的目的。一对一格斗是空中格斗基础，能够体现 UCAV 在特定环境下的性能、战术动作的运用，是空中格斗技术研究的关键。

## 1.2 国内外研究现状

## 1.2.1 空战决策理论研究现状

无人战斗机的空战决策是指 UCAV 在空战环境中，通过感知状态信息，自主生成机动指令，及时准确地进行战术动作选择，是 UCAV 智能化水平的核心。我们可以将空战决策分为两大类，一类是以微分对策和专家系统为代表的传统方法，另一类是以神经网络、遗传算法、影响图法、蚁群算法、人工免疫系统等为代表的智能方法[4]。

微分对策理论将无人机空中格斗问题演化为追逃博弈问题，无人机机动的目标是指在格斗过程中，远离敌方危险区域，并且尽量使敌方进入自己的武器射程范围之内。Raivio[5]等人采用定性的方法，通过划分无人机状态空间，研究不同区域内的无人机机动；Ehtamo 等人[6]将机动的极值作为控制变量，定量分析了双机格斗的机动决策过程；Lachner 等人[7]通过最优必要条件，在三维空间内研究了导弹对飞机的攻击过程。但从目前的研究看，微分对策模型同实际空中格斗的差距较大，应用较为困难。

影响图法近些年发展较为迅速，对于不确定性问题，可以用影响图的方法来求解和表示。影响图是一个无环有向图，由若干个节点和节点之间的有向连接（有向弧）组成，影响图中的节点表示需要解决问题的变量，有向弧指的是图中各个节点之间的相互联系。Virtanen 等人[8]在空战模型中加入了飞行员（指挥员）的偏好、经验等先验知识，基于影响图的方法，利用贝叶斯网络感知战场态势，建立了空战决策模型；Virtanen[9]又在单层影响图的基础上，构造了多级影响图，用来解决空战决策问题，提升了影响图在复杂问题上的应用能力。尽管影响图法能够有效利用先验知识、较直观地表示空战态势，但仍很难得到解析解，目前只能在预测控制理论的基础上，求得近似最优解。

专家系统也是人工智能领域中常用的方法，正如它的名字一样，这个系统需要有大量的先验知识，也就是说系统中预先设置了很多专业领域的知识，这些知识通过一定的规则来影响系统做出判断，形成决策。基于专家系统的空战决策模型研究以美国国家航空航天局（NASA）支持开发的 AML（AdaptiveManeuvering Logic）模型为代表，根据飞行员模拟飞行时得到的数据，利用 IF-THEN 规则，在知识库中建立规则集，实现对作战飞机的控制与仿真，并在训练、作战飞行仿真中得到了应用，取得了不错的效果。但 AML 也有一些明显的缺点，因其规则库的建立过程比较复杂，且需要不断调试，面对瞬息万变的作战环境，AML 系统采用的规则集很难覆盖所有的空战情境。

遗传算法以生物进化理论中的自然选择为模型，模拟了自然界中的进化过程。自从 1975 年 Holland 提出该算法后，经过多年的发展，在优化控制、信号处理等问题上得到了广泛的应用，是解决随机搜索问题的有效方法。Smith等人[10]以 GA 算法为基础，设计了一个分类器系统，它通过模拟进化过程产生最优解，用一条规则表示一个个体，用来指导无人机的行为，在一定条件下实现了未知空战环境的决策。尽管遗传算法利用规则库，理论上能应用于所有的空战环境，但遗传算法中涉及的编码方案、评价函数以及遗传方式等都需要主观设定，智能化程度仍有待提高。

人工免疫系统[11]也是一种解决优化问题的智能算法，它通过模仿免疫学原理，将免疫学中的抗原、抗体、以及抗原与抗体之间的关系类比为需要解决问题中的目标函数，最优解以及目标函数和优化解之间的关系。John 等人基于该算法思想将“问题-方案”进行归类，给出了免疫机动算法（TIMS）的流程。TIMS 算法结合免疫学原理，不断增强系统的记忆功能，以便为今后再次遇到这种问题时，能够采用合适的方案。该方法具备一定的自学能力，但不容易控制收敛速度，且预测模型较为单一，需要进一步的改进。

人工神经网络[12]以其优良的自学能力和存储能力，能够快速找到优化解，也是解决空战决策问题较为常用的方法。比较经典的是 Roger 等人结合 BP 神经网络，建立了机动决策模型，通过把当前和之前的空战态势作为输入量，以机动决策指令为输出，较好地解决了飞行中的机动决策问题。

从我国决策理论的发展上看，一些学者开始了 UCAV 空战决策算法的研究，也取得了一系列的成果。例如，郭昊[13]等人以对策论（博弈论）为基础，通过建立 UCAV 在攻击阶段产生的对策模型，给出了一种 UCAV 空战自主决策算法，该算法将风险判断引入对策论中，根据态势函数，做出合理的决策。并通过仿真实验结果表明，该算法能够使 UCAV 及时根据环境变化调整机动动作，占据有利位置。张涛等人[14]在双机空战环境中，通过构建人工势场函数，利用人工势场确定 UCAV 重点机动方向，最后利用粒子群算法寻找最优机动动作，从而完成空战机动。孙永芹等人[15]利用多级影响图对策方法，构建了三维空战模型，通过与微分对策模型的仿真结果做对比，结果显示，多级影响图模型要优于微分对策模型。

## 1.2.2 强化学习研究现状

强化学习，国外称 Reinforcement Learning，也有人翻译为增强学习、激励学习，是人工智能技术（AI ，Artificial Intelligence）的一个重要研究领域，它最早在上个世纪60年代由Minsky等人提出。但在该算法提出后的十余年里，尽管强化学习技术吸收了生物学界的响应定律，通过试错的方式学习，但很多研究都把强化学习当做监督学习的一种，并不是一种独立的学习方法。Widrow等人在 1973 年分析了强化学习与监督学习的不同点，指出强化学习需要不断试错，利用环境的反馈信号来影响以后的学习过程，通过迭代找到一种隐藏结构，或者是环境和动作之间的映射关系，而监督学习的基础是有样本参照的，它需要一个指导信号，根据样本误差修改输出参数的权值。进入上个世纪 80年代，伴随着计算科学的发展，强化学习的计算问题得到了解决，掀起了强化学习研究的新高潮。1983 年，Barto 等人提出了 AHC 算法，通过设计一个控制器和一个评价器，构造了强化学习系统，并在倒立摆模型中做了验证。此后，萨顿对 AHC 算法做了改进，并在 1988 提出了强化学习的经典算法，TD 差分算法。随后的 1992 年，沃特金斯等人给出了 Q 学习算法，更重要的是，他们还证明了 Q 学习算法的收敛性。TD 差分算法和 Q 学习算法的提出，也标志着强化学习理论发展进入了新的阶段，直到现在，有关强化学习的研究都以这两种算法为基础。

当前，尽管强化学习的探索和实践得到了科学家们的重视，做了很多工作，也取得了不少成绩，但仍面临很多问题。例如，以试错为基础的强化学习有时间上的延迟，回报函数的设计带有很强的主观色彩，且不太容易利用先验知识改进策略。从最近十余年强化学习研究的成果来看，面对复杂问题，强化学习的研究重点仍是所面临的维数灾难以及探索与利用的平衡问题。

为了应对强化学习系统中面临的维数难题，科学家们做了很多尝试，从目前的情况看，对状态空间进行抽象和泛化起到了比较好的效果。泛化是指当强化学习中的智能体不能遍历空间中的所有状态动作对时，通过一定范围的学习和记忆[16]，采用一定的方法对值函数和策略进行逼近，进而能够利用已知状态动作对的值近似得到其他未知的状态动作对的值。

根据逼近器的结构，值函数逼近可分为两种，一种线性的，一种是非线性的。非线性值函数逼近以人工神经网络为代表，蒋国飞等人[17]把强化学习和人工神经网络相结合，研究了倒立摆的控制问题。另外，也有一些学者将神经网络和模糊推理相结合，建立模糊神经网络来逼近值函数，程玉虎等人[18]基于 RBF 网络，同时又结合模糊规则，在动作选择前，设置了模糊规则，通过调整网络参数，达到自适应学习的目的，并且将该模型用到了倒立摆系统的控制上，通过动态调整网络节点，使得倒立摆的平衡控制能力较强。Duan 等人[19]采用支持向量机（LSVM）算法，设计了一个能够在线学习的逼近器来逼近值函数。线性值函数逼近相对于非线性值函数逼近来说，形式简单，使用方便，得到的应用也更为广泛。比较常用的逼近函数有模糊规则基函数[20]、傅里叶基函数[21]、高斯径向基函数等。线性值函数逼近需要对基函数的参数进行调整，参数估计的方法也很多，比较常用的有最小二乘法[20]、主成分分析法、贝尔曼误差法[22]等。在不同的应用环境中，选择不一样的基函数将直接影响逼近效果，需要根据应用特点，选择基函数，并选用适当的方法调整参数。近年来，一些能够自动选择基函数的方法也被提出，如后继表示[23]、相关分析[24]、时间近邻[25]、流行表示[26]、基于图的基函数等。

另外，除了函数逼近方法外，Singh 等人提出了状态聚类法来减少状态空间，也就是相近的状态归结为一个状态。使用该方法虽然减少了状态空间，但由于状态聚类后，系统将不具有马尔科夫性质，算法可能不收敛。Moriarty 等人[27]改进了状态空间的搜索策略，在局部有限状态空间中找到最优策略，但该方法容易陷入局部最优。此外，分层强化学习通过将任务进行分解，可以得到泛化的目的。

探索与利用的平衡问题也是强化学习研究的重点。强化学习系统中的智能体一方面为获得较高的奖励，需要选择奖励值高的动作，即利用；另一方面，由于奖励值高的动作在实际中并不一定是最优。因而为了得到更好的效果，需要对更多的动作进行尝试，尤其是在开始阶段，即探索。因此，在强化学习过程中需要不断探索，才能找到最优策略，但与此同时，探索是和效率密切相关的，智能体在系统中探索的过多，效率也会降低。因此对于强化学习探索策略，需要尽可能做到探索和利用的平衡，贝叶斯模型、近似效用模型以及间接选择法是探索策略设计的常用方法。

贝叶斯模型将已知的概率密度参数，通过获得先验概率，然后利用贝叶斯公式给出概率估计。强化学习和贝叶斯理论的结合在于，它能够让智能体依据已知的信息或者是刚刚得到的信息，通过贝叶斯公式，根据概率的大小决定采用什么样的策略，也就是确定是否采用已经得到的最优值相对应的动作。Dearden 等人[28]在 Q 学习中引入信息决策思想，结合重采样技术，给出了贝叶斯动态规划算法，加快了收敛速度。Sorg 等人又对贝叶斯理论做了改进，提出了近似贝叶斯策略，在一定程度上解决了传统贝叶斯 Q 学习方法采样复杂的难题，使得基于贝叶斯的策略选择可以被用作大规模或者连续状态的问题中。Asmuth 等人基于蒙特卡洛树（Monte-Carlo tree）前向探索，利用稀疏采样的方法，给出了基于近似贝叶斯强化学习算法的流程[30]。

近似效用算法思想并不强调最好的回报，算法的目标是尽量减少“差”的动作，是一种强调稳妥的方法。这类探索算法一般将环境分为已知和未知两类，设定一个标志，智能体需要在能接受的代价下探索环境。Brafman、Alexander等人都对近似效用方法进行了研究。

间接选择法利用玻尔兹曼分布、 方法等方法，在动作选择时，利用一定的规则，让系统采用一定的概率进行随机探索，是目前比较常用的方法。

## 1.3 本文的主要研究内容

本文将以强化学习算法的研究为核心，针对传统强化学习算法中不能有效利用先验知识的难题，将标准 Q 学习的状态到动机的二层映射，转变为动机引导 Q 学习状态-动机-动作的三层映射，另外采用神经网络逼近 Q 值函数，并且用模拟退火算法的思想对强化学习过程进行了优化。

各章节的具体安排如下：

第一章绪论。这一章介绍了课题的研究背景，并对空战决策理论和强化学习的研究现状做了简单的介绍。

第二章强化学习理论。在这一章中，将重点介绍强化学习的相关知识，首先以马尔科夫模型为切入点，介绍了强化学习理论模型、基本原理和基本组成要素；其次介绍基于策略值函数迭代的 TD 算法、基于状态动作值函数迭代的Q 学习算法等一些经典的强化学习算法；最后，对强化学习在优化问题、机器人、调度控制等领域的应用做了简单的介绍。

第三章动机引导强化学习算法设计。这一章的重点工作是改进标准的 Q学习算法，在改进算法的过程中，通过对强化学习算法过程进行分析，从强化学习的结构和策略选择两个方面改良标准的强化学习算法。首先在算法结构中添加一个动机层，用来引入先验知识和 Agent 的意图，这样就将标准 Q 学习由状态到动作的映射，转变为先通过状态映射到动机，再由动机引导动作执行，通过动机引导，加快了学习速度。接下来，在 Q 学习算法的探索策略上引入了模拟退火算法的思想，在解决探索和利用平衡问题上取得了比较理想的效果。最后，通过仿真实验将本章提出的基于模拟退火的动机引导强化学习算法与 动机引导强化学习算法和单纯的 Q 学习算法在 Agent 路径规划问题上做了对比实验。

第四章基于强化学习的无人机空中格斗算法研究。这一章主要以 UCAV空中格斗为应用背景，对无人机空中格斗算法做了研究。首先定义了一个态势感知器，用来获取格斗双方的状态，然后根据无人机的运动学方程设计 UCAV的机动动作生成器，最后基于 M-SA-Q 算法，结合 RBF 神经网络，设计了基于 RBF 神经网络的动机引导强化学习算法，并将该算法用到了 UCAV 自主决策中。

## 第 2 章 强化学习理论

## 2.1 强化学习及其理论基础

强化学习（Reinforcement Learning），又称激励学习[29]，是机器学习方法的一种，它借鉴了心理学、生理学、控制科学、运筹学、统计学、生物学、神经网络等众多学科的研究成果，是各学科综合运用的结果。能够与环境交互是强化学习的一个重要特点，它的学习过程是以尝试错误的方式进行的，通过不断的尝试，逐步找到合适的策略。该方法非常接近人类或动物学习的本能，在机器人智能控制、预测分析、控制调度等问题上有着非常多的成功实践，至今仍是人工智能领域最活跃的分支之一。

## 2.1.1 马尔科夫决策过程模型

马尔科夫决策过程（MDP），它是强化学习研究的理论基石，MDP 过程是一种随机过程，该模型能够提供一种非常简便的表达方式，对于解决序贯决策问题（Sequential Decision）十分有效。MDP 过程所研究的系统处在一个不断动态变化的过程中，它首先假设对于MDP 过程的任一时刻 $t ~ = ~ t _ { 1 } , t _ { 2 } , \cdots t _ { n - 1 } , t _ { n } \cdots , ~ \mathrm { t _ { n } }$ 时刻对应的状态仅仅和在这个状态出现前的一个时刻的动作和状态有关。一个马尔科夫决策过程可以用一个六元组 $\left. S ; A ; P ; R ; \gamma ; V \right.$ 来表示，其各部分组成元素的含义如下：

（1）S表示 MDP 过程的系统状态空间，也称环境空间，它是由马尔科夫决策过程中所有可能出现的状态组成的集合，状态的数量是不可知的，可以是有限集合，只要满足非空条件即可；

（2）A表示MDP 过程可选的动作空间，例如，对于系统中的某一状态 $i \subset S$ A i( )指的是智能体在状态i处所有可能的动作集合；

（3）P表示 MDP 过程的状态转移概率， $P ( { \mathrm { s } } ; { \mathrm { a } } ; { \mathrm { s } } ^ { \prime } ) \in [ 0 ,$ 1]指的是在 MDP 过程中，选择动作a概率，使系统由一个状态 s 转换到另一个状态 $s ^ { \prime }$ ，在这个系统中，任意一个状态所对应的动作集合的状态转移概率相加应该是 1。

$$
P ( s ; a ; s ^ { \prime } ) = \operatorname* { P r } \{ s _ { t + 1 } = s ^ { \prime } | s _ { t } = s , a _ { t } = a \}\tag{2-1}
$$

（4）R 代表 MDP 过程的回报函数， $R ( s , a , s ^ { \prime } )$ 指的是智能体选择一个动作并执行后所获得奖励值，s 、 $s ^ { \prime }$ 分别表示动作执行前和动作执行后智能体的状态。

$$
R ( s ; a ; s ^ { \prime } ) = E \{ r _ { t + 1 } | s _ { t } = s , a _ { t } = a , s _ { t + 1 } = s ^ { \prime } \}\tag{2-2}
$$

（5） 表示 MDP 过程的折扣因子，是一个 0\~1 之间的实数，能够控制 MDP过程的学习速率。

（6）V表示 MDP 过程决策优化目标函数（准则函数），反映了当前状态下选择某一动作后的累积回报（奖励），这也体现了马尔科夫过程的连续性。

平稳马尔科夫决策过程是指状态转移函数 P 和回报函数 R 只与系统的状态有关，与决策发生的时刻和顺序无关。平稳 MDP 过程需要考虑累积奖励的期望（也被称为状态值函数），可以采用的目标函数 V有三个：

（1）无限折扣总回报模型：

$$
V ^ { \pi } ( s _ { t } ) = E _ { \pi } ( R ( s _ { t } ) ) = E _ { \pi } ( \sum _ { k = 0 } ^ { \infty } \gamma ^ { k } r _ { t + k } ) \qquad 0 < \gamma \leq 1\tag{2-3}
$$

从公式（2-3）可以看出，无限折扣总回报模型中采用这个决策后所有状态的奖励值作为估计模型， 表示折扣因子， $\gamma = 0$ 时，只考虑当前的奖励值。这个模型比较接近系统的实际状态，也是较为常用的值函数计算方式。

（2）有限状态总回报模型：

$$
V ^ { \pi } ( s _ { t } ) = E _ { \pi } ( R ( s _ { t } ) ) = E _ { \pi } ( \sum _ { k = 0 } ^ { n - 1 } \gamma ^ { k } r _ { t + k } )\tag{2-4}
$$

该模型只把该决策状态后 n个状态的奖励值作为估计模型，从公式（2-4）可见，当状态数趋向无穷大时，有限状态总回报模型也就可以看成无限状态总回报模型，但这个模型有可能发散，并不实用。

（3）平均回报模型

$$
V ^ { \pi } ( s _ { t } ) = E _ { \pi } ( R ( s _ { t } ) ) = E _ { \pi } ( \operatorname* { l i m } _ { n  \infty } \frac { 1 } { n } \sum _ { k = 0 } ^ { n } \gamma ^ { k } r _ { t + k } ) \qquad 0 < \gamma \leq 1\tag{2-5}
$$

强化学习目标是在模型未知的 MDP 过程中找到一个策略 $\pi ^ { * }$ ，也就是找到一个从状态集合到智能体可以选择的动作集合的映射关系，使得折扣总回报的值最大。强化学习需要研究的是在事先不知道系统的状态转移概率，并且也不知道系统报酬函数的前提下，求解状态值函数。当然，最优策略也有可能不唯一，但只要其值函数相同，在状态动作选择后取得的总的效果应该是一样的。如果强化学习模型的 $V ^ { \pi } ( s )$ 已知，最佳策略值函数为：

$$
V ^ { \ast } ( s ) = \operatorname* { m a x } _ { \pi } ( V ^ { \pi } ( s ) ) \quad \quad \forall s \in S\tag{2-6}
$$
