(a)参数编码;

(b)初始种群的设定；

(c)适应度函数的设计；

(d)遗传算子的设计；

(e)终止准则以及结果的解码;

(f)控制参数的设定。

主要实现流程框图以及相应的步骤主要如下[34].

1)编码以及初始化。定义编码和染色体表示，对需要设计的进化代数进行变量的设置。然后进行代数计数，设置起始值 $k = 0$ ，设置种群群体规模，需要进行计算的进化代数M，以及交叉概率和变异概率。由此形成了初始种群 $p ( 0 )$ ，其个体均随机产生；

2)个体评价。计算初始个体的适应度；

3)终止条件判断。若 $k > M$ ，则按照当前种群个体对应的适应度值进行判断选择，根据适应值的不同，选择具有最大适应度对应的个体，以此作为最优解输出，进而就可以终止计算，否则转到步骤4)；

4)遗传操作。对群体P(k)进行遗传操作，由此生成 $P ( k { + } 1 )$ ，再令 $k = k + 1$ ，转至步骤2)。

## 2.1.2 遗传算法核心步骤

## (1)编码

遗传算法是通过特定的编码机制将待解决的实际问题进行抽象概括，将问题中的参数抽象编译为特定的并且有序的符号串。目前主要的编码方式有二进制编码和实数编码，还有其他的一些编码方式如格雷码编码，排列编码等[35]。但是编码方式和策略的选择是取决于具体需要解决的问题，不同形式的编码方式会对后续的遗传算子产生不同的影响，但是总的原则是编码的方式是要有利于研究问题的。

## (2)适应度函数

适应度函数是遗传算法进行进化选择的唯一的标准，它可以判断对应的解的质量。设定适应度函数需要对实际待求解的问题进行合理的分析与判断。适应度函数是遗传算法选择操作的依据，如何设定将直接影响到遗传算法的效率[36]。对于解决单目标的寻优问题，可以利用目标函数来直接设计对应的适应度函数。

## (3)确定选择机制

选择机制的确定不仅要考虑保持种群的多样性，同时还要能够加快算法的收敛速度，其参照的是个体适应度值。选择策略决定了从父代种群中选择哪些基因个体遗传进化到子代种群中，最常用的选择策略就是轮盘赌选择机制[37]。

设群体的大小为n，个体i的适应度值记作 $f _ { i }$ ，则个体i选择遗传到下一代的的概率可记为 $p _ { i } = f _ { i } / \sum f _ { i }$ 。这样所有个体的概率相加为1，以累计概率构造一个圆盘，根据每个个体被选择的概率把一个圆盘分为N份，其中第i个扇形的圆心角是 $2 \pi p _ { i }$ 弧度。轮盘选择时产生一个[0,1]区间内的随机数，该随机数在哪一个扇形区域，就选择该扇形区域对应的个体进入到子代种群中。当一个个体在种群中越优的时候，它在轮盘中所占扇形的圆心角就越大，被选中遗传到下一代的概率越大。轮盘赌选择策略的特点是：种群中所有个体都可能被选择，只是个体适应值越高，其被选择的概率就越大，其示意图如图2.3所示：

## (4)遗传操作

使用遗传算法解决实际问题时，首先产生初始化种群，对种群中的每个个体求其适应值，再经过相应的遗传操作，从而实现适者生存的进化过程。遗传算法通常采用选择、交叉、变异三个遗传操作[38]。

1)选择：即上文所说的轮盘赌选择法。

2)交叉：将父代种群中的个体两两配对，以交叉概率交换其部分基因染色体。交叉操作在遗传算法中起核心作用，能够大大提高算法的搜索能力。

3)变异：将父代种群中的个体以变异概率改变某个或某些基因染色体。

## 2.2深度强化学习理论

## 2.2.1 强化学习

强化学习是机器学习的一种，主要应用于智能控制机器人以及数据分析和预测等多个领域[39]。在本质上，强化学习就是探索在有奖罚的环境下，如何确定智能体当前状态与动作之间的关系。确定这样的关系时，智能体就可以知道如何能获得最大的奖赏。在强化学习过程中，通过与外部环境进行交互，智能体通过采取的动作会引起外部环境状态的变化，并根据设定的评估标准进行奖励或惩罚(也称为强化信号)。智能体根据自己所得的奖励或处罚调整策略并继续重复此学习过程，直到任务完成。所以，强化学习是一种典型的奖惩式学习[40]，是一种强适应性的学习方法。

<!-- image-->  
图2.4 强化学习模型图

智能体在当前状态下采取某一个动作用于环境，环境接受该动作后会导致状态发生改变，同时产生一个强化信号反馈给智能体[41]。如图2.4所示，智能体在当前状态下采取一个动作α，环境接受该动作后就从状态s改变为状态s'，同时智能体接收到环境反馈的强化信号r。

本文所用的强化学习中除了智能体与环境，还包括以下几个元素：

1)状态集合 state：表示智能体当前所处环境的可能；

2)动作集合action：表示智能体所有可行的动作；

3)强化信号 $r _ { s s ^ { \prime } } ^ { a }$ ：表示智能体通过采取动作 $a$ 从状态s转移到 $s ^ { \prime }$ 所得到的即时奖励。是由环境提供的对智能体采取动作的好坏作的一种评价

4)策略 policy：表示状态和动作之间的映射关系，表示智能体在某个状态下应采取什么样的动作。

强化学习的主要任务就是通过智能体在环境中不断地尝试，根据所获得的反馈信息调整策略，最终生成一个较优的策略。智能体根据这个策略便可以在当前状态下采取最佳的动作，即状态与动作的最佳映射，这就是状态-动作值函数[42]。

强化学习中有很多算法，其中Q-learning 算法是强化学习中一个重要里程碑[43]。Q-learning算法是智能体不知道整体的环境，通过分析计算每个状态采取不同动作所得的Q值来决定智能体应该采取的策略。计算公式如(2-1)所示：

$$
Q \big ( s _ { t } , a _ { t } \big ) \gets Q \big ( s _ { t } , a _ { t } \big ) + \alpha \Big [ r _ { t + 1 } + \gamma \operatorname* { m a x } Q \big ( s _ { t + 1 } , a \big ) - Q \big ( s _ { t } , a _ { t } \big ) \Big ]\tag{2-1}
$$

其中， $\alpha$ 是学习速率。 $r _ { t + 1 } + \gamma \operatorname* { m a x } Q \big ( s _ { t + 1 } , a \big )$ 整体是Q-learning 的学习目标。

令 ${ \bf n } _ { l }$ 表示该模型所具有的层数，第l层表示为 $L _ { \iota }$ 。用 $\boldsymbol { W } _ { j i } ^ { l }$ 表示l层第j个神经元与1+1层的第i个神经元之间的权重参数，用 $b _ { i } ^ { l }$ 表示l+1层第i个神经元的偏置项。所以参数 $\boldsymbol { W } ^ { ( 1 ) } \in \boldsymbol { R } ^ { 3 \times 3 }$ ， $W ^ { ( 2 ) } \in R ^ { 1 \times 3 }$ 。此外，神经网络第l层中节点的数量为 $s _ { l }$ ；l层第i个神经元的激活值记作 $a _ { i } ^ { ( l ) }$ ；第l层第i个神经元的输入值表示为 $z _ { i } ^ { ( l ) }$ ，如

$$
z _ { i } ^ { ( 2 ) } = \sum _ { j = 1 } ^ { n } W _ { i j } ^ { ( 1 ) } x _ { j } + b _ { i } ^ { ( 1 ) }\tag{2-6}
$$

则 $a _ { i } ^ { ( l ) } = f \left( z _ { i } ^ { ( l ) } \right)$ 。

在定义每个网络的符号之后，神经网络的计算步骤如下：

$$
\begin{array} { c } { { a _ { 1 } ^ { ( 2 ) } = f \left( W _ { 1 1 } ^ { ( 1 ) } x _ { 1 } { + } W _ { 1 2 } ^ { ( 1 ) } x _ { 2 } + W _ { 1 3 } ^ { ( 1 ) } x _ { 3 } { + } b _ { 1 } ^ { ( 1 ) } \right) } } \\ { { { } } } \\ { { a _ { 2 } ^ { ( 2 ) } = f \left( W _ { 2 1 } ^ { ( 1 ) } x _ { 1 } { + } W _ { 2 2 } ^ { ( 1 ) } x _ { 2 } { + } W _ { 2 3 } ^ { ( 1 ) } x _ { 3 } { + } b _ { 2 } ^ { ( 1 ) } \right) } } \\ { { { } } } \\ { { a _ { 3 } ^ { ( 2 ) } = f \left( W _ { 3 1 } ^ { ( 1 ) } x _ { 1 } { + } W _ { 3 2 } ^ { ( 1 ) } x _ { 2 } { + } W _ { 3 3 } ^ { ( 1 ) } x _ { 3 } { + } b _ { 3 } ^ { ( 1 ) } \right) } } \\ { { { } } } \\ { { h _ { \scriptscriptstyle { W , b } } \left( x \right) = a _ { 1 } ^ { ( 3 ) } = f \left( W _ { 1 1 } ^ { ( 2 ) } a _ { 1 } ^ { ( 2 ) } { + } W _ { 1 2 } ^ { ( 1 ) } a _ { 2 } ^ { ( 2 ) } { + } W _ { 1 3 } ^ { ( 1 ) } a _ { 3 } ^ { ( 2 ) } { + } b _ { 1 } ^ { ( 2 ) } \right) } } \end{array}\tag{2-7}
$$

如果将激活函数 $f ( \bullet )$ 扩展为用向量表示：

$$
f \left( \left[ z _ { 1 } , z _ { 2 } , z _ { 3 } \right] \right) = \left[ f \left( z _ { 1 } \right) , f \left( z _ { 2 } \right) , f \left( z _ { 3 } \right) \right]\tag{2-8}
$$

那么，上述等式可以表示为

$$
\begin{array} { c } { { z ^ { ( 2 ) } = W ^ { ( 1 ) } x + b ^ { ( 1 ) } } } \\ { { a ^ { ( 2 ) } = f \left( z ^ { ( 2 ) } \right) } } \\ { { z ^ { ( 3 ) } = W ^ { ( 2 ) } a ^ { ( 2 ) } + b ^ { ( 2 ) } } } \\ { { h _ { \scriptscriptstyle { W , b } } \left( x \right) = a ^ { ( 3 ) } = f \left( z ^ { ( 3 ) } \right) } } \end{array}\tag{2-9}
$$

以上计算过程即神经网络的前向传播(Forward Propagation)。如果网络第l层的激活值是 $a ^ { ( l ) }$ ，那么可以如下获得第l+1层的激活值 $a ^ { ( l + 1 ) }$ ：

$$
\begin{array} { l } { { z ^ { ( l + 1 ) } = W ^ { ( l ) } a ^ { ( l ) } + b ^ { ( l ) } } } \\ { { a ^ { ( l + 1 ) } = f \left( z ^ { ( l + 1 ) } \right) } } \end{array}\tag{2-10}
$$

如果提供m个训练样本，如 $\{ ( \boldsymbol x ^ { ( 1 ) } , \boldsymbol y ^ { ( 1 ) } ) , \cdots , ( \boldsymbol x ^ { ( m ) } , \boldsymbol y ^ { ( m ) } ) \}$ 一样，每个样本既包括输入x，也包括对应的输出y(也称作目标值)。神经网络的前向传播会得到输出值，使用一个代价函数来评估神经网络的输出值与目标值的差异，单个样本 $\left( x , y \right)$ 的代价函数表示为

$$
J \left( W , b ; x , y \right) = \frac { 1 } { 2 } { \left\| h _ { _ { W , b } } \left( x \right) - y \right\| } ^ { 2 }\tag{2-11}
$$

上式为一个样本数据的代价函数，则m个样本数据的整体代价函数为

$$
\begin{array} { c } { { J \left( W , b \right) = \displaystyle \frac { 1 } { m } \sum _ { i = 1 } ^ { m } J \left( W , b ; x ^ { ( i ) } , y ^ { ( i ) } \right) } } \\ { { \displaystyle = \frac { 1 } { m } \sum _ { i = 1 } ^ { m } \left( \frac { 1 } { 2 } \| h _ { \scriptscriptstyle { W , b } } \left( x \right) - y \| ^ { 2 } \right) } } \end{array}\tag{2-12}
$$

式中，J(W,b)是一个均方差项。

我们的目标是通过训练参数W和b来求得函数J(W,b)的最小值，然后用梯度下降算法算法对目标函数进行优化。

对参数W和b的更新公式如下：

$$
\begin{array} { l } { { W _ { i j } ^ { { ( l ) } } = W _ { i j } ^ { { ( l ) } } - \alpha \frac { \displaystyle \hat { \partial } } { \displaystyle \hat { \partial } w _ { i j } ^ { { ( l ) } } } J \left( W , b \right) } } \\ { { \displaystyle b _ { i } ^ { ( l ) } = b _ { i } ^ { ( l ) } - \alpha \frac { \displaystyle \hat { \partial } } { \displaystyle \hat { \partial } b _ { i } ^ { ( l ) } } J \left( W , b \right) } } \end{array}\tag{2-13}
$$

式中，α表示神经网络中参数的学习速率。

所以需要计算如下两个偏导数：

$$
\begin{array} { r l } & { \frac { \partial } { \partial w _ { i j } ^ { ( l ) } } J \left( W , b \right) } \\ & { \frac { \partial } { \partial b _ { i } ^ { ( l ) } } J \left( W , b \right) } \end{array}\tag{2-14}
$$

求函数J(W,b)的偏导数应该使用以下公式：

$$
\begin{array} { r l r } & { } & { \frac { \hat { \partial } } { \hat { \partial } w _ { i j } ^ { ( l ) } } J \left( { W , b } \right) = \frac { 1 } { m } { \sum _ { i = 1 } ^ { m } } \frac { \hat { \partial } } { \hat { \partial } w _ { i j } ^ { ( l ) } } J \left( { W , b ; x ^ { ( i ) } , y ^ { ( i ) } } \right) } \\ & { } & { \frac { \hat { \partial } } { \hat { \partial } b _ { i } ^ { ( l ) } } J \left( { W , b } \right) = \frac { 1 } { m } { \sum _ { i = 1 } ^ { m } } \frac { \hat { \partial } } { \hat { \partial } b _ { i } ^ { ( l ) } } J \left( { W , b ; x ^ { ( i ) } , y ^ { ( i ) } } \right) } \end{array}\tag{2-15}
$$

反向传播算法[47]求解偏导数的大体步骤如下所示：

首先利用神经网络的前向传播求得 $L _ { 2 } , L _ { 3 } , \cdots L _ { n _ { l } }$ 各层的激活值。然后通过下式计算输出层每个神经元的误差项。

$$
\delta _ { i } ^ { \left( n _ { l } \right) } = \frac { \hat { \partial } } { \hat { \partial } z _ { i } ^ { n _ { l } } } J \left( W , b ; x , y \right) = - \Big ( y _ { i } - a _ { j } ^ { \left( n _ { l } \right) } \Big ) \cdot f ^ { \prime } \Big ( z _ { j } ^ { \left( n _ { l } \right) } \Big )\tag{2-16}
$$

对于 $l = n _ { l } - 1 , n _ { l } - 2 , n _ { l } - 3 , \cdots 2$ 的各层，每个节点的误差项按照公式(2-17)计算：

$$
\begin{array} { r } { \delta _ { i } ^ { ( l ) } = \left( \sum _ { j = 1 } ^ { s _ { l + 1 } } W _ { j i } ^ { ( l ) } \delta _ { j } ^ { ( l + 1 ) } \right) f ^ { \prime } \left( z _ { j } ^ { ( n _ { l } ) } \right) } \end{array}\tag{2-17}
$$

得到误差项后，就可以通过公式(2-18)来计算公式(2-14)中的两项

$$
\begin{array} { r l } & { \frac { \partial } { \partial w _ { i j } ^ { ( l ) } } J \left( W , b ; x , y \right) = a _ { j } ^ { ( l ) } \delta _ { i } ^ { ( l + 1 ) } } \\ & { \frac { \partial } { \partial b _ { i } ^ { ( l ) } } J \left( W , b ; x , y \right) = \delta _ { i } ^ { ( l + 1 ) } } \end{array}\tag{2-18}
$$

在得到梯度值后，就可以通过梯度下降法一次次地减小误差项 $\boldsymbol { J } \left( \boldsymbol { W } , \boldsymbol { b } \right)$ 的值，从而训练出整个神经网络。

## 2.2.3 深度强化学习

在强化学习算法中，当状态空间或者动作空间特别大时，则对应的 $Q ( s , a )$ 的矩阵会变得非常大。根据智能体当前的状态，选取对应的最佳动作会非常困难，一般很难找到状态-动作的最佳关系，往往导致智能体无法作出正确的动作。

故而需要对传统强化学习算法进行改进，通过使用线性或非线性函数来表示估值函数，则输入任何状态即可输出结果，就可以将状态-动作值函数矩阵的更新转化为函数拟合问题，当输入相近状态时可以得到相近的输出动作。所以采用深度神经网络估计强化学习的状态-动作估值函数，并且使用梯度下降法代替强化学习的迭代更新，这就是深度强化学习的基本思想。其中强化学习最常用的是Q-learning 算法。深度Q-learning算法就是将深度神经网络与强化学习中的Q-learning相结合[48]。深度神经网络可以直接使用原始信息作为输入。

将得到的数据样本作为深度Q-learning 网络的输入，经过深度神经网络前向传播运算，就可以得到每个动作对应的动作估值，然后就可以选取其中最大动作估值对应的动作 $a = \operatorname* { m a x } Q ( \mathrm { s } , \mathrm { a } , \mathrm { w } )$ 执行。

深度Q-learning使用均方差更新网络权重来定义目标函数，如公式(2-19)所示：

$$
L \big ( w \big ) = E \Bigg [ \Big ( r + \gamma \operatorname* { m a x } _ { a ^ { \prime } } Q \big ( s ^ { \prime } , a ^ { \prime } , w \big ) - Q \big ( s , a , w \big ) \Big ) ^ { 2 } \Bigg ]\tag{2-19}
$$

式中 $s ^ { \prime }$ 是某一时刻的状态，r是当前动作得到的奖励值。

其中， $r + \gamma \operatorname* { m a x } _ { a ^ { \prime } } Q \bigl ( s ^ { \prime } , a ^ { \prime } , w \bigr ) - Q \bigl ( s , a , w \bigr )$ 是Q-learning 状态-动作值函数更新中计算出的Q值与旧矩阵中的Q值之间的差值，在Q-learning 中以一定的学习速率来学习

这个差值，深度Q-learning通过梯度下降处理网络权重的更新。

损失函数关于w的梯度如公式(2-20)所示：

$$
\frac { \partial L \big ( w \big ) } { \partial w } = E \Bigg [ \bigg ( r + \gamma \operatorname* { m a x } _ { a ^ { \prime } } Q \big ( s ^ { \prime } , a ^ { \prime } , w \big ) - Q \big ( s , a , w \big ) \bigg ) \frac { \hat { \sigma } Q \big ( s , a , w \big ) } { \hat { \sigma } w } \Bigg ]\tag{2-20}
$$

接着便可以沿着梯度下降的方向进行迭代计算，在梯度下降过程中，网络中参数的更新公式如下：

$$
\boldsymbol { w } = \boldsymbol { w } - \alpha \nabla _ { \boldsymbol { w } } L \big ( \boldsymbol { w } \big )\tag{2-21}
$$

式中 $\alpha$ 表示学习率。

在深度强化学习过程中我们可以通过使用了一个记忆表来存储过去的历史，将智能体每次与环境交互得到的“状态-动作-奖励-新状态”序列放入记忆表中，每次训练时随机从中抽取部分样本，采用梯度下降法对参数进行更新。在深度学习算法中，如果数据间有较强的相关性，如果直接通过这些连续样本进行学习的效率会很低，而且训练出的神经网络模型会有偏向性。而强化学习处理的模型一般是马尔科夫决策过程，训练的数据是一个相关序列。为了打破这种强相关性，需要通过随机抽样来消除这种依赖关系，降低数据分布的相关性[49]。

在强化学习中常常遇到的问题之一就是探索或利用问题[50],即每次搜索时是选择还未被探索的陌生节点还是选择已经搜寻过许多次并且具有最大估值的节点。在深度Q-learning算法中我们经常使用ε-贪心策略来解决这样的问题，即以ε的概率选择一个随机动作， $_ { 1 - \varepsilon }$ 的概率选择估值最大的动作。

## 2.3航路规划数学建模

目前对无人机航路规划的研究一般都有确定的起始点和终点，这也是目前航路规划算法应用的前提。然而本文所探讨的是多架无人机如何协同工作以完成对目标区域的监视任务，无人机需要进行持续、不间断地巡逻飞行，因此相应的航路没有固定的飞行终点，这就使得现有的航路规划模型无法直接使用。针对上述问题，并在无人机的飞行约束条件下，本节建立了一种多无人机协同区域监视的航路规划模型。

## 2.3.1 设置航路规划问题的仿真参数

首先，设定多无人机的指定监视区域。多无人机的飞行任务就是在无人机进行巡逻飞行的过程中，能够使得机载雷达尽可能大的监视整个任务区域。

其次，根据无人机的系统机动性能，设定相应的无人机运动参数。与本次航路规划有关的无人机运动参数有：无人机平均飞行速度，用于表示无人机在一定时间间隔内的飞行速度平均值；无人机的偏航角，表示无人机飞行速度与坐标系x轴正方向的夹角；无人机的横滚角，表示无人机转弯时机身倾斜角；无人机的转弯角以及无人机的转弯半径。

在无人机上装备一个机载雷达，该雷达既是发射机也是接收机。无人机群航路规划的最终目的是最大化监视目标区域，故需要确定单架无人机机载雷达系统的监视范围。这里为了简化计算模型，我们假使无人机的机载雷达对所有方向的监视范围相同，故将监视区域简化为一个以当前无人机所在位置为圆心，以监视距离为半径的圆。无人机的监视半径由雷达方程给出：

$$
R _ { \mathrm { m a x } } = \left[ \frac { P _ { \mathrm { a v } } G _ { \mathrm { t } } G _ { \mathrm { r } } \sigma \lambda ^ { 2 } } { ( 4 \pi ) ^ { 3 } k T _ { 0 } B _ { \mathrm { n } } F _ { \mathrm { n } } L _ { \mathrm { s } } D _ { 0 } } \right] ^ { 1 / 4 }\tag{2-22}
$$

式中， $R _ { \mathrm { m a x } }$ 为雷达的最大作用距离； $P _ { \mathrm { a v } }$ 为雷达发射平均功率； $G _ { \mathrm { t } }$ 和 $G _ { \mathrm { r } }$ 分别为天线发射增益和天线接收增益； $\sigma _ { t }$ 为目标的RCS；λ为雷达工作波长；k为波尔兹曼常数；$T _ { 0 }$ 为等效噪声温度； $F _ { \mathrm { n } }$ 为接收机噪声系数； $L _ { \mathrm { s } }$ 为系统损耗； $D _ { 0 }$ 为可检测因子； $B _ { \mathrm { n } }$ 为多普勒带宽。

## 2.3.2 无人机飞行时的转弯约束

无人机在空中进行巡逻飞行，必定有转弯操作。转弯动作是依据空气动力作用原理，通过改变舵面上的空气动力，产生附加力和相对于飞机重心的操纵力矩，达到改变无人机飞行状态的目的。

无人机在空中飞行时其机身的倾斜运动是自由的，例如，当无人机向右方倾斜时，无人机的升力不再与重力互相平衡，于是产生一个无人机转弯飞行的向心力。在向心力的作用下，无人机向右转弯飞行。

<!-- image-->  
图2.9飞机在空中转弯时的受力情况示意图

无人机在空中转弯时的受力情况如图2.9所示。由上述可知，无人机在空中转弯时，机身必须倾斜，此时由于左右主翼升力的不同会产生一个向心力使得无人机转弯。假设无人机匀速转弯，那么此时无人机的受力方程如下：

$$
\begin{array} { l } { F \cos \gamma = m g } \\ { m V _ { p } ^ { 2 } / R = F \sin \gamma } \end{array}\tag{2-23}
$$

式中，F表示升力；γ表示横滚角，即机身转弯倾斜角；R表示转弯半径； $V _ { p }$ 表示无人机飞行速度。则由上式可得：

$$
R { = } V _ { p } ^ { ~ 2 } / ( g \cdot \tan \gamma )\tag{2-24}
$$

式中，tanγ在一些文献中被称为过载。显然转弯半径与过载成反比。当过载最大时，无人机的转弯半径最小为 $R _ { \mathrm { m i n } }$ ，因此，无人机在转弯时只能以大于或等于 $R _ { \mathrm { m i n } }$ 的转弯半径进行转弯。以无人机的最小转弯半径 $R _ { \mathrm { m i n } }$ 和飞行速度 $V _ { p }$ 飞行一定时间后就可以得到无人机的最大转弯角，记为 $\theta _ { \mathrm { m a x } }$ ，最大转弯角是指相邻两个时刻由无人机速度方向变化可能产生的最大夹角。无人机的转弯角θ不得大于最大转弯角 $\theta _ { \mathrm { m a x } }$ ，即 $\theta \leq \theta _ { \mathrm { m a x } }$ 。

## 2.3.3 确定无人机下一时刻的可行位置

由上节可知，无人机以最小转弯半径转弯时，以一定的飞行速度飞行固定时间后就可以得到最大转弯角，所以无人机每次转弯时的转弯角要小于最大转弯角，此时的航路才视为可行。根据无人机飞行时的最大转弯角来确定无人机下一时刻的可行位置。

如果已知无人机的当前所在节点，根据无人机的飞行速度和上节所得到的最小转弯半径计算出无人机在一定的时间间隔后所能飞到的可行区域。如下图2.10所示：

## 第三章基于遗传算法的多无人机协同区域监视的航路规划

## 3.1 引言

随着现代战场环境越来越复杂、战场纵深不断扩展，并且具有全方位、大范围的特点，凭单单一架无人机常常无法完成对目标区域的所有监视任务，尤其当需要监视的区域比较广阔，往往需要多架无人机通过合理的航路规划来协同工作。多架无人机之间如何协同飞行来完成对目标区域的监视成为了至关重要的问题，也是本章将重点进行研究的对象。

多无人机协同区域监视的航路规划，需要规划出每架无人机各自飞行的航路，多架无人机按照各自的航路协同飞行时，机载雷达能够有效地监视整个目标区域。如此，无人机群可以充分获得战场区域内的目标信息。因此研究适用于多无人机协同区域监视的航路规划方法具有重大的实际意义。

本章提出了一种基于遗传算法的多无人机协同区域监视的航路规划方法。本方法通过对无人机的转弯角进行基因编码，将多无人机的监视面积覆盖率作为适应度函数，并进行一系列遗传操作。依据无人机群机载雷达监视面积覆盖率最大原则，对多无人机协同区域监视进行航路规划。其中，对转弯角进行基因编码保证了无论进行交叉操作还是变异操作，得到的新种群中每一个个体仍然是一种可实现的协同飞行方式，与直接将位置作为基因编码的方式相比，此种编码方式在计算步骤和计算量上有较大的优势。仿真结果表明，该方法可以较好的解决多无人机对监视区域的最大化覆盖问题。此外，本文还提出了远视和多步两种改进方法来进一步提高覆盖性能。

## 3.2基于遗传算法的多无人机航路规划方法

首先设定航路规划问题的初始条件，即初始时刻每架无人机的位置坐标和速度角度。多无人机在巡逻飞行的过程中，每次需要转弯时产生的转弯角要小于无人机飞行时的最大转弯角，在此约束条件下选择该无人机在下一时刻可行位置上的最优节点作为飞行的目标节点，这里的最优是指下一时刻无人机群机载雷达的监视面积覆盖率最高。然后通过航路规划模型中的位置坐标-速度角度更新公式更新每架无人机的位置坐标和速度方向。重复以上步骤进行搜索无人机的再下一个目标节点，这样不断飞行直至任务结束。

因此，对多无人机的转弯角进行基因编码，由此种编码方式组成的种群中，每个个体都代表无人机群的一种协同飞行方式。当由遗传算法确定无人机如何协同飞行时，对每一种协同飞行方式对应的个体进行适应度评估，选择适应度值较高的个体组成新的种群，对该种群中的每个个体对应的无人机群的转弯角进行交叉和变异操作，得到新的种群，再对其中的个体进行适应度评估，继续选择其中优秀个体进入下一轮的交叉和变异。循环以上过程直至满足最大迭代次数，选择在整个迭代过程中适应度值最高的个体，作为无人机群飞往下一步目标节点的每架无人机对应的转弯角。

## 3.2.1 基因编码

对N架无人机的转弯角进行基因编码，该种编码方式保证了在接下来的遗传操作中，无论是进行交叉操作还是变异操作，得到的新种群中每一个个体仍然是一种可实现的协同飞行方式。如果这里我们将位置进行基因编码，在经过相应的交叉操作与变异操作后得到的新的种群中的个体，即产生的新的航路位置节点有可能不满足无人机的飞行约束条件，导致无人机不能飞到对应的目标节点，所以对位置进行基因编码可能会产生大量作废的节点。因此与直接将位置作为基因编码的方式相比，本文中对转弯角进行基因编码在计算步骤和计算量上有较大优势。

已知无人机的最大转弯角为 $\theta _ { \mathrm { m a x } }$ ，无人机每次需要转弯时产生的转弯角θ不能大于 $\theta _ { \mathrm { m a x } }$ ，即令 $\theta = 2 \theta _ { \mathrm { m a x } } \times r a n d - \theta _ { \mathrm { m a x } }$ ，rand表示[0,1]区间内的一个随机数。所以得到的无人机的转弯角 $\theta \in [ - \theta _ { \operatorname* { m a x } } , \theta _ { \operatorname* { m a x } } ]$ ，以此规划出的航路可行。

## 3.2.2 初始化种群

根据基因编码方式初始化种群G，如式(3-1)所示，该种群用一个矩阵表 $\textstyle { \overline { { \overline { { \mathcal { A } } } } } } $ 。设定种群中的个体数为S，每个个体的基因染色体数为无人机的个数N。

$$
G = \left[ \begin{array} { c c c c } { \theta _ { 1 1 } } & { \theta _ { 1 2 } } & { \cdots } & { \theta _ { 1 N } } \\ { \theta _ { 2 1 } } & { \theta _ { 2 2 } } & { \cdots } & { \theta _ { 2 N } } \\ { \vdots } & { \vdots } & { \vdots } & { \vdots } \\ { \theta _ { s 1 } } & { \theta _ { s 2 } } & { \cdots } & { \theta _ { s N } } \end{array} \right]\tag{3-1}
$$

上式矩阵中，每一行表示种群中的一个个体基因，即航路规划问题中无人机群的一种协同飞行方式；每一列为每个个体基因的染色体，表示第i架无人机的转弯角，$i = 1 , \cdots N$ 0

所以种群中每个个体都由N架无人机的转弯角组成，表示N架无人机的一种协同飞行方式，则S个个体表示N架无人机的S种协同飞行方式。通过接下来的遗传操作，包括选择、交叉和变异，会逐代产生越来越优的无人机群的协同飞行方式。最后，从中选择最优的一个个体作为无人机群中每架无人机对应的转弯角进行飞行。

## 3.2.3 适应度函数

此次航路规划的飞行任务是要求多架无人机协同工作，以完成对目标区域的最大范围的不间断监视。所以选择无人机群在下一时刻的监视面积覆盖率作为此次航路规划的适应度函数。如此设计适应度函数的好处是无人机群每次选择的协同飞行方式的适应度值越优，每架无人机以对应的转弯角飞行时，下一时刻无人机群的监视面积覆盖率越高，则可以满足无人机群的飞行任务要求。

当计算无人机群的监视面积覆盖率时，首先需要计算无人机群的监视面积，再除以目标区域的总面积即可。当计算无人机群的监视面积时，其中，每架无人机监视范围均为已知，多架无人机协同飞行以完成对目标区域的监视任务时，无人机的监视范围肯定会与其他的无人机有所重叠，所以通过统计网格的方法来计算所有无人机在目标区域的监视面积。具体过程如下：首先将目标区域均匀划分为二维网格，然后将被无人机的机载雷达监视到的网格标记为1，没被监视到的区域标记为0，其中如果监视区域有所重叠，则这个重叠区域最终也只会标记一次1。最终计算无人机群此时的监视面积时，只需将目标区域内所有被标记为1的网格个数相加即可。对于正在执行飞行任务的无人机，它的监视范围就是以此时无人机的位置坐标为圆心，以该无人机的监视威力为半径的圆；其他无人机的监视范围是以其他无人机此刻所在位置为圆心，以其监视威力为半径的圆；如果有无人机的监视范围在目标区域以外，则以目标区域为边界，超出目标区域的面积不算作无人机的监视面积。

## 3.2.4 个体选择机制

本文采用轮盘赌选择法选择种群中适应值较优的个体，即在无人机群的S种协同飞行方式中选择较优的飞行方式组成新的种群，对种群中N架无人机的转弯角进行下一步骤中的交叉和变异操作。用轮盘赌选择时首先计算种群中每个个体的适应度值，用 $f _ { i }$ 表示个体i的适应度值，则个体i被选择遗传到下一代的的概率可记为

$$
p _ { i } = { \frac { f _ { i } } { \displaystyle \sum { f _ { i } } } }\tag{3-2}
$$

当选择个体时，每次产生一个介于[0,1]区间内的随机数，将此随机数作为一个选择指针，该随机数在哪个个体的概率区域，就选择该个体进入到子代种群中。所以适应度值越大的个体被选择的概率就越大。所以通过轮盘赌选择法，当前种群中S种无人机群的协同飞行方式都可能被选择，只是哪种协同飞行方式可以在下一时刻的监视覆盖率越高，该种协同飞行方式被选择的概率就越大。

## 3.2.5 交叉与变异操作

交叉操作：经过选择操作后，由S种较优的协同飞行方式组成新的种群，对其中每种协同飞行方式对应的N架无人机的转弯角进行交叉操作。首先设定一个交叉概率，在迭代中每次产生一个介于[0,1]内的随机数，如果此次产生的随机数小于设定的交叉概率，则将当前种群中的N架无人机的转弯角进行两两配对，如第一种协同飞行方式与第二种协同飞行方式，第三种协同飞行方式与第四种协同飞行方式，以此类推。将配对的协同飞行方式交换它们之间的部分转弯角，得到交叉后的S个新的协同飞行方式，组成新的种群。

交叉操作在本章解决航路规划问题中起核心作用，交叉操作中产生的无人机群的协同飞行转弯角有很高的概率要优于当前种群中无人机群的协同飞行的转弯角。交叉操作能够大大提高对无人机群最优协同飞行方式的搜索能力。

变异操作：经过交叉操作后，重新由S种协同飞行方式组成新的种群，对其中每种协同飞行方式对应的N架无人机的转弯角进行变异操作。首先设定一个变异概率，在迭代中每次产生一个介于[0,1]内的随机数。如果此次产生的随机数小于设定的变异概率，则在当前种群中，在每种协同飞行方式对应的N架无人机的转弯角中随机选取一个无人机的转弯角进行基因变异，将原来的 $\theta _ { s n }$ 替换为新的 $\theta _ { s n } ^ { ' } , \theta _ { s n } ^ { ' }$ 为 $[ - \theta _ { \mathrm { m a x } } , \theta _ { \mathrm { m a x } } ]$ 范围内产生的随机数。得到变异后的S种新的协同飞行方式，组成新的种群。

变异操作可以避免算法陷入局部最优，改善无人机群的协同飞行方式。但也有可能将无人机群的较优的协同飞行方式变异成差的，就像生物在自然界的进化过程中，绝大部分的变异都是不利于生物的。因此，在变异操作中，我们设定一个较小的变异概率。

如此，对产生的新的无人机群协同飞行方式再次进行选择、交叉、变异的遗传操作，直至满足设定的最大迭代代数，选取在整个迭代的过程中的适应度值最大的个体作为N架无人机各自的转弯角，通过第二章数学建模中的位置-速度角度更新公式(2-26)更新无人机的位置坐标与角度向量。将更新过的无人机群的位置坐标及飞行角度作为下一步航路规划算法的初始条件。重复以上步骤，依次得到接下来每一步的最优航迹位置。这样不断获得无人机的最优航路节点，直至任务结束。对各架无人机来说，按照顺序将每次确定的最优航迹位置进行依次连接，就可得到各架无人机的飞行航路。
