息”的测量来确定传感器控制，文献[32]给出了无人机跟踪目标的闭环稳定性，但是限定了无人机的运动为匀速和匀加速两种模型，因此结论不具有普遍性。文献[33]针对无人机对地面目标的视觉跟踪开展研究，基于图像建立了无人机控制模型，航向角作为控制变量实现运动控制，该算法要求目标的可视程度好，即目标完全可观测。文献[34]采用航向角作为控制量设计了无人机跟踪目标的引导控制模型，但是模型的条件是对目标的速度状态完全可知。文献[35]采用进化算法计算无人机跟踪控制问题的近似解，得到了目标跟踪的时空优化方案，但是该方法限定了输入的完全可观测性，且必须满足二阶特性。

非短视方法考虑决策的长远的影响，对未来的演化进行规划和预测。非短视的方法以马尔科夫决策过程（Markov Decision Process, MDP）为理论为基础，将目标跟踪的运动决策转变为一个序贯决策过程，文献[36]基于 MDP 计算目标跟踪的决策，对输入状态采用卡尔曼滤波进行更新，实现了针对输入状态的实时控制，但是作为约束条件，无人机被限定为匀速运动，同时目标运动模型也被限定。针对传感器对状态反映的不确定性，部分可观测马尔科夫决策过程（Partially Observable Markov Decision Process, POMDP）为目标跟踪任务的传感器运动决策提供了良好的建模架构[37-45]，文献[37]基于 POMDP 对两栖车辆的运动路线进行了规划设计。文献[38]在 POMDP 框架下建立了无人机自动识别目标的模型；文献[39]采用 POMDP 构建了无人机跟踪目标的决策模型，并提出了一种新的近似解来实现 POMDP 模型的实时解算，但是模型中对目标的观测模型限定为线性模型。文献[40]利用 POMDP 建立了无人机路径规划模型，但是模型中对量测信息进行了线性化设定。

以上文献在采用 POMDP 建立目标跟踪的决策模型中均存在一些实际限制。主要体现在对目标运动模型的限制和传感器量测的限制，例如运动目标必须以恒定速度运动，这在实际中不可能实现；目标的观测模型为线性模型，当传感器为测向的非线性模型时，模型无法求解，制约了无人机应用效果。

## 1.2.2 单机空战机动决策研究现状

相对于攻击地面目标，空中目标不仅运动速度快，且运动范围由二维平面扩展到了三维空间，因此，空对空的战场态势比空对地复杂得多，尤其是近距空战，双方进行高速大机动，双方飞行状态改变迅速，战场几何态势和速度时刻变化，传统的遥控操作难以胜任指挥无人机进行空战[46]，因此，让无人机根据态势进行自主决策控制，完成空战机动占位的自主化是无人机智能化的一个主要研究方向[8]。

自主空战机动决策是指基于数学优化、人工智能等方法，模拟各种空战态势下飞行员空战决策，自动生成飞行控制指令的过程，是无人机实现自主空战的关键技术[47]。目前，自主机动决策的研究方法主要分为基于对策方法[48-60]、基于优化方法[61-73]、基于人工智能[74-89]方法三类。

基于对策的方法中，比较具有代表性的包括基于矩阵对策的方法和基于影响图的方法。这类方法所建立的模型能够较为直观地反映空战对抗的各个因素，但是受计算实时性的限制，难以求解具有复杂决策集的模型。文献[52]利用矩阵博弈对单机对抗展开研究，通过矩阵支付函数评估策略，依据最小最大原则在有限个机动策略中选取最优策略，模型较为简单，实用性不大。文献[53]同样采用矩阵博弈建立机动决策模型，利用模型的对称性减小决策空间的大小，在计算实时性方面取得了一定的进步。文献[55]基于微分对策对多对一的追逃问题进行建模，但是存在求解复杂和鞍点解不存在的情况。文献[57]采用影响图研究空战决策模型，在模型中考虑了飞行员知识，在此基础上，文献[58]采用贝叶斯推理描述和更新影响图中飞行员对态势的信念，影响图模型对空战效能的建模和分析更加全面，但是模型难于实时解析求解。

基于优化的方法是基于一种优化方法构建机动决策的优化模型，将机动决策问题转换为最优化问题，通过求解最优化模型，获得机动策略。常见的方法有基于遗传算法的机动决策、基于统计理论的机动决策、基于粒子群算法的机动决策等方法。文献[63]将空战的态势空间和行动空间分割为有限个离散区间，建立空战机动决策的分类器模型，采用遗传算法在分类器个体组成的种群中搜索最佳机动策略，实现了空战策略的搜索，但是算法的实时性较差，不能实现在线决策，只能用于战术动作的探索研究。文献[64]采用自适应伪并行遗传算法求解机动策略，提高了遗传算法的求解效率，但是实时性依然不能满足在线决策。文献[68]基于统计原理构建机动策略的评估模型，采用贪婪策略从所有机动动作的试探效果中选取评估值最佳的动作，该方法原理简单，但是受限于计算实时性要求，机动动作模型较为有限。文献[69]基于人工势场法建立空战人工势场函数，采用粒子群算法求解机动决策模型，仿真实现了对目标尾追的机动，但是该方法存在人工势场局部极小值和粒子陷入局部最优的问题。文献[73]基于蒙特卡洛树搜索方法从基本机动动作库中搜索最佳机动动作，该方法通过双方策略的演化搜索最优行动，考虑了决策的远期的效果，但是蒙特卡洛树搜索的计算量较大，因此对机动策略搜索的深度和动作库的大小都有限。

基于人工智能的方法有专家系统法、深度学习法和强化学习法等。专家系统法是较早提出且技术比较成熟的机动决策方法[74-75]，核心是将飞行经验提炼为规则库，通过规则库中的规则来产生飞行控制指令。文献[76]设计了一种基于专家系统的空战机动决策方法，但该方法完全依赖于专家的经验，机动策略的选择可能并不是最优结果，对态势的适应性较差。文献[77]针对专家系统法在空战应用中适应性差的问题，提出了一种基于滚动时域控制的机动决策算法对空战机动决策专家系统进行改进，在一定程度上提高了决策系统的鲁棒性。专家系统法的问题在于规则库构建复杂，难以构建完备的规则库，且策略单一固化，很容易被破解。

深度学习[78]是近些年来人工智能领域发展最为迅猛的方向之一，在语音识别、图像识别等各个领域取得了卓著成就[79-81]。深度学习属于监督学习，其训练过程依赖于标准样本数据。基于深度学习的空战机动决策研究，其核心是利用神经网络来存储机动规则，网络的输入端为当前空战态势，输出端可以为机动指令，神经网络机动决策的鲁棒性和实时性较强，具备学习能力，能从大量样本中不断学习更新，但是神经网络模型训练所需的空战标记样本的制作需要大量的人工精力来完成，因此这种算法虽然提出较早，但是面临学习样本不足和不完备的情况[82,83]。

与深度学习相比，强化学习是一种无监督的学习方法，不需要标记的学习样本，Agent 通过与外部环境的交互试错来探索环境更新行动策略[6]，能够在没有学习样本的情况下，动态的学习适应新的环境，是解决缺乏先验模型的序贯决策问题的有效方法，不少学者开展了基于强化学习的空战机动决策研究。文献[46]采用近似动态规划的方法构建机动决策模型，并进行了飞行实验，验证了强化学习可以实现无人机自主机动决策，但是模型假设无人机在二维平面内的运动，没有考虑空战中飞机在三维空间中运动的实际情况。文献[84]结合模糊逻辑的方法对空战环境的状态空间进行模糊划分，同时利用线性近似的方法对 Q 值进行近似处理，但是随着对状态空间的不断模糊细分，状态数量的剧增导致强化学习的效率下降，学习容易陷于维度爆炸而失败。文献[85-86]采用深度强化学习算法构建了空战的机动决策模型，但是模型中没有速度决策变量，双方的速度均保持不变，这与实际的空战过程有相当的差异。文献[87]采用深度 Q 网络（Deep Q Network, DQN）算法构建了超视距空战的机动决策模型，在模型构建中考虑了速度的控制，但是依然限定空战双方均在同一平面内运动，未考虑高度变化对空战的影响。综上，在基于强化学习的机动决策研究中，对于模型规模过大容易造成训练困难的问题，多采取降低空战模型维度的方式进行解决，这种简化降低了模型的仿真精度，使得学习的机动策略不能较为全面地反映空战过程。

## 1.2.3 多机协同空战机动决策研究现状

现有的空战机动决策研究多是对单机对抗场景下的空战机动决策方法进行研究，而现实空战中，基本都是多架飞机组成编队协同作战[90]。多机协同空战涉及空战态势评估[91-98]、多目标分配[99-107]、机动决策三个方面[108]，协同空战[108-114]是这三个部分的紧密联系的耦合过程，相对于单机对抗的机动决策，多机协同空战除了兵力数量规模扩大之外，还需要考虑战术协同，问题更加复杂。

对多机协同空战决策研究可以分为集中式和分布式，集中式的方法是将编队看作一个整体，由一个中心计算编队内所有飞机的行动，这类方法建立的模型较为复杂，难以计算，例如文献[109]将群决策理论引入多机协同空战机动决策，通过风险决策准则的偏好排序确定各个平台的决策方案，方法虽然在小规模场景中完成了仿真实现，但是存在决策模型的复杂度随着兵力资源增多而上升的问题。文献[110]建立了中距协同空战的训练评估模型，从中距空战战术角度分析了中距空战与协同决策的相关性，但是模型的解算依然存在实时性不足的问题。分布式方法的思路是在目标分配的基础上由编队内的各个飞机自行计算各自的机动动作，从而降低模型的复杂度，通过目标分配来实现编队任务的协同。现有的分布式协同空战决策方法多采用先进行目标分配，再根据目标分配的结果将多对多空战转化为一对一的情况[111-114]，这种方法无法很好地发挥多目标攻击能力和编队作战的战术协同，无法达到“1+1>2”的效果。因此，让无人机自身的动作决策与整个编队的作战目标相统一，是分布式协同空战决策模型的关键。

过去十年人工智能领域取得了巨大的技术进步。在单体决策方面，人工智能在包括 Atari 电子游戏[115]和围棋[116]在内的各种游戏中击败了人类。然而，真正的人类智慧包含了社会和集体智慧，通过公众的共同努力可以解决单人无法想象的问题。因此，群体智能成为人工智能新的研究热点，重点解决多个智能体如何在其所处的激励与约束共存的环境中学习人类层面的协作或竞争策略。随着深度强化学习[115,116]的蓬勃发展研究人员开始通过强化学习的方法来解决多主体决策问题[117-118]。但是，为单个智能体设计的强化学习方法通常在多智能体任务上效果不佳，如果将各个智能体看作一个整体来套用传统方法，即采用集中式决策，那么联合的行动空间会随 Agent 的数量呈指数增长，模型的求解效果不佳，因此采用分布式的多智能体强化学习架构是解决这一维度爆炸问题的有效途径。分布式多智能体强化学习的关键是学习智能体之间的通信协议，保证行动策略的协调。文献 [119] 提出了可微分的 智能体 内部学习（Differentiable Inter-agent Learning, DIAL），模型中的每个智能体都是独立学习者，智能体之间通过循环神经网络消息传递，实现梯度信息在各个智能体之间的传递，减轻模型训练的不平稳。与 DIAL 方法不同，文献[120]设计了联合行动的学习模型，将多个智能体模型统一成一个整体网络，消息通过各层之间的智能体模块传递。由于网络是完全对称的整体，因此这种方法缺乏处理异构智能体的能力，模型中智能体数量的可伸缩性也不强。文献[121]同样采用循环神经网络作为智能体间的通信网络，建立了异构的分布式强化学习系统，实现了在星际争霸（StarCraft）游戏中不同角色的战术动作配合的学习。

综上，基于分布式的多智能体强化学习能够实现协同策略的学习，但是在具体建模过程中仍需解决智能体间通信和策略的协同机制设计问题。

## 1.3 主要内容和创新点

## 1.3.1 论文研究内容

自主化是无人机未来发展主要方向，而自主化的基础是智能化。在人工智能发展迅速的当代，如何将人工智能的理论研究与具体工程应用相结合是研究的出发点和立足点，人工智能在工程的应用可以大幅度提高设备的自动化程度，进而提高设备的效率，反之，人工智能理论在工程应用过程中遇到的问题又推动理论研究进一步发展。

图 1-4 论文研究内容

强化学习是不断试错的过程，通过对周围环境不断地探索得出最佳的行动策略。对于环境模型的不依赖性使得其特别适合无人机、无人车、无人船等设备在陌生环境中自主行动并完成预设任务。目前，强化学习在地面运动的机器人和水中无人航行器的自主控制和导航避障中都有了相关应用研究[122]，而无人机由于其在三维空间中运动，状态维度大，而且无人机运动状态改变迅速，需要及时给出行动策略，这种状态空间巨大且实时性要求高的特点让强化学习算法在无人机的决策控制应用中面临不小挑战[123]。

论文拟以无人机在空战过程中目标跟踪和机动占位的运动决策问题为背景，基于强化学习理论建立无人机自主智能决策模型，以此为基础，结合分布式多智能体强化学习思想，研究多无人机协同空战的机动决策问题，建立一套分布式多无人机空战机动决策方法。

根据工程背景和任务需求，论文的整个研究内容可以分为三个部分：基于强化学习的无人机自主跟踪路径规划研究、基于强化学习单无人机空战机动决策研究、基于多智能体强化学习的多无人机协同空战机动决策研究。

## 1.3.2 研究的创新点

本论文主要是围绕无人机在空战不同任务背景下的运动决策问题展开的，在当前不断趋于智能化的战场环境中，无人机空战智能决策问题得到了各国研究者的重视，智能决策技术的研究是一个涉及多学科相互交叉、融合的方向，属于当前装备智能化研究的前沿课题。

论文的主要创新点体现在如下几个方面：

（1）设计提出了基于 POMDP 的无人机自主跟踪路径规划建模方法和POMDP 模型的在线求解算法，解决了无人机目标跟踪的实时运动决策问题。

将目标跟踪和运动决策统一于 POMDP 框架，实现了传感器观测到运动决策之间的端到端映射。针对 POMDP 模型计算量大难以在线求解的问题，提出了有限行动集算法，提高了求解效率，实现了远视策略与在线计算的统一；针对目标运动规律的复杂性，在 POMDP 模型中进一步引入了 IMM 方法描述状态转移规律，能适应无人机目标跟踪中目标信息的不确定性，同时保证跟踪精度。

（2）设计提出了基于深度强化学习的单无人机空战机动决策建模方法和模型的训练方法，解决了单无人机空战机动策略的自主学习问题。

针对传统方法建立的空战机动决策模型在大规模决策空间中性能较差的问题，提出了基于深度强化学习的空战机动决策建模方法。基于深度神经网络在连续空间条件下对空战机动决策进行了实例化研究，减少了传统研究建模时由于策略泛化困难或者状态维度爆炸对空战模型的限定。针对基于深度强化学习的空战机动决策模型中由于奖励稀疏导致的训练不收敛问题，提出了“基础-对抗”分步训练方法，在保证了空战模型精度的同时提高了决策实时性和策略的鲁棒性。

（ 3 ） 设 计 提 出 了 基 于 多 智 能 体 深 度 强 化 学 习 （ Multi-agent DeepReinforcement Learning, MDRL）的多无人机协同空战机动决策建模方法和策略协调机制，解决了多无人机协同智能空战机动策略的自主学习问题。

首先，分析了现有多机空战机动决策方法的模型架构和协调机制及其对决策效果的影响。采用双向循环神经网络（Bi-directional Recurrent Neural Network,BRNN）设计了无人机编队的通信网络，建立了分布式的多无人机协同空战机动决策模型，相较于集中式决策方法有效降低了模型的复杂度。然后，结合目标分配方法和编队空战态势评估方法设计了空战协同策略的协调方法，解决了编队各无人机策略协调的问题。有效提升了多无人机空战机动的协同效果和决策的实时性。

## 2 基于强化学习的无人机自主跟踪路径规划研究

在空战过程中，需要时刻获取目标的状态信息，对战场态势进行理解和掌握，才能做出目标分配和机动占位等空战决策，因此目标跟踪是空战的发起点。随着战场环境的不断复杂化，探测技术也有很大的发展，为了提高探测的隐蔽性，被动探测技术有了较大发展，但是被动探测对载机的机动占位要求较高，需要实时规划飞行路径以保证跟踪精度。为提升被动探测条件下无人机对目标的自主跟踪能力，本章以 POMDP 为建模框架，建立了无人机自主跟踪目标的路径决策模型，设计了在线求解算法，使得无人机能够实时调整路径保持对目标跟踪。

## 2.1 引言

知己知彼百战不殆，是千百年来战场上颠扑不破的真理，凸显了对敌我双方态势的掌握对战争成败的决定性作用。现代空战都是从几百公里外发起的，战场空间大，态势变化迅速，先敌发现目标并实现跟踪，是空战取胜的先决条件。被动探测作为一种新兴的探测手段，探测设备不主动发出电磁波，通过检测目标发出的电磁信息完成态势感知，在电磁环境日趋复杂的现代战场上对战机提高态势感知能力和发挥隐身性能具有重要的意义[124]。无人机在进行被动探测跟踪任务过程中，为保持对目标的跟踪效果，需要对自身的航向和速度等运动状态进行调整和规划。

规划的策略选择分为短视的和非短视的两种[43]。短视方法可以理解为简单的贪婪算法，即以当前决策动作带来的立即效果最大化为决策目标，而忽略采取该策略后的长远效果。非短视方法则在选择行动决策时考虑当前动作对后续长远态势的影响。

典型的非短视规划方法以 MDP 理论为框架，针对状态不完全可观测的问题，多使用 POMDP 为建模方法。针对目标探测跟踪过程中信息的不确定性，以及目标跟踪算法的特征，本章以强化学习中的 POMDP 为建模框架，建立无人机目标跟踪的路径规划决策模型，提出了决策模型的求解算法，实现无人机在跟踪过程中的实时路径规划。在研究过程中主要解决以下几个问题。

首先，在强化学习建模方法中，POMDP 虽然很适合对状态不完全可观测的问题建模，但是由于该方法建立模型的非短视性，以及模型中状态的不确定性，对决策的精确求解计算量很大，难以实时计算[42]。为了保证求解精度和决策速度相统一，需要针对跟踪问题设计 POMDP 模型的求解算法，在保证实时性的前提下求取次优解。同时，基于本算法，也可以为无人机目标跟踪路径决策问题的研究建立有效的理论框架。

其次，在目标跟踪过程中，需要进行数据融合以提高目标跟踪精度。针对被动探测的传感器观测方程多为非线性方程的问题，需要选择合适的滤波算法，来保证滤波的精度和实时性。

最后，针对目标运动规律复杂的情况，传统的单一模型的定位跟踪算法不能实现良好的定位跟踪，需要建立相应的目标运动模型来估计状态转移规律，采用 IMM 方法可以较好地解决这个问题，同时，也可以提高复杂运动模型下的目标跟踪精度。

在本章接下来的内容中，首先介绍了强化学习的基本概念和 POMDP 的建模方法和模型求解思路，然后基于 POMDP 建立了无人机自主跟踪路径规划模型，分别对简单机动目标和复杂机动目标的跟踪问题进行了研究，并提出了有限行动集算法实现了对跟踪决策模型的在线解算，最后通过仿真仿真结果验证了算法的有效性。

## 2.2 不完全信息下的强化学习建模问题

## 2.2.1 强化学习基本概念

基于交互的学习是最基础最有效的学习方式。当一个婴儿在玩耍的时候，挥动胳膊或者观察周围情况，这个过程中没有老师，但却与环境存在一个直接的感知运动关联。这个关联关系的不断运行产生大量关于原因和效果的信息，即行动的效果和如何基于行动能够达到目标。

源于这种通过交互学习的思想，强化学习的研究最早见于动物心理学的研究[125]，提出了基于反复试错来加强行为映射的方法[126,127]。与此同时，最优控制问题及其使用值函数和动态规划[128,129]的研究方法进一步夯实了强化学习的理论发展，并围绕着时间差[130]方法的有关研究[131-133]，最终融合产生了现代的强化学习领域[134,135]。

强化学习通过交互学习行动方式，将状态映射到行动以使数字化的奖励信号最大化[6]。学习者和决策者称为 Agent，与之交互的事物（Agent 外部的所有事物）称为环境。试错法（Agent 主动尝试与环境交互获得行为策略）和延迟奖励（行动不仅会影响直接的奖励，而且会影响下一个状态）是强化学习的两个最重要的特征[136]。

除了 Agent 和环境之外，强化学习系统的四个主要子元素为：策略，奖励信号，值函数以及环境模型。其中，根据环境模型是否已知，分为模型已知和模型未知的强化学习问题。

## 2.2.1.1 策略

策略定义了正在学习的 Agent 的行为方式。概略地说，策略是从感知获得的环境状态与处于这些状态时采取的行动之间的映射关系。

## 2.2.1.2 奖励信号

奖励信号是环境对行动的立即评价。在每个时间步骤中，环境都会向Agent 发送一个称为奖励的数值。Agent 的学习目标是使长期获得的奖励的累加值最大化。

## 2.2.1.3 值函数

奖励信号在即时意义上指示行动的好坏，而值函数则是从长远上指示策略的优劣。状态的值是 Agent 从该状态开始可以期望在未来累加的奖励值的总和。奖励决定了环境状态即时、内在的可取性，而值考虑了该状态后续可能遵循的状态以及这些状态中可获得的奖励后，状态的长期可取性。

## 2.2.1.4 环境模型

强化学习系统的第四个也是最后一个要素是环境模型。这是一种模拟环境行为的方法，即建立模型来推断环境的行为方式。基于模型的方法（规划方法）求解效率更高，但是强化学习的优势还是通过试错学习处理无模型的问题。

## 2.2.2 马尔科夫决策过程

MDP[134]是强化学习问题的基本数学形式，基于 MDP 可以对强化学习问题的四个元素和交互过程进行精确的数学描述。

## 2.2.2.1 Agent-环境交互

MDP 旨在直接解决从交互中学习以实现目标的问题。Agent 与环境二者不断地相互作用，Agent 根据当前自身所处环境的状态选择动作，环境响应这些动作并向 Agent 呈现新状态。环境还产生奖励，即 Agent 通过选择行动而力求使之最大化的数值。

<!-- image-->  
图 2-2 马尔可夫决策过程中 Agent-Environment 交互过程

Agent 和环境在离散的每一个时间步长 $( t = 0 , 1 , 2 , 3 , \ldots )$ 中进行交互。如图 2-2所示，在每一个时间步t，Agent收到环境状态的某种表示， $S _ { t } \in S$ ，在此基础上选择一个行动 $A _ { t } \in \mathcal { A } \left( s \right)$ 执行。一个时间步长后，作为行动执行的结果，Agent在收到一个奖励值 $R _ { t + 1 } \in \mathcal { R } \subset \mathbb { R }$ 的同时，处于一个新的状态 $S _ { t + 1 }$ 。因此，MDP和Agent 产生了像这样开始的序列轨迹，

$$
S _ { 0 } \to A _ { 0 } \to R _ { 1 } , S _ { 1 } \to A _ { 1 } \to R _ { 2 } , S _ { 2 } \to A _ { 2 } \to R _ { 3 } , \dots\tag{2-1}
$$

MDP 中，随机变量 $R _ { t }$ 和 $S _ { t }$ 具有确定的离散概率分布，概率分布仅取决于先前的状态和动作，也就是说，对于这些随机变量 $s ^ { \prime } \in \mathcal { S }$ 和 $r \in \mathcal { R }$ 的特定值，给定先前状态 和动作的特定值 $s ^ { \prime }$ 和 有可能在时间 t 出现的概率为，

$$
p ( { s ^ { \prime } } , r { | { s , a } ) } \doteq \operatorname* { P r } \{  S _ { t } = s ^ { \prime } , R _ { t } = r { | { S _ { t - 1 } = s , A _ { t - 1 } = a } \} } \tag{2-2}
$$

函数 $p : \mathcal { S } \times \mathcal { R } \times \mathcal { S } \times \mathcal { A }  [ 0 , 1 ]$ 是四个参数的普通确定性函数，对于所有 $s \in S$ $a \in { \mathcal { A } } ( s )$ ，有

$$
\sum _ { s ^ { \prime } \in S } \sum _ { r \in \mathcal { R } } p \big ( s ^ { \prime } , r \big | s , a \big ) = 1\tag{2-3}
$$

四参数函数 $p$ 给出的概率完全表征了 MDP 的动力学特性（也可记为状态转移模型 ），由此可以计算出有关环境的任何其他信息，例如状态转换概率

$$
p \left( \boldsymbol { s } ^ { \prime } \boldsymbol { \vert s } , \boldsymbol { a } \right) \doteq \operatorname* { P r } \left\{ S _ { t } = \boldsymbol { s } ^ { \prime } \big \vert S _ { t - 1 } = \boldsymbol { s } , A _ { t - 1 } = \boldsymbol { a } \right\} = \sum _ { \boldsymbol { r } \in \mathcal { R } } p \left( \boldsymbol { s } ^ { \prime } , \boldsymbol { r } \big \vert \boldsymbol { s } , \boldsymbol { a } \right)\tag{2-4}
$$

或者将状态-动作对的预期奖励计算为两个参数的函数 $r : S \times \mathcal { A } $ R，

$$
r \left( s , a \right) \doteq E \left[ R _ { t } \left| S _ { t - 1 } = s , A _ { t - 1 } = a \right. \right] = \sum _ { r \in \mathcal { R } } r \sum _ { s ^ { \prime } \in S } p \left( s ^ { \prime } , r | s , a \right)\tag{2-5}
$$

由此，一个 MDP 模型可以描述为由状态集合 ，行动集合 ，奖励集合和状态转移模型 组成的四元组

## 2.2.2.2 返回值和幕

前面提到强化学习中，Agent 的目标是使得远期的累加奖励值最大化。如果 时刻后收到的奖励序列为 $R _ { t + 1 } , R _ { t + 2 } , R _ { t + 3 } , . . .$ ，那么需要定义一个准确的形式，让其最大化。通常寻求回报期望的最大化，回报记为 $G _ { \imath }$ ，被定义为奖励序列的某些特定函数，其中最简单的形式是奖励值的直接求和，即

$$
G _ { t } = R _ { t + 1 } + R _ { t + 2 } + R _ { t + 3 } + \cdots + R _ { T }\tag{2-6}
$$

其中 $T$ 表示最终时刻。这种回报的形式在存在自然时间步长概念的应用中很有意义，即当 Agent 与环境之间的相互作用自然分解为子序列时，将其称为幕（Episode），每一幕都在到达终止状态或者最大步长后结束，然后将状态置为设定的初始状态后继续进行新的一幕。

另一方面，在许多情况下，Agent 与环境的互动不会有明确的终止状态标记而停止运行。在这种情况下，回报公式(−)存在问题，因为最终时间步长为$T = \infty$ ，所以试图最大化的回报值则变得无穷大。在这种情况下，引入折扣的概念，定义折扣率为 $\gamma$ $0 \leq \gamma \leq 1$ ，则折扣回报为

$$
G _ { t } = R _ { t + 1 } + \gamma R _ { t + 2 } + \gamma ^ { 2 } R _ { t + 3 } + \cdots = \sum _ { k = 0 } ^ { \infty } \gamma ^ { k } R _ { t + k + 1 }\tag{2-7}
$$

折扣回报值是目前强化学习领域中使用最为普遍的回报值形式。

## 2.2.2.3 策略和值函数

作为强化学习的要素之一，几乎所有的强化学习算法都需要值函数估计。通常为状态值函数或行动-值函数，状态值函数用来估计 Agent 在一个给定的状态中“好的程度”，行动-值函数用来评估在一个给定状态中 Agent 执行一个给定行动的“好的程度”，“好的程度”则由未来可以预期的回报值来定义。由于Agent 未来期望获得的回报取决于其将采取的行动，因此，值函数是根据 Agent特定的行为方式定义的，Agent 的行为方式即为策略。

策略是从状态到 Agent 所能选择的各个行动的概率的映射，在 时刻，如果Agent 服从策略 $\pi$ ，则 $\pi ( a | s )$ 是状态 $S _ { t } = s$ 时行动 $A _ { t } = a$ 的概率。强化学习方法指定了 Agent 的策略如何根据其经验进行更新。基于策略 $\pi$ ，状态 的值函数记为$\nu _ { \pi } \left( s \right)$ ，根据值函数的定义，有

$$
\nu _ { \pi } \left( s \right) = \mathbb { E } _ { \pi } \left[ G _ { t } \left| S _ { t } = s \right. \right] = \mathbb { E } _ { \pi } \left[ \sum _ { k = 0 } ^ { \infty } \gamma ^ { k } R _ { t + k + 1 } \left| S _ { t } = s \right. \right]\tag{2-8}
$$

称 $\nu _ { \pi } \left( s \right)$ 为策略 的状态值函数。同理，定义基于策略 $\pi$ ，在状态 下执行行动 $a$ 的值函数 $q _ { \pi } \left( s , a \right)$ 为

$$
q _ { \pi } \left( s , a \right) = \mathbb { E } _ { \pi } \left[ G _ { t } \left| S _ { t } = s , A _ { t } = a \right. \right] = \mathbb { E } _ { \pi } \left[ \sum _ { k = 0 } ^ { \infty } \gamma ^ { k } R _ { t + k + 1 } \left| S _ { t } = s , A _ { t } = a \right. \right]\tag{2-9}
$$

称 $q _ { \pi } \left( s , a \right)$ 为策略 $\pi$ 的行动-值函数。

由(2-7)式可知， $G _ { t } = R _ { t + 1 } + \gamma R _ { t + 2 } + \gamma ^ { 2 } R _ { t + 3 } + \cdots = R _ { t + 1 } + \gamma G _ { t + 1 }$ ，则有

$$
\begin{array} { r l } { \displaystyle \nu _ { \boldsymbol \pi } ( s ) = \mathbb { E } _ { \boldsymbol \pi } [ G _ { t } | S _ { t } = s ] } \\ { \displaystyle } & { \mathrm { = } \mathbb { E } _ { \boldsymbol \pi } [ R _ { t + 1 } + \gamma G _ { t + 1 } \big | S _ { t } = s ] } \\ { \displaystyle } & { \mathrm { = } \sum _ { a } \pi \big ( a \big | s \big ) \sum _ { s ^ { \prime } } \sum _ { r } p ( s ^ { \prime } , r \big | s , a \big ) \Big [ r + \gamma \mathbb { E } _ { \boldsymbol \pi } [ G _ { t + 1 } \big | S _ { t + 1 } = s ^ { \prime } ] ] } \\ { \displaystyle } & { \mathrm { = } \sum _ { a } \pi \big ( a \big | s \big ) \sum _ { s ^ { \prime } , r } p ( s ^ { \prime } , r \big | s , a \big ) \Big [ r + \gamma \nu _ { \boldsymbol \pi } ( s ^ { \prime } ) \Big ] } \end{array}\tag{2-10}
$$

(2-10)式即为值函数 $\nu _ { \pi }$ 的贝尔曼公式[134]，表征了当前状态的值与后续状态

的值之间的关系。

## 2.2.2.4 最优策略和最优值函数

求解强化学习问题的最终目的，是找到一种获得更大回报值的策略。在MDP 中，如果定义一个策略 $\pi$ 优于另一个策略 $\pi ^ { \prime }$ ，则各个状态下策略 的值函数大于等于策略 $\pi ^ { \prime }$ 的值函数，即对于所有 $s \in S$ ，当且仅当 $\nu _ { \pi } \left( s \right) \geq \nu _ { \pi ^ { \prime } } \left( s \right)$ 时，则有$\pi \geq \pi ^ { \prime }$ 。如果一个策略优于所有其他策略，那么该策略即为最优策略，记为 $\pi _ { * }$ ，最优策略对应的状态值函数被称为最优状态值函数，记为 $\nu _ { \ast }$ ，对于所有 $s \in S$ ，有

$$
\nu _ { \ast } \left( s \right) = \operatorname* { m a x } _ { \pi } \nu _ { \pi } \left( s \right)\tag{2-11}
$$

同理，行动-值函数被定义为

$$
q _ { * } \left( s \right) = \operatorname* { m a x } _ { \pi } q _ { \pi } \left( s , a \right)\tag{2-12}
$$

根据贝尔曼公式，(2-11)分别展开为如下形式

$$
\begin{array} { l } { { \displaystyle \nu _ { * } ( s ) = \operatorname* { m a x } _ { a \in A ( s ) } q _ { \pi } ( s ) } \ ~ } \\ { { \displaystyle ~ = \operatorname* { m a x } _ { a } \mathbb { E } \Bigl [ R _ { t + 1 } + \gamma \nu _ { * } ( S _ { t + 1 } )  S _ { t } = s , A _ { t } = a  \Bigr ] } \ ~ } \\ { { \displaystyle ~ = \operatorname* { m a x } _ { a } \sum _ { s ^ { \prime } , r } p ( s ^ { \prime } , r  s , a ) \Bigl [ r + \gamma \nu _ { * } ( s ^ { \prime } ) \Bigr ] } } \end{array}\tag{2-13}
$$

同理，(2-12)式也可以展开为如下形式，

$$
\begin{array} { r l r } {  { q _ { * } \big ( s , a \big ) = \mathbb { E } \bigg [ R _ { t + 1 } + \gamma \operatorname* { m a x } _ { a ^ { \prime } } q _ { * } \big ( S _ { t + 1 } , a ^ { \prime } \big ) \big | S _ { t } = s , A _ { t } = a \bigg ] } } \\ & { } & { \quad = \sum _ { s ^ { \prime } , r } p \big ( s ^ { \prime } , r \big | s , a \big ) \bigg [ r + \gamma \operatorname* { m a x } _ { a ^ { \prime } } q _ { * } \big ( s ^ { \prime } , a ^ { \prime } \big ) \bigg ] } \end{array}\tag{2-14}
$$

贝尔曼最优方程(2-13)为一个方程组，MDP 状态空间的 个状态，对应个方程。如果环境的动力学模型 $p$ 是已知的，那么原则上可以使用多种求解非线性方程组的方法中的任何一种来求解 $\nu _ { * }$ 的方程组。同理可以求解 $q _ { * }$ 。MDP的求解思路可以归结为对根据探索获取的奖励值来更新值函数，从而更新行动策略的过程。

## 2.2.3 部分可观测马尔科夫决策过程

2.2.2 节讲述了基于 MDP 的强化学习模型，MDP 为解决强化学习问题提供了简单有效的建模架构，但其中的前提是 Agent 对自身所处的环境状态是完全可观测的，然而很多现实问题不满足这一前提，例如很多“传感器-行动器”的决策系统中，传感器的观测值有一定的量测范围，因此不能完全反映 Agent 所处的整体环境，此外传感器的量测中存在噪声，其量测值难免存在误差，这也会造成 Agent 对环境状态的理解偏差。POMDP 将 MDP 中的“状态-行动”模式扩展为“观测-状态-行动”模式，为这类部分可观测的问题提供了灵活的数学架构[137]。

## 2.2.3.1 模型框架

POMDP 模型的构成一般可以定义为一个 7 元组 组成，其中 与 MDP 的 4 个元素相同， 表示状态集合，A表示行动集合， 表示奖励集合， 表示环境的状态转移模型， 分别定义为：

：观测空间，即 Agent 所有可能获得的观测集合，有些问题中将观测空间统一于观测函数；

：观测函数，给出 Agent 执行完行动 $a _ { { _ t } }$ 后，状态转移至 $s _ { t + 1 }$ 后获得观测值$z _ { t + 1 }$ 的概率，即 $O \left( s , a , z \right) = P \left( z _ { t + 1 } = z \middle | s _ { t + 1 } = s , a _ { t } = a \right)$ ；

：信念状态空间，信念状态指 Agent 基于过去观察、行动的历史统计值对当前所处环境状态的概率估计。

记 信 念 状 态 为 给 出 当 前 环 境 处 于 状 态 s 的 概 率 ，$b _ { t } ( s ) = P ( s _ { t } = s | z _ { t } , a _ { t - 1 } , . . . , a _ { 0 } )$ ，当前的信念状态可以递归地根据贝叶斯推理方法唯一确定，即

$$
b _ { t } ( s ^ { \prime } ) = \frac { O ( s ^ { \prime } , a _ { t - 1 } , z _ { t } ) \sum _ { s \in \mathcal { S } } T ( s , a _ { t - 1 } , s ^ { \prime } ) b _ { t - 1 } ( s ^ { \prime } ) } { \operatorname* { P r } ( z _ { t } | b _ { t - 1 } , a _ { t - 1 } ) }\tag{2-15}
$$

其中 $\mathrm { P r } ( z _ { t } | b _ { t - 1 } , a _ { t - 1 } )$ 是一个归一因子，表示 Agent 在信念点 $b _ { { } _ { t - } }$ 处采取行动 $a _ { t - }$ 得到观察值 $z _ { t }$ 的概率

$$
\begin{array} { r } { \mathrm { P r } \big ( z _ { t } \big | b _ { t - 1 } , a _ { t - 1 } \big ) = \sum _ { s ^ { \prime } \in \mathcal { S } } O \big ( s ^ { \prime } , a _ { t - 1 } , z _ { t } \big ) \sum _ { s \in \mathcal { S } } T \big ( s , a _ { t - 1 } , s ^ { \prime } \big ) b _ { t - 1 } \big ( s \big ) } \end{array}\tag{2-16}
$$

信念状态更新的优势是在知道前一步状态和相应的行动及观察，可以计算出当前的信念状态，无需之前的历史信息，根据公式(2-15)就可以计算当前状态的概率分布估计。因此 POMDP 可以看作是定义在信念空间上的 MDP，策略可以表示为信念到动作的映射 $\pi : B  A$ 0

设初始信念状态为 $b _ { 0 }$ ，Agent 在给定策略后的任务是反复执行三个基本动作：基于现在时刻所处的信念点采取行动，进而获得观察和奖励值，再更新信念状态。定义 Agent 在策略 下的值函数为

$$
\begin{array} { r } { V _ { \pi } \left( b \right) = \mathbb { E } \left[ \sum _ { t = t _ { 0 } } ^ { T } \gamma ^ { t - t _ { 0 } } r \left( b _ { t } , \pi ( b _ { t } ) \right) \right] } \end{array}\tag{2-17}
$$

则 POMDP 的求解过程就是在 POMDP 模型完全已知的情况下计算最优策略 $\pi ^ { * }$ 使得获得的远期回报最大化，即

$$
\begin{array} { r } { \pi ^ { * } \left( b \right) = \arg \operatorname* { m a x } _ { \pi } \left[ V _ { \pi } \left( b \right) \right] } \end{array}\tag{2-18}
$$

## 2.2.3.2 求解思路

POMDP 的求解算法大致可以分为离线求解算法和在线求解算法两大类。

离线求解算法的目的是建立整个信念空间上的完整策略，代表算法有值迭代算法[137-140]和基于信念点[141-144]的算法，其中值迭代算法是精确求解 POMDP模型的理论基础。

根据信念状态的值函数，可以基于贝尔曼方程迭代得到最优策略，POMDP

的值函数更新公式为

$$
V _ { k + 1 } \left( b \right) = \mathrm { m a x } _ { a \in A } \left[ \sum _ { s \in S } b ( s ) r ( s , a ) + \gamma \sum _ { z \in Z } P \big ( z | b , a \big ) V _ { k } \left( b \right) \right]\tag{2-19}
$$

与之对应的最优策略可以表示为

$$
\begin{array} { r } { \pi _ { k + 1 } \left( b \right) = \arg \operatorname* { m a x } _ { a \in A } \left[ \sum _ { s \in S } b ( s ) r \big ( s , a \big ) + \gamma \sum _ { z \in Z } P \big ( z | b , a \big ) V _ { k } \left( b \right) \right] } \end{array}\tag{2-20}
$$

由(2-19)式可以看出 POMDP 的最优策略的值函数表达公式与 MDP 的相似，但是 POMDP 的信念空间定义在多维连续空间上，这使得精确求解过程不能像解决 MDP 问题的方式一样直接列出 个方程组来进行求解。为了解决这个问题，Sondik 证明了在有限步的 POMDP 中，值函数在信念空间上具有分段线性凸的性质[137]。多维空间中的一个线性函数可以用其稀疏向量来表示，那么分段线性函数就可以用若干个向量表示，因而可将值函数表示为一个向量组合，$\Gamma = \left\{ \alpha _ { 1 } , \alpha _ { 2 } , . . . , \alpha _ { | \Gamma | } \right\}$ ，值函数可以写为

$$
V \left( b \right) = { \mathrm { m a x } } _ { \alpha \in \Gamma } b \cdot \alpha\tag{2-21}
$$

这样就将函数的值迭代转换成为了向量的迭代

$$
\alpha _ { a , z } ^ { * } \left( b \right) = \underset { \alpha _ { i - 1 } \in \Gamma _ { i - 1 } } { \arg \operatorname* { m a x } } \alpha _ { i - 1 } \left( b _ { a } ^ { z } \right)\tag{2-22}
$$

$$
\alpha _ { a } ^ { * } ( b ) = r ( b , a ) + \gamma \sum _ { z } P ( z | b , a ) \alpha _ { a , z } ^ { * } ( b )\tag{2-23}
$$

假设 t 时刻值函数包含的向量集合为 $\Gamma _ { t }$ ，那么在经过一轮迭代后，到 $t + 1$ 时刻向量集合的数量为 $\left| \Gamma _ { t + 1 } \right| = \left| \Gamma _ { t } \right| \left| A \right| \left| Z \right| + \left| \Gamma _ { t } \right|$ ，即向量集合随着 $\lvert A \rvert \lvert Z \rvert$ 呈指数增长，在个步长后，POMDP 精确计算的复杂度将达到 $\left| A \right| ^ { n } \left| Z \right| ^ { n }$ ，所以基于值迭代的POMDP 精确求解算法存在维度灾难的问题，由此可见，完整值迭代算法的计算复杂度非常高，因此多采用近似算法。

由于求解完整策略的计算复杂度较大，因此离线求解算法只能适应于小规模问题。相比较而言，在线规划算法[145,146]更适合应用于大规模问题。在线规划算法的思想是只考虑从当前信念状态出发的可达信念空间，不计算完整的向量，以此来减小计算量。代表算法有启发式搜索算法[147,148]和蒙特卡罗树[149-152]算法。在线算法的关键是选取合适的信念点对整个信念空间进行估计，减少概率分布计算，从而提高计算效率。

## 2.3.2 简单机动目标的自主跟踪路径规划模型

## 2.3.2.1 路径规划 POMDP 模型

POMDP 是一个可控的序贯决策模型架构，可以用于各类资源管理和控制决策的建模。一个 POMDP 模型由多个关键要素构成，基于 POMDP 的路径规划建模过程就是将各个要素根据问题进行数学描述的过程。本规划问题的POMDP 模型可由 1 个 6 元组 来表示，其中，S表示状态空间，为行动空间， 为状态转移规律， 为观测和观测率， 表示代价函数[43]（求解极小值问题中将奖励改为代价），B 为信念空间。下面根据具体问题对各个要素进行实例化建模。

## (1)状态空间

在无人机航路规划的问题中，状态空间 S 由 3 个子状态空间组成，分别为无人机状态 $\boldsymbol { x } _ { k }$ 、目标状态 $\zeta _ { _ k }$ 、和滤波状态 $\left( \xi _ { \boldsymbol { k } } , \pmb { P } _ { \boldsymbol { k } } \right)$ ，即 $\pmb { S } _ { k } = \left( \pmb { x } _ { k } , \pmb { \zeta } _ { k } , \pmb { \xi } _ { k } , \pmb { P } _ { k } \right)$ 。无人机的状态 $\mathbf { \boldsymbol { x } } _ { k } = \left( \boldsymbol { p } _ { k } ^ { x } , \boldsymbol { p } _ { k } ^ { y } , \boldsymbol { \nu } _ { k } , \boldsymbol { \theta } _ { k } \right) ^ { T }$ 包括 时刻无人机所在的位置和速度，其中 $p _ { k } ^ { x }$ 和 $p _ { k } ^ { y }$ 分别为横纵坐标的值，用以表示无人机的位置 $\pmb { x } _ { k } ^ { p o s }$ ， $\nu _ { k }$ 表示速度大小值，$\theta _ { k }$ 表示方向。目标的状态 ${ \pmb { \zeta } } _ { k } = \left( q _ { k } ^ { x } , q _ { k } ^ { y } , u _ { k } ^ { x } , u _ { k } ^ { y } \right) ^ { T }$ 表示 时刻目标的位置和速度，其中 $q _ { k } ^ { x }$ 和 $q _ { k } ^ { y }$ 分别为横纵坐标值，表示目标的位置 $\zeta _ { k } ^ { p o s }$ $\boldsymbol { u } _ { k } ^ { x }$ 和 $u _ { k } ^ { y }$ 分别为横纵速度值。滤波状态 $\left( \xi _ { \boldsymbol { k } } , \pmb { P } _ { \boldsymbol { k } } \right)$ 表示对目标的估计状态， $\xi _ { \scriptscriptstyle k }$ 表示目标状态的后验估计值， $P _ { k }$ 为估计的协方差矩阵[43]。

## (2) 行动空间

行动空间是所有能执行的决策的集合，即调整改变无人机运动状态的动作空间。根据二维运动模型（状态转移规律）的定义，本章采取加速度 $a _ { k }$ 和倾斜角 $\varphi _ { k }$ 作为行动变量，控制无人机的运动，则 $A _ { k } = \left( a _ { k } , \varphi _ { k } \right)$ 。

## (3) 观测和观测率

在 POMDP 模型中，由于传感器获得的观测值是存在误差，目标状态不能被完全准确测量。因此，观测的结果定义为以状态 $S _ { k }$ 信息和传感器观测噪声 $\eta _ { k }$ 为输入的函数，如(−)式所示，

$$
z _ { k } = h \big ( S _ { k } \big ) + \eta _ { k }\tag{2-24}
$$

无人机在基于被动探测技术条件下寻找目标导航的过程中，观测值多为目标的角度信息[153-154]。因此，将 $h \big ( S _ { k } \big )$ 定义为：

$$
h \big ( S _ { k } \big ) = \arctan \frac { q _ { k } ^ { y } - p _ { k } ^ { y } } { q _ { k } ^ { x } - p _ { k } ^ { x } }\tag{2-25}
$$

(−)式中， $\eta _ { k }$ 表示观测噪声，表征传感器测量的不确定程度，事实上 $\eta _ { k }$ 的分布与传感器与目标间的空间位置相关，当传感器探测到目标的距离较近时，观测的距离和角度的不确定程度小，反之当探测距离较大时，电磁空间内受各种因素带来的干扰较多，观测的不确定程度较大。据此，建立 $\eta _ { k }$ 的方差模型为

$$
R _ { k } = R \big ( \pmb { x } _ { k } , \pmb { \xi } _ { k } \big ) { = } E r r ^ { * } D \big ( \pmb { x } _ { k } , \pmb { \xi } _ { k } \big )\tag{2-26}
$$

其中 $E r r$ 表示传感器输出目标方位角的不确定度， $D \left( \pmb { x } _ { k } , \pmb { \zeta } _ { k } \right)$ 表示无人机和目标之间的距离。

## 3)滤波状态

滤波状态是滤波算法根据观测值和目标状态转移规律对目标的状态进行融合估计，滤波状态是信念状态空间的主要分布，滤波状态的转移过程也是信念状态的更新过程，因此滤波算法将在介绍信念状态时一并介绍。

## (5) 代价函数

代价函数计算当前状态下采取行动 $\boldsymbol { A } _ { k }$ 的代价，在目标跟踪中，行动目的是减小探测误差，因此本章采用目标真实状态与系统估计的滤波状态的均方误差表示行动代价，记为：

$$
C \left( \boldsymbol { \zeta } _ { k } , \mathbf { A } _ { k } \right) = \mathbb { E } _ { \eta _ { k + 1 } , w _ { k } } \left[ \left\| \boldsymbol { \zeta } _ { k + 1 } - \boldsymbol { \xi } _ { k + 1 } \right\| ^ { 2 } \big | \boldsymbol { \zeta } _ { k } , \mathbf { A } _ { k } \right]\tag{2-32}
$$
