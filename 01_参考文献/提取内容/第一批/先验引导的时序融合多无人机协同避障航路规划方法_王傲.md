# 先验引导的时序融合多无人机协同避障航路规划方法

王 傲① 李大鹏\*① 徐逸凡② 范炳阳③ 韩 光① 赵海涛①

①(南京邮电大学通信与信息工程学院 南京 210003)②(中国人民解放军陆军工程大学通信工程学院 南京 210001)③(南京邮电大学波特兰学院 南京 210023)

摘 要：针对多无人机自主协同避障航路规划任务中，传统多智能体强化学习算法存在的收敛速度慢，无人机协同性不足等问题，该文提出一种先验引导的时序融合价值分解算法(PGL-QMIX)。该方法在离线阶段利用A星(A\*)算法生成全局参考路径，并在在线决策中仅提取智能体感知范围内的局部路径片段与几何评分作为弱先验，引导个体策略在部分可观测环境下实现稳定探索与协同避障。同时，设计了双重长短期记忆网络(LSTM)架构，用于建模先验知识与实时状态的时序依赖关系。并对各无人机的动作价值函数进行动态加权融合与自适应优化，提升系统的环境适应性与多无人机协同的稳定性。实验结果表明，所提方法在三维栅格场景中，相较于同场景下次优结果，所提方法的收敛步数分别减少3.0%, 7.2%和7.4%，稳态任务成功率分别提升1.26, 4.41和8.12个百分点，平均航路长度分别缩短6.2%, 8.5%和10.0%，验证了该方法在多无人机自主协同避障航路规划中的有效性与稳定性。

关键词：多无人机；航路规划；深度强化学习；先验知识；协同避障

## 1    引言

随着低空经济的快速发展，无人机(UnmannedAerial Vehicle, UAV)作为一种具备高机动性与灵活调度能力的空中平台，已广泛应用于数据采集[1]，移动通信[2]等任务场景。相较于单无人机系统，多无人机协同系统在任务覆盖范围、执行效率和鲁棒性等方面具有明显优势，为克服这些不足，多无人机协同避障航路规划方法[3]逐渐成为当前研究的热点。

现有研究已提出多种传统算法，其中，基于启发式搜索的A\*算法[4]因其高效性与良好的扩展性强，得到了广泛应用。近年来，深度强化学习(DeepReinforcement Learning, DRL)被广泛应用在航路规划任务中。深度Q网络(Deep Q-Network,DQN)[5]能够通过与环境交互自主学习策略，在未知环境中逼近最优解，从而弥补了传统方法在环境适应性方面不足。文献[6]提出了基于阈值的深度Q网络(Threshold Deep Q-Network, T-DQN)算法，通过阈值筛选经验回放样本，有效提升了避障策略的收敛速度。文献[7]将卷积神经网络(Convo-lutional Neural Network, CNN)与长短期记忆网络(Long Short-Term Memory, LSTM)[8]融合设计了双网络架构，提取无人机避障任务中的时空特征。然而，这些方法在扩展至多无人机协同任务时，往往难以准确区分观测变化究竟源自环境扰动还是其他无人机策略调整，策略学习过程因此容易受到环境非平稳性的干扰。

为提升多智能体策略的稳定性与泛化能力，价值分解网络(Value-Decomposition Networks, VDN)[9]采用加性结构，将个体基于局部观测的价值函数组合。深度确定性策略梯度算法(Q-decompositionMulti-agent Independent eXtension, QMIX)[10]引入满足单调性约束的混合网络结构，并利用混合网络生成加权参数，增强了智能体之间的协同能力。为进一步缓解过估计问题。冯斯梦等人[11]面向低空混合障碍环境下无人机难以兼顾通信性能与飞行安全的问题，提出基于碰撞概率地图的避障通信模型，并结合用户调度优化与多智能体深度确定性策略梯度(Multi-Agent Deep Deterministic Policy Gradient,MADDPG)实现协同规划。此外，Guan等人[12]针对灾害应急通信场景中的多无人机协同优化，将K聚类算法与多智能体近端策略优化(Multi-AgentProximal Policy Optimization, MAPPO)算法联合建模，实现了更快的策略收敛与更高的系统吞吐率。

此外，一些研究尝试将先验路径信息与强化学习相结合，以加快训练收敛。文献[13]将A\*生成的先验路径与冲突优先规则嵌入DQN框架，但该方法对静态先验知识依赖过强，限制了策略在未知环境中的探索能力与泛化表现。文献[14]在离线阶段利用A\*算法规划全局轨迹，在线阶段将局部轨迹片段与实时观测融合输入深度强化学习网络，引导策略稳定收敛至全局目标。上述工作表明，先验知识与学习优化的有机融合有助于加速收敛并提升在线决策稳健性。

综上所述，现有多智能体深度强化学习方法在多无人机自主协同避障导航任务中存在明显不足：一方面，仅依赖局部观测难以有效捕捉全局状态特征，导致价值估计准确性不足，学习效率低下；另一方面，在未知环境中，频繁碰撞会产生大量负面样本，降低了初期训练数据的有效性，显著延缓策略的稳定收敛进程。

基于此，本文提出一种先验引导的时序融合价值分解算法(Prior-Guided-LSTM-QMIX, PGL-QMIX)。具体贡献如下：

(1)提出一种先验引导的时序融合价值分解算法。本算法通过在QMIX值分解框架中引入两级时序建模机制，通过先验LSTM与混合LSTM融合全局参考与局部观测，实现了全局引导信息与局部时序特征的融合，有效提升了策略学习的前瞻性与稳定性。

(2)构建了局部先验片段的构造与时序融合机制。本机制利用A\*算法在静态环境中生成的参考路径，在执行过程中仅提取局部可见的路径片段，作为启发式先验输入，从而在获取全局几何趋势信息的同时，不需要依赖完整全局信息。在保持自主探索能力的同时，显著提升收敛效率与在未知环境中的泛化性能。

## 2.2  POMDP模型建立

由于多无人机自主协同避障导航任务具有状态依赖性，并且无法完全观测到环境中的全部信息，因此该问题可建模为部分可观察马尔可夫决策过程(Partially Observable Markov Decision ProcessPOMDP)[15]。POMDP模型可表示为一个元组：$G = \langle S , A , P , R , \mathcal { O } , \varOmega , \gamma \rangle$ S，其中 为全局状态空间；A是所有无人机可执行动作的集合。 $P$ 是状态转移s函数，表示在状态 下，无人机执行联合动作 $\pmb { a } \sqrt { \sharp }$ ，系统转移至状态 $s ^ { \prime }$ 的概率，记为： $P ( s ^ { \prime } \mid s , \pmb { a } )$ R ；为奖励函数，无人机采取动作 $\textbf { \em a }$ 获得的共享全局奖O i t励； 表示观测空间；第 个无人机在时刻 的观测记为 $o _ { i , t } \in \mathcal { O }$ 。观测函数为 $\varOmega ( o \mid s ^ { \prime } , \pmb { a } )$ 表示无人机采取动作 $^ { a }$ s′ o 转移至 时获得观测 的概率。 $\gamma$ 是折扣因子，用于平衡短期与长期奖励影响。

## 2.2.1  观测空间建模

在POMDP框架下，环境全局状态 $S _ { t }$ 仅在集中训练阶段可见；执行阶段各智能体依据局部观测$\mathbf { o } _ { i }$ 独立决策。对于无人机 $U _ { i }$ ，其局部观测 $\mathbf { o } _ { i }$ 由自身状态与感知域内的环境信息组成。局部观测 $\mathbf { o } _ { i }$ 通过半径 $r _ { o }$ 的传感器在 $M \times M \times M$ 的三维局部栅格内获得，仅反映可感知范围内的障碍和邻机信息。具体定义为

$$
\pmb { o } _ { i } = \{ \pmb { p } _ { t } ^ { i } , \pmb { p } _ { \mathrm { g o a l } } ^ { i } , d _ { \mathrm { u } } ^ { i j } ( t ) , d _ { \mathrm { g } } ^ { i } ( t ) , d _ { o } ^ { i } ( t ) \}\tag{2}
$$

其中， $\mathbf { \Delta } _ { \mathbf { \mathcal { p } } _ { t } ^ { i } }$ t  为 时刻的当前位置； $p _ { \mathrm { g o a l } } ^ { i }$ 为目标位置；$d _ { \mathrm { g } } ^ { i } ( t )$ 为t时刻无人机 $U _ { i }$ 到目标距离； $d _ { \mathrm { u } } ^ { i j } ( t ) = \lVert \mathbf  \} p _ { t } ^ { i } - \mathbf { \mathbf { \mathbf { \mathit { p } } } } _ { t } ^ { j }$ ∥为t时刻无人机 $U _ { i }$ 和无人机 $U _ { j }$ 的欧氏距离 $( i \neq j )$ ；$\begin{array} { r } { d _ { o } ^ { i } = \operatorname* { m i n } _ { o _ { \mathrm { m i n } } \in O } \| \pmb { p } _ { t } ^ { i } - \pmb { p } _ { o } \| } \end{array}$ 为t时刻无人机 $J _ { i }$ 与最近障碍物的距离。训练阶段在栅格上离线生成A\*路径；执行阶段各智能体仅能在观测范围内访问局部路径片段，不访问全局栅格。

## 2.2.2  动作空间建模

在多无人机协同避障规划中，动作空间决定了无人机的行为集合，并直接影响策略学习的效率与可执行性。本文采用离散动作空间 $A _ { i }$ 包括六连通离散动作及停留动作集： $A _ { i } = \{ + x , - x , + y , - y , + z , - z$ stay}。在执行时进行越界检测与障碍物可行性判定，确保动作决策的安全。

采用离散动作空间具有两方面优势：一方面，与三维栅格环境及离线A\*参考路径的连通方式一致，可实现全局参考轨迹与动作序列的自然映射，避免先验路径与实际执行不一致的问题；另一方面，离散化降低了策略网络输出维度和联合动作空间的复杂度，从而提升训练稳定性与样本效率。

此外，为提高轨迹的连续性与执行平滑性，本文在后处理阶段引入B-spline轨迹平滑方法[16]，将离散路径节点序列转换为连续轨迹。具体地，采用3次B-spline表示为

$$
\pmb { c } ( t ) = \sum _ { j = 0 } ^ { m } P _ { j } B _ { j , 3 } ( t ) , t \in [ 0 , 1 ]\tag{3}
$$

其中， $P _ { j }$ 为由离散路径节点拟合得到的控制点，$B _ { j , 3 } ( t )$ 为3次B-spline基函数。需要指出的是，该平滑过程仅用于轨迹展示与执行参考，并不参与强化学习训练，也不改变离散动作空间定义。

## 2.2.3  奖励函数建模

为实现路径长度最小化与安全约束的统一优化，本文在强化学习框架中设计了一种基于势函数塑形(potential-based shaping)与全局先验引导相结合的奖励函数。本设计综合考虑任务完成、路径推进、碰撞惩罚及先验路径贴合等因素，在保证策略长期收敛性的同时，使无人机具备自主探索与全局引导的平衡能力。

$$
\overline { { d } } _ { \mathrm { g } } ( t ) = \frac { 1 } { N } \sum _ { i = 1 } ^ { N } d _ { \mathrm { g } } ^ { i } ( t )\tag{4}
$$

其中 $d _ { \mathrm { g } } ^ { i } ( t )$ 表示第 架无人机在时刻 到目标点的欧氏i t距离。同时，将障碍物和无人机之间的安全约束以软约束形式表示为

$$
\rho _ { o } ( t ) = \left[ \frac { d _ { \mathrm { m i n } } - d _ { o } ^ { \mathrm { m i n } } ( t ) } { d _ { \mathrm { m i n } } } \right] _ { + } , \rho _ { \mathrm { u } } ( t ) = \left[ \frac { d _ { \mathrm { m i n } } - d _ { \mathrm { u } } ^ { \mathrm { m i n } } ( t ) } { d _ { \mathrm { m i n } } } \right] _ { + }\tag{5}

## 3 先验引导的时序融合价值分解算法 $\mathbf { P G L }$ QMIX

## 3.1  系统架构

为提升复杂环境下多无人机协同航路规划的效率与稳定性，本文提出一种先验引导的时序融合价值分解算法PGL-QMIX。本方法在集中训练、分散执行框架下，将启发式先验信息与多智能体值分解结构相结合：在静态环境中，系统首先为每架无人机离线生成A\*参考路径；训练阶段利用全局状态与完整参考路径，而执行阶段每个智能体仅访问其感知范围内的局部路径片段和局部环境信息，从而在引入全局趋势先验的同时保持部分可观测设定。

如图2所示，PGL-QMIX采用“个体层-系统层”两级时序建模结构。个体层将局部A\*路径片段与无人机局部观测共同输入LSTM，以提取融合先验引导和局部动态信息的时序特征；系统层进一步对所有智能体的时序表征进行融合，生成满足单调性约束的混合权重与偏置，构建联合动作价值函数。

## 3.2  局部可见路径片段的先验引导与时序融合

A\*算法是一种典型的基于启发式搜索的全局航路规划方法，其评价函数定义为

$$
f \left( n \right) = g \left( n \right) + h \left( n \right)\tag{10}
$$

其中， $g \left( n \right)$ 表示起点到当前节点的累计代价，$h ( n )$ 为从该节点到目标的启发式估计。 $\mathrm { A } ^ { * }$ 能够在静态环境中高效生成具有明确全局趋势的参考路径，但其仅面向静态障碍和单无人机场景，难以处理多机交互。因此，本文不将A\*作为在线决策策略，而是将其输出路径转化为启发式先验，为强化学习提供全局方向引导。为适应部分可观测设定，本文仅截取无人i机的感知范围内的局部A\*路径片段。对于第架无人机，在静态地图中离线计算其最短路径 $P _ { \mathrm { r e f } } ^ { i } =$ $\{ P _ { 1 } ^ { i } , P _ { 2 } ^ { i } , \cdots , P _ { L _ { i } } ^ { i } \}$ ，并在运行时根据当前位置 ${ \mathbf { } } _ { } { p } _ { i } ( t )$ 与感知半径 $r _ { o }$ 提取局部可见片段

$$
\mathcal { Q } _ { t } ^ { ( i ) } = \{ P _ { j } ^ { i } \in P _ { \mathrm { r e f } } ^ { i } \mid \Vert P _ { j } ^ { i } - p _ { i } ( t ) \Vert \leq r _ { o } \}\tag{11}
$$

为在局部路径片段 $\varOmega _ { t } ^ { ( i ) }$ 内综合评估各参考节点的重要性，本文为每个节点 $P _ { j } ^ { i }$ 构建综合评分函数。具体定义为

$$
\omega _ { j } ^ { ( i ) } ( t ) = \frac { d _ { o } ^ { i } ( \mathbf { { \cal P } } _ { i } ^ { j } ) + \operatorname* { m i n } _ { k } d _ { \mathrm { u } } ^ { i k } ( \mathbf { { \cal P } } _ { i } ^ { j } ) } { d _ { \mathrm { r e f } } ^ { i } ( \mathbf { { \cal P } } _ { i } ^ { j } ) + d _ { \mathrm { g } } ^ { i } ( \mathbf { { \cal P } } _ { i } ^ { j } ) + 1 }\tag{12}

## 3.3  状态-动作时序融合下的Q值结构优化

在多无人机协同导航中，环境与个体策略随时间演化，体间交互呈现显著的非平稳性。仅依靠个体层时序建模难以反映群体协同行为的动态依赖，易导致联合价值评估不稳定。为此，本文在PGL-QMIX框架中引入系统层LSTM，生成时间相关的非线性权重与偏置，以自适应调节各个体Q值对联合Q的贡献，从而提升联合策略对非平稳交互的表达力与稳定性。

由3.2节的先验嵌入LSTM得到个体时序特征$h _ { t } ^ { i }$ i针对第 架无人机，定义其个体动作价值函数为

$$
Q _ { i } ( { h } _ { t } ^ { i } , { \bf { a } } _ { t } ^ { i } ; \boldsymbol { \theta } _ { i } ) = \mathbb { E } \left[ r _ { t } + \gamma \mathrm { { m a x } } _ { \boldsymbol { a } ^ { \prime } } Q _ { i } ( { h } _ { t + 1 } ^ { i } , { \boldsymbol { a } } ^ { \prime } ; \boldsymbol { \theta } _ { i } ^ { - } ) \right]\tag{14}
$$

其中， $r _ { t }$ 为即时团队回报， $\theta _ { i }$ 与 $\theta _ { i } ^ { - }$ 分别为评估网络和目标网络参数。个体Q函数在局部观测与先验引导下的时序价值，评估个体动作的价值。需要指出的是， $\mathrm { A ^ { * } }$ 先验仅提供全局几何趋势信息，并不直接保证多无人机间的无冲突协同；相关的动态冲突缓解与联合避障由系统层LSTM的时变权重及其单调性混合网络共同实现。首先在时间步t收集所有智能体的时序特征，并构造反映全局协同行为的输入向量。将所有个体的时序表征拼接为${ \pmb m } _ { t } = \mathrm { C o n c a t } \left( { \pmb h } _ { t } ^ { 1 } , { \pmb h } _ { t } ^ { 2 } , \cdots , { \pmb h } _ { t } ^ { N } \right)$ 系统层LSTM在时间维度整合 $\mathbf { \nabla } m _ { t }$ 的体间依赖并输出隐藏状态

$$
[ z _ { t } , C _ { t } ] = \mathrm { L S T M } _ { \operatorname* { m i x } } ( { m } _ { t } , [ z _ { t - 1 } , C _ { t - 1 } ] ; \theta _ { m } )\tag{15}
$$

其中 $\theta _ { m }$ 为系统层LSTM参数。随 $\sqrt { \_ }$ ，由该LSTM架构的输出层直接生成混合权重与偏置

$$

$$

$$

为全面评估所提方法的性能，本文设计了对比实验与消融实验。对比算法包括多智能体值分解方法VDN, QMIX，基于策略梯度的集中式训练与分布式执行（Centralized Training with DecentralizedExecution, CTDE）算法MAPPO以及传统启发式路径规划算法A\*。此外，在PGL-QMIX框架上构造3种消融变体：(1)No-Prior(去除A\*启发式先验)、(2)No-iLSTM(去除个体层LSTM)和(3)No-sLSTM(去除系统层LSTM)，分别用于分析先验引导、个体时序建模和系统层时序融合对算法性能的影响。相关超参数设置见表1。

## 5    结束语

针对多无人机协同避障与航路规划问题，本文提出了一种先验引导的多智能体价值分解方法。本方法利用A\*离线生成参考路径作为弱先验，并通过双层时序网络融合局部观测与先验信息，对局部动态和群体协同进行建模，从而提高联合价值估计的稳定性与协同性。仿真结果表明，本方法能够在保持实时性的同时减少路径冲突，提升多无人机航路规划的可行性与协同性。

本文在三维栅格环境下采用离散动作空间进行协同规划，尚未显式考虑真实无人机的动力学约束与通信机制。未来工作将从两个方面展开：一是结合无人机三维动力学与安全约束，引入轨迹生成与优化方法，将离散路径映射为可跟踪的平滑轨迹；二是引入显式通信与信息共享机制，进一步研究面向协同避障的通信决策与信息选择方法，以提升群体协同效率与安全性。

# Prior-guided Temporal Fusion Method for Multi-UAV Cooperative Obstacle-avoidance Route Planning

WANG Ao① LI Dapeng① XU Yifan② FAN Bingyang③ HAN Guang① ZHAO Haitao①

①(School of Communications and Information Engineering, Nanjing University of Posts and Telecommunications, Nanjing 210003, China)

②(College of Communications Engineering, Army Engineering University of PLA, Nanjing 210001, China)   
③(Portland Institute, Nanjing University of Posts and Telecommunications, Nanjing 210023, China)

## Abstract:

Objective Traditional multi-agent reinforcement learning methods for multi-Unmanned Aerial Vehicle(UAV) cooperative obstacle-avoidance route planning in cluttered 3D environments often suffer from slow convergence, weak coordination, and limited global awareness under partial observability. To address these limitations, this paper proposes a prior-guided temporal fusion value-decomposition framework, termed Prior-Guided-LSTM-QMIX (PGL-QMIX). The method uses local heuristic scores derived from offline A\* reference paths to guide decision-making under partial observability. The aim is to reduce route length, avoid collisions, and preserve real-time planning capability. Methods The multi-UAV cooperative obstacle-avoidance route-planning task is formulated as a Partially Observable Markov Decision Process (POMDP). In the offline stage, A\* is used to generate a reference path for each UAV. During online execution, only the locally visible path segment is extracted, and heuristic scores are constructed from this local prior information and fused with each UAV’s local observation. An individual-level Long Short-Term Memory (LSTM) network is used to capture temporal dependencies in local perception and prior guidance, whereas a system-level LSTM-based mixing network dynamically generates the mixing weights and bias for value decomposition, thereby enabling coordinated joint action-value estimation. Potential-based reward shaping is further adopted to improve training stability. Results and Discussions Simulation results in 3D grid environments show that PGL-QMIX converges faster and more stably than QMIX, VDN, and MAPPO. Compared with the corresponding second-best result in each scenario, PGL-QMIX reduces the number of convergence steps by 3.0%, 7.2%, and 7.4%, improves the steadystate task success rate by 1.26, 4.41, and 8.12 percentage points, and shortens the average route length by 6.2%, 8.5%, and 10.0%, respectively. In addition, the generated trajectories are shorter and more efficient across different map sizes. Conclusions PGL-QMIX improves coordination, safety, and route efficiency for multi-UAV cooperative obstacle avoidance in cluttered 3D environments. By integrating heuristic prior guidance, recurrent temporal fusion, and value decomposition, the proposed method achieves faster convergence, higher success rates, and better generalization than existing baselines. Future work will incorporate real UAV dynamic constraints and communication-aware cooperative obstacle avoidance.
