# Cooperative Task Allocation of Multi-UAVs Based on Multi-Strategy

Improved RIME Algorithm

CHEN Haiyang，GUO Jinhui，JIA Tong，HAN Yang，YANG Lei (School of Electronic Information, Xi'an Polytechnic University, Xi'an, 710048)

Abstract:Aiming at the cooperative task allocation problem of multiple unmanned aerial vehicles (UAVs) in a multi-target scenario, this paper builds a task allocation constraint programming model with the objective of minimizing cost based on real three-dimensional elevation data (DEM). A UAV task allocation method based on the multi-strategy improved rime ice optimization algorithm (MIRIME) is proposed. By introducing a piecewise chaotic mapping to enrich the initial diversity of the population, embedding a reinforcement learning mechanism to achieve adaptive adjustment of the search strategy, the algorithm's convergence accuracy is improved. In addition, an elite local search strategy is combined to further enhance the algorithm's local exploitation ability. Simulation experiment results show that MIRIME reduces the total cost by 10.8% compared with the original RIME algorithm, demonstrating the superiority of the MIRIME algorithm in solving the cooperative task allocation problem of multiple UAVs.

Keywords: UAV; Collaborative task allocation; RIME algorithm; DEM

无人机（UAV）凭借其成本低廉、适应性强等特点，已在民用及军事领域展现出广泛的应用潜力。尤其在军事范畴内，无人机能够胜任情报搜集[1]、火力支援[2]、压制敌方防空系统[3]等复杂且关键的任务，成为现代战场上不可或缺的装备。在实际作战中，单无人机受限于载荷能力、续航时长与功能覆盖范围，面对多目标、强对抗、动态变化的复杂场景时，任务完成效率较低[4]，往往需要多无人机协同执行任务，而多无人机协同任务合理分配成为高效完成任务的关键[5]，因此多无人机协同任务分配问题成为当前无人机自主控制领域需要解决的关键问题[6]。

任务分配问题模型的构建是求解的基础，多无人机协同任务分配是指在满足多维度约束的前提下，将任务集合理分配给无人机集群，使无人机花费最小代价实现任务收益的最大化。多无人机协同任务分配问题通常被建模为一个组合优化问题[7]，常见有多旅行商问题[8]、混合整数线性规划模型[9]和协同多任务分配问题[10]等。这些模型为不同场景下的任务分配问题提供了求解基础，但仍需结合实际需求进一步优化。

求解算法是任务分配的核心工具，求解算法主要分为最优化方法、基于市场机制的方法和启发式算法。最优化方法主要有线性规划(LP)、整数规划(IP)和分支定界法[11](Branch and Bound, B&B)等，该类方法往往可以求出精确解，但随着问题规模变大，计算复杂度呈指数增大。基于市场机制的算法主要有合同网协议[12](Contract Net Protocol, CNP)、基于博弈论和基于拍卖机制等[13]，该类算法灵活性高，但容易受个体行为影响，计算成本高。启发式算法是当前研究的主流，常见有遗传算法、粒子群算法[14]和蚁群算法等，该类算法易实现，计算成本低且性能优越，适用于复杂多约束场景。例如，文献[15]设计了一种混合粒子群任务分配算法，解决异构多无人机任务分配问题。文献[16]提出一种基于无监督学习离散鸽群算法用于求解多无人机任务分配。这些研究为多无人机任务分配提供了有效思路，但针对实际场景的复杂性与算法性能仍需进一步优化。

霜冰优化算法（RIME）由 Su 等人[17]于 2023 年提出的，灵感来源于霜冰的形成，算法设计结构精巧，具有很强的寻优能力。然而，在高维复杂问题中，算法容易陷入局部最优，常常难以找到全局最优解。因此，许多研究者进行了改进应用。例如，文献[18]提出一种自适应混沌高斯霜冰算法，用于处理特征选择问题。文献[19]提出一种改进的霜冰算法求解阵列优化问题。尽管这些改进算法取得了一定效果，但根据 NFL 定理（无免费午餐定理），没有一种优化算法能适配所有类型的优化问题，这意味着现有改进算法面对多样化的高维复杂问题时，性能仍有提升空间，因此需要进一步对 RIME 的寻优性能进行改进。

为了更好地解决复杂环境下多无人机协同任务分配问题，以三维高程数据为基础，构建以最小化成本为优化目标的任务分配约束规划模型，并提出一种融合强化学习机制与精英局部搜索策略的多策略改进霜冰(Multi‑strategy Improved RIME，MIRIME)算法用于求解多无人机三维协同任务分配问题，在满足约束条件下，规划出成本最小的分配方案。

## 1 任务分配问题模型

## 1.1 问题描述

本文针对三维复杂场景下多无人机协同任务分配问题。无人机在三维空间执行任务需要规避地形障碍；任务区域内存在多个威胁区域，无人机距离威胁中心越近，被击毁的概率越高；需要N 架无人机执行 M个任务目标；每个任务被至少一架无人机执行且任务需在指定时间窗口完成；无人机毁伤会导致任务失败，需保证无人机生存概率。在满足上述条件下，使任务分配方案的代价最低。

## 2 多策略改进霜冰算法

## 2.1霜冰算法

霜冰(Rime Algorithm, RIME)算法的核心思想来源于自然界中霜冰形成与扩散的过程，构建软霜随机搜索机制与硬霜穿刺机制，实现全局探索和局部开发。霜冰算法具有结构简单、搜索效率高和计算成本低等优点，适合求解高维多约束复杂优化问题。

## 2.2 MIRIME 的改进措施

## 2.2.1 Piecewise 混沌映射

标准RIME算法采用随机初始化，容易导致初始种群分布不均匀等情况，使得算法在初期优化效率不高。相比之下，如果初始解的分布足够均匀，算法后续的搜索方向将更具多样性，从而提高整体算法搜索效率。混沌映射被广泛证明为解决种群初始质量的有效方法，为此，本文提出的改进霜冰算法(MIRIME)采用分段（Piecewise）混沌映射生成初始种群。其核心是将定义域划分为多个子区间，每个子区间采用不同函数生成具有混沌特性的序列。数学表达式如式（17）所示。

$$
\begin{array} { r } { R _ { i , j + 1 } = \left| \begin{array} { l l l } { R _ { i , j } } & { 0 < R _ { i , j } < p } \\ { p } & { 0 < R _ { i , j } < p } \\ { R _ { i , j } - p } & { p < R _ { i , j } < 0 . 5 } \\ { 0 . 5 - p } & { 0 . 5 < R _ { i , j } } \\ { 0 . 5 - p } & { 0 . 5 < R _ { i , j } < 1 - p } \\ { \frac { 1 - R _ { i , j } } { p } , } & { 1 - p < R _ { i , j } < 1 } \end{array} \right| } \end{array}\tag{17}
$$

式中：初始值 $R _ { \mathrm { i , 1 } }$ 由均匀分布随机生成，分段阈值参数 $p$ 取 $0 . 4$ 。

当前文献中大部分采用 Logistic 映射进行初始化，但Logistic 混沌映射的参数敏感性强，序列分布存在偏向性。而 Piecewise 混沌映射分多个子区域进行映射，全局遍历性更好。混沌点图如图 1所示。

## 2.2.2强化学习自适应搜索策略

在原RIME算法中，软霜探索阶段和硬霜开发阶段的选择，过分依赖参数E与随机数，参数敏感性高，易导致算法探索能力与开发能力的失衡。为了平衡算法的全局探索与局部开发，本文将强化学习算法的机制引入RIME算法中，实现搜索阶段的自适应动态调整。强化学习机制核心是一个试错的过程，通过与环境的交互，指导算法在不同的状态选择最佳的动作，例如在多样性丰富的初期，分别选择各动作，得到奖励反馈根据更新方程及时更新Q 表，最终确定最优动作。核心框架主要由状态、动作、奖励和策略组成。

状态空间基于迭代进度离散化为5 个状态，其数学表达如式（18）所示。

$$
s = \left\{ \begin{array} { l l } { 1 , } & { 0 \leq \frac { t } { T } < 0 . 2 } \\ { 2 , } & { 0 . 2 \leq \frac { t } { T } < 0 . 4 } \\ { 3 , } & { 0 . 4 \leq \frac { t } { T } < 0 . 6 } \\ { 4 , } & { 0 . 6 \leq \frac { t } { T } < 0 . 8 } \\ { 5 , } & { 0 . 8 \leq \frac { t } { T } \leq 1 . 0 } \end{array} \right.\tag{18}
$$

式中：t为当前迭代次数，T 为最大迭代次数。

动作空间主要定义三种动作，对应不同的搜索

策略，搜索动作直接与参数E关联，影响算法搜索阶段的选择。其数学表达如式（19）所示。

$$
E = \left\{ \begin{array} { l l } { 0 . 1 , } & { a = 1 } \\ { 0 . 5 , } & { a = 2 } \\ { 0 . 9 , } & { a = 3 } \end{array} \right.\tag{19}
$$

动作 1侧重局部开发，算法优先选择硬霜机制进行开发；动作2 侧重探索与开发的平衡，混合软霜机制与硬霜机制进行探索；动作3侧重全局探索，算法优先选择软霜机制进行探索。

奖励函数 r 用于量化当前动作带来的适应度提升，并通过归一化限制其在[0,1]之间，表达式如式（20）所示。

$$
r \left( t \right) = \operatorname* { m i n } \left( 1 , \operatorname* { m a x } \left( 0 , \frac { f _ { b e s t } \left( t - 1 \right) - f _ { b e s t } \left( t \right) } { \left| f _ { b e s t } \left( t - 1 \right) \right| + \delta } \right) \right)\tag{20}
$$

式中： $f _ { \mathrm { b e s t } } ( t { - } 1 )$ 和 $f _ { \mathrm { b e s t } } ( t )$ 分别表示 t-1阶段和t阶段的全局最优适应度值，为一个极小的常数，用于防止除零。

Q 表的更新机制通过 Bellman 方程实现，其数学表达如式（21）所示。

$$
\begin{array} { r l } & { Q \bigl ( s , a \bigr ) \gets Q \bigl ( s , a \bigr ) + } \\ & { \alpha \cdot \Bigl [ r + \gamma \cdot \operatorname* { m a x } _ { a } , Q \bigl ( s ^ { \prime } , a ^ { \prime } \bigr ) - Q ( s , a ) \Bigr ] } \end{array}\tag{21}
$$

式中：Q(s,a）代表状态s下选择动作 $a$ 的价值函数，学习率 α=0.1，控制更新幅度， $\gamma$ 为折扣因子，用于平衡当前奖励与未来奖励。 $s ^ { \prime }$ 代表下一状态， $a ^ { \prime }$ 代表下一状态的可能动作。

动作选择策略采用??-贪婪策略，即以大概率利用当前最优，小概率随机探索。其数学表达如式（22）所示。

$$
a = \left\{ \begin{array} { l l } { r a n d ( a ) , } & { r a n d < \varepsilon } \\ { \arg \operatorname* { m a x } _ { a } { Q ( s , a ) } , } & { o t h e r w i s e } \end{array} \right.\tag{22}
$$

式中：探索概率??=0.2，rand(a)表示随机选择动作a，a∈[1,2,3]。

## 2.2.3精英局部搜索

在 RIME 算法的硬霜开发阶段，直接调用全局最优解的信息，这将导致算法在最优解附近难以精细搜索，容易陷入局部最优。为了克服这些不足，本文引入基于 Levy 飞行的精英局部搜索策略，利用Levy飞行的重尾特性对当前最优个体进行扰动，提高算法局部开发精度，避免陷入局部最优。

Levy 飞行是一种具有重尾分布特性的随机游走模型，其步长分布满足幂律衰减。其步长变化图如图 2所示，数学表达式如（23）所示。

$$
s t e p = \frac { \mu } { \left| \boldsymbol { \nu } \right| ^ { 1 / \beta } } \cdot \sigma\tag{23}
$$

$$
\sigma = \left( \frac { \Gamma \left( 1 + \beta \right) \cdot \sin \left( \pi \beta / 2 \right) } { \Gamma \left( \left( 1 + \beta \right) / 2 \right) \cdot \beta \cdot 2 ^ { \left( \beta - 1 \right) / 2 } } \right) ^ { 1 / \beta }\tag{24}
$$

式中：step 表示步长， $\mu$ 和 v 为服从正态分布的随机数，特征指数 β=1.5，??为尺度参数。

精英局部搜索的数学表达如（25）所示。

$$
R ^ { n e w } = R _ { b e s t } + \alpha + s t e p\tag{25}
$$

式中： $R _ { \mathrm { b e s t } }$ 为当前全局最优个体，扰动强度系数α=0.01。

## 2.2.4任务编码及映射

MIRIME算法难以适配多无人机任务分配问题。本文决策变量采用多维度融合的编码策略，编码向量主要由无人机分配、任务序列及成本约束构成，其中向量维度按无人机数量、任务数量及两者最大规模划分。为确保各维度决策变量在统一尺度下优化，将无人机分配、任务序列和成本约束分别除以自身的向量维度进行归一化，将离散决策转化为连续向量 K。

映射过程采用最小代价偏差匹配策略，整个过程分为两个阶段。首先是初始任务匹配阶段，将求解出的连续向量 K （1：N）作为理想成本代价，在任务代价矩阵中匹配偏差最小的元素，之后将已匹配的元素赋予无穷值，保证该任务不被重复执行。第二阶段为任务序列的构建，根据阶段一的结果，初始化中间代价矩阵，行索引代表无人机当前位置到所有未分配任务的代价，剩余向量 K （N+1：M）作为理想转移成本，在中间代价矩阵中匹配到偏差最小的元素后，将其赋予无穷值防止该任务被重复执行。更新无人机位置，重复阶段二直到确定最终分配方案。

## 2.2.5 算法复杂度分析

MIRIME 算法时间复杂度主要取决于种群规模 N、最大迭代次数T 和问题维度D。在迭代过程中，种群位置更新的复杂度为 O(T·N·D)，精英局部搜索策略的复杂度为 O(T·K·D)。由于强化学习策略选择为常数级开销，且K≪N，因此 MIRIME 的复杂度仍为O(T·N·D)阶数，并未增加算法的时间复杂度量级。

综上所述，MIRIME 算法优化性能最好，原RIME 算法次之，这一结果不仅验证了改进 RIME算法的合理性，也证明MIRIME算法提供的任务分配方案更合理高效。

## 4 结语

本文针对多无人机协同任务分配问题，首先建立基于真实三维高程数据的环境模型，通过考虑任务执行成本、时间成本、毁伤成本及约束惩罚完成问题的数学建模，并提出一种多策略改进霜冰(MIRIME)算法进行求解，在仿真实验中，MIRIME算法的分配方案成本更低，能够有效解决多无人机协同任务分配问题。后续研究将考虑更先进的约束处理办法（如可行性规则、-约束法等），实现更高效的约束处理；同时，考虑引入动态威胁，优化算法的实时性，以适配更复杂的实战场景。
