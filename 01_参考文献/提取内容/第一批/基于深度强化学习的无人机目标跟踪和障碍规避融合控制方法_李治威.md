# 基于深度强化学习的无人机目标跟踪和障碍规避融合控制方法

李治威，刘志宏，王祥科

## 摘要

在障碍环境下，由于目标运动不确定、视野遮挡、无人机自身动力学约束等影响，无人机对非协作目标的持续跟踪依然面临着技术挑战。对此，提出了一种基于深度强化学习的目标跟踪和障碍规避融合控制方法。该方法基于端到端的思想，设计直接从图像特征映射到无人机控制指令的融合控制策略，可有效克服传统控制中跟踪与避障模块分离设计的局限。首先，设计一种结合单应性变换的运动补偿扩展卡尔曼滤波方法，在图像平面中实时估计目标的位置与运动方向；随后，设计基于深度强化学习的运动控制器，将传感器观测输入策略网络，实时生成控制指令，使无人机能够自主跟踪运动目标并规避障碍。通过对比实验，验证了所提方法在目标跟踪稳定性、运动平滑度及计算实时性等方面的优越性。

## 0 引言

随着无人机（UAV）在物流运输、灾害救援、电力巡检、影视航拍等领域的广泛应用，其在复杂障碍环境下的自主目标跟踪能力已成为迫切需求[1-4]。这一能力要求无人机在保证自身安全的同时，持续跟踪运动目标，并确保目标始终处于机载传感器的有限视场内。在城市、丛林等非结构化障碍环境中，目标运动的不确定性、障碍物造成的视野遮挡及无人机自身动力学约束，使得该问题极具挑战性[5-7]。

针对无人机目标跟踪问题，已有大量研究成果[8-13]。传统方法主要分为基于运动预测与轨迹优化的规划方法。这类方法通常将问题分解为目标状态估计和安全轨迹生成两个阶段。例如，HAN等[10]采用基于贝塞尔曲线的约束回归方法进行目标运动预测，并结合启发式的带运动学和动力学约束的路径搜索前端与时空最优轨迹优化后端，实现了在杂乱环境中对运动目标的鲁棒跟踪，但路径搜索阶段没有考虑障碍遮挡的问题。JEON等[11] 在目标预测时使用协变优化，将障碍物地图信息融入目标轨迹回归中，使预测更加真实，且后端轨迹规划中同时考虑了安全和可视的约束，最终通过实物验证了算法的可靠性。PAN等[12] 针对其不足进行了多方面的改进，不仅用云台相机代替了相机阵列以减少感知对规划的限制，而且在路径搜索中引入遮挡相关的损失函数，提升了算法在转角等场景的鲁棒性。JI等[13] 引入可视区域约束，并与安全、时间等多个约束统一优化，进一步提高了跟踪的鲁棒性。这类方法通常具有良好的可解释性，但其性能严重依赖前端目标预测与路径搜索的准确性，且通常需要精确的环境感知信息作为输入。

近年来，基于深度学习的方法也被广泛探索并取得了进展。BHAGAT 等[14] 提出了 TF-DQN 算法，利用深度 Q 网络（DQN）框架结合课程学习训练，使无人机能够在障碍环境中持续跟踪目标，但网络输出仅为6种离散动作，限制了无人机性能。XU等[15] 则针对深度强化学习（DRL）算法收敛慢、成功率低的问题，提出了多经验池双延迟深度确定性策略梯度算法（MPTD3），通过设计连续的状态与动作空间以及多个经验回放池机制，提升了算法的收敛速度和跟踪成功率。为了进一步提升模型对多种目标运动轨迹的泛化能力，SHEN等[16] 基于元强化学习理论，提出了 PEARL-2Buf算法，使无人机通过元任务集学习快速适应不同跟踪任务，而无需针对新任务重新训练。同时，最新的研究开始向更复杂的场景延伸。针对野外非结构化环境下的高速飞行挑战，LOQUERCIO等[17] 探索融合深度图与本体状态的多模态观测策略，显著提升了无人机在极端环境下的敏捷性。在跨平台迁移学习方面，SADEGHI等[18] 提出的 CAD2RL 框架通过高度的域随机化技术，证实了仅利用仿真渲染图像即可训练出能直接迁移至真实世界的飞行策略。SINGLA等[19] 则针对动态环境下的避障难题，提出了基于记忆模块的深度强化学习方法，增强了智能体在环境知识受限情况下的自适应避障能力。然而，尽管上述研究推动了领域发展，但现有的端到端主动跟踪方法仍存在显著局限。例如，LUO等[20] 提出的基于强化学习的主动目标跟踪算法虽实现了端到端的视觉控制，但直接采用原始高维 RGB 图像作为观测输入，导致特征提取难度大，且离散化动作输出难以满足无人机对运动平滑性与控制精度的需求。此外，现有方法大多缺乏对跟踪精度、避障安全与运动平稳性的协同优化，且常依赖目标位置真值以降低学习难度，这在实际的非协作目标跟踪任务中难以实现，因而限制了其应用价值。

针对传统方法中跟踪与避障模块分离设计的局限，本文充分发挥深度强化学习的端到端决策能力，提出一种基于深度强化学习的融合控制方法，实现目标跟踪与障碍规避的一体化决策。该方法的核心在于利用深度网络的特征映射能力，设计联合优化跟踪误差与碰撞风险的奖励函数，引导智能体在仿真环境中自主学习，实现从图像特征到无人机控制指令的端到端映射，最终使智能体习得一种无需显式环境地图构建、不依赖目标位置信息的鲁棒策略模型。该策略以机载相机捕获图像中目标的特征信息作为直接观测，实现了对非协作目标的纯视觉跟踪与避障，有效规避了对目标进行独立位姿估计的难题。

## 2 基于 EKF的目标状态估计

EKF算法作为系统状态估计问题的经典框架，因其在估计精度和计算效率之间具有良好的平衡性而被广泛采用。本文针对无人机动态平台对运动目标的视觉跟踪问题，提出一种结合单应性变换的运动补偿扩展卡尔曼滤波方法。

## 2.1 状态定义与运动模型

为估计目标在相机图像平面中的运动，本文将目标的状态定义为包含其位置与速度的 4维向量$\mathbf { x } _ { k } = [ u _ { k } , \nu _ { k } , \dot { u } _ { k } , \dot { \nu } _ { k } ] ^ { \mathrm { T } }$ ，其中， $( u _ { k } , \nu _ { k } )$ 为目标在像素坐标系中的中心坐标， $( \dot { u } _ { k } , \dot { \nu } _ { k } )$ u v为其在   和   方向上的像素变化速率。

对于目标在图像平面内的运动特性，本文采用恒定速度（CV）模型进行建模。该模型假设在较短的采样周期内，目标的像素坐标变化速率保持不变。基于此模型，系统的离散时间状态转移方程可表示为

$$
\begin{array} { l } { { \pmb { x } } _ { k } = F { \pmb { x } } _ { k - 1 } + { \pmb { w } } _ { k } } \\ { \quad { \pmb { F } } = \left[ \begin{array} { c c c c } { 1 } & { 0 } & { \Delta t } & { 0 } \\ { 0 } & { 1 } & { 0 } & { \Delta t } \\ { 0 } & { 0 } & { 1 } & { 0 } \\ { 0 } & { 0 } & { 0 } & { 1 } \end{array} \right] , ~ { \pmb { w } } _ { k } \sim N ( 0 , { \pmb { Q } } _ { k } ) } \end{array}\tag{1}
$$

其中，过程噪声 ${ \pmb w } _ { k }$ 被建模为均值为 0、协方差矩阵为 $Q _ { k }$ 的高斯过程。

## 2.2 无人机运动补偿

无人机在飞行过程中，其相机位姿持续变化，导致世界坐标系下同一空间点在图像平面上的投影坐标随之变化。为在图像平面进行连续滤波，需首先解耦无人机自身运动带来的坐标变化。为解决此问题，本文针对城市安防、交通监控及野外平原巡检等主流应用场景，提出两点假设：其一为无人机飞行高度保持不变；其二为被跟踪目标在平坦的地面上运动。做出这些假设的依据在于：在上述任务中，无人机通常在指定空域层执行定高巡航，而车辆、行人等目标主要在起伏平缓的道路或广场上运动。因此，该模型在简化任务复杂度的同时，仍能保持对现实环境的高度近似。基于以上假设，前后两帧相机视图对同一地面目标的成像关系可由单应矩阵描述。本文利用连续两帧间的单应矩阵，将不同相机位姿下观测到的目标坐标统一变换至同一参考视角，从而在滤波前补偿了无人机运动的影响。

## 2.3 扩展卡尔曼滤波流程

结合上述模型，EKF的具体步骤为：

1) 初始化。根据第 1帧检测结果初始化状态向量 $x _ { 0 }$ 及其误差协方差矩阵 $\pmb { P } _ { 0 }$ 。

2) 预测。根据系统模型预测下一时刻状态：

$$
\pmb { x } _ { k } ^ { - } = \pmb { F } \pmb { x } _ { k - 1 }\tag{2}
$$

$$
\pmb { P } _ { k } ^ { - } = \pmb { F } \pmb { P } _ { k - 1 } \pmb { F } ^ { \mathrm { T } } + \pmb { Q } _ { k - 1 }\tag{3}
$$

3) 更新。观测量为当前帧直接检测到的目标图像中心坐标 ${ \boldsymbol { z } } _ { k } = \left[ u _ { k } ^ { \mathrm { o b s } } , \nu _ { k } ^ { \mathrm { o b s } } \right] ^ { \mathrm { T } }$ 。观测方程可建模为

$$
\begin{array} { r l } & { z _ { k | k - 1 } = H x _ { k } ^ { \mathrm { c o m p } } + \pmb { \nu } _ { k } } \\ & { H = \left[ \begin{array} { c c c c } { 1 } & { 0 } & { 0 } & { 0 } \\ { 0 } & { 1 } & { 0 } & { 0 } \end{array} \right] , ~ \pmb { \nu } _ { k } \sim N ( 0 , \pmb { R } _ { k } ) } \end{array}\tag{4}
$$

其中，观测噪声 $\nu _ { k }$ 被建模为均值为 0、协方差矩阵为 $\pmb { R } _ { k }$ 的高斯过程， $\pmb { x } _ { k } ^ { \mathrm { c o m p } }$ 为补偿后的状态向量。卡尔曼增益计算为

$$
K _ { k } = P _ { k } ^ { - } H _ { k } ^ { \mathrm { { T } } } ( \pmb { H } _ { k } \pmb { P } _ { k } ^ { - } \pmb { H } _ { k } ^ { \mathrm { { T } } } + \pmb { R } _ { k } ) ^ { - 1 }\tag{5}
$$

状态更新：

$$
\pmb { x } _ { k } = \pmb { x } _ { k } ^ { - } + K _ { k } ( z _ { k } - \pmb { H } \pmb { x } _ { k } ^ { \mathrm { c o m p } } )\tag{6}
$$

协方差更新：

$$
\pmb { P } _ { k } = ( \pmb { I } - \pmb { K } _ { k } \pmb { H } _ { k } ^ { \mathrm { T } } ) \pmb { P } _ { k } ^ { - }\tag{7}
$$

该目标估计器最终输出为 $\pmb { \sigma } _ { t } ^ { \mathrm { d } } = [ u _ { t } , \nu _ { t } , h _ { t } , \dot { u } _ { t } , \dot { \nu } _ { t } ] ^ { \mathrm { T } }$ ，旨在为后续跟踪控制方法提供目标状态信息。其中， $h _ { t }$ 为直接来自目标检测器的检测框高度信息，在目标物理尺寸变化不明显的场景，该信息间接反映了目标和无人机之间的相对距离，其余 4个分量来自目标估计器的状态信息， $( u _ { k } , \nu _ { k } )$ 可以作为视觉伺服信号引导无人机跟踪目标， $( \dot { u } _ { k } , \dot { \nu } _ { k } )$ 构成的向量则间接反映了无人机航向和目标朝向的关系。

## 3 基于 DRL 的目标跟踪控制

无人机在障碍环境中的目标跟踪任务可以建模为部分可观的马尔科夫决策。部分可观的马尔科夫(S,A,P,R,Ω,O)决策可以用一个六元组 表示。其S A P中， 表示状态空间；   表示动作空间；   为状态R Ω转移概率； 为奖励函数； 表示所有可能观测的O a集合；   表示当执行了动作   且状态转移到 $\mathbf { { \pmb { s } } ^ { \prime } } .$ 后，o得到的观测   的概率（ $\begin{array} { r } { \bigcirc ( s ^ { \prime } , \pmb { a } , \pmb { \sigma } ) - P _ { \circ } ( \pmb { o } | s ^ { \prime } , \pmb { a } ) \bigcirc } \end{array}$ ， $P _ { \mathrm { ~ o ~ } }$ 表示观测概率函数。

## 3.1 观测空间

对于此任务，观测空间由来自 2维激光雷达和目标检测器的外部感知信息，以及来自惯性测量单t元的自身感知信息共同构成。具体而言， 时刻的观测可以表示为 $\pmb { \theta } _ { t } = \left[ \pmb { \theta } _ { t } ^ { z } , \pmb { \theta } _ { t } ^ { \mathrm { d } } , \pmb { \theta } _ { t } ^ { \mathrm { v } } \right]$ ，其中， ${ \pmb O } _ { t } ^ { z }$ 表示 2维激光雷达连续 3帧的数据， ${ \pmb { o } } _ { t } ^ { \mathrm { d } }$ 为来自目标估计器的目标状态估计值， ${ \pmb O } _ { t } ^ { \vee }$ 为无人机的速度信息。为降低计算复杂度并统一观测空间维度，本文将激光雷达输入数据降采样至 512 维。

## 3.2 动作空间

动作空间由无人机    x方向和    y方向的速度控制指令和偏航角速度控制指令组成，其输出最大值分别为 2.5 m/s、2.0 m/s 和 0.5 rad/s。由于无人机速度控制属于上层控制指令，由嵌入式飞行控制器中的底层闭环控制器负责执行，因此选择该控制方式有效降低了从仿真到实物迁移过程中的模型误差，并使得速度指令在不同环境下具有天然的鲁棒性。

## 3.3 终止条件

本任务的终止条件只有两个：其一，当目标脱离无人机的相机视野；其二，当无人机和目标发生碰撞。当无人机遇到终止条件时，其将被重置至安全位置重新进行任务。

## 3.4 奖励函数

t时刻的奖励函数可以表示为

$$
r _ { t } = r _ { t } ^ { \mathrm { d e t e c t i o n } } + r _ { t } ^ { \mathrm { p o s i t i o n } } + r _ { t } ^ { \mathrm { c o l l i s i o n } } + r _ { t } ^ { \beta } + r _ { t } ^ { \mathrm { s t a t e } } + r _ { t } ^ { \mathrm { g o a l } }\tag{8}
$$

奖励项 $r _ { t } ^ { \mathrm { d e t e c t i o n } }$ 表示将目标保持在视野内所获得的奖励。当检测框与参考框高度重合时，智能体得到较高的奖励；随着偏离程度的增大，奖励值逐渐减小。若两框之间无重叠区域，则奖励为 $0 _ { \circ }$ 。其具体形式为

$$
r _ { t } ^ { \mathrm { d e t e c t i o n } } = \omega _ { \mathrm { d e t e c t i o n } } F _ { \mathrm { I o U } } ( B _ { \mathrm { d e t } } , B _ { \mathrm { r e f } } )\tag{9}
$$

式中， $B _ { \mathrm { d e t } }$ 和 $B _ { \mathrm { r e f } }$ 分别表示当前目标检测框和参考框， $F _ { \mathrm { I o U } } ( B _ { \mathrm { d e t } } , B _ { \mathrm { r e f } } )$ 为两框的交并比（IoU）。

奖励项 $r _ { t } ^ { \mathrm { p o s i t i o n } }$ 用于根据无人机和目标的位置信息引导无人机跟踪目标。若无人机和目标的距离接近预设参考距离，且无人机航线对准目标，则获得奖励；反之，则予以惩罚。具体形式为

$$
\begin{array} { r } { r _ { t } ^ { \mathrm { p o s i t i o n } } = \omega _ { \mathrm { d i s t a n c e } } ( D ( \pmb { p } _ { t - 1 } ) - D ( \pmb { p } _ { t } ) ) } \\ { + \omega _ { \alpha } ( \mathrm { c o s } \alpha _ { t } - \mathrm { c o s } \alpha _ { t - 1 } ) } \end{array}\tag{10}
$$

其中， $D ( \pmb { p } _ { t } ) = \| \vert \pmb { p } _ { t } \| - p _ { \mathrm { r e f } } \|$ 用于计算无人机与目标实际距离与期望距离之间的差值， $\pmb { p } _ { t } \in \mathbb { R } ^ { 3 }$ 表示目标在α无人机机体坐标系下的位置向量；   为无人机和目标连线与无人机航向之间的夹角，如图3所示。

$$

其中， $\beta \in [ - \pi ,$ π]表示无人机航向和目标朝向的夹角。

惩罚项 $r _ { \mathrm { t } } ^ { \mathrm { s t a t e } }$ 用于激励无人机实现平稳运动：

$$
r _ { \mathrm { t } } ^ { \mathrm { s t a t e } } = \omega _ { \mathrm { s t a t e } } \| \pmb { \nu } _ { t } - \pmb { \nu } _ { t - 1 } \|\tag{13}
$$

式中， $\mathbf { \nu } _ { \mathbf { \nu } _ { t } } = [ \nu _ { x } , \nu _ { y } , \omega _ { z } ]$ 为无人机   x轴和   y轴的线速度和偏航角速度。

奖励项 $r _ { t } ^ { \mathrm { g o a l } }$ 为稀疏奖励项，仅在无人机相对目标的状态满足预设条件时生效，其数值设定遵循多目标量级对齐原则，旨在使其与其他稠密奖励项维持在同一数量级，防止因单项激励过大而主导梯度更新方向，具体而言：

$$
r _ { t } ^ { \mathrm { g o a l } } = \left\{ 0 . 2 , \quad \mathrm { i f } F _ { \mathrm { I o U } } ( B _ { \mathrm { d e t } } , B _ { \mathrm { r e f } } ) > F _ { \mathrm { r e f } } \mathrm { a n d } | \beta | < \beta _ { \mathrm { r e f } } \right.\tag{14}
$$

ωdetection 、 、ωdistance $\omega _ { \alpha }$ 、 $\omega _ { \beta }$ 和 $\omega _ { \mathrm { s t a t e } }$ 分别为各奖励项的非负权重，其取值依次设定为 0.2、0.5、0.5、0.05 和 $0 . 0 0 5 _ { \scriptscriptstyle \mathrm { S } }$ 。本文参考了文 [21] 的参数设计，并在训练过程中对其进行了微调。

## 3.5 策略网络

本文提出的策略网络由 1维卷积编码器与多层感知机（MLP）融合模块构成。其中，1维卷积编码器负责将 2维激光雷达输入编码为 512维的特征向量；MLP融合模块则用于将上述特征向量与其他向量化输入进行融合。1 维卷积编码器共包含 3 层结构：第 1隐藏层使用 32个尺寸为 5、步长为 2的1维卷积核对连续 3帧输入数据进行特征提取，随后利用 ReLU（rectified linear unit）激活函数进行非线性处理；第 2隐藏层进一步使用 32个尺寸为 3、步长为 2的 1维卷积核进行卷积运算，同样选用ReLU激活函数处理；第 3层为用于将特征编码为512维的全连接层。MLP融合模块采用单隐藏层结构，其隐藏层特征维度为 256。最后通过一个全连接层将特征映射为 3维动作输出。网络整体结构如图 4和表 1所示，其中橙色部分表示 ReLU激活操作，激光雷达的输入N取512。

## 4.2 模型训练

在模型训练阶段，首先在仿真环境中随机生成障碍物，随后对目标和无人机的位置进行随机初始化，确保二者均不与障碍物发生碰撞，且目标位于无人机的初始视野范围内。为降低训练难度，此阶段将目标设置为静止状态。无人机依据策略网络输出的控制指令进行运动，直至触发任务终止条件或达到预设的最大时间步长。通过随机初始化目标与无人机的相对位姿，该方法可在目标静止的条件下，有效模拟无人机在实际跟踪任务中可能面临的各种状态，从而提升策略的泛化能力。同时，将目标设置为静止状态可显著降低训练初期策略探索的难度，有利于提高训练稳定性与收敛效率，避免因任务复杂度过高而导致训练难以进行。

## 4.3 仿真实验

## 5 结论

本文提出了一种基于深度强化学习的无人机目标跟踪与障碍规避融合控制方法。该方法首先通过结合单应变换的扩展卡尔曼滤波在图像平面估计目标状态；随后，借助端到端的深度强化学习策略网络，将感知信息直接映射为无人机控制指令，实现了跟踪与避障的融合控制，有效避免了传统分层结构中存在的响应延迟与目标丢失风险。训练阶段，通过设计兼顾跟踪精度、避障安全与运动效率的复合奖励函数，并利用 Flightmare 仿真平台的高效并行采样能力对策略网络进行训练，使智能体逐步掌握在障碍环境下的自主跟踪策略。实验与对比分析验证了本文方法的性能优势。在目标速度低于2.0 m/s时，跟踪成功率可达 100%且无碰撞发生。进一步分析表明，无人机在跟踪沿“8”字形路径运动的目标时能够兼顾视场保持与主动避障。与 Fast-Tracker的对比结果显示，本文方法得益于端到端的控制架构，不仅在计算实时性上较分层规划控制方法有显著提升，而且跟踪轨迹更加平滑，有效避免了控制抖动与急停急起现象，验证了本文方法的鲁棒性与平稳性。

然而，本文研究仍存在一定局限性。首先，当前目标状态估计模块依赖于“无人机飞行高度保持不变”与“被跟踪目标在平坦的地面上运动”两项假设，在涉及剧烈高度变化的复杂地形或结构复杂的室内场景中，假设失效可能导致估计精度下降。其次，尽管仿真实验效果显著，但从仿真到现实（Sim-to-Real）的迁移仍面临挑战，真实环境中的传感器噪声、光照变化及通信延迟等非理想因素尚未被完全建模，可能影响实机部署性能。针对上述局限性，未来工作将围绕 3 个方面展开：一是优化状态估计算法，探索摆脱平坦地形假设的估计方法；二是针对 Sim-to-Real迁移难题，引入域随机化与实机微调等技术，提升算法在物理世界中的泛化能力；三是针对单无人机视场有限的固有约束，探索多无人机协同跟踪框架，通过不同视角的信息融合增强系统在遮挡及大范围场景下的鲁棒性与适应性。
