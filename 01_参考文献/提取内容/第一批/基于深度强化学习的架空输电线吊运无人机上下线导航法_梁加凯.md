# 基于深度强化学习的架空输电线吊运无人机上下线导航法

梁加凯1，方玉群1，朱凯1，李炯1，林峰1，宋俊杰2

(1.国网金华供电公司，浙江 金华 321017；2.浙江大学 机械工程学院，浙江 杭州 310058)

摘 要：针对架空输电线路场景下吊运无人机面临的欠驱动、强耦合及多障碍物环境导航难题，本文提出了一种基于分层 PPO-PID 的智能导航方法。首先，构建了考虑阻尼效应与负载转动的二维非线性动力学模型，为系统控制奠定精确的物理基础。进而，设计了分层协同规划控制架构：高层以近端策略优化(PPO)算法为决策器，在连续状态空间中生成离散化局部航点；底层则结合级联比例-积分-微分(PID)控制器，实现对期望轨迹的精准跟踪。在此基础上，构造了融合安全避障、作业时效与主动抗摆等多目标约束的复合奖励函数，引导智能体自主学习兼顾高效逼近与精准稳停的最优策略。仿真实验表明，在上线与下线典型作业场景中，该方法规划成功率均为 100% 。与A\*及 RRT\*算法相比，该方法平均运动时间缩短了约 27%\~32% ，且具备优异的主动抗摆性能，将摆动强度指标始终控制在 0.361 rad²∙s 以下，充分验证了所提方法在复杂非结构化环境下的有效性与鲁棒性。

关键词：吊运无人机；PPO 算法；主动抗摆；深度强化学习；架空输电线

# Navigation Method for Payload-Carrying UAVs Mounting and Dismounting Overhead Transmission Lines Based on Deep Reinforcement Learning

LIANG Jiakai1 , FANG Yuqun 1 , ZHU Kai1 , LI Jiong 1 ,LIN Feng1,SONG Junjie2 (1. State Grid Jinhua Power Supply Company, Jinhua Zhejiang 321017, China； 2. College of Mechanical Engineering, Zhejiang University, Hangzhou Zhejiang 310058, China)

Abstract: To address the navigation challenges posed by the underactuated, strongly coupled dynamics, and multi-obstacle environments faced by payload-carrying UAVs in overhead transmission line scenarios, an intelligent navigation method based on a hierarchical PPO-PID architecture was proposed. First, a two-dimensional nonlinear dynamic model considering damping effects and payload rotation was constructed, laying an accurate physical foundation for system control. Furthermore, a hierarchical collaborative planning and control architecture was designed: the high-level decision-maker, utilizing the Proximal Policy Optimization (PPO) algorithm, generated discretized local waypoints within a continuous state space; the low-level execution incorporated a cascaded Proportional-Integral-Derivative (PID) controller to achieve precise tracking of the desired trajectory. Building on this, a composite reward function integrating

multi-objective constraints—including safe obstacle avoidance, operational efficiency, and active anti-swing— was formulated to guide the agent in autonomously learning an optimal policy that balanced an efficient approach with precise, stable stopping. Simulation results demonstrated that the proposed method achieved a 100% planning success rate in both typical line-mounting and dismounting operational scenarios. Compared with A\* and RRT\* algorithms, the proposed method reduced the average motion time by approximately 27% – 32% and exhibited superior active anti-swing performance, consistently maintaining the swing intensity index below 0.361 rad²∙s. These results fully verify the effectiveness and robustness of the proposed method in complex, unstructured environments.

## 0 引言

随着智能电网建设的推进，输电线路的运维模式正从“人工巡检”向“人机协同作业”转型。在带电作业场景中，作业人员往往需要携带沉重的检修工具(如绝缘杆、金具等)登塔，劳动强度大且安全风险高，而重载无人机凭借其灵活的机动性和垂直起降能力，逐渐被应用于带电作业平台的空中运输任务，成为“空中起重机”[1-2]。然而，相对普通的航拍巡检，吊运作业面临着更复杂的动力学挑战：缆绳连接的负载在气流扰动和无人机机动过程中会产生非线性摆动，这种“双摆”甚至“多摆”效应不仅影响定位精度，严重时还会导致无人机失稳坠机[3]。此外，针对架空输电线路这一特定应用场景，复杂多变的风场气象条件以及高压线路产生的强电磁场，极易干扰无人机的通信与导航设备，进而严重影响其飞行状态的稳定性[13]。因此，如何实现吊运无人机在复杂环境下的自主避障导航，并同时有效抑制负载摆动，是当前亟待解决的关键痛点。

针对无人机路径规划问题，国内外学者已开展了大量研究，主要可分为传统方法和基于学习的方法。早期的研究多采 A\*算法[5]、Dijkstra 算法[6]或快速扩展随机树(RRT)[7]算法，应用非常广泛；最近研究如文献[8]通过改进 A\*算法实现无人机三维环境下的路径规划，能有效减少冗余扩展节点并提升了搜索效率，文献[9]利用改进人工势场法(IAPF)解决了传统人工势场法存在的目标不可达、局部极小及路径振荡问题。然而这些方法通常依赖高精度的全局地图，且在面对动态环境和非线性动力学约束时，计算实时性较差[10]，难以直接应用于高动态的吊运任务，近年来深度强化学习(DRL)因其强大的感知与决策能力成为研究热点。文献[11-12]综述了 DRL 在无人机导航中的应用，证明了其通过与环境交互实现端到端控制的潜力；针对连续控制问题，近端策略优化(PPO)算法表现出了优异的稳定性，姜智中[13]等人提出了一种改进 PPO 算法，显著提升了无人机在复杂障碍环境下的通过率；Tang[14]等人则引入了动作掩码机制，优化了 PPO 在受限空间内的探索效率。尽管通用导航算法已较成熟，但针对吊运无人机的研究仍不够，由于负载的欠驱动特性，单纯的位置控制往往会导致剧烈的残留摆动。Li[15]等人尝试利用 DRL 生成无摆动轨迹，但未充分考虑复杂障碍物环境；Wang[16]等人研究了双摆系统的抗摆控制，但主要集中在姿态稳定而非长距离导航。

针对上述问题，本文提出一种面向架空输电线路带电作业场景的吊运无人机智能导航方法。不同于仅关注单一控制目标的文献[17-18]，本文综合考虑了安全性与效率，主要创新点如下：

1)建立了考虑阻尼效应与负载转动的二维动力学模型。

2)提出了一种具备“主动行为控制”的在线航点规划框架。

3)精心设计了满足多目标约束的复合奖励函数。

## 1.2 吊运无人机系统控制模型

为实现对规划轨迹的精准跟踪，本文基于时间尺度分离原则(Time-Scale Separation Principle)，设计了双层级联 PID 控制模型[20]，将动力学解耦为平动控制子系统(外环)与转动控制子系统(内环)，外环负责解算期望加速度并生成虚拟控制指令，内环则负责快速响应姿态变化以产生实际控制力矩。系统各控制环均采用标准 PID 控制律，其通用表达式为：

$$
\begin{array} { r } { u ( t ) = k _ { p } e ( t ) + k _ { i } \int _ { 0 } ^ { t } e ( \tau ) d \tau + k _ { d } \dot { e } ( t ) } \end{array}\tag{8}
$$

式中： $u ( t )$ 为控制输出； $e ( t )$ 为系统输入误差； $k _ { \mathrm { p } }$ 、$k _ { \mathrm { i } }$ 和 $k _ { \mathrm { d } }$ 分别为比例、积分和微分增益系数；为了防止执行器饱和，所有的积分项均引入了抗饱和(Anti-windup)机制。

## 1.2.2 转动控制子系统(姿态/角速率环)

转动环处于控制模型最底层，要求具备最高的控制带宽以快速跟踪期望俯仰角 $\theta _ { \mathrm { d } }$ ，该环节同样采用串级结构。首先，外环姿态控制器以角度误差 $e _ { \theta } = \theta _ { \mathrm { d } } - \theta$ 为输入，利用标准 PID 控制律解算出期望角速率 $\omega _ { \mathrm { d } }$ 。随后，内环角速率控制器以角速率误差 $e _ { \omega } = \omega _ { d }$ ? 为输入，再利用标准 PID 控制 律 计 算 出 最 终 的 控 制 力 矩 由 角 度 误 差$e _ { \theta } = \theta _ { \mathrm { d } } - \theta$ 得到期望角速率 $\omega _ { \mathrm { d } }$ ，随后角速率控制器根据误差 $e _ { \omega } = \omega _ { d } - \dot { \theta }$ 计算最终的控制力矩 $\tau _ { \theta }$ 。

上述控制律构成了系统的执行基础，确保无人机能够稳定、准确地响应上层规划算法生成的导航指令。

## 2.2 马尔可夫决策过程(MDP)建模

针对输电线无人机吊运作业中系统欠驱动、强耦合及环境约束复杂的特点，本文将无人机的自主导航与抗摆控制问题建模为一个马尔可夫决策过程(MDP)。该过程由四元组 S A P R, , , 描述，其中智能体(Agent)根据当前状态 $\pmb { S } _ { t }$ 选择动作 $\pmb { a } _ { t }$ ，环 境 根 据 系 统 动 力 学 进 行 状 态 转 移$\mathbf { } s _ { t + 1 } \sim \mathrm { P } \left( \cdot | \mathbf { } s _ { t } , \mathbf { } a _ { t } \right)$ 并反馈即时奖励r 。

## 2.2.1 状态空间

为了实现精准的“点对点”导航并同时抑制负载摆动，状态空间的设计必须包含无人机本体运动信息、负载摆动信息以及环境感知信息。本文定义状态向量如 $\pmb { S } _ { t } \in \dag ^ { N _ { s } }$ 下：

$$
s _ { t } = [ p _ { t } ^ { T } , v _ { t } ^ { T } , \phi _ { t } ^ { T } , \dot { \phi } _ { t } ^ { T } , p _ { r e l } ^ { T } , d _ { o b s } ^ { T } ] ^ { T }\tag{14}
$$

具体定义为：

1)无人机机体运动状态 $p _ { t } = \left( x , z \right) ^ { T }$ 、 $v _ { t } =$ $( { \dot { x } } , { \dot { z } } ) ^ { T }$ ：表示无人机在惯性系下的位置及线速度，用于感知无人机的飞行状态。

2) 姿 态 与 摆 动 状 态 $\pmb { \phi } _ { t } = \left( \theta , \alpha \right) ^ { T }$ 及 其 $\dot { \phi } _ { t } =$ $( { \dot { \theta } } , { \dot { \alpha } } ) ^ { T }$ 变化率：其中 为机体俯仰角，为吊绳摆角，引入摆角及其角速度是实现主动抗摆控制的必要条件。

3)环境感知状态 $p _ { \mathrm { r e l } } = p _ { \mathrm { t a r g e t } } - p _ { t }$ 及 $\pmb { d } _ { \mathrm { { o b s } } } \in \mathbf { \dot { l } } ^ { \textit { K } }$ ：表示无人机与目标作业点 $p _ { \mathrm { t a r g e t } }$ 、周围 K 根高压线(障碍物)的相对距离向量，用于引导无人机向目标逼近以及支持避障决策。

## 2.2.2 动作空间

为了降低连续运动空间的探索难度，并适配底层 PID 控制器的跟踪特性，本文采用了离散化动作空间设计，即智能体不直接输出电机推力，而是输出下一时刻的局部导航目标，动作向量$\pmb { a } _ { t } = \left( a _ { \mathrm { d } } , a _ { \psi } \right) ^ { T }$ 包含两个独立的决策维度：

1)导航距离指令 $a _ { \mathrm { d } } \in \left\{ 0 , 1 , . . . , M - 1 \right\}$ ：对应预设的离散距离集合 $\mathrm { ~ D ~ } = \left\{ d _ { 0 } , d _ { 1 } , . . . , d _ { \operatorname* { m a x } } \right\}$

2)导航方位指令 $a _ { \psi } \in \left\{ 0 , 1 , . . . , N - 1 \right\}$ ：对应预设的离散角度集合 $\Psi = \left\{ 0 , \Delta \psi , . . . , 2 \pi \right\}$

本文动作空间采 用 $1 5 ^ { \mathrm { ~ \circ ~ } }$ 等间距方位与0-3.2m 非均匀距离步长设计，以期算法收敛性和导航精度达成平衡。在每个决策周期，智能体选择动作 $\pmb { a } _ { t }$ 后，进而计算出期望位置 $p _ { \mathrm { d e s } }$ 输入底层控制器。这种分层设计有效将复杂的非线性动力学融入较高层的运动规划中。

## 2.2.3 状态转移

状态转移函数 P $\left( \pmb { S } _ { t + 1 } \mid \pmb { S } _ { t } , \pmb { a } _ { t } \right)$ 描述了吊运无人机系统在执行动作后的动态演化过程，由两部分决定：一是底层级联 PID 控制器对期望位置 $p _ { \mathrm { d e s } }$ 的跟踪响应；二是无人机-吊挂负载系统的拉格朗日动力学方程(见 2.1 节)。由于物理环境具有确定性，该转移过程在仿真中是确定的，但在实际环境中可能会受到风扰等不确定因素影响。

## 2.2.4 复合奖励函数

奖励函数的设计是引导智能体学习最优策略的核心。为了引导智能体在复杂障碍物环境中实现“快速趋近”、 “安全避障”与“精准稳停”的多目标任务，本文设计了一个多层次的复合奖励函数。该函数不仅包含稀疏的终端奖励，还引入了基于势能的稠密引导奖励和动态安全约束。总奖励r 定义为：

$$
r _ { t } = r _ { \mathrm { n a v } } + r _ { \mathrm { o b s } } + r _ { \mathrm { s a f e } } + r _ { \mathrm { e f f } } + r _ { \mathrm { s t a b } } + r _ { \mathrm { t e r m } }\tag{15}

## 1)进程导航奖励

为解决稀疏奖励导致的收敛困难问题，采用基于势能差分的形式设计导航奖励。相比于简单的距离函数，势能差分能保证最优策略的一致性：

$$
r _ { \mathrm { n a v } } = \lambda _ { \mathrm { p r o g } } \cdot \left( d _ { t - 1 } - d _ { t } \right) - \lambda _ { \mathrm { d i s t } } \cdot d _ { t }\tag{16}
$$

其中： $d _ { t } = \lVert \pmb { p } _ { \mathrm { t a r g e t } } - \pmb { p } _ { t } \rVert ,$ 为当前时刻与目标的欧式距离， $\lambda _ { \mathrm { p r o g } }$ 和 $\lambda _ { \mathrm { d i s t } }$ 为奖励权重系数。第一项$\lambda _ { \mathrm { p r o g } } \cdot \left( d _ { t - 1 } - d _ { t } \right)$ 奖励每一步向目标靠近的增量，鼓励持续进取；第二项 $- \lambda _ { \mathrm { d i s t } } \cdot d _ { t }$ 惩罚较远的距离，促使智能体寻找最短路径。

## 2)静态障碍斥力奖励

$$
r _ { \mathrm { o b s } } = - \eta _ { \mathrm { o b s } } \sum _ { o \in \mathrm { 0 } \mathrm { \ o b s } } \bar { \mathsf { u } } \bigl ( d _ { o } < R _ { \mathrm { p e n } } \bigr ) \Biggl ( \frac { d _ { o } - R _ { \mathrm { p e n } } } { R _ { \mathrm { r e p } } } \Biggr ) ^ { 2 }\tag{17}

其中： $d _ { o }$ 为系统中心与障碍物表面的距离， $\mathfrak { o } ( \cdot )$ 为仅当条件满足的示性函数， $\eta _ { \mathrm { { o b s } } }$ 为奖励权重系数。

其中： $\lambda _ { \alpha }$ 和 $\lambda _ { \dot { \alpha } } \qquad $ 为对应的奖励权重系数；由于 $\alpha _ { t }$ 数值较小， $\alpha _ { \mathrm { { n o r m } } }$ 为标准化系数；若摆角超过安全阈值，则施加额外巨额惩罚。

该项在全飞行包络内持续生效，促使策略网络学习出较为稳定的动作，主动消除摆动能量。

## 2.3 基于分层 PPO-PID 的上下线导航方法

针对输电线路吊运作业中无人机系统存在的欠驱动、强非线性以及“导航决策”与“姿态控制”在时间尺度上的巨大差异，直接采用端到端的强化学习方法往往难以收敛且安全性较差。为此，本文提出了一种分层运动规划架构，该方法的核心思想是将高维复杂的控制任务解耦：利用深度强化学习(DRL)强大的非线性拟合能力处理上层的智能决策问题，同时保留经典控制理论(PID)在底层稳定性控制上的优势。通过这种“高层规划+底层跟踪”的组合，实现了对复杂吊运任务的高效求解。

## 2.3.1 PPO 算法原理

近端策略优化 $( \mathrm { P P O } ) ^ { [ 2 1 ] }$ 采用 Actor-Critic 框架，其中策略网络(Actor)负责输出动作概率分布，价 值 网 络(Critic) $V _ { \phi }$ 负责评估当前状态的预期回报。为了提升训练的稳定性与收敛速度，算法通过以下三个核心组件构建总目标函数：

## 1)裁剪代理目标函数

为了防止策略更新步长过大导致性能崩溃，PPO 引入了裁剪机制，则策略优化的目标函数$L ^ { C L I P }$ 定义为：

$$
\left\{ { \begin{array} { l l } { L ^ { C L I P } ( \theta ) = \mathbb { E } _ { t } [ m i n ( r _ { t } ( \theta ) \widehat { A } _ { t } , \widehat { A } _ { t } ) ] } \\ { C ( \theta , \epsilon ) = c l i p ( r _ { t } ( \theta ) , 1 - \epsilon , 1 + \epsilon ) } \\ { r _ { t } ( \theta ) = \frac { \pi _ { \theta } ( a _ { t } | s _ { t } ) } { \pi _ { \theta _ { o l d } } ( a _ { t } | s _ { t } ) } } \end{array} } \right.\tag{22}
$$

其中： $r _ { t } \left( \theta \right)$ 为新旧策略的比率；ò为允许偏离的超参数阈值，控制策略更新的步长； $\hat { \boldsymbol A } _ { t }$ 为为优势函数估计值，以估计更新策略的好坏。

该公式确保了当策略更新超出 $( 1 - \epsilon , 1 + \epsilon )$ 范围时，梯度传播被截断，从而实现了“信任区域”内的保守更新。

## 2)广义优势估计(GAE)

为了在偏差与方差之间取得最佳平衡，本文采用 GAE 算法计算优势函数 $\hat { \boldsymbol A } _ { t }$ 。定义时序差分残差：

$$
\delta _ { t } = r _ { t } + \gamma V _ { \phi } \left( s _ { t + 1 } \right) - V _ { \phi } \left( s _ { t } \right)\tag{23}
$$

式中： $\gamma \in \left( 0 , 1 \right)$ 为折扣因子。

在此基础上，通过引入平滑因子 $\lambda \in \left( 0 , 1 \right)$ ，将多步优势进行指数加权平均，得到 GAE 形式的优势估计：

$$
\begin{array} { r l } {  { \hat { \boldsymbol { A } } _ { t } ^ { G A E ( \gamma , \lambda ) } = \sum _ { k = 0 } ^ { \infty } \bigl ( \gamma \lambda \bigr ) ^ { k } \delta _ { t + k } } } \\ & { = \delta _ { t } + \bigl ( \gamma \lambda \bigr ) \delta _ { t + 1 } + \bigl ( \gamma \lambda \bigr ) ^ { 2 } \delta _ { t + 2 } + . . . } \end{array}\tag{24}
$$

该方法有效利用了价值网络 $V _ { \phi }$ 的预测信息来降低蒙特卡洛采样的方差。

## 3)价值损失与策略熵

价值网络 $V _ { \phi }$ 的参数通过最小化均方误差进行更新，以使其准确拟合累积回报 $R _ { t }$ ：

$$
L _ { t } ^ { V F } \left( \phi \right) = \left( V _ { \phi } \left( s _ { t } \right) - R _ { t } \right) ^ { 2 }\tag{25}
$$

此外，为了鼓励智能体在训练初期进行充分探索，防止陷入局部最优，引入策略分布的香农熵 $S [ \pi _ { \theta } ]$ 作为正则项：

$$
S \bigl [ \pi _ { \theta } \bigr ] \bigl ( s _ { t } \bigr ) = - \sum _ { a \in \Lambda } \pi _ { \theta } \bigl ( a \mid s _ { t } \bigr ) \log \pi _ { \theta } \left( a \mid s _ { t } \right)\tag{26}
$$

综上所述，PPO 算法的总优化目标函数$L ( \theta , \phi )$ 由策略提升项、价值拟合项和熵正则项加权组成：

$$
L \left( \theta , \phi \right) = \breve { \boldsymbol { \mathfrak { a } } } _ { t } \left[ \begin{array} { l } { L ^ { C L I P } \left( \theta \right) - c _ { 1 } L _ { t } ^ { V F } \left( \phi \right) } \\ { + c _ { 2 } S \left[ \pi _ { \theta } \right] \left( s _ { t } \right) } \end{array} \right]\tag{27}
$$

其中： $c _ { 1 }$ 和 $c _ { 2 }$ 为价值系数和熵系数，用于平衡各部分的重要性。

## 2.3.2 分层运动规划架构与智能体训练机制

基于上述分层思想，本文设计的具体控制架构如图 5 所示。该架构基于时序抽象原理 142]，明确划分了决策与执行的功能边界：

1)决策层：运行频率较低(本文为 2.5Hz)，PPO智能体根据当前观测状态 $\pmb { S } _ { t }$ ，输出离散化的局部导航指令 $\pmb { a } _ { t }$ ，该指令经解码器转换为物理空间中的期望导航点 $\pmb { p } _ { \mathrm { d e s } }$ 。该层主要负责处理长时程的路径规划任务，在满足避障约束的前提下引导无人机向目标逼近。

2)执行层：运行频率较高(例如 50Hz)，底层PID 控制器接收 $p _ { \mathrm { d e s } }$ 作为设定值，计算无人机所需的倾角与推力，并在 K 个物理仿真步长内持续执行，达到运动导航的目的。

图 4 所示为基于“采样-更新”闭环机制的智能体在线训练流程。该流程遵循标准的强化学习范式：初始化后的智能体在输电塔仿真环境中循环执行“规划路点-跟踪控制”任务，从而生成包含状态、动作及奖励的一系列经验轨迹 ，并将其存入经验回放缓冲区。当缓冲区内的样本量达到预设阈值时，PPO 算法利用采集的批量数据计算广义优势估计，并通过随机梯度上升法更新ACTOR 网络与 CRITIC 网络的参数。参数更新后的策略网络随即被部署为新的交互智能体，投入下一轮的采样任务。通过这种“交互采样—策略优化—部署验证”的迭代循环，智能体能够逐步掌握环境的动力学约束与任务边界，最终收敛至满足上下线导航需求的最优策略。

## 3.2 算法对比实验

为了保证本文提出的基于分层 PPO-PID 的上下线导航方法在面对复杂非结构化环境时的适应能力与鲁棒性，实验构建了一个具有高度随机性的仿真训练环境。与传统方法通常针对固定场景进行参数整定不同，本实验在训练阶段引入了广泛的环境变量扰动，迫使智能体学习通用的导航策略而非记忆特定地图，在每一训练回合的初始化阶段，系统会对环境进行如下随机化设置：

1)输电塔结构随机化：为了模拟现实中不同电压等级杆塔的差异，输电塔的双层横担高度在预设范围内随机采样。下层横担高度在 20\~32 范围内随机生成，上层横担高在 36\~45 范围内随机生成，从而改变障碍物的空间垂直分布特征。

2)起止状态随机化：无人机的作业起止点不再局限于单一坐标，地面起降点在 0\~50 范围内随机生成，作业目标则从四根线路中随机选取。

通过上述随机化设置，智能体在数千万次的交互中能学习到在不同电线高度、不同起飞位置下均能稳定作业的泛化能力。

图6给出了PPO算法在本文环境下的累积奖励随训练步数变化的曲线。可以看出，在训练初期，智能体处于随机探索阶段，尚未形成有效策略，导致累积奖励上升缓慢且伴有剧烈波动；随着训练的不断深入，智能体逐步适应了环境的动力学约束与奖惩机制，迅速学习到了获取高回报的有效策略，奖励值呈现快速攀升；在训练后期，奖励曲线逐渐趋于平稳并最终收敛，这表明智能体已成功逼近该复杂作业环境下的最优策略解。

## 3.2.1 评价指标

考虑到输电塔作业场景的高危性，本文针对每个目标线路，要求各算法独立运行 10 次，选取其中轨迹最短的一次作为典型轨迹分析。为了定量评估算法性能，对后文设定的四根目标线路，定义如下五项关键指标：

1)平均轨迹长度：四次典型轨迹长度的算术平均值；

2)最大摆动角度：统计四次典型轨迹全过程中，负载摆动角度绝对值的最大值。

3)摆动强度指标：四次典型轨迹摆动强度指标的平均值。单次轨迹的摆动强度指标定义为60s 内摆动角度(弧度制)平方的积分。

4)平均运动时间：四次典型轨迹运动时间的平均值。运动时间定义为无人机与终点距离小于0.1m 且速度小于 0.05m/s，同时在随后的仿真时间内这两个数值不再超越该阈值的第一个时刻。

5)规划成功率：在 40 次实验中，满足上述运动时间条件且未发生碰撞的次数占比。

## 4 结论

本文针对架空输电线场景下吊运无人机面临的强耦合动力学与多障碍物避障难题，提出了一种基于分层 PPO-PID 的智能导航方法。该方法通过分层协同架构，利用深度强化学习(PPO)处理高层轨迹规划，结合底层(PID)控制器实现精准跟踪，并设计了包含安全、效率及消摆约束的复合奖励函数，实现了复杂非结构化环境下的自主作业。

仿真实验结果表明，所提方法在上线与下线任务中的规划成功率均为 100%。与传统的 A\*及RRT\*算法相比，该方法不仅生成的轨迹更加平滑，且作业效率显著提升，平均运动时间缩短了约27%\~32% ；同时具备优异的主动抗摆性能，将摆动强度指标始终控制在 0.36rad2 ∙s 以下，有效解决了传统规划方法“行得通但停不稳”的问题。

考虑到“仿真到现实(Sim-to-Real)”迁移过程中的潜在挑战，未来研究工作将深入探讨突发阵风、空气动力学地效等外部动态扰动，以及真实传感器噪声与执行器延迟等内部不确定性对系统表现的影响。此外，针对本文二维动力学模型未考虑三维空间侧风及横向摆动的局限性，后续拟通过建立三维全空间动力学模型并设计多维度解耦控制策略，以适应更复杂的实际作业工况。在此基础上，拟结合域随机化与多传感器融合技术进一步提升算法鲁棒性，从而推进该智能导航方法在真实物理样机上的部署与应用验证。
