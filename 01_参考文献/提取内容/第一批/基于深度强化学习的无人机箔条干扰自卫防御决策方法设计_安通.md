# 基于深度强化学习的无人机箔条干扰自卫防御决策

## 方法设计

安 通\*，王冰切，时满红，王海杰，王资，贺玲（空军预警学院信息对抗系，湖北 武汉 430019）

摘 要：针对无人机箔条干扰自卫防御决策智能化程度不高的问题，提出一种基于深度强化学习的智能化决策方法。构建无人机利用箔条干扰导弹雷达导引头的场景模型，以无人机为智能体，结合任务特性设计状态空间、动作空间及奖励函数。基于近端策略优化（Proximal Policy Optimization, PPO）算法，设计一种具备数据缓存区机制的箔条干扰自卫防御决策方法。仿真结果表明，所设计的方法能够在有限训练回合数内收敛，能够显著提高无人机生存成功率，数据缓存区机制可以有效提高算法收敛速度。相比于其他的深度强化学习算法，所设计的算法优势明显，更适用于箔条干扰自卫防御任务场景。

# Design of UAV Chaff Jamming Self-Defense Decision-Making Method Based on Deep Reinforcement Learning

AN Tong，WANG Bingqie，SHI Manhong，WANG Haijie，WANG Zi，HE Ling (Air Force Early Warning Academy, Wuhan 430019, Hubei, China)

Abstract: Aiming at the issue of low level of UAV chaff jamming self-defense decision intelligence, an intelligent decision-making algorithm is proposed based on deep reinforcement learning. This paper firstly constructs a scenario where UAVs use chaff jamming to counter missile radar seekers. The UAV is regarded as an agent, and the state space, action space, and reward function are designed according to the mission characteristics. Furthermore, based on the Proximal Policy Optimization (PPO) algorithm, a chaff jamming self-defense decision-making method with a data buffer function is proposed. The simulation results show that the designed algorithm can converge to the optimal strategy within a limited number of training episodes, and significantly improve the survival success rate of UAV. The data buffer function can also effectively accelerate the algorithm convergence speed. Compared with other deep reinforcement learning algorithm, the proposed algorithm exhibits distinct advantages and is more suitable for the mission scenario.

Keywords: deep reinforcement learning; chaff jamming; UAV self-defense; missile tracking; proximal policy optimization

## 0 引言

察打一体等多功能无人机平台遂行任务类型日益多样，战术价值不断提高，被广泛用于特种作战或局部武装冲突[1-2]。未来空中战场态势更加复杂多变，对无人机态势感知与智能决策提出了更高的要求，深度强化学习(Deep Reinforce Learning, DRL)理论能够为该需求提供有效解决方案。典型的 DRL算法包括近端策略优化 (Proximal Policy Optimization，PPO) 算 法 [3] 、 深 度 确 定 性 策 略 梯 度 (DeepDeterministic Policy Gradient， DDPG)算法[4]等，目前已有研究将DRL技术运用到无人机空战决策设计之中[5-7]。多功能无人机平台防御导弹攻击是无人机空战的典型场景，然而受限于平台的机动过载与速度特性，其在导弹攻击场景下的生存能力面临严峻挑战，针对无人机防御导弹攻击的问题，已有研究成果将 PPO 算法运用于无人机规避机动决策设计[8]和规避机动与诱饵弹投放协同决策设计过程[9]。

箔条干扰具备干扰效果可靠、成本低于红外诱饵弹的优势，可用于应对雷达寻的制导导弹的攻击，提高平台生存概率，如何采用合适的策略施放箔条干扰以提升无人机自卫防御能力具有很高的研究价值。近些年来已有研究成果将DRL应用于箔条干扰决策设计中，如文献[10]针对海上多无人平台协同箔条干扰从而保卫重要资产的问题，将质心干扰决策问题转化为马尔科夫决策问题，构建了决策智能体，最后通过多智能体近端策略优化算法（Multi AgentProximal Policy Optimization, MAPPO）对决策智能体进行训练。文献[11]面向舰队编队利用箔条云开展质心干扰的任务，构建了舰对空防御智能模型，设计了基于 DRL的箔条干扰决策算法，并建立了敌方反舰导弹威胁等级评估模型，以提高决策算法的效率和成功率。

与地面和海面机动平台不同，无人机可在三维空间进行机动，其投放的箔条弹的质心运动自由度同样是三维，动作空间维度显著增加。现有无人机箔条干扰自卫防御策略研究仍存在以下不足：（1）研究成果相对较少，箔条干扰自卫防御策略研究面向的平台多为船舰[11-16]；（2）面向无人机自卫防御任务进行箔条干扰策略设计时，常规的方法是根据质心干扰原理建立相关约束条件和投放参数解算，形成基于质心干扰的箔条弹投放策略[17-20]。然而由于战场态势愈加复杂多变，无人机平台和导弹攻防态势关系复杂多样，传统的箔条干扰策略智能化决策水平不高，难以适应复杂的场景变化，需要基于DRL 等智能化方法开展无人机箔条干扰自卫防御策略设计。

因此，本文将基于DRL理论，开展面向自卫防御任务的无人机箔条干扰策略研究，主要创新点包括：（1）构建无人机箔条干扰导弹雷达导引头的自卫防御场景，将无人机建模为智能体，设计适配任务特性的 DRL 框架、状态空间、动作空间与奖励函数；（2）针对无人机箔条干扰自卫防御任务特点，对 PPO 算法进行优化改进，设计一种具备数据缓存区机制的箔条干扰自卫防御决策方法，并通过仿真验证设计方法的有效性。本文的研究可让无人机根据攻防态势信息，智能生成箔条干扰自卫防御策略，从而提高无人机箔条干扰自卫防御智能化决策水平，进一步丰富完善无人机智能化决策理论。

## 1.2 箔条云扩散模型

箔条云雷达反射截面积随时间变化的模型可以利用瑞利分布曲线来构建 [22]：

$$
\sigma _ { \mathrm { { C } } } ( t ) = k \frac { t } { T _ { 0 } ^ { 2 } } \mathrm { e } ^ { - \frac { t ^ { 2 } } { 2 T _ { 0 } ^ { 2 } } }\tag{2}
$$

式中： $T _ { 0 }$ 表示箔条云的持续总时长， 表示箔条云反射截面积在扩散过程中的最大值， 表示箔条发射后的时间。

设无人机发射箔条的俯仰角、偏角分别为 $\theta _ { \mathrm { C } }$ 和$\varphi _ { \mathrm { c } }$ ，发射距离为 $L _ { \mathrm { c } }$ ，箔条云发射前的质心位置和无人机质心位置相同，而发射后的质心位置计算公式为：

$$
\begin{array} { r } { \left\{ \begin{array} { l l } { X _ { \mathrm { c } } = X _ { \mathrm { U } } ^ { t _ { 0 } } + L _ { \mathrm { c } } \sin \theta _ { \mathrm { c } } \cos \varphi _ { \mathrm { c } } } \\ { Y _ { \mathrm { c } } = Y _ { \mathrm { U } } ^ { t _ { 0 } } + L _ { \mathrm { c } } \sin \theta _ { \mathrm { c } } \sin \varphi _ { \mathrm { c } } } \\ { Z _ { \mathrm { c } } = Z _ { \mathrm { U } } ^ { t _ { 0 } } + L _ { \mathrm { c } } \cos \theta _ { \mathrm { c } } } \end{array} \right. } \end{array}\tag{3}
$$

式 中: $t _ { 0 }$ 为 箔条云 的发射时 刻， $\left( X _ { \mathrm { c } } , Y _ { \mathrm { c } } , Z _ { \mathrm { c } } \right)$ 和(X,Y,Z)分别为 $t _ { 0 }$ 时刻箔条云和无人机平台的位置坐标。在忽略风速影响的简化条件下，箔条云发射后其质心位置保持恒定。

## 1.3 质心模型

导弹雷达导引头跟踪的目标质心位置取决于分辨单元内箔条和无人机各自的雷达反射截面积和位置坐标。考虑叠加效应，当单个/多个箔条与无人机处于导引头的同一分辨单元时，导弹获取的目标坐标可由式(4)描述[10]:

$$
\left\{ \begin{array} { l l } { \displaystyle X _ { \mathrm { p } } = \frac { X _ { \mathrm { U } } \sigma _ { \mathrm { U } } + \sum _ { i = 1 } ^ { n } X _ { \mathrm { C } , i } \sigma _ { \mathrm { C } , i } } { \sigma _ { \mathrm { U } } + \sum _ { i = 1 } ^ { n } \sigma _ { \mathrm { C } , i } } } \\ { \displaystyle Y _ { \mathrm { p } } = \frac { Y _ { \mathrm { U } } \sigma _ { \mathrm { U } } + \sum _ { i = 1 } ^ { n } Y _ { \mathrm { C } , i } \sigma _ { \mathrm { C } , i } } { \sigma _ { \mathrm { U } } + \sum _ { i = 1 } ^ { n } \sigma _ { \mathrm { C } , i } } } \\ { \displaystyle Z _ { \mathrm { p } } = \frac { Z _ { \mathrm { U } } \sigma _ { \mathrm { U } } + \sum _ { i = 1 } ^ { n } Z _ { \mathrm { C } , i } \sigma _ { \mathrm { C } , i } } { \sigma _ { \mathrm { U } } + \sum _ { i = 1 } ^ { n } \sigma _ { \mathrm { C } , i } } } \end{array} \right.\tag{4}
$$

式中: $\left( X _ { \mathrm { P } } , Y _ { \mathrm { P } } , Z _ { \mathrm { P } } \right)$ 为导弹跟踪目标的质心坐标， 为导引头分辨单元内箔条的数目， $( X _ { \mathrm { { C } } , i } , Y _ { \mathrm { { C } } , i } , Z _ { \mathrm { { C } } , i } )$ 为箔条 i 的位置坐标， $\sigma _ { \mathrm { U } }$ 为无人机的雷达反射截面积，$\sigma _ { \mathrm { { C } } , i }$ 为箔条i在该时刻的雷达反射截面积。

## 2 基于 PPO 的箔条干扰决策模型

将无人机视为智能体，分别构建状态空间、动作空间以及智能体在对抗环境中的奖励函数。

## 2.1 状态空间

无人机箔条干扰决策所需要的状态空间包括导弹信息、无人机信息、箔条信息和相对位置信息。

## 2.1.1 导弹信息

导弹信息直接影响箔条投放方向和无人机机动方向等动作的选择，包括导弹位置坐标 $\left( { { X } _ { \mathrm { M } } } , { { Y } _ { \mathrm { M } } } , { { Z } _ { \mathrm { M } } } \right)$ 导弹飞行方向坐标 $( \theta _ { \mathrm { M } } , \varphi _ { \mathrm { M } } )$ 和飞行速率 $\nu _ { \mathrm { { M } } }$ 。

## 2.1.2 无人机信息

无人机的位置、飞行方向等信息影响无人机的决策动作，无人机信息包含位置坐标 $\left( X _ { \mathrm { U } } , Y _ { \mathrm { U } } , Z _ { \mathrm { U } } \right)$ 1无人机机动方向坐标 $( \theta _ { \mathrm { U } } , \varphi _ { \mathrm { U } } )$ 和机动速率 $\nu _ { \mathrm { U } }$

## 2.1.3 箔条信息

箔条信息对干扰决策影响很大，箔条信息包括剩余箔条数量、装填的第 i个箔条的雷达反射截面积$\sigma _ { \mathrm { { C } } , i }$ 和箔条位置观测矩阵 $\sigma _ { \mathrm { c } }$

$$
\begin{array} { r } { \partial _ { \mathrm { c } } = \left[ \begin{array} { l l l } { O _ { X _ { \mathrm { c } , 1 } } } & { O _ { Y _ { \mathrm { c } , 1 } } } & { O _ { z _ { \mathrm { c } , 1 } } } \\ { \vdots } & { \vdots } & { \vdots } \\ { O _ { X _ { \mathrm { c } , i } } } & { O _ { Y _ { \mathrm { c } , i } } } & { O _ { z _ { \mathrm { c } , i } } } \\ { \vdots } & { \vdots } & { \vdots } \\ { O _ { X _ { \mathrm { c } , N } } } & { O _ { Y _ { \mathrm { c } , N } } } & { O _ { z _ { \mathrm { c } , N } } } \end{array} \right] } \end{array}\tag{8}
$$

## 2.3 奖励函数

为使无人机依据观测状态自主生成箔条干扰自卫防御策略，从而能够逃脱导弹雷达导引头锁定，保护自身不被导弹摧毁，奖励函数由波束逃离奖励、方向偏离奖励与终局奖励三部分构成。

## 2.3.1 波束逃离奖励

当 t时刻无人机处于波束范围内时，波束逃离奖励值设计为：

$$
r _ { \mathrm { e s c a p e } , t } = \eta _ { 1 } \cdot ( 2 \delta / \theta _ { \mathrm { b e a m } } )\tag{9}
$$

式中： $\eta _ { \mathrm { 1 } }$ 为波束逃离奖励系数， $\theta _ { \mathrm { { b e a m } } }$ 为导弹导引头波束宽度， $\delta$ 为导弹与无人机连线和波束中心轴的夹角，此时无人机越接近波束边缘，奖励越大。当无人机在导弹雷达导引头波束范围外时，设计给予定额奖励。通过波束奖励设计，能够鼓励无人机尽可能逃离导弹雷达导引头波束范围，从而提高无人机生存概率。

## 2.3.2 方向偏离奖励

方向偏离奖励设计为：

$$
r _ { \mathrm { d e v } , t } = \eta _ { 2 } \cdot ( \delta / \pi )\tag{10}
$$

其中 $\eta _ { 2 }$ 为方向偏离奖励系数。方向偏离奖励可以鼓励无人机尽可能偏离导弹飞行方向。

## 2.3.3 终局奖励

终局奖励函数设计为：

$$
r _ { \mathrm { e n d } } = \left\{ { + 2 0 , } \atop { - 2 0 , }  &  d _ { \mathrm { m i n } } > L _ { \mathrm { t h r e a t } } \right.\tag{11}
$$

其中 $d _ { \operatorname* { m i n } }$ 表示任务回合从开始到结束无人机与导弹的最小距离，称为最小威胁距离， $L _ { \mathrm { t h r e a t } }$ 为导弹爆炸杀伤半径。通过设计终局奖励函数，当无人机在任务回合中与导弹的距离始终大于导弹爆炸杀伤半径时，认为无人机自卫防御成功，获得高额奖励，否则获得高额惩罚。

则一次任务回合中的获得的累计奖励为：

$$
r _ { \mathrm { a l l } } = \sum _ { t = 0 } ^ { T _ { \mathrm { d } } } r _ { \mathrm { e s c a p e } , t } + \sum _ { t = 0 } ^ { T _ { \mathrm { d } } } r _ { \mathrm { d e v } , t } + r _ { \mathrm { e n d } }\tag{12}
$$

其中 $T _ { \mathrm { d } }$ 为任务结束时刻。强化学习的目标是使智能体在与环境交互过程中获取的折扣累积回报最大，折扣累计回报计算公式为：

$$
R { = } \sum _ { j { = 0 } } ^ { \infty } \gamma ^ { j } r _ { j }\tag{13}
$$

式中: $r _ { j }$ 为智能体在第 j 个时间步所获得的奖励，为折扣因子。

## 3.2.1 数据获取

在预设的空间约束范围内，随机重置导弹和无人机的位置，其中无人机初始位置各坐标分量的随机重置范围为[1000m, 5000m]，无人机初始运动方向随机，初始运动速率为 30m/s；导弹初始位置距离无人机 300-400m随机采样，初始时刻导弹飞行方向指向无人机。智能体基于策略网络输出动作并作用于环境之中，将产生的交互数据存储下来。当一个仿真回合结束后，重新初始化环境，并继续采集下一回合的数据。

## 3.2.2 网络更新

根据 PPO 算法，采集最新回合的数据存储到数据缓存区。当数据缓存区存储的训练回合数达到或超过 3 时，合并缓存区内所有回合的交互数据，然后按照学习率 和 ，对策略网络与价值网络执行$K _ { \mathrm { n u m } }$ 次参数更新。若缓存区内的训练回合数超出其容量限制，则删除最早存储的一个回合的数据队列。

## 3.2.3 策略评估

每经过 $T _ { \mathrm { a s s } }$ 轮次的训练后，进行一次策略评估，测试训练后的策略/价值网络在测试环境中的性能。评估采用 $N _ { \mathrm { e n v } } = 1 0 0$ 个环境进行，为了保证公平，每次评估所用的测试环境对应相同，但同一次评估下$N _ { \mathrm { e n v } }$ 个测试环境中导弹和无人机的初始位置状态、无人机初始运动方向都彼此不同，均为在一定范围内进行随机采样，从而尽可能使测试环境涵盖更多的无人机-导弹态势关系，使评测结果更加具有参考意义。此外需要说明的是：（1）策略评估所用的 $N _ { \mathrm { e n v } }$ 个测试环境与智能体获取训练数据的交互环境是相互独立的；（2）策略评估过程中同样基于策略网络输出的正态分布对动作进行采样，这样可以实时检验所训练的策略网络在线使用时的性能。

## 3.3.1 不同数据缓存区容量下的评估结果分析

图 4 为在不同数据缓存区容量下，测试环境中无人机生存成功率随训练回合数的变化曲线，无人机生存成功率的计算方法为：所有测试环境下生存成功的无人机数量之和除以测试环境总数量。从图 4中可以看出，在训练初期，无人机生存成功率略低于 20%，随着训练回合数的增加，无人机生存成功率不断上升。当数据缓存区容量为 10 和 40 时，训练回合数达到约 $1 \times 1 0 ^ { 4 }$ 次后，无人机生存成功率开始在 60%附近稳定震荡；而当数据缓存区容量为 1 时（此时可以认为 PPO 算法只利用单回合数据进行训练、没有数据缓存功能），当训练回合数达到约 $6 { \times } 1 0 ^ { 4 }$ 次后，无人机生存成功率才开始稳定下来，收敛速度要明显更慢，且训练稳定后的生存成功率下限值低于数据缓存区容量为 10和40的情况。

图 5-图 6 分别给出在不同数据缓存区容量下，测试环境中无人机平均累计奖励值和平均最小威胁距离随训练回合数的变化曲线，平均累计奖励值和平均最小威胁距离计算方法为：首先计算每个测试环境下智能体获得的累计奖励以及最小威胁距离，然后对所有测试环境求平均值。从图 5 和图 6 中可以看出，平均累计奖励值和平均最小威胁距离随训练回合数的变化呈现出与图 4 类似的规律，且图 6表明在训练开始时，测试环境中的平均最小威胁距离小于导弹爆炸杀伤半径距离（60m），然而随着训练的进行，平均最小威胁距离逐渐升高，最后将大于导弹爆炸杀伤半径。

以上仿真结果表明：（1）随着训练回合数的增加，所设计的具备数据缓存区机制的 PPO 算法能够显著提高无人机在测试环境下的生存率、平均累计奖励和平均最小威胁距离，具有有效性；（2）传统PPO 算法通常使用单回合数据或固定大小经验池，而具备数据缓存区机制的 PPO 算法通过使用最近 B个回合数据进行训练，能够有效减小单回合噪声影响，在提高数据样本利用效率的同时保持数据新鲜度，能够显著提高训练收敛速度，更加适用于无人机箔条干扰决策过程； （3）数据缓存区容量增大虽然能够一定程度上改善训练效果，但当缓存区容量达到一定数值后，训练效果提升便不明显了，反而会浪费缓存资源，因此并不是缓存区容量越大越好，而是需要根据实际情况灵活选取。

需要说明的是，无人机通过训练后在测试环境中的生存成功率虽然存在上限，但这也是因为在部分测试环境下，无人机和导弹的位置参数随机初始化导致从回合一开始就使得无人机几乎无法逃脱导弹的追踪。

## 4 结论

本文聚焦无人机面临导弹威胁的自卫防御需求，基于DRL理论开展箔条干扰自卫防御决策方法研究，主要完成以下工作并得出相应结论：

（1）构建了无人机箔条干扰自卫防御场景模型，包括无人机三维运动模型、箔条云扩散模型、无人机-箔条云质心模型及导弹制导与运动模型，为后续决策算法设计与验证提供了仿真基础；

（2）设计了适配无人机箔条干扰自卫防御任务的 DRL 框架，明确了包含导弹信息、无人机信息、箔条信息及相对位置信息的高维度状态空间，定义了涵盖无人机机动与箔条投放参数的7维动作空间，并构建了由波束逃离奖励、方向偏离奖励和终局奖励组成的奖励函数，有效引导智能体学习最优策略。

（3）基于PPO方法设计了具备数据缓存区机制的箔条干扰自卫防御决策算法，通过缓存最近 B 个训练回合的交互数据并批量更新网络参数，既保留了在线策略算法的数据新鲜度优势，又借鉴了离线策略算法对经验数据的高效利用特性。仿真验证表明，该算法可使无人机智能体直接基于对抗环境状态信息生成箔条干扰自卫防御策略，能够在多样化初始态势的测试环境中显著提高无人机生存成功率，且训练收敛速度显著优于无缓存 PPO 算法。此外相较于DDPG 算法，设计的算法通过广义优势估计方法能够缓解稀疏奖励问题，且探索能力更强，能够及时更新获取高质量训练数据，训练效果更好，更适用于无人机箔条干扰自卫防御决策任务。

本文的研究实现了DRL在无人机箔条干扰自卫防御决策领域的应用，为无人作战平台智能化自卫决策提供了新的理论依据与技术支撑。未来可进步提高环境模型的构建精度，提升模型的实战适配性，同时可拓展至多无人机协同箔条干扰场景，进一步挖掘DRL在无人机箔条干扰决策中的应用潜力。
