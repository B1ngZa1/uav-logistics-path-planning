# 基于双层强化学习的异构多无人机任务规划

付星桐 吴亚辉 马武彬 周浩浩 戴超凡

国防科技大学信息系统工程全国重点实验室 长沙 410073（fuxingtong24@nudt.edu.cn）

摘 要 随着现代作战场景日益复杂化，多种类无人机协同作战已经成为提高作战效能的重要手段。面向异构多无人机系统在复杂战场环境中的任务规划问题，强化学习算法虽能通过与环境交互自主学习决策策略，但存在实时性较差、模型求解计算复杂度高的问题。为降低异构多无人机任务分配与路径规划的联合优化模型求解的复杂度，提出基于双层强化学习架构的 BiARL（Bi-level Attention Reinforcement Learning,BiARL）算法：上层基于近端策略优化（Proximal Policy Optimization, PPO）算法，引入图注意力与动作掩码机制，根据任务和无人机类型进行任务分配，确保每个任务都被分配给具备相应执行能力的无人机；下层采用基于注意力机制的A2C模型，为每个无人机生成具体的任务执行路径，在满足航程约束的同时最大化任务完成价值。实验在包含80个任务点与3类无人机的场景中进行，结果表明：所提方法在测试场景中平均任务完成价值为37.607，平均航程利用率为91.35%，单次计算时间仅0.044 秒，在所有算法中实时性表现最好，且在平均任务完成价值与航程利用率上优于K-means+VND、K-means+AM等启发式算法。该研究为异构无人机集群的实时协同决策提供了有效途径。

关键词： 强化学习；异构无人机；任务分配；路径规划；分层决策

# Heterogeneous Multi-UAV Task Planning Based on a Two-Layer Reinforcement Learning Framework

FU Xingtong, WU Yahui, MA Wubin, ZHOU Haohao and DAI Chaofan

National Key Laboratory of Information Systems Engineering,National University of Defense Technology, Changsha 410073,China

Abstract With modern combat scenarios becoming increasingly complex, collaborative operations involving multiple types of unmanned aerial vehicles (UAVs) have become a crucial approach to enhancing combat effectiveness. To address the mission planning problem of heterogeneous multi-UAV systems in complex battlefield environments, reinforcement learning algorithms can autonomously learn decision-making strategies through environmental interactions. However, these algorithms often suffer from poor real-time performance and high computational complexity in model solving. To reduce the complexity of joint optimization models for heterogeneous multi-UAV task allocation and path planning, this study proposes the BiARL(Bi-level Attention Reinforcement Learning, BiARL) algorithm based on a Two-layer reinforcement learning architecture: the upper layer employs the Proximal Policy Optimization (PPO) algorithm with graph attention and action masking mechanisms to perform task allocation according to mission requirements and UAV types, ensuring each mission is assigned to UAVs with corresponding execution capabilities; the lower layer utilizes an attention-based A2C model to generate specific mission execution paths for individual UAVs, maximizing mission completion value while satisfying flight range constraints. Experiments were conducted in scenarios containing 80 mission points and 3 UAV types. Results demonstrate that the proposed method achieves an average mission completion value of 37.607, an average flight range utilization rate of 91.35%, and a single computation time of only 0.044 seconds. The BiARL algorithm exhibits the best real-time performance among all tested algorithms, while outperforming heuristic approaches such as K-means+VND and K-means+AM in both

average mission completion value and flight range utilization. This research provides an effective solution for real-time collaborative decision-making in heterogeneous UAV swarms.

Keywords Reinforcement learning, Heterogeneous UAVs, Task allocation, Path planning, Joint optimization

## 1 引言

近年来，无人机凭借其生存能力强、成本低、部署灵活等优势，在压制敌方防空、战场侦察监视等军事场景中展现出巨大价值。单一的无人机功能有限，难以胜任复杂的作战任务，因此，由侦察型、电子对抗型、察打一体型等不同功能混合编组的异构无人机集群协同作战，正逐渐成为未来智能化战争的核心支柱[1]。其中，异构无人机指的是具备不同作战能力的无人机，如侦察无人机、打击无人机等。研究普遍认为，合理的任务分配方案能使异构无人机灵活执行各类任务，提升整体作战效能。

现代信息化战争中，异构多无人机协同作战已成为提升战场效能的关键手段，从侦察监视、电子对抗到精确打击，不同类型的无人机需在复杂的战场环境中协同完成多类任务。然而，随着任务规模不断扩大，战场环境日趋复杂，传统任务规划方法在处理多无人机任务规划问题时，往往面临计算复杂度高、规划速度慢等问题，严重影响系统的实时性与有效性。

从问题本质来看，异构多无人机任务规划问题是一个 NP-hard 的组合优化问题，可视为多旅行商问题（MTSP）的一个变种。已有相关研究提出了多种求解方法，如精确算法、启发式算法等。精确求解算法能在小规模问题中找到全局最优解，但计算复杂度随问题规模呈指数级增长，难以满足实际应用需求[2]。启发式算法（例如遗传算法、蚁群算法、粒子群算法等）通过模拟自然界的优化过程，能够在较短时间内找到近似最优解，适用于中小规模问题；但在大规模复杂场景下通常需要较长的计算时间，无法满足实时决策的需求[3–5]，且会存在部分无人机闲置或被分配的任务过少、收敛速度过快导致局部最优的情况[6,7]。此外，启发式算法的核心规则均依赖人工设计，对研究者的领域经验要求较高，且人工规则的局限性可能会影响最终的求解效果。

与传统方法相比，深度强化学习（DeepReinforcement Learning, DRL）通过与环境交互自主学习决策策略，无需人工设计规则，展现出强大的适应性和泛化能力。近年来，强化学习在多无人机任务规划领域的应用日益受到关注[8,9]。 特别是在车辆路径问题（VRP）、旅行商问题（TSP）及其变种问题的求解中，深度强化学习方法已经取得了显著成果[10,11]。然而，将深度强化学习直接应用于异构多无人机协同任务规划仍面临困难。随着无人机与任务数量增加，DRL 的状态空间呈指数级增长，计算复杂度急剧上升，导致算法难以在可接受时间内找到高效策略。

针对强化学习模型求解复杂度高的问题，在同构多无人机任务规划研究中学者已提出若干改进思路。例如，Jiazhan Gao 等人基于多头注意力的编码器-解码器架构，以最小化所有无人机的总飞行路径长度为目标，将任务分配情况作为条件来建模，在实时性方面表现良好[12]；XiaoMao 等基于双层强化学习框架（DL-DRL）将多无人机任务规划问题分解为任务分配与路径规划两个子问题，在大规模任务调度中展现出优于传统启发式算法的性能[13]。然而，上述研究未充分考虑无人机与任务的异构性，通常假设所有任务类型相同，限制了其在实际复杂场景中的应用。

目前，尽管已有部分研究关注强化学习在多无人机任务规划中的应用，但大多数研究集中在单一类型无人机的同构场景，对于多种类无人机的异构特性考虑不足[14,15]。同时，利用 DRL 求解异构多无人机系统的任务复杂度更高，如何降低异构多无人机系统模型求解的复杂度成为新的问题。此外，在该系统中任务分配与路径规划之间存在强耦合关系，而现有方法常将二者解耦处理，忽略其内在关联，导致系统整体性能难以达到最优[16]。

为了应对这些挑战，本文提出一种基于双层强化学习的异构多无人机协同任务规划方法。首先，针对无人机和任务的异构性，构建能力-任务关系矩阵，并建立异构多无人机系统的任务分配与路径规划联合优化模型。进而，提出一种新型 BiARL 算法：上层采用结合编码器-解码器结构的 PPO 算法，根据无人机和任务的类型匹配矩阵进行任务分配，确保每个任务都被分配给具备相应执行能力的无人机；下层采用基于注意力机制的 A2C 算法，为每个无人机生成具体的任务执行路径，最大化无人机的任务完成价值。这种分层设计不仅有效降低决策空间的维度，还通过端到端的训练过程实现深度协同：上层输出的任务分配方案作为下层输入，下层路径规划的结果以奖励形式反馈至上层，从而实现对任务分配和路径规划策略的联合调优，避免因解耦优化而导致的次优解问题。通过多次仿真实验并与传统方法进行对比分析，验证所提方法具有良好的实时性和可扩展性，为异构多无人机系统的实际作战提供一种可行方案。本文的主要贡献包括：

1.建立无人机与任务类型的匹配矩阵，构建了异构多无人机系统的任务分配和路径规划的联合优化模型。

2.提出了基于双层强化学习框架的 BiARL算法，引入动作掩码机制满足类型矩阵约束，通过分层决策有效缓解了状态空间的维度灾难问题，实现了任务分配与路径规划的协同优化；

3.实验表明，所提算法在大规模任务场景下具有良好的实时性与可扩展性，求解速度优于传统启发式算法，更适用于战场环境下的实时决策需求。

## 3 算法设计

针对无人机集群任务分配与路径规划的联合优化模型，本文提出基于双层强化学习框架的BiARL 算法进行求解（如图 1 所示）。该架构将复杂决策过程分解为上层任务分配策略优化与下层路径规划策略优化两层，通过交替训练实现协同优化。具体来看，上层基于改进的 PPO 算法学习任务-无人机匹配策略，下层基于注意力机制的 A2C 算法处理单无人机路径规划，最终目标为最大化任务完成价值。与直接用强化学习求解联合优化模型相比，分层设计通过降低单层决策维度，显著减少了计算与存储开销，尤其在大规模任务场景下优势明显。

## 3.1 上层 PPO 模型

## 3.1.3 网络架构

上层任务分配模型的网络架构如图 2 所示，行动者网络采用图注意力增强的编码器-解码器架构，通过多层神经网络捕获任务与无人机的全局关联特征，实现任务-无人机匹配决策；评论家网络评估状态价值，从而计算行动者网络的优势函数，指导动作选择策略优化。其结构主要包含三个模块：

图注意力编码器：首先，将任务和无人机特征转化为统一维度的高维向量，映射到同一特征空间。之后采用 3 层多头图注意力网络捕获节点间的关联。以特征嵌入层输出为输入，通过邻接矩阵定义初始关联；每层通过 8 个注意力头并行计算节点关联权重，重点关注空间距离近、类型匹配的节点对；最终通过层间特征聚合，输出包含全局关联信息的节点嵌入矩阵。

解码器：对输入进行最大池化后拼接，得到任务子集上下文（Task subset context）的特征序列，对其依次进行 Linear 变换、Feed ForwardNetwork 处理、Linear 变换。随后经 Softmax 生成各动作的概率分布，再通过动作掩码机制过滤无效动作，最终输出任务-无人机的匹配决策。

评论家网络：评论家网络评估状态价值，对全局嵌入特征进行最大池化，通过线性变换输出当前状态的价值估计。

## 3.1.4 动作掩码机制

在执行作战任务的分配时，要将不符合类型要求的无人机分配视作无效决策。为此，通过动作掩码机制，调整策略网络的输出，确保每次决策均满足类型匹配约束。具体方式为基于能力-任务关系矩阵 ，将类型不匹配的任务-无人机组合设置概率为 0，仅保留满足 $A _ { \kappa ( i ) , \tau ( j ) } = 1$ 的可行决策。

$$
\pi _ { \theta } ^ { \mathrm { m a s k e d } } ( a | s ) = \mathrm { S o f t m a x } \left( \mathrm { l o g i t s + M a s k } \right)\tag{5}
$$

其中 为掩码矩阵（不匹配组合对应位置为 ，匹配组合为 0）。

在上层任务分配过程中，动作掩码并非静态，而是随着任务分配状态实时更新。同时，若是能力-任务匹配矩阵有所变动，模型无需重新训练也可进行任务规划，但性能可能会因为分布变化而小幅度下降，这时只需要再进行几轮训练即可恢复正常性能。

## 3.1.5 PPO 优化目标

上层模型采用 PPO 优化策略，目标函数为：

$$
\mathcal { L } ^ { \mathrm { P P O } } = \mathbb { E } _ { t } \Big [ \operatorname* { m i n } \Big ( r _ { t } ( \theta ) \hat { A } _ { t } , \mathrm { c l i p } \left( r _ { t } ( \theta ) , 1 - \epsilon , 1 + \epsilon \right) \hat { A } _ { t } \Big ) \Big ] ( 6 )
$$

其中 $r _ { t } ( \theta ) = \frac { \pi _ { \theta } \left( a _ { t } \vert s _ { t } \right) } { \pi _ { \theta _ { \mathrm { o l d } } } \left( a _ { t } \vert s _ { t } \right) }$ 为概率比， $\hat { A } _ { t }$ 为优势函数估计。

总损失函数包含策略损失、价值损失和熵正则化项：

$$
\mathcal { L } ^ { \mathrm { u p p e r } } = \mathcal { L } ^ { \mathrm { p o l i c y } } + c _ { 1 } \mathcal { L } ^ { \mathrm { v a l u e } } - c _ { 2 } \mathcal { L } ^ { \mathrm { e n t r o p y } }\tag{7}
$$

其中 $c _ { 1 } = 0 . 5$ 为价值损失系数， $c _ { 2 } = 0 . \ : 0 2$ 为熵系数。

## 3.1.6 奖励函数

上层强化学习模型采用分层奖励机制，结合即时分配奖励与最终执行反馈：

1）即时分配奖励：在每个时间步 t，模型分配任务后立即获得该任务的价值作为即时奖励：

$$
r _ { t } = \nu _ { i }\tag{8}
$$

其中， $v _ { i }$ 表示在时间步 t 分配的任务 i 的价值。

2）最终修正奖励：回合结束时，根据下层模型实际完成任务对总奖励进行修正：

$$
R _ { \mathrm { { c o r r e c t e d } } } = R _ { \mathrm { { a s s i g n } } } - V _ { \mathrm { { u n c o m p l e t e d } } }\tag{9}
$$

其中 $V _ { \mathrm { u n c o m p l e t e d } }$ 为下层未完成任务总价值，由所有任务奖励和减去下层模型多个无人机奖励和所得， $R _ { \mathrm { a s s i g n e d } }$ 为上层分配的任务总价值。修正后的奖励值可视作实际完成任务总价值。

## 3.2 下层 A2C 模型

下层基于 A2C 算法求解，为每个无人机独立规划路径序列。

## 3.2.1 状态空间设计

状态空间 $S ^ { \mathrm { l o w e r } }$ 包含任务子集和环境

信息：

$$
\boldsymbol { s } _ { t } ^ { l } = \langle \mathcal { P } _ { l } , \mathcal { R } , \mathcal { M } , \mathcal { C } \rangle\tag{10}
$$

其 中 $\mathcal { P } _ { l } \subset \mathbb { R } ^ { M \times 2 }$ 表示分配任务子集的位置，$\mathcal { R } \in \mathbb { R } ^ { M }$ 表示任务价值向量， $\mathcal { M } \in { \bf 0 } ,$ 表示任务掩码，标识可行任务， $\mathcal { C } _ { \mathrm { c } } \in \mathbb { R } ^ { 2 }$ 表示无人机当前位置。

## 3.2.2 动作空间设计

动作空间为离散空间，是当前无人机选择下一个要访问的任务节点：

$$
a _ { t } ^ { \mathrm { l o w e r } } \in \ r _ { 0 } , 1 , \cdots , m\tag{11}
$$

其中0表示出发点，其他值表示任务索引。

## 3.2.3 网络架构

下层 A2C 的行动者网络采用注意力增强的编码器-解码器结构，针对单无人机的局部任务子集优化路径访问顺序，结构包含三个模块：

特征编码器复用上层模型中与无人机相关的任务嵌入特征。对于每个分配的任务，进一步融合其价值信息与无人机当前位置的相对距离特征，生成包含局部任务优先级的嵌入向量。

解码器基于编码器输出的局部任务特征与无人机当前状态，通过全连接层与注意力机制计算待访问任务的优先级，重点关注价值高、距离近且未访问的任务。之后，通过 Softmax 函数输出下一个访问节点的概率分布，并通过掩码机制屏蔽已访问任务和超出路径长度约束的任务，确保动作可行性。

评论家网络与解码器共享编码器，通过聚合局部任务嵌入与无人机状态特征，输出当前状态的价值评估。该评估值用于计算行动者网络的优势函数，指导动作选择策略优化。

## 3.2.4 A2C 优化目标

A2C 算法的优势函数通过广义优势估计计算：

$$
\hat { A } t ^ { \mathrm { G A E } } = \sum l = 0 ^ { \infty } ( \gamma \lambda ) ^ { l } \delta _ { t + l }\tag{12}
$$

其中 $\delta _ { t } = r _ { t } + \gamma V ( s _ { t + 1 } ) - V ( s _ { t } )$ 为时序差分误差。总损失函数结构同上层 PPO 的损失函数相

同，系数设置为 $c _ { 1 } { = } 0 . 5 , c _ { 2 } { = } 0 . 0 3$

## 3.2.5 奖励函数

奖励函数设为该架无人机的完成任务价值：

$$
R ^ { \mathrm { { l o w e r } } } = \sum _ { j \in \mathrm { { c o m p l e t e d } } } r _ { j }\tag{13}
$$

其中 $r _ { j }$ 为完成第 j个任务的奖励。

## 4.4 性能指标和对比分析

为全面评估本算法的性能，我们定义了以下指标并在仿真实验中进行度量：①平均完成任务价值，即多个场景中完成任务点的平均总价值，数值越高，表示模型的任务分配效果越好；②平均航程利用率，即多个场景中无人机群实际飞行总距离与其最大允许航程总和之比的平均值。相同完成任务价值下，该数值越低，说明模型的路径规划越合理；③计算时间：算法在运行中求解测试集所有场景的耗时（单位：秒）。

在测试集上，我们将 BiARL 算法与以下四种基准算法进行了性能对比：

(1) OR-tools ： 采 用 Google 开 源 优 化 库

OR-Tools 中的 CP-SAT 求解器求解混合整数线性规划模型，设置最大求解时间上限为300 秒。

(2) K-means+VND：首先使用 K-means 聚类算法（聚类簇数 K 等于无人机数量）对任务进行初步分区分配，随后在每个分区内使用变邻域下降算法（VND）分别优化各无人机的路径。

(3) K-means+AM：任务点分配策略同 K-means+VND，但后续路径优化改用注意力机制训练。

（4）MAPPO：一种基于集中式训练、分布式执行的多智能体强化学习算法。

表 3 展示了五种算法在 500 个随机场景下的性能指标对比结果。数据表明，BiARL 算法在实时性方面表现更好，其平均计算时间在多个对比算法中耗时最少（总耗时 21.99 秒，单次场景平均耗时约 0.044 秒）。在任务完成价值方面，BiARL（37.607）在四类算法中完成任务价值最高，显著优于 K-means+VND（31.036）、K-means+AM（32.3）等启发式算法，略高于 OR-tools（37.47）与 MAPPO 算法（37.24），任务分配效果最好。同时，综合考虑航程利用率和完成任务价值，可以看到在相近的航程利用率下，与其他算法相比，BiARL 算法用较少的航程完成了更多有价值的任务，实现了最优的路径规划。

## 4.6 消融实验

为验证本文所提的 BiARL 算法中各关键模块的有效性，我们设计了消融实验，依次移除图注意力编码机制、动作掩码机制及上下层交替训练策略，测试其对任务完成总价值（即上层奖励值）的影响。实验在相同环境设置下进行，各消融版本的模型设置如下：

1) BiARL 算法（蓝色）:原始模型作为性能基准；

2) 无图注意力编码（红色）:改用全连接层替换图注意力模块；

3) 无动作掩码机制（绿色）:移除类型匹配约束，允许任意任务-无人机分配；

4) 非原交替训练策略（橙色）:上下层模型交替训练频率从原设计改为每隔10轮交替。

结束语 本文针对异构多无人机系统在复杂战场环境中的多无人机协同任务规划问题，构建了异构多无人机任务分配和路径规划联合优化模型。为求解该模型，提出了一种基于双层强化学习的BiARL 算法，通过设计上层任务分配与下层路径规划的双层决策架构，有效解决了传统方法在处理大规模任务场景下异构无人机协同规划时面临的计算复杂度高、实时性差等问题。实验结果表明，相比传统的精确算法和启发式方法，BiARL 算法在任务完成价值、航程利用率和计算效率等方面均表现出优越性能。目前，下层路径规划主要聚焦于单机航程与任务价值优化，尚未显式建模多机间的空域冲突与时间协同约束。未来研究将探索引入多智能体强化学习框架，以进一步增强无人机间的协同避碰能力，提升方法的实战适用性。
