# 多无人机分区协同区域覆盖航迹规划

黄姣茹,李虎鑫,袁鹏飞,张晓艳

(西安工业大学 电子信息工程学院,西安 )

摘 要: 针对存在未知动态障碍物的多无人机分区覆盖航迹规划问题,提出了一种基于改进图的多无人机分区覆盖航迹规划算法。该算法通过引入广度优先搜索的距离计算方式替代欧氏距离对任务区域进行划分,避免传统 分区在复杂环境中产生的“死区”问题;并通过边界均衡调节策略对相邻子区域的边界栅格进行有限调整,在给定阈值约束下实现区域负载的相对均衡;最后在各个子区域内利用改进的深度强化学习算法训练实现无人机区域航迹规划,引入基于覆盖率的自适应探索衰减动作选择策略,加快航迹规划算法的收敛速度。实验结果表明,所提出的改进分区覆盖航迹规划方法区域划分更加合理,能够避免区域覆盖遗漏,实现动态避障全覆盖;同时,对于 架无人机仿真情形,平均重复覆盖率从 下降到 ,覆盖效果更好。

关键词: 区域划分;区域覆盖;强化学习;动态避障

随着无人机技术与集群协同控制理论的快速发展,多无人机协同执行面积区域覆盖任务已广泛应用于灾害监测、环境巡检和搜索救援等场景[1-4]。相较于单无人机覆盖任务,多无人机系统能够通过协同作业显著提升覆盖效率,尤其针对覆盖区域面积大、任务时间受限的应用环境[5-7]。在实际应用中,覆盖区域环境中可能同时存在静态障碍物与动态障碍目标,这对多无人机系统的协同规划能力和在线决策能力提出了更高要求。

多无人机协同覆盖常用的一类方法是采用“区域划分—子区域覆盖规划”的分层协同思想,将整体覆盖任务分解为多个相互独立的子任务,从而降低规划复杂度并提升系统的可扩展性[8-10]。于驷男等[11]提出了基于初始位置和搜索面积的划分方法,通过分析无人机最小转弯半径和初始位置路径规划的影响,结合平行搜索对凸多边形搜索区域进行分割,使每个子区域成为单机覆盖问题,有效简化了协同搜索复杂度。 等[12]提出了一种基于凹多边形凸分解的多无人机区域划分方法,通过空间位置排序与面积均衡策略分配子区域,该方法对非凸区域进行分解处理后,可以进一步根据子区域宽度和方向制定统一的扫描线覆盖策略,从而提升覆盖效率。 等[13]提出了一种基于空间—时间相似性聚类的区域划分方法,通过迭代聚类中心使得分配区域在性能参数上更加适配不同类型无人机的能力,同时优化访问顺序以降低路径代价,可显著降低路径规划复杂性和覆盖总代价。等[14]通过根据无人机初始位置 动 态 划 分 任 务 空间,保证每架无人机的任务区域相对平衡、连通且可通过 简 单 栅 格 规 划 实 现 无 冗 余 覆 盖。等[15]通过近似细胞划分与图搜索算法结合,实现对不规则区域与非凸区域的有效覆盖,并进一步通过图搜索技术对可行路径进行优化,以支持对静态障碍物的避障能力。

上述研究在各子区域内进行单机覆盖规划时,没有考虑动态障碍物的存在,在应对动态障碍与未知环境时存在明显局限。 [16]提出一种基于端 到 端 强 化 学 习 ( ,)的控制方法,通过采用双深度 网络,借助类地图输入通道与卷积网络传递空间信息,解决了小型无人机续航受限及能耗不确定的问题,实现了能量约束与覆盖目标的平衡,具备多环境适配能力与复杂任务协调能力。 [17]提出了一种基于多智能体强化学习的分布式规划框架,通过定制化网络结构、规模无关奖励函数与安全滤波机制提升任务可靠性。王鑫等[18]通过构建状态与动作空间及奖励机制,使无人机在复杂障碍环境中实现自主避障规划。

鉴于上述分析,现有研究要么忽略复杂环境下的合理分区问题,要么缺乏在动态障碍环境下高效的区域内规划策略。本研究通过改进的图分区法对覆盖任务区域实现可通行均衡划分,在各个子区域利用强化学习 算法规划无人机的覆盖航迹路线,使无人机具备自主决策能力。

## 最短可通行距离计算

为确保无人机在分布障碍物场景的区域可通行性 文中采用最短可通行距离 $D ^ { i } \left( \mathrm { u a v } \right)$ 替代欧氏距离作为 划分依据,表示为

$$
D ^ { i } \left( \mathrm { u a v } \right) = \mathrm { d i s t } ( P _ { \mathit { u } \mathit { A } V } ^ { i } , c ) , \forall c \in \mathrm { A r e a } ,\tag{2}
$$

其中, (·)表示基于广度优先搜索计算的最短航迹距离,c 表示可通行栅格。以无人机起点为生成点,通过广度优先搜索在栅格地图计算各个无人机 $P _ { \mathrm { \ U A V } } ^ { i }$ 到 达 各 可 通 行 栅 格 的 最 短 航 迹 距 离$D ^ { 1 } ( \mathrm { u a v } ) , D ^ { 2 } ( \mathrm { u a v } ) , \cdots , D ^ { n } ( \mathrm { u a v } )$ ,从而 构建 基 于障碍物约束的无人机覆盖航迹距离场。对每一个可达的栅格单元,根据其到各无人机的最短航迹距离,将其划分至无人机所对应的区域队列,表示为

$$
c \in \mathrm { U A V } _ { \mathrm { q u e u e } } ^ { i } , \mathrm { i f } i = \mathrm { a r g m i n } D ^ { i } \left( \mathrm { u a v } \right) ,\tag{3}
$$

其中, $\mathrm { U A V } _ { \mathrm { q u e u e } } ^ { i }$ 表示无人机 初始负责的覆盖任务区域队列。每个子区域内部保持连通结构,确保满足后续无人机区域覆盖航迹规划训练条件。

通过将广度优先搜索计算得到的最短可达航迹长度作为分区依据,该分区方法能够将每个栅格单元分配给具有最小可达距离的无人机,从而保证划分区域的连通性,不存在“死区”。

## 边界调节机制

在多无人机区域分区覆盖场景中,由于无人机初始位置分布和动态障碍物移动的随机性,基于的初始划分往往会导致各子区域规模存在明显差异,从而引发部分无人机任务量过重、整体覆盖效率下降等问题。

引入覆盖区域任务边界均衡调节机制,对区域划分的边界进行渐进式调节,仅对相邻子区域之间的边界栅格进行有限局部调整,通过局部栅格单元的转移逐步缩小不同子区域之间的负载差异,同时严格约束调整过程以维持区域连通性与可达性。

通过引入负载均衡目标 ,代表无人机覆盖栅格数量的平均数,表示为

$$
{ \overline { { \mathrm { \ q u e u e } } } } = { \frac { 1 } { n } } \sum _ { i = 1 } ^ { n } { \mathrm { U A V } } _ { \mathrm { \ q u e u e } } ^ { i } \qquad { \mathrm { \circ } }\tag{4}
$$

区域覆盖航迹规划的目标是在实现环境全域覆盖的同时,以较低的重复覆盖率避开动态障碍物。最优策略的获取不仅依赖于合理的奖励函数设计,还需要高效的未知环境探索机制。在现有强化学习路径规划相关研究中,探索概率通常采用线性衰减或指数衰减方式,逐步降低随机探索的比重,对提升算法训练效率具有一定效果。

然而,在存在动态障碍物的复杂环境中,无人机需要经过大量有效训练才能完成高效区域覆盖任务。若探索概率衰减过快,无人机在训练前期尚未学习到有效的覆盖与避障策略,便会过早依赖已有经验进行决策,容易陷入局部最优的覆盖路径。因此,在整体覆盖率较低时,应保持较高的探索概率,以执行更多有效的随机动作,充分探索环境;当覆盖率逐步提升并满足训练要求后,再降低探索概率,侧重利用已学习到的有效经验。基于上述思路,本研究建立覆盖率与探索概率之间的直接映射关系,设计一种基于实时覆盖率的自适应探索概率策略,表示为

## 栅格划分数量

栅格数量 $S _ { \mathrm { c o v e } }$ ,代表分区后分配到每个无人机的栅格数量,文中的分区改进目标是为了尽可能让每个无人机的覆盖栅格数量 S 一致或者相近,确保每个无人机飞行时间相近,减少等待时间。

## 覆盖航迹总步数

无人机实现对整个环境的完全覆盖,将覆盖总飞行步 数 定 义 为 覆 盖 总 步 数 $\begin{array} { r l } { \operatorname { s t e p } _ { \operatorname { c o v e } \mathrm { ~ \circ ~ } } } & { { } \operatorname { s t e p } _ { \operatorname { c o v e } } } \end{array}$ 越小,则说明无人机区域覆盖中存在的冗余飞行航迹较少。

## 重复覆盖率

在飞行过程中,由于障碍物以及局部环境的复杂性,无人机容易陷入局部最优并产生重复覆盖,重复覆盖率定义为

$$
c _ { \mathrm { { r e - r a t e } } } = \frac { s _ { \mathrm { { r e - c o v e } } } } { s _ { \mathrm { { c o v e } } } } \qquad ,\tag{22}

其中, $C _ { \mathrm { \ r e - r a t e } }$ 表示重复覆盖率, $S _ { \mathrm { \scriptsize ~ r e - c o v e } }$ 表示被覆盖两次及以上的栅格总数。重复覆盖率高意味着存在大量无效路径。在保证高覆盖率的前提下,以低重复覆盖率为目标,学习覆盖任务的最优航迹。

## 4 结论

围绕存在未知动态障碍物的多无人机分区覆盖航迹规划问题,分别在三架无人机和五架无人机两种场景下,对平行分区方法、 分区方法以及所提出的改进 分区方法进行分区覆盖航迹规划实验验证。平行分区覆盖方法在复杂环境下易受障碍物分布影响,区域负载不均衡问题明显; 分区方法在能够在分布障碍物场景实现分区,但是分区不均并存在“死区”问题;文中提出的改进 分区覆盖方法通过引入基于广度优先搜索的距离度量,有效提升了复杂环境下区域划分的合理性,并结合边界均衡调节策略,在不同无人机数量条件下均能够实现较为均衡的区域负 载 分 配。同 时,在 各 子 区 域 内 引 入 基 于的覆盖航迹规划策略及覆盖率驱动的自适应探索衰减机制,使无人机在动态障碍物干扰下仍能保持稳定的决策能力,加快了策略收敛速度。
