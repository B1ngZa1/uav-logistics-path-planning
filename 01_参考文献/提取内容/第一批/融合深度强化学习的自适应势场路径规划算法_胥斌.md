# The adaptive potential field path planning algorithm integrated with deep reinforcement learning

XU Bin1 ，WANG Qing1，2

1. Hangzhou International Innovation Institute， Beihang University， Hangzhou 311115， China 2. School of Automation Science and Electrical Engineering， Beihang University， Beijing 100191， China

Abstract To address the issues of local minima and parameter sensitivity in the traditional artificial potential field （APF）， as well as the slow convergence and low sample efficiency of deep reinforcement learning in UAV path planning in complex unknown environments， an adaptive path planning algorithm fusing proximal policy optimization （PPO） and improved artificial potential field （PPO-APF） is pro⁃

posed. A hierarchical architecture is applied in this algorithm. The repulsive force coefficient， effective distance， and rate adjustment coefficient are adaptively outputted by the upper-layer PPO network based on local perception， and flight commands are generated by the lower-layer improved APF model， where a target distance factor and kinematic constraints are introduced. Meantime， a composite reward function incorporating path smoothness with parameter stability is designed to suppress path jitter. Simulation results demonstrate that in complex scenarios with 22% obstacle coverage， the planning success rate of PPO-APF reaches 97. 33%， which is significantly superior to the improved APF by 53. 67% and pure reinforcement learning based PPO by 85%. The proposed algorithm takes advantage of a significant "cold start" mode， which effectively combines the adaptability of DRL with the stability of APF to realize UAV′s autonomous learning of slow-down crossing on narrow passage and preemptive avoidance strate⁃ gies， etc.

Key words UAV； Path planning； Artificial potential field； Deep reinforcement learning； Proximalpolicy optimization

## 0 引 言

随着无人机在低空感知［1］ 、物流配送［2］及灾后救援［3］ 等领域的广泛应用，其在复杂未知环境中实现安全高效的路径规划，已成为当前研究领域的重点方向。

在传统路径规划方法中，全局规划算法如A\*算法及快速扩展随机树等在静态已知环境中表现良好，但是在未知环境中适应性较差［4］ 。人工势场法作为反应式避障的代表算法，以其模型简洁和计算高效的特点，常用于实时避障［5］ ，但其在复杂场景中易陷入局部极小值或因斥力过大导致目标不可达，对参数设置较为敏感［6］ 。为此，学者们提出了多种改进思路，如通过修正斥力势场函数缓解目标不可达问题［7］；在 Frenet 坐标系中结合安全椭圆与预测距离动态调节斥力范围［8］ ；借助神经网络调整人工势场参数［9］ 。 。

近年来，深度强化学习为路径规划提供了新的解决途径，其能够通过智能体与环境的交互，从高维数据中学习行动策略［10］ 。例如，基于近端策略优化算法的端到端策略应用于无人机去中心化避障［11］ ；采用双延迟深度确定性策略梯度算法，根据深度图像直接确定所需的控制指令，并由飞行控制器执行［12］。然而，这类方法在训练初期样本效率低、收敛速度慢，且模型可解释性较弱，在未知环境中的泛化能力仍有局限。

因此，结合传统方法可解释性与深度强化学习自适应性的融合思路，逐渐成为研究趋势。主流方法之一是利用深度强化学习动态调整传统算法的关键参数，例如通过注意力机制编码环境特征以调节人工势场斥力系数［13］ ，采用双延迟深度确定性策略梯度算法优化扰动流体动态系统的参数组合［14］ 。

针对人工势场法在复杂环境适应性不足及易陷入局部最优等问题，本文提出一种融合近端策略优化与改进人工势场的自适应路径规划算法（PPO-APF）。在强化学习训练过程中，设计了包含路径平滑度与参数稳定性的复合奖励函数，引入课程学习机制以提升收敛效率与鲁棒性。

## 1 问题描述与系统建模

## 1. 1 问题描述与无人机运动学模型

无人机的路径规划是指在给定无人机起始点、目标点、飞行环境信息以及无人机的性能参数的条件下，寻找一条从起始点到目标点的最优或可行飞行路径。在二维平面的路径规划研究中，传统人工势场法通常将无人机简化为质点，其理想化的一阶运动学模型可表示为

$$
{ \dot { \pmb q } } = { \pmb v }\tag{1}
$$

式中： $\mathbf { \boldsymbol { q } } \in \mathbb { R } ^ { 2 }$ 表示无人机的位置向量， $\pmb { v } \in \mathbb { R } ^ { 2 }$ 表示无人机的速度向量。

然而，上述理想模型忽略了实际四旋翼无人机的物理惯性和执行机构限制。在实际飞行任务中，无人机的运动受到严格的动力学约束，主要体现在最大飞行速率和最大偏航角速度上。为了保证规划出的轨迹在物理上可执行，本文在规划模型中引入以下两类硬性约束：

1）最大飞行速率约束：无人机的瞬时飞行速率‖ v ‖不能超过其物理极限 $v _ { \mathrm { m a x } }$ ，即‖ $v \parallel \leqslant v _ { \operatorname* { m a x } }$ 。

2）最大偏航角速度约束：受限于机体惯性，无人机在单位时间内的航向角变化量是有限的。设 t时刻无人机的速度方向角为 $\boldsymbol { \psi } _ { t }$ ，单位时间最大转角为 $\Delta \psi _ { \mathrm { { m a x } } }$ ，则相邻时刻的航向角变化量必须满足：

$$
\left| { \psi _ { t + 1 } - \psi _ { t } } \right| \leqslant \Delta { \psi _ { \operatorname* { m a x } } }\tag{2}
$$

式中： $X _ { \operatorname* { m i n } }$ 和 $X _ { \mathrm { m a x } }$ 分别是 x 方向的下界值和上界值，$Y _ { \mathrm { m i n } }$ 和 $Y _ { \mathrm { m a x } }$ 分别是y方向的下界值和上界值。

## 2. 1 改进的人工势场算法

传统人工势场法在复杂环境中易陷入局部极小值且难以满足无人机动力学约束。本文在Ge等［7］的基础上引入无人机运动学约束与速率调节因子。

## 2. 1. 1 改进引力与斥力场

为避免长距离下引力过大导致速度失控，采用分段引力函数。设无人机位置为P，目标点为 $P _ { \mathrm { g o a l } }$ 两者的距离为 $\rho ( P , P _ { \mathrm { g o a l } } )$ ，引力势场 $U _ { \mathrm { a t t } }$ 的负梯度 ${ \pmb F } _ { \mathrm { a t t } }$ 定义为

$$
F _ { \mathrm { a t t } } ( P ) = \left\{ \begin{array} { l l } { - k _ { \mathrm { a t t } } ( P - P _ { \mathrm { _ { g o a l } } } ) , } & { \rho ( P , P _ { \mathrm { _ { g o a l } } } ) \leqslant d _ { \mathrm { t h } } } \\ { - d _ { \mathrm { t h } } k _ { \mathrm { a t t } } \frac { P - P _ { \mathrm { _ { g o a l } } } } { \rho ( P , P _ { \mathrm { _ { g o a l } } } ) } , } & { \rho ( P , P _ { \mathrm { _ { g o a l } } } ) > d _ { \mathrm { t h } } } \end{array} \right.\tag{4}
$$

式中： $\mathrm { : } k _ { \mathrm { a t t } }$ 为引力系数（本文固定为3，以减少动作空间维度）， $d _ { \mathrm { t h } }$ 为距离阈值。

针对“目标不可达”问题，在斥力场中引入目标距离因子 $\rho ^ { n } ( P , P _ { \mathrm { g o a l } } )$ 。改进后的斥力 $\boldsymbol { F } _ { \mathrm { r e p } }$ 分解为背离 障 碍 物 的 排 斥 力 $\boldsymbol { F } _ { \mathrm { r e p l } }$ 和 指 向 目 标 的 引 力分量 $F _ { \mathrm { r e p } 2 }$ ：

$$
{ \pmb F } _ { \mathrm { r e p } } = { \pmb F } _ { \mathrm { r e p } 1 } + { \pmb F } _ { \mathrm { r e p } 2 }\tag{5}
$$

$$
F _ { \mathrm { r e p } 1 } = k _ { \mathrm { r e p } } \bigg ( { \frac { 1 } { \rho ( P , P _ { \mathrm { o b s } } ) } } - { \frac { 1 } { \rho _ { \mathrm { o } } } } \bigg ) { \frac { \rho ^ { n } ( P , P _ { \mathrm { g o a l } } ) } { \rho ^ { 2 } ( P , P _ { \mathrm { o b s } } ) } } \nabla \rho ( P , P _ { \mathrm { o b s } } )\tag{6}
$$

$$
F _ { \mathrm { r e p } } = - \frac { n } { 2 } k _ { \mathrm { r e p } } \bigg ( \frac { 1 } { \rho ( P , P _ { \mathrm { o b s } } ) } - \frac { 1 } { \rho _ { 0 } } \bigg ) ^ { 2 } \rho ^ { n - 1 } ( P , P _ { \mathrm { g o a l } } ) \nabla \rho ( P , P _ { \mathrm { g o a l } } )\tag{7}
$$

式中 ${ \displaystyle \mathbf { \cdot } \rho ( P , P _ { \mathrm { o b s } } ) }$ 为障碍物距离， ${ } , { \rho } _ { 0 }$ 为障碍物斥力起效距离， $k _ { \mathrm { r e p } }$ 为斥力系数。当无人机接近目标点时，斥力合力趋于0，保证全局收敛。

在上述模型中， $\mathbf { \xi } _ { k _ { \mathrm { a t t } } } , k _ { \mathrm { r e p } }$ 以及 $\rho _ { 0 }$ 是决定路径质量的关键参数。大 $k _ { \mathrm { a t t } } / k _ { \mathrm { r e p } }$ ：无人机趋向目标的动力强，路径平直，但通过障碍物密集区时可能因避障不及时而发生碰撞。小 $k _ { \mathrm { a t t } } / k _ { \mathrm { r e p } }$ ：避障安全性高，但无人机可能过早产生绕行，导致路径冗余。 $\rho _ { 0 }$ 的选择直接影响路径的质量，增大 $\rho _ { 0 }$ 会提前绕障、路径更平滑但更可能导致局部最小值问题；减小 $\cdot \rho _ { 0 }$ 使路径能够更贴近障碍物，穿越狭窄通道，但风险上升。

## 基于运动学约束的修正与自适应速率调节

传统人工势场法通常直接将合力 $F _ { \mathrm { _ { r e s } } } = F _ { \mathrm { _ { a t t } } } +$ $\boldsymbol { F } _ { \mathrm { r e p } }$ 的方向作为期望速度方向，且假设速率恒定。为解决 节中提出的运动学约束问题，并提升复杂环境下的避障效率，本文在势场输出的基础上，设计了方向修正策略与自适应速率调节机制。

## 1）满足最大偏航角约束的方向修正

设无人机当前时刻的实际速度方向为 $\psi _ { \mathrm { { c u r } } } ,$ ，由改进势场计算出的期望合力方向为 $\psi _ { \mathrm { d e s } } \circ$ 为了保证轨迹的平滑性并满足式（2）定义的偏航角约束，下一时刻的实际速度方向 $\psi _ { \mathrm { n e x t } }$ 修正如下：

$$
\psi _ { _ \mathrm { { n e x t } } } = \left\{ \begin{array} { l l } { \psi _ { _ \mathrm { { d e s } } } , } & { \left| \psi _ { _ \mathrm { { d e s } } } - \psi _ { _ \mathrm { c u r } } \right| \leqslant \Delta \psi _ { _ { \mathrm { m a x } } } } \\ { \psi _ { \mathrm { c u r } } + \mathrm { s g n } ( \psi _ { _ \mathrm { { d e s } } } - \psi _ { _ \mathrm { c u r } } ) \cdot \Delta \psi _ { _ \mathrm { { m a x } } } , } & { \left| \psi _ { _ \mathrm { { d e s } } } - \psi _ { _ \mathrm { c u r } } \right| > \Delta \psi _ { _ { \mathrm { m a x } } } } \end{array} \right.\tag{8}
$$

## 2）基于强化学习的自适应速率调节

为了提高飞行效率与安全性，无人机的飞行速度v不应是恒定值，而应根据当前飞行状态调整，在接近密集障碍物时应降低速度，以确保安全通过；而在远离障碍物时则应提高速度，以加快向目标点的飞行。因此引入速率调节系数 α，该系数由深度强化学习策略输出，设基础飞行速度为 $v _ { 0 }$ ，则下一时刻的指令速度大小如下：

$$
v _ { \mathrm { n e x t } } = \alpha \cdot v _ { \mathrm { 0 } }\tag{9}
$$

上文中的 $k _ { \mathrm { r e p } } , \rho _ { \mathrm { 0 } }$ 与 $\alpha$ 参数由深度强化学习策略将本文问题建模为马尔可夫决策过程（S，A，P，R），其中，S表征状态空间，A对应动作空间，P为状态转

移，R为奖励函数，具体如下：

## 1）状态空间S

状态向量 ${ \pmb s } _ { t } = \big ( { \pmb s } _ { t } ^ { \mathrm { e n v } } , { \pmb s } _ { t } ^ { \mathrm { u a v } } \big )$ 由环境感知与自身状态组成。环境感知 ${ \pmb s } _ { t } ^ { \mathrm { e n v } }$ v：采用扇区直方图编码。以速度方向为中心将前方 $1 8 0 ^ { \circ }$ 视场划分为45个子扇区，记录各扇区内障碍物归一化距离 h，形成 45维特征向量。自身状态 $\mathbf { \pmb { s } } _ { t } ^ { \mathrm { u a v } }$ ：包含当前速度单位向量与目标方向单位向量，共4维。总状态维度为49。

## 2）动作空间A

动作直接对应势场关键参数 $\mathbf { \delta } \mathbf { a } _ { t } = ( k _ { \mathrm { r e p } , t } , \rho _ { 0 , t } , \alpha _ { t } ) $ 。为保证训练稳定性，将连续动作空间离散化，各参数在预设范围内选取（如 $k _ { \mathrm { r e p } } \in \left[ 3 , 1 2 \right] )$ ），策略网络输出多维离散索引。

## 3）奖励函数R

为兼顾避障安全与轨迹平滑，设计多目标复合奖励函数：

$$
\begin{array} { r } { R _ { t } = \lambda _ { \mathrm { _ 1 } } R _ { \mathrm { _ { d i s } } } + \lambda _ { \mathrm { _ 2 } } R _ { \mathrm { _ { t i m e } } } + \lambda _ { \mathrm { _ 3 } } R _ { \mathrm { _ { c u r v e } } } + \lambda _ { \mathrm { _ 4 } } R _ { \mathrm { _ { t h r e a t } } } + } \\ { \lambda _ { \mathrm { _ 5 } } R _ { \mathrm { _ { p a r a m s } } } + R _ { \mathrm { _ { e v e n t } } } \quad } \end{array}\tag{10}
$$

各分项定义如下：引导奖励 $R _ { \mathrm { d i s } }$ 为相邻时刻目标距离差，鼓励趋近目标。平滑奖励为 $R _ { \mathrm { c u r v e } }$ 与$R _ { \mathrm { p a r a m s } } , R _ { \mathrm { c u r v e } }$ 为惩罚速度方向突变， $R _ { \mathrm { p a r a m s } }$ 为惩罚参数序列方差，抑制因参数跳变导致的轨迹抖动。安全奖励为 $R _ { \mathrm { t h r e a t } } .$ ，当进入障碍物威胁半径时给予惩罚。稀疏奖励为 $R _ { \mathrm { e v e n t } }$ ，成功到达奖励时+100，碰撞或超时惩罚-100。

## 2. 3 近端策略优化算法训练

采 用 近 端 策 略 优 化（Proximal policy optimiza⁃， ）算法训练策略网络 $\pi _ { \theta ^ { 0 } }$ PPO通过引入裁剪目标函数 $L ^ { \mathrm { C L I P } }$ 限制策略更新幅度，避免训练震荡：

$$
\begin{array} { r l } & { L ^ { \mathrm { C L I P } } \big ( \theta \big ) = \mathbb { E } _ { t } \Big [ \operatorname* { m i n } \big ( r _ { t } \big ( \theta \big ) \hat { A } _ { t } , \mathrm { c l i p } ( r _ { t } \big ( \theta ) , } \\ & { \quad \quad \quad 1 - \epsilon , 1 + \epsilon ) \hat { A } _ { t } \big ) \Big ] } \end{array}\tag{11}
$$

网络采用 Actor-Critic 架构，Actor 网络输出上述 3 个参数的概率分布，Critic 网络评估状态价值。本文提出的融合算法采用“采样-更新”的在线学习模式：在每一时间步，将状态向量输入网络，采样得到组合系数，代入 节模型计算合力与位置，将轨迹数据存入经验回放池，满足批量后利用广义优势估计更新网络参数。

## 3 仿真校验

本节通过二维无人机仿真验证所提算法的有效性与鲁棒性，并在典型场景下分析其自适应机理。计算机仿真硬件配置为Intel Core i7-13620H 4. 90GHz 处理器，环境搭建采用 Python3. 10作为主要编程语言，深度强化学习算法框架基于PyTorch2. 6. 0 构建。

## 3. 1 实验描述与参数设定

## 3. 3 自适应机理分析

为进一步揭示算法如何自适应调节势场参数，本节结合轨迹与参数变化曲线进行分析。如图 所示，在狭窄通道穿越场景 ～ 时间步中，当无人机接近通道入口时，策略网络主动调低斥力起效距离 $\dot { \rho } _ { \scriptscriptstyle 0 }$ 并减小速率系数 $\alpha _ { \circ }$ 降低 $\mathbf { \nabla } _ { \rho _ { 0 } }$ 减少了通道两侧的合斥力大小和影响距离，使无人机得以“挤入”通道；降低速度则便于进行更安全的避障操作。穿越完成后，速度迅速恢复。而固定参数的 $\mathrm { A P F  – G e }$ 陷入局部最小点，无法穿越障碍物。在连续障碍规避场景44～56时间步中，面对前方大面积阻挡，策略网络将斥力影响距离 $\rho _ { 0 }$ 持续维持在较高水平。这使得无人机能够在更远处感知到障碍物的横向排斥力分量，从而“早发现、早反应”，提前开始平滑绕行，有效避免了路径抖动明显的现象。

## 4 结 论

本文针对无人机在复杂环境中的路径规划问题，提出了一种融合近端策略优化与人工势场法的自适应路径规划算法。该方法将强化学习的策略决策能力与势场法的解析优势相结合，使无人机能够基于局部环境感知信息，实时自适应调节斥力场关键参数及飞行速度，从而有效克服传统人工势场法依赖固定参数且易陷入局部极小值的问题，同时缓解纯强化学习方法训练收敛缓慢和路径抖动较大的不足。

仿真结果表明，在障碍物覆盖率达22%的复杂场景中，PPO-APF算法规划成功率达到97. 33%，显著优于传统APF-Ge算法和PPO算法。此外，算法能够在狭窄通道及复杂障碍环境中学习到合理的减速与绕行策略，兼顾路径可行性与平滑性，体现出良好的环境适应能力与规划鲁棒性。
