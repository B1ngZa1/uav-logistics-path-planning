## 二、多智能体强化学习（MARL）

### 2.1 多智能体PPO（MAPPO）

#### [7] The Surprising Effectiveness of PPO in Cooperative Multi-Agent Games

- **标题（中文）**：PPO在合作多智能体博弈中的惊人有效性
- **标题（英文）**：The Surprising Effectiveness of PPO in Cooperative Multi-Agent Games
- **作者**：Yu, C., Velu, A., Vinitsky, E., Gao, J., Wang, Y., Bayen, A., Wu, Y.
- **年份**：2022
- **期刊/会议**：Advances in Neural Information Processing Systems (NeurIPS)
- **DOI**：N/A（arXiv:2103.01955）
- **关键词**：MAPPO; PPO; multi-agent; cooperative; centralized training decentralized execution
- **摘要**：本文系统研究了PPO算法在合作多智能体博弈中的表现，提出了MAPPO（Multi-Agent PPO）算法。MAPPO采用集中式的Critic和分散式的Actor架构，Critic接收全局状态信息评估每个智能体的动作价值，Actor仅基于局部观测进行决策。实验表明MAPPO在多个标准多智能体基准任务（星际争霸、谷歌足球等）上超越了QMIX等值分解方法，且训练更加稳定。

#### [8] Multi-Agent Actor-Critic for Mixed Cooperative-Competitive Environments (MADDPG)

- **标题（中文）**：混合合作竞争环境下的多智能体Actor-Critic算法
- **标题（英文）**：Multi-Agent Actor-Critic for Mixed Cooperative-Competitive Environments
- **作者**：Lowe, R., Wu, Y., Tamar, A., Harb, J., Abbeel, P., Mordatch, I.
- **年份**：2017
- **期刊/会议**：Advances in Neural Information Processing Systems (NeurIPS)
- **DOI**：N/A（arXiv:1706.02275）
- **关键词**：MADDPG; multi-agent; actor-critic; CTDE; cooperative-competitive
- **摘要**：本文提出了MADDPG（Multi-Agent Deep Deterministic Policy Gradient）算法，是CTDE框架的经典代表作。训练阶段每个智能体的Critic可访问所有智能体的观测和动作信息，执行阶段每个智能体仅使用自己的局部观测进行决策。该方法在多智能体通信、竞争和合作任务中均表现出色，为后续CTDE方法奠定了基础。

### 2.2 值分解方法（QMIX, VDN）

#### [9] QMIX: Monotonic Value Function Factorisation for Deep Multi-Agent Reinforcement Learning

- **标题（中文）**：QMIX：深度多智能体强化学习中的单调值函数分解
- **标题（英文）**：QMIX: Monotonic Value Function Factorisation for Deep Multi-Agent Reinforcement Learning
- **作者**：Rashid, T., Samvelyan, M., de Witt, C.S., Farquhar, G., Foerster, J., Whiteson, S.
- **年份**：2018
- **期刊/会议**：International Conference on Machine Learning (ICML)
- **DOI**：N/A（arXiv:1803.11485）
- **关键词**：QMIX; value decomposition; multi-agent; monotonic; CTDE; deep reinforcement learning
- **摘要**：本文提出了QMIX算法，一种用于多智能体强化学习的值分解方法。QMIX通过约束全局Q值函数与各智能体局部Q值函数之间的单调递增关系，保证了集中训练时的最优联合动作与分散执行时各智能体贪心动作的一致性。该方法在星际争霸微操任务上取得了当时最优的性能，成为值分解方法的里程碑。

#### [10] Value-Decomposition Networks For Cooperative Multi-Agent Learning (VDN)

- **标题（中文）**：用于合作多智能体学习的值分解网络
- **标题（英文）**：Value-Decomposition Networks For Cooperative Multi-Agent Learning
- **作者**：Sunehag, P., Lever, G., Gruslys, A., Czarnecki, W.M., Zambaldi, V., Jaderberg, M., Lanctot, M., Sonnerat, N., Leibo, J.Z., Tuyls, K., Graepel, T.
- **年份**：2018
- **期刊/会议**：International Conference on Autonomous Agents and Multiagent Systems (AAMAS)
- **DOI**：N/A（arXiv:1706.05296）
- **关键词**：VDN; value decomposition; cooperative; multi-agent; additive factorization
- **摘要**：本文提出了值分解网络（VDN），是值分解方法的开创性工作。VDN将全局值函数简单地分解为各智能体局部值函数的加性求和，即 Q_tot = sum(Q_i)，从而实现了集中训练分散执行。虽然VDN的分解能力有限（仅支持加性关系），但其简洁的设计理念启发了QMIX等后续更强大的分解方法。

#### [11] QPLEX: Duplex Dueling Multi-Agent Q-Learning

- **标题（中文）**：QPLEX：双工对弈多智能体Q学习
- **标题（英文）**：QPLEX: Duplex Dueling Multi-Agent Q-Learning
- **作者**：Wang, J., Ren, Z., Liu, T., Yu, Y., Zhang, C.
- **年份**：2021
- **期刊/会议**：International Conference on Learning Representations (ICLR)
- **DOI**：N/A（arXiv:2008.01062）
- **关键词**：QPLEX; value decomposition; dueling; multi-agent; IGM
- **摘要**：本文提出了QPLEX算法，将Dueling结构引入值分解框架，通过双通道编码实现全局Q值与局部Q值之间更灵活的映射关系。QPLEX满足个体-全局-最大化（IGM）条件，理论上比QMIX具有更强的表达能力。实验在星际争霸基准任务上验证了QPLEX相对于QMIX和VDN的性能优势。

### 2.3 通信学习

#### [12] Learning Multiagent Communication with Backpropagation (CommNet)

- **标题（中文）**：基于反向传播的多智能体通信学习
- **标题（英文）**：Learning Multiagent Communication with Backpropagation
- **作者**：Sukhbaatar, S., Szlam, A., Fergus, R.
- **年份**：2016
- **期刊/会议**：Advances in Neural Information Processing Systems (NeurIPS)
- **DOI**：N/A（arXiv:1605.07736）
- **关键词**：Communication learning; multi-agent; CommNet; backpropagation; continuous communication
- **摘要**：本文提出了CommNet，一种端到端可微分的多智能体通信学习框架。智能体在每个时间步生成连续向量作为通信消息，其他智能体通过平均池化聚合接收到的消息用于决策。整个通信过程可通过反向传播进行端到端训练，无需预定义通信协议。实验表明，学习到的通信策略能够显著提升多智能体协作任务的性能。

#### [13] Learning to Communicate with Deep Multi-Agent Reinforcement Learning (DIAL/RIAL)

- **标题（中文）**：基于深度多智能体强化学习的通信学习
- **标题（英文）**：Learning to Communicate with Deep Multi-Agent Reinforcement Learning
- **作者**：Foerster, J., Assael, Y., de Freitas, N., Whiteson, S.
- **年份**：2016
- **期刊/会议**：Advances in Neural Information Processing Systems (NeurIPS)
- **DOI**：N/A（arXiv:1605.06676）
- **关键词**：Communication; discrete messages; DIAL; RIAL; multi-agent reinforcement learning
- **摘要**：本文提出了DIAL（Differentiable Inter-Agent Learning）和RIAL（Reinforced Inter-Agent Learning）两种多智能体通信学习方法。DIAL通过梯度直通估计器实现了离散消息的端到端训练，RIAL使用强化学习分别训练每个智能体的通信和动作策略。实验在Switch Riddle等通信任务上验证了方法的有效性。

#### [14] TarMAC: Targeted Multi-Agent Communication

- **标题（中文）**：TarMAC：面向目标的多智能体通信
- **标题（英文）**：TarMAC: Targeted Multi-Agent Communication

- **年份**：2019
- **期刊/会议**：International Conference on Machine Learning (ICML)
- **DOI**：N/A（arXiv:1810.11187）
- **关键词**：Targeted communication; attention; multi-agent; signed message; soft attention
- **摘要**：本文提出了TarMAC，一种基于注意力机制的目标化多智能体通信方法。与广播式通信不同，TarMAC使用软注意力机制使发送者智能体能够选择性地向特定接收者发送消息。消息使用签名机制确保接收者能够识别消息来源。实验在多智能体协作导航和通信任务中验证了目标化通信相对于广播通信的效率优势。

## 三、任务分配算法

### 3.1 匈牙利算法

#### [15] The Hungarian Method for the Assignment Problem

- **标题（中文）**：指派问题的匈牙利方法
- **标题（英文）**：The Hungarian Method for the Assignment Problem
- **作者**：Kuhn, H.W.
- **年份**：1955
- **期刊/会议**：Naval Research Logistics Quarterly
- **DOI**：10.1002/nav.3800020109
- **关键词**：Hungarian method; assignment problem; combinatorial optimization; linear programming
- **摘要**：本文是匈牙利算法的经典原著，提出了一种求解指派问题（二分图最优匹配）的多项式时间算法。算法基于对偶理论，通过交替标记和增广路径操作，在O(n^3)时间复杂度内找到使总代价最小的最优分配方案。该算法广泛应用于任务分配、资源调度等领域，是组合优化领域的基础算法。

### 3.2 拍卖算法

#### [16] Distributed Assignment Problems and Auction Algorithms

- **标题（中文）**：分布式指派问题与拍卖算法
- **标题（英文）**：Distributed Assignment Problems and Auction Algorithms
- **作者**：Bertsekas, D.P.
- **年份**：1992
- **期刊/会议**：Parallel and Distributed Computation: Numerical Methods (Prentice-Hall, Chapter 6)
- **DOI**：N/A
- **关键词**：Auction algorithm; distributed assignment; parallel computation; optimization
- **摘要**：本文系统介绍了拍卖算法在分布式指派问题中的应用。拍卖算法模拟了市场经济中的竞标过程：未被分配的"竞标者"对其最偏好的"物品"出价，物品价格随竞标上升，直到市场达到均衡。算法天然适合分布式实现，每个智能体可独立进行竞标决策。该方法在机器人任务分配、传感器网络等领域有广泛应用。
