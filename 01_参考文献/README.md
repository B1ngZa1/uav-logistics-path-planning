## 五、使用指南

### 5.1 查找文献

1. 按方向查找：进入对应子目录
2. 按类型查找：参考知识库索引
3. 按关键词搜索：使用IDE搜索功能

### 5.2 阅读文献

1. 快速浏览：阅读知识卡片
2. 深入阅读：查看提取的Markdown
3. 原文参考：打开PDF文件

### 5.3 引用文献

使用BibTeX格式引用，参考知识库中的引用示例
