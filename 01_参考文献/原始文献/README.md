# 无人机项目参考文献库

本目录面向“带高度分层的无人机空中走廊与多机协同”项目，当前按六个主题整理：

| 主题 | 目录 | 用途 |
|---|---|---|
| 强化学习 | `01_RL` | PPO、SAC、TD3、端到端飞行控制 |
| 多智能体协同 | `02_MARL协同` | MAPPO、MADDPG、QMIX、集中训练分布执行 |
| 多算法路径规划 | `03_多算法路径规划` | PRIMAL、EGO-Planner、RRT*、覆盖规划 |
| 三维高度空中走廊 | `04_三维高度空中走廊` | 安全走廊、时空走廊、低空容量、死锁消解 |
| 能耗安全约束 | `05_能耗安全约束` | CPO、屏障证书、旋翼机能耗 |
| 综述基准 | `06_综述基准` | 安全学习、控制基准、MARL/UAV 综述 |

## 文件与证据规则

- PDF 是公开网页、arXiv 或作者公开版本的研究资料；每篇核心记录对应 `_检索记录/<ID>_record.json`。
- `_检索记录` 保存查询结果、官方页面 HTML、下载信息、SHA-256 与首屏预览，便于复核。
- `文献索引.csv` 是当前 30 篇记录的机器可读索引，含关键词、项目关系、OpenAlex ID、实际 PDF 页数、可读性、SHA-256 和核验状态。
- 当前 30/30 篇已由 OpenAlex 与公开来源完成题名/年份/作者交叉匹配；这表示书目元数据一致，不等同于论文结论已被复现。AnySearch 候选与官方页面证据均保存在 `_检索记录`，正式论文引用前仍应核对正式出版版本与 DOI。
- 目录 `04_三维_高度_空中走廊`、`05_能耗与安全约束`、`06_综述与基准` 是前一轮生成的兼容别名，保留以避免破坏已有链接；索引和后续新增文件统一使用本 README 上方的六个规范目录。
- 不把预印本、教程或基准环境当成工程合规依据；真实飞行高度、空域、通行权和安全间隔需要主管部门与现场风险评估确认。

## 推荐阅读顺序

先读 `CO01/CO02/CO04` 建立三维走廊与冲突消解基线，再读 `PA01/PA02/PA03/PA04` 连接几何规划；随后用 `MA01/MA02/MA04/MA06` 设计 CTDE 协同策略，用 `SA01/SA02/SA04/SA05` 加入安全与能耗约束，最后以 `RL01/RL02/RL03/RL05` 做单机策略和连续控制对照。
