## 一、研究背景与动机

### 1.1 问题背景

- 空中作战逐渐成为现代军事对抗主力，无人作战飞行器（UCAV）成为未来信息化、智能化空战的主要载体
- UCAV需具备两大核心能力：**势态评估（Situation Assessment）**能力和**机动战术决策（Maneuvering Decision-Making）**能力
- 空战环境复杂、格斗势态高速变化，要求无人机能准确感知战场环境并产生有效的自主格斗决策

### 1.2 传统方法及其局限

| 方法类别 | 代表算法 | 核心局限 |
|---|---|---|
| 微分对策法 | 追逃博弈 | 计算量大，追逃角色高速变化，不适于实时决策 |
| 专家系统 | 规则库 | 无法覆盖未知场景，需人为参与 |
| 影响图法 | 贝叶斯网络 | 依赖先验知识过多，响应速度慢 |
| 矩阵博弈法 | 得分函数矩阵 | 无长期规划能力，决策"短视" |
| 人工免疫系统 | 接种免疫式学习 | 收敛慢，方案单一 |
| 遗传算法 | GFT（遗传模糊树） | 编码和评价函数过度依赖主观设定 |
| 近似动态规划 | ADP+线性函数逼近 | 简化假设不适用于复杂场景，样本需求指数爆炸 |
| 迁移学习 | 动态脚本DS | 依赖特定规则库，泛化性差 |

### 1.3 研究动机

- 空战格斗为大规模状态空间下的序列化决策问题，传统RL面临**维度爆炸（Curse of Dimensionality）**
- 深度神经网络具备端到端感知学习特性，可与RL结合解决连续状态空间下的动作价值近似问题
- 函数逼近机制避免穷举式表示每个离散状态价值，以更少参数覆盖高维状态空间

## 二、理论基础

### 2.1 强化学习三要素

1. **策略（Policy）**：状态到动作的映射 pi(a|s)
2. **值函数（Value Function）**：对每个状态的长期奖励估计 V^pi(s) 或 Q^pi(s,a)
3. **模型（Model）**：Agent对环境的认知，可预测下一时刻的观测值和奖励信号

### 2.2 马尔可夫决策过程（MDP）

六元组表示：<S, A, P, R, gamma, G>

- **状态空间 S**：所有可能的离散状态
- **动作空间 A**：当前状态可执行的所有动作
- **状态转移概率 P**：Pa = [Pij] 表示在状态i执行动作a转移到状态j的概率
- **奖励函数 R**：R(s, a, s') 表示单步立即回报
- **折扣因子 gamma**：0~1之间，越大越重视远期奖励
- **累积折扣奖励 Gt**：Gt = sum(gamma^k * R_{t+k})

核心方程：

- 状态值函数：V^pi(s) = E^pi[Gt | st=s]
- 贝尔曼方程：V^pi(s) = E^pi[R_{t+1} + gamma * V^pi(s_{t+1}) | st=s]
- 动作值函数：q^pi(s,a) = E^pi[Gt | st=s, at=a]
- 最优策略：pi*(s) = argmax(q*(s,a))

### 2.3 基础RL算法

| 算法 | 核心思想 | 特点 |
|---|---|---|
| 蒙特卡罗（MC） | 从完整回合经验中学习，V(s)=S(s)/N(s) | 无偏估计，但方差大、需等回合结束 |
| 时序差分（TD） | 自举式单步更新：V(s) += alpha*(R+gamma*V(s')-V(s)) | 在线学习，效率高于MC |
| Q-Learning | 异策略TD：Q(s,a) += alpha*(R+gamma*max_a'Q(s',a')-Q(s,a)) | 免模型、异策略，采样效率高 |

### 2.4 DQN（深度价值网络）核心机制

DQN将Q-Learning与深度神经网络结合，解决了高维状态空间下的学习问题：

1. **经验回放（Experience Replay）**：创建记忆存储空间记录经验元组 <st, at, rt, s_{t+1}>，随机采样打破时序相关性，使数据更符合IID假设
2. **损失函数**：Loss(theta) = E[(r + gamma*max Q(s',a',theta^-) - Q(s,a,theta))^2]
3. **暂时参数冻结（Target Network）**：每N步将评估网络参数theta复制给目标网络参数theta^-，保持目标值阶段性稳定

## 三、研究方法与设计

### 3.1 状态空间设计

- **单机状态七元组**：s = [v, x, y, z, theta, psi, phi]
  - v：飞行速率
  - (x, y, z)：三维空间坐标（x北、y东、z垂直向上）
  - theta：俯仰角（Pitch）
  - psi：偏航角（Yaw）
  - phi：滚转角（Roll）
- **系统总状态**：14维向量（红方7维 + 蓝方7维）
- **网络输入**：12维（去除双方滚转角，因滚转角为固定离散值用于动作编码）

### 3.2 动作空间设计

采用NASA基本空战机动集合（BFM），7种离散动作，使用三元组 [Nx, Nz, phi] 编码：

| 动作 | 切向过载 Nx | 法向过载 Nz | 滚转角 phi |
|---|---|---|---|
| 定常飞行 | 0 | 1 | 0 |
| 加速飞行 | 2 | 1 | 0 |
| 减速飞行 | -2 | 1 | 0 |
| 左转弯 | 0 | 5 | -pi/3 |
| 右转弯 | 0 | 5 | pi/3 |
| 向上拉起 | 0 | 5 | 0 |
| 向下俯冲 | 0 | -5 | 0 |

- 切向过载范围 [-2, 2]，法向过载范围 [-5, 5]
- 运动学方程（6个一阶微分方程）：描述dv/dt, dpsi/dt, dtheta/dt, dx/dt, dy/dt, dz/dt
- 状态更新：采用**四阶龙格-库塔**数值解法（优于欧拉法），仿真时间步长 dt=0.25s

### 3.3 势态评估与奖励函数设计

势态感知要素（从红方角度）：

- **脱离角（AA）**：敌机纵轴尾部方向与我机雷达准线的夹角
- **偏离角（ATA）**：我机飞行纵轴线与检测到敌机雷达准线的夹角
- **高度差 delta_h**：红方与蓝方的高度差
- **速度差 delta_v**：红方与蓝方的速度差

**分项奖励函数**：

1. **角度奖励 Ra**：Ra = 2 - 2(AA + ATA)/pi （线性映射到[-1,1]）
2. **高度奖励 Rh**：由高度差奖励r_h + 自身高度约束r_h_self组成
   - 高度差 > 0 时正向奖励，> 2000m 后优势减弱
   - 自身高度 < 300m 时施加惩罚
3. **速度奖励 Rv**：由速度差奖励r_v + 自身速度约束r_v_self组成
   - 速度差线性奖励
   - 速度 < 50m/s 时施加惩罚（避免失速）

**综合奖励函数**：
R = a1 * Ra + a2 * Rh + a3 * Rv   (a1+a2+a3=1, a1,a2,a3 >= 0)

默认权重：a1=0.5, a2=0.25, a3=0.25（角度因素最重要）

### 3.4 对比基线：Min-Max格斗策略

- 零和博弈算法，搜索深度3层
- 核心思想：我方选使敌方奖励最小化的动作，敌方选使自身回报最大化的动作
- ab_MM = argmax_ab(argmin_ar Rb(s))
- 7种动作/方，3层搜索，计算代价适中

### 3.5 胜负判定条件

- **胜利条件**：脱离角AA < 30度 且 偏离角ATA < 60度（占据绝对攻击优势）
- **回合限制**：300步内未分胜负判为平局

## 四、核心算法：基于价值近似网络的决策系统

### 4.1 网络结构

五层全连接神经网络：

| 网络层 | 神经单元数 | 激活函数 |
|---|---|---|
| 输入层（状态） | 12 | - |
| 隐藏层1 | 32 | ReLU |
| 隐藏层2 | 64 | ReLU |
| 隐藏层3 | 32 | ReLU |
| 输出层（动作） | 7 | - |

- 输入：12维状态向量 s = [vr, xr, yr, zr, theta_r, psi_r, vb, xb, yb, zb, theta_b, psi_b]
- 输出：7个Q值 Q(s, a1), Q(s, a2), ..., Q(s, a7) 对应7种机动动作
- 最优动作：pi*(s) = argmax_a(Q*(s, a, theta))

### 4.2 训练优化方法

- **双网络架构**：价值评估网络（Eval_net, 参数theta）+ 目标网络（Target_net, 参数theta^-）
- **经验回放**：格斗经验池为二维矩阵 [Memory_Size, n_features+2]，Memory_Size=2000，n_features=12
- **损失函数**：Loss(theta) = sum(q_target - q_eval)^2 / Batch_Size
- **优化器**：RMSProp（二阶梯度方法）
- **参数冻结**：评估网络每训练200次，将参数theta传递给目标网络theta^-
- **训练频率**：每5步仿真训练一次网络

### 4.3 探索与利用机制

设计了**贪心程度递增的epsilon-greedy策略**：

epsilon = 0.1 + learning_steps/1000,  if epsilon < epsilon_max
epsilon = epsilon_max,                  otherwise

- 起始贪心程度 0.1（高探索）
- 每优化一次网络，epsilon增加0.001
- 最大贪心程度 epsilon_max = 0.9（高利用）
- 相比固定epsilon和纯贪心策略：递增式在前期充分探索、后期充分利用，整体训练损失最小

## 五、实验结果与分析

### 5.1 实验环境

- 硬件：Intel i7-3770K@3.50GHz, 16GB RAM, NVIDIA GTX 660
- 软件：Ubuntu 16.04, TensorFlow 1.2.0, Python 3.6
- 超参数：gamma=0.9, g=10m/s^2, dt=0.25s, Batch_Size=64, 学习率=0.01

### 5.2 实验一：简单任务训练（敌方定常飞行）

- 初始化：红方(0,0,2900)速率250m/s，蓝方(3000,3000,2800)速率248m/s，双方对飞
- 约40个回合后，红方学会**"筋斗"战术**（先拉高再俯冲绕后攻击）
- 约116回合后，红方学会**"眼镜蛇"战术**（先拉高再右转俯冲到敌后方）
- 关键发现：红方学会高度优势"适可而止"，在合适高度及时转弯或空翻

### 5.3 实验二：自我学习（Self-Play）

- 红蓝双方均采用DQN价值近似网络
- 双方均学会主动攻击或规避威胁，产生有效自主格斗行为
- 出现**"强势回旋"战术**、迂回战术等多种战斗策略
- 总体表现势均力敌

### 5.4 实验三：DQN vs Min-Max 对比实验

初始化：红方(0,0,2900)速率250m/s，蓝方(3000,3000,2895)速率240m/s

**胜率变化趋势**（以100回合为一阶段）：
- 前15个阶段：红方平均胜率 < 30%，蓝方占优，模型处于学习探索期
- 第16阶段起：红方胜率显著上升
- 后期稳定结果：
  - 红方胜率：**71.04%**
  - 蓝方胜率：**6.16%**
  - 平局率：**22.80%**

**回合步长变化**：
- 初期蓝方Min-Max快速击败红方
- 中期红方学到技能，交战回合变长
- 后期红方能力提升，回合步数减少（快速击败敌方）

**Loss曲线**：初始随机参数导致高Loss，随迭代训练逐渐下降收敛

## 六、贡献与不足

### 6.1 主要贡献

1. **构建了完整的三维单机格斗仿真平台**：含状态描述（14维）、7种BFM动作编码、运动学方程、四阶龙格-库塔状态更新
2. **设计了多因素综合奖励函数**：融合角度（AA/ATA）、高度（势能优势+安全约束）、速度（动能优势+失速惩罚）三维度，采用线性加权组合
3. **提出基于DQN的价值近似网络决策方法**：5层全连接网络（12-32-64-32-7），结合经验回放和暂时参数冻结训练
4. **设计了贪心程度递增的epsilon-greedy策略**：前期充分探索、后期充分利用，优于固定epsilon和纯贪心
5. **对比实验证明DQN策略显著优于传统Min-Max**：训练后期红方胜率达71.04%，具备自适应能力

### 6.2 研究局限

1. 仅考虑**单机1v1格斗**，未涉及多机协同作战
2. 动作空间为**离散的7种基本机动**，未采用连续动作空间
3. 未考虑军用武器性能、风扰动、通信延迟等实际因素
4. 对手策略（Min-Max）较为固定，未验证面对更强对手（如PPO/A3C）的泛化性
5. 仿真假设简化（无空气阻力、无侧滑、恒定质量等）

### 6.3 对本项目的启示

| 维度 | 本文方法 | 对无人机配送项目的映射 |
|---|---|---|
| 状态空间 | 12维连续（位置+速度+角度） | 位置+订单状态+携带量，维度相近 |
| 动作空间 | 7种离散BFM | 4方向/8方向离散配送动作 |
| 奖励函数 | 角度+高度+速度线性组合 | 配送+时间+能耗+安全约束 |
| 算法 | DQN（Value-based） | L1用Q-learning，L2用DQN，L3/L4用PPO |
| 探索策略 | 递增epsilon-greedy | 可复用该递增贪心策略 |
| 对比基线 | Min-Max | 经典RL（Q-learning/SARSA） |
| 训练方式 | 经验回放+目标网络 | L2及以上层级均需此技术 |
