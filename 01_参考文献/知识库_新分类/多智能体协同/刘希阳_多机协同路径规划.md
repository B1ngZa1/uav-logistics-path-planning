## 一、研究问题与背景

### 1.1 核心问题

解决多无人机协同执行配送/侦察等任务时的**路径规划**问题，将其分解为两个子问题：
1. **目标分配子问题**：哪架无人机去哪个目标？（组合优化）
2. **局部路径规划子问题**：每架无人机如何从当前位置飞到目标？（连续控制 + 避障）

总优化目标为**最小化所有无人机完成全部任务的总时间**（makespan）。

### 1.2 应用场景

- **物流配送**：Amazon、京东、顺丰、美团无人机配送
- **搜索救援**：灾区多机协同搜索
- **军事侦察**：多机编队覆盖侦察
- 本论文聚焦**二维平面**（室内实验）和**三维空间**（仿真）场景

### 1.3 核心挑战

| 挑战 | 具体内容 |
|------|----------|
| NP-hard目标分配 | $N$ 架无人机分配到 $M$ 个目标，组合爆炸 |
| 实时避障 | 多机同时飞行，需避免互相碰撞 |
| 动态约束 | 速度/加速度受限、转弯半径、能量消耗 |
| 集中式 vs 分布式 | 全局最优 vs 可扩展性 |
| sim-to-real | 仿真到真实硬件的迁移 |

## 二、方法体系

### 2.1 系统建模（第二章）

#### 坐标系

采用双坐标系：
- **地面惯性坐标系** $O_g\text{-}X_gY_gZ_g$
- **机体坐标系** $O_b\text{-}X_bY_bZ_b$

#### 旋转矩阵（欧拉角表示）

$$R_{bg} = R_z(\psi) \cdot R_y(\theta) \cdot R_x(\phi) \tag{2-1 \sim 2-5}$$

其中 $\phi, \theta, \psi$ 分别为滚转角、俯仰角、偏航角。

#### 运动学模型

$$\begin{cases}
\dot{x} = v\cos\psi\cos\theta \\
\dot{y} = v\sin\psi\cos\theta \\
\dot{z} = -v\sin\theta
\end{cases} \tag{2-6 \sim 2-11}$$

#### 动力学模型

$$\begin{cases}
m\ddot{x} = F_x + f_{\text{drag},x} \\
m\ddot{y} = F_y + f_{\text{drag},y} \\
m\ddot{z} = F_z - mg + f_{\text{drag},z}
\end{cases} \tag{2-12 \sim 2-16}$$

#### 优化目标

$$\min T = \max_{i=1}^{N} T_i \tag{2-17}$$

其中 $T_i$ 为第 $i$ 架无人机的飞行时间，目标为最小化最大完成时间（makespan）。

#### 约束条件

- **碰撞避免**：$\|P_j - P_i\| > 2r, \quad \forall i \neq j$ $\tag{2-21}$
- **最大速度**：$\|v_i\| \leq v_{\max}$ $\tag{2-22}$
- **最大加速度**：$\|a_i\| \leq a_{\max}$ $\tag{2-23}$

#### 目标分配子问题

$$\min \sum_{i=1}^{N} \sum_{j=1}^{M} c_{ij} \cdot x_{ij} \tag{2-24}$$

其中 $c_{ij}$ 为无人机 $i$ 到目标 $j$ 的路径代价，$x_{ij} \in \{0,1\}$ 为分配指示变量，约束条件包括每个目标恰好被一架无人机服务、每架无人机至多服务一个目标。

#### 局部路径规划子问题

$$\min \int_0^{T_i} \|v_i(t)\| \, dt \tag{2-26}$$

约束：起止点约束、无碰撞、动力学可行。

### 2.2 集中式目标分配（第三章）

#### 2.2.1 遗传算法（GA）

**编码**：排列编码，基因 = 目标排列

**适应度函数**：

$$f = \frac{1}{T_{\text{total}}} \tag{3-1}$$

**选择算子**：精英保留 + 轮盘赌（elitism ratio = 0.1）

**交叉算子**：顺序交叉（Order Crossover, OX），保持排列合法性

**变异算子**：交换变异（Swap Mutation），随机交换两个基因位置

**GA参数配置**：

| 参数 | 值 | 说明 |
|------|-----|------|
| 种群规模 | 200 | population size |
| 最大迭代 | 1000 | max iterations |
| 交叉概率 | 0.6 | crossover probability |
| 变异概率 | 0.05 | mutation probability |
| 精英比例 | 0.1 | elitism ratio |

**算法流程（Algorithm 3-1, 3-2）**：
```
Initialize population P(0) with random permutations
For t = 1 to max_iter:
    Evaluate fitness for all individuals
    Select parents (elite + roulette)
    Apply OX crossover (prob=0.6)
    Apply swap mutation (prob=0.05)
    Replace population
Return best individual
```

#### 2.2.2 改进粒子群优化（PSO）

**核心改进**：用GA的交叉操作**替代**传统PSO的速度更新，解决离散排列空间的编码问题。

**位置更新公式**：

$$x_i^{t+1} = \text{Crossover}(x_i^t, p_{\text{best},i}) \oplus \text{Crossover}(x_i^t, g_{\text{best}}) \tag{3-3 \sim 3-5}$$

**变异操作**：

$$x_i^{t+1} = \text{Mutate}(x_i^{t+1}) \quad \text{with probability } p_m \tag{3-6, 3-7}$$

**PSO参数配置**：

| 参数 | 值 | 说明 |
|------|-----|------|
| 种群规模 | 100 | particle count |
| 交叉概率 | 0.99 | crossover probability (high) |
| 变异概率 | 0.99 | mutation probability (high) |

#### 2.2.3 分布式目标分配

**基于网格分区的分布式方法**：

- 按通信范围 $R_c$ 划分网格，每个网格内运行KM算法
- KM（Kuhn-Munkres）算法求解网格内的最优二部图匹配
- 网格间通过BFS通信传递信息

**分布式参数配置**：

| 参数 | 值 | 说明 |
|------|-----|------|
| 场地尺寸 | 10m x 10m | field size |
| 通信范围 | 3-5m | communication range $R_c$ |
| 最大无人机数 | 200 | max N for scalability test |
| 网格尺寸 | 依 $R_c$ 而定 | grid cell size |

**算法流程（Algorithm 3-3）**：
```
Each UAV i:
    1. Determine grid cell from position
    2. Communicate with neighbors within R_c
    3. Build local cost matrix C_ij
    4. Run KM algorithm for optimal matching
    5. BFS for inter-grid target handoff
```

### 2.3 基于MADDPG的路径规划（第四章）

#### 2.3.1 MAMDP建模

将多机路径规划建模为**多智能体马尔可夫决策过程（MAMDP）**，七元组：

$$\langle \mathcal{N}, \mathcal{S}, \mathcal{A}, \mathcal{R}, \pi, \gamma, \mathcal{T} \rangle \tag{4-2}$$

| 符号 | 含义 |
|------|------|
| $\mathcal{N}$ | 智能体集合 $\{1, 2, \ldots, N\}$ |
| $\mathcal{S}$ | 全局状态空间 |
| $\mathcal{A}$ | 联合动作空间 $\mathcal{A} = \prod_i \mathcal{A}_i$ |
| $\mathcal{R}$ | 奖励函数 |
| $\pi$ | 策略集合 $\{\pi_1, \ldots, \pi_N\}$ |
| $\gamma$ | 折扣因子（discount factor） |
| $\mathcal{T}$ | 状态转移函数 |

#### 2.3.2 状态空间

**智能体 $i$ 的观测**：

$$o_i = [o_i^{\text{self}}, o_i^{\text{target}}, o_i^{\text{others}}] \tag{4-14, 4-15}$$

- **自身状态** $o_i^{\text{self}}$：位置 $(x_i, y_i)$、速度 $(v_{x,i}, v_{y,i})$
- **目标状态** $o_i^{\text{target}}$：相对目标位置 $(x_{\text{goal},i} - x_i, y_{\text{goal},i} - y_i)$
- **其他智能体状态** $o_i^{\text{others}}$：其他 $N-1$ 架无人机的相对位置和速度

#### 2.3.3 动作空间

$$a_i = [v_{x,i}, v_{y,i}] \in \mathbb{R}^2 \tag{4-16}$$

二维连续速度控制（2D场景）。

#### 2.3.4 奖励函数（4项分解）

$$R_i = w_1 R_i^{\text{collision}} + w_2 R_i^{\text{goal}} + w_3 R_i^{\text{dist}} + w_4 R_i^{\text{other}} \tag{4-17 \sim 4-21}$$

| 分量 | 公式/说明 | 作用 |
|------|-----------|------|
| $R_i^{\text{collision}}$ | 碰撞惩罚，$-P_{\text{collision}}$ | 鼓励避障 |
| $R_i^{\text{goal}}$ | 到达目标奖励，$+R_{\text{goal}}$ | 鼓励到达 |
| $R_i^{\text{dist}}$ | 距离引导，$-\alpha \cdot d_i$ | 引导向目标靠近 |
| $R_i^{\text{others}}$ | 与其他智能体距离惩罚 | 维持安全间距 |

**权重设置**（$w_1 \sim w_4$ 为各项权重，需调参）。

#### 2.3.5 MADDPG算法

**Actor-Critic结构**：

- **Actor** $\pi_i(o_i; \theta_i)$：输入局部观测，输出确定性动作
- **Critic** $Q_i(o_1, \ldots, o_N, a_1, \ldots, a_N; \phi_i)$：输入全局观测和联合动作，输出Q值

**Critic更新（TD target）**：

$$y_i = r_i + \gamma Q_i'(o_1', \ldots, o_N', a_1', \ldots, a_N'; \phi_i') \tag{4-29}$$

其中 $a_j' = \pi_j'(o_j'; \theta_j')$，带 ' 的为目标网络。

**Actor策略梯度**：

$$\nabla_{\theta_i} J(\theta_i) = \mathbb{E}[\nabla_{\theta_i} \pi_i(o_i) \cdot \nabla_{a_i} Q_i(o, a)|_{a_i=\pi_i(o_i)}]$$

**软更新**（Target Network）：

$$\theta_i' \leftarrow \tau \theta_i + (1-\tau) \theta_i' \tag{soft update}$$

**分布式MADDPG改进（Algorithm 4-3）**：

1. **策略共享**：所有智能体共享同一个策略网络参数
2. **局部值函数**：每个智能体维护独立的Critic
3. **策略参数继承**：新加入的智能体继承已有策略参数

这大幅提升了可扩展性，避免 $N$ 增大时Critic输入维度爆炸。

### 2.4 ORCA避障算法及改进（第四章）

#### 2.4.1 标准ORCA

**速度障碍（Velocity Obstacle）**：

$$VO_{i|j} = \{v_i | \exists t > 0: tv_i \in D(p_j - p_i, 2r)\} \tag{4-38}$$

即智能体 $i$ 的所有会导致与 $j$ 在未来某时刻碰撞的速度集合。

**ORCA核心思想**：双方各承担一半避让责任：

$$\text{ORCA}_{i|j} = v_i \in \{v | (v - v_i^{\text{opt}}) \cdot n_{ij} \geq 0\} \tag{4-41 \sim 4-46}$$

其中 $v_i^{\text{opt}}$ 为最优速度，$n_{ij}$ 为避障法向量。

**增量线性规划求解（Algorithm 4-4）**：
```
For each neighbor j:
    Compute ORCA half-plane constraint
Add constraint to LP incrementally
Solve LP for new velocity v_i*
```

#### 2.4.2 改进1：加速度约束预处理

**问题**：标准ORCA假设速度可瞬时切换，实际无人机受加速度限制。

**加速度约束**：

$$\|v_i^{t+1} - v_i^t\| \leq a_{\max} \cdot \Delta t \tag{4-52, 4-53}$$

**改进方法（Algorithm 4-5）**：
- 在ORCA求解前，先对速度可行域施加加速度约束
- 将速度限制为以当前速度为中心、半径 $a_{\max} \Delta t$ 的球内
- 再在受限域内求解ORCA线性规划

#### 2.4.3 改进2：Connect-RRT虚拟目标点引导

**问题**：ORCA只做局部反应式避障，可能导致死锁或路径低效。

**虚拟目标点生成（Algorithm 4-6）**：

$$p_{\text{virtual}} = \text{Connect-RRT}(p_i, p_{\text{goal}}, \text{obstacles}) \tag{4-55 \sim 4-57}$$

**方法**：
- 当直接向目标移动受阻时，调用Connect-RRT快速生成一条到目标的无碰撞路径
- 取该路径上的下一个航点作为虚拟目标
- ORCA以虚拟目标为局部引导方向，绕过障碍物

**效果**：解决ORCA的局部最优问题，实现全局路径引导。

### 6.1 直接可借鉴的方法

| 本文方法 | 本项目应用 | 适配层级 |
|----------|-----------|----------|
| MAMDP建模框架 | 多机配送的MDP建模 | L4 |

| GA/PSO目标分配 | 配送订单-无人机匹配 | L4 |

| UWB定位 + ROS架构 | 真实硬件平台搭建参考 | 原型验证 |

### 6.2 本项目可改进之处

1. **动作空间扩展**：本文为2D速度控制，本项目需扩展到3D连续动作
2. **奖励函数**：可借鉴4项分解结构，增加"配送完成"和"返回基地"分量
3. **ORCA + RL混合**：ORCA做底层避障，RL做高层决策，分层设计
4. **分布式策略共享**：对多机配送场景，所有无人机共享一个策略网络是高效的

### 6.3 局限性

1. **仅二维仿真+简单室内场景**：未涉及复杂城市3D环境
2. **ORCA假设匀速段**：实际配送中频繁启停，加速度约束更关键
3. **奖励函数需调参**：4项权重需针对具体场景大量实验
4. **MADDPG训练效率低**：可考虑用MAPPO或QMIX替代
