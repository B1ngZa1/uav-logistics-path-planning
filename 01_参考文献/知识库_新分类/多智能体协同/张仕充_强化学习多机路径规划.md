## 二、摘要与核心贡献

### 摘要

本文以强化学习为基础，研究多无人机在**未知环境**中的路径规划问题。将多无人机任务场景概括为两类：**汇合任务**（多机到同一目标点集结）和**分配任务**（多机分别到不同目标点），涵盖常见的多无人机协同场景。

### 核心贡献（2项）

1. **APF-DQN模型**（汇合任务）：将人工势场法（APF）的思想融入DQN的奖励函数设计中，用势场函数生成密集奖励信号替代稀疏奖励，解决了强化学习稀疏奖励导致的收敛慢、效果差问题，并解决了APF的目标点不可达和局部最小值问题。

2. **改进SOM算法 + 动态重分配**（分配任务）：提出两阶段迭代的改进自组织映射网络（SOM）算法，消除传统SOM在无人机-目标点分配中的摇摆/不收敛现象；并利用SOM的自组织特性实现任务动态重分配（目标点增/改、无人机下线等场景）。

## 三、核心方法

### 3.1 问题建模

#### 任务类型分类

| 任务类型 | 描述 | 优化目标 |
|----------|------|----------|
| 汇合任务 | 多架无人机从不同出发点到达**同一**目标点 | 最小化总路径/总时间 |
| 分配任务 | 每架无人机分配**不同**目标点，规划到达路径 | 最小化总代价，所有目标点均被访问 |

#### 环境建模

- **空间**：3D栅格化环境，100x100x100
- **动作空间**：离散6方向（上/下/左/右/前/后），步长 $d = v_{max}$
- **观测空间**：相对坐标（无人机-目标点相对位置、无人机-障碍物相对位置），9维
- **障碍物**：障碍区、禁飞区、威胁区统一建模为障碍区
- **平台**：基于OpenAI Gym自行开发仿真环境

#### 集群架构

采用**分散式架构**：每架无人机独立进行避障和路径规划，最后在目标点汇合。好处是不依赖无人机间通信。

### 3.2 APF-DQN模型（核心创新1）

#### 人工势场法（APF）基础

APF的思想：目标点产生引力场，障碍物产生斥力场，机器人受合力运动。

**引力场函数：**

$$U^+(p) = \frac{1}{2}\xi d^2(p, p_{goal})$$

**斥力场函数：**

$$U^-(p) = \begin{cases} \frac{1}{2}\eta\left(\frac{1}{d(p,p_{obs})} - \frac{1}{d_o}\right)^2, & d(p,p_{obs}) \le d_o \\ 0, & d(p,p_{obs}) > d_o \end{cases}$$

**合力：**

$$F = F^+(p) + F^-(p) = -\nabla U^+(p) + (-\nabla U^-(p))$$

**APF的两个固有缺陷：**
- 目标点不可达：目标点周围有障碍物时，斥力>引力，机器人无法到达
- 局部最小值：合力为0时机器人停止运动

#### APF-DQN的奖励函数设计

将APF的势场思想转化为强化学习的密集奖励信号，共5类奖励分量：

| 奖励 | 公式 | 含义 |
|------|------|------|
| $r_1$ | $r_{arrived}$ | 抵达目标点奖励（正） |
| $r_2$ | $r_{target}(p_{uav}) = -\xi d(p_{uav}, p_{target})$ | 靠近目标点奖励（距离越近越大） |
| $r_3$ | $r_{obs}(p_{uav})$ | 靠近障碍物惩罚（感知范围内） |
| $r_4$ | $r_{away} = \delta(d_{last} - d_{now})$ | 远离目标点惩罚（解决APF不可达） |
| $r_5$ | $r_{collision}$ | 碰撞惩罚（负） |

**总奖励：**

$$r_{sum} = \sum_{i=1}^{5} w_i r_i$$

**关键设计思想：**
- $r_2$（靠近奖励）：借鉴APF引力，距离越近奖励越大，解决稀疏奖励问题
- $r_3$（靠近障碍惩罚）：借鉴APF斥力，在感知范围内接近障碍物时给予惩罚
- $r_4$（远离惩罚）：设计远离目标点时的负奖励，解决APF目标点不可达问题；同时由于DQN用$\epsilon$-greedy且动作空间无静止动作，解决了APF局部最小值问题

#### DQN网络参数

| 参数 | 值 |
|------|-----|
| 隐藏层个数 | 3 |
| 隐藏层神经元 | [64, 128, 64] |
| 激活函数 | ReLU |
| 学习率 | 0.0001 |
| 优化器 | Adam |
| 批大小 | 32 |
| 折扣因子 $\gamma$ | 0.99 |
| 目标网络更新间隔 | 10000步 |
| 经验缓存区大小 | 100000 |
| 动作空间大小 | 6 |

#### 多机汇合方案

采用分治思想：独立训练单机APF-DQN模型，部署到每架无人机。每架无人机仅知道自身坐标、目标点坐标和有限感知范围内的障碍物信息。优化目标为总体最短路径：

$$D_{sum} = \sum_{i=1}^{n} d_i$$

### 3.3 改进SOM算法（核心创新2）

#### 传统SOM用于任务分配

SOM（自组织映射网络）用于多无人机-多目标点的任务分配：
- **输入层**：目标点坐标 $T_i = (x_i, y_i, z_i)$（3个神经元）
- **输出层（竞争层）**：$n$个神经元，权重初始化为无人机坐标
- **获胜神经元**：与输入目标点欧氏距离最小的输出神经元
- **权重更新**：

$$W(t+1) = W(t) + \theta(t)L(t)(I(t) - W(t))$$

其中 $L(t) = L_0 e^{(-t/\lambda)}$ 为学习率，$\theta(t)$ 为邻域影响因子。

**传统SOM的问题**：当无人机数量<目标点数量时，容易出现摇摆现象——同一架无人机在多个目标点间来回摇摆，迭代结束也未访问任何目标点。

#### 两阶段改进SOM算法

**第一阶段**：使用传统SOM算法迭代$K_1$次。若在$K_1$次内收敛（所有目标点被访问），算法结束。

**第二阶段**（若第一阶段未收敛）：
1. 复用第一阶段的网络权值
2. 建立数组 $Res$ 记录目标点$i$是否已分配到无人机$j$：

$$Res_i = \begin{cases} j, & |I_i - W_j| < \sigma \\ -1, & otherwise \end{cases}$$

3. 建立字典 $uav\_target_j$ 存储无人机$j$的访问序列
4. 计算每架无人机的获胜目标点集合 $uav\_winner_j$
5. 更新权值 $W$
6. 计算自由无人机集合 $free\_uavs$ 和未访问目标点 $free\_data$
7. 以自由无人机为权重继续迭代，直至所有目标点被分配

**消除摇摆的核心思想**：当无人机A同时是B、C两个目标点的获胜神经元时，通过比较先访问路径长度来确定优先目标：

$$Target_A = \begin{cases} B, & d_{ACB} - d_{ABC} = b - c > 0 \\ C, & d_{ACB} - d_{ABC} = b - c < 0 \end{cases}$$

#### 动态重分配机制

利用SOM的自组织特性实现三种动态场景：

| 场景 | 处理方式 |
|------|----------|
| 目标点增加 | 将新目标点输入SOM，求获胜神经元，分配给最近无人机 |
| 目标点变更 | 用当前无人机坐标更新SOM权重，重新迭代分配 |
| 无人机下线 | 将下线无人机对应SOM权值置为无限大，重新迭代 |

#### 整体系统架构

```
中央控制模块 <-> SOM网络模型（任务分配）
     |
     +-> UAV1: APF-DQN（路径规划）
     +-> UAV2: APF-DQN（路径规划）
     +-> UAVn: APF-DQN（路径规划）
```

中央控制模块与无人机间建立心跳机制，心跳超时判定下线，触发动态重分配。

## 四、实验结果

### 实验1：APF-DQN vs DQN（汇合任务）

| 指标 | APF-DQN | DQN（稀疏奖励） |
|------|---------|------------------|
| 收敛回合 | ~100K | ~200K仍未完全收敛 |
| 收敛时回合长度 | ~150步 | ~4000步（200K时） |
| 奖励趋势 | 100K后稳定增长 | 增长缓慢 |

**结论**：APF-DQN的密集奖励设计显著加速收敛，规划路径更短。

### 实验2：APF-DQN vs 传统APF（汇合任务，4架无人机）

**实验设置**：4架无人机从(0,0,0)、(0,100,0)、(100,0,0)、(100,100,100)飞往(50,50,50)，随机障碍物100~500个。

**抵达率对比：**

| 障碍物数量 | APF抵达率 | APF-DQN抵达率 |
|-----------|-----------|---------------|
| 100 | 98% | 100% |
| 200 | 95% | 99% |
| 300 | 89% | 99% |
| 400 | 82% | 98% |
| 500 | 70% | 97% |

**平均步长对比（4机总步数）：**

| 障碍物数量 | APF平均步长 | APF-DQN平均步长 | 理想最佳步长 |
|-----------|------------|----------------|-------------|
| 100 | 694 | 613 | 600 |
| 200 | 692 | 616 | 600 |
| 300 | 693 | 625 | 600 |
| 400 | 720 | 631 | 600 |
| 500 | 839 | 642 | 600 |

**运行时间对比（秒/回合）：**

| 障碍物数量 | APF | APF-DQN |
|-----------|-----|---------|
| 100 | 0.39 | 0.86 |
| 500 | 1.32 | 2.91 |

**结论**：APF-DQN在抵达率和路径长度上全面优于APF，路径接近理想最优；代价是运行时间较长（神经网络推理开销）。

### 实验3：改进SOM有效性对比

**收敛率对比**（传统SOM vs 改进SOM）：

| 场景 | 传统SOM | 改进SOM |
|------|---------|---------|
| 无人机数>目标点数 (10 vs 5) | 近似 | 近似 |
| 无人机数=目标点数 (10 vs 10) | 差距增大 | 明显更好 |
| 无人机数<目标点数 (5 vs 10) | 几乎不收敛 | 完全收敛 |

**改进SOM vs 匈牙利算法**（N=M时）：样本数量小时两者路径总长度基本一致；样本增大后改进SOM稍高，但匈牙利算法不具有动态自组织特性。

### 实验4：分配任务下的路径规划

三种情况（N=M、N<M、N>M）均验证了"改进SOM分配 + APF-DQN路径规划"的完整流程在3D随机障碍物环境中的可行性。

### 实验5：动态重分配仿真

三种动态场景的仿真实验均验证了可行性：
- 目标点增加（3机3目标 -> 新增T4）
- 目标点变更（运行中途强制变更所有目标点坐标）
- 无人机下线（运行中途强制UAV1下线，剩余2机接管3个目标点）

## 六、可借鉴要点

### 6.1 奖励函数设计（直接可借鉴） ★★★★★

**APF思想融入奖励函数**是本文最有价值的贡献。将物理势场的概念转化为RL奖励信号：

- **引力奖励** $r_{target} = -\xi \cdot d(p_{uav}, p_{target})$：距离目标越近奖励越大
- **斥力惩罚** $r_{obs}$：感知范围内接近障碍物时的递增惩罚
- **远离惩罚** $r_{away} = \delta(d_{last} - d_{now})$：防止在目标点附近徘徊

**对本项目的启示**：在无人机配送的奖励函数中，可以类似地设计：
- 用到目的地的距离作为密集引导奖励（代替稀疏的"送达+100"）
- 用到障碍物/禁飞区的距离作为避障惩罚
- 用接近/远离目标的方向性奖励防止徘徊

### 6.2 SOM网络用于订单-无人机匹配 ★★★★☆

SOM的自组织特性天然适合动态订单分配：
- 输入层：订单取餐/送餐坐标
- 输出层：无人机当前位置（权重）
- 竞争获胜 = 最近无人机获得该订单
- 动态场景下可实时重分配

**局限**：SOM只考虑欧氏距离，未考虑时间窗口、无人机负载等约束。用于外卖配送时需要扩展。

### 6.3 分而治之的多机协调策略 ★★★☆☆

本文采用分散式架构，每架无人机独立规划路径，不需要通信。这种思路适合外卖配送中"各自完成各自订单"的场景，但对于需要协调的场景（如多机同时到达同一取餐点）则不足。

### 6.4 仿真环境开发参考 ★★★☆☆

基于OpenAI Gym的10模块仿真环境设计（重置、初始化、观测、动作、奖励计算等）可作为开发指南中环境接口设计的参考。

### 6.5 论文写作参考 ★★★☆☆

本文的文献综述结构（传统算法->智能优化算法->强化学习）和实验设计方法（对比基线选择、多指标评估：抵达率+步长+运行时间）可作为策划书撰写参考。
