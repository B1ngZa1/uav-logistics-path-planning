## 2. 问题与动机 / Problem & Motivation

### 2.1 研究背景

- 察打一体无人机平台战术价值日益提高，被广泛用于特种作战或局部武装冲突
- 未来空中战场态势复杂多变，对无人机态势感知与智能决策提出更高要求
- 无人机受限于平台的机动过载与速度特性，在导弹攻击场景下的生存能力面临严峻挑战

### 2.2 现有研究不足

1. **研究对象偏窄**：箔条干扰自卫防御策略研究面向的平台多为船舰，面向无人机的研究成果相对较少
2. **决策智能化程度不高**：常规方法根据质心干扰原理建立约束条件和投放参数解算，传统的箔条干扰策略智能化决策水平不高，难以适应复杂场景变化
3. **动作空间维度显著增加**：无人机可在三维空间机动，箔条弹质心运动自由度同样是三维，相比二维海面平台动作空间维度显著增加

### 2.3 研究目标

- 构建无人机箔条干扰导弹雷达导引头的自卫防御场景，将无人机建模为智能体
- 基于PPO算法设计具备数据缓存区机制的箔条干扰自卫防御决策方法
- 使无人机能够根据攻防态势信息，智能生成箔条干扰自卫防御策略

## 3. 方法与模型 / Method & Model

### 3.1 场景模型

面向自卫防御任务的无人机箔条干扰导弹雷达导引头场景，包含四个子模型：

**（1）无人机运动模型**

无人机在三维空间的位置坐标随时间变化率：

```
dX_U/dt = v_U * sin(θ_U) * cos(φ_U)
dY_U/dt = v_U * sin(θ_U) * sin(φ_U)
dZ_U/dt = v_U * cos(θ_U)
```

其中 θ_U ∈ [0, π] 为飞行俯仰角，φ_U ∈ (-π, π] 为飞行偏角。

**（2）箔条云扩散模型**

箔条云雷达反射截面积随时间变化（瑞利分布）：

```
σ_C(t) = k * (t² / T₀²) * exp(-t² / (2T₀²))
```

其中 T₀ 为箔条云持续总时长，k 为最大反射截面积。

**（3）质心模型**

导弹跟踪的目标质心位置（加权叠加）：

```
X_P = (X_U * σ_U + Σ X_{C,i} * σ_{C,i}) / (σ_U + Σ σ_{C,i})
```

（Y_P、Z_P 同理）

**（4）导弹制导与运动模型**

导弹采用纯跟踪制导律，速度方向始终指向质心：

```
θ_M = π/2 - arctan((Z_P - Z_M) / sqrt((Y_P - Y_M)² + (X_P - X_M)²))
φ_M = arctan((Y_P - Y_M) / (X_P - X_M))
```

### 3.2 DRL框架设计

**状态空间（四类信息）**：

| 类别 | 具体内容 |
|------|----------|
| 导弹信息 | 位置坐标 (X_M, Y_M, Z_M)、飞行方向 (θ_M, φ_M)、飞行速率 v_M |
| 无人机信息 | 位置坐标 (X_U, Y_U, Z_U)、机动方向 (θ_U, φ_U)、机动速率 v_U |
| 箔条信息 | 剩余箔条数量、各箔条反射截面积 σ_{C,i}、箔条位置观测矩阵 O_C |
| 相对位置信息 | 无人机与导弹之间的实时距离 |

**动作空间（7维连续动作）**：

| 动作 | 符号 | 取值范围 |
|------|------|----------|
| 飞行加速度 | a_{U,ac} | [-a_{Umax}, a_{Umax}] |
| 俯仰角速度 | a_{U,θ} | [-ω_{Umax}, ω_{Umax}] |
| 偏角速度 | a_{U,φ} | [-ω_{Umax}, ω_{Umax}] |
| 是否发射箔条 | a_{ic} | {0, 1} |
| 箔条发射俯仰角 | a_{c,θ} | [0, π] |
| 箔条发射偏角 | a_{c,φ} | (-π, π] |
| 箔条发射距离 | a_{c,d} | [0, L^C_{max}] |

网络输出7维 a_i ∈ [-1,1]，通过线性映射转换为实际动作值。两次箔条发射间隔不小于0.5s。

**奖励函数（三部分）**：

- **波束逃离奖励**：r_{escape,t} = η₁ * (2δ / θ_beam)，鼓励无人机逃离导引头波束范围
- **方向偏离奖励**：r_{dev,t} = η₂ * (δ / π)，鼓励无人机偏离导弹飞行方向
- **终局奖励**：r_end = +20（d_min > L_threat，安全）；r_end = -20（d_min ≤ L_threat，被毁）

累计奖励：r_all = Σ r_{escape,t} + Σ r_{dev,t} + r_end

### 3.3 基于PPO的决策算法（含数据缓存区机制）

**价值网络** v(s; ω)：最小化均方误差损失

```
L(ω_new) = (1/K) * Σ (v(s_k; ω_new) - R_k)²
```

**策略网络** Π(s; θ)：PPO截断损失 + 策略熵

```
L(θ_new) = -(1/K) * Σ min(A₁, A₂) - (φ/K) * Σ S(Π(s_k; θ_new))
```

其中 A₁ = γ_{k,θ_new} * A_k，A₂ = clip(γ_{k,θ_new}, 1-ε, 1+ε) * A_k。

优势函数通过GAE（广义优势估计）计算：

```
A_k = Σ (γλ)^l * δ_{k+l}
δ_k = r_k + γ * v(s_{k+1}; ω_new) - v(s_k; ω_new)
```

重要性采样权重：γ_{k,θ_new} = Π(a_k|s_k; θ_new) / Π(a_k|s_k; θ_old)

**数据缓存区机制（核心创新）**：

- 存储最近 B 个回合的交互数据（经验回放池）
- 当缓存区回合数 ≥ 训练所需最小回合数时，合并所有数据进行网络参数更新
- 缓存区超出容量时，删除最早存储的回合数据
- 既保持在线策略算法的数据新鲜度，又借鉴离线策略算法的经验数据高效利用特性

## 4. 实验与结果 / Experiments & Results

### 4.1 仿真环境设置

- 平台：Python + PyTorch，Intel Core i5-10210U CPU
- 网络结构：3层，隐藏层128神经元，ReLU激活函数
- 策略网络输出通过tanh和softplus函数处理，基于正态分布采样动作

**关键参数**：

| 参数 | 符号 | 数值 |
|------|------|------|
| 策略网络学习率 | α | 1×10⁻⁴ |
| 价值网络学习率 | β | 2×10⁻⁴ |
| 最大训练回合数 | E_max | 10⁵ |
| 截断参数 | ε | 0.2 |
| 折扣因子 | γ | 0.99 |
| GAE参数 | λ | 0.95 |
| 策略熵系数 | φ | 0.02 |
| 每回合最大步数 | T_max | 70 |
| 仿真时间步长 | ΔT | 0.1s |
| 导弹速率 | v_M | 150 m/s |
| 无人机最大速率 | v_{Umax} | 60 m/s |
| 箔条最大装填量 | N | 5 |
| 测试环境数量 | N_env | 100 |

### 4.2 实验一：不同数据缓存区容量（B=1/10/40）

| 指标 | B=1 | B=10 | B=40 |
|------|-----|------|------|
| 收敛回合数 | ~60,000 | ~10,000 | ~10,000 |
| 训练后生存率 | 较低（下限值低于B=10/40） | ~60% | ~60% |
| 训练稳定性 | 较差 | 较好 | 较好 |

**结论**：数据缓存区机制显著加速收敛，B=10和B=40效果接近，缓存区并非越大越好。

### 4.3 实验二：与DDPG算法对比

| 指标 | 本文PPO（B=10） | DDPG |
|------|-----------------|------|
| 训练效果 | 好 | 较差，明显劣于设计算法 |
| 平均累计奖励 | 更高 | 较低 |
| 生存成功率 | 更高 | 较低 |

**PPO优于DDPG的原因**：
- GAE优势估计能从偶然成功轨迹中提取更多学习信号，更好地处理稀疏奖励问题
- 策略熵机制增大了算法探索能力
- 保留在线策略特点，使用最近若干回合数据，能及时更新获取高质量训练数据

### 4.4 策略验证案例

数据缓存区容量B=10、训练5×10⁴回合后的某测试回合：
- Step 2：导弹锁定无人机，无人机决策发射箔条并机动
- Step 5：导弹跟踪目标转移到箔条云和无人机构成的质心上
- Step 8：导弹锁定箔条云，持续向箔条云飞行
- Step 12：导弹引爆（质心距离<60m），此时导弹与无人机距离为77.07m > 60m，无人机成功生还

## 5. 核心贡献与创新点 / Key Contributions

1. **场景建模**：构建了面向自卫防御任务的无人机箔条干扰导弹雷达导引头三维场景模型（无人机运动 + 箔条云扩散 + 质心模型 + 导弹制导运动）
2. **DRL框架设计**：明确了包含四类信息的状态空间、7维连续动作空间、以及由波束逃离/方向偏离/终局奖励构成的三部分奖励函数
3. **数据缓存区机制**：在PPO基础上引入数据缓存区，缓存最近B个回合交互数据并批量更新网络参数，兼顾数据新鲜度和经验利用效率，显著加速收敛
4. **GAE + 策略熵**：利用GAE缓解稀疏奖励问题，策略熵增强探索能力

### 6.2 可借鉴之处

1. **PPO + 数据缓存区机制**：本项目在L3/L4训练PPO时可借鉴该缓存区机制，在单回合经验与大批量经验回放之间取得平衡，尤其在稀疏配送奖励场景下
2. **多分量奖励函数设计思路**：波束逃离奖励（连续引导）+ 方向偏离奖励（连续引导）+ 终局奖励（稀疏）的三层结构，与本项目"过程奖励 + 配送奖励 + 终局奖励"的设计思路一致
3. **连续动作空间映射方法**：网络输出 [-1,1] 通过线性映射到实际物理范围的方法简洁有效，可直接用于本项目L3/L4的动作输出设计
4. **GAE + 策略熵**：在稀疏奖励场景下，GAE优势估计和策略熵机制对本项目同样适用

### 6.3 差异与局限

- 本文仅涉及单智能体场景，未涉及多机协同（文献[10]提及MAPPO多智能体方案但非本文重点）

- 本文场景对抗性强（导弹追击），本项目为合作性配送任务，决策逻辑差异较大
- 本文未涉及CTDE（集中式训练分布式执行）框架
