## 二、摘要与核心贡献

### 2.1 研究问题

针对多无人机自主协同避障航路规划任务中，传统多智能体强化学习(MARL)算法存在的三大不足：

1. **收敛速度慢** -- 仅依赖局部观测难以有效捕捉全局状态特征，价值估计不准确
2. **协同性不足** -- 无法区分观测变化来源（环境扰动 vs 其他智能体策略调整），受非平稳性干扰
3. **初期样本效率低** -- 频繁碰撞产生大量负面样本，延缓策略稳定收敛

### 2.2 核心方法

提出 **PGL-QMIX** (Prior-Guided-LSTM-QMIX) 算法，将QMIX值分解框架与先验知识引导、双层LSTM时序建模相结合。

### 2.3 三大贡献

1. **先验引导的时序融合价值分解算法** -- 在QMIX中引入两级时序建模（先验LSTM + 混合LSTM），融合全局引导与局部时序特征
2. **局部先验片段构造与时序融合机制** -- 离线A*生成参考路径，在线仅提取感知范围内的局部片段作为"弱先验"，保持部分可观测性同时加速收敛
3. **势函数塑形奖励设计** -- 基于目标距离与参考路径贴合度构建势函数，提供稠密信号引导

### 2.4 实验结论（概括）

在三维栅格场景(20^3, 30^3, 40^3)中，4架无人机，相较于次优结果：
- 收敛步数分别减少 **3.0%, 7.2%, 7.4%**
- 稳态成功率分别提升 **1.26, 4.41, 8.12** 个百分点
- 平均路径长度分别缩短 **6.2%, 8.5%, 10.0%**

## 三、核心方法详解

### 3.1 问题建模

**数学描述：**

- 无人机集合 $U = \{U_1, U_2, ..., U_N\}$，障碍物集合 $O = \{o_1, o_2, ..., o_M\}$
- 无人机 $U_i$ 从起点 $ST_i$ 出发，到达目标点 $TA_i$，轨迹 $L_i$，长度 $d_{L_i}$

**目标函数：**

$$\min \sum_{i=1}^{N} d_{L_i}$$

约束条件：
- 路径长度约束：$0 \leq d_{L_i} \leq d_{L_{\max}}$
- 机间安全约束：$\|p_i(t) - p_j(t)\| \geq d_{\min}, \forall i \neq j$
- 障碍安全约束：$\|p_i(t) - o_k\| \geq d_{\min}, \forall o_k \in O$
- 初末位置约束：$p_i(0) = ST_i, p_i(T_i) = TA_i$

**POMDP建模：** $G = \langle S, A, P, R, O, \Omega, \gamma \rangle$

### 3.2 观测空间

局部观测定义：

$$o_i = \{p_i^t, p_i^{\text{goal}}, d_{u}^{ij}(t), d_g^i(t), d_o^i(t)\}$$

| 符号 | 含义 |
|---|---|
| $p_i^t$ | t时刻当前位置 |
| $p_i^{\text{goal}}$ | 目标位置 |
| $d_u^{ij}(t)$ | 与其他无人机的欧氏距离 |
| $d_g^i(t)$ | 到目标点的欧氏距离 |
| $d_o^i(t)$ | 与最近障碍物的距离 |

- 传感器为球形感知模型，感知半径 $r_o = 3$（体素单元）
- 训练阶段可访问全局状态；执行阶段仅局部观测

### 3.3 动作空间

离散动作空间，六连通 + 停留：

$$A_i = \{+x, -x, +y, -y, +z, -z, \text{stay}\}$$

优势：
1. 与三维栅格及A*参考路径连通方式一致，避免先验路径与执行不一致
2. 降低策略网络输出维度和联合动作空间复杂度

后处理：3次B-spline平滑（仅用于轨迹展示，不参与训练）

$$c(t) = \sum_{j=0}^{m} P_j B_{j,3}(t), \quad t \in [0, 1]$$

### 3.4 奖励函数设计（势函数塑形）

**团队平均到目标距离：**

$$d_g(t) = \frac{1}{N} \sum_{i=1}^{N} d_g^i(t)$$

**安全约束软化：**

$$\rho_o(t) = \frac{[d_{\min} - d_o^{\min}(t)]_+}{d_{\min}}, \quad \rho_u(t) = \frac{[d_{\min} - d_u^{\min}(t)]_+}{d_{\min}}$$

**参考路径偏差：**

$$d_{\text{ref}}^i(t) = \min_{P_j^i \in P_{\text{ref}}^i} \|P_j^i - p_i(t)\|$$

**势函数：**

$$\Phi(s_t) = \kappa_g \bar{d}_g(t) + \kappa_r \bar{d}_{\text{ref}}(t)$$

**即时奖励：**

$$r_t = -\mu - \rho_o(t) - \rho_u(t) + (\gamma \Phi(s_{t+1}) - \Phi(s_t)) + r_{\text{goal}} I_{\text{goal}} - r_{\text{coll}} I_{\text{coll}}$$

| 分量 | 含义 |
|---|---|
| $-\mu$ | 每步微惩罚，抑制冗余动作 |
| $\rho_o(t), \rho_u(t)$ | 障碍物/机间安全软约束惩罚 |
| $\gamma \Phi(s_{t+1}) - \Phi(s_t)$ | 势函数塑形项（稠密引导信号） |
| $r_{\text{goal}} I_{\text{goal}}$ | 到达目标奖励 |
| $r_{\text{coll}} I_{\text{coll}}$ | 碰撞惩罚 |

**★ 势函数塑形的设计亮点：** 偏离全局路径时给予小幅惩罚，贴合参考轨迹时一次性获得累计正向奖励，既保持探索多样性又维持长期引导趋势。

### 3.5 算法架构：PGL-QMIX

#### 3.5.1 离线阶段：A*参考路径生成

- 对每架无人机在静态栅格地图上运行A*算法生成参考路径 $P_{\text{ref}}^i$
- 时间复杂度：$O(N \cdot V \log_2 V)$，离线完成不影响在线实时性

#### 3.5.2 局部先验片段提取与评分

在线执行时，根据当前位置 $p_i(t)$ 与感知半径 $r_o$ 提取局部可见片段：

$$\Omega_t^{(i)} = \{P_j^i \in P_{\text{ref}}^i \mid \|P_j^i - p_i(t)\| \leq r_o\}$$

**综合评分函数（★关键创新）：**

$$\omega_j^{(i)}(t) = \frac{d_o(P_j^i) + \min_k d_u^k(P_j^i)}{d_{\text{ref}}(P_j^i) + d_g(P_j^i) + 1}$$

- 分子：障碍距离 + 机间安全距离（越大越安全）
- 分母：到当前位置距离 + 到目标距离（越小越接近目标）
- 数值越大代表节点参考价值越高

#### 3.5.3 个体层：先验LSTM时序编码

将局部观测 $o_i(t)$ 与参考评分 $\omega_j^{(i)}(t)$ 拼接后输入LSTM：

$$x_i^t = [o_i(t); \omega_j^{(i)}(t)]$$

LSTM标准门控机制：

$$f_t^i = \sigma(W_f [h_{t-1}^i, x_t^i] + b_f) \quad \text{(遗忘门)}$$

$$i_t^i = \sigma(W_i [h_{t-1}^i, x_t^i] + b_i) \quad \text{(输入门)}$$

$$C_t^i = f_t^i \cdot C_{t-1}^i + i_t^i \cdot \tilde{C}_t^i \quad \text{(单元状态更新)}$$

$$o_t^i = \sigma(W_o [h_{t-1}^i, x_t^i] + b_o) \quad \text{(输出门)}$$

$$h_t^i = o_t^i \cdot \tanh(C_t^i) \quad \text{(隐藏状态)}$$

**作用：** 动态整合局部观测与参考趋势的时序信息，提取个体时序特征 $h_t^i$

#### 3.5.4 系统层：LSTM混合网络

**个体Q值函数：**

$$Q_i(h_t^i, a_t^i; \theta_i) = \mathbb{E}[r_t + \gamma \max_{a'} Q_i(h_{t+1}^i, a'; \theta_i^-)]$$

**系统层LSTM融合所有智能体时序特征：**

$$m_t = \text{Concat}(h_t^1, h_t^2, ..., h_t^N)$$

$$[z_t, C_t] = \text{LSTM}_{\text{mix}}(m_t, [z_{t-1}, C_{t-1}]; \theta_m)$$

**动态生成混合权重与偏置（★关键创新）：**

$$W_i(t) = \text{SoftPlus}(W_i^{(L)} z_t + b_i^{(L)}) \quad \text{（保证} W_i(t) \geq 0 \text{，满足单调性）}$$

$$b(t) = W_b^{(L)} z_t + b_b^{(L)}$$

**联合Q值函数（单调性分解）：**

$$Q_{\text{tot}}(h_t, a_t; \Theta) = \sum_{i=1}^{N} W_i(t) Q_i(h_t^i, a_t^i; \theta_i) + b(t)$$

**优势：** SoftPlus保证权重非负，满足QMIX单调性约束 $Q_{\text{tot}} = f(Q_1, ..., Q_N)$，$\partial Q_{\text{tot}} / \partial Q_i \geq 0$，实现集中训练分散执行。

#### 3.5.5 训练损失函数

$$\mathcal{L}_\theta = \sum_{t=0}^{T} [Y_t - Q_{\text{tot},t}(h_t, a_t; \Theta)]^2$$

TD目标：

$$Y_t = R(t) + \gamma Q_{\text{tot},t+1}(h_{t+1}, a_{t+1}^*; \theta^-)$$

目标网络软更新：$\theta^- \leftarrow \tau \theta + (1-\tau)\theta^-$

### 3.6 复杂度分析

| 阶段 | 时间复杂度 | 说明 |
|---|---|---|
| 离线预处理 | $O(N \cdot V \log_2 V)$ | A*路径生成，任务前完成 |
| 在线执行/每步 | $O(N \cdot (H_{\text{ind}}^2 + D_{\text{in}} H_{\text{ind}} + \|A\| + K))$ | 关于N线性增长 |
| 空间 | $O(N \cdot H_{\text{ind}})$ 运行时 + $O(N \cdot L_{\text{path}})$ 参考路径 | 参数共享，常数级网络参数 |

**★关键优势：** 在线执行复杂度 $O(N)$，避免了联合动作空间的指数级开销 $O(A^N)$，适合大规模集群。

4. **双层LSTM时序建模** -- 个体层捕获局部动态，系统层协调群体行为，对本项目的L4多机CTDE架构有参考意义
5. **消融实验设计** -- 三组消融变体(No-Prior, No-iLSTM, No-sLSTM)的实验范式值得借鉴

## 六、可借鉴要点总结

### 6.1 算法设计层面

1. **★ 先验引导范式** -- A*离线路径作为"弱先验"而非硬约束，仅在感知范围内提取局部片段。这一设计平衡了全局引导与自主探索，避免对静态先验过度依赖。**建议：** 本项目可在L3层级引入类似机制，离线用Dijkstra/A*在简化地图上生成参考轨迹，在线RL中作为辅助输入特征。

2. **★ 势函数塑形奖励** -- 势函数 $\Phi(s_t) = \kappa_g \bar{d}_g(t) + \kappa_r \bar{d}_{\text{ref}}(t)$ 将目标距离与参考贴合统一为稠密信号。**建议：** 本项目reward_function_design.md中可增加"参考轨迹贴合度"分量，在早期训练中提供更稳定的梯度信号。

3. **★ 系统层LSTM混合网络** -- 用时变权重 $W_i(t)$ 替代QMIX的静态混合网络，自适应调节各智能体对联合Q值的贡献。**建议：** 本项目CTDE框架中的critic网络可考虑类似机制，用时变权重融合各agent的value估计。

4. **局部先验评分函数** -- $\omega_j^{(i)}(t) = \frac{d_o + \min_k d_u^k}{d_{\text{ref}} + d_g + 1}$ 综合安全性与方向性。**建议：** 可改造为外卖配送中的"订单紧急度评分"，分子增加时间窗口约束，分母增加取餐/送达距离。

### 6.2 工程实现层面

5. **参数共享策略** -- 个体网络参数完全共享，仅系统层LSTM独立，大幅降低参数量。本项目的多agent PPO可借鉴此设计。

6. **学习率线性衰减** -- $\alpha_t = \alpha_0(1 - t/M)$，简单有效。本项目PPO训练可参考。

7. **评估指标体系** -- AUC + 稳态奖励 + 收敛步数 + 成功率 + 路径长度 + 安全距离，多维度全面评估。本项目实验评估可采纳类似指标体系。

8. **B-spline后处理** -- 离散路径到连续轨迹的B-spline平滑，仅用于展示不改变训练。本项目3D可视化可借鉴。
