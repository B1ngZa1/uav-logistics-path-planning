## 二、核心问题与动机

### 2.1 研究背景

多无人机集群协同路径规划是高维、非线性的序贯决策问题。传统方法（RRT采样法、GA启发式搜索）在静态场景下表现良好，但在高动态强对抗环境下计算复杂度过高或适应性不足。

### 2.2 现有方法的两大挑战

| 挑战 | 具体问题 | 本文解决思路 |
|------|----------|--------------|
| **感知信息扁平化** | 现有注意力机制将障碍物威胁与队友协同信息置于同一优先级进行无差别计算，避险信息易被淹没 | HCA分层交叉注意力：按"意图-威胁-协同"优先级序贯处理 |
| **稀疏奖励下探索低效** | RND等好奇心机制盲目追求新奇性，诱导个体脱离编队，破坏集群协同 | 协同一致性门控：将个体探索激励与集群目标动态耦合 |

## 三、方法体系

### 3.1 问题建模

**Dec-POMDP建模**：多无人机协同路径规划被形式化为去中心化部分可观马尔可夫决策过程。

$$\langle S, \{A_i\}_{i=1}^{N}, P, \{R_i\}_{i=1}^{N}, \{O_i\}_{i=1}^{N}, \gamma \rangle$$

- $S$：全局状态空间
- $A_i$：智能体 $i$ 的动作空间（控制指令：速度 $v_{cmd}$、爬升角 $\gamma_{cmd}$、航向角 $\psi_{cmd}$）
- $O_i$：局部观测空间，结构化为四部分：自身状态 $s_{self}$、领导者实体 $E_{lead}$、障碍物实体 $E_{obs}$、跟随者实体 $E_{fol}$
- $\gamma$：折扣因子

### 3.2 无人机运动学模型（3-DOF）

一阶惯性系统平滑更新：

$$v(t+\Delta t) = v(t) + (v_{cmd} - v(t))(1 - e^{-\Delta t / \tau_v})$$

$$\gamma(t+\Delta t) = \gamma(t) + (\gamma_{cmd} - \gamma(t))(1 - e^{-\Delta t / \tau_\gamma})$$

$$\psi(t+\Delta t) = \psi(t) + \psi_{norm}(1 - e^{-\Delta t / \tau_\psi})$$

其中 $\tau_v, \tau_\gamma, \tau_\psi$ 分别是速度、爬升角和航向角响应的时间常数。$\psi_{norm}$ 是将指令值与当前值的原始差值映射到 $[-\pi, \pi]$ 区间内的标准化角度差。

三维速度矢量分解：

$$v_x(t+\Delta t) = v(t+\Delta t)\cos(\gamma(t+\Delta t))\sin(\psi(t+\Delta t))$$

$$v_y(t+\Delta t) = v(t+\Delta t)\cos(\gamma(t+\Delta t))\cos(\psi(t+\Delta t))$$

$$v_z(t+\Delta t) = v(t+\Delta t)\sin(\gamma(t+\Delta t))$$

欧拉前向积分更新位置：

$$P(t+\Delta t) = P(t) + \vec{V}_{vec}(t+\Delta t) \cdot \Delta t$$

### 3.3 协同约束条件

**(1) 空间位置约束（不等式组）：**

$$\|p_i(t) - p_j(t)\| \geq d_{safe}, \quad \forall i \neq j \quad \text{（机间避撞）}$$

$$\min_{p_{obs} \in O_k} \|p_i(t) - p_{obs}\| \geq d_{obs}, \quad \forall i, k \quad \text{（障碍物避障）}$$

$$\|p_i(t) - p_i^{target}(t)\| \leq R_{follow}, \quad \forall i \in N_{fol} \quad \text{（集群保持）}$$

**(2) 时间协同约束：**

$$T_{last} - T_{first} \leq \delta, \quad \text{其中 } T_i = \min\{t \mid \|p_i(t) - R_{goal}\| \leq \epsilon\}$$

### 3.4 创新点一：分层交叉注意力（HCA）执行者网络

**核心思想**：不将所有观测信息扁平化输入网络，而是按信息源类型和决策逻辑优先级进行有序的注意力计算。

#### 网络输入嵌入

$$Q_1 = \max(0, W_{self}s_{self} + b_{self})$$

$$K_1, V_1 = \max(0, E_{lead}W_{lead}^T + b_{lead})$$

$$K_2, V_2 = \max(0, E_{obs}W_{obs}^T + b_{obs})$$

$$K_3, V_3 = \max(0, E_{fol}W_{fol}^T + b_{fol})$$

#### 三层序贯注意力计算

| 层级 | 名称 | 功能 | Query来源 | Key/Value来源 |
|------|------|------|-----------|---------------|
| 第一层 | **意图感知层** | 关注领导者状态，明确任务意图 | $Q_1$（自身状态） | $K_1, V_1$（领导者实体） |
| 第二层 | **威胁感知层** | 关注环境威胁 | $Q_2 = \max(0, W_{u2}[Q_1^T, C_{lead}^T] + b_{u2})$ | $K_2, V_2$（障碍物实体） |
| 第三层 | **协同感知层** | 关注集群协同需求 | $Q_3 = \max(0, W_{u3}[Q_2^T, C_{obs}^T] + b_{u3})$ | $K_3, V_3$（跟随者实体） |

每层的多头交叉注意力计算（以第 $j$ 个头为例）：

$$e_{jk} = \frac{(Q W_j^Q)(K[k] W_j^K)^T}{\sqrt{d_k}}$$

$$\alpha_{jk} = \frac{\exp(e_{jk})}{\sum_{l=1}^{N} \exp(e_{jl})}$$

$$\text{head}_j = \sum_{k=1}^{N} \alpha_{jk}(V_1[k] W_j^V)$$

$$C_{lead} = [\text{head}_1, \dots, \text{head}_h] W^O$$

#### 最终输出

特征融合后输入策略网络：

$$\vec{F}_{final} = [Q_1^T, C_{lead}^T, C_{obs}^T, C_{fol}^T]$$

$$a_i = \pi_i(\vec{F}_{final})$$

**与本项目的关联**：该HCA架构可直接用于L4层级中无人机对建筑物/禁飞区（$E_{obs}$）、队友（$E_{fol}$）、基地/目标（$E_{lead}$）的优先级感知。

---

### 3.5 基于加权一致性算法的协同目标生成

为每个跟随者实时计算"一致性移动目标点"，分两步：

**第一步：构建归一化权重矩阵 $W$**

根据集群拓扑图 $G$ 构建邻接矩阵 $S$（$S_{ij}=1$ 表示无人机 $i$ 可感知 $j$ 的状态），计算图距离 $d_{ij}$，结合信息传递因子 $\eta \in (0,1)$：

$$W_{ij} = S_{ij} \cdot \eta^{d_{ij}}$$

归一化：$\bar{W}_{ij} = W_{ij} / \sum_k W_{ik}$

**第二步：一致性目标状态迭代**

$$P_i(k+1) = \sum_{j=1}^{N} \bar{W}_{ij} P_j(k)$$

$$V_i(k+1) = \sum_{j=1}^{N} \bar{W}_{ij} V_j(k)$$

该动态目标状态 $(P^*, V^*)$ 同时用于：HCA执行者网络的态势感知输入、协同门控模块的计算基准、奖励函数的编队保持引导。

---

### 3.6 创新点二：协同一致性门控的内在好奇心模块

**动机**：RND式好奇心在协同任务中盲目追求新奇性，诱导偏离编队的无效探索。

#### 原始新奇性信号（基于RND）

$$r_{novelty}(o_{i,t+1}) = \|f_{predictor}(o_{i,t+1}; \theta_p) - f_{target}(o_{i,t+1})\|_2^2$$

- $f_{target}$：固定的随机目标网络
- $f_{predictor}$：可学习的预测网络

#### 协同门控函数

$$G_i(t) = \exp\left(-\gamma \frac{d_i^2(t)}{R_{follow}^2}\right)$$

其中 $d_i(t) = \|p_i(t) - p_i^{target}(t)\|_2$，$\gamma$ 为正的超参数。

- $d_i(t) \to 0$（紧密跟随）：$G_i(t) \to 1$，允许完整新奇性奖励
- $d_i(t) \gg 0$（严重偏离）：$G_i(t) \to 0$，抑制无效新奇性奖励

#### 门控有效内在奖励

$$r_{int}(o_{i,t+1}) = G_i(t) \cdot r_{novelty}(o_{i,t+1})$$

通过运行时统计归一化后，与外在奖励加权组合用于策略更新。

**与本项目的关联**：该门控机制可改造用于本项目L4层级中，将无人机好奇心探索与配送任务目标（而非编队目标）耦合。

---

### 3.7 奖励函数设计

采用线性加权复合奖励：$R_{leader} = \sum_{k \in K_L} w_k R_k$，$R_{follower} = \sum_{k \in K_F} w_k R_k$

| 类别 | 项 | 公式/描述 | 适用对象 |
|------|------|-----------|----------|
| **任务完成** | $R_1$ 到达奖励 | $R_1 = \sum_j r_j \cdot I(\|P_i(t) - P_{goal}\| < d_j) + k_{task} \cdot I(\text{arrived})$，阶段性+终点奖励 | 全部 |
| | $R_2$ 距离逼近 | $R_2 = k_2(d_{t-1} - d_t)$，每步距离缩减的密集奖励 | 全部 |
| **安全引导** | $R_3$ 避撞/避障惩罚 | $R_3 = k_3\left(\frac{d_{safe}}{d} - 1\right)$，$d < d_{safe}$ 时指数增长 | 全部 |
| | $R_4$ 碰撞截断 | $R_4 = k_4$，发生碰撞时的截断惩罚 | 全部 |
| | $R_5$ 冲突感知引导 | $R_5 = k_5 \frac{\vec{v}_{uav} \cdot \vec{v}_{guide}}{\|\vec{v}_{uav}\| \|\vec{v}_{guide}\| + \epsilon}$，吸引力/排斥力夹角超阈值时切换为切线方向 | 全部 |
| **编队协同** | $R_6$ 动作平滑 | $R_6 = k_6 \left\| a_i(t) - \frac{1}{W}\sum_{j=0}^{W-1} a_i(t-j) \right\|^2$ | 全部 |
| | $R_7$ 时间同步 | $R_7 = k_7 \|\|P_{L0}(t) - P_{goal}\| - \|P_{L1}(t) - P_{goal}\|\|$ | 领导者 |
| | $R_8$ 领导者安全间距 | $R_8 = k_8\left(\frac{d_{safe,L}}{\|P_{L0}(t) - P_{L1}(t)\|} - 1\right)$，若间距$< d_{safe,L}$ | 领导者 |
| | $R_9$ 跟随者掉队惩罚 | $R_9 = k_9 \|P_i(t) - P_i^{target}(t)\|$，若 $d > R_{follow}$ | 跟随者 |

奖励项集合：$K_L = \{1,2,3,4,5,6,7,8\}$（领导者），$K_F = \{1,2,3,4,5,6,9\}$（跟随者）

**与本项目的关联**：$R_1$（阶段性到达奖励）和$R_2$（距离逼近密集奖励）的设计可直接借鉴到本项目的配送奖励函数中；$R_5$（冲突感知引导）可改造用于建筑/禁飞区避障引导。

### 3.8 算法训练流程（Algorithm 1 概要）

```
初始化 HCA 执行者网络 π_i 和共享评论家网络 V_θ
for episode = 1 to max_episode:
    并行重置 M 个环境，获取初始观测
    for t = 1 to max_t:
        for 每个智能体 i:
            从策略 π_i(a_t | o_t) 采样动作 a_t
        在所有并行环境执行联合动作
        获取新观测、奖励、完成标志
        存入轨迹存储器 D
    使用 D 计算优势函数估计 Â_i^t
    for epoch = 1 to max_epoch:
        随机抽取小批量数据
        最小化 L(θ) 更新评论家网络
        最大化 L_CLIP(θ_i) 更新执行者网络
```

| 本文 | 本项目 | 改造要点 |
