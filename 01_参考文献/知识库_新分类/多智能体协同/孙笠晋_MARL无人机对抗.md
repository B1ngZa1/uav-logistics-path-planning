## 一、研究动机与问题定义 / Motivation & Problem Definition

### 1.1 核心问题

多无人机对抗（Multi-UAV Combat）是无人机集群技术的延伸，面临以下挑战：

- **高维状态空间**导致训练不稳定、收敛速度慢
- 每架无人机仅能感知**局部环境**，难以获得全局视野
- 传统规则驱动方法（Rule-driven）在复杂动态环境中适应性差
- 现有多智能体算法在强对抗场景下**协作效率**与**学习稳定性**不足

### 1.2 研究目标

提出基于注意力机制的改进型 MADDPG 算法（ATT-MADDPG），通过点对点信息交换增强每架无人机的**全局态势感知能力**，在多无人机红蓝对抗场景中提升红方胜率。

**★ 研究动机评级：★★★☆☆（3/5）**
> 问题背景清晰，但挑战描述较为泛化，未深入分析现有CTDE方法的具体缺陷。研究目标指向明确，但创新性边界不够突出。

## 二、核心方法 / Core Methodology

### 2.1 MADDPG 基础框架（Baseline）

基于 Lowe 等人（2017）的 MADDPG 算法，采用**集中训练、分布执行（CTDE）**范式：

**确定性策略（执行阶段）**：

$$a_i = \mu_{\theta_i}(o_i) \tag{1}$$

其中 $\theta_i$ 为策略参数，$o_i$ 为局部观测，执行时仅依赖自身观测输出动作。

**目标函数（训练阶段）**：

$$J(\theta_i) = \mathbb{E}_{x, a_i \sim D}[Q_i(x, a_1, a_2, \ldots, a_N)] \tag{2}$$

其中 $Q_i$ 为集中式 Critic 近似的动作价值函数，$D$ 为经验回放池。

**确定性策略梯度**：

$$\nabla_{\theta_i} J(\theta_i) = \mathbb{E}_{x \sim D}[\nabla_{\theta_i} \mu_{\theta_i}(o_i) \cdot \nabla_{a_i} Q_i(x, a_1, \ldots, a_N) | a_i = \mu_{\theta_i}(o_i)] \tag{3}$$

### 2.2 集中式 Critic 训练

**损失函数（Bellman残差）**：

$$L_i = \mathbb{E}[(Q_i(x, a_1, \ldots, a_N) - y_i)^2] \tag{4}$$

**目标值定义**：

$$y_i = r_i + \gamma Q_i'(x', a_1', a_2', \ldots, a_N') \tag{5}$$

$$a_j' = \mu_{\theta_j'}(o_j'), \quad j = 1, 2, \ldots, N \tag{6}$$

其中 $\gamma$ 为折扣因子，$Q_i'$ 和 $\mu_{\theta_j'}$ 分别为目标 Critic 网络与目标策略网络。

### 2.3 注意力机制融合（本文核心改进）

**注意力权重计算**：

$$\alpha_{ij} = \frac{\exp(\text{score}(o_i, o_j))}{\sum_{k \neq i} \exp(\text{score}(o_i, o_k))} \tag{7}$$

其中 $\text{score}(o_i, o_j)$ 为智能体 $i$ 与 $j$ 之间的相关性得分（内积或距离度量）。

**加权观测向量聚合**：

$$\tilde{o}_i = \sum_{j \neq i} \alpha_{ij} \cdot o_j \tag{8}$$

$\tilde{o}_i$ 作为智能体输入，替代原始局部观测用于策略决策。

**距离加权注意力（伪代码中的简化实现）**：

$$s_i^t \leftarrow s_i^t \oplus \left(s_i^t \times \frac{d_{ij}}{\sum_{j=1, j \neq i}^{N} d_{ij}}\right)$$

即根据距离权重将其他智能体的状态与当前智能体状态进行合并。

### 2.4 无人机运动模型

运动方程（2D平面）：

$$v_{t+1} = v_t + a_t \cdot t \tag{9}$$

$$\alpha_{t+1} = \alpha_t + \lambda_t \tag{10}$$

$$x_{t+1} = x_t + v_t \cos(\alpha_t) \cdot t \tag{11}$$

$$y_{t+1} = y_t + v_t \sin(\alpha_t) \cdot t \tag{12}$$

其中 $v_t$ 为速度，$a_t$ 为加速度，$\alpha_t$ 为航向，$\lambda_t$ 为转向角，$(x_t, y_t)$ 为坐标。

**★ 方法评级：★★★☆☆（3/5）**
> MADDPG+注意力机制的组合思路合理，但注意力实现较为简单（距离加权），未采用标准的Query-Key-Value点积注意力。CTDE范式是成熟框架，本文改进幅度有限。

## 四、关键实验结果 / Key Results

### 4.1 核心对比结果

| 指标 | MADDPG（Baseline） | ATT-MADDPG（本文） |
|---|---:|---:|
| 收敛胜率 | **~60%** | **~72%** |
| 收敛轮次 | ~3,000 轮 | ~2,000 轮 |
| 胜率提升 | — | **+12 个百分点** |
| 训练总轮次 | 10,000 | 10,000 |

### 4.2 关键发现

1. **胜率提升显著**：ATT-MADDPG 相比标准 MADDPG，红方胜率从 60% 提升至 72%，绝对提升 12 个百分点。
2. **收敛加速**：ATT-MADDPG 在约 2,000 轮即收敛，比 MADDPG 的 3,000 轮提前约 1,000 轮（~33% 加速）。
3. **注意力机制作用**：动态选择其他无人机的关键信息，减少信息处理负担，提升全局协作能力。

**★ 结果评级：★★★☆☆（3/5）**
> 12% 胜率提升数值明确，但缺乏置信区间/方差统计、缺乏统计显著性检验。仅报告胜率单一指标，缺少平均回合奖励、存活率、击毁数等多维评估。

## 五、理论贡献与局限性 / Contributions & Limitations

### 5.1 理论贡献

1. **ATT-MADDPG 算法**：将注意力机制融入 MADDPG，通过距离加权实现多无人机间的选择性信息聚合
2. **CTDE 范式在对抗场景的验证**：在 8v8 红蓝对抗中验证了集中训练+分布执行的有效性
3. **多无人机对抗仿真平台**：基于 MPE 搭建了可复现的对抗环境

### 5.2 局限性（本文自述+批判分析）

| 局限性 | 说明 |
|---|---|
| 鲁棒性待提升 | 未在更复杂动态环境中验证 |
| 规模扩展性 | 未验证大规模集群（>16架）的可扩展性 |
| 蓝方策略单一 | 蓝方为规则基线，未与学习型对手对比 |
| 注意力实现简单 | 使用距离加权而非标准多头注意力 |
| 环境简化 | 2D平面、无风扰/禁飞区/通信约束 |
| 缺乏消融实验 | 未分离注意力机制各组件的独立贡献 |
| 无统计检验 | 胜率结果缺乏方差和显著性分析 |
| 场景单一 | 仅8v8对称对抗，非对称/异构场景未涉及 |

**★ 贡献评级：★★☆☆☆（2/5）**
> 改进幅度有限（注意力机制融入MADDPG已有先例，如刘峰等2021年Att-MADDPG），理论深度不足，缺乏严格的消融和统计分析。

### 6.2 可借鉴的具体技术

1. **CTDE 范式**：MADDPG 的集中训练+分布执行模式可直接用于本项目L4多机协同层

3. **训练流程**：伪代码中的经验回放+目标网络+梯度更新流程可作为多Agent训练的骨架
4. **状态编码思路**：将"与其他无人机的距离/方位角/存活情况"编码为状态向量的思路可迁移至配送场景中的"与其他无人机/订单/建筑的距离"
