## 二、摘要与核心贡献

### 摘要

本文研究基于强化学习的无人机无人战斗机（UCAV）空中格斗决策算法。针对传统强化学习不能有效利用先验知识的问题，提出在标准Q学习的"状态-动作"二层映射中插入"动机层"，形成"状态-动机-动作"三层映射，并结合模拟退火算法优化探索策略。最终将改进算法与RBF神经网络结合，应用于UCAV三维空中格斗轨迹生成。

### 核心贡献（3项）

1. **动机引导Q学习（Motivation-Guided Q-Learning）**：在MDP中引入动机空间M，将七元组 ⟨S, M, A, P, R, γ, V⟩ 替代标准六元组，通过IF-THEN规则将先验知识注入动机到动作的映射，加速收敛。

2. **基于模拟退火的动机引导Q学习（M-SA-Q）**：将Metropolis准则融入动机选择过程，用等比降温策略 t_{k+1} = λ·t_k（λ∈(0.5,1)）平衡探索与利用，防止陷入局部最优。

3. **RBF-M-SA-Q空中格斗算法**：用RBF神经网络拟合Q值函数，解决连续高维状态空间下的维数灾难；定义了8维态势向量、7个基本机动动作、9个动机，以及基于威胁指数的奖励函数，实现了不同作战意图下的UCAV格斗轨迹生成。

## 三、核心方法详解

### 3.1 动机引导强化学习结构

将标准MDP六元组 ⟨S; A; P; R; γ; V⟩ 扩展为七元组：

$$\langle S; M; A; P; R; \gamma; V \rangle$$

其中 $M$ 为动机空间。映射关系从"状态→动作"变为：

$$S \xrightarrow{\pi_1} M \xrightarrow{\pi_2} A$$

**动机到动作映射**采用IF-THEN规则（手动设计先验知识）。例如：动机"主动进攻"→ 动作"机头转向敌机"。

### 3.2 动机引导Q学习的值函数更新

Q值函数针对状态-动机对学习：

$$Q(s, m) = r(s, \pi_2(m)) + \gamma V^*(\delta(s, \pi_2(m)))$$

更新公式：

$$Q(s, m) \leftarrow Q(s, m) + \alpha [r + \gamma \max_{a \in A} Q(s', m') - Q(s, m)]$$

### 3.3 模拟退火策略（Metropolis准则）

在动机选择中引入模拟退火，先根据贪心策略选动机 m_1，再随机选动机 m_2，产生随机数 δ ∈ (0,1)，若：

$$\delta < \exp\left[\frac{Q(s, m_2) - Q(s, m_1)}{T}\right]$$

则选择随机动机 m_2，否则仍选 m_1。降温策略为等比降温 t_{k+1} = λ · t_k，λ ∈ (0.5, 1)。

### 3.4 UCAV状态空间（8维态势向量）

$$s = [q_r, q_b, d, \beta, \Delta h, \Delta V^2, V^2, h]$$

| 变量 | 含义 |
|---|---|
| q_r | 偏离角（红方速度矢量与红蓝质心方向夹角） |
| q_b | 脱离角（蓝方速度矢量与蓝红质心方向夹角） |
| d | 红蓝UCAV质心距离 |
| β | 红蓝速度矢量夹角 |
| Δh | 高度差 h_r - h_b |
| ΔV² | 速度平方差 V_r² - V_b² |
| V² | 红方速度平方 |
| h | 红方飞行高度 |

### 3.5 UCAV动力学方程（三自由度质点模型）

$$\frac{dv}{dt} = g(n_x - \sin\tau)$$

$$\frac{d\tau}{dt} = \frac{g}{v}(n_f \cos\gamma_x - \cos\tau)$$

$$\frac{d\chi}{dt} = \frac{g}{v\cos\tau} n_f \sin\gamma_x$$

其中 n_x 为切向过载，n_f 为法向过载，γ_x 为速度滚转角。

### 3.6 奖励函数设计

**基础奖励** R(s)：

- +10：d < 10km, q_r < 30°, q_b > 30°, β < 40°（获得攻击机会）
- -10：d < 10km, q_b < 30°（被攻击位置）
- -10：V_r < 80m/s 或 V_r > 700m/s（失速/超速）
- -10：h < 300m 或 h > 18000m（越界）
- 0：其他

**威胁指数修正奖励** R_u(s)：

$$R_u(s) = \omega R(s) - (1 - \omega) T(s) \times 10$$

总威胁指数：

$$T = 0.2 T_a + 0.4 T_r + 0.2 T_v + 0.2 T_h$$

其中 T_a（角度威胁）、T_r（距离威胁）、T_v（速度威胁）、T_h（高度威胁）分别由公式(4-5)至(4-8)定义。

### 3.7 RBF神经网络Q值拟合

五层网络结构：输入层(8节点) → 隐藏层(K节点, 高斯基函数) → 输出层(9个动机Q值) → 映射层(动机→动作) → 状态输出层。

高斯基函数：

$$f(X, C_i) = \exp\left(-\frac{||X - C_i||^2}{2\sigma_i^2}\right), \quad i = 1, \ldots, K$$

Q值计算：

$$Q(s_t, m_t) = \sum_{i=1}^{K} \phi(s_i, C_i) \omega_{i, \text{idx}(m_t)}$$

权值更新（TD误差反传）：

$$\omega_{i,\text{idx}(m_t)} \leftarrow \omega_{i,\text{idx}(m_t)} + \alpha \cdot E_{\text{error}} \cdot \varphi(s_t, m_t)$$

RBF中心用k-means聚类离线确定，宽度取 σ_i = (1/N_i) * Σ||X - C_i||²。

## 四、实验结果

### 4.1 路径规划验证实验（M-SA-Q vs 基线算法）

| 项目 | 值 |
|---|---|
| 环境 | 10×10×10三维网格 |
| 起点 | (2, 2, 2) → 目标 (9, 9, 9) |
| 学习周期 | 4000幕 |
| 每幕最大步数 | 3000步 |
| 学习率 α | 0.2 |
| 折扣因子 γ | 0.95 |
| 退火初始温度 T₀ | 500 |
| 降温参数 λ | 0.93 |
| ε (ε-greedy基线) | 0.1 |

**结果**：M-SA-Q算法在约1200幕后步数显著下降，1800幕后稳定在约50步/幕到达目标，优于ε-greedy Q学习和ε-greedy动机引导Q学习。

### 4.2 UCAV空中格斗实验

| 项目 | 值 |
|---|---|
| 格斗空间 | 200km × 200km × 18km |
| RBF隐藏层节点数 | 6 |
| 训练样本数 | 90,000个状态样本 |
| 攻击条件 | d<10km, q_r<30°, q_b>30°, β<40° |

**表4-3 算例初始条件**：

| 算例 | 红方位置(km) | 红方 χ/τ | 蓝方位置(km) | 蓝方 χ/τ |
|---|---|---|---|---|
| 算例1 | (13, 1.5, 6.0) | 40°/0° | (6, 13, 8.7) | 40°/0° |
| 算例2 | (3, 18, 18) | 30°/0° | (6, 10, 6) | 30°/0° |

**结果**：
- **主动进攻意图**：红蓝双方主动接近，运动轨迹纠缠，保持一定安全距离，符合实际空中格斗趋势。
- **积极防御意图**：红蓝双方保持距离，避免被发现，安全优先，符合防御态势。
- 结论：通过引入动机层，不同作战意图可产生不同的格斗轨迹，验证了算法有效性。

## 六、可借鉴要点

### 6.1 动机层思想（Motivation Layer）—— 可直接应用

**适用层级**：L1、L2

在标准Q-learning的"状态→动作"映射中插入动机层，形成"状态→动机→动作"三层结构。对配送场景，可设定如下动机：

| 动机编号 | 动机 | 对应动作 |
|---|---|---|
| 1 | 前往最近取货点 | A*路径导航到最近商家 |
| 2 | 前往最近送货点 | A*路径导航到最近客户 |
| 3 | 返回基地 | A*路径回起点 |
| 4 | 避障 | 绕行建筑/禁飞区 |
| 5 | 等待 | 原地悬停（订单未就绪） |
| 6 | 携带多单优先送近 | 多单调度策略 |

将配送领域的先验知识（如"先取后送""近单优先"等规则）编码为IF-THEN规则，映射到动机到动作的对应关系，可在训练初期快速引导探索方向。

### 6.2 多维威胁指数加权奖励 —— 可直接借鉴

本文将角度、距离、速度、高度四个威胁指数加权为总威胁，再与基础奖励结合。配送场景可类比构造：

$$R_{\text{delivery}}(s) = \omega_1 R_{\text{task}}(s) - \omega_2 D_{\text{dist}}(s) - \omega_3 T_{\text{time}}(s) - \omega_4 C_{\text{collision}}(s) - \omega_5 F_{\text{nofly}}(s)$$

其中各分量的量级需保持一致（参考项目CLAUDE.md中"不要让奖励分量的量级差异过大"的指导）。

### 6.3 模拟退火探索策略 —— 可选择性移植

可将M-SA-Q的Metropolis准则用于替换DQN中的ε-greedy，初始高温阶段鼓励充分探索，后期低温收敛到最优策略。等比降温参数λ=0.93可作为初始参考值。

### 6.4 态势向量设计范式 —— 可参考设计思路

本文将格斗双方的相对关系压缩为8维连续向量的方法，可用于设计L3/L4层级的观测空间：

$$s_{\text{delivery}} = [\Delta x_{\text{nearest\_shop}}, \Delta y_{\text{nearest\_shop}}, \Delta x_{\text{nearest\_customer}}, \Delta y_{\text{nearest\_customer}}, V_{\text{battery}}, N_{\text{carrying}}, d_{\text{nearest\_obs}}, \text{flag\_nofly}]$$

### 6.5 局限性（供警示参考）

- 动机到动作的IF-THEN规则为手动设计，缺乏自适应能力
- RBF网络+表格Q-learning难以扩展到大规模状态空间，深度网络更优
- 训练样本为随机生成，非真实飞行数据，泛化性存疑
- 单机1v1场景，未涉及多机协同（项目L4层需求）
