## 二、研究问题与动机

### 2.1 核心问题

传统无线资源管理算法（凸优化、元启发式）需要**完全且精确的环境状态信息**，存在三大局限：
1. 先验信息在实际场景中**难以获取**
2. 计算复杂度随用户/无人机数量**高阶增长**（通常大于三次方）
3. 策略无法随环境变化**动态调整**

### 2.2 两大典型通信场景

| 场景 | 核心任务 | 资源管理子问题 |
|------|---------|--------------|
| 单无人机中继 | 轮流为地面用户提供突发通信服务 | 飞行轨迹设计、发射功率控制 |
| 无人机集群基站 | 多机协同充当临时基站（应急/按需通信） | 集群模式选择、用户关联、功率控制、时频资源块分配 |

### 2.3 无人机通信三大优势

1. **传输信道良好**：LoS 特性好，小尺度/阴影衰落影响小
2. **高机动性**：可快速调整 3D 位置，适应应急场景
3. **组网灵活经济**：部署成本低，适合体育场/音乐会等临时场景

## 三、技术框架与方法

### 3.1 RLB-HIDM 总体架构

提出**基于强化学习的分层智能决策架构**（Reinforcement Learning Based Hierarchical Intelligent Decision-Making, RLB-HIDM），共四层：

| 层级 | 名称 | 功能 |
|------|------|------|
| L1 | 决策分析层 | 任务分类与场景识别 |
| L2 | 任务规划层 | 宏观资源分配策略规划 |
| L3 | 算法设计及协同控制层 | 选择具体 RL 算法并协调多智能体 |
| L4 | 任务执行层 | 执行具体动作（轨迹/功率/资源块） |

**核心优势**：不需提前获知全部环境信息，仅需环境交互反馈，通过试错探索最优策略；计算复杂度远低于传统架构。

### 3.2 单无人机中继：TSIS 三步智能方案

将高维度联合决策解耦为三个低维度子问题：

**Step 1 — 降维（高度部署）**
- 算法：MPR-ML（Model Parameter Reconstructive Machine Learning）
- 思路：基于模型参数重构估计空-地信道参数，确定无人机最优飞行高度
- 信道模型：城市空-地信道，区分 LoS/NLoS 路径

**Step 2 — 轨迹设计**
- 算法：蚁群优化（ACO）
- 目标：以低复杂度求解二维飞行轨迹（本质为 NP 难的旅行商问题）
- 适用于：覆盖多个地面用户的中继轮转服务

**Step 3 — 功率控制**
- 算法：PS-TD3（Prioritized Sampling Twin Delayed Deep Deterministic Policy Gradient）
- 创新点：
  - 引入**优先级采样**（Prioritized Sampling）提升经验回放效率
  - 利用 TD3 的**双 Q 网络**和**延迟策略更新**降低 Q 值过估计偏差
- 状态空间：无人机位置、信道增益、干扰信息
- 动作空间：连续发射功率
- 回报函数：信道容量最大化 + 功率惩罚

### 3.3 无人机集群机间通信：快速强化学习方案

#### 基础算法：DQN 及三种改进

| 算法 | 改进点 |
|------|-------|
| DQN | 基线，经验回放 + 目标网络 |
| DDQN（Double DQN） | 解耦动作选择与价值评估，降低过估计 |
| Dueling DQN | 分离状态价值与优势函数，提升泛化 |
| IS-DQN（Importance Sampling DQN） | 引入重要性采样修正分布偏移 |

**联合决策**：集群模式选择（离散）+ 发射功率（离散化）

#### 快速强化学习算法

| 算法 | 核心思想 | 优势 |
|------|---------|------|
| Meta-DQN（元深度Q网络） | 元学习框架：支撑集训练 + 查询集微调 | **少样本学习**（Few-Shot Learning），快速适应新环境 |
| MVE-DQN（模型价值扩展Q网络） | 利用环境模型展开多步"想象"（imagination steps H） | 减少样本需求，**更高概率收敛到最优解** |

### 3.4 集群基站对地通信：CA-MARL 方案

**问题**：用户关联、节点部署、功率控制、时频资源块分配的**四维联合优化**（NP 难）

**解耦策略**：分为两个阶段、三个子问题

#### 阶段一：预部署

| 子问题 | 算法 | 说明 |
|--------|------|------|
| 用户聚类 | MEM（Modified Expectation-Maximization） | 无监督聚类，将用户关联问题转为"无人机-用户簇匹配"问题，降低决策维度 |
| 无人机-簇匹配 | KM（Kuhn-Munkres）算法 | 二分图最优匹配，完成用户关联和无人机预部署 |

#### 阶段二：位置微调与资源分配

| 子问题 | 算法 | 说明 |
|--------|------|------|
| 轨迹 + 功率 | MATD3（Multi-Agent TD3） | 集中训练分散执行（CTDE），低偏差 Q 值估计 |
| 时频资源块分配 | MAA2C（Multi-Agent A2C） | 优势更新使训练更易收敛，抵抗典型干扰 |

**MATD3 核心机制**：
- 双 Critic 网络取最小值 → 降低 Q 值过估计
- 延迟策略更新 → 减少策略震荡
- 集中训练（Central Unit）+ 分散执行（各 UAV Agent）

**MAA2C 核心机制**：
- 优势函数 A(s,a) = Q(s,a) - V(s) → 方差缩减
- 多智能体各自决策资源块 → 避免同频干扰
- 不同时频资源块切片方案支持灵活频谱管理

## 四、信道与干扰建模

### 4.1 空-地信道模型

- 区分 **LoS（视距）** 和 **NLoS（非视距）** 两种传播路径
- 路径损耗随无人机高度变化：存在最优高度使路径损耗最小
- 城市环境参数化：建筑密度、载波频率等

### 4.2 干扰建模

论文考虑了**六种典型干扰类型**：
1. 窄带调制干扰
2. 梳状多音干扰
3. 部分频带噪声干扰
4. 脉冲噪声干扰
5. 线性调频干扰
6. 噪声调频干扰

干扰分为**静态干扰**（固定时频图案）和**动态干扰**（时变图案），验证算法在对抗环境下的鲁棒性。

## 五、实验结果与关键发现

### 5.1 单无人机中继（TSIS）

- MPR-ML 的信道参数估计精度高（真实值 vs 估计值对比验证）
- PS-TD3 在无干扰和六种干扰环境下，平均回报均优于 DDPG、TD3、PS-DDPG
- PS-TD3 的 Q 值估计偏差显著低于 PS-DDPG → 更可靠的策略评估
- 优先级采样因子有效提升收敛速度
- 计算复杂度对比：PS-TD3 与传统优化算法相比大幅降低

### 5.2 集群机间通信（DQN / Meta-DQN / MVE-DQN）

- DQN 系列改进（DDQN、Dueling DQN、IS-DQN）在六种干扰下均有效提升平均回报
- Meta-DQN 在**小样本**条件下表现显著优于 DQN（支撑集训练 → 查询集快速适应）
- MVE-DQN 通过多步想象（H 步展开）提升样本效率，以更高概率收敛至最优解
- 覆盖范围增大时，DQN 能自动调整集群模式和功率以维持覆盖

### 5.3 集群对地通信（CA-MARL）

- MEM 聚类算法效果优于 K-Means 和 GMM
- MATD3 的 Q 值估计偏差低于 MADDPG、MAA2C → 策略更优
- MAA2C 在六种干扰下，满足 QoS 的用户比例（PUMQoS）均优于 A2C、MADDPG
- CA-MARL 方案总体：聚类辅助 + 预部署显著提升平均回报，降低发射功率
- 计算复杂度：CA-MARL 以较低复杂度达到较优策略

### 5.4 算法对比总结

| 对比维度 | 凸优化 | 元启发式 | 强化学习（本文） |
|----------|--------|---------|----------------|
| 先验信息需求 | 需要完全精确 | 不需要 | 不需要（环境交互学习） |
| 问题类型 | 仅凸问题 | 组合优化 | 连续/离散均可 |
| 计算复杂度 | 用户/无人机数高阶项 | 中等 | 远低于凸优化 |
| 动态适应 | 不支持 | 有限 | **强（在线适应）** |
| 可扩展性 | 差 | 中等 | 好（多智能体分布式） |

## 六、与本项目的关联性分析

### 6.1 高度相关

| 本论文贡献 | 对无人机配送项目的启发 |
|-----------|---------------------|
| RLB-HIDM 分层决策架构 | 可借鉴用于配送系统的分层调度（全局规划层 → 局部路径层 → 即时避障层） |
| TSIS 解耦高维联合决策 | 配送系统中的"路径+功率+载荷"联合优化可借鉴此降维思路 |
| PS-TD3 连续动作控制 | 直接适用于 L3/L4 层级的连续飞行轨迹与功率控制 |
| Meta-DQN 快速适应 | 配送系统需快速适应不同区域/时段订单分布变化 |
| CA-MARL 多智能体协同 | 配送场景中的多机协同调度直接映射，MATD3/MAA2C 可迁移 |
| MEM 聚类 + KM 匹配 | 用户聚类思想可用于"商家-用户"订单分组，降低调度维度 |
| 六种干扰对抗 | 配送场景中的通信干扰、禁飞区动态变化可类比建模 |

### 6.2 关键差异

| 维度 | 本文（通信资源管理） | 本项目（配送调度） |
|------|-------------------|-------------------|
| 优化目标 | 信道容量/吞吐量/QoS | 配送效率/奖励/完成率 |
| 核心决策变量 | 功率 + 频谱资源块 + 轨迹 | 路径 + 速度 + 订单选择 |
| 环境模型 | 无线信道 + 干扰 | 地图 + 建筑 + 禁飞区 + 风险区 |
| 约束条件 | SINR、功率上限、正交性 | 时间窗口、能耗、碰撞避免 |

### 6.3 可直接迁移的技术

1. **CTDE（集中训练分散执行）范式** → 多机配送的核心训练框架
2. **TD3 双 Critic 机制** → 降低 Q 值过估计，改善 L3/L4 连续控制质量
3. **优先级经验回放（PER）** → 提升配送训练的样本效率
4. **元学习快速适应** → 适应新区域/新场景的零样本/少样本迁移
5. **聚类预处理降低决策维度** → 订单分组 + 指派优化的两阶段解法
