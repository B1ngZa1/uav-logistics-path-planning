## 一、研究问题与动机 ★★★★★

### 1.1 核心问题

四旋翼无人机自主导航与控制中，现实世界存在多重不确定性：动力学建模不准确、传感器数据存在噪声、空间感知不完整、存在其他动态未知智能体。这些因素对四旋翼无人机的安全控制带来潜在风险。本论文从四个角度系统研究四旋翼无人机的安全控制问题。

### 1.2 关键挑战

| 挑战编号 | 挑战描述 | 对应解决思路 |
|:---:|:---|:---|
| C1 | 底层轨迹跟踪控制器安全性保障：如何在保证轨迹跟踪性能的同时，约束无人机状态不超出安全区域 | 微分平坦级联控制 + 控制障碍函数(CBF) + 二次规划(QP) |
| C2 | 复杂空间中安全运动规划：障碍物导致路径积分控制采样效率低，存在不安全采样路径 | CBF约束采样输入 + 顺序投影算法(Sequential Projection) |
| C3 | 强化学习控制器的安全认证：深度RL策略无法从理论上保障安全性，存在sim-to-real差距 | 近端策略优化(PPO) + 管道非线性鲁棒MPC安全认证 |
| C4 | 集群内部碰撞规避：多机编队需实时避障，同时抑制建模误差和外部扰动 | 弹性安全间隙(基于指数CBF) + 管道鲁棒MPC + 分层架构 |

### 1.3 与本项目的关联度 ★★★★☆

- **相关**: 控制障碍函数(CBF)在安全约束中的理论框架、模型预测控制(MPC)的鲁棒设计、强化学习(PPO)竞速控制策略设计
- **差异**: 本文面向单机/集群飞行控制场景（低层控制），本项目面向物流配送场景（高层调度+轨迹规划）；控制频率和模型层级不同
- **可借鉴**: CBF安全约束设计思路（可用于配送场景中的禁飞区/碰撞规避）、PPO奖励函数设计中的进度奖励和安全奖励分离思路、分层安全架构思想（底层安全控制器 + 高层规划器）

## 二、系统模型与数学建模 ★★★★★

### 2.1 四旋翼无人机动力学模型

**坐标系定义**:
- 惯性坐标系 `{E}`：与地球固连，原点为无人机重心起始位置
- 机体坐标系 `{B}`：固连在无人机上，原点与几何中心重合

**完整动力学模型**（牛顿-欧拉方程）:

$$\dot{p} = v$$

$$\dot{v} = g e_3 + \frac{T}{m} R e_3$$

$$\dot{R} = R \hat{\omega}$$

$$J \dot{\omega} = -\omega \times J\omega + \tau$$

其中 $p \in \mathbb{R}^3$ 为位置，$v \in \mathbb{R}^3$ 为速度，$R \in SO(3)$ 为旋转矩阵，$\omega \in \mathbb{R}^3$ 为角速度，$T$ 为总推力，$\tau \in \mathbb{R}^3$ 为力矩，$m$ 为质量，$J$ 为转动惯量矩阵，$g$ 为重力加速度，$e_3 = [0,0,1]^T$。

### 2.2 合外力与角速度控制模型

为避免电机转速控制频率过高（上千Hz）不切实际的问题，采用合外力 $T$ 和角速度 $\omega$ 作为控制输入：

$$\dot{p} = v$$

$$\dot{v} = g e_3 + \frac{T}{m} R e_3$$

$$\dot{q} = q \otimes \begin{bmatrix} 0 \\ \omega/2 \end{bmatrix}$$

其中 $q$ 为四元数表示的姿态，$\otimes$ 为四元数乘法。最终安全控制输入通过底层PID角速度控制器转换为电机转速。

### 2.3 级联控制结构

四旋翼无人机典型级联控制结构分为三层：

| 控制层级 | 输入 | 输出 | 典型频率 |
|:---|:---|:---|:---:|
| 位置环（外环） | 期望位置/轨迹 | 期望姿态 + 期望推力 | 100-200 Hz |
| 姿态环（中环） | 期望姿态 | 期望角速度 | 200-500 Hz |
| 角速度环（内环） | 期望角速度 | 电机转速 | 500-1000 Hz |

### 2.4 微分平坦性质

四旋翼无人机具有微分平坦特性，平坦输出为：

$$z = [p^T, \psi]^T$$

其中 $p$ 为位置，$\psi$ 为偏航角。系统的全部状态和控制输入均可由平坦输出及其有限阶导数表示，这使得轨迹跟踪控制器设计可以解耦为位置控制和姿态控制。

### 2.5 安全集合定义

安全区域建模为类椭球体：

$$h(x) = 1 - \frac{(p_x - p_x^c)^2}{d_x^2} - \frac{(p_y - p_y^c)^2}{d_y^2} - \frac{(p_z - p_z^c)^2}{d_z^2}$$

其中 $p^c = [p_x^c, p_y^c, p_z^c]^T$ 为安全区域中心，$d_x, d_y, d_z$ 为椭球体各轴半径。

安全集合定义为 $C = \{x \in \mathcal{X} : h(x) \geq 0\}$。

## 三、核心算法与创新点 ★★★★★

### 3.1 第三章：基于微分平坦的安全级联控制器

**核心思想**: 在微分平坦级联控制器基础上，引入控制障碍函数(CBF)设计安全输入约束，通过二次规划(QP)最小化修改原有稳定控制器输出。

**控制障碍函数定义** (相对阶为1):

$$\sup_{u \in U} [L_f h(x) + L_g h(x) u] \geq -\alpha(h(x))$$

其中 $L_f, L_g$ 为李导数，$\alpha(\cdot)$ 为扩展类 $\mathcal{K}$ 函数。

**指数控制障碍函数** (相对阶为 $r$):

$$\inf_{u \in U} [L_f^r h(x) + L_f^{r-1} L_g h(x) u + \sum_{i=1}^{r-1} \alpha_i L_f^i h(x)] \geq 0$$

引入虚拟控制量 $T_v = \frac{T}{m} R e_3$ 后，构建三级CBF链：

$$h_0(x) = h(x)$$

$$h_1(x) = L_f h_0(x) + c_1 h_0(x)$$

$$h_2(x) = L_f h_1(x) + c_2 h_1(x)$$

$$h_3(x, u) = L_f h_2(x) + L_g h_2(x) u + c_3 h_2(x)$$

**安全控制器** (QP形式):

$$u^* = \arg\min_{u} \|u - u_{nom}\|^2$$

$$\text{s.t.} \quad h_3(x, u) \geq 0$$

其中 $u_{nom}$ 为原级联控制器的标称输出。通过求解二次规划，在保证安全的前提下最小化对原控制器的修改。

**不同层级安全控制器对比**:

| 安全控制器 | 安全约束施加层级 | CBF相对阶 | 优点 | 缺点 |
|:---|:---|:---:|:---|:---|
| 速度安全控制器 | 速度环 | 1 | 实现简单 | 无法约束底层动力学 |
| 姿态安全控制器 | 姿态环 | 2 | 考虑姿态约束 | 仍有延迟 |
| 角速度安全控制器 | 角速度环 | 3 | **最接近底层物理约束，安全保障最优** | 计算复杂度最高 |

**实验结论**: 考虑四旋翼无人机底层动力学的**角速度安全控制器**能够更好地将无人机限制在安全空间中。

### 3.2 第四章：基于安全障碍认证的路径积分控制

**核心思想**: 路径积分控制(PIC)基于蒙特卡洛采样计算随机最优控制律，但采样路径可能与障碍物碰撞导致计算代价过高。本章利用CBF将位置安全约束转换为控制输入约束，通过顺序投影算法过滤不安全采样。

**路径积分控制基本原理**:

将控制问题建模为存在输入不确定性的随机系统最优控制问题，通过蒙特卡洛采样近似求解：

$$u^* = \frac{\sum_{i=1}^{N} \exp(-\frac{1}{\lambda} S_i) \cdot u_i}{\sum_{i=1}^{N} \exp(-\frac{1}{\lambda} S_i)}$$

其中 $N$ 为采样数，$S_i$ 为第 $i$ 条轨迹的代价，$\lambda$ 为温度参数。

**顺序投影算法(Sequential Projection)**:

将CBF安全约束从状态空间转换为输入空间，对不安全的采样控制输入进行投影修正：

$$u_{safe} = \Pi_U(u_{unsafe}) = u_{unsafe} - L_g h_2^{\dagger} \cdot \min(0, h_3(x, u_{unsafe}))$$

**创新点**:
1. 将控制障碍函数以线性变换的方式约束采样控制，同时改善路径积分控制的鲁棒性和采样效率
2. 系统不确定性通过随机最优控制建模，基于采样的控制方法近似求解

### 3.3 第五章：强化学习安全认证方法

**核心思想**: 利用近端策略优化(PPO)训练时间最优竞速控制器，针对sim-to-real差距，设计基于管道非线性鲁棒MPC的安全认证算法。

**PPO奖励函数设计**:

| 奖励分量 | 公式/描述 | 作用 |
|:---|:---|:---|
| 进度奖励 | $r_{progress} = \Delta d_{gate}$ (到下一个检查点的距离差) | 引导沿赛道前进 |
| 碰撞惩罚 | $r_{collision} = -1$ (与障碍物碰撞时) | 惩罚不安全行为 |
| 完成奖励 | $r_{finish} = +10$ (通过检查点) | 鼓励完成任务 |
| 时间惩罚 | $r_{time} = -0.01$ (每步) | 鼓励快速完成 |
| 临界状态惩罚 | $r_{critical}$ (接近障碍物时) | 提前规避危险 |

**观测空间**: $o = [v_d, \omega, q, d, \Phi] \in \mathbb{R}^{12+6}$

- $v_d$: 无人机速度（3维）
- $\omega$: 角速度（3维）
- $q$: 四元数姿态（4维）
- $d$: 到赛道门的距离信息（6维）
- $\Phi$: 赛道进度信息（2维）

**动作空间**: $a = [T_{norm}, \omega_{x,norm}, \omega_{y,norm}, \omega_{z,norm}]$，归一化到 $[-1, 1]^4$

**初始化策略**: 完全随机化（初始位置、速度、姿态随机 + 赛道门位置随机），最大化探索状态空间。

**模型预测安全认证**:

假设标称系统满足局部增量稳定性（存在李雅普诺夫函数 $V_s$）：

$$c_1 \|x\|^2 \leq V_s(x) \leq c_2 \|x\|^2$$

$$\min_{v} \dot{V}_s(x, K(x,v), v) \leq -\rho V_s(x) + c_3$$

通过扰动有界假设，收紧标称系统约束条件，保证真实系统安全性：

$$g_j(x, K(x, \hat{x}, v)) - g_j(x, v) \leq \epsilon_j$$

最终通过鲁棒MPC在线滚动优化，在每个时域窗口内对RL策略输出进行安全认证和过滤。

### 3.4 第六章：集群安全弹性间隙方法

**核心思想**: 基于指数CBF设计弹性安全间隙约束，结合管道鲁棒MPC处理建模误差和外部扰动，通过分层架构实现四旋翼无人机集群在线安全编队控制。

**弹性安全间隙设计**:

基于指数控制障碍函数设计集群间安全距离约束：

$$h_{ij}(x) = \|p_i - p_j\|^2 - d_{safe}^2$$

其中 $d_{safe}$ 为安全距离阈值。通过ECBF保证：

$$\ddot{h}_{ij} + (k_1 + k_2)\dot{h}_{ij} + k_1 k_2 h_{ij} \geq 0$$

**最小鲁棒正不变集估计**:

考虑系统建模误差和外部扰动 $w$，估计最小鲁棒正不变集 $\mathcal{Z}$：

$$\mathcal{Z} = \{z : V(z) \leq \bar{v}\}$$

其中 $V(z)$ 为辅助系统的李雅普诺夫函数，$\bar{v}$ 为上界。通过管道MPC将误差状态限制在不变集内。

**分层控制架构**:

| 层级 | 功能 | 方法 |
|:---|:---|:---|
| 集群规划层 | 路径规划 + 编队协调 | 分布式MPC + 弹性安全间隙 |
| 个体控制层 | 轨迹跟踪 + 鲁棒性保证 | 管道MPC + 辅助反馈控制器 |
| 底层执行层 | 电机转速控制 | PID角速度控制器 |

## 四、实验结果与分析 ★★★★☆

### 4.1 实验平台

- **仿真平台**: Gazebo物理仿真器
- **实物平台**: Crazyflie 2.1 小型四旋翼无人机（重约27g）
- **软件框架**: 基于机器人操作系统(ROS)的软件框架

### 4.2 第三章实验结果

**仿真与实物对比**:

| 安全控制器类型 | 安全区域越界情况 | CBF最小值 | 备注 |
|:---|:---|:---|:---|
| 速度安全控制器 | 容易越界 | 偏差大 | 仅约束速度层面 |
| 姿态安全控制器 | 存在越界 | 偏差中等 | 约束姿态层面 |
| 角速度安全控制器 | **最少越界** | 偏差最小（约-0.1） | 约束角速度层面，**最优** |

实验验证了：考虑底层动力学的角速度安全控制器能更好地保障四旋翼无人机安全，实物实验中CBF最小值误差在 $-0.1$ 左右，属于可接受范围。

### 4.3 第四章实验结果

- 在Gazebo仿真中对比MPPI控制器和SBCPI控制器（基于安全障碍认证）
- SBCPI在不同采样次数下均展现更好的控制能量和速度表现
- 实物实验在室内环境中验证了算法在复杂空间中的安全运动规划能力

### 4.4 第五章实验结果

| 指标 | 仅RL控制器 | RL + 安全认证 |
|:---|:---|:---|
| 赛道完成率（质量不确定性下） | 随不确定性增大显著下降 | **保持较高水平** |
| 平均圈速 | 较快但不稳定 | 略慢但**安全稳定** |
| 碰撞概率 | 随不确定性增大显著上升 | **大幅降低** |

### 4.5 第六章实验结果

- 仿真验证了四架四旋翼无人机集群编队控制
- **MPC vs TubeMPC对比**: TubeMPC跟踪误差均值和方差均更小
- **ESC-MPC vs PBMPC对比**: 弹性安全间隙方法避障响应速度更快
- 实物实验：四架Crazyflie 2.1完成队形变换，无碰撞

## 五、关键技术总结 ★★★★★

### 5.1 技术路线图

```
第三章（底层）  →  第四章（高层）  →  第五章（RL认证）  →  第六章（集群）
  CBF+QP           PIC+CBF            PPO+NMPC           管道MPC+ECBF
  安全轨迹跟踪      安全运动规划       安全认证             集群安全编队
```

### 5.2 核心方法对比

| 方法 | 适用场景 | 安全保障方式 | 计算复杂度 | 理论保证 |
|:---|:---|:---|:---:|:---:|
| CBF + QP | 底层轨迹跟踪 | 在线约束修正 | 低（QP） | 安全集合前向不变性 |
| PIC + 顺序投影 | 高层运动规划 | 采样过滤 | 中（蒙特卡洛） | 概率安全 |
| PPO + NMPC认证 | RL控制器认证 | 在线安全滤波 | 高（MPC求解） | 鲁棒管道保证 |
| 管道MPC + ECBF | 集群编队 | 不变集约束 | 高（分布式MPC） | 正不变集保证 |

### 5.3 控制障碍函数(CBF)核心公式汇总

**基本CBF条件**:

$$\sup_{u \in U} [\dot{h}(x, u)] \geq -\alpha(h(x))$$

**安全过滤(QP)**:

$$u^* = \arg\min_u \|u - u_{nom}\|^2 \quad \text{s.t.} \quad \nabla h(x) \cdot f(x, u) \geq -\alpha(h(x))$$

**指数CBF** (高相对阶系统):

$$L_f^r h(x) + L_g L_f^{r-1} h(x) u + \sum_{i=0}^{r-1} \alpha_i L_f^i h(x) \geq 0$$

## 六、对本项目的启示 ★★★★☆

### 6.1 可借鉴的设计思路

1. **CBF安全约束框架**: 可用于无人机配送场景中的禁飞区约束、建筑碰撞规避。将空间约束转换为控制输入约束的形式可直接应用于L3/L4层级的安全约束设计。

2. **分层安全架构**: 底层安全控制器（CBF+QP）+ 高层安全规划器（MPC/PIC）的分层思想，与本项目的L1-L4渐进式框架高度一致。

3. **PPO奖励函数设计**: 进度奖励 + 碰撞惩罚 + 时间惩罚的复合奖励结构，可借鉴用于配送场景中的订单完成奖励 + 碰撞惩罚 + 时间窗口惩罚。

4. **管道鲁棒MPC**: 处理模型不确定性的思想可用于处理无人机配送中的风扰、载荷变化等不确定性因素。

5. **弹性安全间隙**: 集群间安全距离约束的设计方法可直接用于L4多机协同配送中的防碰撞机制。

### 6.2 局限性与差异

| 维度 | 本文 | 本项目 |
|:---|:---|:---|
| 控制频率 | 底层100-1000Hz | 高层决策1-10Hz |
| 状态空间 | 连续物理状态 | 离散网格 + 订单状态 |
| 动作空间 | 连续（推力+角速度） | 离散方向(L1/L2) / 连续速度(L3/L4) |
| 安全约束 | 物理碰撞/越界 | 禁飞区/碰撞/时间窗口 |
| 优化目标 | 轨迹跟踪/时间最优 | 配送效率/多目标权衡 |
| 集群规模 | 4架（实物验证） | 目标10+架 |
