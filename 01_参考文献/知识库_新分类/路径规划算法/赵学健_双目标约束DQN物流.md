## 二、摘要与核心贡献

### 摘要

低空经济与城市即时配送需求的增长，展现出多无人机物流配送在提升末端效率方面具有显著潜力。然而在障碍密集、禁飞区域频发且存在能量补给约束的三维城市空域中，多无人机路径规划与动态避障同时面临高维离散决策、稀疏回报、价值估计不稳定以及强安全约束难以全过程保证等挑战。为此，本文面向体素化三维城市环境构建多无人机取送任务的序列决策模型，提出一种双目标约束深度Q网络（DTC-DQN）。该方法在Double DQN基础上：引入双目标网络下界估计以抑制Q值高估并提升收敛稳定性；设计面向多智能体轨迹一致性的n步回报缓冲以加速回报传播并避免时间片段混入；融合Dueling架构与优先级经验回放以增强特征表达与样本利用效率；并将动作掩码与安全屏蔽机制嵌入决策与目标计算全过程，从源头限制动作选择于可行集合，保障全过程安全与任务可达。实验在不同规模三维栅格实例上开展对比，结果表明：相较DQN、Double DQN与Dueling DQN等基线，所提方法在收敛速度、策略稳定性与任务完成成功率方面均表现更优，并在时延与能量损耗指标上取得更好的综合权衡。

### 核心贡献

1. **提出基于双目标网络下界的稳定价值评估机制**：引入两套独立更新的目标网络，在计算时序差分目标时取其Q值最小值，有效抑制Q值高估，提升收敛质量。
2. **将硬约束掩码与安全屏蔽机制深度嵌入DQN全流程**：通过"先验+屏蔽"的约束嵌入方案，在每一决策点利用动作掩码将选择限制于物理与规则允许的动作子集，并引入安全屏蔽机制动态修改动作空间以强制引导安全行为，保障任务可行性与过程安全性。
3. **设计面向多智能体轨迹一致性的N步回报缓冲策略**：为每架无人机维护独立的N步经验缓冲区，确保计算N步回报时经验片段来源于同一智能体的连续轨迹，避免多智能体并行采样导致的时间维度污染，保证估计无偏性。
4. **构建融合多种技术的协同学习架构**：将Dueling网络、优先级经验回放、双目标网络与N步回报有机整合，形成高效、稳定的端到端学习闭环。

## 三、核心方法

### 3.1 场景与任务建模

将低空三维城市空域离散为尺寸为 $G_x \times G_y \times G_z$ 的体素栅格。建筑体及不可飞越结构构成静态障碍体素集合 $O$，由政府或场域管理规则产生的禁飞体素构成集合 $F$。场景中给定充电桩集合 $C$（位于地面或低层），无人机可在充电桩上方悬停充电。

系统包含 $K$ 架同构无人机并采用参数共享策略，任务集合 $T = \{1,..., N\}$ 中每个任务 $i$ 由取件点与投递点二元组 $(p_i, d_i)$ 与软截止时间 $L_i$ 构成。环境在执行动作后以小概率引入水平风扰动，电量按单位动作消耗进行累积更新。

### 3.2 状态空间与动作空间

**状态向量**：对任一无人机 $k$，状态由局部占据体素展平的二值向量 $o_t^k$ 与自身和目标特征向量 $f_t^k$ 拼接得到：

$$s_t^k = [o_t^k; u_t^k]$$

其中 $o_t^k$ 为局部邻域占据体素块的二值展平表示（视野区域 $5\times5\times2$），$u_t^k$ 包含当前子目标方向 $g_t^k$、归一化电量 $b_t^k$ 及截止时间相关量。

**动作空间**：采用27个三维离散原语：

$$a_t^k = [\Delta x, \Delta y, \Delta z], \quad \Delta x, \Delta y, \Delta z \in \{-1, 0, 1\}$$

其中 $(0,0,0)$ 为悬停，其余26个动作覆盖相邻体素的面、棱、角方向移动。实际可选动作限制为可行集合 $A_t^k \subseteq A$：若动作导致越界、进入 $O \cup F$，或电量不足，则该动作被实时剔除。

### 3.3 奖励设计

单步奖励函数同时覆盖任务推进、能耗、安全与时效：

$$r_t^k = \lambda_d \Delta D_t^k - \lambda_e E(a_t^k) - \lambda_b \mathbb{I}[b_{t+1}^k < b_{th}] - \lambda_v \mathbb{I}[violate_t^k] - \lambda_n \mathbb{I}[near_t^k] + R_p \mathbb{I}[pickup] + R_d \mathbb{I}[deliver]$$

其中 $\Delta D_t^k$ 采用切比雪夫范数 $D_\infty(x, g) = \|x - g\|_\infty$ 计算距离缩短量。关键系数：取件奖励 $R_p=10$，投递奖励 $R_d=30$，低电量惩罚系数 $0.05$，违规惩罚 $3.0$。"每无人机每步至多计一次近失惩罚"的上限约束防止回报尺度失真。

### 3.4 DTC-DQN算法框架

**Dueling分解**：在线网络采用两层全连接骨干并引入Dueling分解：

$$Q_\theta(s, a) = V_\theta(s) + A_\theta(s, a) - \frac{1}{|A|} \sum_{a'} A_\theta(s, a')$$

**双目标网络下界估计**：首先在可行动作子集上用在线网络选取贪婪动作：

$$a_{t+1}^* = \arg\max_{a \in A_{t+1}} Q_\theta(s_{t+1}, a)$$

随后由两套软更新的目标网络 $Q_{\theta_1^-}, Q_{\theta_2^-}$ 评估并取下界构造TD目标：

$$y_t = r_t + \gamma(1 - done_{t+1}) \min\left(Q_{\theta_1^-}(s_{t+1}, a_{t+1}^*), Q_{\theta_2^-}(s_{t+1}, a_{t+1}^*)\right)$$

**优先级经验回放（PER）**：以TD误差 $\delta_i = y_i - Q_\theta(s_i, a_i)$ 定义采样概率与重要性采样权重：

$$P(i) = \frac{(|\delta_i| + \varepsilon)^\alpha}{\sum_j(|\delta_j| + \varepsilon)^\alpha}, \quad w_i = \frac{(N \cdot P(i))^{-\beta}}{\max_j(N \cdot P(j))^{-\beta}}$$

损失函数为加权均方误差：

$$L(\theta) = \frac{1}{B} \sum_{i=1}^{B} w_i(Q_\theta(s_i, a_i) - y_i)^2$$

**目标网络软更新**：$\theta_j^- \leftarrow \tau\theta + (1-\tau)\theta_j^-, \quad j \in \{1, 2\}$

**N步回报**：对每架无人机维护独立的N步缓冲（实验中 $n=3$），确保序列来自同一智能体连续轨迹：

$$R_t^{(n)} = \sum_{j=0}^{n-1} \gamma^j r_{t+j}$$

$$y_t^{(n)} = R_t^{(n)} + \gamma^n(1 - done_{t+n}) \min Q_{\theta^-}\left(s_{t+n}, \arg\max_{a \in A_{t+n}} Q_\theta(s_{t+n}, a)\right)$$

### 3.5 约束嵌入机制

- **动作掩码**：基于越界、障碍、禁飞与电量可达性实时生成可行动作集合，保证策略始终在可行子集中选择。
- **安全屏蔽（Shield）**：当电量低于阈值时，进一步禁止增大到最近充电桩距离的动作，在资源紧张状态下强制引导回桩补能。
- **冲突消解**：多机对同一体素的占用冲突在执行阶段采用确定性消解策略。
- **随机扰动**：以小概率水平风扰动引入随机位移，提高策略对动态扰动的鲁棒性。

探索采用线性退火的 $\epsilon$-greedy，随机动作与贪婪动作均限制在 $A_t^k$ 内。

## 四、实验结果

### 4.1 实验设置

| 参数 | Small-Case | Medium-Case | Large-Case |
|:---:|:---:|:---:|:---:|
| 三维体素栅格 | 22x22x6 | 32x32x8 | 42x42x10 |
| 无人机数量K | 3/6/10 | 3/6/10 | 3/6/10 |
| 任务数量M | 6/12/20 | 6/12/20 | 6/12/20 |
| 障碍密度 | 6%-10% | 6%-10% | 6%-10% |
| 禁飞区域密度 | 3%-5% | 3%-5% | 3%-5% |
| 充电桩数量C | 2/3/4 | 2/3/4 | 2/3/4 |

- 每个规模使用3个独立随机种子（42、43、44）生成实例，每个实例训练40回合，最大步长500
- 能耗模型：平移1.0、爬升0.6、悬停0.3单位成本；电量阈值12，桩上充电速率1.5
- 网络：两层全连接+ReLU，Adam优化器，学习率 $2\times10^{-4}$，批量大小64，经验池容量120000
- 对比算法：DQN、Double DQN、Dueling DQN、DTC-DQN；另与PPO、MPPO、QMIX、IQL、VDN、QTRAN比较成功率

### 4.2 收敛性实验

- DTC-DQN在训练早期即可获得更快的回报增长速度，并在中后期达到更高的平台值
- 标准差带明显收敛，表现出更强的训练稳定性与更小的策略波动
- DQN曲线波动大、无法收敛；Dueling DQN稳定性与性能仍受限制

### 4.3 成功率实验

| 算法 | 成功率 |
|:---|:---:|
| DTC-DQN | 0.91 |
| PPO | 0.88 |
| IQL | 0.81 |
| QMIX | ~0.70 |
| MPPO | ~0.60 |
| VDN | ~0.55 |
| QTRAN | ~0.45 |

- DTC-DQN在三种规模实例上均取得最高成功率，随问题规模增大优势更加明显
- 风场扰动下（Dryden湍流模型，$\sigma=1.5$ m/s）成功率87%（较无扰动下降4%），路径长度增加7%

### 4.4 消融实验

| 实验组 | 模型描述 | 奖励值 | 性能下降 |
|:---|:---|:---:|:---:|
| DTC-DQN（完整） | 全部改进模块 | 63.3 | — |
| Ablation-1 | 去除双目标网络下界 | 59.4 | 6.2% |
| Ablation-2 | 去除n步回报 | 58.4 | 7.7% |
| Ablation-3 | 去除PER | 60.3 | 4.7% |
| Ablation-4 | 去除动作掩码与安全屏蔽 | ~50 | ~21% |

- 各模块对性能提升具有互补贡献
- 去除动作掩码与安全屏蔽（Ablation-4）导致最高失败率，硬约束缺失使智能体频繁经历不可行动作与高风险状态

### 4.5 时延与能量损耗

DTC-DQN在平均时延与单位任务能耗两项指标上均优于对比算法（DQN、Double DQN、Dueling DQN、PPO、MPPO、QMIX、IQL、VDN、QTRAN），体现出更好的"准时性-能耗"综合权衡能力。

## 六、可借鉴要点

1. **动作掩码+安全屏蔽的硬约束嵌入方案**：在本项目L3/L4层级中，将禁飞区、建筑碰撞、电量可达性等约束通过动作掩码从源头排除不可行动作，当电量低于阈值时触发安全屏蔽强制引导回桩补能。这种"先验+屏蔽"的方案比纯惩罚式软约束学习更安全、训练更稳定。

2. **双目标网络下界估计抑制Q值高估**：在本项目使用DQN作为基线算法的实验中，引入两套独立目标网络取最小值可有效提升收敛稳定性，避免策略振荡收敛至次优解。

3. **面向多智能体的独立N步回报缓冲**：在多无人机CTDE框架中，为每架无人机维护独立的N步经验缓冲区，避免多机并行采样导致的时间维度污染，这一设计对本项目L4多机协同场景尤为关键。

4. **切比雪夫范数用于三维距离度量**：在三维栅格环境中使用切比雪夫范数 $D_\infty(x,g) = \|x-g\|_\infty$ 作为距离度量，相比欧氏距离或曼哈顿距离更能保证不同方向的一致性，可替代本项目现有环境中的距离计算方式。

5. **多分量奖励函数的系统化设计**：奖励函数包含7个分量（距离推进、能耗、低电量警告、违规惩罚、近失惩罚、取件奖励、投递奖励），并通过"每步至多计一次"的上限约束防止回报尺度失真，这一系统化设计模式可直接指导本项目奖励函数的细化与调优。
