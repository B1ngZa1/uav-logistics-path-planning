## 二、研究问题与动机

### 2.1 核心问题

本文从**任务角度**出发，针对无人机路径规划的两个场景进行研究：

1. **场景一（离散域/通信路径规划）**：无人机在三维空间分布的异构无线传感器网络 (WSN) 中执行数据采集任务时，如何规划最短采集路径？
2. **场景二（连续域/两点间路径规划）**：无人机在三维复杂环境中从起点到终点，如何快速规划出安全、可行、平滑的最优飞行路径？

### 2.2 现有研究不足（三个痛点）

| 编号 | 不足描述 | 本文对策 |
|:---:|:---|:---|
| (1) | 三维环境模型创建不完备：大量研究将三维环境简化为"二维平面+固定高度"，损失了空间信息 | 构建真正的三维空间分布异构WSN模型 + 威胁度环境模型 |
| (2) | 已有算法存在局限性：A* 规划时间随环境规模急剧增长；智能优化算法路径不具备最优性 | 针对不同场景采用不同算法并做针对性改进 |
| (3) | 路径规划算法未与无人机自身特点结合：算法源于机器人领域，未利用无人机雷达探测等能力 | 将无人机雷达探测距离引入 BSTDAStar 算法 |

### 2.3 研究意义

无人机路径规划是无人机执行任务的**基础前提**，目标是在特定环境下为无人机计算出满足约束的最优/次最优飞行路径，使无人机能够回避威胁源，安全、可行地在规定时间内完成任务。良好的路径规划可节省时间、提升路径质量、减少无人机磨损、增加任务完成可能性。

## 三、核心方法与技术方案

### 3.1 三维环境建模

#### 3.1.1 空间分布异构 WSN 模型（场景一）

- **空间大小**：$a \times b \times c$，不含威胁源
- **设备**：$K$ 个异构无线传感器设备，三维空间中随机分布，位置固定
- **无人机**：单架四旋翼无人机，起点 $q_{start} = (x_s, y_s, z_s)$，终点 $q_{target} = (x_t, y_t, z_t)$
- **异构特性**：每个传感器设备的最大通信半径 $D_k$ 不同

**LoS 信道模型下的最大通信半径推导**：

$$L_{LoS,k} = 20 \log_{10}\left(\frac{4\pi f_c d_k}{c}\right) + \eta_{LoS}$$

$$P_k - L_{LoS,k} - P_n \geq \Gamma_k$$

$$D_k = \frac{c}{4\pi f_c} \cdot 10^{\frac{L_k - \eta_{LoS}}{20}}$$

**最大采集半径**：

$$R_k = D_k - \lambda V, \quad \forall k \in \{1, 2, ..., K\}$$

其中 $\lambda$ 为数据采集所需时间，$V$ 为无人机速度，$\lambda V$ 是无人机在 $\lambda$ 时间内离开设备的最大距离。

#### 3.1.2 威胁度环境模型（场景二）

**实体威胁度模型**（山体建模）：

$$z(x, y) = h_i \times e^{-[(x-a_i)/k_i]^2 - [(y-b_i)/k_i]^2}$$

$$T_{mountain} = \begin{cases} 0 & d > R_{UAV} \\ \frac{R_{UAV} - d}{R_{UAV}} & d \in [0, R_{UAV}] \\ 1 & d < 0 \end{cases}$$

**雷达威胁度模型**：

$$T_{Dr} = \begin{cases} 1 - \left(\frac{\|(x,y,z)-(x_{r0},y_{r0},z_{r0})\|}{R_{max}}\right)^4 & \|(x,y,z)-(x_{r0},y_{r0},z_{r0})\| \leq R_{max} \\ 0 & \text{其它} \end{cases}$$

**防空武器威胁度模型**：

$$T_{Dg} = \begin{cases} 0 & \|...\| > d_{max} \\ \frac{d_{max} - \|...\|}{d_{max} - d_{min}} & d_{min} \leq \|...\| \leq d_{max} \\ 1 & \|...\| < d_{min} \end{cases}$$

多威胁源叠加时，取**最大威胁度值**。

### 3.2 算法一：NTSP-TCO（数据采集路径规划）

> ★★★★☆ 创新性较高，将实际问题解耦为两个可求解的子问题

#### 3.2.1 优化问题形式化

$$(Pl): \min \sum_{i=1}^{K-1} X_k \cdot L_{i,i+1}$$

$$\text{s.t. } d_{p_k,(x_k,y_k,z_k)} \leq R_k, \quad \sum_{k=1}^K X_k = K, \quad \sum_{i=1}^{K-1} L_{i,i+1} \leq L_{max}$$
$$p_1 = q_{start}, \quad p_m = q_{target}$$

**问题特征**（区别于传统TSPN）：
- 起点和终点不同且预先指定
- 异构传感器设备通信半径各不相同

#### 3.2.2 阶段一：NTSP 问题（不返回旅行商问题）

**核心思想**：引入**虚拟节点** (virtual node)，将原始问题转化为包含 $K+3$ 个节点的闭合回路问题。

**节点转移代价矩阵** $C$ 的设计：

|  | virtual node | S | T | A | B |
|:---|:---:|:---:|:---:|:---:|:---:|
| virtual node | $\infty$ | 0 | $\infty$ | $\infty$ | $\infty$ |
| S | $\infty$ | $\infty$ | d(S,T) | d(S,A) | d(S,B) |
| T | 0 | d(T,S) | $\infty$ | d(T,A) | d(T,B) |
| A ($\in K$) | $\infty$ | $\infty$ | d(A,T) | $\infty$ | d(A,B) |
| B ($\in K$) | $\infty$ | $\infty$ | d(B,T) | d(B,A) | $\infty$ |

**关键约束**：
- virtual node $\to$ S 必为第二步（$[C]_{1,2} = 0$）
- T $\to$ virtual node 必为倒数第二步（$[C]_{3,1} = 0$）

**求解算法**：
1. 按行遍历代价最小值，获取初始桥接点路径
2. **启发式 2-opt 算法**：随机交换两点间路径，计算代价并与前值比较
3. 单轮交换次数定义：$\text{Num}_{exchange} = \frac{K \times (K+1)}{2}$

#### 3.2.3 阶段二：TCO 问题（三点凸优化）

**TCO 问题形式化**：

$$P_k(p_i, p_j): \min_{v} \|p_i - v\| + \|p_j - v\|$$
$$\text{s.t. } v \in R_{T(k)}$$

- 目标函数：线段 $p_i v$ 和 $v p_j$ 长度之和最小化
- 约束：采集位置 $v$ 必须在传感器设备 $T(k)$ 的球形采集区域内
- **凸性证明**：目标函数为两个凸函数之和（距离函数），约束区域为球体（凸集）

**两阶段迭代**：
1. **初优化**：$p_i$ = 前一路径点，$p_j$ = 终点 $q_{target}$，迫使路径趋向起点-终点直线
2. **细化优化**：$p_i$ = 路径点 $k-1$，$p_j$ = 路径点 $k+1$，多轮迭代收敛

采用 **CVXPY** 工具（Python）求解凸优化问题。

#### 3.2.4 路径评估函数

$$f_{eval} = \omega_l \left(1 - \frac{distance_P}{distance_{iniT}}\right) + \omega_n \left(1 - \frac{\text{size}(P, 1)}{K+2}\right)$$

其中 $\omega_l + \omega_n = 1$，实验取 $\omega_l = 0.7, \omega_n = 0.3$。

### 3.3 算法二：BSTDAStar（复杂环境路径规划）

> ★★★★★ 创新性高，五项改进全方位提升A*算法性能，且首次将无人机雷达探测功能引入路径规划

#### 3.3.1 传统 A* 算法核心公式

$$f(n) = g(n) + h(n)$$

#### 3.3.2 改进一：稀疏搜索机制

根据无人机当前飞行方向，结合**最大航向角** $\theta$（分解为最大偏航角 $\psi$ 和最大俯仰角 $\phi$），确定类锥体搜索曲面。

等距搜索点集计算公式：

$$P_{next} = \begin{cases} x + step \cdot \cos\left(\sigma - \frac{2j\phi}{M-1}\right) \cos\left(\theta - \frac{2i\psi}{M-1}\right) \\ y + step \cdot \cos\left(\sigma - \frac{2j\phi}{M-1}\right) \sin\left(\theta - \frac{2i\psi}{M-1}\right) \\ z + step \cdot \sin\left(\sigma - \frac{2j\phi}{M-1}\right) \end{cases}$$

其中 $\forall i, j \in 0, 1, ..., M-1$，$M$ 为截面划分数，$step$ 为搜索步长。

- **效果**：有效减少无用节点搜索，缩小搜索范围，满足偏航角/俯仰角约束
- **参数关系**：$step$ 增大 $\to$ 搜索加快但路径折线化；$M$ 增大 $\to$ 方向更全面但搜索时间增加

#### 3.3.3 改进二：自适应步长

两种触发情况：
1. **接近终点**：终点在步长范围内但不在可行搜索点集中 $\to$ 判断转弯角是否在搜索区域内
2. **接近障碍物**：可行搜索点集为空 $\to$ 逐步减小 step 直到获取可行点集或 step=0 失败

#### 3.3.4 改进三：错位异步双向搜索机制

论文比较了三种双向搜索策略：

| 机制 | 交汇类型 | 优点 | 缺点 |
|:---|:---:|:---|:---|
| 同步双向搜索 | list-to-list | 交汇点集中至少存在一个交汇点 | 交汇处易出现绕径 |
| 异步双向搜索 | node-to-list | 减少同步双向搜索的错位问题 | 复杂障碍物处仍可能绕径 |
| **错位异步双向搜索** | node-to-list | 提前判断交汇处障碍物，调整搜索进程 | -- （本文采用） |

#### 3.3.5 改进四：代价函数改进

$$f(n) = g(n) + \left(\frac{h_1(n)}{1+a} + \frac{a \cdot h_2(n)}{1+a}\right) + h_{threat}(n)$$

- $h_1(n)$：以路径终点 $D$ 为目标点的启发式函数（欧氏距离）
- $h_2(n)$：以对向搜索当前点为目标点的启发式函数（欧氏距离）
- $h_{threat}(n)$：当前节点所处位置的威胁度值
- 参数 $a$：平衡双向搜索中终点与对向前沿点的权重，$a=0$ 退化为单向搜索

**最优参数**：实验确定 $a = 1$。

#### 3.3.6 改进五：引入无人机雷达探测功能

$$h_{threat}(n) = h_{threat} + h_{detect}$$

- $h_{threat}$：威胁度地图中当前节点的威胁度值
- $h_{detect}$：父节点到当前节点方向上，探测距离内的节点威胁度值
- 若 $h_{threat} = 1$（即子节点为障碍物），则 $h_{detect} = 0$，直接转向
- **探测距离**：实验设为 3 倍步长

**创新意义**：首次将无人机自身搭载的雷达探测功能引入路径规划算法。

#### 3.3.7 路径评估函数

$$U_P = U_f \times (a \cdot U_l + b \cdot U_s + c \cdot U_o + d \cdot U_t)$$

| 分量 | 含义 | 公式 |
|:---|:---|:---|
| $U_f$ | 可行性效用 | 航向角是否超限，0或1 |
| $U_l$ | 路径长度效用 | $d_{manh}(S,D) / L$，越短越大 |
| $U_s$ | 平滑度效用 | $(\theta - \overline{angle}) / \theta$，转弯角越小越大 |
| $U_o$ | 威胁度效用 | $1 - \overline{thr} \times \max(thr)$，威胁越小越大 |
| $U_t$ | 规划时间效用 | $(Time - t) / Time$，越快越大 |

取值范围 $[0, 1]$，$U_P = 0$ 表示不可行，越大代表路径越好。$a + b + c + d = 1$。

## 四、实验设计与核心结果

### 4.1 NTSP-TCO 仿真实验

#### 实验设置

| 参数 | 值 |
|:---|:---|
| 仿真区域 | $1000m \times 1000m \times 500m$ |
| 起点 | $q_{start} = (100, 100, 100)$ |
| 终点 | $q_{target} = (900, 900, 400)$ |
| 传感器发射功率 | $P_k \in [1, 2, ..., 15]$ mW |
| 噪声功率 | $P_n = -130$ dBm |
| 信噪比阈值 | $\Gamma_k = 50$ dB |
| LoS附加损耗 | $\eta_{LoS} = 3$ dB |
| 载波频率 | $f_c = 2$ GHz |
| 无人机速度 | $V = 20$ m/s |
| 采集时间 | $\lambda = 2$ s |
| 最大通信半径 | $D_k = 84.50 \sim 327.29$ m |
| 最大采集半径 | $R_k \in [25, 50, ..., 275]$ m |

#### 核心实验结果

**表3-2：NTSP-TCO 与 TSP 算法路径指标比较**（K=25, $R_{max}=275m$, 15次平均）

| 算法 | 采集路径长度 (m) | 采集节点数 | 评估函数值 |
|:---|---:|---:|---:|
| TSP | 5997.83 | 25 | 0.0091 |
| **NTSP-TCO** | **3351.97** | **15** | **0.4418** |

- 路径长度缩短 **44.11%**
- 采集节点数减少 **40%**

**TCO阶段路径优化效果**（$R_{max} = 275m$）：
- 遍历路径长度：5524.63 m，采集点25个
- 优化路径长度：2704.61 m，采集点13个
- 路径长度缩短 **51.04%**，采集点减少 **48%**

#### 参数敏感性分析

| 参数 | 发现 |
|:---|:---|
| 设备数 K | 随K增大，路径长度稳定上升；重叠采集区域增多使采集点减少 |
| 采集半径 $R_{max}$ | 增大时路径长度整体下降（类似分簇采集效果） |
| NTSP交换次数 | 前期快速收敛，后期寻优时间长；最优范围约 [20, 35] 轮 |
| TCO迭代次数 | 约第7次迭代后收敛；增大采集半径时收敛值逼近起点-终点欧氏距离 |
