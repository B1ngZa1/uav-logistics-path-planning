## 2. 摘要与贡献 / Summary & Contributions

### 2.1 摘要

针对传统人工势场法（APF）易陷入**局部极小值**和**参数敏感**，以及深度强化学习在训练初期**收敛慢、样本效率低**等问题，本文提出融合PPO与改进势场的自适应路径规划算法（**PPO-APF**）。该算法采用**分层架构**：上层PPO网络根据局部感知信息自适应输出斥力系数、起效距离及速率调节系数；下层改进APF模型生成飞行指令。在障碍覆盖率约22%的复杂场景中，PPO-APF规划成功率达**97.33%**，显著优于改进APF（53.67%）与纯PPO（85%）。

### 2.2 核心贡献

| 编号 | 贡献 | 关键创新点 | 与本项目相关度 |
|---:|---|---|---|
| 1 | **分层控制架构（PPO-APF）** | 上层PPO输出势场参数 + 下层改进APF生成飞行指令，融合DRL自适应性与势场法稳定性 | ★★★★★ |
| 2 | **改进人工势场模型** | 引入目标距离因子 $\rho^n(P,P_{goal})$ 解决目标不可达问题；引入分段引力避免远距离速度失控 | ★★★★★ |
| 3 | **运动学约束下的方向修正与自适应速率** | 偏航角约束修正公式 + 速率调节系数 $\alpha$ 由PPO输出，狭窄通道减速、远离障碍加速 | ★★★★★ |
| 4 | **复合奖励函数设计** | 包含引导奖励 $R_{dis}$、平滑奖励 $R_{curve}$、参数稳定性惩罚 $R_{params}$、安全奖励 $R_{threat}$、稀疏事件奖励 $R_{event}$ | ★★★★★ |

## 3. 核心方法 / Core Methods

### 3.1 系统架构：分层控制

```
┌─────────────────────────────────────────────────────┐
│               PPO-APF 分层控制架构                    │
├─────────────────────────────────────────────────────┤
│  参数决策层（上层）                                    │
│  ┌─────────────────────────────────────────────┐    │
│  │  PPO策略网络 π_θ                              │    │
│  │  输入: 扇区直方图(45维) + 无人机状态(4维)       │    │
│  │  输出: (k_rep, ρ_0, α) — 离散化动作             │    │
│  └─────────────────────────────────────────────┘    │
│           ↓ 势场参数                                  │
│  路径生成层（下层）                                    │
│  ┌─────────────────────────────────────────────┐    │
│  │  改进APF模型                                   │    │
│  │  输入: F_att(分段引力) + F_rep(目标距离因子)     │    │
│  │  处理: 偏航角约束修正 + 自适应速率调节            │    │
│  │  输出: 飞行指令 (ψ_next, v_next)                │    │
│  └─────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────┘
```

**核心思想**：PPO负责"决策"（调哪些参数），APF负责"执行"（计算合力与轨迹），各司其职。

### 3.2 无人机运动学约束

理想化一阶运动学模型：

$$\dot{q} = v, \quad q \in \mathbb{R}^2, \; v \in \mathbb{R}^2 \tag{1}$$

两类硬性约束：

1）**最大飞行速率约束**：$\|v\| \leq v_{max}$

2）**最大偏航角速度约束**：

$$|\psi_{t+1} - \psi_t| \leq \Delta\psi_{max} \tag{2}$$

其中 $\psi_t$ 为 $t$ 时刻速度方向角，$\Delta\psi_{max}$ 为单位时间最大转角。

### 3.3 改进人工势场模型

#### 3.3.1 分段引力函数

$$F_{att}(P) = \begin{cases} -k_{att}(P - P_{goal}), & \rho(P,P_{goal}) \leq d_{th} \\ -d_{th} \cdot k_{att} \frac{P - P_{goal}}{\rho(P,P_{goal})}, & \rho(P,P_{goal}) > d_{th} \end{cases} \tag{4}$$

**设计目的**：避免长距离下引力过大导致速度失控。$k_{att}$ 固定为3以减少动作空间维度。

#### 3.3.2 改进斥力场（引入目标距离因子）

斥力分解为背离障碍物的排斥力 $F_{rep1}$ 和指向目标的引力分量 $F_{rep2}$：

$$F_{rep} = F_{rep1} + F_{rep2} \tag{5}$$

$$F_{rep1} = k_{rep} \left( \frac{1}{\rho(P,P_{obs})} - \frac{1}{\rho_0} \right) \frac{\rho^n(P,P_{goal})}{\rho^2(P,P_{obs})} \nabla\rho(P,P_{obs}) \tag{6}$$

$$F_{rep2} = -\frac{n}{2} k_{rep} \left( \frac{1}{\rho(P,P_{obs})} - \frac{1}{\rho_0} \right)^2 \rho^{n-1}(P,P_{goal}) \nabla\rho(P,P_{goal}) \tag{7}$$

其中：
- $\rho(P,P_{obs})$：无人机到障碍物距离
- $\rho_0$：斥力起效距离（由PPO自适应输出）
- $k_{rep}$：斥力系数（由PPO自适应输出）
- $\rho^n(P,P_{goal})$：目标距离因子，保证接近目标时斥力合力趋于0，实现全局收敛

**关键参数影响分析**：

| 参数 | 增大效果 | 减小效果 |
|---|---|---|
| $k_{att}/k_{rep}$ | 路径平直，趋向目标动力强，但障碍密集区碰撞风险高 | 避障安全，但可能过早绕行、路径冗余 |
| $\rho_0$ | 提前绕障、路径更平滑，但易陷入局部最小值 | 贴近障碍物、可穿越狭窄通道，但风险上升 |

#### 3.3.3 偏航角约束修正

$$\psi_{next} = \begin{cases} \psi_{des}, & |\psi_{des} - \psi_{cur}| \leq \Delta\psi_{max} \\ \psi_{cur} + \text{sgn}(\psi_{des} - \psi_{cur}) \cdot \Delta\psi_{max}, & |\psi_{des} - \psi_{cur}| > \Delta\psi_{max} \end{cases} \tag{8}$$

#### 3.3.4 自适应速率调节

$$v_{next} = \alpha \cdot v_0 \tag{9}$$

其中 $\alpha$ 由PPO策略网络输出。接近密集障碍物时降低速度确保安全通过；远离障碍物时提高速度加快飞行。

### 3.4 马尔可夫决策过程建模

**状态空间 $S$**（总维度49）：

| 分量 | 维度 | 说明 |
|---|---|---|
| $s_t^{env}$ 环境感知 | 45 | 扇区直方图：前方180°视场分为45个子扇区，记录各扇区归一化障碍物距离 $h_i$ |
| $s_t^{uav}$ 自身状态 | 4 | 当前速度单位向量(2维) + 目标方向单位向量(2维) |

**动作空间 $A$**：

$$a_t = (k_{rep,t}, \; \rho_{0,t}, \; \alpha_t)$$

连续动作空间**离散化**，各参数在预设范围内选取（如 $k_{rep} \in [3, 12]$），策略网络输出多维离散索引。

**奖励函数 $R$**：

$$R_t = \lambda_1 R_{dis} + \lambda_2 R_{time} + \lambda_3 R_{curve} + \lambda_4 R_{threat} + \lambda_5 R_{params} + R_{event} \tag{10}$$

| 分项 | 含义 | 设计目的 |
|---|---|---|
| $R_{dis}$ | 引导奖励：相邻时刻目标距离差 | 鼓励趋近目标 |
| $R_{time}$ | 时间惩罚 | 鼓励高效完成 |
| $R_{curve}$ | 速度方向突变惩罚 | 抑制路径抖动 |
| $R_{threat}$ | 进入障碍物威胁半径时惩罚 | 安全保障 |
| $R_{params}$ | 参数序列方差惩罚 | 抑制参数跳变导致的轨迹抖动 |
| $R_{event}$ | 到达+100 / 碰撞或超时-100 | 稀疏事件奖励 |

### 3.5 PPO训练细节

**PPO裁剪目标函数**：

$$L_{CLIP}(\theta) = \mathbb{E}_t \left[ \min\left( r_t(\theta) \hat{A}_t, \; \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon) \hat{A}_t \right) \right] \tag{11}$$

**网络架构**：Actor-Critic架构
- Actor网络：输出3个参数（$k_{rep}$, $\rho_0$, $\alpha$）的概率分布
- Critic网络：评估状态价值

**学习模式**：采样-更新在线学习模式，利用广义优势估计（GAE）更新网络参数。

### 4.3 训练过程对比（PPO-APF vs PPO）

| 指标 | PPO-APF | PPO（基准） |
|---|---|---|
| 初始奖励 | 约-10（冷启动优势） | 约-130 |
| 训练稳定性 | 全程平滑稳定、方差小 | 明显震荡，750k步附近性能坍塌 |
| 收敛步数 | 约1000k步 | 未完全收敛 |
| 收敛奖励 | 约125 | 约100且持续波动 |

**关键发现**：引入人工势场显著提升了探索效率、稳定性及最终性能。势场引导减少了无效探索，使PPO-APF具备"冷启动"优势。

### 4.4 测试集性能对比（300张地图）

| 指标 | APF-Ge | PPO-APF | PPO | A* |
|---|---|---|---|---|
| **成功率/%** | 53.67 | **97.33** | 85 | 100 |
| **平均长度/m** | 166.842 | 175.631 | 185.427 | 151.593 |
| **平均曲率/rad** | 16.436 | **17.614** | 26.742 | 11.403 |

**详细分析**：

- **成功率**：PPO-APF（97.33%）>> APF-Ge（53.67%），接近A*（100%）。深度强化学习动态调节势场参数有效克服了局部极小值问题。
- **路径长度**：PPO-APF较A*仅增加约15.8%，优于PPO。APF-Ge长度虽短，但仅基于简单场景成功案例，不具备广泛代表性。
- **路径平滑度**：PPO-APF（17.614 rad）与APF-Ge（16.436 rad）相当，显著优于PPO（26.742 rad）。融合算法继承了势场法平滑路径的优势。

### 4.5 自适应机理分析

**场景一：狭窄通道穿越（12-18时间步）**
- 策略网络主动调低斥力起效距离 $\rho_0$ 并减小速率系数 $\alpha$
- 降低 $\rho_0$ 减少通道两侧合斥力大小和影响距离，使无人机得以"挤入"通道
- 穿越完成后速度迅速恢复
- 固定参数的APF-Ge陷入局部最小点，无法穿越

**场景二：连续障碍规避（44-56时间步）**
- 策略网络将 $\rho_0$ 持续维持在较高水平
- 使无人机在更远处感知障碍物横向斥力分量，"早发现、早反应"
- 提前开始平滑绕行，避免路径抖动

**场景三：复杂障碍群避障（14-22, 51-57时间步）**
- 靠近障碍物时速度方向与出口方向夹角较大
- 策略网络降低速度并动态调节斥力系数
- 安全避开障碍物并将速度方向调整至出口方向
- 固定参数APF-Ge难以应对复杂障碍物群

## 5. 关键发现与启示 / Key Findings & Implications

### 5.1 算法设计启示

| 发现 | 对本项目的启示 |
|---|---|
| 分层架构（PPO调参+APF执行）比端到端PPO更优 | 本项目L3/L4层可借鉴此分层思想：PPO输出策略参数，底层控制器执行 |
| 势场引导提供"冷启动"优势，初始奖励差距巨大 | 在奖励稀疏的配送环境中，引入先验势场可显著加速早期训练 |
| 复合奖励含参数稳定性惩罚 $R_{params}$ | 本项目奖励函数设计应考虑动作/参数平滑性，避免路径抖动 |
| 连续动作离散化保证训练稳定性 | 对L3层Box(3)连续动作空间，可考虑混合离散-连续方案 |
| 扇区直方图编码环境感知 | 本项目可借鉴此方法编码障碍物信息，适配180°前向感知 |

### 5.2 与本项目的对比

| 维度 | 胥斌2026 (PPO-APF) | 本项目（无人机配送PPO） |
|---|---|---|
| 任务类型 | 点到点避障路径规划 | 多订单配送调度 |
| 环境 | 2D, 100x100m, 圆形障碍物 | 2D/3D, 四区武汉城市, 建筑+禁飞区 |
| 动作空间 | 离散化（3个参数） | L3: Box(3)连续, L4: Box(4)连续 |
| 状态空间 | 49维（扇区直方图+自身状态） | 多维（位置+订单状态+环境编码） |
| 核心创新 | PPO调势场参数 | CTDE多机协同+分层规划器 |
| 协同能力 | 单机 | L4: 多机协同 |

### 5.3 可借鉴的技术点

1. **势场作为先验引导**：在本项目L3/L4层训练中，可将建筑碰撞势场融入环境动力学，为PPO提供初始避障能力
2. **速率自适应调节**：配送场景中靠近建筑物时减速、开阔区域加速，可提升安全性与效率
3. **参数稳定性惩罚**：在奖励函数中加入动作序列方差惩罚，抑制配送轨迹抖动
4. **扇区直方图感知**：适用于本项目前向障碍物编码，可替代原始坐标输入降低维度
