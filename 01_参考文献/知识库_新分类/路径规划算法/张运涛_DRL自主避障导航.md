## 2. 研究问题与动机

### 2.1 核心问题

基于视觉的无人机3D自主避障导航。传统Visual SLAM方法依赖大量计算资源构建场景地图，不适用于动态、开放、未知的室外环境，缺乏自主性。

### 2.2 现有DRL方法的四大缺陷（作者识别）

| 编号 | 缺陷 | 描述 |
|------|------|------|
| (1) | 单目标局限 | 经典DRL算法的导航目标隐含在神经网络参数中，不同目标需重新训练，无法利用目标间的共同特征 |
| (2) | 部分可测性 | 仅依赖当前第一人称视觉观测无法准确推断环境状态，避障策略与导航策略产生冲突，导致局部循环 |
| (3) | 稀疏奖励 | 到达目标/碰撞的二元反馈过于稀疏，智能体在训练初期难以获得有效信号，导致收敛困难 |
| (4) | 探索-利用困境 | 有效探索缺乏导致学不到控制策略，过度探索导致收敛过慢、计算资源浪费 |

## 3. 核心方法与贡献

### 3.1 贡献一：目标驱动的MDP建模 + 动态相对目标（第三章）

**问题建模：** 将无人机避障导航问题建模为**目标驱动的马尔可夫决策过程（Goal-Conditioned MDP）**，决策时同时考虑当前观测和导航目标。

**状态空间：**
- 视觉观测 $o_t$：前置摄像头深度图（72x128）
- 位置信息：偏转角 $\text{yaw}_t$，位置 $(x_t, y_t)$
- 目标信息：坐标 $(x_g, y_g)$

**动态相对目标（核心创新）：**

用逐步（step-wise）的动态相对距离替代逐情节（episode-wise）的全局绝对目标。令 $g_t = (x_g^t, y_g^t, \text{yaw}_g^t)$ 为无人机当前位置与导航目标之间的相对值，使不同目标的轨迹共享相同路径特征（如图3-1所示，$\tau_0$与$\tau_1$共享路径，$\tau_1$与$\tau_2$共享控制序列）。

**动作空间（离散3动作）：**

| 动作 | 描述 |
|------|------|
| 左转 | 以 $30°/s$ 速度左转 1 秒 |
| 右转 | 以 $30°/s$ 速度右转 0.7 秒 |
| 直行 | 以 $2\text{m/s}$ 速度前进 1 秒 |

> 注：左右转角度不同，防止动作互相抵消导致无人机困在原地。

**非稀疏奖励函数：**

$$R(s_t, a_t, s_{t+1}) = 0.01 \cdot r_{\text{trans}} - 3 \cdot r_{\text{collision}} + 2 \cdot r_{\text{tgt}} + r_{\text{step}}$$

| 分量 | 定义 | 作用 |
|------|------|------|
| $r_{\text{trans}}$ | $\sqrt{(x_g-x_t)^2+(y_g-y_t)^2} - \sqrt{(x_g-x_{t+1})^2+(y_g-y_{t+1})^2}$ | 距离变化的密集反馈 |
| $r_{\text{collision}}$ | 碰撞指示变量 $c_t \in \{0,1\}$ | 碰撞惩罚 |
| $r_{\text{tgt}}$ | 到达目标指示变量 $d_t \in \{0,1\}$ | 目标奖励 |
| $r_{\text{step}}$ | $-0.01$ | 步数惩罚，打破转向循环 |

**基础算法：** DQN + 离散SAC（DSAC），结合TD误差优先经验回放（PER）

### 3.2 贡献二：历史记忆增强的DRL算法（第四章）

**动机：** 解决部分可测环境下避障策略与导航策略冲突导致的局部循环问题。

**记忆结构设计（双记忆模块）：**

**(a) 动作记忆 $c_t^a$：** 保存最近 $K$ 步历史动作 $A_t = (a_{t-1}, ..., a_{t-K})$，通过全连接网络提取特征：
$$c_t^a = W_{ca} A_t + b_{ca}$$

**(b) 空间记忆 $M_t^s$：** 由历史观测与历史动作联合构建。每个记忆单元 $m_i^s = (f_{t-i}^o \| f_{t-i}^a)$，其中观测特征 $f^o$ 由CNN提取，动作特征：
$$f_i^a = W_a(E_a \cdot \text{onehot}(a_i)) + b_{ma}$$

**注意力机制整合：** 使用基于MLP的注意力机制对空间记忆加权整合：
$$c_t^s = \sum_{i=t-K}^{t-1} \alpha_i M_t^i, \quad \alpha_i = \frac{e(e_i)}{\sum_j e(e_j)}$$

其中 $e_i = W^T \tanh(W_\alpha q_t + U_\alpha m_i + b_\alpha)$，$q_t = W_q(f_t^o \| f_t^g)$ 为当前观测与目标的融合特征。

**状态特征融合：**
$$f_t^s = c_t^s \| c_t^a \| f_t^o \| f_t^g$$

**动作惩罚 $r_{\text{act}}$：** 当连续纯转向动作长度 $l_{lr} \geq 5$ 时施加 $-0.05$ 的惩罚，引导无人机脱离困境。

**改进奖励函数：**
$$R(s_t, a_t, s_{t+1}) = 0.01 \cdot r_{\text{trans}} - 3 \cdot r_{\text{collision}} + 2 \cdot r_{\text{tgt}} + r_{\text{step}} + r_{\text{act}}$$

**衍生算法：** MEDQN（记忆增强DQN）、MEDSAC（记忆增强离散SAC）

### 3.3 贡献三：高斯分布探索增强的DRL算法（第五章）

**核心思想：** 将值函数建模为高斯分布而非确定均值，利用分布方差实现自动探索。

**高斯分布值函数建模：** 假设 $Z^\pi(s,a) \sim \mathcal{N}(Q^\pi(s,a), D^\pi(s,a))$，其中 $Q^\pi$ 为均值，$D^\pi$ 为方差。

**方差递推关系（贝尔曼方程的方差形式）：**
$$D^\pi(s,a) = \gamma^2 D^\pi(s_{t+1}, a_{t+1})$$

**EM距离（Wasserstein距离）优化：** 两个高斯分布 $\mathcal{N}_1 = \mathcal{N}(Q^\pi(s_t,a_t), D^\pi(s_t,a_t))$ 与 $\mathcal{N}_2 = \mathcal{N}(r+\gamma Q^\pi(s_{t+1},a_{t+1}), \gamma^2 D^\pi(s_{t+1},a_{t+1}))$ 之间的EM距离为：

$$\text{EM}(\mathcal{N}_1, \mathcal{N}_2) = (Q^\pi(s_t,a_t) - (r+\gamma Q^\pi(s_{t+1},a_{t+1})))^2 + D^\pi(s_t,a_t) + \gamma^2 D^\pi(s_{t+1},a_{t+1}) - 2\sqrt{\gamma^2 D^\pi(s_{t+1},a_{t+1}) D^\pi(s_t,a_t)}$$

**自动探索策略：** 替代 $\epsilon$-greedy，通过值分布采样选择动作：
$$a_t = \arg\max_a \left( x \cdot \sqrt{D(s,a|\theta)} + Q(s,a|\theta) \right), \quad x \sim \mathcal{N}(0,1)$$

随着训练收敛，方差自动缩小，探索力度自动降低，无需额外超参数。

**衍生算法：** GE-DQN、GE-DSAC、GE-MEDQN、GE-MEDSAC

## 4. 实验设计与结果

### 4.1 实验环境

| 项目 | 详情 |
|------|------|
| 仿真平台 | AirSim（基于虚幻引擎）+ SimpleFlight飞控 |
| 简单环境 | Blocks（几何图形组成，用于算法实现） |
| 复杂环境 | Neighborhood（建筑物、道路、树木、湖泊等真实场景） |
| 导航距离 | 终点在起点为中心半径100米的圆上随机选取 |
| 到达判定 | 距目标6米内 |
| 步数上限 | 200步 |
| 观测输入 | 72x128深度图 |
| 服务器 | Ubuntu 18.04, 2x Xeon Silver 4116, 256GB RAM, 4x RTX 2080Ti |
| 深度学习框架 | PyTorch |

| Conv2 | 3x3 | 2x2 | 64 | ReLU |
| Conv3 | 3x3 | 2x2 | 128 | ReLU |

| Conv5 | 1x1 | 1x1 | 64 | ReLU |

### 4.4 评价指标

| 指标 | 缩写 | 定义 |
|------|------|------|
| 平均累计奖励 | MER | 多次导航任务的累计奖励均值 |

| 收敛步长 | CS | 达到特定成功率所需的参数更新次数 |

### 4.5 实验结果

#### 实验1：动态相对目标 vs 全局绝对目标

| 指标 | DQN_abs（绝对目标） | DQN_rlt（相对目标） |

| Neighborhood 最高SR | ~20% | ~60% |
| Blocks 最大MER | 负值 | ~2.0 |
| Neighborhood 最大MER | 负值 | ~2.0 |

**结论：** 动态相对目标使成功率提升约3倍。

## 5. 论文评级与评价

### 5.1 综合评级：★★★★☆ (4/5)

### 5.2 分项评价

| 维度 | 评级 | 说明 |
|------|------|------|
| 问题定义 | ★★★★★ | 清晰识别DRL在无人机导航中的四大缺陷，问题层次分明 |
| 方法创新 | ★★★★☆ | 动态相对目标有巧思；记忆模块设计中规中矩；高斯探索方法理论扎实 |
| 理论深度 | ★★★★☆ | 高斯分布值函数的贝尔曼方程推导完整，EM距离优化有数学严谨性 |
| 实验充分性 | ★★★★☆ | 双环境+多算法对比+Atari泛化验证，但缺少真实无人机实验 |
| 写作质量 | ★★★★★ | 结构清晰，公式推导详尽，伪代码完整，双语文献综述全面 |
| 实用价值 | ★★★★☆ | 仿真验证充分，但未涉及Sim-to-Real迁移，未来工作已识别此问题 |

### 5.3 优势

1. **系统性强**：三篇工作层层递进（建模->记忆->探索），每篇都解决了前述缺陷列表中的一个或多个问题
2. **高斯探索方法设计优雅**：不需要额外超参数，方差随训练自动衰减，自动平衡探索-利用
3. **实验设计合理**：Blocks简单环境验证可行性 + Neighborhood复杂环境验证泛化 + Atari验证通用性
4. **奖励函数设计有工程直觉**：左转/右转不对称设计防止动作抵消；步数惩罚打破转向循环

### 5.4 局限

1. **环境离散化过度**：仅3个离散动作（左转/右转/直行），未考虑连续动作空间
2. **单智能体**：未涉及多无人机协同导航
3. **固定高度飞行**：回避了3D空间的高度维度问题
4. **无Sim-to-Real验证**：仅在AirSim仿真中测试，未部署到真实无人机
5. **高斯分布的单峰假设**：同一目标可能存在多条等价路径（多模态策略），单峰高斯难以拟合（作者已在展望中承认）

## 6. 与本项目的关联

### 6.1 直接相关性

本文与本项目（基于强化学习的无人机外卖配送调度系统）在**避障导航**核心问题上高度相关：

| 对比维度 | 张运涛论文 | 本项目 |
|----------|-----------|--------|
| 问题定义 | 单机避障导航 | 多机配送调度+路径规划 |
| 环境 | 3D AirSim（深度图） | 2D/3D网格+OSM建筑 |
| 动作空间 | 离散3动作 | L1: Discrete(4), L2: Discrete(8), L3/L4: Box(3/4) |
| 算法 | DQN, DSAC, MEDQN, MEDSAC, GE-* | Q-learning, SARSA, MC, DQN, A2C, PPO+CTDE |
| 目标机制 | 动态相对目标（Goal-Conditioned MDP） | 多订单携带+时间窗口 |
| 多智能体 | 无 | CTDE框架（集中训练分散执行） |

### 6.2 可借鉴的设计思路

1. **动态相对目标**：本项目的多目标导航（多个外卖目的地）可借鉴Goal-Conditioned MDP思想，将订单目标编码进状态空间
2. **非稀疏奖励函数设计**：距离变化奖励 $r_{\text{trans}}$ 的思路可直接用于本项目的奖励函数设计（参见 `reward_function_design.md`）
3. **记忆增强方法**：在部分可观测的城市峡谷环境中，历史记忆可帮助无人机避免重复路径
4. **高斯探索方法**：GE-DQN的无参数自动探索机制可集成到本项目的DQN实现中
5. **左转/右转不对称动作设计**：在本项目的8方向动作空间中也应考虑动作之间的对称性

### 6.3 差异化方向

本文是**单机导航**问题，本项目需扩展到：
- 多机协同（CTDE框架）
- 订单分配（多目标优化）
- 时间窗口约束
- 动态禁飞区
- 能耗约束
