## 二、摘要与核心贡献

### 摘要

本文致力于研究一个可以快速准确且能同时应用于不同场景的反应式避障系统。针对避障问题，提出了两种方法：（1）基于自我动态空间转换（Ego Dynamic Space Transform, EDST）的改进算法，利用单目深度估计的深度图作为输入，融合深度误差选择最优航点；（2）基于 Double DQN 的端到端避障系统，直接从深度图输出执行动作。针对深度强化学习的域漂移问题，提出采用对抗判别的域适应方法（Adversarial Discriminative Domain Adaptation, ADDA），通过判别网络引导映射网络将目标场景特征映射到源场景特征空间，复用源场景决策网络实现跨场景避障。实验表明，迁移学习方法相比微调网络可大幅缩短训练时间，并在真实场景无人机避障中验证了实用性。

### 核心贡献

1. **提出改进的 EDST 避障算法**：首次将单目深度估计误差融合到自我动态空间的计算中，通过场景结构非完整率 $SI_k$ 判断深度估计可靠性，计算更安全的有效行驶距离，并在真实无人机上验证。
2. **设计面向避障的密集回报函数**：基于 Double DQN 算法设计单步更新回报函数，通过差异化奖励引导机器人前进而非原地转圈，避免局部最优。
3. **提出基于 ADDA 的跨场景迁移方法**：利用对抗域适应思想，通过判别网络引导目标域特征映射至源域特征空间，无需目标域标签即可完成迁移，训练时间仅需 2 小时（finetuning 需 18.5 小时）。
4. **搭建真实场景无人机避障系统**：在环形走廊和随机障碍两个真实场景中验证了算法的实用性。

## 三、核心方法

### 3.1 改进的 EDST 避障算法

#### 3.1.1 自我动态空间（EDS）

将机器人运动状态约束转化为空间表示。有效行驶距离由障碍物距离、当前速度、最大减速度和控制周期共同决定：

$$d_{eff} = d_{obs} - d_{brake} = d_{obs} - \left(v \cdot T - \frac{a \cdot T^2}{2}\right)$$

其中 $d_{obs}$ 为障碍物距离，$d_{brake}$ 为最短刹车距离，$v$ 为行驶速度，$T$ 为控制周期，$a$ 为最大减速度。

#### 3.1.2 深度估计与误差建模

采用 Garg 等人的单目深度估计网络，输入单张 RGB 图预测深度图。训练时利用双目图像的视差关系：

$$D(x) = \frac{f \cdot B}{d(x)}$$

其中 $f$ 为焦距，$B$ 为基线长度，$d(x)$ 为逆深度，$D(x)$ 为视差。重建损失为：

$$\mathcal{L}_{recon} = \|I_w(x) - I_1(x)\|$$

**深度误差的关键发现**：深度估计误差与场景结构完整性密切相关。利用 mean-shift 聚类将深度图分为 $K$ 个类，定义场景结构非完整率：

$$SI_k = \max\left\{\frac{w_k}{W}, \frac{h_k}{H}\right\}$$

其中 $w_k, h_k$ 为第 $k$ 类边界框宽高，$W, H$ 为图像宽高。若 $SI_k < T_{SI}$ 则深度误差可近似为常数 $e = 0.45$；否则认为深度估计不可靠。

#### 3.1.3 改进的有效行驶距离与航点选择

融合深度误差后的有效行驶距离：

$$d_{eff} = \begin{cases} Q(d_{obs} - e - (v \cdot T - \frac{a \cdot T^2}{2})) & \text{if } SI_k < T_{SI} \\ null & \text{otherwise} \end{cases}$$

航点选择的代价函数：

$$C_k = \frac{r_k}{d_k \cdot \rho_k}$$

其中 $r_k$ 为第 $k$ 类区域最大内切圆半径，$d_k$ 为圆心到光轴距离，$\rho_k$ 为到投影平面中心距离。改进的选择策略：

$$k = \max C_k = \max \frac{1}{2}\left(\text{sgn}(d_k^s - S) + 1\right) \cdot \frac{r_k}{\rho_k}$$

最终控制速度计算：$v_i = \frac{d_i}{T}, \quad i \in \{x, y, z\}$

### 3.2 基于 Double DQN 的避障算法

#### 3.2.1 网络架构

输入为 $80 \times 80$ 深度图，经三层卷积层特征提取 + 五层全连接层决策，输出 5 个离散动作的 Q 值。

| 层名称 | 卷积核/神经元数 | 步长 |
|:---|:---|:---|
| conv1 | (8, 8, 32) | (4, 4) |
| conv2 | (4, 4, 64) | (2, 2) |
| conv3 | (3, 3, 64) | (1, 1) |
| fc1 | 512 | - |
| fc2 | 512 | - |
| fc3 | 512 | - |
| fc_V | 1 | - |
| fc_A | 5 | - |

#### 3.2.2 Double DQN 损失函数

解决 DQN 的过估计问题，通过目标网络预测动作，在线网络评估价值：

$$\mathcal{L}(\theta) = \left(r_t + \gamma \cdot Q^*(s_{t+1}, a_{t+1}|\theta') - Q(s_t, a_t|\theta)\right)^2$$

$$a_{t+1} = \arg\max Q^*(s_{t+1}, a_{t+1}|\theta')$$

其中 $\theta$ 为在线网络参数，$\theta'$ 为目标网络参数。

#### 3.2.3 回报函数设计

采用单步更新方式，鼓励前进、惩罚碰撞：

$$\text{reward} = \begin{cases} 0.035 & \text{if } a = 0 \text{ or } 4 \text{ and } t = 0 \text{（急转弯）} \\ 0.038 & \text{if } a = 1 \text{ or } 3 \text{ and } t = 0 \text{（缓转弯）} \\ 0.040 & \text{if } a = 2 \text{ and } t = 0 \text{（直行，最大奖励）} \\ -10 & \text{if } t = 1 \text{（碰撞，严重惩罚）} \end{cases}$$

其中 $a$ 为动作编号，$t$ 为碰撞标志位。动作对应速度：

| 动作 | 线速度 $v$ | 角速度 $w$ | 含义 |
|:---:|:---:|:---:|:---|
| 0 | 0.5 m/s | -0.5 rad/s | 右急转 |
| 1 | 0.7 m/s | -0.3 rad/s | 右缓转 |
| 2 | 1.0 m/s | 0.0 rad/s | 直行 |
| 3 | 0.7 m/s | 0.3 rad/s | 左缓转 |
| 4 | 0.5 m/s | 0.5 rad/s | 左急转 |

### 3.3 基于 ADDA 的对抗域适应迁移

#### 3.3.1 问题定义

源域数据 $X_s$，目标域数据 $X_t$，源域特征提取网络 $M_s$，目标域特征提取网络 $M_t$。目标是调整 $M_t$ 使 $M_t(X_t)$ 的特征空间逼近 $M_s(X_s)$ 的特征空间。

#### 3.3.2 判别器损失

判别器 $D$ 区分特征来自源域还是目标域（二分类），采用交叉熵损失：

$$L_D(X_s, X_t, M_s, M_t) = -\mathbb{E}[\log D(M_s(X_s))] - \mathbb{E}[\log(1 - D(M_t(X_t)))]$$

优化目标：$\min L_D$（训练判别器）

#### 3.3.3 映射网络损失

优化 $M_t$ 时冻结判别器参数，通过反转标签使目标域特征逼近源域特征：

$$\min L_M(X_t, M_t) = -\mathbb{E}[\log(D(M_t(X_t)))]$$

训练完成后，复用源域决策网络在目标域直接输出动作命令，实现零标签迁移。

#### 3.3.4 系统架构总览

整体迁移流程：
1. **源域训练**：在源场景中用 Double DQN 训练完整的特征提取 + 决策网络
2. **域适应训练**：用 ADDA 训练目标域特征提取网络 $M_t$，使其输出特征逼近源域特征空间
3. **迁移推理**：目标域深度图 -> $M_t$ 提取特征 -> 复用源域决策网络 -> 输出避障动作

## 四、实验结果

### 4.1 实验设置

- **仿真环境**：Gazebo 仿真器，训练场景 + 2个相似场景 + 1个目标场景（结构差异较大）
- **仿真机器人**：TurtleBot
- **真实机器人**：Parrot AR Drone 2.0，前置单目摄像头 93° FOV, 640x360，WiFi 传输图像至主机，主机处理后回传控制命令，20Hz 采集频率
- **评价指标**：最长避障距离、训练时间、鲁棒性

### 4.2 EDST vs Double DQN 避障距离对比

| 场景 | EDST | Double DQN |
|:---|:---:|:---:|
| 训练场景（障碍密集） | 28.262 m | > 100 m |
| 相似场景1（障碍移位） | > 100 m | > 100 m |
| 相似场景2（新搭建） | > 100 m | > 100 m |
| 目标场景（结构差异大） | > 100 m | 27.406 m |

**分析**：
- EDST 作为基于规则的方法，在大多数场景下表现稳定，但密集障碍场景（"缝隙"结构）需手动调参
- Double DQN 在训练场景和相似场景表现优异，但泛化到差异较大场景时避障距离骤降至 27.406 m
- 这验证了深度强化学习的域漂移问题

### 4.3 迁移学习训练时间对比

| 方法 | 源场景 | 目标场景 |
|:---|:---:|:---:|
| Double DQN（从头训练） | 85 h | - |
| Double DQN + finetuning | - | 18.5 h |
| Double DQN + ADDA | - | **2 h** |

**分析**：ADDA 迁移方法仅需 2 小时即可完成目标场景适配，相比 finetuning（18.5 h）节省 89% 训练时间。

### 4.4 迁移后避障距离对比

| 方法 | 目标场景避障距离 |
|:---|:---:|
| EDST | > 100 m |
| Double DQN（直接测试） | 27.406 m |
| Double DQN + finetuning | > 100 m |
| Double DQN + ADDA | > 100 m |

**结论**：ADDA 迁移后避障距离与 finetuning 相当（均 > 100 m），远超直接测试的 27.406 m，证明域适应方法在大幅缩短训练时间的同时保持了避障性能。

### 4.5 真实场景验证

在两个真实场景中测试了基于强化学习和迁移学习的避障系统：
- **场景1**：环形走廊环境
- **场景2**：随机摆放障碍物的环境

系统流程：Ardrone 前视摄像头采集 RGB 图 -> WiFi 传至主机 -> Laina 单目深度估计网络预测深度图 -> 避障算法计算动作 -> WiFi 回传控制命令

实验表明无人机在两个真实场景中均有较好的避障能力。

## 五、评价与局限

### 优势

| 维度 | 评价 | 评级 |
|:---|:---|:---:|
| 创新性 | 首次将深度估计误差融合到 EDS 计算；ADDA 用于避障域迁移属较新尝试 | ★★★★☆ |
| 方法完整性 | EDST（规则）+ Double DQN（学习）+ ADDA（迁移）三层递进，逻辑清晰 | ★★★★★ |
| 实验充分性 | 多场景对比 + 真实无人机验证，训练时间和避障距离双重评价 | ★★★★☆ |
| 工程价值 | 真实无人机系统搭建，主从机架构可直接复用 | ★★★★☆ |
| 理论深度 | MDP、Double DQN、ADDA 损失函数推导完整，但缺乏收敛性理论分析 | ★★★☆☆ |

### 局限性

1. **动作空间离散化**：Double DQN 只支持离散动作输出（5档速度），无法处理精细连续控制需求
2. **场景迁移范围有限**：ADDA 对差别特别大的场景仍然难以收敛
3. **回报函数人工设计**：需要人工定义显式回报函数，难以迁移到更复杂的避障任务
4. **深度图输入单一**：仅使用深度图作为观测，未融合 RGB、语义等多模态信息
5. **缺乏定量对比**：未与 DDPG 等连续动作空间算法对比，也未与其他域适应方法（如 DANN、DAN）做系统对比

### 对本项目的启示

| 维度 | 与无人机配送项目的关联 |
|:---|:---|
| Double DQN 避障 | 可作为 L2 层级（2D离散动作）的基础参考算法，其回报函数设计思路可借鉴 |
| EDST 航点选择 | 规则方法作为 RL 的补充/回退策略，可参考其代价函数设计 |
| ADDA 域迁移 | 为 L3/L4 跨场景泛化提供参考：在仿真中训练，通过域适应迁移到新场景 |
| 深度图输入 | 本项目 L3/L4 层级的连续动作空间观测可参考其 CNN 特征提取方案 |
| 真实无人机验证 | 主从机架构（无人机 WiFi 传图 + 主机计算）可作为本项目实机验证参考 |
