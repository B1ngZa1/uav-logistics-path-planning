## 二、研究问题与动机

### 2.1 核心问题

在障碍环境下，由于目标运动不确定、视野遮挡、无人机自身动力学约束等影响，无人机对**非协作目标**的持续跟踪面临技术挑战。传统方法将跟踪与避障模块分离设计，存在响应延迟与目标丢失风险。

### 2.2 现有方法的局限

| 方法类别 | 代表工作 | 局限 |
|----------|----------|------|
| 运动预测+轨迹优化 | HAN等[10] Fast-Tracker、JEON等[11]、PAN等[12]、JI等[13] Elastic Tracker | 性能依赖前端目标预测准确性，需精确环境感知信息，路径搜索未考虑障碍遮挡 |
| 深度Q网络方法 | BHAGAT等[14] TF-DQN | 网络输出仅6种离散动作，限制性能 |
| 深度确定性策略梯度 | XU等[15] MPTD3 | 收敛慢、成功率低 |
| 元强化学习 | SHEN等[16] PEARL-2Buf | 仍需大量训练适应不同任务 |
| 端到端跟踪 | LUO等[20] | 直接采用高维RGB图像输入，特征提取难度大；离散化动作输出难以满足平滑性与精度需求 |

### 2.3 本文创新点

1. 提出端到端融合控制策略，直接从图像特征映射到无人机控制指令，克服跟踪与避障分离设计的局限
2. 设计结合单应性变换的运动补偿扩展卡尔曼滤波方法，在图像平面实时估计目标位置与运动方向
3. 设计基于深度强化学习的运动控制器，实现从传感器观测到控制指令的端到端映射
4. 不依赖目标位置真值，实现对非协作目标的纯视觉跟踪与避障

## 三、方法框架

### 3.1 总体架构

系统由两大模块构成：
- **基于EKF的目标状态估计器**：在线估计目标在图像平面中的位置坐标及运动方向
- **基于DRL的运动控制器**：以目标状态估计信息与激光雷达感知的环境信息作为输入，通过端到端策略网络直接映射为无人机控制指令

### 3.2 基于EKF的目标状态估计

**状态定义**：目标状态为4维向量 `xk = [uk, vk, u_dot_k, v_dot_k]^T`，其中 `(uk, vk)` 为像素坐标，`(u_dot_k, v_dot_k)` 为像素变化速率。

**运动模型**：恒定速度（CV）模型，离散时间状态转移方程：

```
xk = F * xk-1 + wk
F = [[1, 0, Δt, 0],
     [0, 1, 0, Δt],
     [0, 0, 1, 0],
     [0, 0, 0, 1]]
wk ~ N(0, Qk)
```

**无人机运动补偿**：假设（1）无人机飞行高度保持不变；（2）被跟踪目标在平坦地面上运动。利用单应矩阵将不同相机位姿下观测到的目标坐标统一变换至同一参考视角。

**EKF流程**：
1. 初始化：根据第1帧检测结果初始化 x0 及 P0
2. 预测：`xk- = F * xk-1`，`Pk- = F * Pk-1 * F^T + Qk-1`
3. 更新：观测 `zk = [u_obs_k, v_obs_k]^T`，观测矩阵 `H = [[1,0,0,0],[0,1,0,0]]`，卡尔曼增益 `Kk = Pk- * H^T * (H * Pk- * H^T + Rk)^(-1)`
4. 状态更新：`xk = xk- + Kk * (zk - H * xk_comp)`
5. 协方差更新：`Pk = (I - Kk * H) * Pk-`

**输出**：`od_t = [ut, vt, ht, u_dot_t, v_dot_t]^T`，其中 ht 为检测框高度（间接反映相对距离），`(uk, vk)` 作为视觉伺服信号，`(u_dot_k, v_dot_k)` 反映无人机航向与目标朝向关系。

### 3.3 基于DRL的目标跟踪控制

**MDP建模**：部分可观的马尔科夫决策过程，六元组 `(S, A, P, R, Ω, O)`

**观测空间**（3.1节）：
- `ot = [oz_t, od_t, ov_t]`
- `oz_t`：2维激光雷达连续3帧数据（降采样至512维）
- `od_t`：来自目标估计器的目标状态估计值（5维）
- `ov_t`：无人机速度信息（3维）

**动作空间**（3.2节）：
- 3维连续动作：x方向速度指令、y方向速度指令、偏航角速度控制指令
- 输出最大值：2.5 m/s、2.0 m/s、0.5 rad/s
- 采用速度控制方式（非底层力矩控制），由嵌入式飞行控制器底层闭环执行，降低sim-to-real迁移误差

**终止条件**（3.3节）：
- 目标脱离无人机相机视野
- 无人机与目标发生碰撞

### 3.4 奖励函数设计

总奖励（t时刻）：

```
rt = r_detection + r_position + r_collision + r_beta + r_state + r_goal
```

| 奖励项 | 公式/定义 | 权重 | 说明 |
|--------|-----------|------|------|
| `r_detection` | `ω_d * FIoU(B_det, B_ref)` | 0.2 | 检测框与参考框交并比，保持目标在视野内 |
| `r_position` | `ω_dist * (D(t-1) - D(t)) + ω_α * (cos αt - cos α(t-1))` | ω_dist=0.5, ω_α=0.5 | 距离趋近期望距离+航向对准目标 |
| `r_collision` | -50（碰撞时）/ 0（其他） | 稀疏 | 价值断崖，强制优先规避碰撞 |
| `r_beta` | `ω_β * (cos β - 1)` | 0.05 | 防止环绕目标飞行的局部最优解 |
| `r_state` | `ω_state * \|\|vt - v(t-1)\|\|` | 0.005 | 激励平稳运动，惩罚加速度突变 |
| `r_goal` | 0.2（FIoU > F_ref 且 |β| < β_ref）/ 0 | 稀疏 | 达成跟踪目标的条件奖励 |

其中：
- `D(pt) = |\|\|pt\|\| - p_ref|`：无人机与目标实际距离与期望距离差值
- `α`：无人机和目标连线与无人机航向的夹角
- `β`：无人机航向与目标朝向的夹角
- `vt = [vx, vy, ωz]`：x/y轴线速度和偏航角速度

**奖励设计原则**：
- 多目标量级对齐，防止单项激励主导梯度更新
- 碰撞惩罚构造价值断崖，确保失败回合回报远低于正常跟踪回合
- 稀疏奖励项与其他稠密奖励项维持同一数量级

### 3.5 策略网络结构

**1维卷积编码器**（处理激光雷达输入）：
- 输入：1×3×512（连续3帧，每帧512维）
- 第1隐藏层：32个卷积核，尺寸5，步长2 → ReLU → 32×3×256
- 第2隐藏层：32个卷积核，尺寸3，步长2 → ReLU → 32×3×128
- 展平：12288维
- 全连接层：12288 → 512维特征向量

**MLP融合模块**：
- 拼接：512（激光雷达特征）+ 5（目标状态）+ 3（速度信息）= 520
- 全连接层：520 → 256 → 128 → 128 → 3（动作输出）

**输出**：3维连续动作 `[vx, vy, ωz]`

## 四、实验设计与结果

### 4.1 实验平台

- **训练平台**：Flightmare仿真平台（基于Unity的高保真渲染引擎 + 无人机动力学仿真），支持并行化计算
- **验证平台**：AirSim平台（高保真物理引擎，模拟IMU漂移、图像噪声等传感器不确定性）
- **计算硬件**：i9-13900KF CPU + NVIDIA RTX 4090 GPU

### 4.2 训练配置

| 参数 | 值 |
|------|----|
| 学习率 | 0.0003 |
| 折扣因子 γ | 0.99 |
| PPO裁切范围 | 0.2 |
| GAE λ参数 | 0.95 |
| 单回合最大步数 | 300 |
| 并行仿真环境数量 | 100 |
| 最大训练步长 | 60,000,000 |
| Actor/Critic权重 | 不共享 |
| 训练耗时 | 约80 min |

**课程学习策略**：训练初期将目标设置为静止状态，降低探索难度，提高收敛效率；通过随机初始化无人机与目标相对位姿提升泛化能力。

### 4.3 实验结果

#### 对比基线：Fast-Tracker

**跟踪成功率**（目标沿"8"字形轨迹运动）：

| 目标速度 | 方法 | 跟踪成功率 | 目标丢失比例 | 碰撞比例 |
|----------|------|-----------|-------------|---------|
| 0.8 m/s（低速） | Fast-Tracker | 80% | 20% | 0% |
| 0.8 m/s（低速） | **本文方法** | **100%** | **0%** | **0%** |
| 1.5 m/s（中速） | Fast-Tracker | 60% | 40% | 0% |
| 1.5 m/s（中速） | **本文方法** | **100%** | **0%** | **0%** |
| 2.2 m/s（高速） | Fast-Tracker | 30% | 70% | 0% |
| 2.2 m/s（高速） | **本文方法** | **80%** | **20%** | **0%** |

**轨迹质量**：

| 方法 | 轨迹长度/m | 平均加加速度/(m/s^3) |
|------|-----------|---------------------|
| Fast-Tracker | 146.93 | 1.88 |
| **本文方法** | **131.28** | **0.41** |

**计算实时性**（单步决策平均计算时间/ms）：

| 目标速度 | Fast-Tracker | 本文方法 |
|----------|-------------|---------|
| 1.0 m/s | 3.54 | 0.82 |
| 2.0 m/s | 5.88 | 0.91 |

**核心发现**：
- 本文方法端到端推理时间不受环境复杂度影响（约0.82~0.91 ms），Fast-Tracker随任务复杂度上升耗时大幅增加
- 目标检测框中心点分布：本文方法高度集中于图像中心区域，Fast-Tracker分散发散
- 本文方法轨迹更短、更平滑（加加速度仅为Fast-Tracker的22%）

#### 目标状态估计敏感性分析

| 无人机高度变化/m | 地面高度变化/m | 平均像素误差/像素 |
|-----------------|---------------|------------------|
| ±0.5 | 0 | 4.86 |
| 0 | ±0.5 | 9.53 |
| ±0.5 | ±0.5 | 15.77 |
| ±1.0 | 0 | 13.31 |
| 0 | ±1.0 | 16.12 |
| ±1.0 | ±1.0 | 32.76 |
| ±1.5 | 0 | 20.33 |
| ±1.5 | ±1.5 | 53.52 |

小范围扰动下（±0.5 m），估计误差对系统性能影响较小，得益于神经网络泛化能力的隐式补偿。

#### AirSim跨平台验证

在AirSim高保真平台上，使用Flightmare训练的模型（未微调）直接部署，结果验证：
- 无人机能持续跟踪运动目标，保持稳定相对距离
- 目标方向突变或速度变化时展现良好的动态调整能力
- 接近障碍区域时显示明确规避行为，轨迹平滑无碰撞

## 五、局限性与未来方向

### 5.1 局限性

1. **假设约束**：目标状态估计依赖"飞行高度不变"和"目标在平坦地面运动"两项假设，剧烈高度变化或复杂室内场景中假设失效可能导致估计精度下降
2. **Sim-to-Real迁移**：真实环境中的传感器噪声、光照变化、通信延迟等非理想因素尚未完全建模，可能影响实机部署性能
3. **单机视场限制**：单无人机视场有限，遮挡场景下鲁棒性受限

### 5.2 未来工作方向

1. 优化状态估计算法，探索摆脱平坦地形假设的估计方法
2. 引入域随机化与实机微调技术，提升Sim-to-Real迁移能力
3. 探索多无人机协同跟踪框架，通过多视角信息融合增强系统在遮挡及大范围场景下的鲁棒性

## 六、与本项目的关联分析

### 6.1 方法论参考价值

| 本文方法 | 本项目（无人机配送）可借鉴之处 |
|----------|-------------------------------|
| 端到端DRL融合控制 | 配送任务中可借鉴"感知→控制"端到端映射思路，减少中间模块的误差累积 |
| EKF + DRL双模块架构 | 配送环境中的动态障碍物感知可参考EKF状态估计与DRL控制的分层融合方式 |
| 多奖励项复合奖励函数设计 | 配送奖励函数可参考其"多目标量级对齐""稀疏+稠密混合""价值断崖"等设计原则 |
| PPO训练+课程学习 | L3/L4层级PPO训练可借鉴其课程学习策略：先简化任务再逐步增加复杂度 |
| 速度控制接口设计 | 选择高层速度控制而非底层力矩控制，降低sim-to-real迁移误差，与本项目动作空间设计一致 |
| 轻量化策略网络 | 1D-CNN编码器+MLP融合模块的轻量架构，适合机载实时推理 |

### 6.2 奖励函数设计启示

本文的六项复合奖励设计对本项目奖励函数设计有直接参考：
- **视场保持 → 配送目标保持**：`r_detection` 使用IoU衡量目标是否在视野内，类似配送中订单目标是否在感知范围内
- **距离趋近 + 航向对准**：`r_position` 的双向引导（距离差分+角度差分）可借鉴用于引导无人机趋近配送点
- **碰撞惩罚的价值断崖**：-50的稀疏惩罚确保安全优先，与本项目中碰撞惩罚-200的设计理念一致
- **平稳运动激励**：`r_state` 惩罚加速度突变，可借鉴用于配送中的能耗优化
- **防局部最优**：`r_beta` 防止环绕行为，可参考用于防止无人机在配送点附近徘徊

### 6.3 关键数字记忆

- 训练：100并行环境，6000万步，约80分钟收敛
- 低速（0.8 m/s）：100%跟踪成功率
- 中速（1.5 m/s）：100%跟踪成功率
- 高速（2.2 m/s）：80%跟踪成功率
- 端到端推理延迟：0.82~0.91 ms/步
- 轨迹加加速度仅为对比方法的22%
