## 一、研究动机与问题定义 / Motivation & Problem Definition ★★★★☆

### 1.1 核心问题

RRT（Rapidly-exploring Random Tree）作为基于概率完备性的单查询采样路径规划算法，具有**建模时间短、搜索能力强、方便添加非完整约束**等优点，但存在两个根本缺陷：

- **RRT**: 节点随机扩展导致路径质量差，**无法收敛至最优路径**（概率为零，由Frazzoli 2011年证明）
- **RRT***: 能渐进收敛至最优路径，但**整体消耗时间长**，随节点数增加内存/计算量呈指数上升

### 1.2 路径规划问题形式化定义

设 $X \subseteq \mathbb{R}^n$ 为有界工作空间（$n \geq 2$），$X_{obs} \subset X$ 为障碍区域，$X_{free} = X \setminus X_{obs}$ 为自由空间。

给定起点 $x_{init} \in X_{free}$，目标点 $X_{goal} \in X_{free}$，路径函数 $s:[0,1] \to \mathbb{R}^n$ 满足：

$$s(0) = x_{init}, \quad s(1) = X_{goal}, \quad \forall \tau \in [0,1], \; s(\tau) \in X_{free}$$

最优路径规划问题：

$$s^* = \arg\min_{s \in \Sigma} \{ c(s) \mid s(0)=x_{init},\; s(1)=X_{goal},\; \forall \tau \in [0,1],\; s(\tau) \in X_{free} \} \quad \text{(2-1)}$$

### 1.3 路径规划算法分类总览

| 类别 | 代表算法 | 优点 | 缺点 |
|------|---------|------|------|
| **图搜索** | Dijkstra, A* | 二维全局最优 | 高维环境计算复杂度高 |
| **仿生智能** | GA, AC, PSO, ABC | 处理NP难问题多样 | 易陷局部最优、实时性差 |
| **节点采样** | PRM, RRT, RRT* | 高维复杂环境高效 | 结果随机、次优 |
| **局部规划** | 人工势场, D*, 模糊算法 | 实时建模 | 缺少全局信息 |

## 二、核心方法 / Methodology ★★★★★

### 2.1 算法一：SRRT（Sarsa RRT）-- 基于强化学习的路径规划

**核心思想**: 将Sarsa强化学习嵌入RRT节点扩展过程，通过马尔科夫决策建模实现节点"先探索，后利用"，提高路径质量和稳定性。

#### 2.1.1 MDP建模

将RRT节点扩展过程建模为四元组 $(S, A, T, R)$：

**状态定义**: 状态 $s$ 为随机树上的节点坐标，$s_i = (s_1, s_2)$，$s_i \in S$

**动作定义**: 以当前节点 $(x_0, y_0)$ 为中心，用两条直线 $x = y_0$, $y = x_0$ 分割全局为四个区域：

$$A = \begin{cases} 1 & \theta \in (0, \pi/2] \\ 2 & \theta \in (\pi/2, \pi] \\ 3 & \theta \in (-\pi, -\pi/2] \\ 4 & \theta \in (-\pi/2, 0] \end{cases} \quad \text{(3-1)}$$

$$\theta = \arctan\frac{s_2 - r_2}{s_1 - r_1}, \quad \theta \in (-\pi, \pi) \quad \text{(3-2)}$$

#### 2.1.2 连续奖赏函数设计（四分量）

$$r_i(s,a) = n_1(s,a) + n_2(s,a) + n_3(s,a) + n_4(s,a) \quad \text{(3-3)}$$

| 分量 | 含义 | 定义 |
|------|------|------|
| $n_1(s,a)$ | 目标到达 | $s_{i+1} = X_{goal}$ 时 $+100$（sucgrade），否则 $0$ |
| $n_2(s,a)$ | 障碍碰撞 | $s_{i+1} \in X_{obs}$ 时 $-50$（defgrade），否则 $0$ |
| $n_3(s,a)$ | 相对距离 | $d_{s_{i+1}} > d_{s_i}$ 时 $-u$（步长惩罚），否则 $0$ |
| $n_4(s,a)$ | 分段线性 | $X_{goal} \notin X_a$ 时 $-(dis - d_{s_{i+1}})$，否则 $0$ |

**设计亮点**: $n_3$ 和 $n_4$ 保证每个状态都有有效反馈，实现**奖赏函数连续性**。

#### 2.1.3 变参数 $\varepsilon$-贪婪策略

$$\varepsilon = \begin{cases} 1 - 0.1 \lfloor k/100 \rfloor & k \in [1, 900) \\ 0.1 - 0.01 \lfloor k/100 \rfloor & k \in [900, 1500) \\ 0.05 & k \in [1500, M] \end{cases} \quad \text{(3-4)}$$

- $k$: 学习次数，$M$: 最大学习次数
- 初期 $\varepsilon \approx 1$：以随机探索为主
- 后期 $\varepsilon = 0.05$：95%利用Q表最优策略 + 5%继续探索

#### 2.1.4 Sarsa更新规则（回合制 $\lambda = 1$）

$$Q_{k+1}^{\pi}(s,a) = Q_k^{\pi}(s,a) + \alpha \left[ r + \gamma Q_k^{\pi}(s', a') - Q_k^{\pi}(s,a) \right] \quad \text{(2-7)}$$

- 使用 Sarsa($\lambda$)，$\lambda = 1$：回合制全局更新（从当前状态到初始状态）
- 同策略（on-policy）：训练策略与执行策略一致

#### 2.1.5 SRRT算法流程

```
输入: 随机树最大节点数N, 起点x_init, 目标X_goal, 动作集A, 折扣因子gamma, 学习率alpha
输出: 连接x_init与X_goal的随机树T

1. 初始化 T, Q表全零, s_0 = x_init
2. for n = 1 to N:
3.   X_rand <- Random(); X_near <- Nearest(X_rand, T)
4.   s = X_near(x,y); a <- pi_epsilon(s)     // epsilon-贪婪选动作
5.   r, X_new <- (s, a); s' = X_new(x,y)
6.   添加X_new到T; a' <- pi_epsilon(s')
7.   Q(s,a) <- Q(s,a) + alpha[r + gamma*Q(s',a') - Q(s,a)]
8.   pi(s) <- argmax_a'' Q(s, a'')
9.   if s' == terminal: break
10.  else: s <- s'; a <- a'
```

### 2.2 算法二：AIRRT*（Adjoined Informed RRT*）-- 基于同伦渐进优化

**核心思想**: 在IRRT*的椭圆采样基础上，增加同伦路径渐进优化过程，通过线性插值和自适应选取障碍物顶点，快速缩小椭圆区域，加速最优路径收敛。

#### 2.2.1 IRRT*椭圆采样原理

找到初始路径后，以 $c_{best}$（路径长度）为横向直径，$c_{min}$（起点与目标中心欧氏距离）为焦点距离，构造椭圆采样区域：

$$X_f' = \{ x \in X \mid \|x_{init} - x\|_2 + \|X_{goal} - x\|_2 \leq c_{best} \} \quad \text{(4-2)}$$

**关键性质**: 椭圆外的采样节点无法优化已有路径，因此直接限制无效节点采样。

#### 2.2.2 同伦最优路径定义

设 $X, Y$ 为空间子集，$f: X \to Y$, $g: X \to Y$ 为连续映射。若存在连续映射 $H: [0,1] \times X \to Y$ 使 $H(0,x) = f(x)$, $H(1,x) = g(x)$，则称 $H$ 是 $f$ 到 $g$ 的一个**同伦**。

在路径规划中：$H(0,x) = x_{init}$, $H(1,x) = X_{goal}$，同伦路径在当前路径所对应的障碍物之间寻找。**最短同伦路径即为当前同伦最优路径**。

**重要限制**: 同伦路径不一定能优化至全局最优（不同拓扑类的路径互不同伦）。

#### 2.2.3 同伦渐进优化过程（AdjoinedProcess）

```
AdjoinedProcess(X_sol', u)
输入: 待优化路径X_sol', 最小路径间隔u
输出: 同伦最优路径X_path

1. X_prunepath <- PruningPath(X_sol')    // 删除冗余节点
2. while i < p-1:
3.   X_path' <- Adjoined(x_i, x_{i+1}, x_{i+2}, u)  // 三节点优化
4.   X_path <- X_path ∪ X_path'
5. return X_path
```

**Adjoined() 函数的三种情况**:

| 情况 | 条件 | 处理方式 |
|------|------|---------|
| 状况1 | $PointCoord_1 = PointCoord_2$ | 相同障碍物顶点，用 $cross_2$ 替代 $x_{i+1}$ |
| 状况2 | 不同顶点，切点连线无障碍 | 用两切点 $contact_1, contact_2$ 贴近障碍物 |
| 状况3 | 不同顶点，切点连线有碰撞 | **递归调用** Adjoined()，分解为子问题 |

时间复杂度: $O(n^2)$，与插值间隔精度相关。

#### 2.2.4 AIRRT*完整流程

```
AIRRT*(x_init, X_goal, u)
输入: 起点x_init, 目标X_goal, 迭代次数K, 线性插值间隔u
输出: 最优路径X_optimal

1. 初始化 T, X_sol = empty, c_best = infinity
2. for k = 1 to K:
3.   X_new <- IRRT*(x_init, X_goal, T, X_sol, c_best)
4.   if InGoalRegion(X_new) and cost(X_new) < c_best:
5.     X_sol' <- (T, X_new)
6.     X_solpath(X_new) <- AdjoinedProcess(X_sol', u)  // 同伦优化
7.     X_sol <- X_sol ∪ X_solpath(X_new)
8.     c_best <- min(cost(x | X_solpath(x) in X_sol))    // 缩小椭圆
9. return X_optimal
```

**关键改进链**: RRT* -> IRRT*（椭圆采样）-> AIRRT*（椭圆采样 + 同伦渐进优化）

**表3-2: SRRT vs RRT vs RRT* 性能对比**

| 算法 | 单障碍物路径值 | 局部最优路径值 | 多障碍物路径值 |
|------|-------------|-------------|-------------|

**核心结论**:
- SRRT路径值较RRT分别降低 8.85%, 27.62%, 3.66%
- SRRT成功率较RRT分别高出 23.63%, 20.57%, 22.63%
- SRRT路径值**次于RRT***（非渐进最优），但**成功率显著高于RRT***
- SRRT收敛约需 2200~2850 次学习过程

## 五、局限性与未来方向 / Limitations & Future Work ★★★☆☆

### 5.1 已知局限

| 编号 | 局限 | 说明 |
|------|------|------|
| 1 | **仅仿真实验** | 未在实际机器人上测试，未考虑真实约束（动力学、传感器精度等） |
| 2 | **Q表规模问题** | SRRT后期Q表状态节点数量大，查询计算量增加 |
| 3 | **障碍物形状限制** | AIRRT*仅适用于多边形障碍物（有明确顶点），无法处理曲率连续障碍物 |
| 4 | **椭圆区域瓶颈** | AIRRT*整体性能受限于全局环境中形成的最小椭圆区域 |
| 5 | **同伦路径非全局最优** | 同伦路径只能在当前拓扑类内优化，跨拓扑类的全局最优路径无法通过同伦优化获得 |
| 6 | **2D环境限制** | 本文实验均在二维平面进行，三维扩展未涉及 |

### 5.2 未来研究方向

1. 实际机器人部署测试
2. 提高Q表查找效率（如KD-tree索引）
3. 曲线障碍物的同伦渐进优化
4. 改进随机树自身的节点优化过程
