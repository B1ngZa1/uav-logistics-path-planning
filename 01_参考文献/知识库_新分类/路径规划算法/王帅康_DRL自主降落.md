## 二、研究问题与动机

### 2.1 核心问题

多旋翼无人机在**地面移动平台**上的自主降落问题。传统控制方法在模型设计、非线性近似、干扰抑制和计算效率方面存在局限性，需要探索基于深度强化学习的替代方案。

### 2.2 研究动机

- **军事需求**：无人机需通过军用载具释放并在执行任务后自主降落于移动回收平台
- **民用需求**：抢险救灾、地图勘探、农植环保等任务完成后需自主降落，降低人力消耗
- **技术瓶颈**：小型无人机电池容量有限，自主着陆能力对长期操作至关重要
- **现实困境**：现实世界中无人机强化学习训练可重复性差且危险性高，需搭建仿真平台解决

## 三、研究方法与技术框架

### 3.1 系统架构

采用三层架构：
1. **环境模拟仿真层**：基于Gazebo-Parrot + ROS的仿真平台
2. **强化学习算法层**：DDPG（Deep Deterministic Policy Gradient）算法
3. **计算与数据交互层**：ROS节点通信机制

### 3.2 仿真平台搭建

| 组件 | 说明 |
|:---|:---|
| **操作系统** | Linux Ubuntu 16.04 LTS |
| **仿真环境** | Gazebo 7.0（3D物理引擎） |
| **机器人框架** | ROS Kinetic Kame |
| **无人机模型** | Parrot Bebop2（软件在环SITL） |
| **仿真器** | Parrot-Sphinx（基于Gazebo 7.0） |
| **视觉库** | ArUco Library（基于OpenCV） |
| **编程语言** | Python + C++ |

### 3.3 感知方案（双方案设计）

**方案一：外部辅助（仿真器直接反馈）**
- Gazebo直接推送无人机和平台在世界坐标系下的位姿
- 通过ROS话题`/gazebo/default/pose/info`获取Ground Truth

**方案二：机器视觉（ArUco码解算）**
- 移动平台表面覆盖9个大小不一的ArUco Marker（1.2m x 1.2m x 0.15m平台）
- 算法流程：原始图像 -> 阈值处理 -> 轮廓滤波 -> 透视变换 -> 比特位提取 -> 获取ID
- 基于PNP（Perspective-n-Point）原理进行相对位姿解算
- 利用旋转矩阵R和平移向量T建立相机坐标系与世界坐标系的转换关系

### 3.4 深度强化学习算法：DDPG

**算法演进路径**：PG -> DPG -> Actor-Critic -> DDPG

**DDPG核心改进**：
1. **深度神经网络函数近似**：策略网络和价值网络均使用3隐藏层DNN（400-300-200神经元）
2. **经验回放机制（Replay Buffer）**：消除样本时序关联性，解决数据相关性及非静态分布问题
3. **双网络架构**：每个网络均有在线网络和目标网络，通过软更新（tau=0.001）保持训练稳定性

**网络结构**：
- Actor网络：输入7维状态 -> 400 -> 300 -> 200 -> 5维动作（tanh激活）
- Critic网络：输入7维状态+5维动作 -> 400 -> 300 -> 200 -> 1维Q值
- 激活函数：隐藏层ReLU，输出层tanh
- 优化器：Adam，学习率0.0001
- 探索噪声：Uhlenbeck-Ornstein（UO）随机过程

## 四、问题建模

### 4.1 状态空间（7维）

```
S = {x, y, z, dx, dy, psi, C}
```
- `x, y, z`：UAV相对于移动平台的相对位置（机体坐标系）
- `dx, dy`：相对移动速度（由相邻时间步位置差定义）
- `psi`：相对于平台的偏航角
- `C`：接触传感器二值状态（[0,1]）

状态归一化范围：S in [-1, 1]

### 4.2 动作空间（5维，连续）

```
A = {phi, theta, psi_dot, z_dot, tau}
```
- `phi`：俯仰角（roll）
- `theta`：滚转角（pitch）
- `psi_dot`：偏航角速度（yaw rate）
- `z_dot`：升速（altitude rate）
- `tau`：切断无人机飞控的能力（着陆控制）

动作范围：A in [-1, 1]

### 4.3 奖励函数设计

| 分量 | 条件 | 奖励值 |
|:---|:---|---:|
| r1（越界惩罚） | x>xmax 或 y>ymax 或 z>zmax | -100 |
| r2（高空误切） | tau>0.8 且 (z_tau>z_tau_max 或 z_tau<0) | -50 |
| r3（正确着陆） | tau>0.8 且 (z_tau<z_tau_max 且 z_tau>0) | 100*e^(k*(z_tau-z_tau*)) |
| r4（势能塑形） | 其他情况 | shaping[t]-shaping[t-1] |

势能塑形函数：
```
shaping[t] = -alpha1*||[x,y,z,psi]|| - alpha2*||[x,y]|| - alpha3*||psi|| + ||theta^2+phi^2+z_dot^2||
```
其中 alpha1=100, alpha2=10, alpha3=1, k=1.5

### 4.4 移动平台条件（4种）

| 条件编号 | 平台运动方式 |
|:---|:---|
| 1 | 静止平台 |
| 2 | 0.07 m/s 匀速直线移动 |
| 3 | 0.1 m/s 匀速直线移动 |
| 4 | 0.2 m/s 匀速直线移动 |

## 五、实验结果

### 5.1 实验一：Gazebo直接反馈相对位姿

对比DDPG学习算法与传统PD控制器：

| 指标 | DDPG学习算法 | PID算法 |
|:---|:---:|:---:|
| 降落偏移误差 | [-0.3, 0.3] m | [-0.2, 0.2] m |
| 平均降落时长 | 7.72 s | 12.86 s |
| 降落成功率 | 100% | 100% |

**结论**：DDPG算法达到与PID同一精度水平，且降落效率更高（时间减少约40%）。

### 5.2 实验二：ArUco视觉反馈相对位姿

| 平台条件 | 平均降落时间(s) | 成功率 | 失败原因 |
|:---|---:|:---:|:---|
| 静止 | 11.33 | 100% | - |
| 0.07 m/s | 22.15 | 100% | - |
| 0.1 m/s | 17.81 | 80% | 降落至平台边缘 |
| 0.2 m/s | 17.16 | 53.3% | 难以定位快速移动平台 |

### 5.3 关键发现

1. **学习前后对比**：训练后DDPG算法显著提高降落精准性，减少降落时间
2. **跨速一致性**：Gazebo反馈模式下，不同平台移速对DDPG降落时间基本无影响
3. **DDPG vs PID**：DDPG在降落时间上具有明显优势，精度达到同一水平
4. **视觉模式挑战**：视觉反馈模式下，平台速度过快导致定位丢失，成功率下降
5. **视野丢失策略**：当ArUco标志物丢失时，无人机执行上升操作重新搜索目标

## 六、ROS节点架构

| 节点 | 职责 |
|:---|:---|
| **bebop_driver** | 无人机驱动节点，接收速度/飞行状态/相机控制/起降指令，传输给SITL仿真器 |
| **bebop_dronemsgsros** | 从Gazebo读取无人机和平台Ground Truth；飞行标志位切换；相机控制命令；数据记录 |
| **RlEnviromentGazeboRos** | 环境交互节点：Gazebo初始化；通过ROS Service/Client与Agent交换状态-动作-奖励；ArUco视觉解算 |
| **agent** | DDPG算法实现节点：接收状态空间，输出动作空间，完成A-C网络训练 |

ROS通信方式：话题（Topic）发布/订阅 + 服务（Service/Client）同步交互

## 七、创新点与贡献

1. **仿真平台搭建**：基于Gazebo-Parrot + ROS的软件在环无人机仿真平台，解决了实物训练可重复性差和高危险性的问题
2. **双感知方案**：同时设计了外部辅助（仿真器反馈）和机器视觉（ArUco码）两套相对位姿感知方案
3. **四条件实验设计**：设计了四种不同移动速度的平台条件和传统PID对照控制器
4. **DDPG在降落任务的应用验证**：证明DDPG算法在连续控制任务中的有效性，达到PID同等精度且效率更高

## 八、局限性与改进方向

| 局限性 | 改进方向 |
|:---|:---|
| 高速平台视觉降落成功率仅53.3% | 建立地面移动平台运动估计方案 |
| 降落偏移误差较大（[-0.4,0.4]m） | 优化奖励函数中精度相关项 |
| 降落时间在视觉模式下延长 | 引入运动预测模块减少搜索时间 |
| UO噪声探索效率有限 | 尝试替代噪声策略（如参数空间噪声） |
| 仅验证直线往返运动 | 扩展至曲线运动、随机运动场景 |

## 九、与本项目的关联性

| 对比维度 | 王帅康（本文） | 本项目（无人机配送） |
|:---|:---|:---|
| **任务目标** | 移动平台自主降落 | 城市区域配送路径规划 |
| **动作空间** | 连续5维（姿态+升速+切断控制） | 连续3-4维（三维速度+可选偏航） |

| **仿真平台** | Gazebo-Parrot + ROS | 自建Gymnasium环境 |
| **感知方式** | ArUco视觉/Gazebo真值 | 内置状态观测（网格地图） |
| **参考价值** | DDPG连续控制验证、奖励函数设计思路、仿真-实物迁移思路 | 适用于L3/L4层级连续动作空间的算法设计参考 |

### 核心借鉴点

1. **奖励函数的分层设计思路**：将越界惩罚（大负奖励）、错误动作惩罚（中负奖励）、正确完成奖励（指数函数）、势能塑形（密集引导）四层结合，与本项目配送奖励设计的分层思想一致
2. **状态归一化方法**：通过最大位移量进行归一化处理，确保状态值在[-1,1]范围内，对本项目的状态预处理有参考意义
3. **DDPG双网络架构**：在线网络+目标网络的软更新机制，是连续控制算法的经典范式
4. **仿真到现实的迁移思路**：Gazebo仿真平台具有较强的现实移植性，与本项目从2D仿真逐步扩展到3D仿真再考虑实物验证的路径一致
5. **UO噪声探索策略**：在连续动作空间中使用Uhlenbeck-Ornstein随机过程进行探索，可作为PPO高斯探索策略的对比参考
