## 2. 摘要与贡献 / Summary & Contributions

### 2.1 摘要

本文从**示教学习**和**知识迁移**两个角度研究专家知识辅助的强化学习方法，并将所提方法应用于**无人机航迹规划**问题。强化学习具有自学习和自适应能力，但存在学习效率低、收敛慢的问题。本文通过引入专家知识来加速RL学习过程，并在算法实现层面降低计算复杂度。

### 2.2 六大核心贡献

| 编号 | 贡献 | 关键创新点 | 与本项目相关度 |
|---:|---|---|---|
| 1 | **NAC-BRLS算法** | 将自然Actor-Critic的自然梯度计算转化为批量递推最小二乘问题，减少一个数量级的在线计算量 | ★★★☆☆ |
| 2 | **MDP对称性利用** | 将有限MDP对称性定义推广到连续状态空间MDP，设计对称基函数使基函数数量减半 | ★★☆☆☆ |
| 3 | **DMP示教轨迹分类** | 用少量DMP参数表示示教轨迹，设计CNN分类器识别轨迹序列，训练时可重现示教策略 | ★★★★☆ |
| 4 | **基于DMP泛化的UAV航迹规划** | 基于任务参数间映射关系将源任务DMP参数泛化到目标任务，用于构建势函数指导Q-learning探索 | ★★★★★ |
| 5 | **基于值函数迁移的Q-learning势函数构建** | 利用任务间状态相似度度量迁移源任务值函数到目标Q-learning，构建势函数 | ★★★★☆ |
| 6 | **三种知识迁移方法对比** | 对比A-NN（直接动作迁移）、访问频率奖励塑形、1-NN值函数迁移三种方法的优劣 | ★★★★☆ |

## 3. 核心方法 / Core Methods

### 3.1 批量递推最小二乘自然Actor-Critic (NAC-BRLS)

**问题背景**：自然Actor-Critic需要估计Fisher信息矩阵的逆，计算复杂度高。

**核心思想**：将自然梯度估计转化为**批量递推最小二乘(BRLS)**问题。

$$\theta_{k+1} = \theta_k + \alpha_{\theta,k} \hat{g}_k$$

其中自然梯度 $\hat{g}_k = F^{-1} \nabla_\theta J$，$F$ 为Fisher信息矩阵。

**批量RLE更新**（基函数 $\phi_{a_i}$ 为策略梯度 $\nabla_\theta \log \pi(a_i|s_i;\theta)$）：

$$\hat{w}_{k+1} = \hat{w}_k + Q_{k+1} [\delta_{k+1} - \phi_{a_{k+1}}^T \hat{w}_k]$$

$$Q_{k+1} = P_{k+1} \phi_{a_{k+1}}$$

$$P_{k+1} = \frac{1}{\lambda} \left[ P_k - \frac{P_k \phi_{a_{k+1}} \phi_{a_{k+1}}^T P_k}{\lambda + \phi_{a_{k+1}}^T P_k \phi_{a_{k+1}}} \right]$$

其中 $\lambda \in (0, 1]$ 为遗忘因子，$Q_{k+1}$ 为增益向量，$P_{k+1}$ 为协方差矩阵的逆。

**在线-离线分离**：积累批量数据后批量更新，减少每次迭代的在线计算量。

### 3.2 对称最小二乘策略迭代 (S-LSPI)

**核心概念**：MDP对称性是一组保持状态-动作-奖励-转移结构不变的变换：

$$\pi^*(s) = \pi^*(s'), \quad \forall s \text{ 与} s' \text{ 互为对称}$$

**对称基函数设计**：

| 配置 | 基函数数量 | 说明 |
|---|---|---|
| 非对称 | $2M^d$ | 标准RBF基，高斯函数 |
| 对称 | $M^d$ | 对称组合：$\phi_i(s) = \frac{1}{2}[\phi(s) + \phi(g(s))]$ |

其中 $g(s)$ 为对称变换函数。基函数数量减半，实验表明S-LSPI学习速度更快、对样本数量更不敏感。

### 3.3 动态运动基元 (DMP) 示教学习

**DMP公式**（归一化弧长时间 $x = e^{-\alpha t/T}$）：

$$\ddot{y} = \alpha_z [\beta_z (g - y) - \dot{y}] + f(x)$$

$$\tau \dot{x} = -\alpha_x x$$

其中加速度项 $f(x)$ 为：

$$f(x) = \frac{\sum_{i=1}^{N} w_i \Psi_i(x)}{\sum_{i=1}^{N} \Psi_i(x)} x (g - y_0)$$

$$\Psi_i(x) = \exp\left(-\frac{1}{2\sigma_i^2} (x - c_i)^2\right)$$

**DMP参数化**：一条完整轨迹用 $N$ 个权重 $w_i$ 即可表示，降维后用少量参数完成轨迹分类与迁移。

**CNN轨迹分类器**：
- 输入：$N$ 个DMP参数的时序拼接
- 特殊设计：使用**列向量卷积核**（而非标准方形核），适配时序数据的1D特性
- 输出：轨迹类别

### 3.4 基于DMP泛化的UAV航迹规划

**核心流程**：

```
源任务示教轨迹 → DMP参数化 → 任务参数映射 → 目标任务DMP → 势函数构建 → Q-learning探索引导
```

**势函数设计**：将DMP泛化得到的参考轨迹转化为势函数 $U(s)$，用于修改Q-learning的更新规则：

$$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \max_{a'} Q(s', a') - Q(s, a) \right] + U(s')$$

势函数 $U(s')$ 鼓励智能体向参考轨迹附近的状态探索，从而**加速学习收敛**。

### 3.5 值函数迁移与任务间相似度度量

**方法**：利用源任务值函数 $V_{source}(s)$ 构建目标任务势函数。

**相似度度量**：基于特征空间的距离度量，用于确定状态 $s_{target}$ 在源任务中最近邻状态的值函数：

$$\hat{V}_{target}(s) = \frac{\sum_{i=1}^{K} V_{source}(s_i) \cdot \mathbb{1}[\text{similarity}(s, s_i) < \epsilon]}{\sum_{i=1}^{K} \mathbb{1}[\text{similarity}(s, s_i) < \epsilon]}$$

**三种迁移方法对比**：

| 方法 | 迁移内容 | 适用场景 | 复杂度 |
|---|---|---|---|
| **A-NN**（直接动作迁移） | 最邻近状态-动作对 | 状态空间完全匹配 | 低 |
| **访问频率奖励塑形** | 状态访问分布 | 状态空间可映射 | 中 |
| **1-NN值函数迁移** | 最邻近值函数 | 状态空间部分匹配 | 中 |

## 4. 实验结果 / Experimental Results

### 4.1 NAC-BRLS批量大小影响（表2.2）

| 批大小 $m$ | 平均迭代步数 | 平均运行时间(s) | 性能提升说明 |
|---:|---:|---:|---|
| 1 | 523.2 | 1.346 | 基准（无批量） |
| 3 | 500.3 | 0.6419 | 时间减半 |
| 5 | 549.3 | 0.4866 | 约1/3时间 |
| 7 | 547.8 | 0.4312 | 接近最优时间 |
| 9 | 618.3 | 0.3939 | 最低时间，步数略增 |

**结论**：批量更新将在线计算时间降低一个数量级，而迭代步数增加有限。

### 4.2 S-LSPI vs LSPI 对比（4.2.2节）

在Mountain Car和Acrobot任务上：
- **S-LSPI收敛更快**：利用对称性后，基函数数量从 $2M^d$ 减半为 $M^d$
- **对样本数量更鲁棒**：小样本场景下S-LSPI性能下降更少
- **计算效率提升**：基函数数量减半直接降低计算量

### 4.3 DMP + CNN 轨迹分类结果

**StarLightCurves数据集**：

| 方法 | 错误率 |
|---|---:|
| 基线CNN | 0.095 |
| DMP + CNN (N=3) | 0.069 |
| DMP + CNN (N=5) | 0.055 |
| DMP + CNN (N=10) | 0.052 |
| DMP + CNN (N=20) | 0.048 |

**ECG5000数据集**：

| 方法 | 错误率 |
|---|---:|
| 基线CNN | 0.075 |
| DMP + CNN (N=3) | 0.0684 |
| DMP + CNN (N=5) | 0.0674 |
| DMP + CNN (N=10) | 0.0654 |
| DMP + CNN (N=20) | 0.0604 |

**结论**：DMP参数化+CNN的错误率比基线CNN降低30%-50%。

### 4.4 知识迁移效果（Mountain Car任务，表6.3）

| 方法 | 总步数 | 评价 |
|---|---:|---|
| 无迁移（基准） | 5209 | 基准线 |
| A-NN（直接迁移） | 2846 | 性能提升45% |
| 访问频率奖励塑形 | 5085 | 提升有限 |
| 1-NN（最邻近） | **2508** | **最佳迁移效果** |

**结论**：1-NN值函数迁移方法在Mountain Car任务上效果最优，总步数比无迁移减少约52%。

### 4.5 UAV 5D航迹规划（第7章）

**实验设置**：
- 5维状态空间：$(x, y, z, \theta, \phi)$（位置+姿态角）
- Q-learning + DMP泛化势函数
- Flightgear飞行模拟器验证

**结果**：基于DMP泛化的势函数能有效引导Q-learning探索，相比纯Q-learning收敛速度显著提升，生成的航迹更平滑、更符合无人机动力学约束。

### 5.3 对本项目的启发价值

**高价值借鉴**：
1. **势函数引导探索**：可将地图先验知识（如最优路径方向）转化为势函数，引导PPO探索
2. **任务参数泛化**：不同区域(A/B/C/D)的配送任务可通过参数映射实现快速迁移

**中等价值借鉴**：
3. **DMP参数化轨迹表示**：3D配送路径可用类似思想参数化，降低路径存储开销
4. **对称性利用**：配送场景可能存在空间对称性（如镜像区域），可减少状态空间
