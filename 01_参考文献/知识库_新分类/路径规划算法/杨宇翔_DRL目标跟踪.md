## 第一章 绪论 / Introduction

### 1.1 研究背景与意义

视觉目标跟踪是计算机视觉领域的基础研究问题，目标是在连续视频序列中对感兴趣目标进行跟踪和标注，输出目标的位置和尺度信息。随着深度学习的快速发展，目标跟踪被广泛应用于七大领域：

| 应用领域 | 关键作用 |
|----------|----------|
| 智慧交通 | 车辆行人跟踪、异常状态识别、跨摄像头跟踪 |
| 智慧工业 | 生产流水线监测、设备跟踪、违规操作检测 |
| 智慧农业 | 家畜跟踪、路径规划、健康状态监测 |
| 自动驾驶 | 实时定位、环境识别、突发异常报警 |
| 无人机 | 侦察目标精确定位、运动趋势预测、长时间跟踪 |
| 人机交互 | 脸部手部关键部位跟踪、动作识别 |
| 雷达跟踪 | 空中/水下目标图像跟踪、精确制导 |

### 1.2 国内外研究现状

目标跟踪方法分为三大类：

**第一类：基于相关滤波器（CF）的方法**
- 核心优势：通过FFT快速计算特征匹配，计算量小
- 代表算法：MOSSE(2010) -> CSK -> CN -> KCF -> SAMF/DSST(尺度) -> SRDCF/BACF(边界效应) -> C-COT/ECO(深度特征融合)
- 关键发展：尺度变化研究、边界效应研究、与深度学习结合

**第二类：基于深度学习的方法**
- 早期CNN方法：CNN-SVM、CNT、CF2、MDNet、SANet(RNN引入)
- Siamese网络方法：SINT(首次引入) -> SiameseFC -> CFNet -> SiamRPN -> SiamMask -> SiamRPN++
- 关键突破：双路框架实现高效匹配，RPN提升精度

**第三类：基于深度强化学习的方法（本文重点）**
- 早期DRL方法：EAST(自适应特征选择)、p-tracker(POMDP)、ADNet(11个动作)
- 近期DRL方法：JDTracker(跳跃-扩散)、DRRL(分层追踪)、DP-Siam(动态策略梯度)、SiamRTU(模板更新)

### 1.3 目标跟踪面临的14种挑战

| 挑战缩写 | 全称 | 描述 |
|----------|------|------|
| ARC | Aspect Ratio Change | 边界框长宽比剧烈变化 |
| BC | Background Clutter | 背景与目标外观相似 |
| CM | Camera Motion | 摄像设备突然移动 |
| DEF | Deformation | 目标形状可变形 |
| FM | Fast Motion | 目标运动范围大于边界框 |
| FOC | Full Occlusion | 目标被完全遮挡 |
| IV | Illumination Variation | 目标区域照度变化 |
| LR | Low Resolution | 目标框小于1000像素 |
| MB | Motion Blur | 目标或摄像机运动模糊 |
| OV | Out-of-View | 目标完全离开视频帧 |
| POC | Partial Occlusion | 目标被部分遮挡 |
| ROT | Rotation | 目标在图像中旋转 |
| SV | Scale Variation | 边界框比例超出[0.5,2] |
| VC | Viewpoint Change | 视角对目标外观影响大 |

### 1.4 论文三大创新工作概览

```
问题一：运动模块——动作探索空间有限
  -> 工作一：AEVRNet
       1. 非凸优化SVRG
       2. 自适应探索策略（CUCB）

问题三：更新模块——无法跨域知识迁移
  -> 工作三：STKTMM
       1. 多任务多模型框架（5个教师+1个学生）
```

## 第二章 目标跟踪理论基础 / Theoretical Foundation

### 2.1 单目标跟踪流程

主流跟踪算法由三大模块组成：

| 模块 | 功能 | 关键技术 |
|------|------|----------|
| 表观模块 | 提取目标特征，判别目标与背景 | HOG/CN/深度特征 |
| 运动模块 | 判断目标运动位置，选择最相似候选框 | 候选框匹配、动作选择 |
| 更新模块 | 跟踪过程中对目标变化做响应调整 | 逐帧更新、固定时长更新 |

### 2.2 深度强化学习基础

**MDP五元组**：(S, A, P, R, gamma)
- S：环境状态集合
- A：动作集合
- P：状态转移矩阵 P(s'|s,a)
- R：奖励函数 R(s,a)
- gamma：衰减因子 gamma in (0,1)

**核心公式**：
- 状态值函数：v_pi(s) = E[G_t | S_t = s]
- 状态动作值函数：q_pi(s,a) = E[G_t | S_t=s, A_t=a]
- 最优值函数：v*(s) = max_pi v_pi(s), q*(s,a) = max_pi q_pi(s,a)

**四种代表性RL框架**：

| 框架 | 类型 | 核心思想 |
|------|------|----------|
| Q-Learning | 基于价值 | 构建Q-Table，TD更新 Q(s,a) <- Q(s,a) + alpha[r + gamma*max Q(s',a') - Q(s,a)] |
| Policy Gradient | 基于策略 | 策略参数化，梯度 nabla_theta J(theta) = E[nabla_theta log pi_theta(s,a) * r] |
| DQN | 基于价值(深度) | 经验回放 + 目标网络冻结，解决样本利用率和训练不稳定 |
| DDPG | 价值+策略(深度) | Actor-Critic + DPG，处理连续动作空间，软更新 target 参数 |

### 2.3 主要数据集

| 数据集 | 规模 | 特点 |
|--------|------|------|
| OTB (2013/2015/100) | 50/100/100序列 | 主流基准，11个挑战属性 |
| VOT (2016/2018) | 60/60序列 | EAO/A/R三指标评估 |
| LaSOT | 大规模 | 14个挑战类别，长时间序列 |
| GOT-10k | 大规模 | 5类目标，12个挑战属性 |
| TrackingNet | 大规模 | 海量序列，多种物体 |
| UAV123 | 123序列 | 车辆为主，遮挡和视野外挑战 |
| TColor128 | 128序列 | 彩色跟踪序列 |
| Nfs | 100序列 | 240fps高帧率 |

### 2.4 评价指标

| 指标 | 定义 |
|------|------|
| 精度(Precision) | 预测位置与GT距离 < 阈值(20像素)的帧数占比 |
| 成功率(Success Rate) | IoU(GT, PB) > 阈值(0.5)的帧数占比 |
| EAO | VOT专用，预期平均重叠 |
| AUC | 成功率图的曲线下面积 |

## 第三章 AEVRNet——优化方差下降自适应探索 / Chapter 3

### 3.1 核心问题

现有DRL跟踪方法采用简单动作空间策略，容易陷入局部最优解。

### 3.2 三大技术贡献

#### 3.2.1 非凸优化随机方差下降梯度（non-SVRG）

- **动机**：SGD使用随机参数初始化，收敛慢
- **方法**：将跟踪问题定义为非凸优化问题，使用上一轮训练获得的梯度平均值初始化下一轮训练的梯度
- **效果**：训练损失从1.558降至1.541，测试误差从0.419降至0.392（120 epochs后）
- **优势**：可迁移到ECO和MDNet，分别提升0.6%和0.5%

#### 3.2.2 基于CUCB的自适应动作探索策略

- **动机**：贪心策略无法跳出局部最优
- **方法**：基于组合置信度上限（CUCB），结合时间与空间知识进行动作探索
- **公式**：A_bar_i = mu_hat_i + sqrt(3*ln(t) / 2*M_i)
- **切换策略**：T >= 30帧时激活CUCB，否则使用贪心
- **最佳超参数**：T=30（在OTB2013上测试，精度0.953）
- **效果**：在OTB100和OTB2013上分别提升2.9%和5.0%

#### 3.2.3 基于回归的动作奖励损失函数

- **动机**：分类方法丢失目标连续信息（宽度、高度变化）
- **方法**：用IoU回归值替代二分类标签，r_j(reg) = IoU(p_j, G)
- **多任务损失**：L_SL = (1/m)*sum L1(o_j, o_hat_j) + (1/m)*sum L2(r_j, r_hat_j)
  - L1：交叉熵损失（动作分类）
  - L2：平方损失（回归IoU）
- **奖励函数**：r(s_t,l) = +1 if IoU(b_T, G) > 0.7, else -1
- **效果**：在OTB100和OTB2013上分别提升0.6%和2.0%，重探测频率降低30%

### 3.3 三阶段训练流程

| 阶段 | 目标 | 数据集 | 方法 |
|------|------|--------|------|
| 离线监督训练 | 获得初始模型 | ImageNet | 非凸优化监督学习 |
| 离线DRL训练 | 学习动作选择策略 | ALOV300 | 非凸优化+回归损失+CUCB |
| 在线跟踪 | 实时跟踪+更新 | 测试视频 | 自适应探索+全连接层微调 |

在线跟踪时只微调全连接层(w4~w7)，因为卷积层具有通用跟踪信息，全连接层包含跟踪目标特定知识。

### 3.4 实验结果

| 数据集 | AEVRNet精度 | 对比基准 |
|--------|-------------|----------|
| OTB2013 | 95.3% | ECO 93.1%, MDNet 94.0%, ADNet 89.6% |
| OTB100 | 90.9% | ECO 91.0%, DiMP 90.1%, DAT 90.3% |
| OTB50 | 88.6% | MDNet 89.0%, ECO 87.4% |
| VOT2016 | EAO=0.342 | CCOT 0.331, DSLT 0.332 |
| VOT2018 | EAO=0.466 | PG-Net 0.447, SiamRPN++ 0.414 |
| UAV123 | 75.2% | ECO 74.1% |

消融实验验证三大组件均有效：non-SVRG(+0.8%), CUCB(+2.3%), 回归损失(+0.6%)。

## 第四章 NoisyOTNet——参数空间噪声 / Chapter 4

### 4.1 核心问题

现有DRL跟踪方法使用动作空间噪声（完全随机，不可学习），导致复杂场景中剧烈波动丢失目标。

### 4.2 三大技术贡献

#### 4.2.1 参数空间噪声DDPG网络模型

- **核心创新**：首次将参数空间噪声引入目标跟踪领域
- **参数空间噪声定义**：theta = mu + Sigma * epsilon
  - (mu, Sigma)：可学习的参数向量
  - epsilon：零均值噪声向量
- **噪声线性层**：y = (mu_omega + sigma_omega * epsilon_omega)^T * x + mu_b + sigma_b * epsilon_b
- **噪声生成**：选择独立高斯噪声，sigma_i,j = 0.017
- **优势对比**：
  - 动作空间噪声：完全随机、不可复现、近似线性函数
  - 参数空间噪声：可学习、可复现、可拟合复杂函数

**MDP建模**：
- 状态：输入图像M + 跟踪框(x,y,w,h)
- 动作：连续动作 a = (delta_x, delta_y, delta_w, delta_h)
- 奖励：r(s,a) = +1 if IoU(GT,PB) > 0.7, else -1

#### 4.2.2 基于UCB的自适应模型更新策略

设计四种更新策略：

| 策略 | 触发条件 | 操作 |
|------|----------|------|
| 不更新 | 目标保持不变 | 节省时间，提高速度 |
| 在线网络更新 | 目标较小变化 | 仅更新在线网络参数 |
| 在线+目标网络更新 | 目标较大变化 | 同时更新两个网络 |
| 重定位 | 目标丢失/视野外 | 使用重定位算法 |

UCB公式：UCB(v_a) = Q_a + c * sqrt(ln(t) / N_t(a))
- Q_a：原始更新值
- c：固定权重系数
- N_t(a)：该策略在前t时刻出现次数

#### 4.2.3 基于增量学习的目标重定位方法

- **两种丢失情况**：1) 目标在图像中但不在搜索范围；2) 目标不在图像中
- **方法**：局部到全局重定位，根据目标位置、长宽比例、检测次数D自适应扩展搜索范围
- **四方向扩展**：根据 h_up/h_down 和 w_left/w_right 的比例计算 delta
- **检测阈值**：> 0.7直接接受，> 0.3记录候选，< 0.3认为搜索失败
- **最大重定位次数**：5次/帧

## 第五章 STKTMM——多任务多模型知识迁移 / Chapter 5

### 5.1 核心问题

现有DRL跟踪方法仅通过单一模型跟踪所有不同任务，限制了在不同任务上的鲁棒性和辨别能力。

### 5.2 三大技术贡献

#### 5.2.1 多任务多模型网络框架

- **框架组成**：5个教师模型 + 1个多任务学生模型
- **任务划分**：根据GOT10K数据集的目标属性划分为5类任务
- **教师模型**：基于A3C框架，分别针对特定任务进行离线训练
- **学生模型**：学习所有任务的通用和特定知识
- **网络结构**：5层卷积 + 2层全连接（教师和学生结构相同）

**A3C训练**：
- 全局共享参数 theta, theta_v
- 子线程参数 theta', theta_v'
- 梯度同步更新

#### 5.2.2 多缓冲区存储策略

- **动机**：防止学生模型学习新知识时遗忘旧知识（灾难性遗忘）
- **方法**：为每个任务k设置独立的经验回放缓冲区 D_k
- **训练**：有选择性地从不同任务缓冲区采样进行学生模型训练
- **效果**：保留通用特征信息和特定任务领域特征信息

#### 5.2.3 基于学生-教师知识迁移跟踪

**离线迁移训练阶段**：
1. 5个教师模型分别在对应任务上离线训练
2. 教师模型产生的经验动作存储到对应缓冲区 D_k
3. 从多任务缓冲区采样训练学生模型

**在线迁移跟踪阶段**：
- 表演家网络梯度更新包含两项：
  - 第一项：从教师模型学习转移知识
  - 第二项：自身批评家网络的梯度改善控制策略
- 自适应权重：alpha = r_t / (r_s + r_t)，由教师分数r_t和学生分数r_s动态计算
- 当教师模型判断更准确时（r_t大），alpha增大，更多从教师学习
- 当学生模型判断更准确时（r_s大），alpha减小，更多依赖自身策略

## 第六章 总结与展望 / Conclusion and Future Work

### 6.1 三大创新方法总结

| 算法 | 优化模块 | RL框架 | 核心创新 | 关键性能 |
|------|----------|--------|----------|----------|
| AEVRNet | 运动模块 | Policy Gradient | 非凸SVRG + CUCB自适应探索 + 回归损失 | OTB2013: 95.3%, VOT2018: EAO=0.466 |
| NoisyOTNet | 表观模块 | DDPG | 参数空间噪声 + UCB自适应更新 + 增量重定位 | OTB2013: 92.5%, 41-45 FPS实时 |
| STKTMM | 更新模块 | A3C + DDPG | 5教师-1学生 + 多缓冲区 + 自适应知识迁移 | VOT2018: EAO=0.453, GOT-10k: 0.691 |

### 6.2 未来研究方向

1. **相关滤波器方向**：深度特征与相关滤波器高效结合、自适应模型更新策略、多相关滤波器融合
2. **深度学习方向**：精简网络结构和参数、通道/特征/尺度感知优化、提升深度特征利用效率
3. **深度强化学习方向**：非凸优化动作探索策略、DRL框架与跟踪问题匹配、跨域知识迁移
4. **新技术方向**：图网络（节点/边定义问题）、Transformer（模型庞大/位置匹配）、多层感知机（精简高效）
