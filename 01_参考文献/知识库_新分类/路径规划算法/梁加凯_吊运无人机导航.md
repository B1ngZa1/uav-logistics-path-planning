## 2. 研究问题与动机 / Research Problem and Motivation

### 2.1 研究背景

- 智能电网建设推动输电线路运维从"人工巡检"向"人机协同作业"转型
- 带电作业场景中，作业人员携带沉重检修工具登塔，劳动强度大且安全风险高
- 重载无人机作为"空中起重机"被应用于带电作业平台的空中运输任务

### 2.2 核心问题

架空输电线吊运无人机面临三重挑战：

1. **欠驱动与强耦合**：缆绳连接的负载在气流扰动和无人机机动过程中产生非线性摆动（"双摆"/"多摆"效应），严重影响定位精度，严重时导致失稳坠机
2. **多障碍物环境**：复杂输电线路构成密集障碍物空间
3. **自主避障与抗摆的矛盾**：需同时实现自主避障导航和负载摆动抑制

### 2.3 现有方法不足

| 方法类别 | 代表方法 | 局限性 |
|---|---|---|
| 传统规划方法 | A*、Dijkstra、RRT | 依赖高精度全局地图，面对动态环境实时性差 |
| 改进传统方法 | 改进A*、IAPF | 仍未根本解决非线性动力学约束下的实时规划问题 |
| DRL导航方法 | 改进PPO、动作掩码 | 针对吊运无人机研究不足，单纯位置控制导致剧烈残留摆动 |

## 3. 方法与技术路线 / Method and Technical Approach

### 3.1 总体架构：分层PPO-PID导航方法

核心思想：将高维复杂控制任务解耦——高层DRL(PPO)处理智能决策，底层经典控制(PID)处理稳定性跟踪。

**决策层**（运行频率2.5Hz）：PPO策略网络输出离散化局部航点
**执行层**（运行频率50Hz）：级联PID控制器实现轨迹精准跟踪

### 3.2 系统动力学建模

- **建模方法**：拉格朗日力学方法，二维纵向平面非线性动力学模型
- **广义坐标**：q = (x, z, α, θ)^T，其中(x,z)为无人机位置，α为吊绳摆角，θ为俯仰角
- **关键参数**：
  - 有效转动惯量 J_eff = ml² + J_cm（体现负载几何尺寸对系统惯性的影响）
  - 重力恢复力矩 mgl sinα（提供使摆角回归平衡位置的力矩）
- **基本假设**：无人机与负载均视为刚体；吊绳为无质量刚性连杆；悬挂点位于质心；忽略空气动力学对吊绳的影响
- **动力学方程**：M(q)q̈ + C(q,q̇)q̇ + G(q) = U + D

### 3.3 控制模型设计

基于时间尺度分离原则，设计双层级联PID控制模型：

**平动控制子系统（外环）**：
- 位置-速度串级控制策略（垂直Z轴、水平X轴）
- 垂直通道推力解算：Ft = (M+m)(g + a_cmd,z) / cosθ
- 水平通道姿态映射：θ_d = sat(a_cmd,x / g, θ_max)
- 所有积分项引入Anti-windup机制

**转动控制子系统（内环）**：
- 姿态角外环 → 角速率内环串级结构
- 最高控制带宽以快速跟踪期望俯仰角

### 3.4 MDP建模

**状态空间**（s_t ∈ R^s）：
- 无人机机体运动状态：位置(x,z)、线速度(ẋ, ż)
- 姿态与摆动状态：俯仰角θ、摆角α及其角速度(θ̇, α̇)
- 环境感知状态：与目标的相对距离p_rel、与K根高压线(障碍物)的距离向量d_obs

**动作空间**（离散化设计）：
- 导航距离指令 a_d ∈ {0,1,...,M-1}：M=9个距离等级（0~3.2m非均匀步长）
- 导航方位指令 a_ψ ∈ {0,1,...,N-1}：N=24个方位等级（15°等间距）

**状态转移**：由底层PID跟踪响应和拉格朗日动力学方程共同决定，仿真中为确定性过程。

### 3.5 复合奖励函数设计

总奖励：r_t = r_nav + r_obs + r_safe + r_eff + r_stab + r_term

| 奖励分量 | 设计思路 | 公式要点 |
|---|---|---|
| 进程导航奖励 r_nav | 基于势能差分，解决稀疏奖励收敛困难 | λ_prog·(d_{t-1} - d_t) - λ_dist·d_t |
| 静态障碍斥力奖励 r_obs | 基于幂函数的斥力场惩罚 | 进入惩罚半径R_pen时触发 |
| 动态安全奖励 r_safe | 惩罚朝向危险区域的速度矢量 | 速度方向指向障碍物时施加额外惩罚 |
| 路径效率奖励 r_eff | 基于投影的效率奖励，门控系数设计 | 安全第一效率第二：避障时允许绕路，开阔空域必须走直线 |
| 稳定性奖励 r_stab | 二次型惩罚摆角及角速度 | 全飞行包络内持续生效，主动消除摆动能量 |
| 稀疏终端奖励 r_term | 成功/失败判定 | 成功Rsucc=95；碰撞/越界-Pcrash=-50 |

### 3.6 PPO算法细节

- **Actor-Critic框架**：策略网络π_θ输出动作概率分布，价值网络V_φ评估状态预期回报
- **裁剪代理目标函数**：L_CLIP防止策略更新步长过大（裁剪范围ε=0.2）
- **广义优势估计(GAE)**：平衡偏差与方差（折扣因子γ=0.99，平滑因子λ=0.95）
- **总优化目标**：L(θ,φ) = E[L_CLIP - c₁·L_VF + c₂·S[π_θ]]

## 4. 实验设计与结果 / Experimental Design and Results

### 4.1 实验平台

- 仿真平台：Python + Gymnasium + PyTorch + Stable-Baselines3
- 硬件：i7-9750H CPU + NVIDIA GTX 1650 GPU
- 无人机模型：DJI FC30重型无人机（M=65kg，m=30kg负载，l=1.65m有效摆长）

### 4.2 网络结构

- Actor和Critic均包含：两层256神经元 + 一层128神经元隐藏层
- 激活函数：Tanh

### 4.3 环境随机化策略

| 随机化类型 | 范围 |
|---|---|
| 下层横担高度 | 20~32 随机生成 |
| 上层横担高度 | 36~45 随机生成 |
| 地面起降点 | 0~50 随机生成 |
| 作业目标 | 从四根线路中随机选取 |

### 4.4 对比算法

1. A*（栅格分辨率0.5m + B样条平滑）
2. RRT*（步长1.0m，最大迭代2000次 + B样条平滑）
3. APF（人工势场法 + 随机扰动机制）

### 4.5 核心实验结果

**上线任务（从地面上升至线路）：**

| 指标 | 本文算法 | A* | RRT* | APF |
|---|---|---|---|---|
| 平均轨迹长度/m | 42.651 | 47.121 | 45.647 | 108.265 |
| 最大摆动角度/° | 18.263 | 25.837 | 35.514 | 32.725 |
| 摆动强度指标/rad²·s | 0.361 | 0.672 | 0.461 | 1.655 |
| 平均运动时间/s | 31.135 | 42.730 | 37.530 | 59.960 |
| 规划成功率/% | 100.0 | 100.0 | 100.0 | 2.5 |

**下线任务（从线路下降至地面）：**

| 指标 | 本文算法 | A* | RRT* | APF |
|---|---|---|---|---|
| 平均轨迹长度/m | 42.729 | 45.209 | 43.264 | 47.789 |
| 最大摆动角度/° | 22.618 | 25.891 | 15.511 | 19.902 |
| 摆动强度指标/rad²·s | 0.349 | 0.573 | 0.205 | 0.428 |
| 平均运动时间/s | 24.975 | 36.780 | 31.050 | 37.305 |
| 规划成功率/% | 100.0 | 100.0 | 100.0 | 77.5 |

### 4.6 关键结论

- 规划成功率：上线和下线任务均为 **100%**
- 效率提升：平均运动时间较A*缩短约**27%~32%**，较RRT*缩短约**17%~20%**
- 抗摆性能：摆动强度指标始终控制在 **0.361 rad²·s 以下**
- APF在多线路复杂势场中频繁陷入局部极小值，上线任务成功率仅2.5%

## 5. 创新点与贡献 / Innovations and Contributions

1. **二维非线性动力学模型**：考虑阻尼效应与负载转动，采用拉格朗日力学方法建立完整吊运系统动力学模型
2. **分层PPO-PID协同架构**：高层PPO(2.5Hz)进行智能决策，底层PID(50Hz)精准跟踪，基于时序抽象原理明确划分决策与执行边界
3. **复合奖励函数设计**：融合安全避障、作业时效、路径效率、主动抗摆和终端稳停的多目标约束奖励函数，其中：
   - 势能差分形式的导航奖励保证最优策略一致性
   - 动态安全奖励不仅惩罚位置还惩罚朝向危险的速度矢量
   - 门控系数设计体现"安全第一，效率第二"原则
4. **主动抗摆能力**：在全飞行包络内持续抑制摆角，利用系统惯性进行动力学最优机动

## 6. 局限性与未来方向 / Limitations and Future Directions

### 6.1 当前局限

- **二维模型限制**：未考虑三维空间侧风及横向摆动
- **仿真与现实差距(Sim-to-Real)**：未涉及突发阵风、空气动力学地效等外部动态扰动
- **传感器与执行器**：未考虑真实传感器噪声与执行器延迟
- **单一场景验证**：仅在架空输电线场景验证，泛化性有待考察

### 6.2 未来研究方向

- 建立三维全空间动力学模型，设计多维度解耦控制策略
- 结合域随机化(Domain Randomization)与多传感器融合技术提升鲁棒性
- 在真实物理样机上进行部署与应用验证
- 探索动态扰动下的自适应控制策略
