## 一、研究问题与动机 / Research Problem and Motivation

### 1.1 核心问题 / Core Problem

多无人机协同任务规划（Multi-UAV Cooperative Task Planning）是NP-hard组合优化问题。本文聚焦3~20架小规模无人机的两类子问题：

- **协同侦察任务规划**（自顶向下 / Top-Down）：为N架无人机规划对N个敌方目标的最优侦察序列，综合考虑总航程、生存概率、负载均衡。
- **协同作战任务规划**（自底向上 / Bottom-Up）：将多无人机视为独立智能体，在局部可观测环境下学习协同作战策略。

### 1.2 现有方法的不足 / Limitations of Existing Methods

| 维度 | 自顶向下方法（启发式算法） | 自底向上方法（多智能体RL） |
|:---|:---|:---|
| 实时性 | 差，环境变化需重新优化 | - |
| 泛化性 | 仅针对特定问题实例 | - |
| 专业依赖 | 需大量专家知识和试错 | - |
| 经验回放 | - | 多机环境下互相干扰，被迫关闭 |
| 收敛稳定性 | - | DDRQN波动大 |

### 1.3 创新性评级 / Novelty Rating: ★★★★

**主要创新点：**
1. 将Transformer注意力机制的Seq2Seq框架应用于多机协同侦察建模（自顶向下），替代传统启发式算法
2. 提出EDDRQN（Enhanced Deep Distributed Recurrent Q-Network），在DDRQN基础上引入off-environment重要性采样，恢复经验回放机制（自底向上）
3. 在AirSim三维仿真平台上验证了Seq2Seq模型的有效性

## 二、理论框架与方法论 / Theoretical Framework and Methodology

### 2.1 问题建模

#### 2.1.1 协同侦察模型（第2章）

**问题定义**：N_V架无人机对N_T个目标进行侦察，需满足续航、生存、负载均衡三重约束。

**决策变量**：

$$X_{i,j}^v = \begin{cases} 1, & \text{无人机 } v \text{ 从 } i \text{ 飞行到 } j \\ 0, & \text{其他} \end{cases}$$

**约束条件**：

- 每个侦察节点被访问一次：$\sum_{i=0}^{N_T}\sum_{v=1}^{N_V} X_{i,j}^v = 1, \quad \forall j = 1 \cdots N_T$ —— 公式(2-1)
- 每个侦察节点离开一次：$\sum_{j=0}^{N_T}\sum_{v=1}^{N_V} X_{i,j}^v = 1, \quad \forall i = 1 \cdots N_T$ —— 公式(2-2)
- 续航里程约束：$\forall i \in R_v, j \in R_v, i \neq j, \quad s_{i,j} \cdot X_{i,j}^v \leq L, \quad \forall v = 1 \cdots N_V$ —— 公式(2-3)

**三目标优化函数**：

$$L(\pi) = a \times f_1 + b \times f_2 + c \times f_3, \quad 0 \leq a, b, c \leq a+b+c=1$$

其中：
- $f_1 = \min \sum_{i=1}^{N_T}\sum_{j=1}^{N_T}\sum_{v=1}^{N_V} X_{i,j}^v \cdot s_{i,j}$ —— 总飞行里程最小化（公式2-4）
- $f_2 = \max \sum_{n_{iv}} \prod_{i=a_v}^{b_v} P_i$ —— 生存覆盖函数最大化（公式2-7）
- $f_3 = \min \text{var}(\pi_v)$ —— 负载均衡方差最小化（公式2-8）

**生存覆盖函数**：节点级生存概率累积乘积：

$$\text{Sur}(n_{iv}) = \prod_{i=a_v}^{n_{iv}} P_i, \quad a_v \leq n_{iv} \leq b_v$$

示例：路径节点生存概率(0.9, 0.8, 0.7) → 节点覆盖值分别为0.9, 0.72, 0.50。

#### 2.1.2 协同作战模型（第4章，马尔科夫博弈）

用元组 $(n, S, A_1, \cdots, A_n, T, \gamma, R_1, \cdots, R_n)$ 描述。关键特性：

- 状态转移依赖联合动作：$T: S \times A_1 \times A_2 \times \cdots \times A_n \times S \rightarrow [0,1]$
- 回报函数依赖联合动作：$R_i(s, a_1, \cdots, a_n, s')$
- Q函数依赖联合策略：$Q_i^h(x, \mathbf{a}) = E\left\{\sum_{k=0}^{\infty} \gamma^k R_{i,k+1} \mid x_0=x, \mathbf{a}_0=\mathbf{a}, h\right\}$ —— 公式(4-2)

### 2.2 算法一：基于注意力Seq2Seq的协同侦察规划（第3章）

#### 2.2.1 架构概述

将协同侦察任务规划建模为序列到序列映射问题，输入为侦察目标节点坐标集合，输出为侦察序列 $\pi = (\pi_1, \cdots, \pi_{N_T})$。

策略概率分解：

$$p_\theta(\pi \mid s) = \prod_{t=1}^{n} p_\theta(\pi_t \mid s, \pi_{1:t-1})$$ —— 公式(3-5)

#### 2.2.2 编码器设计

**关键适配**：去除Position Embedding（因为侦察节点无序列相关性），对基地节点和侦察节点使用不同线性映射参数：

$$h_i^{(0)} = \begin{cases} W_x(x_i, y_i) + b_x^x, & i = 0 \text{ (基地)} \\ W_0(x_0, y_0) + b_0^x, & i = 1, \ldots, n \text{ (侦察节点)} \end{cases}$$ —— 公式(3-6)

**编码器结构**：
- Node embedding维度：$d_h = 128$
- MHA层：$M = 8$ 个heads，每head维度 $d_{M_h} = 16$
- FF层：隐含层维度512，ReLU激活
- 正则化：Batch Normalization（BN，优于Layer Normalization）
- 残差连接（skip-connection，源自ResNet）
- Graph embedding：$h_{gn} = \frac{1}{n}\sum_{i=1}^n h_i^{(N)}$

**注意力编码公式**：

$$\hat{h}_i = \text{BN}_l\left(h_i^{(l-1)} + \text{MHA}(h_1^{(l-1)}, \cdots, h_n^{(l-1)})\right)$$ —— 公式(3-7)

$$H_i^{(l)} = \text{BN}_l\left(\hat{h}_i + \text{FF}_l(\hat{h}_i)\right)$$ —— 公式(3-8)

#### 2.2.3 解码器设计

逐步决策（非并行），每步t的context embedding输入包含：
- Graph embedding $\bar{h}^{(N)}$
- 上一侦察节点embedding $h_{\pi_{t-1}}^{(N)}$
- 当前剩余续航 $\hat{D}_{i,t} = L - \delta_{\pi_t}$
- 当前节点生存概率 $p_i$

$$h^{(c)} = \begin{cases} [\bar{h}^{(N)}, h_{\pi_{t-1}}^{(N)}, D_{i,t}, p_i], & t > 1 \\ [\bar{h}^{(N)}, h_{\pi_0}^{(N)}, D_{0,t}, p_0], & t = 1 \end{cases}$$ —— 公式(3-9)

**简化MHA层**（无skip-connection/BN/FF）：

$$\mathbf{q}^{(c)} = W^Q h^{(c)}, \quad \mathbf{k}_i = W^K h_i^{(N)}, \quad \mathbf{v}_i = W^V h_i^{(N)}$$ —— 公式(3-10)

#### 2.2.4 掩码机制（Masking）

维护20节点的状态矩阵（表3-1），将不满足约束的节点相似度设为 $-\infty$：

$$u_j^{(c)} = \begin{cases} \frac{q^{(c)T} k_j}{\sqrt{d_k}}, & \text{if } j \neq \pi_{t'} \; \forall t' < t \\ -\infty, & \text{otherwise} \end{cases}$$ —— 公式(3-11)

**最终访问策略**（单层Attention + softmax）：

$$p_i = p_\theta(\pi_t = i \mid s, \pi_{1:t-1}) = \frac{e^{y_i^{(c)}}}{\sum_j e^{y_j^{(c)}}}$$ —— 公式(3-14)

#### 2.2.5 REINFORCE训练

**目标函数**：$J(\theta) = a \times f_1 + b \times f_2 + c \times f_3$ —— 公式(3-15)

**策略梯度**：$\nabla_\theta J(\theta) = E_{\pi_\theta}[\nabla_\theta \log \pi_\theta(s,a) \cdot Q^\pi(s,a)]$ —— 公式(3-16)

**损失函数**：

$$\mathcal{L}(\theta \mid s) = E_{p_\theta(\pi \mid s)}\left[(L(\pi) - b(s)) \nabla \log p_\theta(\pi \mid s)\right]$$ —— 公式(3-17)

Baseline采用滑动平均：$M \leftarrow \beta M + (1-\beta)L(\pi)$，$\beta = 0.8$

### 2.3 算法二：EDDRQN协同作战网络（第4章）

#### 2.3.1 算法演进链

```
DQN → DRQN (加LSTM) → IQL (独立Q学习) → DDRQN (DRQN+IQL+消息+参数共享)
  → EDDRQN (+ off-environment重要性采样 + 恢复经验回放)
```

#### 2.3.2 DDRQN的三大改进（基准）
1. **邻近动作输入**：t+1时刻输入t时刻的动作a和消息z，LSTM记忆动作历史
2. **参数共享**：共享Q-Net参数，保留独立内部状态 $h_t^m$
3. **关闭经验回放**：避免过时经历误导

#### 2.3.3 EDDRQN核心创新：Off-Environment重要性采样

**问题本质**：多智能体中其他智能体策略 $\pi_{-m}$ 不断变化，导致经验回放中的数据分布漂移。

**解决方案**：将 $\pi_{-m}^c(\mathbf{a}_{-m} \mid s)$ 存储在增强记忆单元中：

$$\text{Memory} = \langle s, a_m, r, \pi_{-m}(\mathbf{a}_{-m} \mid s), s' \rangle^{(t_c)}$$

回放时通过重要性采样矫正：

$$L(\theta) = \sum_{i=1}^{b} \frac{\pi_{-m}^{t_r}(a_{-m} \mid s)}{\pi_{-m}^{t_i}(a_{-m} \mid s)} \left[(y_i^{DQN} - Q(s,a;\theta))^2\right]$$ —— 公式(4-5)

**增强MDP定义**：$\hat{G} = \langle \hat{S}, A, P, \hat{r}, Z, O, m, \gamma \rangle$，其中 $\hat{S} = \{s, \tau_{-a}\} \in \hat{S} = S \times T^{n-1}$

#### 2.3.4 EDDRQN网络结构

每个智能体LSTM网络输入 $(o_t^m, z_{t-1}^m, a_t, m)$：
- $(m, a_t)$ → 查表映射 → 128维embedding
- $z_{t-1}^m$ → 单层感知机 → 128维embedding
- $o_t^m$ → 任务网络 → 128维embedding
- 拼接为 z_s → 两层LSTM → 输出Q值 + 消息z

### 3.3 实验结果

#### 3.3.1 Seq2Seq协同侦察模型

**训练收敛情况**（图3-7~3-9）：
- 目标函数 $L(\pi)$ 持续下降并收敛
- 平均飞行总里程随训练逐步降低
- 生存覆盖值显著提升
- 负载均衡方差趋近零（侦察节点趋向平均分配）
- **关键发现**：求解时间不随性能提升而增加（约3.45ms/case）

**求解时间对比**（表5-2）：

| 模型 | 规模 | 单组求解时间 | 备注 |
|:---|:---:|:---:|:---|
| **Attention-AM (CPU)** | 20节点 | **3.45~4.46 ms** | 可批量并行 |
| **Attention-AM (CUDA)** | 100节点 | **6.62 ms** | GPU加速 |
| TSC-GA (遗传算法) | 100节点 | **2 s** | 需每实例重新优化 |
| SDVRPSC (邻域搜索) | 20节点 | **29.3~50.2 s** | 需每实例重新优化 |
| SDVRPSC (邻域搜索) | 100节点 | **48.3~79.6 s** | 需每实例重新优化 |

**性能提升**：Attention-AM求解速度比启发式算法快约1000倍。

**模型质量对比**（表5-3）：

| 模型 | 平均距离 | 平均生存覆盖 | 相对距离 | 相对生存覆盖 |
|:---|:---:|:---:|:---:|:---:|
| Attention-AM | 7.766 | 12.916 | 118.11% | **140.10%** |
| Attention-CVRP20 | 6.575 | 9.219 | 100% | 100% |

**结论**：AM模型以仅18.11%的路径增长换取了40%的生存覆盖提升。

#### 3.3.2 EDDRQN协同作战模型

**实验配置**：3架无人机 vs 25个敌方目标，180秒时限，奖励：击毁目标+10，无人机被毁-10。

**对比结果**（图4-5~4-10）：

| 平均奖励 | **最高** | 中等 | 最低 |

## 五、局限性与未来方向 / Limitations and Future Directions

### 5.1 已知局限

1. **模型简化**：协同侦察模型相对现实环境存在差距，未考虑风场、动态威胁等因素
2. **权重手动设定**：多目标函数的权重 $[a, b, c] = [0.3, -0.5, 0.2]$ 为手动调参，未必最优
3. **算法天花板**：使用REINFORCE（方差大，样本效率低），未尝试更先进的PPO/A3C等
4. **作战环境简化**：SC2LE环境与真实战场仍有差距
5. **规模限制**：仅研究3~20架小规模问题，大规模多机场景未涉及

### 5.2 作者建议的未来方向

1. 引入更多环境因素增强模型适用性
2. 自动搜索最优目标函数权重
3. 替换为更强的RL算法（如PPO、A3C）
4. 设计泛用性更强的组合优化网络（不同问题=不同数据分布的同一形式）
5. 更成熟的多智能体理论和算法应对大规模扩展

### 6.2 可借鉴的具体技术

1. **掩码机制**：在Seq2Seq解码器中用 $-\infty$ 掩码排除非法动作，可直接借鉴用于本项目的动作掩码设计
