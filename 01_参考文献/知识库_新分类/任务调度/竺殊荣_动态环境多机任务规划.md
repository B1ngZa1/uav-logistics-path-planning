## 二、研究问题与动机

### 2.1 核心问题

在动态战场环境下，多无人机协同任务规划面临四个关键问题：

1. **模型失真**：现有任务分配模型（MTSP、CVRP、CMTAP）为满足模型标准而忽略实际战场约束条件，如异构无人机属性、多任务类型、武器载荷等
2. **异构性缺失**：现有模型中无人机和任务类型多为单一，缺乏对异构无人机（侦察型、打击型、巡航型、察打一体型）和多任务类型的考量
3. **计算效率低**：最优化方法（匈牙利算法、MILP）随问题规模呈几何级增长，实用性低
4. **动态适应性差**：现有算法需要全局环境信息，面对动态不确定环境效率大幅下降

### 2.2 研究意义

- 军事领域：情报收集、监视、火力打击的无人机集群协同作战
- 民用领域：快递配送、农业植保、环境监测等多机协同场景
- 提升机群执行任务的成功率、效率、容错性和鲁棒性

## 三、核心方法与技术贡献

### 3.1 贡献一：扩展的CMTAP任务分配模型

**问题描述**：用四元组 {U, T, M, R} 表示：
- U = {U_1, U_2, ..., U_{N_U}}：无人机集合
- T = {T_1, T_2, ..., T_{N_T}}：任务集合
- M = {S, A, E}：任务类型（侦察/攻击/巡航）
- R：约束条件集合

**关键扩展**（相对原始CMTAP）：
- 引入**武器载荷约束** P_{U_i}
- 引入**巡航任务**（有起点和终点），导致 d_{ij} ≠ d_{ji}，建立**非对称任务分配模型**
- 无人机类型分为4类：M_{U_i} ∈ {{S}, {A}, {E}, {S,A}}

**目标函数**：

$$J = c \cdot J_1 + J_2$$

其中：

$$J_1 = 1 - \frac{\sum_{i=1}^{N_U} N_{U_i}}{N_T}$$

$$J_2 = \sum_{u=1}^{N_U} \sum_{i=1}^{N_T} \sum_{j=1}^{N_T} X_{iju} \cdot d_{iju}$$

- J_1：未完成任务比例（最小化目标）
- J_2：总航程代价
- c：惩罚因子，用于统一 J_1 和 J_2 的数量级
- X_{iju} ∈ {0,1}：决策变量，无人机 u 执行完任务 i 后执行任务 j

**约束条件**：

| 编号 | 公式 | 含义 |
|---|---|---|
| (2.6) | Σ_{u=1}^{N_U} y_{ui} = 1 | 每个任务只能分配给一架无人机 |
| (2.7) | Σ_{i=1}^{N_T} X_{iju} = y_{uj} | 流入约束 |
| (2.8) | Σ_{j=1}^{N_T} X_{iju} = y_{ui} | 流出约束 |
| (2.9) | Σ_{i=1}^{N_T} y_{ui} Q_i ≤ P_u | 武器载荷约束 |
| (2.10) | Σ_{i=1}^{N_T}Σ_{j=1}^{N_T} X_{iju} d_{iju} ≤ D_u | 最大航程约束 |

### 3.2 贡献二：基于SOM神经网络的任务分配算法

**SOM网络设计**：
- **输入层**：N_T 个节点，每个节点代表一个任务，权值为任务点经纬度坐标
- **竞争层**：N_T × N_U 二维平面阵，第 i 列权值初始化为无人机 U_i 的经纬度坐标

**获胜节点选取**（算法1）：
1. 随机选取任务 T_k 作为网络输入
2. 检查每架无人机的约束条件（武器载荷、剩余航程），得到可行集 Capable_{T_k}
3. 使用 haversine 方程计算距离，选取最近节点：

$$D_{ki} = 2r \cdot \arcsin\sqrt{\sin^2\frac{lat_{T_k} - lat_{ki}}{2} + \cos(lat_{ki})\cos(lat_{T_k})\sin^2\frac{lon_{T_k} - lon_{ki}}{2}}$$

4. i* = argmin_i D_{ki}

**优胜邻域计算**（算法2，WTA+Kohonen规则结合）：
- 距离阈值：D_min = D_ave / 3
- 若 D_{ki*} ≤ D_min：采用Kohonen规则，优胜邻域 = 第 i* 列所有节点
- 若 D_{ki*} > D_min：采用WTA规则，优胜邻域 = 仅获胜节点

**权值更新**：

当 D_{ki*} > D_min 时：
$$W_{(j,i)} = W_{(j,i)} + \alpha \cdot (W_{T_k} - W_{(j,i)})$$

否则：
$$W_{(j,i)} = W_{T_k}$$

学习率衰减：
$$\alpha = \beta \cdot e^{-t/t_{max}}$$

### 3.3 贡献三：基于分组策略的动态重分配方法

**触发场景**：任务取消/增加、任务位置更新、无人机故障

**两步策略**：

**Step 1 - SOM聚类分组**：
- 输入层：待重分配任务集 T_re
- 竞争层：一维线阵，类簇数 = 参与重分配的无人机数 n
- 初始类簇中心 = 无人机当前位置坐标
- 优胜邻域半径：r(t) = C_1(1 - t/t_max)
- 权值更新：w_{ij}(t+1) = w_{ij}(t) + η(N)[X_i - w_{ij}(t)]，其中 η(N) = C_2 · e^{-N}

**Step 2 - 精英蚁群算法调整任务序列**：

路径选择概率：

$$P_{ij}^k(t) = \frac{\tau_{ij}(t)^\alpha \eta_{ij}(t)^\beta}{\sum_{r \in allowed_k} \tau_{ir}(t)^\alpha \eta_{ir}(t)^\beta}, \quad j \in allowed_k$$

信息素局部更新：
$$\tau_{ij}(t+1) = \rho \cdot \tau_{ij}(t) + \Delta\tau_{ij}(t, t+1)$$

精英蚂蚁更新：

$$\Delta\tau_{ij}^{best} = \begin{cases} 1/d_{ij} & \text{最优路径包含}(i,j) \\ 0 & \text{otherwise} \end{cases}$$

$$\Delta\tau_{ij}(t, t+n) = \lambda \Delta\tau_{ij}^{best}$$

推荐参数：α=1, β∈[2,5]

### 3.4 贡献四：基于Q-learning+效用追踪的路径规划

**MDP模型** ⟨S, A, r, p⟩：

**状态空间**：栅格化环境，步长 = 无人机最小航迹段长度；威胁区标注为1（禁飞），可飞区标注为0

**动作空间**：A = [0, 1, 2, 3, 4]（直飞、右转45度、左转45度、右转90度、左转90度）

**状态转移概率**：

$$P_{ss'}^a = \begin{cases} 0 & \text{if } s' \in O \text{ or } s' \notin S \\ 1 & \text{otherwise} \end{cases}$$

**瞬时奖励函数**：
$$r_{ss'}^a = w_1 \cdot f_d + w_2 \cdot f_o + w_3 \cdot f_a$$

- f_d：能见度（距目标距离的倒数）
- f_o：威胁程度（所有威胁源距离度量之和）
- f_a：飞行动作惩罚（直飞=0, 45度转弯=-0.2, 90度转弯=-1）

**效用追踪（Eligibility Traces）**：

$$ET_0(s,a) = 0$$

$$ET_t(s,a) = \begin{cases} \gamma\lambda ET_{t-1}(s,a) + 1 & s_t = s, a_t = a \\ \gamma\lambda ET_{t-1}(s,a) & \text{otherwise} \end{cases}$$

ET值饱和上限：
$$ET_{max}(s,a) = \frac{1}{1 - \gamma\lambda}$$

**Q值更新**（结合ET，单步更新）：
$$\delta = r + \gamma \max_{a'} Q(s', a') - Q(s,a)$$
$$Q(s,a) \leftarrow Q(s,a) + \alpha \delta E(s,a)$$
$$E(s,a) \leftarrow \gamma\lambda E(s,a)$$

**动作选择策略**：Boltzmann策略 + 轮盘法

$$w(s,a) = \frac{\exp(Q(s,a)/T)}{\sum_{a_i \in A} \exp(Q(s,a_i)/T)}$$

温度退火：T(t+1) = h · T(t)，h ∈ (0,1)

## 四、实验设计与结果

### 4.1 实验一：VRPLIB标准数据集（任务分配）

使用国际通用算例库VRPLIB的10个算例，将SOM算法与蚁群算法对比：

| 算例 | SOM平均代价 | SOM最小代价 | ACO平均代价 | ACO最小代价 |
|---:|---:|---:|---:|---:|
| E016-03m | 223.982 | 213.386 | 225.162 | 215.786 |
| E016-05m | 224.881 | 219.116 | 240.665 | 227.289 |
| E021-06m | 312.545 | 297.010 | 325.663 | 307.325 |
| E022-06m | 334.410 | 310.924 | 356.368 | 331.426 |
| E022-04g | 282.884 | 261.691 | 287.541 | 261.691 |
| E023-05S | 478.858 | 447.866 | 495.573 | 476.865 |
| E030-04S | 394.111 | 388.701 | 447.550 | 421.906 |
| E033-03N | 1906.519 | 1788.775 | 2039.258 | 1807.155 |
| E045-04f | 573.824 | 536.258 | 740.088 | 648.606 |
| E048-04y | 39941.686 | 38025.515 | 43306.860 | 40977.612 |

**结论**：SOM算法在所有算例的平均和最小任务分配代价上均优于蚁群算法，且随任务数增加优势更显著。SOM算法的平均执行时间也均快于蚁群算法。

### 4.2 实验二：六算法对比（21架无人机 + 13个目标点场景）

| 算法 | 平均代价 | 平均执行时间(s) |
|---|---:|---:|
| **SOM神经网络** | **140.808** | **~0.072** |
| K均值聚类 | 146.650 | ~0.065 |
| 拍卖算法 | 144.558 | ~0.001 |
| 贪心算法 | ~150.786 | ~0.002 |
| 粒子群算法 | ~312.888 | ~1.075 |
| 遗传算法 | ~330.501 | ~1.426 |

**结论**：SOM算法平均代价最低（140.808），拍卖算法执行最快但代价略高，粒子群和遗传算法代价和时间均较差。

### 4.3 实验三：Q-learning路径规划

| 指标 | Q-learning | Q-learning + ET |
|---|---|---|
| 收敛所需episode数 | ~5500 | ~4000 |
| 路径质量 | 能避开威胁区 | 能避开威胁区，路径更短 |
| 震荡程度 | 较明显 | 不明显 |

**实验参数**：α = 0.1, γ = 0.8, λ = 0.3, w_1 = 0.4, w_2 = 0.3, w_3 = 0.3

## 五、创新点与局限性分析

### 5.1 创新点评级

| 创新点 | 评级 | 说明 |
|---|---|---|
| 扩展CMTAP模型（载荷约束+巡航任务+非对称） | ★★★☆ | 工程层面的合理扩展，增加实用性 |
| SOM神经网络用于任务分配 | ★★★☆ | 生物启发方法的合理迁移，结构简单高效 |
| WTA+Kohonen双规则结合 | ★★☆☆ | 改进幅度有限，阈值设计较经验化 |
| SOM聚类 + 精英蚁群的动态重分配 | ★★★☆ | 分组策略降低重分配复杂度，实用价值高 |
| Q-learning + Eligibility Traces路径规划 | ★★★☆ | 经典组合的有效应用，收敛速度提升明显 |
| Boltzmann + 轮盘法动作选择 | ★★☆☆ | 标准方法组合，创新性一般 |

### 5.2 局限性

1. **二维环境限制**：所有实验在2D场景下进行，未考虑三维空间（高度约束、地形起伏）
2. **单机路径规划**：Q-learning仅用于单架无人机路径规划，未考虑多机协同避碰
3. **实验规模偏小**：VRPLIB最大算例仅48个任务，仿真平台最大场景仅21架无人机+13目标点
4. **SOM收敛性**：未提供SOM算法收敛性的理论证明
5. **参数敏感性**：D_min、β、C_1、C_2 等超参数缺乏系统性的消融实验
6. **战场简化**：动态重分配仅考虑3种触发场景，实际战场中威胁模型更为复杂
7. **缺乏与深度强化学习对比**：2019年深度RL已有长足发展，仅与经典方法对比说服力有限
