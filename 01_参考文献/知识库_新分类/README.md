## 知识卡片格式

每篇论文生成一个 `.md` 文件，格式如下：

```
# 论文标题
> 来源/作者/单位/日期/DOI
## 一、基本信息（表格）
## 二、摘要与贡献
## 三、核心方法（含公式）
## 四、实验结果（含数据表格）
## 五、与本项目关联（星级评分）
## 六、可借鉴要点
```

## 编号规则

- 中文论文：`[作者姓]_[关键词缩写].md`，如 `廖勇_配送路径规划综述.md`
- 英文论文：`[编号]_[作者]_[关键词].md`，如 `[25]_Schulman_PPO.md`
