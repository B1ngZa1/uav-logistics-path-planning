## 2. 核心内容摘要

### 2.1 研究问题

固定翼无人机集群编队在复杂环境中的避障控制面临三大挑战：
1. 集群避障时个体陷入局部最优，导致一致性差（速度差峰值达6.0m/s）
2. 传统集群算法在未知复杂多障碍物环境中避障能力不足
3. 传统多机协同系统决策层与控制层分离，无法实现端到端分布式控制

### 2.2 主要贡献（四项）

| 序号 | 贡献 | 对应章节 |
|------|------|----------|
| 1 | 共享障碍物信息的集群协同避障算法 | 第3章 |
| 2 | 单智能体RL + 集群算法的智能避障方法 | 第4章 |
| 3 | 多智能体联合近端策略优化算法（MAJPPO） | 第5章 |
| 4 | ROS + PX4 + Gazebo 的软件在环仿真（SITL）平台 | 第6章 |

## 3. 核心算法与方法

### 3.1 无人机运动学模型

**完整6-DOF 12状态模型**：状态变量为 [p_n, p_e, h, u, v, w, phi, theta, psi, p, q, r]，含4个输入 delta_a, delta_e, delta_r, delta_t。

**简化运动学模型**（集群算法用）：

x_dot = V*cos(psi), y_dot = V*sin(psi)

V_dot = (1/tau_v) * (V_c - V)

psi_ddot = -(1/tau_psi_dot) * psi_dot + (1/tau_psi) * (psi_c - psi)

h_ddot = -(1/tau_h_dot) * h_dot + (1/tau_h) * (h_c - h)

参数值：tau_v=0.2, tau_psi_dot=0.625, tau_psi=0.0156, tau_h_dot=0.7072, tau_h=1

### 3.2 基于Olfati-Saber的集群控制算法

每个智能体输入三部分组成：

u_i = u_i^alpha + u_i^beta + u_i^gamma

- u_i^alpha：智能体间聚合（保持期望距离 d、速度一致）
- u_i^beta：避障项（在障碍物表面构造虚拟 beta-智能体）
- u_i^gamma：导航反馈（追踪虚拟领航者）

beta-智能体构造（球形障碍物，半径 R_k，中心 y_k）：

q_hat = mu * q_i + (I - mu) * y_k, p_hat = mu * P * p_i

其中 mu = R_k / ||q_i - y_k||

### 3.3 共享障碍物信息的协同避障算法（创新点1）

**核心思想**：无人机不仅共享位置/速度，还共享探测到的障碍物信息 (q_hat, p_hat)。

选择规则：收到多个障碍物信息时，选择速度最大值 max(||p_hat_tau||) 的信息对；速度相同时选最小距离 min(||q_i - q_hat_tau||) 的。

新增避障项 u_i^{beta,tau}：使无人机在位置上远离 q_hat_tau，在速度上接近 p_hat_tau。

### 3.4 集群智能避障算法（创新点2）

**核心思想**：PPO算法控制虚拟领航者，集群算法控制无人机跟随领航者，形成动态反馈。

奖励函数：R = R_obstacle + R_leader + R_center

- R_leader：奖励领航者接近目的地
- R_center：奖励集群中心缩小与领航者距离
- R_obstacle：奖励集群中心避开障碍物

**PPO网络结构**：Critic用128单元LSTM + 128单元FC(TanH)；Actor用128单元LSTM + 128单元FC(TanH)，输出为球坐标 (R, alpha, beta) 转速度向量。方差矩阵 C = 0.05I。

### 3.5 MAJPPO算法（创新点3）

**核心思想**：中心化训练分布式执行（CTDE）。通过加权平均不同智能体的状态值函数获得联合状态值函数。

联合状态值函数：

V_joint^i = beta * V^i(O_t^i) + (1-beta) * V^j(O_t^j)

V_joint^j = beta * V^j(O_t^j) + (1-beta) * V^i(O_t^i)

Critic损失函数：L_t = E_t[(r_t + gamma * V(O_{t+1}) - V(O_t))^2]

Actor目标函数（PPO截断替代目标）：

L_CLIP(theta) = E_t[min(l_t(theta)*A_hat_t, clip(l_t(theta), 1-eps, 1+eps)*A_hat_t)]

L_CLIP+S(theta) = E_t[L_CLIP(theta) + c*S[pi_theta](O_t)]

## 5. 关键实验结果

### 5.1 协同避障算法（第3章）

| 指标 | 集群避障算法 | 协同避障算法 | 提升 |
|------|-------------|-------------|------|
| 速度差峰值 | 6.0 m/s | 1.0 m/s | -- |
| E_h_dot（高度变化率一致性） | 178.16 | 127.21 | 28.60% |
| E_psi（航向角一致性） | 43.51 | 31.81 | 26.89% |
| dist_dot（机间距离变化率） | 373.27 m/s | 223.75 m/s | 40.06% |

### 5.2 智能避障算法（第4章，综合两次实验平均）

| 指标 | 集群避障算法 | 智能避障算法 | 提升 |
|------|-------------|-------------|------|
| E_v（速度一致性） | 675.85 | 525.56 | 22.23% |
| E_d（机间距离一致性） | 1634.01 | 879.23 | 41.29% |
| E_phi（滚转角一致性） | 40.82 | 19.24 | 52.62% |
| E_psi（偏航角一致性） | 28.23 | 12.69 | 53.50% |
| E_theta（俯仰角一致性） | 8.25 | 4.37 | 33.94% |

训练收敛：约5000个回合。

### 5.3 MAJPPO算法（第5章）

**编队任务**：MAJPPO (beta=0.9999) 在55000次迭代收敛，MAIPPO在80000次迭代收敛。

**编队避障任务**（MAJPPO beta=0.9）：

| 指标 | MAIPPO | MAJPPO | 提升 |
|------|--------|--------|------|
| E_d（距离一致性） | 5408.17 | 3097.77 | 42.72% |
| E_h（高度一致性） | 1609.09 | 970.94 | 39.66% |
| E_v（速度一致性） | 126.46 | 116.05 | 8.23% |

MAJPPO收敛曲线更稳定，MAIPPO收敛后不稳定。

### 5.4 SITL验证

- **集群算法SITL**：3架PX4固定翼，速度保持在20m/s附近，机间距离60m波动，偏航角0.707rad附近，验证可行性。
- **MAJPPO编队SITL**：2架PX4固定翼，仅达到"能控"程度。期望速度22m/s实际最大24m/s，期望俯仰角-0.1rad实际最小-0.3rad，与数字仿真模型差异有关。

### 6.2 与本项目（无人机配送调度）的关联

| 本论文技术 | 本项目应用场景 |
|------------|---------------|
| 集群一致性算法（Reynolds三规则） | L4多机协同配送的集群运动控制 |
| 共享障碍物信息避障 | 城市环境中的建筑/禁飞区规避 |
| PPO控制虚拟领航者 | L3/L4层级的RL路径规划 |
| MAJPPO（CTDE框架） | 多机配送的联合决策，与本项目CTDE框架高度对齐 |
| 简化运动学模型 | L1/L2层级的2D环境可直接复用 |
| 6-DOF 12状态模型 + PI控制环 | L3/L4层级的3D飞行仿真参考 |
| ROS+PX4+SITL平台 | 从仿真到实飞的过渡验证 |

### 6.3 局限性

1. 仅针对固定翼无人机，旋翼机未涉及
2. 障碍物统一简化为球形，与城市建筑环境有差距
3. MAJPPO仅在最多3架无人机上验证，可扩展性未证明
4. SITL中RL模型精度不足，仅达到"能控"程度
5. 未涉及多机通信延迟和通信中断的鲁棒性分析
6. 奖励函数设计依赖大量人工试错
