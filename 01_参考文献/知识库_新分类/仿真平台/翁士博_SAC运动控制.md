## 二、核心贡献 / Key Contributions

### 2.1 研究目标
研究深度强化学习SAC算法在**实物运动控制**中的应用，重点解决从**仿真训练到实物控制**的迁移（sim-to-real transfer）问题。

### 2.2 两大实验载体

| 载体 | 任务 | 特点 |
|---|---|---|
| 四旋翼无人机（仿真） | 上升至5m并悬停 | 12维连续状态、4维连续动作 |
| 直线一级倒立摆（仿真+实物） | 起摆 + 稳摆 | 4维状态、1维动作（速度）；基于PLC+伺服电机硬件平台 |

### 2.3 核心方法论：仿真训练 → 实物迁移方案

**三步法：**
1. **精细建模**：分析真实系统与典型模型的主要差异（控制周期、延迟、误差），在仿真中模拟具体控制环节
2. **浮动参数训练**：将被控对象参数在一定范围内随机浮动，提升泛化能力
3. **实物额外训练**：若仿真策略在实物上效果不佳，在真实环境中继续训练弥补差距

### 2.4 关键发现

| 发现 | 详情 |
|---|---|
| 起摆控制可直接迁移 | 仿真训练策略模型可直接用于实物起摆（120步内完成） |
| 稳摆控制需额外训练 | 仿真策略在实物上存在角度发散问题，需在实物上继续训练约1000回合 |
| SAC接近PID性能 | 实物稳摆控制平均方差：SAC=0.1434 vs PID=0.1128，差距不大 |
| 奖励函数设计是核心难题 | 稀疏奖励不收敛；reward shaping存在目标歧义问题 |

## 三、算法与理论 / Algorithm & Theory

### 3.1 SAC算法核心公式

**熵正则化最优策略：**

$$\pi^* = \arg\max_\pi \mathbb{E}_{\tau \sim \pi} \left[ \sum_{t=0}^{\infty} \gamma^t \left( R(s_t, a_t, s_{t+1}) + \alpha H(\pi(\cdot|s_t)) \right) \right]$$

**策略熵：**

$$H(\pi(\cdot|s_t)) = -\sum_{t=1}^{\infty} \pi(\cdot|s_t) \log \pi(\cdot|s_t)$$

**软Q函数Bellman方程：**

$$Q^\pi(s,a) = \mathbb{E}_{s' \sim P} \left[ R(s,a,s') + \gamma V^\pi(s') \right]$$

**Q网络损失函数：**

$$L(\varphi_i, D) = \mathbb{E}_{(s,a,r,s',d) \sim D} \left[ \left( Q_{\varphi_i}(s,a) - (r + \gamma(1-d)V_{\psi_{\text{targ}}}(s')) \right)^2 \right]$$

**V网络损失函数：**

$$L(\psi, D) = \mathbb{E}_{s \sim D} \left[ \left( V_\psi(s) - \left( \min_{i=1,2} Q_{\varphi_i}(s, \tilde{a}) - \alpha \log \pi_\theta(\tilde{a}|s) \right) \right)^2 \right]$$

**重参数化技巧（压扁高斯策略）：**

$$\tilde{a}_\theta(s, \xi) = \tanh(\mu_\theta(s) + \sigma_\theta(s) \odot \xi), \quad \xi \sim \mathcal{N}(0, I)$$

**策略网络损失函数：**

$$L(\theta, N) = \mathbb{E}_{s \sim D, \xi \sim \mathcal{N}} \left[ Q_{\varphi_1}(s, \tilde{a}_\theta(s, \xi)) - \alpha \log \pi_\theta(\tilde{a}_\theta(s, \xi)|s) \right]$$

### 3.2 SAC五网络架构

| 网络 | 功能 | 参数更新方式 |
|---|---|---|
| $\pi_\theta(s)$ 策略网络 | 输出动作 | 训练同步更新 |
| $Q_1(s,a)$ 动作价值网络1 | 输出Q值 | 训练同步更新 |
| $Q_2(s,a)$ 动作价值网络2 | 输出Q值（双Q技巧） | 训练同步更新 |
| $V_\psi(s)$ 状态价值网络 | 输出状态价值 | 训练同步更新 |
| $V_{\text{targ}}(s')$ 目标V网络 | 输出下一状态价值 | 软更新：$\psi_{\text{targ}} \leftarrow \rho \psi_{\text{targ}} + (1-\rho)\varphi$ |

### 3.3 倒立摆恒速控制模型

**稳摆模型（线性化，$|\theta| < 10°$）：**

$$\theta[k] = \frac{8l\theta[k-1] - 4l\theta[k-2] + T\dot{v}[k]}{4l - 3gT^2}$$

**起摆模型（非线性，$|\theta| < 180°$）：**

$$\theta[k] = \frac{8l\theta[k-1] - 4l\theta[k-2] + 3T\cos\theta[k-1](v[k]-v[k-1]) + 3gT^2\sin\theta[k-1]}{4l}$$

### 3.4 四旋翼动力学模型

**X型四旋翼六自由度方程（式3-1）：**

$$\ddot{\varphi} = \dot{\theta}\dot{\psi}\frac{I_y - I_z}{I_x} - \frac{J_r}{I_x}\dot{\theta}\Omega + \frac{l}{I_x}U_2 - \frac{lK_4}{m}\dot{\varphi}$$

$$\ddot{\theta} = \dot{\varphi}\dot{\psi}\frac{I_z - I_x}{I_y} + \frac{J_r}{I_y}\dot{\varphi}\Omega + \frac{l}{I_y}U_3 - \frac{lK_5}{m}\dot{\theta}$$

$$\ddot{z} = (\cos\varphi\cos\theta)\frac{1}{m}U_1 - g - \frac{K_3}{m}\dot{z}$$

## 四、实验设计与结果 / Experiments & Results

### 4.1 四旋翼无人机仿真控制试验

**任务：** 从[0,0,0]垂直上升至[0,0,5]并悬停

**SAC超参数：**

| 参数 | 设置值 | 说明 |
|---|---|---|
| 学习率 | 2×10⁻³ | 0.0002~0.0005范围内选取 |
| 熵正则化系数 α | 0.3 | 一般任务取0.2，本任务探索难度高取0.3 |
| 衰减因子 γ | 0.99 | 算法能收敛前提下尽可能大 |
| 经验池大小 | 5×10⁶ | 10⁶数量级 |
| 网络结构 | [300, 400] 双隐层 MLP | ReLU激活函数 |
| 批处理样本数 | 128 | — |
| 最大回合数 | 1×10⁴ | — |
| 每回合最大时间步 | 400 | — |
| 优化器 | Adam | — |

**奖励函数设计经验（★重要）：**

| 经验 | 说明 |
|---|---|
| 采用reward shaping | 稀疏奖励在连续控制任务中几乎不收敛 |
| 线性化奖励函数 | 非线性奖励函数更难收敛，奖励分布均匀利于探索 |
| 奖励尽量非负 | 惩罚过多导致智能体动作保守，甚至不采取动作 |

**最终奖励函数（式3-4）：**

$$r = \begin{cases} 10 - w_1 d - w_2 \max(|\varphi|, |\theta|, |\psi|), & t=0 \text{（未越界）} \\ -100, & t=1 \text{（越界）} \end{cases}$$

**不同权重效果：**

| w₁ | w₂ | 抖动幅度 |
|---:|---:|---|
| 0.8 | 0.03 | < 20° |
| 0.8 | 0.05 | < 10° |
| 0.8 | 0.08 | < 7.5°（悬停性能下降） |

**学习率对比试验：**

| 学习率 | 最大奖励回合 | 最大奖励值 | 稳定性 |
|---:|---:|---:|---|
| 0.0001 | 9930 | 3521.31 | 最稳定 |
| 0.0002 | 8780 | 3513.15 | 适中（推荐） |
| 0.0005 | 5275 | 3520.49 | 5800回合后恶化 |

**泛化能力试验：**
- 固定参数训练（m=1.5kg）→ m=1.4/1.6kg控制效果差异明显（过拟合）
- **浮动参数训练**（m∈[1.4,1.6]kg）→ 不同质量控制效果几乎一致（泛化能力强）
- 代价：单一质量控制效果略差于固定参数训练

### 4.2 倒立摆起摆控制试验

**问题定义：** 摆杆从自然下垂（θ=0°）起摆至|θ|≥175°，最大200步

**奖励函数设计与改进：**

| 奖励方案 | 效果 |
|---|---|
| 稀疏奖励 | 1000回合内无明显进步 |
| reward shaping: r=|θ/180°| | 100回合起摆成功，但200回合后训练效果下降（目标歧义） |
| 额外奖励方案（式5-2，β=8） | 消除长期训练退化问题，起摆时间有效降低 |

**起摆训练退化原因分析：**
智能体发现避免起摆成功、反复摆动可获得更大累积回报 R（因起摆成功后N减小导致R减小）。

**起摆SAC超参数：**

| 参数 | 设置值 |
|---|---|
| α（熵系数） | **0.1**（起摆需精确控制，α不宜过大） |
| γ | 0.99 |
| minibatch | 256 |
| 经验池容量 | 500,000 |
| 网络结构 | [300, 400] |

**起摆Sim-to-Real结果：**
- 仿真训练中浮动摆杆长度 l=[0.42, 0.45]（实际 l=0.37，加长以模拟阻力）
- 仿真与实物起摆效果**极为相近**，均在120步内成功起摆
- **结论：起摆控制可实现仿真策略直接迁移至实物**

### 4.3 倒立摆稳摆控制试验

**问题定义：** 摆杆从倒立状态保持|θ|<10°，最大400步

**稳摆奖励函数（式5-4）：**

$$r = \begin{cases} \beta\left(1 - \frac{|\theta|}{10}\right) + (1-\beta)\left(1 - \frac{|d|}{50}\right), & \text{未越界} \\ -10, & \text{越界} \end{cases}$$

**β值对比：**

| β值 | 效果 |
|---|---|
| 1.0 | 控制步数难达400（仅关注角度，小车越界） |
| 0.9 | 达400步回合明显增多（推荐） |
| 0.8 | 达400步回合明显增多（推荐） |
| 0.7 | 达400步回合下降（过度关注小车位置） |

**稳摆Sim-to-Real挑战：**
- 仿真策略在实物上出现**角度发散**（400步后因限位结束）
- 原因：通信延迟（实际>6ms）、恒速模型速度突变引发振动
- 优化方案：增大滞后模拟时间至12-18ms重新训练；增大训练量（20000回合、1000步/回合）

**实物额外训练效果：**

| 训练回合数 | 效果 |
|---|---|
| 100 | 角度仍发散 |
| 300 | 角度仍发散 |
| 600 | 角度仍发散 |
| **1000** | **角度发散基本解决，曲线平滑** |

### 4.4 SAC vs PID 性能对比（实物稳摆控制）

| 指标 | SAC算法 | 双闭环PID算法 |
|---|---|---|
| 控制步数 | 500步内稳定 | 500步内稳定 |
| 摆杆角度范围 | ±1°以内 | 更小 |
| 10次试验平均方差 | **0.1434** | **0.1128** |
| 调参方式 | 仿真训练+少量超参调整（无先验经验） | 人工精良调参（需大量先验经验） |
| 应用范围 | 被控对象复杂度影响小 | 越复杂调参越困难 |

**关键结论：** SAC性能略逊PID，但差距不大；SAC作为无先验自学习算法，理论应用范围更广。

## 五、方法论总结 / Methodology Summary

### 5.1 Sim-to-Real迁移关键技巧

| 技巧 | 具体做法 | 适用场景 |
|---|---|---|
| 浮动参数训练 | 参数在测量值±范围内随机浮动 | 所有场景（必需） |
| 模型偏差补偿 | 仿真中摆杆长度偏离实际值以模拟未建模因素 | 阻力/摩擦难以建模时 |
| 噪声注入 | 仿真中增加高斯噪声模拟机械振动 | 硬件平台存在振动干扰 |
| 延迟模拟 | 在仿真中增加控制指令滞后 | 通信系统存在延迟 |
| 控制量离散化 | 模拟实际PLC/编码器的脉冲量化 | 数字控制系统 |
| 实物额外训练 | 用仿真策略初始化，在实物上继续训练 | 仿真策略精度不足时 |

### 5.2 SAC超参数调优经验

| 参数 | 调优原则 | 典型范围 |
|---|---|---|
| α（熵系数） | 探索难度高→取大；需精确控制→取小 | 0.05~0.4 |
| γ（衰减因子） | 收敛前提下尽可能大 | 0.99 |
| 学习率 | 过大不稳定，过小收敛慢 | 10⁻⁴~10⁻³ |
| 经验池大小 | 过小丢样本，过大旧样本阻碍优化 | 10⁵~10⁶ |

### 5.3 奖励函数设计三条经验（★核心）

1. **采用reward shaping**：连续控制问题中智能体难以通过随机探索达到目标，需密集奖励引导
2. **线性化奖励**：非线性奖励函数更难收敛，奖励分布均匀利于探索
3. **奖励尽量非负**：惩罚过多导致智能体动作保守，甚至不采取任何动作

## 六、与本项目的关联 / Relevance to Drone Delivery Project

### 6.1 直接相关性

| 维度 | 关联 |
|---|---|
| **SAC算法** | 本论文详细展示了SAC在连续控制任务中的完整应用流程，可作为L3/L4层PPO/SAC算法的参考 |
| **四旋翼控制** | 论文中的四旋翼动力学模型、状态空间（12维）、动作空间（4维电机控制量）可直接参考 |
| **Sim-to-Real方法** | 浮动参数训练、噪声注入、延迟模拟等技巧对无人机配送仿真环境搭建有重要参考价值 |
| **奖励函数设计** | 三条经验（reward shaping、线性化、非负）对配送任务奖励函数设计有直接指导意义 |
| **恒速控制模型** | 倒立摆的恒速控制思路可类比无人机的速度控制模式 |

### 6.2 对本项目的启示

1. **泛化能力**：浮动参数训练是仿真→实物迁移的必要条件，本项目四区环境参数应采用类似策略
2. **奖励函数稀疏性**：配送任务（如完成配送+100）属于稀疏奖励问题，需设计密集引导信号
3. **超参数敏感性**：SAC对超参数不敏感的特性使其适合作为L3层的baseline算法
4. **训练策略**：两阶段训练（仿真大量训练 + 实物少量微调）的思路适用于本项目的渐进式开发
5. **SAC vs PID对比**：验证了DRL算法在实物控制上可接近传统算法性能，为项目技术路线提供实证支持

### 6.3 局限性与注意点

- 论文仅涉及单机控制，未涉及多机协同（本项目L4层需要CTDE框架）
- 四旋翼控制结果较粗糙，未完成实物验证
- 倒立摆是一维控制问题，与6DOF无人机控制复杂度差距大
- 论文发表于2020年，SAC后续改进（如SAC-L, DroQ等）未涉及
