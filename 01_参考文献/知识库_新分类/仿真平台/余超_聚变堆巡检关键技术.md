## 一、研究背景与动机

### 1.1 聚变堆巡检需求

EAST（Experimental Advanced Superconducting Tokamak，先进超导托卡马克实验装置）是中国科学院等离子体物理研究所的大型核聚变实验装置。其真空室内部结构复杂、空间狭窄，存在大量第一壁（first wall）面板和螺栓连接件。传统人工巡检方式存在以下问题：

- **辐射风险**：运行后真空室内残留放射性物质，人员进入存在健康风险
- **空间受限**：真空室内部几何复杂，大型机器人难以部署
- **检测精度要求高**：螺栓松动、面板损伤等缺陷尺寸小，需要近距离精确检测

### 1.2 研究目标

本研究提出利用**四旋翼无人机**替代人工进入聚变堆真空室执行巡检任务，解决三大核心技术问题：

1. **飞行控制**：基于深度强化学习（DRL）的自主飞行控制算法
2. **自主导航**：基于视觉惯性导航系统（VINS）的位姿估计与路径规划
3. **管道检测**：基于 Swin-Transformer 的管道螺栓松动检测

### 1.3 国内外研究现状

- **聚变堆遥操作维护**：JET、ITER 等装置已采用遥操作机械臂，但无人机巡检尚属前沿方向
- **UAV 辅助工业巡检**：RGB-D 位姿估计、DRL 控制算法已有成熟研究
- **路径规划算法**：A*、RRT、EGO-Planner 等经典算法广泛应用

## 二、四旋翼无人机平台设计与 DRL 理论基础

### 2.1 无人机硬件平台

本研究设计的巡检四旋翼无人机平台主要参数如下：

| 参数 | 规格 |
|---|---|
| 机架 | F250（轴距 250mm） |
| 整机尺寸 | 325×325×110 mm |
| 整机重量 | 约 2.5 kg |
| 最大载重 | 4 kg |
| 飞行速度 | 3 m/s |
| 续航时间 | 10-15 分钟 |
| 深度相机 | Intel RealSense D435i |
| 机载计算机 | DJI Manifold 2（Intel i7-8550U + NVIDIA Jetson TX2） |
| 飞控 | DJI N3 |
| 电机/电调 | T-Motor 系列 |
| 电池 | 双 1800mAh |
| 连接件 | 3D 打印光敏树脂 |

**系统架构四模块**：

- **感知模块**：Intel RealSense D435i 深度相机采集 RGB-D 图像
- **导航模块**：VINS 视觉惯性导航系统进行位姿估计
- **导引模块**：路径规划（EGO-Planner + FCST_BIT*）生成参考轨迹
- **控制模块**：DRL（PPO/SAC）或 PID 底层飞行控制

### 2.2 四旋翼动力学建模

四旋翼无人机的动力学模型基于牛顿-欧拉方程：

**位置矩阵**：$\mathbf{P}_w = [x, y, z]^T$（世界坐标系下的位置）

**速度方程**：

$$
\mathbf{v}_w = \mathbf{Q}_{wb} \cdot \mathbf{Q} \cdot c + \mathbf{g}
$$

其中 $\mathbf{Q}_{wb}$ 为从机体坐标系到世界坐标系的旋转矩阵，$\mathbf{Q}$ 为四元数表示的姿态，$c$ 为推力系数，$\mathbf{g}$ 为重力加速度。

**扭矩方程**：

$$
\boldsymbol{\tau} = \mathbf{J} \cdot \dot{\boldsymbol{\omega}} + \boldsymbol{\omega} \times (\mathbf{J} \cdot \boldsymbol{\omega})
$$

其中 $\mathbf{J}$ 为转动惯量矩阵，$\boldsymbol{\omega}$ 为角速度向量。

### 2.3 深度强化学习理论

#### 2.3.1 基本框架

DRL 结合深度神经网络（DNN/MLP）与强化学习，通过 Actor-Critic 架构实现连续动作空间的策略优化。

**两大类算法**：

| 类别 | 代表算法 | 核心思想 |
|---|---|---|
| 基于价值 | DQN, TD Learning | 通过最优贝尔曼方程迭代求解 $Q^*(s,a)$ |
| 基于策略 | 策略梯度, Actor-Critic | 直接优化策略 $\pi_\theta(a\|s)$ |

#### 2.3.2 SAC 算法目标函数

SAC（Soft Actor-Critic）引入熵正则化项，平衡探索与利用：

$$
\pi^* = \arg\max_\pi \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t \left(r_t + \alpha \cdot \mathcal{H}\left(\pi(\cdot|s_t)\right)\right)\right]
$$

其中 $\alpha$ 为温度系数（entropy coefficient），控制探索程度；$\mathcal{H}(\pi(\cdot|s_t))$ 为策略的熵。

#### 2.3.3 DRL 任务定义

| 任务类型 | 观测空间 | 动作空间 | 奖励函数 |
|---|---|---|---|
| 起飞 | 位姿 + 速度 | 推力 + 力矩（连续） | 到达目标高度的距离惩罚 |
| 悬停 | 位姿 + 速度 | 推力 + 力矩（连续） | 维持目标位姿的偏差惩罚 |
| 轨迹跟踪 | 位姿 + 速度 + 参考轨迹 | 推力 + 力矩（连续） | 跟踪误差的 L2 范数惩罚 |

## 三、基于 DRL 的飞行控制算法（核心章节）

### 3.1 仿真环境 "Deque"

基于 **PyBullet** 物理引擎构建名为 "Deque" 的仿真环境，模拟 EAST 真空室内部几何结构。

**仿真环境参数**：

| 参数 | 值 |
|---|---|
| 物理引擎 | PyBullet |
| 模拟场景 | EAST 真空室 1/8 扇区 |
| 悬停高度 | 1.1 m |
| 飞行半径 | 2 m |
| 控制频率 | 与 PyBullet 默认步长一致 |

### 3.2 网络架构

采用 Actor-Critic 架构，全连接网络（Fully Connected Network），具体配置：

| 网络 | 层数 | 各层神经元数 | 激活函数 |
|---|---|---|---|
| Actor | 4 层 | 512 → 512 → 256 → 128 | ReLU |
| Critic | 4 层 | 512 → 512 → 256 → 128 | ReLU |

### 3.3 训练超参数

| 超参数 | 值 |
|---|---|
| 学习率（LR） | $1 \times 10^{-4}$ |
| 折扣因子（$\gamma$） | 0.99 |
| 训练步数（steps） | $3 \times 10^6$ |
| 批量大小（batch size） | 1024 |
| 经验回放缓冲区 | 5000 |

### 3.4 训练硬件

| 设备 | 型号 |
|---|---|
| CPU | Intel i9-12900K @ 5.2GHz |
| 内存 | 64 GB |
| GPU | NVIDIA RTX 3090 |
| 操作系统 | Ubuntu 20.04 |

### 3.5 奖励函数设计

**起飞/悬停任务**：

$$
r = -\| [0, 0, h] - \mathbf{p}_t \|^2
$$

（公式编号：式 3.6）

其中 $h$ 为目标悬停高度，$\mathbf{p}_t$ 为 $t$ 时刻无人机位置。

**轨迹跟踪任务**：

$$
r = -\|\mathbf{p}_t - \mathbf{p}_{\text{ref}}\|^2
$$

（公式编号：式 3.7）

其中 $\mathbf{p}_{\text{ref}}$ 为参考轨迹上的目标点。

**参考轨迹定义**（圆形轨迹）：

$$
x^2 + y^2 = R^2, \quad z = z_h
$$

（公式编号：式 3.8、3.9）

在高度 $z_h$ 处做半径为 $R$ 的匀速圆周运动。

### 3.6 实验结果

#### 3.6.1 仿真实验：轨迹跟踪精度对比

| 指标 | PPO | SAC |
|---|---:|---:|
| XY 平面最大误差 (m) | **0.324** | 1.437 |
| Z 轴最大误差 (m) | **0.006** | 0.008 |

**结论**：PPO 在轨迹跟踪稳定性和精度方面均显著优于 SAC。PPO 的 XY 误差仅为 SAC 的 22.5%。

#### 3.6.2 实物迁移实验

将仿真训练的 PPO 模型迁移到实物平台（圆形轨迹，$R = 1.5$ m）：

| 指标 | PPO（实物） |
|---|---:|
| XY 平面最大误差 (m) | 0.412 |
| Z 轴最大误差 (m) | 0.052 |

**Sim-to-Real 分析**：实物 XY 误差（0.412m）比仿真（0.324m）增加约 27%，Z 轴误差增加约 767%。误差来源包括空气扰动、传感器噪声、执行器延迟等现实因素。

### 3.7 关键发现

1. **PPO 优于 SAC**：PPO 在轨迹跟踪任务中表现更稳定，SAC 倾向于过度探索导致跟踪精度下降
2. **Sim-to-Real 可行**：DRL 模型从仿真到实物的迁移基本可行，但需要针对真实环境进行微调
3. **网络深度有效**：4 层 [512-512-256-128] 的网络结构在该任务规模下表现良好

## 四、基于 VINS 的自主导航系统

### 4.1 视觉惯性导航系统（VINS）

VINS 融合 Intel RealSense D435i 深度相机图像与 IMU 惯性测量数据，实现无人机的实时位姿估计。

**关键技术**：

- **相机模型**：针孔模型 + 畸变校正
- **重投影误差**：视觉特征点的 2D-3D 重投影误差最小化
- **IMU 预积分**：利用 IMU 测量值进行帧间运动预积分，提高位姿估计的实时性

### 4.2 路径规划算法

| 算法 | 说明 |
|---|---|
| EGO-Planner | 基于梯度的局部路径规划器，适用于未知环境中的实时避障 |
| FCST_BIT* | 改进的 BIT*（Batch Informed Trees）算法，提高路径规划效率 |

### 4.3 实验验证

- **多障碍物自主飞行实验**：在仿真和实物环境中完成多障碍物场景下的自主避障飞行
- **EAST 1/8 扇区巡检实验**：在模拟 EAST 真空室 1/8 扇区的环境中完成巡检路径规划与执行

## 五、基于 Swin-Transformer 的管道缺陷检测

### 5.1 检测任务

针对 EAST 聚变堆外围管道上的**螺栓防松动检测**（bolt anti-loosening detection），采用基于深度学习的目标检测算法。

### 5.2 数据集

| 参数 | 值 |
|---|---|
| 原始图像数 | 1870 张 |
| 增强后图像数 | 2244 张 |
| 训练集/测试集划分 | 70:30（1571 训练 / 673 测试） |
| 标注格式 | COCO 2017 |
| 数据增强策略 | 旋转、饱和度调整、曝光调整、色调调整 |

### 5.3 训练配置

| 参数 | 值 |
|---|---|
| CPU | Intel Xeon E5-2650v3 |
| 内存 | 128 GB |
| GPU | NVIDIA RTX 3090 (24GB) |
| 深度学习框架 | PyTorch 1.12.1 |
| 学习率 | $1 \times 10^{-4}$ |
| 权重衰减 | $5 \times 10^{-2}$ |
| 批量大小 | [16, 32, 64, 128] |

### 5.4 检测算法对比实验

| 检测算法 | mAP (%) | 训练时间 (h) |
|---|---:|---:|
| Faster R-CNN | 86.17 | 5.24 |
| SSD | 88.30 | 4.43 |
| YOLO V5 | 92.45 | 4.12 |
| **Swin-Transformer** | **97.20** | 120.85 |

**结论**：Swin-Transformer 以 97.20% 的 mAP 取得最优检测精度，但训练时间长达 120.85 小时，是 YOLO V5 的约 29 倍。在精度优先的巡检场景中，Swin-Transformer 是最佳选择；在实时性要求较高的场景中，YOLO V5 提供更好的精度-速度平衡。

## 六、总结与展望

### 6.1 主要贡献

1. **聚变堆巡检无人机系统设计**：针对 EAST 真空室环境设计了专用四旋翼无人机平台
2. **DRL 飞行控制理论**：在 PyBullet 仿真环境 "Deque" 中训练 PPO/SAC 控制器，并验证了 Sim-to-Real 迁移可行性
3. **VINS 自主导航系统**：融合视觉与惯性测量实现位姿估计，结合 EGO-Planner 和 FCST_BIT* 实现自主路径规划
4. **管道缺陷检测**：基于 Swin-Transformer 实现 97.20% mAP 的螺栓松动检测

### 6.2 创新点

- 提出面向聚变堆真空室的**智能化无人机巡检系统**
- 建立基于 DRL 的**四旋翼飞行控制理论**，PPO 优于 SAC 的结论为后续研究提供指导
- 提出基于 VINS 的**自主导航方案**，实现狭窄空间内的自主飞行

### 6.3 未来工作方向

1. **抗辐射加固**：针对聚变堆辐射环境对电子元器件进行屏蔽设计
2. **轻量化设计**：减小无人机尺寸以适应更狭窄的巡检空间
3. **多智能体协同**：引入 Multi-Agent RL 实现多无人机编队协同巡检
