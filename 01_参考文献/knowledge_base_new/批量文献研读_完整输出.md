# 第三部分：技术演进图

## MARL算法演进：VDN → QMIX → QPLEX → MAPPO

```
2016年：IQL (Independent Q-Learning) 存在非平稳问题
    │
    ▼
2018年：VDN [10] Sunehag et al.
    │   - 首次提出值分解范式：Q_tot = Σ Q_i
    │   - 加性约束过强，无法表达非线性交互
    │
    ▼
2018年：QMIX [9] Rashid et al.
    │   - 关键转折：单调性约束替代加性约束
    │   - Q_tot = MixNet(Q_1,...,Q_N)，∂Q_tot/∂Q_i ≥ 0
    │
    ▼
2021年：QPLEX [11] Wang et al.
    │   - 关键突破：双工决斗架构突破单调性限制
    │   - 在hard场景超越QMIX 7-10%
    │
    ▼
2022年：MAPPO [7] Yu et al. (当前最优)
        - 关键发现：简单PPO在合作场景中超越众多复杂算法
        - 参数共享 + 中心化critic + 价值归一化
```

## 通信学习演进：CommNet → DIAL/RIAL → TarMAC

```
2016年：CommNet [12] Sukhbaatar et al.
    │   - 首创可微分通信信道
    │   - 连续消息 + 广播通信 + 平均池化
    │
    ▼
2016年：DIAL/RIAL [13] Foerster et al.
    │   - 关键转折：从连续消息到离散符号
    │   - 通信门控机制：agent可选择是否发送消息
    │
    ▼
2019年：TarMAC [14] Das et al.
        - 关键突破：注意力机制实现目标化通信
        - 通信成本比全连接降低40-60%
```

# 第四部分：研究空白与创新方向

## 研究空白

1. **MARL + 显式能耗建模**：MARL文献普遍忽略能耗约束，能耗优化文献未用MARL
2. **注意力通信 + 能耗感知决策**：通信学习未考虑通信能耗
3. **值分解 + 连续动作空间**：VDN/QMIX/QPLEX均假设离散动作空间
4. **课程学习 + 多目标优化**：未在课程学习框架中逐步引入多目标
5. **大规模无人机群（50+）的MARL**：MARL实验通常<20个智能体

## 5个创新方向

1. **能耗感知的MARL框架**（难度中等，预期续航提升15-25%）
2. **分层MARL架构处理大规模无人机群**（难度较高，可扩展到50-100架）
3. **动态课程学习+多目标约束渐进引入**（难度中等，训练收敛提速30-50%）
4. **能耗感知的选择性通信机制**（难度较高，通信能耗降低40-60%）
5. **异构无人机的条件参数共享**（难度中等，异构场景性能提升10-20%）

## 算法选择
- **核心算法**：MAPPO（工程简洁、训练稳定、连续动作支持）
- **补充算法**：QPLEX（处理非单调奖励，如资源竞争场景）
- **对比基线**：SAC、VDN、MADDPG

## 奖励函数（8分量复合）
$$R_{total} = w_1 R_{goal} + w_2 R_{dist} + w_3 R_{collision} + w_4 R_{energy} + w_5 R_{time} + w_6 R_{smooth} + w_7 R_{协同} + w_8 R_{势能}$$

## 能耗建模（分段模型）
$$P(v, m, v_z) = \begin{cases} k_1 v^3 + k_2 \frac{mg}{v} + k_3 m g v_z & v > v_{min} \\ P_{hover} + k_3 m g v_z & v \leq v_{min} \end{cases}$$
