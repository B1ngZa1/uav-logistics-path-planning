# 第一部分：文献综述初稿

## 1. 研究背景与意义

近年来，无人机（Unmanned Aerial Vehicle, UAV）技术的快速发展催生了物流配送领域的深刻变革。相较于传统地面运输方式，无人机配送具有不受地形限制、响应速度快、运营成本低等显著优势，在应急物资投送、偏远地区配送和城市末端物流等场景中展现出广阔的应用前景。然而，单架无人机受限于载荷能力和续航时间，难以满足大规模物流配送需求，多无人机协同配送成为必然趋势。多无人机协同路径规划作为实现高效配送的核心技术，涉及任务分配、路径优化、避障协同和能耗管理等多个子问题，其求解质量直接决定了配送系统的整体效率和可靠性。

传统的多无人机路径规划方法主要依赖于精确的数学模型和全局信息，如混合整数线性规划、A*搜索、快速扩展随机树（RRT）等。这些方法在小规模、静态环境下能够获得理论最优解，但面临维度灾难、实时性差和对环境模型依赖性强等固有缺陷，难以适应大规模、动态、部分可观测的真实物流场景。与此同时，深度强化学习（Deep Reinforcement Learning, DRL）作为一种端到端的学习范式，能够通过与环境的交互自主发现复杂决策策略，在单智能体路径规划任务中已取得显著成果。将DRL扩展到多智能体场景，即多智能体强化学习（Multi-Agent Reinforcement Learning, MARL），为解决多无人机协同路径规划问题提供了一条全新的技术路径。

本研究聚焦于基于深度强化学习的多无人机协同物流配送路径规划问题，旨在设计一种兼具协同性、可扩展性和能耗感知能力的智能决策框架。该研究在理论层面有望丰富MARL在连续控制和物理约束场景中的应用方法论，在实践层面可为无人机物流配送系统提供可落地的技术方案，具有重要的学术价值和工程意义。

## 2. 多无人机协同技术研究现状

多无人机协同技术的研究可从集中式和分布式两条主线展开。集中式方法由中央控制器获取全局信息并统一规划所有无人机的路径，典型代表包括集中式模型预测控制（MPC）和联合状态空间搜索。Kamel等提出分布式MPC路径规划方法，每架无人机独立求解局部优化问题并通过轨迹交换实现协同避碰，在成功率上接近集中式方法的同时将计算时间降低90%。然而，集中式方法的计算复杂度随无人机数量呈指数增长，可扩展性受限。

分布式方法中每架无人机基于局部信息独立决策，通过隐式或显式协调实现协同。Wang等基于深度强化学习设计分布式编队控制器，采用领导-跟随者架构实现多无人机编队飞行，在编队精度上优于传统PID方法50%以上，且对通信延迟具有天然鲁棒性。Chen等提出基于社交注意力机制的分布式协同避障方法，通过动态学习邻居重要性权重实现密集场景下的高效协同，在100个智能体的场景中仍保持96%以上的成功率，通信开销降低99%。Sartoretti等提出的PRIMAL算法通过模仿学习和强化学习相结合的方式实现分布式多智能体路径规划，可扩展到256个智能体的场景，计算时间相比传统方法降低2-3个数量级。

在协同策略方面，Phan等提出基于CTDE（集中训练去中心化执行）框架的多无人机协同路径规划方法，通过独立Actor加共享Critic的架构实现三维城市环境中的协同避障，成功率94.2%，计算时间较集中式DRL降低95%。该工作表明CTDE框架能够在训练效率和执行效率之间取得良好平衡。

综合来看，集中式方法在解质量上具有优势但可扩展性差，分布式方法可扩展性强但协同效果受限于信息共享程度。CTDE框架作为一种折中方案，在训练阶段利用全局信息提升协同效果，在执行阶段仅依赖局部信息保证实时性，成为当前多无人机协同研究的主流范式。

## 3. 多智能体强化学习研究现状

多智能体强化学习的核心挑战在于环境非平稳性：每个智能体的策略更新会改变其他智能体所面对的环境动态，导致独立学习方法难以收敛。CTDE框架通过在训练阶段引入全局信息来缓解这一问题，成为当前MARL研究的主流范式。

在值分解方法方面，Sunehag等提出VDN算法，首次通过加性分解将全局Q值分解为各智能体局部Q值之和，奠定了CTDE值分解的基础，但加性约束过于严格，无法表达智能体间的非线性交互。Rashid等提出QMIX算法，通过单调性约束替代加性约束，利用超网络生成状态依赖的混合权重，在12个SMAC地图上超越VDN。Wang等进一步提出QPLEX算法，采用双工决斗架构突破单调性限制，在hard场景上超越QMIX约7-10%。值分解方法的核心优势在于支持去中心化执行：每个智能体仅需自身的Q值即可选择最优动作。

在Actor-Critic方法方面，Lowe等提出MADDPG算法，每个智能体的Critic接收所有智能体的观测和动作，Actor仅使用本地观测，首次系统性地解决了混合合作-竞争场景的MARL问题。然而，Critic的输入维度随智能体数量线性增长，限制了大规模应用。Yu等在2022年NeurIPS发表的工作中系统性论证了MAPPO（多智能体PPO）的惊人有效性：通过参数共享的Actor加中心化Critic的简洁架构，在14个SMAC地图上达到最优性能，超越众多复杂MARL算法。该工作揭示了算法设计中"少即是多"的哲学，对本项目具有重要指导意义。

在通信学习方面，Sukhbaatar等提出CommNet，首次实现端到端可微分的通信信道学习，但广播通信方式带宽浪费严重。Foerster等提出DIAL/RIAL，引入离散符号通信和门控机制，提升了通信效率和可解释性。Das等提出TarMAC，通过注意力机制实现目标化通信，通信成本比全连接降低40-60%，但注意力计算复杂度为O(N^2)。

算法演进总体呈现从追求复杂性回归简洁有效的趋势。MAPPO的成功表明，在合作场景中，精心设计的简单算法往往优于过度工程化的复杂方案，这一发现为本项目的算法选型提供了重要依据。

## 4. 任务分配与路径规划研究现状

任务分配与路径规划是多无人机物流配送的两个核心子问题。传统优化方法中，匈牙利算法通过求解指派问题实现最优任务分配，复杂度为O(n^3)，适用于静态场景。Bertsekas提出的拍卖算法通过市场定价机制实现分布式任务分配，天然支持并行计算，但缺乏学习和适应能力。

深度强化学习方法的兴起为这两个问题的联合求解提供了新思路。Kool等提出基于Transformer的注意力模型用于组合优化问题，实现了端到端的路径规划，推理速度比传统启发式快10-100倍。Li等将MARL引入组合优化问题，设计多智能体编码器-解码器架构，通过轮流决策机制实现多车辆协同路径规划。Li等进一步提出QMIX-SAR算法，结合课程学习和动态任务分配，在搜救场景中将任务完成率提升10-15%。

混合方法试图结合传统优化的理论保证和深度学习的适应能力。Zhang等的综述系统梳理了MARL的发展脉络，指出联合优化任务分配与路径规划是未来的重要方向，但现有工作仍处于初步探索阶段。

## 5. 无人机物流配送与能耗优化研究现状

车辆-无人机协同配送是物流领域的重要研究方向。Murray和Choi首次定义了TSP-D（旅行商问题与无人机）问题，开创了车辆-无人机协同配送的研究范式。Agatz等在车辆路径问题中引入能耗约束，发现忽略能耗建模会导致约30%的路径方案在实际中不可行，有力论证了能耗建模的必要性。

在能耗建模方面，Liu建立了飞行-通信能耗耦合模型，揭示了无人机速度与能耗的立方关系（功率P与v^3成正比），并通过连续凸逼近（SCA）优化求解。Wang等提出时间-能耗-安全三目标优化框架，为多目标奖励函数设计提供了参考。Euchi的综述系统梳理了无人机物流配送的挑战与趋势，指出能耗管理是制约无人机配送规模化的核心瓶颈之一。

然而，现有能耗优化文献主要依赖传统优化方法，缺乏与强化学习的深度结合；而MARL文献普遍忽略显式能耗建模，仅使用简单的时间惩罚作为代理指标。这一空白为本项目提供了明确的创新切入点。

## 6. 现有研究不足与本文切入点

综合以上分析，现有研究存在以下主要不足：

第一，MARL与显式能耗建模的结合严重不足。MARL文献普遍忽略物理约束下的能耗建模，仅使用简单时间惩罚；能耗优化文献则依赖传统优化方法，缺乏学习和适应能力。第二，注意力通信机制尚未与能耗感知决策相结合。TarMAC实现了目标化通信但未考虑通信能耗，能耗建模文献未采用学习方法。第三，值分解方法局限于离散动作空间，难以直接应用于无人机的连续路径规划。第四，缺乏面向大规模无人机群（50架以上）的MARL可扩展性验证。第五，现有工作普遍假设同构智能体、理想通信和静态环境，与真实物流场景存在差距。

本文的创新切入点在于：以MAPPO为核心算法框架，将物理约束下的能耗模型嵌入MARL的状态空间和奖励函数，通过课程学习逐步引入多目标优化约束，设计面向异构无人机的条件参数共享机制，构建首个"MARL加物理约束能耗建模"的系统性工作，填补深度强化学习与无人机能耗优化之间的研究空白。

# 第二部分：项目技术路线建议

## 1. 状态空间和动作空间设计

### 1.1 状态空间

推荐方案为3D连续空间加栅格化局部感知，状态向量设计如下：

每架无人机i在时刻t的状态由四部分组成：自身状态（三维位置p_i、三维速度v_i、电池SOC_i）、目标信息（到目标的距离d_goal^i、方位角theta^i、俯仰角phi^i）、障碍物信息（24条射线检测结果o_ray^24，覆盖球面感知）和协同信息（邻居无人机的位置、速度和SOC，仅Critic使用）。该设计综合了Tai 2017的距离引导思想、Polvara 2019的射线检测方法和Chen 2022的邻居信息编码方式。

对于物流配送场景，还需加入以下状态变量：当前载荷m_i（配送前后动态变化）、当前配送任务信息（收货点位置、优先级）、停机坪占用状态（用于资源竞争建模）。

### 1.2 动作空间

推荐连续动作空间，每个动作包含三个分量：航向角变化率（yaw rate）、俯仰角变化率（pitch rate）和速度调节量（speed adjustment）。连续动作空间更符合无人机实际飞行控制需求，可直接映射为底层飞控指令。

离散动作空间（前进/后退/左转/右转/上升/下降/悬停）可作为简化版本用于快速原型验证和消融实验。

## 2. MARL算法选择

### 2.1 推荐方案

以MAPPO为核心算法，QPLEX为任务分配层补充算法。

| 算法 | 角色 | 适用阶段 | 推荐度 | 理由 |
|------|------|---------|--------|------|
| MAPPO | 核心算法 | 全阶段 | 4星 | 工程简洁、训练稳定、连续动作支持、多智能体扩展成熟 |
| QPLEX | 补充算法 | 任务分配层 | 3星 | 处理非单调奖励（资源竞争）、去中心化执行 |
| VDN | 最简基线 | 快速验证 | 2星 | 极简架构、验证多机协同可行性 |
| SAC | 对比基线 | 消融实验 | 2星 | 最大熵探索、样本效率高 |

### 2.2 MAPPO配置参数

| 参数 | 值 | 来源 |
|------|-----|------|
| 裁剪范围epsilon | 0.2 | PPO原论文 |
| 折扣因子gamma | 0.99 | PPO原论文 |
| GAE参数lambda | 0.95 | PPO原论文 |
| 优化轮数K | 5 | MAPPO原论文 |
| 学习率 | 3e-4（余弦退火） | PPO原论文 |
| 熵系数c2 | 0.01 | PPO原论文 |
| 并行环境数 | 32-64 | MAPPO原论文 |
| 梯度裁剪 | max_norm=0.5 | MAPPO原论文 |
| 网络初始化 | 正交初始化 | MAPPO原论文 |
| 价值归一化 | running mean/std | MAPPO原论文 |

### 2.3 网络架构

Actor网络：输入层（状态维度）- 全连接层（256维，ReLU）- 全连接层（256维，ReLU）- 输出层（动作维度，tanh激活）。所有无人机共享Actor参数，输入包含agent_id的one-hot编码。

Critic网络：输入层（全局状态维度）- 全连接层（512维，ReLU）- 全连接层（512维，ReLU）- 输出层（1维，状态价值）。每个无人机配备独立的Critic。

### 2.4 异构无人机适配

针对异构无人机（不同载重、续航、速度），采用条件参数共享方案：在Actor网络中加入条件批归一化（Conditional Batch Normalization）或FiLM调制层，根据无人机类型ID生成调制参数，使共享网络能够适应不同类型的无人机。

## 3. 奖励函数设计

推荐8分量复合奖励函数：

R_total = w_1 * R_goal + w_2 * R_dist + w_3 * R_collision + w_4 * R_energy + w_5 * R_time + w_6 * R_smooth + w_7 * R_coop + w_8 * R_potential

| 分量 | 公式 | 值域 | 作用 |
|------|------|------|------|
| 目标奖励 R_goal | +200（到达目标时） | 稀疏正奖励 | 稀疏主信号 |
| 距离引导 R_dist | alpha * (d_{t-1} - d_t) | 连续 | 密集梯度信号 |
| 碰撞惩罚 R_collision | -200（碰撞时） | 稀疏负奖励 | 安全约束 |
| 能耗惩罚 R_energy | -lambda_e * E_t | 连续负值 | 能耗优化 |
| 时间惩罚 R_time | -0.1 per step | 连续负值 | 效率激励 |
| 动作平滑 R_smooth | -lambda_s * ||a_t - a_{t-1}||^2 | 连续负值 | 控制稳定性 |
| 协同奖励 R_coop | +beta * task_complete | 稀疏正奖励 | 集体目标 |
| 势能塑形 R_potential | gamma * Phi(s') - Phi(s) | 连续 | 解决稀疏奖励 |

势能函数Phi(s)定义为未完成任务数的负值，保证最优策略在势能塑形后不变。

## 4. 任务分配机制

推荐MAPPO端到端联合优化为主方案，拍卖算法为分布式启发式基线。

端到端方案中，MAPPO同时学习任务分配和路径规划，避免两阶段次优。引入"任务价格"隐变量，通过Critic网络学习，无人机根据"价格-成本"差选择任务，实现隐式拍卖，保留MAPPO的端到端优化能力同时获得拍卖机制的可解释性。

拍卖算法基线中，每架无人机对未完成任务计算竞标值（考虑距离、能耗、剩余电量），通过分布式拍卖机制分配任务。匈牙利算法作为静态基线用于初始验证。

## 5. 能耗建模方法

### 5.1 分段能耗模型

采用分段能耗模型处理全速度范围：

当速度v大于最小速度v_min时：P(v, m, v_z) = k_1 * v^3 + k_2 * m * g / v + k_3 * m * g * v_z

当速度v小于等于v_min时：P(v, m, v_z) = P_hover + k_3 * m * g * v_z

其中k_1为诱导阻力系数（建议值0.001-0.01 W*s^3/m^3），k_2为寄生阻力系数（建议值0.1-1.0 W*m/s），k_3为爬升功率系数（建议值9.8-15.0 W*s/kg），P_hover为悬停功率（建议值100-300 W）。

### 5.2 SOC作为状态变量

SOC_{t+1} = SOC_t - P(v_t, m_t, v_{z,t}) * Delta_t / E_battery

SOC纳入状态空间，使智能体能够感知剩余能量并做出相应决策。

### 5.3 返航阈值机制

当SOC_t < SOC_return = E_return_trip / E_battery + safety_margin时触发返航，其中E_return_trip根据当前位置到基站距离动态计算，safety_margin取0.15-0.20。

## 6. 预期创新点

### 6.1 能耗感知的MAPPO框架

将SOC作为状态变量、能耗惩罚作为奖励分量、返航阈值作为约束，构建首个MARL加物理约束能耗的系统性工作。

### 6.2 分层MARL架构

底层MAPPO处理单机路径规划，高层QMIX/QPLEX处理群组任务分配，实现可扩展到100架无人机的协同配送系统。

### 6.3 动态课程学习加多目标优化

课程学习框架中逐步引入约束：先无约束训练基本导航能力，加能耗约束，加安全约束，加通信限制，最终引入全部约束。预期训练效率提升30-50%。

### 6.4 能耗感知的选择性通信

将通信能耗纳入注意力权重计算，低电量时减少通信频率和通信范围，实现通信-决策联合优化。预期通信能耗降低40-60%，续航提升15-20%。

# 第四部分：研究创新点建议

## 创新点一：能耗感知的MARL框架

**创新点描述**：将物理约束下的无人机能耗模型（含悬停、爬升、巡航等多模态）嵌入MARL的状态空间和奖励函数，使智能体在学习路径规划策略的同时学会能耗管理。

**理论依据**：现有MARL文献普遍使用简化的时间惩罚作为能耗代理，Agatz 2018已证明忽略能耗建模会导致约30%的路径方案不可行。将真实能耗模型嵌入RL框架可避免学习到物理上不可行的策略。

**预期效果**：配送系统续航提升15-25%，路径可行性接近100%，在电池容量受限场景中优势更为显著。

**实施难度**：中等。能耗模型参数需要根据具体无人机型号标定，分段能耗模型可能引入梯度不连续问题，需设计平滑过渡机制。

## 创新点二：分层MARL架构处理大规模无人机群

**创新点描述**：设计双层MARL架构，底层MAPPO处理单机路径规划（连续动作），高层QMIX/QPLEX处理群组任务分配（离散动作），两层通过共享状态和奖励耦合。

**理论依据**：单一MAPPO架构在智能体数量超过20时性能显著下降，值分解方法QMIX在任务分配场景表现优异但不擅长连续控制。分层架构使各层使用最适合的方法，避免"一刀切"的局限。

**预期效果**：可扩展到50-100架无人机的协同配送系统，任务分配效率相比纯MAPPO提升10-15%，路径规划质量保持MAPPO水平。

**实施难度**：较高。两层之间的梯度传递和信用分配是关键难点，需要设计合理的层次间通信接口和联合训练策略。

## 创新点三：动态课程学习加多目标约束渐进引入

**创新点描述**：设计四阶段课程学习框架，逐步引入优化目标和环境约束：阶段1无障碍单机学习基本导航、阶段2加静态障碍物和碰撞惩罚、阶段3加多机协同和协同奖励、阶段4加能耗约束和动态障碍物。

**理论依据**：Phan 2023和Li 2023的工作表明课程学习可有效解决稀疏奖励问题，但现有工作仅增加环境复杂度，未逐步引入多目标约束。多目标同时优化可能导致训练不稳定和目标冲突。

**预期效果**：训练收敛速度提升30-50%，最终策略性能提升10-15%，训练稳定性显著改善（方差降低40%以上）。

**实施难度**：中等。课程阶段划分和过渡时机需要经验调优，可考虑自动课程学习方法（如基于性能阈值的自动进阶）降低人工调参负担。

## 创新点四：能耗感知的选择性通信机制

**创新点描述**：将通信能耗纳入注意力权重计算，设计通信门控网络，根据任务紧急程度和剩余电量动态决定是否通信以及通信对象，实现通信-决策联合优化。

**理论依据**：TarMAC（Das 2019）实现了目标化通信但未考虑通信能耗，Liu 2020建模了通信能耗但未采用学习方法。在实际无人机系统中，通信模块的能耗占总能耗的5-15%，在低电量场景中可能成为关键瓶颈。

**预期效果**：通信能耗降低40-60%，系统续航提升15-20%，在通信带宽受限场景中性能优势更为显著。

**实施难度**：较高。离散通信门控的梯度估计需要Gumbel-Softmax等技巧，通信能耗的准确建模需要射频硬件参数，联合优化的训练稳定性需要仔细调参。

## 创新点五：异构无人机的条件参数共享

**创新点描述**：针对不同型号无人机（不同载重、续航、速度），设计条件参数共享方案，通过条件批归一化或FiLM调制层根据无人机类型生成网络调制参数，使单一共享网络能够适应异构智能体。

**理论依据**：MAPPO（Yu 2022）假设同构智能体的参数共享，在异构场景中性能下降。MADDPG（Lowe 2017）支持异构智能体但每个agent独立参数，无法共享经验。条件参数共享在保持经验共享优势的同时支持异构性。

**预期效果**：异构场景下性能相比独立参数MAPPO提升10-20%，相比完全参数共享MAPPO提升5-10%，训练速度保持与参数共享方案相当。

**实施难度**：中等。FiLM调制层的实现相对简单，关键在于如何定义无人机类型的特征编码以及调制参数的初始化策略。
