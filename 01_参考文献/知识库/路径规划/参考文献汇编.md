## 一、DRL路径规划（4篇）

### [1] Path Planning using Deep Reinforcement Learning

- **作者**：Tai, L., Paolo, G., Liu, M.
- **年份**：2017
- **期刊**：arXiv preprint
- **关键词**：DRL; path planning; mobile robot; continuous action
- **摘要**：将深度强化学习应用于移动机器人路径规划，使用DDPG算法在连续动作空间中学习路径策略。
- **与本项目关联**：★★★ 直接相关

### [2] Mobile Robot Path Planning Using DRL in Unknown Environment

- **作者**：Li, B., Zhang, Y., et al.
- **年份**：2021
- **期刊**：IEEE Access
- **关键词**：DQN; path planning; unknown environment; obstacle avoidance
- **摘要**：基于DQN的未知环境下移动机器人路径规划方法，智能体通过与环境交互学习避障策略。
- **与本项目关联**：★★★ 直接相关

### [3] Autonomous Navigation via Deep Reinforcement Learning

- **作者**：Zhu, Y., Mottaghi, R., et al.
- **年份**：2020
- **期刊**：IEEE TNNLS
- **关键词**：Autonomous navigation; DRL; end-to-end; visual navigation
- **摘要**：基于DRL的端到端自主导航方法，从视觉输入直接学习导航策略。
- **与本项目关联**：★★ 方法参考

### [4] Deep Reinforcement Learning for UAV Navigation

- **作者**：Polvara, R., Patacchiola, M., et al.
- **年份**：2019
- **期刊**：IEEE RA-L
- **关键词**：UAV; navigation; DRL; quadrotor
- **摘要**：将DRL应用于四旋翼无人机导航，智能体学习从传感器数据到控制指令的映射。
- **与本项目关联**：★★★ 直接相关

## 二、传统路径规划（2篇）

### [5] Distributed Multi-Agent Path Finding (PRIMAL)

- **作者**：Sartoretti, G., Kerber, J., et al.
- **年份**：2019
- **期刊**：IEEE RA-L
- **关键词**：MAPF; distributed; DRL; PRIMAL
- **摘要**：PRIMAL算法，基于模仿学习的分布式多智能体路径搜索方法。
- **与本项目关联**：★★★ 核心参考

### [6] Multi-UAV Path Planning Using Distributed MPC

- **作者**：Kamel, M.A., Yu, X., Zhang, Y.
- **年份**：2020
- **期刊**：Autonomous Robots
- **关键词**：Distributed MPC; path planning; multi-UAV
- **摘要**：基于分布式MPC的多无人机路径规划，考虑动力学和通信约束。
- **与本项目关联**：★★ 方法参考
