# 上市公司财报分析输出

本目录是低空经济/无人机上市公司财务研究交付物，包含 5 家公司：中无人机、纵横股份、EHang、AeroVironment、Parrot。

文件说明：

- `annual_reports_index.csv`：报告期、币种、原始单位、页数、官方链接、镜像链接和本地文件。
- `financials_raw.csv`：按报告原始单位保留的财务指标，未做汇率转换；空值表示来源未披露或本地底稿不足。
- `financials_normalized.csv`：同币种金额缩放为本币百万；百分比指标保留为 ratio，不能与金额相加。
- `analysis.md`：盈利、现金流、研发/资本开支、订单/合同负债和行业风险分析。
- `three_statement_forecast.xlsx`：Parrot 2024A 历史锚点 + 2025E–2027E 公式驱动情景预测，黄色单元格为可编辑假设。
- `market_opportunity_pipeline.xlsx`：独立机会管线，沿用销售管线字段结构；金额、概率为研究排期假设，不是已签合同。
- `sources.md`：财报与市场来源登记。

重要限制：中无人机本地文件仍为 10 页摘要镜像，不是完整审计年报；CNINFO 直链本次实测响应极慢，未保留不完整下载文件。纵横股份已补充 259 页完整年报。使用中无人机做严肃投资/授信判断前，必须从官方或替代入口取得完整年报并补齐空值字段。模型和分析不构成个人投资建议。
