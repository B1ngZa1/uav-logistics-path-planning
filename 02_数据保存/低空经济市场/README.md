# 低空经济与无人机物流市场数据

更新日期：2026-09-17  
数据范围：中国/全球低空经济、无人机物流、城市空中交通（UAM）、低空基础设施、运营量、飞行小时、政策目标、市场规模与竞争格局。

## 文件说明

- `market_data_raw.csv`：逐指标保留来源原始口径、原始单位/措辞和审计备注。
- `market_data_normalized.csv`：在不改变原始事实含义的前提下统一单位；预测、目标、公司披露和推断均保留状态标签。
- `source_register.csv`：来源登记表，记录发布主体、日期、来源类型和可访问 URL。
- `methodology.md`：市场边界、来源优先级、单位换算、冲突处理和检查规则。
- `market_analysis.md`：基于数据的市场分析、竞争格局、基础设施瓶颈和不确定性。

## 快速结论

1. 中国无人机运行活动已进入规模化统计阶段：民航局公布的注册无人机从 2024 年底 217.7 万架增至 2025 年底 328.7 万架；年度累计飞行小时从 2666.7 万增至 4530.29 万，2025 年同比增速分别为 51.0% 和 69.89%。
2. 2025 年全国低空飞行服务站为 46 个、覆盖 23 个省（自治区、直辖市）；深圳政府披露 2024 年底各类型低空起降点累计 483 个。起降、通信、监视、导航、能源与运行服务仍是扩张的基础约束。
3. 中国“万亿级”与“2 万亿元”均属于目标或行业估算，不能与民航局注册量/飞行小时当作同一口径的已实现市场收入相加。
4. 全球无人机配送已经出现可验证的商业运营者，但披露多为累计订单而非收入，且服务区域、货品、是否包含医疗配送不一致；不能将 Zipline、Wing、Meituan 的累计订单直接相加作为全球总量。

## 使用提醒

- `status=official_statistic`：政府部门统计公报/正式统计数据。
- `status=official_policy`：政府规划、政策目标或监管状态，不代表已经实现的市场规模。
- `status=official_secondary`：政府/研究机构页面转引的二手统计，需注意原始统计口径未在该页面完整展开。
- `status=company_disclosure`：公司官网、年报或投资者关系披露，适合描述该公司运营，不代表行业总量。
- `status=industry_estimate`：咨询机构或专业机构估算/预测；预测年份不作历史事实使用。
- `status=inference`：由可见来源按公式推导的指标，不能视作来源直接公布值。

CSV 中所有记录均包含来源 URL、来源标题、检索日期和 notes；`value` 为近似下限时会在 notes 明确写出。
