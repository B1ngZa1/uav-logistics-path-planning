# 基于深度强化学习的多无人机协同物流配送路径规划

> 大学生创新训练计划项目
> 创建日期：2026-07-01
> 基础项目：多机械臂协同搬运轨迹规划

---

## 项目简介

本项目面向多无人机协同物流配送任务，提出一种基于深度强化学习PPO算法的无碰撞路径规划方法。通过设计三维空域模型、无人机运动学模型和多目标奖励函数，实现多架无人机在复杂环境中的动态路径优化与协同避障，并通过Python仿真平台进行算法验证。

**项目定位**：仅进行算法设计与仿真验证，不涉及真实无人机硬件搭建、飞控系统或实际物流部署。

---

## 核心问题

### 1. 三维空域路径规划
- 无人机在三维空域中飞行，路径规划复杂度显著增加
- 传统二维算法难以直接扩展到三维空间

### 2. 多机协同避障
- 多架无人机共享空域，存在碰撞风险
- 需要实时感知和规避其他无人机

### 3. 动态约束适应
- 气象条件、禁飞区等动态约束
- 需要自适应调整路径

### 4. 能耗与效率平衡
- 无人机电池续航有限
- 需要在配送效率和能耗之间取得平衡

### 5. 多订单任务分配
- 多个配送订单需要分配给多架无人机
- 存在最优匹配问题

---

## 技术方案

### 1. 算法核心
- **深度强化学习**：PPO（Proximal Policy Optimization）
- **多智能体协同**：CTDE（集中式训练分散式执行）框架
- **状态空间**：11维连续状态（位置、速度、距离、电量、进度等）
- **动作空间**：3维连续动作（三维加速度）

### 2. 环境建模
- **三维空域**：体素地图（100×100×50米，分辨率5米）
- **无人机运动学**：简化四旋翼模型
- **能耗模型**：飞行能耗 + 悬停能耗
- **碰撞检测**：三维距离场 + 圆形包围盒

### 3. 奖励函数
设计8项奖励分量：
1. 目标到达奖励（R_goal = 200）
2. 碰撞惩罚（P_collision = 200）
3. 间距惩罚（P_proximity = 100）
4. 队形保持惩罚（λ_form = 1.0）
5. 能耗惩罚（λ_energy = 0.5）
6. 时间惩罚（λ_time = 2）
7. 平滑惩罚（λ_smooth = 0.1）
8. 配送完成奖励（R_delivery = 50）

### 4. 任务分配
- **静态分配**：贪心算法、匈牙利算法
- **动态调整**：实时状态感知、优先级机制
- **端到端优化**：任务分配与路径规划联合优化

## 项目创新点

### 创新点一：三维空域路径规划
将二维栅格扩展到三维体素，处理真实飞行场景，考虑建筑物、禁飞区等三维障碍物。

### 创新点二：深度强化学习应用
从Q-learning升级为PPO深度强化学习，处理高维连续状态空间，实现精细轨迹规划。

### 创新点三：能耗感知优化
引入无人机能耗模型，综合考虑飞行能耗和悬停能耗，平衡配送效率与电池续航。

### 创新点四：多订单动态分配
将任务分配融入强化学习框架，实现端到端优化，支持动态订单插入和优先级调整。

### 创新点五：CTDE多机协同框架
采用集中式训练分散式执行框架，训练阶段学习协同策略，执行阶段分布式决策，无需实时通信。

## 应用场景

### 1. 城市即时配送
- 外卖、快递等小件物品配送
- 建筑物密集、空域受限
- 动态障碍物多

### 2. 医疗物资紧急配送
- 血液、药品等紧急物资
- 时间紧迫、路径最优
- 安全可靠

### 3. 偏远地区物流
- 山区、海岛等偏远地区
- 距离远、地形复杂
- 气象条件多变

### 4. 仓储内部调拨
- 大型仓库内部搬运
- 空间狭小、障碍物密集
- 多机协同

### 4. 推动技术创新
