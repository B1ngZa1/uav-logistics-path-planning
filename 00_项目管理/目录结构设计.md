## 四、文件命名规范

### 4.1 命名规则

1. **使用中文命名**：便于阅读和理解
2. **使用下划线分隔**：提高可读性
3. **包含版本号**：如`_v1`、`_初稿`、`_终稿`
4. **包含日期**：如`_20260701`
5. **避免特殊字符**：仅使用字母、数字、下划线、中文

### 4.2 命名示例

| 文件类型 | 命名示例 |
|---------|---------|
| 算法文档 | `PPO算法设计.md` |
| 仿真代码 | `ppo_agent.py` |
| 实验记录 | `实验记录_20260701.csv` |
| 图表脚本 | `plot_training_curve.py` |
| 输出图片 | `training_curve_scenario_s1.png` |
| 论文初稿 | `论文初稿_v1.md` |
| 答辩PPT | `答辩PPT_v1.pptx` |

## 七、总结

本目录结构设计参考了现有"多机械臂协同搬运轨迹规划"项目，并针对无人机物流配送场景进行了优化和扩展：

1. **空间扩展**：增加了三维空域相关的模型和代码
2. **算法升级**：增加了深度强化学习（PPO）相关的算法文档和代码
3. **能耗建模**：增加了能耗模型相关的文档和代码
4. **任务分配**：增加了任务分配算法相关的文档和代码
5. **可视化增强**：增加了三维可视化和动画生成相关的代码

目录结构清晰、模块化设计，便于团队协作和项目管理。
