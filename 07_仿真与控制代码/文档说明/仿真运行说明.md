# 仿真运行说明

> 项目：基于深度强化学习的多无人机协同物流配送路径规划
> 创建日期：2026-07-01

---

## 1. 环境准备

### 1.1 Python环境

```bash
# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Linux/Mac
# venv\Scripts\activate   # Windows

# 安装依赖
pip install -r requirements.txt
```

### 1.2 硬件要求

- CPU: 4核以上
- 内存: 8GB以上
- GPU: NVIDIA GPU（推荐，用于训练加速）
- 硬盘: 10GB可用空间

## 2. 运行步骤

### 2.1 训练模型

```bash
cd Python仿真
python main_train.py
```

### 2.2 运行实验

```bash
python experiments/run_scenario.py --scenario S1
python experiments/run_scenario.py --scenario S2
```

### 2.3 消融实验

```bash
python experiments/ablation_study.py
```

### 2.4 基线对比

```bash
python experiments/baseline_compare.py
```

## 3. 结果查看

- 训练日志: `../../02_数据保存/训练日志/`
- 模型检查点: `../../02_数据保存/模型检查点/`
- 可视化结果: `../../04_脚本图片输出/`

## 4. 常见问题

### 4.1 CUDA内存不足

减小 `batch_size` 或使用CPU训练。

### 4.2 训练不收敛

调整学习率和奖励权重。
