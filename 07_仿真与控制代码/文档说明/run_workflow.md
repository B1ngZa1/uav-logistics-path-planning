## 五、故障排除

### 5.1 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| Agent执行超时 | 任务复杂度高 | 增加超时时间、简化任务 |
| 输出格式错误 | Schema不匹配 | 检查schema定义、重试 |
| 内存不足 | 并行Agent过多 | 减少并行度、分批执行 |
| 网络错误 | API调用失败 | 重试、检查网络 |

### 5.2 重试机制

如果Agent执行失败，可以：

1. 查看错误日志
2. 分析失败原因
3. 调整参数或任务
4. 重新执行失败的Agent

### 5.3 手动干预

如果自动执行失败，可以：

1. 暂停工作流
2. 手动执行特定Agent
3. 检查输出结果
4. 恢复工作流执行

### 6.1 并行度调整

根据系统资源，可以调整并行度：

```javascript
// 增加并行度
parallel([...], { maxConcurrency: 4 })

// 减少并行度

```

### 6.2 超时设置

根据任务复杂度，可以调整超时时间：

```javascript
// 增加超时时间
agent(..., { timeout: 300000 }) // 5分钟

// 减少超时时间

```

