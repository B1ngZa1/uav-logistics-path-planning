## 一、项目概述

### 1.1 项目背景

城市环境中的无人机物流配送面临复杂挑战：

- **建筑物**：不同高度和类型的建筑障碍
- **河流 + 桥梁**：需要识别可通行区域
- **高压线塔**：高耸障碍物，需要精确避障
- **树木区域**：低空障碍，影响起降
- **动态飞鸟区**：移动障碍物，需要实时避让
- **禁飞区**：政府机关等严格禁飞区域
- **GPS通信干扰区**：影响定位精度
- **风雨天气区**：影响飞行稳定性

### 1.2 项目目标

- 在复杂三维城市环境中自动规划最优路径
- 12个配送点之间高效配送
- 避开所有障碍物，满足载重、高度、能耗约束
- 多无人机协同配送，优化整体效率

### 1.3 技术路线

```
深度强化学习(PPO) + CTDE框架 + 多订单动态分配
```

## 三、算法设计

### 3.1 PPO算法

```
Actor网络: [256, 128, 64] + ReLU → μ, σ
Critic网络: [256, 128, 64] + Tanh → V(s)
```

### 3.2 CTDE框架

```
训练阶段: 集中式Critic + 全局状态
执行阶段: 分散式Actor + 局部观测
```

### 3.3 课程学习

### B. 常见问题

**Q: 训练不收敛怎么办？**
A: 检查奖励函数设计，确保进度奖励足够强，惩罚不要过大。

**Q: 碰撞检测不准确？**
A: 调整障碍物的radius参数，确保覆盖实际碰撞区域。

**Q: 训练速度太慢？**
A: 减少max_steps，或使用GPU加速。
