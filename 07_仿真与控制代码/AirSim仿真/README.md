## 说明

本目录用于存放AirSim仿真相关的代码和配置文件。

AirSim是一个开源的无人机模拟器，可用于更真实的仿真验证。

## 文件说明

| 文件 | 说明 |
|------|------|
| airsim_config.json | AirSim配置文件 |
| airsim_control.py | AirSim控制脚本 |
| README.md | 本文件 |

## 使用方法

1. 安装AirSim
2. 配置airsim_config.json
3. 运行airsim_control.py
