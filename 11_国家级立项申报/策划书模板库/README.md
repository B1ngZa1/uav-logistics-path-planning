# 国家级立项申报·策划书模板库

更新时间：2026-09-20

本库面向无人机、低空经济、科技创新、大学生创新创业、政府科技项目申报和商业计划书写作。正文原文件按来源下载保存，未对原始 PDF/DOCX 内容做编辑；索引和说明文件属于本项目整理产物。

## 快速结论

- 本地共收录 26 份 PDF/DOCX 文件，均已完成文件格式和可解析性核验。
- 其中 6 份实际物理页数不少于 50 页：T01、T10、T11、T13、T14、T22。
- T12 为 46 页配套附件，不单独宣称达到 50 页；它与 T11 组合后可支撑选项比较、风险、采购、融资和交付章节。
- 中国高校/政府申报表大多是短表格或在线系统导出的申请书，不存在“官方统一要求正文不少于 50 页”的证据。本库将其作为章节来源、格式约束和评审要点使用，不把短表格冒充成长篇模板。

## 建议使用方式

1. 国家级项目/低空基础设施：先用 T02/T03/T04 确定政府或企业可研骨架，再用 T01、T11/T12 补充需求、选址、方案比选、投融资、风险和实施管理。
2. 无人机技术研发：用 T22 的“大型无人机研发及应用”方向作为政策需求与考核指标线索；用 T15/T16、T23/T25 的科研项目章节补充立项依据、技术路线、研究基础、成果和预算。
3. 大学生创新创业：用 T19、T20、T21、T26 形成“申报表/商业计划书/参赛范例”组合；用 T14 补充市场、销售估算、成本、现金流和启动资金。
4. 需要扩展至 50 页以上时，按 `50页以上模板清单.md` 的组合目录扩写，并将无人机项目自己的实验、测试、竞品、市场、财务、风险、知识产权和附件证据作为正文主体。

## 核验口径

- PDF：以 `pypdf` 读取到的物理页数为准；同时检查 `%PDF-` 文件头、加密状态和前若干页文字证据。
- DOCX：检查 ZIP/XML 可解析性、段落数、文字数和文档缓存页数。DOCX 缓存页数受排版环境影响，不能替代最终导出 PDF 的物理页数。
- 页数不等于内容适配度。任何正式申报前，都必须以当年度主管部门、学校或赛事系统的最新指南和在线表单为准。
