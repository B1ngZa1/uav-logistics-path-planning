## 一、工作流调用方式

### 1.1 单篇文献研读

在 Claude Code 中输入：

```
请帮我研读这篇论文：
[Paste PDF内容 或 提供文件路径]

项目背景：基于深度强化学习的多无人机协同物流配送路径规划
研读深度：标准（或 快速/深度）
```

### 1.2 批量文献研读

```
请按以下清单批量研读文献：
[提供文献清单或引用参考文献清单.md]

项目背景：基于深度强化学习的多无人机协同物流配送路径规划
重点方向：多智能体强化学习、任务分配
```

### 1.3 主题式文献研读

```
请研读与"奖励函数设计"相关的所有文献，并进行对比分析。

项目背景：基于深度强化学习的多无人机协同物流配送路径规划
```

## 二、单篇文献研读 Workflow

### Phase 1: 预处理与分类

**Agent: Parser**
- 读取文献内容
- 提取元数据（标题、作者、年份、来源）
- 判断文献类型
- 评估与本项目相关度

**输出:**
```markdown
## 文献元数据
| 项目 | 内容 |
|------|------|
| 标题 | [中文/英文] |
| 作者 | [列表] |
| 年份 | [年份] |
| 类型 | [期刊/学位/综述] |
| 相关度 | ★★★ / ★★ / ★ |
| 研读深度 | 深度/标准/快速 |
```

### Phase 2: 内容提取与分析

**Agent: Analyzer**
- 根据文献类型选择研读Prompt
- 逐章节提取结构化信息
- 转录关键公式
- 提取实验数据
- 进行批判性分析

**输出:** 知识卡片初稿

### Phase 3: 质量评审

**Agent: Reviewer**
- 检查完整性
- 验证准确性
- 评估深度
- 评估关联性

**输出:** 评审报告 + 评分

### Phase 4: 修订与定稿

- 如果评分 < B，返回Phase 2修订
- 如果评分 ≥ B，进入知识库

**输出:** 最终知识卡片

## 三、批量文献研读 Workflow

### Phase 1: 文献分类与排序

**输入:** 参考文献清单（32篇）

**Agent: Orchestrator**
```
任务:
1. 按研究方向分类
   - 多无人机协同（6篇）
   - 多智能体强化学习（8篇）
   - 任务分配算法（6篇）
   - 深度强化学习路径规划（6篇）
   - 无人机物流配送（6篇）

2. 按文献类型分类
   - 期刊论文
   - 会议论文
   - 学位论文
   - 综述

3. 按相关度排序
   - 高相关（优先研读）
   - 中相关
   - 低相关（可略读）

4. 确定研读批次
   - 第1批：高相关 + 核心文献（10篇）
   - 第2批：中相关文献（15篇）
   - 第3批：其他文献（7篇）
```

**输出:** 研读计划表

### Phase 2: 并行深度研读

**按方向分3组并行研读：**

```
┌─────────────────┐  ┌─────────────────┐  ┌─────────────────┐
│  Agent: 分析器A  │  │  Agent: 分析器B  │  │  Agent: 分析器C  │
│                 │  │                 │  │                 │
│  方向: 协同+物流  │  │  方向: MARL算法  │  │  方向: 规划+分配  │
│  文献: 12篇     │  │  文献: 10篇     │  │  文献: 10篇     │
│                 │  │                 │  │                 │
│  逐篇:          │  │  逐篇:          │  │  逐篇:          │
│  1. 提取内容    │  │  1. 提取内容    │  │  1. 提取内容    │
│  2. 深度分析    │  │  2. 深度分析    │  │  2. 深度分析    │
│  3. 质量评审    │  │  3. 质量评审    │  │  3. 质量评审    │
│  4. 生成卡片    │  │  4. 生成卡片    │  │  4. 生成卡片    │
└─────────────────┘  └─────────────────┘  └─────────────────┘
```

### Phase 3: 交叉关联分析

**Agent: Linker**
```
任务:
1. 构建文献-方法矩阵
   行: 各文献
   列: 关键技术维度
   值: 使用/未使用/改进

2. 绘制技术演进图
   - MARL算法演进: DQN → MADDPG → QMIX → MAPPO
   - 通信学习演进: CommNet → DIAL → TarMAC

3. 识别研究空白
   - 哪些组合未被探索？
   - 哪些假设未被验证？

4. 映射到本项目
   - 环境建模: 参考哪些文献？
   - 奖励设计: 参考哪些文献？
   - 算法选择: 推荐哪些方法？
```

**输出:**
- 文献-方法矩阵
- 技术演进图
- 研究空白分析
- 项目借鉴清单

### Phase 4: 知识整合与输出

**Agent: Orchestrator**
```
任务:
1. 更新知识库索引
2. 生成文献综述初稿
3. 输出项目设计启示
4. 标记需补读的文献
```

**输出:**
- 知识库更新
- 文献综述初稿
- 项目借鉴清单
- 补读建议

## 四、快速研读模式（15分钟/篇）

适用于：一般相关度的期刊论文

```
步骤1: 速读（3分钟）
- 读摘要和结论
- 判断相关度
- 确定是否需要深入

步骤2: 方法提取（5分钟）
- 核心方法是什么？
- 关键创新点？
- 与现有方法的区别？

步骤3: 结果提取（3分钟）
- 主要实验结果
- 与基线对比

步骤4: 快速整理（4分钟）
- 填写精简知识卡片
- 标注与本项目关联
```

---

## 五、标准研读模式（30分钟/篇）

适用于：高相关度的期刊论文

```
步骤1: 通读全文（10分钟）
- 理解整体结构
- 标记重点段落

步骤2: 方法解析（10分钟）
- 提取核心公式
- 理解算法流程
- 分析创新点

步骤3: 实验分析（5分钟）
- 提取关键数据
- 分析实验设计
- 评估结果可信度

步骤4: 整理输出（5分钟）
- 生成完整知识卡片
- 分析与本项目关联
- 提炼借鉴要点
```

---

## 六、深度研读模式（60分钟/篇）

适用于：博士论文、核心参考文献

```
步骤1: 通读全文（20分钟）
- 理解研究脉络
- 标记所有重点

步骤2: 方法论分析（15分钟）
- 理解技术路线
- 分析公式推导
- 评估方法创新性

步骤3: 实验体系分析（10分钟）
- 分析实验设计
- 提取所有关键数据
- 评估可重复性

步骤4: 批判性分析（10分钟）
- 识别方法局限
- 分析隐含假设
- 评估适用性

步骤5: 整理输出（5分钟）
- 生成详细知识卡片
- 深度关联分析
- 详细借鉴方案
```
