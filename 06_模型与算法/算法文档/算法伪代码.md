## 1. PPO训练算法

```
初始化策略网络 π_θ，价值网络 V_φ
for episode = 1, 2, ..., N do
    重置环境，获取初始状态 s
    for t = 1, 2, ..., T do
        根据 π_θ(a|s) 采样动作 a
        执行动作 a，获取下一状态 s'，奖励 r
        存储 (s, a, r, s') 到经验缓冲区
        s = s'
    end for
    计算优势函数 A_t
    更新策略网络 π_θ
    更新价值网络 V_φ
end for
```

## 2. CTDE训练算法

```
初始化共享Actor网络 π_θ，集中式Critic网络 V_φ
for episode = 1, 2, ..., N do
    各智能体收集轨迹数据
    汇总全局状态和奖励
    计算集中式价值评估
    更新各智能体策略
end for
```

## 3. 任务分配算法

```
输入：配送任务列表 T，无人机列表 U
输出：任务分配方案 A
for each task t in T do
    计算各无人机到 t 的代价
    选择代价最小的无人机 u
    分配任务 t 给 u
end for
```
