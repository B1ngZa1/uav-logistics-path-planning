## 1. 飞行能耗

### 1.1 前进功率

克服空气阻力所需功率与速度的立方成正比：

$$P_{forward} = k_1 \cdot \|\mathbf{v}_{horizontal}\|^3$$

其中：
- $k_1$：前进功率系数，与空气密度、阻力系数、旋翼面积相关
- 典型值：$k_1 = 0.8 \, W \cdot s^3 / m^3$

展开形式：

$$P_{forward} = k_1 \cdot (v_x^2 + v_y^2)^{3/2}$$

### 1.2 爬升功率

克服重力做功所需功率：

$$P_{climb} = k_2 \cdot m \cdot g \cdot v_z$$

其中：
- $k_2$：爬升效率系数，$k_2 = 1.2$
- $m$：无人机总质量（含载荷），单位 kg
- $g$：重力加速度，$g = 9.81 \, m/s^2$
- $v_z$：垂直速度（正值为上升，负值为下降）

**注意：** 当 $v_z < 0$（下降）时，$P_{climb} < 0$，表示能量回收。

### 1.3 总飞行功率

$$P_{flight} = P_{forward} + P_{climb} = k_1 \cdot \|\mathbf{v}_{horizontal}\|^3 + k_2 \cdot m \cdot g \cdot v_z$$

考虑电机效率 $\eta_{motor}$（典型值 0.8）：

$$P_{flight,total} = \frac{P_{flight}}{\eta_{motor}}$$

## 2. 悬停能耗

### 2.1 悬停功率

悬停时需要产生等于重力的升力：

$$P_{hover} = k_3 \cdot m \cdot g$$

其中：
- $k_3$：悬停功率系数
- 典型值：$k_3 = 0.08 \, m/s$

**物理推导：**

根据动量理论，悬停时的理想功率为：

$$P_{ideal} = \frac{(mg)^{3/2}}{\sqrt{2 \rho A}}$$

其中 $\rho$ 为空气密度（约 1.225 kg/m³），$A$ 为旋翼盘面积。

### 2.2 悬停时间计算

总悬停时间包括：

$$t_{hover,total} = t_{takeoff} + t_{landing} + t_{delivery\_wait}$$

| 阶段 | 符号 | 典型时长 | 说明 |
|------|------|----------|------|
| 起飞阶段 | $t_{takeoff}$ | 10~30 s | 垂直爬升至巡航高度 |
| 降落阶段 | $t_{landing}$ | 10~30 s | 垂直下降至目标点 |
| 配送等待 | $t_{delivery\_wait}$ | 30~120 s | 等待取货/卸货 |

悬停能耗：

$$E_{hover} = P_{hover} \cdot t_{hover,total} = k_3 \cdot m \cdot g \cdot t_{hover,total}$$

## 3. 电池模型

### 3.1 电池参数定义

| 参数 | 符号 | 典型值 | 单位 |
|------|------|--------|------|
| 电池容量 | $E_{capacity}$ | 500 | Wh |
| 放电效率 | $\eta_{discharge}$ | 0.9 | - |
| 电压 | $V_{battery}$ | 22.2 | V |
| 最大放电倍率 | $C_{max}$ | 10 | C |
| 安全余量 | $\alpha_{safe}$ | 0.15 | - |

**可用能量：**
$$E_{usable} = E_{capacity} \cdot \eta_{discharge} \cdot (1 - \alpha_{safe})$$

代入典型值：
$$E_{usable} = 500 \times 0.9 \times (1 - 0.15) = 382.5 \, Wh$$

### 3.2 剩余电量计算

连续时间形式：

$$E_{remain}(t) = E_{init} - \int_0^t P_{total}(\tau) \, d\tau$$

离散时间形式：

$$E_{remain,t+1} = E_{remain,t} - P_{total,t} \cdot \Delta t$$

### 3.3 电量状态（SOC）

$$SOC(t) = \frac{E_{remain}(t)}{E_{capacity}} \times 100\%$$

**返航条件：**
$$SOC(t) \leq SOC_{threshold} \Rightarrow \text{触发返航指令}$$

典型阈值：$SOC_{threshold} = 20\%$

## 4. 参数标定方法

### 4.1 实验标定法

1. **前进功率系数 $k_1$ 标定：**
   - 在无风环境下进行多组匀速飞行测试
   - 测量不同速度 $v$ 下的功率消耗 $P$
   - 线性回归拟合 $P = k_1 v^3$

2. **爬升功率系数 $k_2$ 标定：**
   - 进行垂直爬升测试
   - 测量爬升功率与 $m \cdot g \cdot v_z$ 的关系

3. **悬停功率系数 $k_3$ 标定：**
   - 测量悬停状态下的功率消耗

### 4.2 理论计算法

基于空气动力学理论：

$$k_1 = \frac{1}{2} \rho C_D A_{front}$$

$$k_3 = \frac{1}{\eta_{rotor}} \sqrt{\frac{1}{2 \rho A_{disk}}}$$

## 6. Python实现框架

```python
import numpy as np

class EnergyModel:
    """无人机能耗模型"""

    def __init__(self, config):
        self.k1 = config.get('k1', 0.8)              # 前进功率系数
        self.k2 = config.get('k2', 1.2)              # 爬升功率系数
        self.k3 = config.get('k3', 0.08)             # 悬停功率系数
        self.eta_motor = config.get('eta_motor', 0.8) # 电机效率
        self.E_capacity = config.get('E_capacity', 500.0)  # 电池容量 (Wh)
        self.eta_discharge = config.get('eta_discharge', 0.9)  # 放电效率
        self.alpha_safe = config.get('alpha_safe', 0.15)  # 安全余量
        self.SOC_threshold = config.get('SOC_threshold', 0.2)  # 返航阈值

        # 计算可用能量
        self.E_usable = self.E_capacity * self.eta_discharge * (1 - self.alpha_safe)

    def compute_flight_power(self, velocity, mass):
        """
        计算飞行功率

        Args:
            velocity: [vx, vy, vz] 速度向量
            mass: 无人机总质量 (kg)

        Returns:
            power: 飞行功率 (W)
        """
        v_horizontal = np.sqrt(velocity[0]**2 + velocity[1]**2)
        v_z = velocity[2]

        P_forward = self.k1 * v_horizontal**3
        P_climb = self.k2 * mass * 9.81 * v_z

        P_flight = (P_forward + P_climb) / self.eta_motor
        return max(P_flight, 0)  # 功率不能为负

    def compute_hover_power(self, mass):
        """
        计算悬停功率

        Args:
            mass: 无人机总质量 (kg)

        Returns:
            power: 悬停功率 (W)
        """
        return self.k3 * mass * 9.81

    def compute_energy_consumption(self, power, dt):
        """
        计算能耗

        Args:
            power: 功率 (W)
            dt: 时间步长 (s)

        Returns:
            energy: 能耗 (Wh)
        """
        return power * dt / 3600.0

    def update_SOC(self, SOC_current, power, dt):
        """
        更新电量状态

        Args:
            SOC_current: 当前SOC
            power: 功率 (W)
            dt: 时间步长 (s)

        Returns:
            SOC_new: 新的SOC
        """
        energy_consumed = self.compute_energy_consumption(power, dt)
        SOC_new = SOC_current - energy_consumed / self.E_capacity
        return max(SOC_new, 0)

    def check_return_condition(self, SOC_current):
        """检查是否需要返航"""
        return SOC_current <= self.SOC_threshold
```
