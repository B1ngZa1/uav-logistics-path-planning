# 技术路线说明文档

> 项目：基于深度强化学习的多无人机协同物流配送路径规划
> 版本：v1.0
> 创建日期：2026-07-01

---

## 一、技术选型总览

| 技术领域 | 选型 | 选择理由 |
| ------- | ------ | ------- |
| 强化学习算法 | PPO | 训练稳定、实现简单、连续动作空间表现好 |
| 多智能体框架 | CTDE | 集中训练提高效率，分散执行便于部署 |
| 深度学习框架 | PyTorch | 动态图、调试方便、社区活跃 |
| 仿真环境 | Python + Gym | 兼容性好、易于扩展 |
| 可视化 | Matplotlib + Plotly | 3D渲染、交互式图表 |

## 二、算法技术路线

### 2.1 PPO算法选型理由

对比分析：

| 算法 | 优点 | 缺点 | 适用性 |
| ---- | ---- | ---- | -------- |
| PPO | 训练稳定、超参数不敏感 | 样本效率一般 | ⭐⭐⭐⭐⭐ |
| SAC | 样本效率高 | 实现复杂、超参数敏感 | ⭐⭐⭐⭐ |
| DDPG | 连续动作好 | 训练不稳定 | ⭐⭐⭐ |
| TD3 | 改进DDPG | 实现复杂 | ⭐⭐⭐⭐ |

**结论**：PPO在训练稳定性和实现复杂度之间取得最佳平衡。

### 2.2 CTDE框架选型理由

- 集中训练：利用全局信息，加速学习
- 分散执行：仅需局部观测，便于实际部署
- 参数共享：减少参数量，提高泛化能力

## 三、仿真技术路线

### 3.1 环境搭建

```
Python 3.8+
├── PyTorch 1.10+ (深度学习)
├── Gym 0.21+ (环境接口)
├── NumPy 1.21+ (数值计算)
├── SciPy 1.7+ (优化算法)
└── Matplotlib 3.5+ (可视化)
```

### 3.2 代码架构

```
Python仿真/
├── config.py (全局配置)
├── main_train.py (训练入口)
├── algorithm/ (算法模块)
│   ├── ppo_agent.py (PPO智能体)
│   ├── network.py (神经网络)
│   ├── reward_function.py (奖励函数)
│   ├── ctde_framework.py (CTDE框架)
│   └── task_allocator.py (任务分配)
├── environment/ (环境模块)
│   ├── airspace.py (空域环境)
│   ├── airspace_env.py (Gym环境)
│   ├── collision.py (碰撞检测)
│   ├── uav_dynamics.py (动力学)
│   └── energy_model.py (能耗模型)
├── utils/ (工具模块)
│   ├── state_encoder.py (状态编码)
│   ├── action_processor.py (动作处理)
│   └── logger.py (日志记录)
```

## 四、实验技术路线

### 4.1 实验场景

| 场景 | UAV数 | 订单数 | 障碍物 | 目的 |
| ---- | ----- | ------ | ------ | ---- |
| S1 | 3 | 5 | 0 | 基础功能验证 |

### 4.2 评估指标

| 指标 | 计算方式 | 目标值 |
| ---- | ------- | ------ |
| 任务完成率 | 完成订单/总订单 | ≥85% |
| 碰撞率 | 碰撞次数/总步数 | ≤5% |
| 平均配送时间 | 总时间/完成订单数 | ≤15min |
| 路径优化率 | (贪心-PPO)/贪心 | ≥20% |

## 六、总结
