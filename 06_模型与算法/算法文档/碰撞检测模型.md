## 1. 碰撞类型定义

### 1.1 无人机间碰撞

两架无人机之间的距离小于安全距离阈值时判定为碰撞。设无人机 $i$ 的位置为 $\mathbf{p}_i = (x_i, y_i, z_i)$，无人机 $j$ 的位置为 $\mathbf{p}_j = (x_j, y_j, z_j)$，安全距离为 $d_{safe}$，则碰撞条件为：

$$\|\mathbf{p}_i - \mathbf{p}_j\| < d_{safe}$$

其中 $\|\cdot\|$ 为欧氏距离。当多架无人机同时作业时，需对所有无人机对进行两两检测。

### 1.2 无人机-障碍物碰撞

无人机与静态障碍物（建筑物、树木等）之间的碰撞检测。设无人机位置为 $\mathbf{p}$，障碍物占据区域为 $\Omega_{obs}$，无人机包围球半径为 $r_{uav}$，则碰撞条件为：

$$\min_{\mathbf{q} \in \Omega_{obs}} \|\mathbf{p} - \mathbf{q}\| < r_{uav}$$

对于体素地图表示的障碍物，该距离可通过遍历周围体素计算点到体素的最短距离获得。

### 1.3 无人机-边界碰撞

无人机飞出空域边界时判定为边界碰撞。设空域范围为 $[0, L_x] \times [0, L_y] \times [0, L_z]$，无人机位置为 $\mathbf{p} = (x, y, z)$，则边界碰撞条件为：

$$x < 0 \lor x > L_x \lor y < 0 \lor y > L_y \lor z < 0 \lor z > L_z$$

考虑无人机半径时，边界条件扩展为：

$$x - r_{uav} < 0 \lor x + r_{uav} > L_x \lor y - r_{uav} < 0 \lor y + r_{uav} > L_y \lor z - r_{uav} < 0 \lor z + r_{uav} > L_z$$

### 1.4 无人机-禁飞区碰撞

禁飞区（No-Fly Zone）是空域中禁止无人机进入的特殊区域，通常由多边形底面和高度范围定义。设禁飞区为 $NFZ = \{(x, y, z) | (x, y) \in P_{xy}, z_{min} \leq z \leq z_{max}\}$，其中 $P_{xy}$ 为多边形区域。碰撞条件为：

$$(x, y) \in P_{xy} \land z_{min} \leq z \leq z_{max}$$

多边形内外判断采用射线法（Ray Casting）算法。

## 2. 碰撞检测算法

### 2.1 球形包围盒检测

将无人机近似为球形包围盒（Bounding Sphere），半径为 $r_{uav}$。检测时遍历包围球范围内的所有体素，计算点到体素的最短距离。

**算法流程：**

1. 将无人机位置转换为体素索引 $(i, j, k)$
2. 计算检查范围：$R = \lceil r_{uav} / \Delta \rceil$，其中 $\Delta$ 为体素分辨率
3. 遍历范围 $[-R, R]^3$ 内的所有邻域体素
4. 对每个障碍物体素，计算点到体素的最短距离
5. 若最短距离小于 $r_{uav}$，则判定碰撞

**点到体素距离计算：**

设体素中心为 $(v_x, v_y, v_z)$，半边长为 $h = \Delta / 2$，点坐标为 $(p_x, p_y, p_z)$，则点到体素（视为长方体）的最短距离为：

$$d = \sqrt{d_x^2 + d_y^2 + d_z^2}$$

其中：
$$d_x = \max(0, |p_x - v_x| - h)$$
$$d_y = \max(0, |p_y - v_y| - h)$$
$$d_z = \max(0, |p_z - v_z| - h)$$

### 2.2 距离场快速查询

距离场（Distance Field）是一种预计算数据结构，存储每个自由体素到最近障碍物的距离。查询时只需一次数组访问，时间复杂度为 $O(1)$。

**构建方法：**

采用欧氏距离变换（Euclidean Distance Transform, EDT）算法，基于 scipy 库实现：

```python
from scipy.ndimage import distance_transform_edt

# 创建自由空间掩码
free_mask = (voxel_data == VoxelState.FREE).astype(np.float32)

# 计算距离场（结果为体素单位，需乘以分辨率转换为米）
distance_field = distance_transform_edt(free_mask) * resolution
```

**查询方法：**

给定世界坐标 $(x, y, z)$，先转换为体素索引，再直接读取距离场值：

```python
i, j, k = world_to_voxel(x, y, z)
distance = distance_field[i, j, k]
```

### 2.3 轨迹碰撞检测

检测无人机从起点到终点的直线轨迹是否与障碍物碰撞。采用离散采样法，在轨迹上均匀取 $N$ 个检测点。

**算法流程：**

1. 输入起点 $\mathbf{p}_s$ 和终点 $\mathbf{p}_e$
2. 对参数 $t \in [0, 1]$ 均匀采样 $N$ 个点：$\mathbf{p}(t) = \mathbf{p}_s + t(\mathbf{p}_e - \mathbf{p}_s)$
3. 对每个采样点执行球形包围盒碰撞检测
4. 若任一采样点碰撞，则判定轨迹碰撞

采样点数 $N$ 需满足：$N \geq \lceil \|\mathbf{p}_e - \mathbf{p}_s\| / (2 r_{uav}) \rceil$，以确保不遗漏碰撞。

### 2.4 多机碰撞检测

对 $n$ 架无人机进行两两碰撞检测，输出所有碰撞的无人机对。

**算法流程：**

1. 输入所有无人机位置 $\{\mathbf{p}_1, \mathbf{p}_2, \ldots, \mathbf{p}_n\}$
2. 对所有无人机对 $(i, j)$，$i < j$，执行距离检测
3. 若 $\|\mathbf{p}_i - \mathbf{p}_j\| < d_{safe}$，则记录碰撞对 $(i, j)$
4. 输出碰撞对列表

**复杂度分析：** 时间复杂度 $O(n^2)$，适用于小规模无人机群。大规模场景可采用空间哈希或 k-d tree 优化至 $O(n \log n)$。

## 3. 安全距离定义

| 类型 | 安全距离 | 说明 |
| ---- | -------- | ---- |
| 无人机间安全距离 $d_{safe}$ | 10 m | 两架无人机中心点之间的最小允许距离 |
| 障碍物安全距离 $d_{obs}$ | 5 m | 无人机中心点到障碍物表面的最小允许距离 |
| 地面安全高度 $h_{min}$ | 10 m | 无人机飞行的最低允许高度 |

安全距离的设置考虑了以下因素：

- **无人机间安全距离（10 m）**：包含无人机本体尺寸、GPS 定位误差、控制响应延迟等因素的综合安全裕度
- **障碍物安全距离（5 m）**：考虑传感器测量误差和机动能力限制，确保有足够距离进行避障机动
- **地面安全高度（10 m）**：避免地面效应和人员安全风险

## 4. 距离场构建

### 4.1 体素地图距离场

体素地图将三维空间离散化为规则网格，每个体素标记为自由空间（FREE=0）、障碍物（OBSTACLE=1）、禁飞区（NO_FLY=2）或动态障碍物区域（DYNAMIC=3）。

**数据结构：**

```python
class VoxelMap:
    def __init__(self, nx, ny, nz, resolution):
        self.nx = nx          # X方向体素数量
        self.ny = ny          # Y方向体素数量
        self.nz = nz          # Z方向体素数量
        self.resolution = resolution  # 体素分辨率（米）
        self.data = np.zeros((nx, ny, nz), dtype=np.int8)  # 体素状态
        self.distance_field = None  # 距离场（懒加载）
```

**坐标转换：**

- 世界坐标转体素索引：$(i, j, k) = (\lfloor x / \Delta \rfloor, \lfloor y / \Delta \rfloor, \lfloor z / \Delta \rfloor)$
- 体素索引转世界坐标（体素中心）：$(x, y, z) = ((i + 0.5)\Delta, (j + 0.5)\Delta, (k + 0.5)\Delta)$

### 4.2 EDT 算法

欧氏距离变换（Euclidean Distance Transform）是一种计算每个像素/体素到最近背景像素/体素欧氏距离的算法。

**算法原理：**

对于三维体素地图，EDT 算法将三维距离计算分解为三个一维距离变换的组合：

$$D(i, j, k) = \min_{i', j', k' \in \text{obstacle}} \sqrt{(i-i')^2 + (j-j')^2 + (k-k')^2}$$

实际实现采用 scipy 库的 `distance_transform_edt` 函数，该函数基于 Meijster 算法，时间复杂度为 $O(N)$，其中 $N$ 为体素总数。

**构建流程：**

1. 创建自由空间二值掩码：`free_mask = (data == FREE)`
2. 执行 EDT 变换：`distance_field = distance_transform_edt(free_mask) * resolution`
3. 结果存储为浮点数组，单位为米

### 4.3 O(1) 快速查询

距离场构建完成后，任意位置的障碍物距离查询只需一次坐标转换和一次数组访问，时间复杂度为 $O(1)$。

**查询函数：**

```python
def get_distance_at(self, x, y, z):
    if self.distance_field is None:
        self.compute_distance_field()
    i, j, k = self.world_to_voxel(x, y, z)
    return float(self.distance_field[i, j, k])
```

**空间复杂度：** 距离场与体素地图大小相同，为 $O(n_x \times n_y \times n_z)$。对于 100m x 100m x 50m 空域、5m 分辨率的场景，体素数量为 $20 \times 20 \times 10 = 4000$，内存占用约 16 KB（float32）。

## 5. 避障策略

### 5.1 反应式避障

反应式避障（Reactive Obstacle Avoidance）基于当前传感器信息实时调整飞行方向，适用于未知环境或动态障碍物场景。

**VO（Velocity Obstacle）算法：**

1. 计算速度障碍物锥：对于每个障碍物，计算所有可能导致碰撞的速度集合
2. 选择安全速度：在可行速度空间中选择满足目标方向且避开速度障碍物的速度
3. 速度调整：将选定速度投影到动力学可行范围内

**人工势场法：**

$$\mathbf{F}_{total} = \mathbf{F}_{att} + \mathbf{F}_{rep}$$

- 引力：$\mathbf{F}_{att} = -k_{att}(\mathbf{p} - \mathbf{p}_{goal})$
- 斥力：$\mathbf{F}_{rep} = k_{rep} \left(\frac{1}{d} - \frac{1}{d_0}\right) \frac{1}{d^2} \nabla d$，其中 $d$ 为到障碍物距离，$d_0$ 为影响范围

### 5.2 预测式避障

预测式避障（Predictive Obstacle Avoidance）基于轨迹预测提前规划避障路径。

**轨迹预测：**

假设其他无人机和动态障碍物在短时间 $\Delta t$ 内保持匀速直线运动：

$$\hat{\mathbf{p}}(t + \Delta t) = \mathbf{p}(t) + \mathbf{v}(t) \cdot \Delta t$$

**预测碰撞检测：**

1. 预测未来 $T$ 秒内所有实体的轨迹
2. 对预测轨迹执行碰撞检测
3. 若预测到碰撞，提前调整航向或速度

**MPC（Model Predictive Control）方法：**

在有限时域 $[t, t+T]$ 内求解最优控制序列，同时满足碰撞约束：

$$\min_{\mathbf{u}} \sum_{k=0}^{N-1} \left[ \|\mathbf{p}_k - \mathbf{p}_{goal}\|^2 + \lambda \|\mathbf{u}_k\|^2 \right]$$
$$\text{s.t.} \quad \|\mathbf{p}_k^{(i)} - \mathbf{p}_k^{(j)}\| \geq d_{safe}, \quad \forall i \neq j$$

### 5.3 多机协调避障

多机协调避障（Cooperative Obstacle Avoidance）在多无人机系统中实现全局避障协调。

**优先级策略：**

为每架无人机分配优先级，高优先级无人机保持原航路，低优先级无人机负责避让：

$$\text{priority}(i) = f(\text{remaining\_energy}, \text{task\_urgency}, \text{uav\_id})$$

**协议规则：**

1. 右侧通行规则：当两架无人机迎面相遇时，各自向右偏移
2. 高度分层：不同高度层分配给不同方向的无人机
3. 通信协调：通过机间通信交换位置和意图信息，协商避障方案

**CBS（Conflict-Based Search）算法：**

1. 为每架无人机独立规划初始路径
2. 检测路径间的冲突（时间-空间重叠）
3. 对冲突添加约束，重新规划受影响的路径
4. 迭代直至无冲突

## 6. Python 实现

### 6.1 CollisionDetector 类

```python
class CollisionDetector:
    """碰撞检测器"""

    def __init__(self, airspace, uav_radius=0.5, safe_distance=10.0):
        """
        初始化碰撞检测器

        Args:
            airspace: 三维空域环境（Airspace3D 实例）
            uav_radius: 无人机包围球半径（米）
            safe_distance: 无人机间最小安全距离（米）
        """
        self.airspace = airspace
        self.uav_radius = uav_radius
        self.safe_distance = safe_distance
        self.voxel_map = airspace.voxel_map
        self.resolution = airspace.resolution

    def check_point_obstacle(self, position):
        """检测点与障碍物的碰撞"""
        x, y, z = position
        # 边界检测
        if (x < 0 or x > self.airspace.size[0] or
            y < 0 or y > self.airspace.size[1] or
                z < 0 or z > self.airspace.size[2]):
            return True
        # 体素碰撞检测
        i, j, k = self.voxel_map.world_to_voxel(x, y, z)
        return self.voxel_map.is_obstacle(i, j, k)

    def check_sphere_obstacle(self, position):
        """检测球形包围盒与障碍物的碰撞"""
        x, y, z = position
        radius = self.uav_radius
        # 边界检测
        if (x - radius < 0 or x + radius > self.airspace.size[0] or
            y - radius < 0 or y + radius > self.airspace.size[1] or
                z - radius < 0 or z + radius > self.airspace.size[2]):
            return True
        # 获取可能碰撞的体素范围
        i, j, k = self.voxel_map.world_to_voxel(x, y, z)
        check_range = max(1, int(np.ceil(radius / self.resolution)))
        for di in range(-check_range, check_range + 1):
            for dj in range(-check_range, check_range + 1):
                for dk in range(-check_range, check_range + 1):
                    ni, nj, nk = i + di, j + dj, k + dk
                    if self.voxel_map.is_obstacle(ni, nj, nk):
                        dist = self._point_to_voxel_distance(position, ni, nj, nk)
                        if dist < radius:
                            return True
        return False

    def check_uav_collision(self, pos1, pos2):
        """检测两架无人机之间的碰撞"""
        dist = np.linalg.norm(pos1 - pos2)
        return dist < self.safe_distance

    def check_multi_uav_collision(self, positions):
        """检测多架无人机之间的碰撞"""
        n = len(positions)
        collisions = []
        for i in range(n):
            for j in range(i + 1, n):
                if self.check_uav_collision(positions[i], positions[j]):
                    collisions.append((i, j))
        return collisions

    def check_trajectory_collision(self, start, end, num_checks=10):
        """检测轨迹碰撞（线段与障碍物）"""
        for t in np.linspace(0, 1, num_checks):
            position = start + t * (end - start)
            if self.check_sphere_obstacle(position):
                return True
        return False
```

### 6.2 距离场计算

```python
class VoxelMap:
    """三维体素地图"""

    def compute_distance_field(self):
        """
        计算障碍物距离场

        Returns:
            距离场数组，每个体素存储到最近障碍物的距离（米）
        """
        from scipy.ndimage import distance_transform_edt

        # 创建自由空间掩码
        free_mask = (self.data == VoxelState.FREE).astype(np.float32)

        # 使用欧氏距离变换
        self.distance_field = distance_transform_edt(free_mask) * self.resolution

        return self.distance_field

    def get_distance_at(self, x, y, z):
        """获取指定世界坐标处的障碍物距离"""
        if self.distance_field is None:
            self.compute_distance_field()
        i, j, k = self.world_to_voxel(x, y, z)
        return float(self.distance_field[i, j, k])
```

### 6.3 碰撞检测函数

```python
def check_obstacle_collision(uav_pos, obs_pos, obs_radius, d_obs=3.0):
    """
    检测无人机与障碍物是否碰撞

    Args:
        uav_pos: 无人机位置
        obs_pos: 障碍物中心位置
        obs_radius: 障碍物半径
        d_obs: 障碍物安全距离

    Returns:
        collision: 是否碰撞
        distance: 距离
    """
    distance = np.linalg.norm(uav_pos - obs_pos)
    return distance < obs_radius + d_obs, distance


def check_boundary(position, space_size, h_min=10):
    """
    检测是否超出边界

    Args:
        position: 位置
        space_size: 空域尺寸 (Lx, Ly, Lz)
        h_min: 最低安全高度

    Returns:
        in_bounds: 是否在边界内
    """
    return (0 <= position[0] <= space_size[0] and
            0 <= position[1] <= space_size[1] and
            h_min <= position[2] <= space_size[2])


def detect_all(uav_positions, obstacle_positions, obstacle_radii,
               d_safe=10.0, d_obs=5.0):
    """
    检测所有碰撞

    Returns:
        uav_collisions: 无人机间碰撞列表
        obs_collisions: 障碍物碰撞列表
    """
    uav_collisions = []
    obs_collisions = []

    # 无人机间碰撞
    for i in range(len(uav_positions)):
        for j in range(i + 1, len(uav_positions)):
            collision, dist = check_uav_collision(
                uav_positions[i], uav_positions[j], d_safe)
            if collision:
                uav_collisions.append((i, j, dist))

    # 障碍物碰撞
    for i in range(len(uav_positions)):
        for k in range(len(obstacle_positions)):
            collision, dist = check_obstacle_collision(
                uav_positions[i], obstacle_positions[k],
                obstacle_radii[k], d_obs)
            if collision:
                obs_collisions.append((i, k, dist))

    return uav_collisions, obs_collisions
```

### 6.4 最近障碍物查询

```python
def get_nearest_obstacle_info(self, position):
    """
    获取最近障碍物信息

    Args:
        position: 位置 [x, y, z]

    Returns:
        包含距离和方向的字典
    """
    x, y, z = position
    i, j, k = self.voxel_map.world_to_voxel(x, y, z)

    # 搜索范围（体素单位）
    search_range = 5
    min_dist = float('inf')
    nearest_pos = None

    for di in range(-search_range, search_range + 1):
        for dj in range(-search_range, search_range + 1):
            for dk in range(-search_range, search_range + 1):
                ni, nj, nk = i + di, j + dj, k + dk
                if self.voxel_map.is_obstacle(ni, nj, nk):
                    dist = self._point_to_voxel_distance(position, ni, nj, nk)
                    if dist < min_dist:
                        min_dist = dist
                        nearest_pos = self.voxel_map.voxel_to_world(ni, nj, nk)

    return {
        'distance': min_dist,
        'nearest_position': np.array(nearest_pos) if nearest_pos else None
    }


def get_nearest_uav_distance(uav_index, positions):
    """
    获取最近其他无人机的距离

    Args:
        uav_index: 当前无人机索引
        positions: 所有无人机位置数组

    Returns:
        最近距离
    """
    if len(positions) <= 1:
        return float('inf')

    pos = positions[uav_index]
    other_positions = np.delete(positions, uav_index, axis=0)
    distances = np.linalg.norm(other_positions - pos, axis=1)
    return float(np.min(distances))
```
