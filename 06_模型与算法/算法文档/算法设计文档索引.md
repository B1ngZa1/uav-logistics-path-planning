## 设计总结

### 状态空间设计

- **维度**：11维连续状态
- **编码方式**：连续状态归一化 + 离散状态独热编码
- **编码后维度**：16-31维（取决于订单数量）

### 动作空间设计

- **维度**：3维连续动作（三维加速度）
- **约束**：水平±5 m/s²，垂直±3 m/s²
- **平滑性**：Jerk限制 + EMA滤波

### 奖励函数设计

- **分量数量**：8项
- **类型**：事件触发型 + 连续型
- **稀疏奖励处理**：塑形 + 课程学习

### PPO算法设计

- **网络结构**：Actor-Critic双网络，3层全连接（256, 128, 64）
- **超参数**：学习率3e-4，折扣因子0.99，GAE λ=0.95
- **训练策略**：优先级采样 + 余弦退火 + 早停

### CTDE框架设计

- **集中式训练**：共享Actor + 集中式Critic + 全局奖励
- **分散式执行**：独立决策 + 局部观测 + 无需通信
- **通信机制**：低带宽协议 + 事件触发 + 分层架构

### 任务分配算法

- **静态分配**：贪心算法 O(M²) + 匈牙利算法 O(n³)
- **动态调整**：5种事件触发 + 负载均衡
- **端到端优化**：任务分配与路径规划联合优化
