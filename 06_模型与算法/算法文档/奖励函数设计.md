## 一、概述

### 1.1 设计目标

本文档定义无人机物流配送系统的8项奖励分量，用于PPO深度强化学习算法的训练。

### 1.2 奖励函数总览

总奖励函数采用加权求和结构：

R_total = R_goal + P_collision + P_proximity + P_formation + P_energy + P_time + P_smooth + R_delivery

## 二、奖励分量定义

### 2.1 目标到达奖励 R_goal

**类型**：事件触发型

**数学公式**：
R_goal = +100 × 1[||p_t - p_goal|| ≤ 5]

**触发条件**：距离目标点 ≤ 5米

**参数**：
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 目标奖励 | R_goal | +100 | 到达目标点的正向奖励 |
| 目标阈值 | ε_goal | 5 | 判定到达的距离阈值（米） |

### 2.2 碰撞惩罚 P_collision

**类型**：事件触发型

**数学公式**：
P_collision = -200 × 1[collision detected]

**触发条件**：碰撞检测触发

**参数**：
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 碰撞惩罚 | P_collision | -200 | 碰撞发生时的惩罚 |

### 2.3 间距惩罚 P_proximity

**类型**：连续型

**数学公式**：
P_proximity = -100 × Σ max(0, 1 - d_ij/10)

**触发条件**：无人机距离 < 10米安全距离

**参数**：
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 间距惩罚 | P_proximity | -100 | 无人机距离过近的最大惩罚 |
| 安全距离 | d_safe | 10 | 无人机间最小安全距离（米） |

### 2.4 队形保持惩罚 P_formation

**类型**：连续型

**数学公式**：
P_formation = -λ_form × (1/N) × Σ ||p_t^(i) - p_des^(i)||

**参数**：
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 队形系数 | λ_form | 1.0 | 队形偏差的权重 |

### 2.5 能耗惩罚 P_energy

**类型**：连续型

**数学公式**：
P_energy = -λ_energy × (1/N) × Σ ||a_t||²

**参数**：
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 能耗系数 | λ_energy | 0.5 | 能耗惩罚的权重 |

### 2.6 时间惩罚 P_time

**类型**：连续型

**数学公式**：
P_time = -λ_time = -1.0 (每步固定)

**参数**：
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 时间系数 | λ_time | 1.0 | 每步时间成本 |

### 2.7 平滑惩罚 P_smooth

**类型**：连续型

**数学公式**：
P_smooth = -λ_smooth × (1/N) × Σ ||Δa_t||²

**参数**：
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 平滑系数 | λ_smooth | 0.1 | 动作变化的惩罚 |

### 2.8 配送完成奖励 R_delivery

**类型**：事件触发型

**数学公式**：
R_delivery = +100 × 1[delivery completed]

**触发条件**：完成一个订单配送

**参数**：
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 配送奖励 | R_delivery | +100 | 完成单个配送的奖励 |

## 三、参数标定方法

### 3.1 分层标定策略

采用4层标定策略：

1. **核心层**：目标到达奖励、碰撞惩罚
2. **安全层**：间距惩罚
3. **编队效率层**：队形保持、能耗惩罚、时间惩罚
4. **平滑层**：平滑惩罚

### 3.2 权重平衡

基于归一化的权重平衡方法：

1. 计算各分量的典型值范围
2. 归一化到相同尺度
3. 根据重要性分配权重

## 四、稀疏奖励处理

### 4.1 奖励塑形（Potential-Based Reward Shaping）

基于势函数添加塑形奖励：

Φ(s) = -c × ||p_t - p_goal||

F = γ × Φ(s') - Φ(s)

**参数**：
| 参数 | 符号 | 值 | 说明 |
|------|------|-----|------|
| 塑形强度 | c | 0.5 | 势函数系数 |
| 折扣因子 | γ | 0.99 | 未来奖励折扣 |

### 4.2 进度奖励

R_progress = c_p × (η_t - η_{t-1})

其中 η_t = 1 - d_goal/d_goal_init 为归一化进度。

### 4.3 中间检查点

在起点和终点之间均匀插值生成3-5个路径点，每个检查点提供阶段性奖励：

R_checkpoint = +10 (到达检查点)

### 4.4 课程学习（Curriculum Learning）

分4个阶段逐步增加难度：

| 阶段 | 场景 | 进入条件 |
|------|------|----------|
| 阶段1 | 单机简单 | - |
| 阶段2 | 单机复杂 | 成功率 > 80% |
| 阶段3 | 多机协作 | 成功率 > 80%, 碰撞率 < 5% |
| 阶段4 | 完整配送 | 成功率 > 80%, 碰撞率 < 5% |

**塑形强度递减**：

c^(epoch) = c_init × (T_decay / (T_decay + epoch))

## 五、Python实现

```python
import numpy as np

class RewardCalculator:
    def __init__(self, config):
        self.R_goal = config.get('R_goal', 100)
        self.P_collision = config.get('P_collision', 200)
        self.P_proximity = config.get('P_proximity', 100)
        self.lambda_form = config.get('lambda_form', 1.0)
        self.lambda_energy = config.get('lambda_energy', 0.5)
        self.lambda_time = config.get('lambda_time', 1.0)
        self.lambda_smooth = config.get('lambda_smooth', 0.1)
        self.R_delivery = config.get('R_delivery', 100)
        self.d_safe = config.get('d_safe', 10)
        self.epsilon_goal = config.get('epsilon_goal', 5)

    def calculate_reward(self, state, action, prev_action, collision, delivery, desired_pos):
        """
        计算总奖励
        """
        position = state[:3]
        velocity = state[3:6]
        d_goal = state[6]
        d_obs = state[7]
        d_uav = state[8]

        reward = 0.0

        # 1. 目标到达奖励
        if d_goal <= self.epsilon_goal:
            reward += self.R_goal

        # 2. 碰撞惩罚
        if collision:
            reward -= self.P_collision

        # 3. 间距惩罚
        if d_uav < self.d_safe:
            reward -= self.P_proximity * (1 - d_uav / self.d_safe)

        # 4. 队形保持惩罚
        formation_error = np.linalg.norm(position - desired_pos)
        reward -= self.lambda_form * formation_error

        # 5. 能耗惩罚
        energy_cost = np.linalg.norm(action) ** 2
        reward -= self.lambda_energy * energy_cost

        # 6. 时间惩罚
        reward -= self.lambda_time

        # 7. 平滑惩罚
        smooth_cost = np.linalg.norm(action - prev_action) ** 2
        reward -= self.lambda_smooth * smooth_cost

        # 8. 配送完成奖励
        if delivery:
            reward += self.R_delivery

        return reward
```

## 七、总结

### 7.1 设计要点

1. **8项奖励分量**：涵盖目标、安全、效率、平滑四个维度
2. **事件触发+连续型**：混合奖励类型，平衡稀疏与密集信号
3. **参数可调**：支持网格搜索和敏感度分析
4. **稀疏奖励处理**：塑形、进度奖励、课程学习三层策略

### 7.2 设计优势

1. **多目标优化**：综合考虑距离、安全、能耗、时间等因素
2. **训练稳定**：奖励塑形和课程学习提高训练稳定性
3. **可解释性**：各分量物理含义清晰
4. **灵活性**：参数可根据场景调整
