# 无人机物流配送项目 - 3维连续动作空间设计文档

## 一、概述

### 1.1 设计目标

本文档定义无人机物流配送系统的3维连续动作空间，用于PPO深度强化学习算法的训练与执行。

### 1.2 动作空间总览

动作向量 a ∈ R^3 由以下3个维度组成：

a = [ax, ay, az]^T

其中：
- ax: X方向水平加速度
- ay: Y方向水平加速度
- az: Z方向垂直加速度

---

## 二、动作空间定义

### 2.1 动作维度

| 维度 | 符号 | 物理含义 | 最小值 | 最大值 | 单位 |
|------|------|----------|--------|--------|------|
| 1 | ax | X方向水平加速度 | -5 | 5 | m/s² |
| 2 | ay | Y方向水平加速度 | -5 | 5 | m/s² |
| 3 | az | Z方向垂直加速度 | -3 | 3 | m/s² |

### 2.2 动作约束

**加速度边界硬约束**：
- |ax| ≤ 5 m/s²
- |ay| ≤ 5 m/s²
- |az| ≤ 3 m/s²

**合速度上限**：
- |v| = sqrt(vx² + vy² + vz²) ≤ 15 m/s

**高度范围硬约束**：
- 10 ≤ z ≤ 50 m

**空域边界硬约束**：
- 0 ≤ x ≤ 100 m
- 0 ≤ y ≤ 100 m

---

## 三、动作有效性检测

### 3.1 五步检测-修正流水线

```
步骤1：加速度边界裁剪
    clip(a, -a_max, a_max)

步骤2：Jerk限幅
    clip(delta_a, -jerk_max*dt, jerk_max*dt)

步骤3：EMA低通滤波
    a_smooth = alpha*a_new + (1-alpha)*a_old

步骤4：速度投影裁剪
    v_safe = v/max(1, |v|/v_max)

步骤5：位置边界反向推力和高度夹紧
```

### 3.2 Jerk限制参数

| 参数 | 符号 | 水平值 | 垂直值 | 单位 |
|------|------|--------|--------|------|
| Jerk上限 | jerk_max | 20 | 15 | m/s³ |
| 时间步长 | dt | 0.1 | 0.1 | s |
| 加速度变化量 | delta_a_max | 2.0 | 1.5 | m/s² |

### 3.3 EMA滤波系数

自适应EMA滤波系数：

alpha = 0.5 + 0.5 * d_obs / d_safe

- 近障碍时 alpha → 1（减少平滑提高响应）
- 远障碍时 alpha → 0.5（增加平滑提高品质）

---

## 四、动作平滑性处理

### 4.1 平滑度代价函数

J_t = 0.4 * J_jerk + 0.4 * J_turn + 0.2 * J_osc

其中：
- J_jerk：归一化Jerk平方
- J_turn：归一化转向角速度平方
- J_osc：加速度反向振荡检测

### 4.2 转向平滑约束

| 约束类型 | 符号 | 值 | 单位 |
|----------|------|-----|------|
| 水平转向角速度 | omega | π/3 | rad/s |
| 方向一致性约束 | psi | π/2 | rad |

### 4.3 边界预警机制

| 参数 | 符号 | 值 | 单位 |
|------|------|-----|------|
| 边界预警距离 | d_b | 5 | m |
| 制动增益 | k_b | 2.0 | s⁻¹ |

## 五、状态更新方程

### 5.1 运动学方程

采用半隐式欧拉积分：

```
v_{t+1} = v_t + a_t * dt
p_{t+1} = p_t + v_{t+1} * dt
```

### 5.2 完整状态更新流水线

对应代码实现：`07_仿真与控制代码/Python仿真/utils/action_processor.py`

```python
import numpy as np


class ActionProcessor:
    """
    动作处理器 - 3维连续动作空间的裁剪、约束检查、平滑与映射

    处理流水线：
        raw_action -> process_action -> check_velocity_constraint
                     -> smooth_action -> apply_jerk_limit -> tanh_mapping
    """

    def __init__(self, config):
        """
        Args:
            config: dict, 包含以下键（括号内为默认值）：
                a_max (5.0): 最大加速度 (m/s^2)
                v_max (15.0): 最大合速度 (m/s)
                dt (0.1): 仿真时间步长 (s)
                jerk_max_xy (20.0): 水平Jerk上限 (m/s^3)
                jerk_max_z (15.0): 垂直Jerk上限 (m/s^3)
        """
        self.a_max = config.get('a_max', 5.0)
        self.v_max = config.get('v_max', 15.0)
        self.dt = config.get('dt', 0.1)
        self.jerk_max_xy = config.get('jerk_max_xy', 20.0)
        self.jerk_max_z = config.get('jerk_max_z', 15.0)

    def process_action(self, raw_action):
        """
        步骤1：加速度边界裁剪

        将原始动作裁剪到 [-a_max, a_max] 的有效范围内。
        水平分量(ax, ay)和垂直分量(az)使用统一上限，如需分别约束
        可自行扩展为 np.array([a_xy_max, a_xy_max, a_z_max])。

        Args:
            raw_action: (3,) 原始加速度 [ax, ay, az]

        Returns:
            action: (3,) 裁剪后的加速度
        """
        action = np.clip(raw_action, -self.a_max, self.a_max)
        return action

    def check_velocity_constraint(self, velocity, action):
        """
        步骤2：速度约束检查与投影裁剪

        预测下一步速度，若超出 v_max 则缩放动作分量，
        使新速度恰好不超过上限。

        Args:
            velocity: (3,) 当前速度 [vx, vy, vz]
            action:   (3,) 加速度动作

        Returns:
            valid_action: (3,) 满足速度约束的动作
        """
        new_velocity = velocity + action * self.dt
        speed = np.linalg.norm(new_velocity)

        if speed > self.v_max:
            # 缩放动作以满足速度约束
            scale = (self.v_max - np.linalg.norm(velocity)) / (
                np.linalg.norm(action) * self.dt + 1e-8
            )
            action = action * max(scale, 0)

        return action

    def smooth_action(self, current_action, prev_action, alpha=0.3):
        """
        步骤3：EMA低通滤波平滑

        a_smooth = alpha * a_new + (1 - alpha) * a_old

        alpha 越小平滑越强；近障碍物时应增大 alpha 以提高响应速度。
        自适应公式：alpha = 0.5 + 0.5 * d_obs / d_safe

        Args:
            current_action: (3,) 当前动作
            prev_action:    (3,) 上一步动作，首次调用时传 None
            alpha:          float, 平滑系数 (0, 1]

        Returns:
            smoothed_action: (3,) 平滑后的动作
        """
        if prev_action is None:
            return current_action
        return alpha * current_action + (1 - alpha) * prev_action

    def apply_jerk_limit(self, current_action, prev_action):
        """
        步骤4：Jerk限幅

        限制相邻时间步之间的加速度变化量，防止突变：
            delta_a = clip(a_t - a_{t-1}, -jerk_max * dt, jerk_max * dt)
            a_limited = a_{t-1} + delta_a

        水平(ax, ay)和垂直(az)使用不同的 jerk_max 上限。

        Args:
            current_action: (3,) 当前加速度
            prev_action:    (3,) 上一步加速度，首次调用时传 None

        Returns:
            limited_action: (3,) Jerk限幅后的加速度
        """
        if prev_action is None:
            return current_action

        delta_a = current_action - prev_action
        jerk_limit = np.array([
            self.jerk_max_xy * self.dt,
            self.jerk_max_xy * self.dt,
            self.jerk_max_z  * self.dt,
        ])
        delta_a = np.clip(delta_a, -jerk_limit, jerk_limit)
        return prev_action + delta_a

    def tanh_mapping(self, raw_action, a_max=None):
        """
        tanh动作映射

        将网络输出的无界值映射到有界动作空间：
            a_final = tanh(a_raw) * a_max

        此映射保证输出始终在 [-a_max, a_max] 之间，且保留梯度信息，
        适用于PPO高斯策略的连续动作输出。

        Args:
            raw_action: (3,) 网络原始输出
            a_max:      float 或 (3,) array, 各维度加速度上限，
                        默认使用 self.a_max

        Returns:
            mapped_action: (3,) 映射后的加速度
        """
        if a_max is None:
            a_max = self.a_max
        return np.tanh(raw_action) * a_max

    def apply_action(self, state, action, prev_action=None):
        """
        应用动作更新状态 - 完整流水线

        按照五步检测-修正流水线处理动作并更新运动状态：
            1. 加速度边界裁剪
            2. Jerk限幅
            3. EMA低通滤波
            4. 速度更新与投影裁剪
            5. 位置更新与边界夹紧

        Args:
            state:        dict, 包含以下键：
                              'position': (3,) [x, y, z]
                              'velocity': (3,) [vx, vy, vz]
            action:       (3,) 原始加速度动作
            prev_action:  (3,) 上一步加速度，首次调用时传 None

        Returns:
            new_state: dict, 更新后的状态
                       {'position': (3,), 'velocity': (3,)}
        """
        # 1. 加速度裁剪
        action = self.process_action(action)

        # 2. Jerk限幅
        action = self.apply_jerk_limit(action, prev_action)

        # 3. EMA滤波（默认alpha，实际应根据障碍物距离自适应计算）
        action = self.smooth_action(action, prev_action, alpha=0.5)

        # 4. 速度更新
        velocity = state['velocity'] + action * self.dt

        # 5. 速度投影
        speed = np.linalg.norm(velocity)
        if speed > self.v_max:
            velocity = velocity * self.v_max / speed

        # 6. 位置更新
        position = state['position'] + velocity * self.dt

        # 7. 边界处理（x, y: [0, 100], z: [10, 50]）
        position = np.clip(position, [0, 0, 10], [100, 100, 50])

        return {'position': position, 'velocity': velocity}
```

## 六、PPO集成

### 6.1 高斯策略

Actor网络输出动作均值μ和对数标准差log_σ：

```
μ, log_σ = Actor(s)
σ = exp(log_σ)
a ~ N(μ, σ²)
a_final = tanh(a) * a_max
```

### 6.2 Jacobian修正

对数概率需进行tanh变换的Jacobian修正：

log π(a|s) = log N(u;μ,σ²) - Σ log(1-tanh²(u_i))

### 6.3 ActionProcessor与PPO算法的接口

ActionProcessor作为动作后处理模块，位于Actor网络输出与环境`step()`调用之间。以下说明各方法在PPO训练流程中的调用时机与角色。

#### 6.3.1 训练流程中的调用顺序

```
PPO训练循环 (每个时间步):
  1. obs = env.reset()  /  obs = next_obs
  2. mu, log_sigma = actor(obs)           # Actor网络前向传播
  3. raw_action = sample from N(mu, sigma) # 采样原始动作
  4. action = processor.tanh_mapping(raw_action, a_max)  # tanh映射到物理范围
  5. log_prob -= sum(log(1 - tanh(raw_action)^2))        # Jacobian修正
  6. action = processor.check_velocity_constraint(velocity, action)  # 速度约束
  7. action = processor.smooth_action(action, prev_action, alpha)     # EMA平滑
  8. action = processor.apply_jerk_limit(action, prev_action)         # Jerk限幅
  9. next_obs, reward, done, info = env.step(action)  # 环境交互
  10. store (obs, action, log_prob, reward, value) in buffer
```

#### 6.3.2 各方法的接口说明

| 方法 | 输入 | 输出 | PPO中的角色 |
| --- | --- | --- | --- |
| `tanh_mapping(raw_action, a_max)` | Actor网络原始输出 (3,) | 有界加速度 (3,) | 将无界采样值映射到物理可行范围，保证梯度可回传 |
| `process_action(raw_action)` | 原始加速度 (3,) | 裁剪后加速度 (3,) | 硬裁剪保底，用于环境内部或评估阶段 |
| `check_velocity_constraint(velocity, action)` | 当前速度、加速度 | 调整后加速度 (3,) | 防止动作导致速度越界，训练时作为安全层 |
| `smooth_action(current, prev, alpha)` | 当前动作、上步动作 | 平滑后动作 (3,) | 抑制策略抖动，提高轨迹平滑性 |
| `apply_jerk_limit(current, prev)` | 当前动作、上步动作 | 限幅后动作 (3,) | 限制加速度突变率，保证物理可行性 |

#### 6.3.3 代码示例：PPO采样函数

```python
def ppo_select_action(actor, processor, obs, prev_action, velocity):
    """
    PPO策略网络采样动作并经ActionProcessor后处理。

    Args:
        actor:       Actor网络，输入obs，输出 (mu, log_sigma)
        processor:   ActionProcessor实例
        obs:         (obs_dim,) 观测向量
        prev_action: (3,) 上一步动作，第一步为None
        velocity:    (3,) 当前速度

    Returns:
        action:   (3,) 最终施加到环境的动作
        log_prob: scalar, 经Jacobian修正的对数概率
    """
    import torch
    import torch.distributions as dist

    # Actor前向传播
    mu, log_sigma = actor(torch.FloatTensor(obs))
    sigma = torch.exp(log_sigma)

    # 从高斯分布采样
    normal = dist.Normal(mu, sigma)
    u = normal.rsample()  # 重参数化采样

    # tanh映射到物理范围
    action_tensor = torch.tanh(u) * processor.a_max

    # Jacobian修正的对数概率
    log_prob = normal.log_prob(u) - torch.log(1 - torch.tanh(u).pow(2) + 1e-6)
    log_prob = log_prob.sum(dim=-1)

    # 转为numpy进行后处理
    action = action_tensor.detach().numpy()

    # 速度约束 + 平滑 + Jerk限幅
    action = processor.check_velocity_constraint(velocity, action)
    action = processor.smooth_action(action, prev_action, alpha=0.5)
    action = processor.apply_jerk_limit(action, prev_action)

    return action, log_prob
```

#### 6.3.4 评估与训练模式的差异

| 环节 | 训练模式 | 评估模式 |
| --- | --- | --- |
| 动作采样 | `u ~ N(mu, sigma)` 随机探索 | `u = mu` 确定性策略 |
| tanh映射 | 必须执行，保留梯度 | 必须执行，使用numpy |
| 后处理 | check/smooth/jerk 全部启用 | 同训练模式，保证一致性 |
| log_prob | 计算并存入buffer | 不需要计算 |

## 八、总结

### 8.1 设计要点

1. **3维连续动作空间**：三维加速度控制，实现精细轨迹规划
2. **多层约束处理**：加速度边界→速度上限→高度空域→平滑性
3. **自适应平滑**：根据障碍物距离动态调整滤波系数
4. **PPO兼容**：支持高斯策略和Jacobian修正

### 8.2 设计优势

1. **物理可行**：所有动作满足运动学约束
2. **平滑控制**：Jerk限制和EMA滤波确保动作平滑
3. **安全边界**：多层边界保护防止越界
4. **训练稳定**：梯度裁剪和约束处理提高训练稳定性
