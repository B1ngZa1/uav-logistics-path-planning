## 快速开始

### 1. 算法设计概览

本项目采用深度强化学习PPO算法，实现多无人机协同物流配送路径规划。核心算法设计包括：

- **状态空间**：11维连续状态（位置、速度、距离、电量、任务进度）
- **动作空间**：3维连续动作（三维加速度）
- **奖励函数**：8项奖励分量（目标、安全、效率、平滑）
- **PPO算法**：Actor-Critic网络 + 裁剪目标 + GAE优势估计
- **CTDE框架**：集中式训练 + 分散式执行
- **任务分配**：贪心/匈牙利算法 + 动态调整 + 端到端优化

### 2. 关键参数

| 参数类别 | 核心参数 | 推荐值 |
|----------|----------|--------|
| 状态空间 | 编码维度 | 16-31 |
| 动作空间 | 加速度上限 | 5/3 m/s² |
| 奖励函数 | 目标奖励 | +200 |
| 奖励函数 | 碰撞惩罚 | -200 |
| PPO | 学习率 | 3e-4 |
| PPO | 折扣因子 | 0.99 |
| PPO | 裁剪参数 | 0.2 |
| CTDE | 无人机数量 | 3-6架 |
| 任务分配 | 订单数量 | 5-20个 |

### 3. 文档阅读顺序

建议按以下顺序阅读算法设计文档：

1. **状态空间设计** → 了解系统状态定义
2. **动作空间设计** → 了解控制动作定义
3. **奖励函数设计** → 了解优化目标
4. **PPO算法设计** → 了解核心算法
5. **CTDE框架设计** → 了解多机协同框架
6. **任务分配算法** → 了解任务分配策略
7. **完整算法伪代码** → 了解整体算法流程

## 算法流程

```
系统初始化
    ↓
主循环 (每dt=0.1s)
    ├── 状态更新 (位置、速度、电量)
    ├── 事件检测 (碰撞、配送、电量)
    ├── 任务分配决策 (贪心/匈牙利/RL)
    ├── 路径规划 (PPO策略网络)
    ├── 动作执行 (4层约束处理)
    ├── 奖励计算 (8项分量)
    └── 终止检查 (完成/超时/电量不足)
    ↓
训练循环
    ├── 经验收集 (2048步)
    ├── GAE优势估计
    ├── 策略更新 (K=4轮)
    ├── 学习率调度 (余弦退火)
    ├── 日志记录
    ├── 检查点保存
    └── 早停检查
```
