## 二、算法设计成果

### 2.1 状态空间设计

**核心设计**：
- **维度**：11维连续状态
- **组成**：位置(3) + 速度(3) + 距离(3) + 电量(1) + 任务进度(1)
- **编码方式**：连续状态Min-Max归一化 + 离散状态独热编码
- **编码后维度**：16-31维（取决于订单数量M）

**关键参数**：
| 参数 | 值 | 说明 |
|------|-----|------|
| 空域范围 | [0,100]×[0,100]×[10,120] | 米 |
| 速度范围 | [-15,15] | m/s |
| 安全距离 | 10 | 米 |
| 批次大小 | 256 | 训练采样 |

### 2.2 动作空间设计

**核心设计**：
- **维度**：3维连续动作（三维加速度）
- **约束**：水平±5 m/s²，垂直±3 m/s²
- **平滑性**：Jerk限制 + EMA滤波 + 转向平滑
- **有效性检测**：五步检测-修正流水线

**关键参数**：
| 参数 | 值 | 说明 |
|------|-----|------|
| 水平加速度上限 | 5 | m/s² |
| 垂直加速度上限 | 3 | m/s² |
| 最大速度 | 15 | m/s |
| Jerk上限 | 20/15 | m/s³ (水平/垂直) |

### 2.3 奖励函数设计

**核心设计**：
- **分量数量**：8项
- **类型**：事件触发型(3) + 连续型(5)
- **稀疏奖励处理**：塑形 + 进度奖励 + 课程学习

**奖励分量**：
| 分量 | 符号 | 类型 | 基准值 |
|------|------|------|--------|
| 目标到达奖励 | R_goal | 事件触发 | +200 |
| 碰撞惩罚 | P_collision | 事件触发 | -200 |
| 间距惩罚 | P_proximity | 连续 | -100 (max) |
| 队形保持惩罚 | λ_form | 连续 | -1.0/step |
| 能耗惩罚 | λ_energy | 连续 | -0.5/step |
| 时间惩罚 | λ_time | 连续 | -2.0/step |
| 平滑惩罚 | λ_smooth | 连续 | -0.1/step |
| 配送完成奖励 | R_delivery | 事件触发 | +50 |

### 2.4 PPO算法设计

**核心设计**：
- **网络结构**：Actor-Critic双网络，3层全连接（256, 128, 64）
- **超参数**：学习率3e-4，折扣因子0.99，GAE λ=0.95
- **训练策略**：优先级采样 + 余弦退火 + 早停

**关键超参数**：
| 参数 | 符号 | 值 |
|------|------|-----|
| 学习率 | lr | 3e-4 |
| 折扣因子 | γ | 0.99 |
| GAE参数 | λ | 0.95 |
| 裁剪参数 | ε | 0.2 |
| 批次大小 | B | 256 |
| 训练轮次 | N_epochs | 1000 |

### 2.5 CTDE框架设计

**核心设计**：
- **集中式训练**：共享Actor + 集中式Critic + 全局奖励
- **分散式执行**：独立决策 + 局部观测 + 无需通信
- **通信机制**：低带宽协议 + 事件触发 + 分层架构

**框架特点**：
1. 共享Actor网络提高参数效率
2. 集中式Critic学习全局价值
3. 分散式执行降低通信开销
4. 支持3-6架无人机协同

### 2.6 任务分配算法

**核心设计**：
- **静态分配**：贪心算法 O(M²) + 匈牙利算法 O(n³)
- **动态调整**：5种事件触发 + 负载均衡
- **端到端优化**：任务分配与路径规划联合优化

**分配策略**：
| 算法 | 复杂度 | 适用场景 |
|------|--------|----------|
| 贪心算法 | O(M²) | 实时动态场景 |
| 匈牙利算法 | O(n³) | 静态批量分配 |
| 强化学习 | - | 端到端优化 |

### 2.7 算法伪代码

**核心内容**：
- **整体流程**：系统初始化 → 主循环 → 状态更新 → 事件检测 → 任务分配 → 路径规划 → 动作执行 → 奖励计算 → 终止检查
- **核心函数**：20个函数覆盖状态编码、动作选择、碰撞检测、奖励计算、任务分配
- **PPO训练**：7个阶段循环（经验收集 → GAE估计 → 策略更新 → 学习率调度 → 日志记录 → 检查点保存 → 早停检查）
