## 一、约束体系概述

多无人机协同系统需要满足多维约束，确保安全、高效运行。约束体系包括：

- 安全距离约束
- 通信约束
- 时序约束
- 资源约束
- 队形保持约束

---

## 二、安全距离约束

### 2.1 无人机间安全距离

**约束条件**：
$$||p_i - p_j||_2 \geq d_{safe}^{uav}, \quad \forall i \neq j$$

参数：$d_{safe}^{uav} = 10$ 米

**碰撞判定**：
$$\text{collision}(i,j) = \begin{cases} 1 & \text{if } ||p_i - p_j||_2 < d_{safe}^{uav} \\ 0 & \text{otherwise} \end{cases}$$

### 2.2 障碍物安全距离

**约束条件**：
$$||p - o||_2 \geq d_{safe}^{obs}, \quad \forall o \in \mathcal{O}$$

参数：$d_{safe}^{obs} = 5$ 米

### 2.3 地面安全高度

**约束条件**：
$$z \geq h_{min}$$

参数：$h_{min} = 10$ 米

---

## 三、通信约束

### 3.1 通信距离约束

$$||p_i - p_j||_2 \leq R_{comm}, \quad \text{if communicating}$$

参数：$R_{comm} = 500$ 米

### 3.2 事件触发通信

触发条件：

- 距离小于阈值
- 任务状态变化
- 紧急事件（碰撞预警）

---

## 四、时序约束

### 4.1 配送时间窗口

$$t_{arrival} \in [t_{earliest}, t_{latest}]$$

### 4.2 起降时序

同一起降点，无人机起降需保持时间间隔：
$$|t_i - t_j| \geq \Delta t_{sep}$$

参数：$\Delta t_{sep} = 5$ 秒

---

## 五、资源约束

### 5.1 电池容量约束

$$E_{consumed} \leq E_{capacity} \times (1 - \alpha_{safe})$$

参数：$E_{capacity} = 500$ Wh, $\alpha_{safe} = 0.15$

### 5.2 负载能力约束

$$m_{payload} \leq m_{max}$$

---

## 六、队形保持约束

### 6.1 编队队形定义

支持V字形、直线形、菱形编队。

**相对位置矩阵**：
$$\mathbf{F} = [f_{ij}] \in \mathbb{R}^{N \times N}$$

### 6.2 容忍偏差

$$||p_i - p_i^{target}||_2 \leq \delta_{form}$$

参数：$\delta_{form} = 5$ 米

## 七、Python实现

```python
import numpy as np

class ConstraintChecker:
    """协同约束检查器"""

    def __init__(self):
        self.d_safe_uav = 10.0      # UAV间安全距离(m)
        self.d_safe_obs = 5.0       # 障碍物安全距离(m)
        self.h_min = 10.0           # 最小安全高度(m)
        self.R_comm = 500.0         # 通信距离(m)
        self.dt_sep = 5.0           # 起降间隔(s)
        self.E_capacity = 500.0     # 电池容量(Wh)
        self.alpha_safe = 0.15      # 安全余量
        self.delta_form = 5.0       # 队形容忍偏差(m)

    def check_uav_collision(self, positions):
        """检查UAV间碰撞"""
        n = len(positions)
        collisions = []
        for i in range(n):
            for j in range(i+1, n):
                dist = np.linalg.norm(positions[i] - positions[j])
                if dist < self.d_safe_uav:
                    collisions.append((i, j, dist))
        return collisions

    def check_obstacle_collision(self, position, obstacles):
        """检查障碍物碰撞"""
        for obs in obstacles:
            dist = np.linalg.norm(position - obs['center']) - obs['radius']
            if dist < self.d_safe_obs:
                return True, dist
        return False, float('inf')

    def check_height_constraint(self, position):
        """检查高度约束"""
        return position[2] >= self.h_min

    def check_communication(self, pos_i, pos_j):
        """检查通信距离"""
        dist = np.linalg.norm(pos_i - pos_j)
        return dist <= self.R_comm

    def check_energy_constraint(self, energy_consumed):
        """检查能量约束"""
        max_energy = self.E_capacity * (1 - self.alpha_safe)
        return energy_consumed <= max_energy

    def check_formation(self, positions, target_positions):
        """检查队形保持"""
        deviations = []
        for i, (pos, target) in enumerate(zip(positions, target_positions)):
            dev = np.linalg.norm(pos - target)
            deviations.append(dev)
            if dev > self.delta_form:
                return False, deviations
        return True, deviations

    def compute_constraint_penalty(self, positions, obstacles, energy_consumed):
        """计算约束违反惩罚"""
        penalty = 0.0

        # UAV间碰撞惩罚
        collisions = self.check_uav_collision(positions)
        penalty += len(collisions) * 100.0

        # 障碍物碰撞惩罚
        for pos in positions:
            hit, dist = self.check_obstacle_collision(pos, obstacles)
            if hit:
                penalty += 100.0
            elif dist < self.d_safe_obs * 2:
                penalty += 10.0 * (1 - dist / (self.d_safe_obs * 2))

        # 高度约束惩罚
        for pos in positions:
            if not self.check_height_constraint(pos):
                penalty += 50.0

        # 能量约束惩罚
        if not self.check_energy_constraint(energy_consumed):
            penalty += 200.0

        return penalty
```
