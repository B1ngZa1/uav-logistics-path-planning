# 空中走廊设计交付包

本目录给出“高度分层空中走廊 + 路口变道/合流/冲突消解 + 多无人机路径规划”的可复现设计。它是交通规划层规范，不修改原项目 PPO、环境和实验脚本。

## 文件

- `model_spec.md`：高度如何由障碍物、风险、通信、能耗和法规假设确定；层、车道、变道、合流和间隔规则。
- `数学模型.md`：状态、动作、转移、目标函数、碰撞/间隔/能耗/时间/容量/电量约束与量纲检查。
- `参数表.csv`：示例参数、项目基线、法规占位和来源性质的分层清单。
- `algorithm_pseudocode.md`：图搜索、预约/CBS、动作 mask、安全投影和 MAPPO/CTDE 训练伪代码。
- `toy_simulation.py`：只依赖 Python 标准库的小规模原型，演示高度选层、合流预约、变道请求和安全距离敏感性。
- `references.md`：可核验法规、标准框架、论文和项目内部来源。

## 复现

在项目根目录执行：

```powershell
python .\06_模型与算法\空中走廊设计\toy_simulation.py
```

预期输出包含：

1. L1 因 25 m 障碍物 + 5 m 净空不满足而被拒绝，选用 L2；
2. 4 架无人机经过共享路口时生成不重叠的冲突区时隙；
3. 车道变更请求只有在变道区、目标车道容量和安全间隔均满足时才通过；
4. `d_safe_uav=5/10/15 m` 的敏感性表，以及最小预约间隔/最小净距。

## 使用注意

项目当前存在多套历史参数：主 3D 配置为 `z=[10,50] m`、`dt=0.1 s`，武汉分区配置为 `z=[10,200] m` 且有 `physics_dt=0.1 s/control_dt=0.5 s`。本目录把它们视为不同实验基线，不隐式拼接。

10 m/5 m 安全距离、示例层带、通信阈值、优先级和时隙参数均不是法规结论。真实部署前必须用批准空域、机型包络、定位误差、通信测量、飞控制动能力和运行程序重新标定。
